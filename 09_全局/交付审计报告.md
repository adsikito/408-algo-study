## 五、核实方法（可直接执行）

### 5.1 题库 60 题的链接有效性复验

```bash
cd "C:\Users\freecss\Desktop\资料\00_学习工程"
# 抽取全部链接
grep -oE "https?://[^ )|]+" "02_竞赛/03_题库/_题库总表.md" | sort -u > /tmp/urls.txt
wc -l /tmp/urls.txt
# 逐个探测（-I 只看响应头，--max-time 限时）
while read u; do
  code=$(curl -s -o /dev/null -w "%{http_code}" -I --max-time 8 "$u")
  echo "$code  $u"
done < /tmp/urls.txt | sort | uniq -c
```
