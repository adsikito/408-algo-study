## 三、本目录不放什么

| 类别 | 应当放的位置 | 理由 |
|------|------------|------|
| 规范文档（`21` 至 `25`） | `20_规范\` | 它们是提示词的引用真源，属工作文档，不属内容库 |
| 提示词（`11` 至 `17`） | `10_提示词\` | 同上 |
| 各分类的笔记 | `01_考研\`、`02_竞赛\` | 按分类归属 |
| 题库与知识点真源 | `02_竞赛\03_题库\` | 题库独立于笔记目录，便于跨阶段引用 |

### 为什么不把规范文档放进内容库

内容库（`01_考研\`、`02_竞赛\`、`03_常规课程\`）的定位是**学习材料**，
要被发布到 GitHub、要在 Obsidian 里阅读。

而规范文档是**生产工具**——它们规定「怎么产出学习材料」，
对读者没有价值，放在内容库里会稀释密度。

因此采用二分：

```text
工作区根目录  ──►  工作文档（提示词 + 规范 + 方案 + 工具）
内容库        ──►  学习材料（笔记 + 题库 + 附录）
```

两者的关系见 `README_学习工程总纲.md` 第三节的依赖关系图。
