```text

> 课件来源 / 配套代码          ← 溯源信息
## 本章地图                     ← 白话引入 + 学习路线
## 本章重点（3-5个）            ← 原文以符号图标标注
## 本章难点（2-3个）            ← 原文以符号图标标注
## 本章易错点（3-5个）          ← 原文以符号图标标注
## 知识点讲解
   每个知识点固定三段式：**是什么** / **为什么** / **怎么用**
   含对比表格、注意事项、规律、一句话总结（原文均以符号图标标注）
## 例题 / 代码                  ← 带注释的 C/C++ 代码
```

> **格式说明**：现有笔记大量使用 emoji 与装饰性符号作为标记。本次产出的两套笔记**一律改用纯 Markdown 原生语法**（加粗、引用块、方括号标签），不保留任何 emoji。因此整合原资料内容时，需逐段转换标记形式，不得直接复制带入。

**结论**：现有笔记**不是原始素材，而是已加工的成品**。本任务的价值不在「重写」，而在于**考研/竞赛双轨重组 + 学习先后顺序重排 + 优先级标注 + 前置与延伸知识点补充 + 缺口补齐 + 赛事题源映射**。

   ↓

   ↓
