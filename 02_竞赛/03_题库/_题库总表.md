# 题库总表

> **作用**：题目的**元数据单一真源**。题号、链接、涉及知识点、状态、代码文件全部在此登记。
> **不在此处的内容**：题面（在链接里）、代码（在 `代码\` 下）、思路详解（在 `题解\` 下，可选）。
> **组织方式**：按「阶段 → 知识点」分组，**不按平台排列**。理由见 `33_笔记题库知识点组织方案.md` 第 4.2 节。
> **配套**：`_知识点索引.md`（知识点真源）、`check_bank.py`（一致性校验）

---

## 使用方式

```text
第 1 步　学     在笔记里读完知识点
第 2 步　登记   在本表对应阶段下加一行（先登记，后做题）
第 3 步　做     在「代码\」下建 <题目编号>.cpp，状态改「已做」
第 4 步　复盘   通过改「已通过」；未通过记录原因并改「待复习」
```

**列说明**：

| 列 | 含义 |
|----|------|
| 题号 | 格式 `<平台小写>-<原题号>`，如 `luogu-P5788` |
| 题名 | 题目名，末尾附难度标签 `【入门】` 或 `【进阶】` |
| 链接 | 题目地址，**唯一保存处**。笔记中只写题号，不重复链接 |
| 知识点 | `主 · 副`，主知识点决定这道题归属哪个阶段分组 |
| 状态 | `未做` / `已做` / `已通过` / `待复习` |
| 代码 | `代码\` 下的文件名；未写时为 `—` |

> **【要点】** 状态为 `已通过` 时，`代码\` 下**必须**有对应文件，否则 `check_bank.py` 会报错。
