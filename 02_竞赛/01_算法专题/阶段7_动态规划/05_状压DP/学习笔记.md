## 🗺️ 本章地图

> **本章解决一个问题：状态太多存不下时，怎么把"一整行/一整个集合"压成一个二进制数来做DP？**
> 路线是"工具 → 思想 → 技巧 → 实战"：先备好基本功——位运算五大技巧（知识点 1）；再理解状压的本质——以集合为状态、一数一状态（2）；然后学两个关键套路——合法状态预处理与枚举子集（3）；最后用 P1896 互不侵犯把"行内限制 + 行间限制"全部翻译成与运算（4）。
> 学完请自测三件事：会不会用 `(1<<(i-1))&x` 判断第 i 位？能不能用三个 `&` 判断上下两行国王是否冲突？说清为什么状压DP只能处理 n≤20 量级的小规模问题？

## 📌 本章重点（3-5个）

⭐ **位运算技巧**：判断/置1/清0第 i 位、去掉最右的 1、`__builtin_popcount` 数 1 的个数
⭐ **状态压缩的本质**：每个单元只有两种状态（0/1），把一串 0/1 压成一个整数，一数即一状态
⭐ **合法状态预处理**：行内不冲突的状态先筛出来存表（状态数远小于 2^n），dp 时只在合法状态间转移
⭐ **行间冲突的位运算判断**：`S1&S2`、`(S2<<1)&S1`、`(S2>>1)&S1` 三个与运算分别查正下、右下、左下
⭐ **状态设计三件套**：dp[i][j][S] = 前 i 行、用了 j 个棋子、第 i 行状态为 S 的方案数

## 🔥 本章难点（2-3个）

🔥 **把"位置限制"翻译成位运算**：九宫格攻击范围 → 正下查 `S1&S2`、右下先 `S2<<1` 对齐再与、左下先 `S2>>1`，方向和移位极易搞反
🔥 **枚举子集 `S1=(S1-1)&S` 的原理**：为什么这样跳能不重不漏地遍历 S 的所有非空子集
🔥 **三维状态的转移推导**：dp[i][j][S] 要从 dp[i-1][j-cnt[S]][S1] 转移，j 的扣除与 cnt 预处理必须对齐

## ⚠️ 本章易错点（3-5个）

⚠️ **移位方向记反**：`(S2<<1)&S1` 查的是"本行棋子在上一行棋子右下方"的冲突，左移右移对应哪个斜向要自己画图推，不能背
⚠️ **行内合法判断只写一半**：`s&(s<<1)` 和 `s&(s>>1)` 查的是同一种相邻，写一个即可，但必须保证是"行内自己与自己"做与，别拿两行状态做
⚠️ **忘记 dp[0][0][0]=1**：初始"第 0 行什么都不放"是唯一初始方案，漏掉则全盘答案为 0
⚠️ **答案没有 long long**：n=9,k=9 时方案数可达百万级以上，中间累加用 int 会溢出（例题代码中 dp 与 ans 都是 long long）
⚠️ **枚举子集漏掉空集**：`for(S1=S; S1; S1=(S1-1)&S)` 只枚举非空子集，需要空集时循环外单独处理

## 📖 知识点讲解

### 1. 位运算：状压DP的基本功

**是什么**：位运算就是直接对二进制的每一位做操作。状压DP里每位代表一个"事件的有无"（放/不放、选/不选），所以四大基本规律是全部技巧的地基：`1&x=x`、`0&x=0`（与：1 保留原位）、`1|x=1`、`0|x=x`（或：0 保留原位）。常用技巧五个：

```cpp
// 第 i 位（最低位算第 1 位）
if ((1 << (i-1)) & x)   // 1. 判断第 i 位是不是 1
x = x | (1 << (i-1));   // 2. 把第 i 位改成 1
x = x & ~(1 << (i-1));  // 3. 把第 i 位改成 0
x = x & (x - 1);        // 4. 去掉最靠右的 1
__builtin_popcount(x);  // 5. 统计二进制下 1 的个数（手写循环也行）
```

**为什么**：一个状态有 n 个"是否"型事件，开数组要 n 个 int；压成一个二进制数只要 1 个 int，而且"判断/合并/比较两个状态"全部变成一次 O(1) 的位运算，空间和时间双双受益。

**怎么用**——跟着算：x = 101001（十进制 41），判断第 2 位：`1<<1 = 000010`，`101001 & 000010 = 0`，结果是 0，说明第 2 位没放；置第 2 位为 1：`101001 | 000010 = 101011`；去掉最右的 1：`101001 & 101000 = 101000`。

> ⚠️ 注意事项：课件里"第 i 位"从 1 数起，所以左移 i-1 位；若自己约定从 0 数起（代码里更常见），则左移 i 位，全文统一别混用。

> 🎯 规律：与 0 清零、与 1 保留；或 1 置一、或 0 保留。
> 💡 一句话总结：每一位就是一个开关，位运算就是遥控开关。

### 2. 状态压缩的思想与使用条件

**是什么**：状压DP = 用一个二进制数表示"一个集合的状态"，一个数就是一个状态。例如 8 枚硬币的正反结果，8 位二进制数即可完全表示，共 2^8 = 256 个状态（0~255）。它本质上是一种**暴力**：逐个遍历所有状态，以集合为状态做DP，复杂度是指数级的，只适合小规模问题。

**为什么**：DP 要求状态能被快速存取和比较。二进制数把集合压成一个 int：①存储空间从 n 降到 1；②状态整体比较、合并、判冲突都变成一次位运算。代价是状态总数 2^n，所以 n 必须很小（int 存状态则单元数不超过 32/64）。

**怎么用**——使用条件自查：
1. 每个单元只有**两种状态**（棋盘格子放/不放、硬币正/反）；
2. 有一维数据范围很小（n≤20 左右），否则 2^n 爆炸。
常见题型：棋盘类（互不攻击、连通性）、集合类（每件物品选没选过）。

> ⚠️ 注意事项：状压DP难点在位运算的运用，状态和转移方程反而相对好推——先把位运算练熟。

> 🎯 规律：两态单元 + 维度很小 = 状压的入场券。
> 💡 一句话总结：把一行状态压成一个数，一数一状态。

### 3. 合法状态预处理与枚举子集

**是什么**：两个实战套路。①**合法状态筛选**：先枚举 0 ~ 2^n-1 的所有状态，把行内就非法的（如相邻放国王）提前剔除，只把合法状态和它的 1 的个数存进 `ok[]`、`cnt[]` 表；②**枚举子集**：`for(int S1=S; S1; S1=(S1-1)&S)` 按**降序**不重不漏地枚举 S 的所有非空子集（S1 是子集，S\S1 是补集）。

**为什么**：①行内合法性只与本行有关，每行状态固定最多 2^n 个，预处理一次后 dp 时不用反复判断，且合法状态数往往远小于 2^n，省时省空间；②集合类问题常需要"从大集合里挑子集分组"，`(S1-1)&S` 恰好从 S 中剥掉最低位组合出下一个更小的子集。

**怎么用**——跟着算（n=3，国王互不相邻，筛合法状态）：

| s | 二进制 | s&(s<<1) | 行内合法？ | cnt[s] |
|---|--------|----------|-----------|--------|
| 0 | 000 | 0 | ✅ | 0 |
| 1 | 001 | 0 | ✅ | 1 |
| 2 | 010 | 0 | ✅ | 1 |
| 3 | 011 | 010≠0 | ❌ 相邻 | — |
| 4 | 100 | 0 | ✅ | 1 |
| 5 | 101 | 0 | ✅ | 2 |
| 6 | 110 | 100≠0 | ❌ 相邻 | — |
| 7 | 111 | 110≠0 | ❌ 相邻 | - |

8 个状态只剩 5 个合法（0,1,2,4,5）——这就是"先筛后存"的威力。

枚举子集——跟着算（S = 101）：

```cpp
for (int S1 = S; S1; S1 = (S1 - 1) & S)  // S1: 101 -> 100 -> 001, 然后为 0 退出
```

步骤：S1=101 → (101-1)&101 = 100&101 = 100 → (100-1)&101 = 011&101 = 001 → (001-1)&101 = 000，结束。共枚举出 101、100、001 三个非空子集（空集在循环外单独算）。

```cpp
for (int s = 0; s < (1 << n); s++)              // 预处理：筛合法状态
    if ((s & (s << 1)) == 0 && (s & (s >> 1)) == 0) {
        ok[++num] = s;
        for (int t = s; t; t &= t - 1) cnt[s]++; // 数 1 的个数
    }
```

> ⚠️ 注意事项：`s&(s<<1)` 与 `s&(s>>1)` 判断的是同一种相邻（& 的交换律），写一个就够；但两者都为 0 才代表行内无相邻 1，这一步不能省。

> 🎯 规律：非法状态提前枪毙，dp 只在合法状态间跑。
> 💡 一句话总结：先筛合法态，再跑转移表。

### 4. 例题精讲：P1896 互不侵犯（棋盘状压DP模板）

**是什么**：n×n 棋盘放 k 个国王，每个国王的九宫格内不能有其他国王，求方案数。一行的放法压成二进制数（如 101001 = 41），设 `dp[i][j][S]` = 已放完前 i 行、第 i 行状态为 S、共用了 j 个国王的方案数。

**为什么**：逐行DP时，第 i 行只受第 i-1 行影响，所以"一行"就是最小完整单元，天然适合状压。冲突拆成两层：**行内**（同一行国王不相邻）用预处理筛掉；**行间**（上下+斜对角）用三个与运算在转移时判断。

**怎么用**——行间冲突判断跟着算（上一行 S1、本行 S2）：

```
(1) 正下方冲突： S1=101001   S2=* **1** **   →  S1 & S2 != 0        不合法
(2) 右下冲突：   S1=101001   S2=***1**      →  S2 左移一位对齐后
                S1=101001   S2=**1**0      →  (S2<<1) & S1 != 0   不合法
(3) 左下冲突：   同理右移一位               →  (S2>>1) & S1 != 0   不合法
合法条件：S1&S2==0 且 ((S2<<1)&S1)==0 且 ((S2>>1)&S1)==0
```

验证一例：S1=001，S2=100 → 三个与全是 0，合法（错开对角）；S1=001，S2=010 → (010>>1)&001=001≠0，不合法（斜对角相邻）。

转移与统计（对应 `P1896.cpp`）：

```cpp
dp[0][0][0] = 1;                          // 第0行什么都不放，唯一初始方案
for (i = 1..n)                            // 枚举行
  for (本行状态 s : ok)                   // 只在合法状态里枚举
    for (上一行状态 s1 : ok)
      if (s&s1 || (s<<1)&s1 || (s>>1)&s1) continue;   // 行间冲突
      else for (j = cnt[s]..k)
        dp[i][j][s] += dp[i-1][j - cnt[s]][s1];       // 本行用掉 cnt[s] 个国王
ans = Σ dp[n][k][s]                       // 枚举第 n 行所有合法状态求和
```

复杂度：O(n × 合法状态数² × k)，合法状态数约几十个，轻松通过。

> ⚠️ 注意事项：例题代码里第二维 j 的循环放在冲突判断**之后**，能少算很多无用状态；cnt[s] 表示本行用掉的国王数，留给前 i-1 行的是 j - cnt[s] 个，两者必须配平。

> 🎯 规律：行内限制进预处理，行间限制进转移，一维一贡献。
> 💡 一句话总结：逐行压缩，三位一体，与运算查冲突。

## 🔍 相似概念辨析

**组1：状压DP vs 普通DP**

| 维度 | 状压DP | 普通DP |
|------|--------|--------|
| 状态形式 | 二进制数表示一个集合 | 下标/数值直接表示 |
| 状态总数 | 2^n，指数级 | 通常多项式级 |
| 适用规模 | 有一维 n≤20 左右 | n 可达 10^5 以上 |
| 转移操作 | 位运算（&、\|、<<、>>） | 加减乘、比较 |
| 典型问题 | 棋盘放棋子、TSP、集合划分 | 背包、LIS、区间DP |
| 本质 | 暴力遍历所有集合状态 | 利用最优子结构避免重复 |
| 核心技巧 | 合法状态预处理 + 枚举子集 | 状态设计与转移方程推导 |

**组2：二进制枚举全部状态 vs 枚举子集**

| 维度 | 枚举全部状态 | 枚举子集 |
|------|--------------|----------|
| 代码 | `for (s = 0; s < (1<<n); s++)` | `for (S1 = S; S1; S1 = (S1-1)&S)` |
| 遍历对象 | 0 ~ 2^n-1 每个数 | 大集合 S 的所有非空子集 |
| 状态数 | 2^n | 2^popcount(S)，只与 S 大小有关 |
| 空集 | 自动包含 0 | 循环外单独处理 |
| 典型用途 | 预处理每一行的合法状态 | 集合分组类DP（如斯坦纳树、分组） |
| 复杂度性质 | 固定指数 | 子集和为 3^n（枚举所有对的子集） |
| 顺序 | 升序 | 严格降序（天然保证无后效性） |

## 🧩 本章归纳

一条主线：**"两态单元 → 二进制数 → 位运算转移"**。当每个单元只有 0/1 两种状态且某一维很小时，把一行/一个集合压成一个 int；用五大位运算技巧完成"查、置、清、删、数"；先预处理行内合法状态把 2^n 砍小，再在合法状态间用三个与运算判断行间冲突做逐行转移。P1896 把这套流水线完整走了一遍：`筛合法态 → dp[0][0][0]=1 → 行×状态×状态×国王数四重循环转移 → 求和`。记住结论：状压DP是"暴力+压缩"，难点在位运算，会了位运算方程自然水到渠成。

## 📋 速查表

| 操作 | 代码 | 说明 |
|------|------|------|
| 判断第 i 位是否为 1 | `(x >> (i-1)) & 1` | 结果 1 即是 |
| 第 i 位置 1 | `x \|= 1 << (i-1)` | 或上单一位掩码 |
| 第 i 位清 0 | `x &= ~(1 << (i-1))` | 与上反掩码 |
| 去掉最右的 1 | `x &= x - 1` | 循环即 popcount |
| 数 1 的个数 | `__builtin_popcount(x)` | 手写：`while(x){x&=x-1;c++;}` |
| 枚举全部状态 | `for(s=0;s<(1<<n);s++)` | 2^n 个 |
| 枚举 S 的非空子集 | `for(S1=S;S1;S1=(S1-1)&S)` | 降序，空集另算 |
| 行内合法（不相邻） | `(s & (s<<1)) == 0` | 预处理进 ok[] |
| 行间合法（九宫格） | `!(s1&s2) && !((s2<<1)&s1) && !((s2>>1)&s1)` | 查正下/右下/左下 |
| 初始化 | `dp[0][0][0] = 1` | "全不放"是唯一起点 |
