## 本章地图

本章解决一个问题：**「n ≤ 20 的集合决策，怎么枚举得完？」**

```text
n ≤ 20（数据范围信号）→ 2ⁿ = 10⁶ 可枚举
   ↓
集合 → 二进制 mask（第 k 位 = 第 k 个元素选没选）
   ↓
两大状态形态：
   ├─ dp[mask][i]：已选集合 mask、当前在 i（TSP 型）
   └─ dp[i][mask]：前 i 行、第 i 行状态 mask（棋盘逐行型）
   ↓
转移三件套：
   ├─ 扩展集合：mask | (1 << v)
   ├─ 合法性预筛：行内（mask 自身）与行间（mask & mask'）
   └─ 子集枚举：sub = (sub − 1) & mask
```

**为什么这条路径是这样**：状压 DP 的本质是**「把枚举的单位从元素换成集合」**——
普通枚举枚举元素（n 种），状压枚举集合（2ⁿ 种），
**换来的是「任意子集信息 O(1) 可查」**（位运算）。
n ≤ 20 就是这个交换的盈亏平衡点。

## 核心概念与模板

**是什么**：把「集合」压进一个整数的二进制位（第 k 位 = 1 表示选了第 k 个元素），
DP 状态 = `dp[mask]` 或 `dp[mask][i]`。

**为什么**：适用前提：**集合规模 ≤ 20**（2²⁰ = 10⁶）——数据范围反推算法的第一直觉
（阶段 0 0-1 的基准表）。识别信号：n ≤ 20 且「互相影响 / 顺序约束 / 覆盖关系」。

> **【规律】** **位运算口诀三件套**：取第 k 位 `mask >> k & 1`；
> 置 1 `mask |= 1 << k`；置 0 `mask &= ~(1 << k)`。
> **`mask | (1 << v)` 千万别写成 `mask + (1 << v)`**——v 已置 1 时加法会进位污染。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
typedef long long ll;
const int N = 20;
int n;
ll w[N][N], dp[1 << N][N];                /* dp[mask][i]：已访集合 mask、当前在 i */

/* 1. TSP 旅行商：O(2^n × n^2) */
void tsp() {
    memset(dp, 0x3f, sizeof(dp));
    dp[1][0] = 0;                         /* 起点 0，集合 {0} */
    for (int mask = 1; mask < (1 << n); mask++)
        for (int u = 0; u < n; u++) {
            if (!(mask >> u & 1) || dp[mask][u] == 0x3f3f3f3f3f3f3f3fLL) continue;
            for (int v = 0; v < n; v++)
                if (!(mask >> v & 1))
                    dp[mask | (1 << v)][v] =
                        min(dp[mask | (1 << v)][v], dp[mask][u] + w[u][v]);
        }
    /* 答案：min(dp[(1<<n)-1][u] + w[u][0]) */
}

/* 2. 子集枚举：mask 的子集（含技巧 2^k - 1 递减） */
for (int sub = mask; sub; sub = (sub - 1) & mask) {
    /* sub 是 mask 的真子集，降序枚举 */
}

/* 3. 位运算口诀：取第 k 位 mask>>k&1；置 1 |=1<<k；置 0 &=~(1<<k) */
```

> **【类比】** mask 像**开关面板**：一排 20 个开关，每个开关管一个元素「选没选」；
> DP 转移 = **拨动一个开关跳到新面板**；
> 合法性预筛 = **出厂前把非法的面板全部贴封条**（棋盘型的行预筛）——
> 之后 DP 只在没贴封条的面板之间跳。

## 本章难点

> **【难点】** **棋盘型的合法行预筛。**
> 逐行转移前先跑一遍「所有 mask 是否行内合法」（如相邻位不同时为 1），
> 把合法行存进链表 / 数组——**DP 时只在合法行之间转移**，
> 复杂度从 O(4ⁿ) 降到 O(合法对数)。
> 预筛是效率关键：**先封条后 DP**。

> **【难点】** **内存账。**
> `dp[1 << n][n]` 在 n = 20 时 = 2²⁰ × 20 × 8B ≈ 160 MB——**开不下**。
> 处理三选一：① 实际 n 小（如 15）再全开；② 滚动（逐层型）；③ 换 unordered_map
> 只存可达态。**写状压前先算这张账。**

---

## 本章易错点

> **【头号易错】** **dp 数组按 `(1 << n)` 全开爆内存**（n = 20 时 2²⁰ × n × 8B = 160 MB）——
> 按需开或滚动。

> **【易错】** **`mask | (1 << v)` 写成 `mask + (1 << v)`**（重复置位时错）；
> 枚举子集的 sub 循环漏空集处理；n = 20 时内层判断用 `(ll)` 防符号位。

> **【易错】** **行间互斥的判定**：`mask & mask'` 应为 0（不相邻型）或按题面
> （斜向约束写成 8 方向检查）。

> **【易错】** **方案数取模**（P1896 mod 10⁸）：累加每步做。

> **【易错】** **行内合法预筛忘做**：先 O(2^m) 筛合法行，再 DP——不筛必超时。

## 典型例题

### 例 1　TSP（状压母题）　难度：模板题

**题干摘要**：n ≤ 18 完全图，求经过每点恰一次回到起点的最短回路。
**题源**：状压母题（对照练习见配套 T2——棋盘型的另一分支）
**涉及知识点**：知识点 2、4

**解题思路**：

1. **信号**：「经过全部点 + n 小」→ dp[mask][i]。
2. **方法**：核心模板 tsp。

**复杂度**：O(2ⁿ × n²) ≈ 2¹⁸ × 324 ≈ 8.5×10⁷。

> **【易错】** INF 判别用 `dp[mask][u] >= 0x3f.../2` 防加法溢出；
> 起点固定 0（回路对称减 n! 倍无需枚举起点）。

---

### 例 2　不相交棋盘放置（逐行型）　难度：变式题

**题干摘要**：n × m ≤ 12 棋盘放互不相邻的棋子（含斜向），求方案数。
**题源**：状压轮廓线入门（同类真源见配套 T1 / T2 的行预筛实战）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「棋盘 + 互斥 + 行数少」→ 逐行转移。
2. **方法**：逐行转移，状态 = 上一行的占用 mask；新行 mask2 与上行 mask
   合法性预筛（先跑预处理存合法对，转移 O(合法对数)）；方案数累加。

**复杂度**：O(合法行对数 × n)。

> **【易错】** 预筛合法对是效率关键（先跑预处理再 DP）；
> 斜向约束把「掩码与掩码」判定写成 8 方向检查。

## 本章总结

### 核心内容（一页纸）

1. **集合 → 二进制 mask**；n ≤ 20 是入场券（2ⁿ = 10⁶）。
2. **位运算三件套**：取位 / 置 1 / 置 0；**`|` 不是 `+`**。
3. **两大状态形态**：dp[mask][i]（TSP 型）与 dp[i][mask]（棋盘逐行型）。
4. **合法行预筛**：先封条后 DP——效率命门。
5. **内存账先算**：2ⁿ × n × 8B，n = 20 约 160 MB。
6. **子集枚举**：`sub = (sub − 1) & mask`（降序、含技巧）。
7. **行间互斥判定**：`mask & mask'` 按题面（相邻 / 斜向）。
8. **方案数取模每步做**。
9. **TSP 起点固定减 n! 倍**；INF 判别防加法溢出。
10. **n ≥ 25 状压死**——范围反推的双向反射。
