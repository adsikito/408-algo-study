## 本章地图

本章解决一个问题：**「约束 / 决策长在树上，最优怎么算？」**

```text
树上的决策：每个点的选择受「孩子 / 父亲」约束
   ↓
状态：dp[u][s] = u 子树内、u 处于状态 s 的最优值
   ↓
两大基本型：
   ├─ 状态机型：dp[u][0/1]（选 / 不选）→ 舞会、最大子树和
   └─ 树形背包：dp[u][j]（子树内选 j 个）→ 依赖背包
   ↓
转移 = dfs 回溯时「合并孩子信息」（合成数学：min / max / +）
   ↓
工程两件事：防回走（知识点 2）· 倒序合并（知识点 3）
```

**为什么这条路径是这样**：树是**天然无环、子树独立**的——
树上 DP 无需拓扑排序（dfs 回溯顺序即拓扑序）、无需判重叠（子树互不重叠）。
**线性 DP 的「填表顺序」在树上由 dfs 递归自动完成**——这就是树形 DP 的全部便利。

## 核心概念与模板

**是什么**：DP 跑在树上：`dp[u][s]` = 以 u 为根的子树、状态 s 下的最优值；
转移 = **合并子树信息**（dfs 回溯时把孩子的 dp 揉进自己）。

**为什么**：识别信号：「选点 / 选边满足约束」「树上路径」「子树统计」。
两大基本型：**树形背包**（选点互斥，体积维）与**状态机树形**（每个点按父边状态分类）。

> **【规律】** **dfs 回溯顺序 = 自动的拓扑序**——树形 DP 不需要
> 显式拓扑（对比 DAG DP），递归结构自带「孩子先于父亲算完」。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
#include <vector>
#include <algorithm>
using namespace std;
typedef long long ll;
const int N = 2005;

int n, val[N];
vector<int> ch[N];
ll dp[N][2];                              /* dp[u][0/1]：u 不选 / 选 */

/* 基础型：没有上司的舞会（相邻不能同选，求最大权和） */
void dfs(int u, int pa) {
    dp[u][0] = 0;
    dp[u][1] = val[u];
    for (int v : ch[u]) {
        if (v == pa) continue;            /* 防回走（父指针法） */
        dfs(v, u);
        dp[u][0] += max(dp[v][0], dp[v][1]);   /* u 不选：孩子随便 */
        dp[u][1] += dp[v][0];                  /* u 选：孩子必不选 */
    }
}

/* 树形背包：子树内选 k 个的最大价值（体积 = 结点数） */
ll f[N][N];                               /* f[u][j]：u 子树选 j 个 */
int sz[N];

void dfsPack(int u, int pa) {
    sz[u] = 1;
    f[u][0] = 0;
    f[u][1] = val[u];                     /* 选 u 自己 */
    for (int v : ch[u]) {
        if (v == pa) continue;
        dfsPack(v, u);
        /* 经典倒序合并：容量从大到小防重复计入 v */
        for (int j = sz[u]; j >= 1; j--)
            for (int k = 1; k <= sz[v]; k++)
                f[u][j + k] = max(f[u][j + k], f[u][j] + f[v][k]);
        sz[u] += sz[v];
    }
}
```

> **【类比】** 树形 DP 像**逐级汇报**：每个经理（点）听完所有下属（子树）的
> 两套方案（选 / 不选），按公司规则（约束）拼出自己的两套方案上报——
> **汇报顺序天然从基层到高层**（dfs 回溯），这就是「自动拓扑序」。

## 本章难点

> **【难点】** **树形背包的倒序合并。**
> `for (j = sz[u] → 1)` 倒序 + `sz[u]` **先用后加**——
> 正序会把 v 的贡献算两次（同一个 v 被重复合并），
> 这与 0-1 背包「容量倒序」完全同源（树形背包 = 每棵子树是一个「分组」的依赖背包）。
> **记忆锚：背包倒序是「防同件重选」，树形倒序是「防同子树重并」。**

> **【难点】** **负权下的「断开权」。**
> 最大子树和类题（P1122）：子树和为负时**可以不带上它**——
> 转移写成 `dp[u] += max(0LL, dp[v])`（每个孩子独立决定带上与否），
> 而不是无条件累加。**「dp[u] 可为负」与「允许断开子树」是同一件事的两面。**

---

## 本章易错点

> **【头号易错】** **树形背包的合并顺序**：容量倒序 + `sz` 先用后加——
> 正序会把 v 的贡献算两次（同背包 0-1 倒序的树版）。

> **【易错】** **无向树建图忘防父结点回走**（pa 判断或 vis）——无限递归爆栈。

> **【易错】** **dp 初值在负权下要 −∞**（选 u 才有 val[u] 的语义，不选 ≠ 0）。

> **【易错】** **森林情形**：对每个根跑 dfs 取 max（不是只跑 1 号点）。

> **【易错】** **换根 DP 忘记撤销旧贡献**（rerooting：换根时先减旧子贡献再加新向贡献）。

## 典型例题

### 例 1　没有上司的舞会（状态机型）　难度：模板题

**题干摘要**：n ≤ 10⁴ 组织树，员工与直属上司不能同选，求最大快乐值。
**题源**：同类真源见配套练习 T1（P1352 没有上司的舞会）
**涉及知识点**：知识点 1、2

**解题思路**：

1. **信号**：「上下级互斥」→ 状态机型。
2. **方法**：核心模板 dfs（根 = 无上司者，多根时逐根取 max）。

**复杂度**：O(n)。

> **【易错】** 森林情形对每个根跑 dfs 取 max；dp[u][1] 初值含 val[u]（选自己必有收益）。

---

### 例 2　最大子树和（可断开的聚合）　难度：变式题

**题干摘要**：n 点带权（可负）树，删掉任意子树，求剩余最大权和。
**题源**：同类真源见配套练习 T2（P1122 最大子树和）
**涉及知识点**：知识点 1、4

**解题思路**：

1. **信号**：「子树 + 可负权 + 可删除」→ 聚合型 + 断开权。
2. **方法**：`dp[u] = val[u] + Σ max(0, dp[v])`——负贡献的孩子整棵舍弃。

**复杂度**：O(n)。

> **【易错】** 答案是 max(dp[u])（全程取最大）而非 dp[root]——
> 最优解可以根在任何位置。

## 本章总结

### 核心内容（一页纸）

1. **状态**：`dp[u][s]` = u 子树内、u 处于状态 s 的最优值。
2. **转移 = dfs 回溯时合并孩子**——递归顺序即自动拓扑序。
3. **两大基本型**：状态机型（dp[u][0/1]）与树形背包（dp[u][j]）。
4. **防回走两写法**：pa 判断 / vis——无向树必选其一。
5. **树形背包倒序合并**：容量倒序 + sz 先用后加（防同子树重并）。
6. **负权可断开**：`dp[u] += max(0, dp[v])`；答案取全局 max。
7. **森林多根**：逐根 dfs 取 max。
8. **dp[u][1] 初值含 val[u]**（选自己必有收益）。
9. **换根 = 两次扫描 + 贡献撤销**（进阶路线）。
10. **图有环不是树形 DP**——先确认「是树」。
