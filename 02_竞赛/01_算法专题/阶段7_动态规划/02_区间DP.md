## 本章地图

本章解决一个问题：**「一段连续区间的合并 / 取舍，最优顺序是什么？」**

```text
「合并」「石子」「取两端」「回文」类题
   ↓
状态：dp[i][j] = 处理区间 [i, j] 的最优值
   ↓
两类转移：
   ├─ 分割点型：dp[i][j] = min/max{ dp[i][k] + dp[k+1][j] + cost(i,j) }
   └─ 两端型：dp[i][j] 由 dp[i+1][j-1] / dp[i+1][j] / dp[i][j-1] 推
   ↓
循环顺序：按区间长度 len 从小到大（命门）
   ↓
环形题：断环成链（复制一份，长 2n），答案在所有长 n 窗口取 min
```

**为什么这条路径是这样**：区间 DP 的依赖是**「长区间依赖短区间」**——
dp[i][j] 的所有转移源都是更短的区间。
**按 len 从小到大填表，就是保证「依赖的格子已填好」**——
这与线性 DP 的「按下标顺序」一脉相承，只是排序键变成了长度。

|---------|------------|--------|

> 合并任意堆 → 哈夫曼。**读题漏「相邻」二字，算法选型全错。**

## 核心概念与模板

**是什么**：状态是**区间 [i, j]**：`dp[i][j]` = 把区间 i..j 处理成目标的最优值；
转移 = 枚举**分割点 k** 或讨论**区间两端**。

**为什么**：循环顺序是它的命门：**按区间长度从小到大**（长区间依赖短区间）。
识别信号：「合并」「石子」「取两端」「回文」。

> **【规律】** **两型转移一表记**：
> 分割点型（合并不对称，枚举 k）；两端讨论型（对称，只看两端是否配对）。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
const int N = 305;
int n, a[N], pre[N];                      /* pre：前缀和（合并代价） */
int dp[N][N];

/* 石子合并：相邻两堆合并，代价 = 两堆之和，求最小总代价 */
int stoneMerge() {
    for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + a[i];
    memset(dp, 0x3f, sizeof(dp));
    for (int i = 1; i <= n; i++) dp[i][i] = 0;      /* 长度 1：零代价 */
    for (int len = 2; len <= n; len++)               /* 枚举长度 */
        for (int i = 1, j = i + len - 1; j <= n; i++, j++) {
            int w = pre[j] - pre[i - 1];
            for (int k = i; k < j; k++)              /* 分割点 */
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + w);
        }
    return dp[1][n];
}

/* 回文子序列：讨论两端（另一类转移） */
/* dp[i][j] = a[i]==a[j] ? dp[i+1][j-1] + 2 : max(dp[i+1][j], dp[i][j-1]) */
```

> **【类比】** 区间 DP 像** 项目拆解**：完成一个大区间 [i, j] 的任务，
> 先把它在某个 k 处切成两段分别完成（子区间），再花 cost(i, j) 拼起来——
> **枚举 k 就是枚举「第一刀切在哪」**。
> 按 len 从小到大填表 = 先完成小项目再拼大项目。

## 本章难点

> **【难点】** **循环顺序的三层写法。**
> `for len → for i（j 自动确定）→ for k`——
> i 与 j 的联动用 `j = i + len − 1` 一行确定，**不要分别枚举 i、j 再判长度**（慢且易漏）。
> 初始化：len = 1 时 dp[i][i] = 0（合并零堆零代价），**不是 INF**。

> **【难点】** **环形断链的答案收集。**
> 复制成 2n 长的链后跑区间 DP，答案 = **所有长为 n 的窗口的最值**
> （`min{ dp[i][i+n−1] : i = 1..n }`）——只取 dp[1][n] 是漏解。
> P1063（能量项链）与 P1880 环形版都是这个形状。

---

## 本章易错点

> **【头号易错】** **循环顺序写反**（先 i 后 j 而不是先 len）——
> 短区间的 dp 还没算就被长区间引用。

> **【易错】** **环形的处理**（断环成链复制一份，长 2n，答案在所有长 n 的窗口取 min）。

> **【易错】** **分割点 k 的范围 `[i, j−1]`**（漏 k = j−1 或多 k = j）。

> **【易错】** **cost 用前缀和而非每次重算**（区间和 O(1) 取）。

> **【易错】** **长度 2 的两端型边界**（dp[i+1][j−1] 越界为 0）要显式处理；
> 与「最长回文子**串**」（连续）是两道题——子序列允许跳字。

## 典型例题

### 例 1　石子合并（区间 DP 母题）　难度：模板题

**题干摘要**：n ≤ 300 石子堆相邻合并，求最小代价。
**题源**：同类真源见配套 T1（P1880 石子合并——注意原题是**环形**版，需断链）
**涉及知识点**：知识点 1、2

**解题思路**：

1. **信号**：「相邻合并」→ 分割点型区间 DP。
2. **方法**：核心模板 `stoneMerge`；P1880 为环形版 → 断链复制。

**复杂度**：O(n³) = 2.7×10⁷（n = 300 可过；环形版 2n = 600 → O(8n³)
需四边形不等式优化，超本阶段）。

> **【易错】** 长度 1 初始化为 0 而非 INF；cost 是区间和（pre 数组 O(1) 取）。

---

### 例 2　最长回文子序列（两端讨论型）　难度：变式题

**题干摘要**：串长 ≤ 5×10³，求最长回文子序列。
**题源**：区间 DP 变式（P1063 能量项链为「环形 + 分割点」的同型进阶）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「回文」→ 两端讨论。
2. **方法**：len 从 2 起；两端等 → dp[i+1][j−1] + 2（j = i+1 时底为 0 + 2）；
   两端不等 → max(dp[i+1][j], dp[i][j−1])；答案 dp[1][n]。

**复杂度**：O(n²)。

> **【易错】** 长度 2 的边界（dp[i+1][j−1] 越界为 0）要显式处理；
> 与「最长回文子串」（连续）是两道题——子序列允许跳字。

## 本章总结

### 核心内容（一页纸）

1. **状态 = 区间 [i, j]**；两类转移：分割点枚举 / 两端讨论。
2. **循环顺序命门**：len 外层 → i 内层 → k 分割；`j = i + len − 1` 联动。
3. **len = 1 初始化为 0**（不是 INF）。
4. **cost 用前缀和 O(1) 取**（合并代价 = 区间和）。
5. **环形 = 断链复制 2n，答案在所有长 n 窗口取 min/max**。
6. **两端型边界**：dp[i+1][j−1] 越界为 0（len = 2）。
7. **回文子序列 ≠ 回文子串**（跳字 vs 连续）。
8. **「相邻」是门牌**：相邻合并区间 DP，任意合并哈夫曼。
9. **n ≤ 100 ~ 500** 是 O(n³) 的规模信号。
10. **变体 = 换 cost 与方向**（和/积 × min/max），骨架不变。
