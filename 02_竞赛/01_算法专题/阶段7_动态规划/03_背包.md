## 本章地图

本章解决一个问题：**「容量有限的取舍，每类物品的规则不同，怎么统一处理？」**

```text
五类背包 = 「每件物品能选几次」的五种规则：
   ├─ 0-1：至多一次     → 容量倒序
   ├─ 完全：无限次      → 容量正序
   ├─ 多重：限 s 次     → 二进制拆分 → 0-1
   ├─ 分组：组内互斥    → 三层循环（组 → 容量 → 组内）
   └─ 二维费用：两个容量维 → f 加一维
   ↓
计数变体：max 换 +（方案数）；初值三态（至多 / 恰好 / 至少）
   ↓
混合背包：按类型分流，共用一个 f 数组顺序处理
```

**为什么这条路径是这样**：背包家族的统一视角是
**「物品的可用次数」与「计数 or 最值」两个正交开关**——
前者决定循环顺序与拆分，后者决定转移算符与初值。
**抓住两个开关，五类背包就是一张表。**

## 核心概念与模板

**是什么**：容量维 + 物品维的计数 / 最值 DP。

**为什么**：考研附录 C 已给 0-1 与完全的一维对照（倒序 / 正序）；
竞赛侧补全家族与高频变式：**多重（二进制拆分）、分组、二维费用、方案数、恰好装满**。
核心口诀不变：**0-1 倒序、完全正序**。

> **【规律】** **「0-1 倒序、完全正序」的推导**：
> 一维 f[c] 的转移 `f[c] = max(f[c], f[c−w] + v)` 中，f[c−w] 应该是
> **上一轮**（未考虑本物品）的值——0-1 每件一次 → 倒序保证 f[c−w] 未被本轮污染；
> 完全无限件 → 正序让 f[c−w] 已含本物品（可重复选）。
> **污染与否，就是次数语义。**

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
const int C = 100005;
typedef long long ll;
ll f[C];

/* 0-1 背包：容量倒序（考研附录 C 已学，此处为复习锚点） */
void zeroOne(int w, ll v, int cap) {
    for (int c = cap; c >= w; c--)
        f[c] = max(f[c], f[c - w] + v);
}

/* 完全背包：容量正序（每件无限） */
void complete(int w, ll v, int cap) {
    for (int c = w; c <= cap; c++)
        f[c] = max(f[c], f[c - w] + v);
}

/* 多重背包：二进制拆分成 0-1（s 件拆成 1,2,4,...,余） */
void multiple(int w, ll v, int s, int cap) {
    for (int k = 1; s > 0; k <<= 1) {
        int take = min(k, s);
        s -= take;
        zeroOne(w * take, v * take, cap);
    }
}

/* 分组背包：组内至多选一件，组间枚举 */
void grouped(int items[][2], int cnt, int cap) {
    for (int t = 0; t < cnt; t++)          /* 每组 */
        for (int c = cap; c >= 1; c--)     /* 容量倒序（组内互斥） */
            for (int i = 0; i < 2; i++)    /* 组内物品（示意两件） */
                if (c >= items[t][i])
                    f[c] = max(f[c], f[c - items[t][i]] + 1);
}
```

> **【类比】** 背包像**行李箱 packing**：0-1 是「每样东西最多带一件」，
> 完全是「(zip 粒度)想带几件带几件」，多重是「限购 s 件」，
> 分组是「同类商品只能选一款」。
> **一维数组的遍历方向，就是「本件还能不能再选」的开关。**

## 本章难点

> **【难点】** **「恰好装满」的初值三态。**
> 「至多装满」：f 全 0（不装也合法）；「恰好装满」：f[0] = 0 其余 −∞
> （不合法态不可达）；「至少装满」：全 0 但转移语义不同。
> **初值错 → 答案差一个量级**——写题先问题面是哪一种。

> **【难点】** **二进制拆分的正确性。**
> s 件拆成 1 + 2 + 4 + … + 余（各打包件互斥地组合出 0..s 的任意件数）——
> **拆的是「件数」不是「价值」**：打包件为 (w × take, v × take)。
> 与快速幂的二进制同源：任何次数都能被 2 的幂拼出。

---

## 本章易错点

> **【头号易错】** **循环顺序与背包类型错配**：0-1 正序 = 变完全背包（错解）；
> 分组背包把「组内枚举」放进容量循环之外（每组选多件）。

> **【易错】** **求「恰好装满」忘把初值设 −∞**（只有 f[0] = 0）。

> **【易错】** **方案数用 int 累加溢出**；取模每步做。

> **【易错】** **多重拆分系数 k 从 1 起、余量 take = min(k, s)**
> 写成 min(k, cap)。

> **【易错】** **分组背包三层循环的顺序**：组在最外、容量居中、组内最里——
> 容量必须在组内枚举之前定死（组内互斥）。

## 典型例题

### 例 1　混合背包（三类合流）　难度：综合题

**题干摘要**：n ≤ 100 物品：部分 0-1、部分无限、部分限 s 件，容量 ≤ 10⁵，求最大价值。
**题源**：背包混合经典（对照练习见配套 T1 / T2 / T3 的单类版）
**涉及知识点**：知识点 1、2、5

**解题思路**：

1. **信号**：「三类规则同时出现」→ 按类型分流。
2. **方法**：0-1 调 zeroOne、无限调 complete、限 s 先二进制拆分再调 zeroOne；
   共用一个 f 数组顺序处理。

**复杂度**：O(C × Σlog s + nC)。

> **【易错】** 拆分后的「打包件」当成 0-1 件处理即可；
> 三类顺序不影响正确性（各自独立转移）。

---

### 例 2　背包方案数（恰好装满计数）　难度：变式题

**题干摘要**：n ≤ 100、容量 ≤ 10⁴，求恰好装满的方案数 mod 10⁹+7。
**题源**：背包计数（与 `01_线性DP.md` 的计数并列思想同源）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「方案数 + 装满语义」→ max 换 + + 初值三态。
2. **方法**：0-1 方案数：f[0] = 1，其余 0；倒序 `f[c] += f[c − w]`；完全则正序。

**复杂度**：O(nC)。

> **【易错】** max 换 + 是唯一改动；取模每步做；
> 「至少装满」与「恰好装满」初值不同（前者全 0，后者 −∞）。

## 本章总结

### 核心内容（一页纸）

1. **两个正交开关**：可用次数（五类）× 计数 or 最值——抓住即得全表。
2. **0-1 倒序、完全正序**：f[c−w] 用「上轮」还是「本轮」的语义推导。
3. **多重 = 二进制拆分成 0-1**：拆件数 (w×take, v×take)，k 从 1 起。
4. **分组三层循环**：组 → 容量 → 组内（容量定死后组内互斥）。
5. **初值三态**：至多全 0 / 恰好 f[0]=0 余 −∞ / 至少语义不同。
6. **计数 = max 换 +**，取模每步。
7. **混合背包按类分流**，共用 f 数组。
8. **输出方案靠倒推** f[c] 的来源。
9. **T1 与 T3 成对做**：循环方向就是答案开关。
10. **提交前三自查**：循环方向 / 初值 / 取模。
