## 🗺️ 本章地图

> **本章解决一个问题：状态和转移长在树上，DP 怎么做？**
> 路线是"思想 → 两类经典"：先理解树形 DP 的本质——DP 是记忆化搜索、树是递归定义，天然契合，用 DFS"叶→根"在回溯时合并子树状态；再攻两类老套路——选择节点类（P1352 最大独立集，`f[x][0/1]` 选/不选两态）与树上背包（P2014 选课，森林加虚拟根 + 分组合并）。
> 学完请自测三件事：状态是不是定义为"以 x 为根的子树的某种性质"？转移是不是发生在回溯时？树上背包的 j 为什么倒序、k 为什么 ≤ j-1？

## 📌 本章重点（3-5个）

⭐ **树形 DP 的状态设计**：一般定义为"以当前结点为根的子树的某种性质"，转移发生在父子结点/兄弟/树与子树之间
⭐ **实现骨架：DFS 备忘录写法**：递归到叶子后回溯，在回溯时用孩子的 dp 值更新父亲的 dp 值（叶→根）
⭐ **选/不选两态（P1352）**：`f[x][0]` = x 不参加时子树最大快乐值，`f[x][1]` = x 参加时；孩子状态二选一合并
⭐ **找根**：建树时标记"有没有父亲"，没有父亲标记的结点即根（树形 DP 必须从根开始 DFS）
⭐ **树上背包（P2014）**：`dp[u][j]` = 以 u 为根的子树选 j 个结点的最大权值和；每棵子树是一"组"，按组合并、j 倒序

## 🔥 本章难点（2-3个）

🔥 **"回溯时合并"的后序语义**：`dfs(y)` 必须先递归返回，孩子状态才算完，才能执行 `dp[x][1]+=dp[y][0]`——递归深度方向与状态合并方向相反，理解这一点才算入门树形 DP
🔥 **树上背包的双重背包式合并**：课件先用三维 `dp[u][i][j]`（前 i 棵子树选 j 个）表达分组背包，再像 01 背包一样把 i 降掉、j 改倒序——树上背包 = 背包套在子树枚举上，两层"倒序"嵌套最容易绕晕
🔥 **森林变树**：P2014 中"每门课最多一门先修课"对应"每点最多一个父亲"，课程组成森林；新增 0 学分的 0 号课程当虚拟根，问题变成"n+1 个结点选 m+1 个（0 号必选）"

## ⚠️ 本章易错点（3-5个）

⚠️ **课件笔误别照抄**：幻灯片把"x 去"的转移写成 `f[x][0]+=f[y][0]`，正确是 **`f[x][1]+=f[y][0]`**（x 去了孩子只能不去，只能累加孩子"不去"的值），以例题代码为准
⚠️ **忘找根 / 根找错**：输入边 `l k` 表示 k 是 l 的上司，需 `v[l]=1` 标记"l 有父亲"，最后没被标记的才是根；直接拿 1 号点当根在有根指定时会 WA
⚠️ **树上背包的容量细节**：`dp[u][1]=val[u]`（选 u 本身先占 1 个名额），合并时 `k ≤ j-1`（留一个位置给 u）且 j 要**倒序**（防同一子树选多次）；正序会像 01 背包那样重复取
⚠️ **初始状态漏写**：进 dfs 先 `dp[x][0]=0; dp[x][1]=r[x];`（课件：初始认为只有自己去），漏写会导致累加在垃圾值上
⚠️ **存树方式不匹配数据规模**：vector 邻接表好写但常数大，链式前向星省内存快；题目 n 大时递归 dfs 可能爆栈/爆递归深度，需留意

## 📖 知识点讲解

### 1. 树形 DP 的思想与实现骨架

**是什么**：树形 DP 是把 DP 建立在树状结构上的思想——用树形结构存储数据，在树上做状态转移。通常把**一个结点或一棵子树**看成一个状态；实现上以 **DFS** 为骨架、采用备忘录写法。两种搜索方向：**叶→根**（从根向下递归，回溯时从叶子往上更新，最常用）与**根→叶**（先叶→根做预处理，再从根往下推一遍获取答案）。两者按需选用，没有高低之分。

**为什么**：动态规划本质是记忆化搜索（备忘录写法），基于递归；而树本身就是递归定义的（"树 = 根 + 若干子树"），所以树形结构天然适合 DP——大树的解由子树的解推出，正合最优子结构。

**怎么用**——通用骨架（存树可用 vector 邻接表或链式前向星，树是特殊的图）：

```cpp
void dfs(int x) {                  // 求"以 x 为根的子树"的 dp 值
    dp[x][...] = 初始值;           // 按题意给初值
    for (每个孩子 y) {
        dfs(y);                    // 先算完孩子的子树
        dp[x][...] = 合并(dp[x][...], dp[y][...]);  // 回溯时合并
    }
}
int main() { 找根 root; dfs(root); 答案取自 dp[root][...]; }
```

套路三步：① 确定结点状态（"以当前结点为根的子树的某种性质"）；② 确定转移关系（父子/兄弟）；③ 备忘录写法实现。课件原话："树形 DP 的老套路就那么多，难的还是想出转移方程。"

> ⚠️ 注意事项：必须从树根开始 DFS；孩子状态未算完（dfs 未返回）前不能合并。
> 🎯 规律：大树由子树推出——递归定义的树配递归的 DP。
> 💡 一句话总结：先算儿子，回溯合爹。

### 2. 选择节点类：P1352 没有上司的舞会（最大独立集）

**是什么**：树中每个结点是一个人，父结点是顶头上司，点权是快乐指数；**父子结点不能同时选**，选哪些结点使权值和最大。状态：`f[x][0]` = x 不参加时，以 x 为根子树的最大快乐值；`f[x][1]` = x 参加时。初始 `f[x][1]=r[x]`。答案 `max(f[root][0], f[root][1])`。

**为什么**：对最终集合，每个结点只有"在/不在"两种状态。x **不去**：孩子们去不去都行，每个孩子取 `max(f[y][0], f[y][1])` 累加；x **去**：孩子们全不能去，只能累加 `f[y][0]`。孩子子树的最优值先由递归算出，回溯时合并——典型的叶→根。

**怎么用**——跟着算：4 结点小树，1 为根（r=2），孩子 2（r=5）、3（r=1），2 的孩子 4（r=3）。按后序合并：

| 结点（后序顺序） | 合并过程 | f[x][0] | f[x][1] |
|---|---|---|---|
| 4（叶） | 初始 | 0 | 3 |
| 3（叶） | 初始 | 0 | 1 |
| 2 | 初始 f[2][1]=5；孩子4：f[2][1]+=f[4][0]=3；f[2][0]+=max(0,3)=3 | **3** | **8** |
| 1（根） | 初始 f[1][1]=2；孩子2：f[1][1]+=f[2][0]=5；f[1][0]+=max(3,8)=8；孩子3：f[1][1]+=f[3][0]=6；f[1][0]+=max(0,1)=9 | **9** | 6 |

答案 max(9,6)=**9**：不选上司 1，选 2、3、4（5+1+3=9）。

```cpp
void dfs(int x) {
    dp[x][0] = 0;                 // 都不选
    dp[x][1] = r[x];              // 只选自己
    for (int i = 0; i < g[x].size(); i++) {
        int y = g[x][i];
        dfs(y);                   // 先算孩子
        dp[x][1] += dp[y][0];                     // x 去 -> y 不能去
        dp[x][0] += max(dp[y][0], dp[y][1]);      // x 不去 -> y 随意
    }
}
```

> ⚠️ 注意事项：找根靠"无父亲标记"；注意课件笔误，x 去的分支是 `f[x][1]+=f[y][0]`。
> 🎯 规律：相邻不能同选 → 状态带一维"自己选没选"。
> 💡 一句话总结：我去儿不去，我去加零态。

### 3. 树上背包：P2014 选课

**是什么**：n 门课，学分 val，每门课至多一门先修课（构成森林），选 m 门使学分和最大，选课必须连根带子（选了先修课才能选它）。转化：加 0 学分的 0 号课程作所有无先修课课程的先修课，森林变以 0 为根的树，问题变为 **n+1 个结点选 m+1 个（0 号必选）**。状态（降维后）：`dp[u][j]` = 以 u 为根的子树中选 j 个结点的最大权值和，初始 `dp[u][0]=0, dp[u][1]=val[u]`，答案 `dp[0][m]`。

**为什么**："子树中选若干结点、每个至多一次、总数是容量"完全是 01 背包的描述，只是"物品组"变成了"子树"：以 u 为根的树若选多门课必先选 u，剩余 j-1 个名额分配给各棵子树；三维原始式 `dp[u][i][j] = max(dp[u][i-1][j-k] + dp[v][sv][k])`（第 i 棵子树的根为 v、在其中选 k 个）中 i 只由 i-1 行得到，故可像 01 背包一样降掉 i、j 倒序维护。合并式：`dp[u][j] = max(dp[u][j], dp[v][k] + dp[u][j-k])`，k ≤ j-1。

**怎么用**——跟着算：0 号虚拟根（val=0），孩子：课程 1（val=2）、课程 2（val=3）；目标 dp[0][2]（选 2 门，含 0 号）。合并按子树逐棵进行、j 倒序：

| 步骤 | 操作 | dp[0][1] | dp[0][2] |
|---|---|---|---|
| 初始 | dp[0][0]=0, dp[0][1]=val[0]=0 | 0 | -inf |
| 合并子树1（课程1，dp[1][1]=2） | j=2：k=1 → dp[1][1]+dp[0][1]=2；j=1：k=0 → 无提升 | 0 | **2** |
| 合并子树2（课程2，dp[2][1]=3） | j=2：k=1 → dp[2][1]+dp[0][1]=3 更优 | 0 | **3** ✓ |

答案 dp[0][2]=3（选 0 号 + 课程 2）。

```cpp
int dfs(int u, int d) {
    int sumu = 1;                     // 以 u 为根的结点数（含 u）
    dp[u][0] = 0; dp[u][1] = val[u];
    for (int i = head[u]; i > 0; i = e[i].next) {
        int v = e[i].to;
        int sumv = dfs(v, d+1);       // 先算子树 v
        sumu += sumv;
        for (int j = min(m-d, sumu); j > 0; j--)          // 容量倒序！
            for (int k = 0; k <= min(j-1, sumv); k++)     // 留 1 个名额给 u
                dp[u][j] = max(dp[u][j], dp[v][k] + dp[u][j-k]);
    }
    return sumu;
}
// main: n 读入 (fa, val[i])，add(fa, i)；m++；dfs(0,0)；输出 dp[0][m]
```

> ⚠️ 注意事项：j 倒序防止同一棵子树被重复选择；`k ≤ j-1` 因为 u 自己必占一个名额；用子树实际大小 sumv、m-d 截断循环是重要的剪枝。
> 🎯 规律：树上背包 = 每棵子树是一组物品的分组背包。
> 💡 一句话总结：子树当组，倒序合并。

## 🔍 相似概念辨析

### 组一：树形 DP vs 线性 DP

| 对比维度 | 线性 DP | 树形 DP |
|---------|---------|---------|
| 结构基础 | 序列（线性结构） | 树（递归定义的分层结构） |
| 状态对象 | 前缀/以 i 结尾 | 一个结点 / 一棵子树 |
| 转移方向 | 下标递增（i-1 → i） | 回溯时孩子 → 父亲（叶→根） |
| 实现方式 | 循环递推填表 | DFS + 备忘录（递归） |
| 转移来源 | 固定几个邻居 | 孩子集合逐个合并 |
| 答案位置 | dp[n] / max(dp[1..n]) | dp[root][...] |
| 典型问题 | LIS、LCS、背包 | 舞会、选课、子树和 |

### 组二：自顶向下记忆化（备忘录）vs 自底向上递推

| 对比维度 | 备忘录写法（树形 DP 常用） | 递推填表（线性/区间 DP 常用） |
|---------|--------------------------|------------------------------|
| 计算顺序 | 从根 DFS，回溯自然形成后序 | 手动安排枚举顺序（如按长度） |
| 访问状态 | 用到才算，不浪费 | 可能算出无用状态 |
| 需要的前提 | 递归能到达（栈深够） | 明确的依赖顺序 |
| 代码形态 | dfs 函数 + 数组记忆 | 多重循环 |
| 适用结构 | 树/图（依赖关系不规则） | 序列/区间（依赖规则） |
| 爆栈风险 | 深树可能爆递归栈 | 无递归风险 |

### 组三：选择节点类 vs 树上背包类

| 对比维度 | 选择节点类（P1352） | 树上背包类（P2014） |
|---------|--------------------|---------------------|
| 附加约束 | 相邻（父子）不同选 | 选点个数/容量受限 |
| 状态维度 | dp[x][0/1]（+选/不选一维） | dp[u][j]（+容量一维） |
| 合并方式 | 各子树独立取 max/直接累加 | 子树间分配容量（分组背包） |
| 循环层数 | 子树枚举一层 | 子树枚举 + 容量 + 分配 k |
| 复杂度 | O(n) | O(n·m) 或 O(n²) |
| 变体方向 | 最小支配集、最大匹配 | 依赖背包、树形分组 |

## 🧩 本章归纳：一条主线串全章

**"树的递归定义 = DP 的最优子结构"**：课件反复强调——DP 本质是记忆化搜索，树本身就是"根 + 子树"的递归结构，所以树形 DP 的状态一律定义为"以 x 为根的子树的某种性质"，用 DFS 走到叶子、回溯时逐个合并孩子的状态。选/不选类问题给状态加一维 [0/1] 描述"自己选没选"（P1352），容量类问题给状态加一维 j 描述"选几个"，再把每棵子树当成一组物品做分组背包式合并（P2014）。森林加一个虚拟根变成树、vector 与链式前向星都是存树的工具——工具可换，"后序合并"这条主线不变。想出转移方程依旧是最难的一步，套路之外的功夫还是要靠刷题积累。
