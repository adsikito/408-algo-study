## 本章地图

本章解决一个问题：**「大问题的最优解，怎么由小问题的最优解拼出来？」**

```text
两个前提（考研附录 C）：最优子结构 + 无后效性
   ↓
四步法：状态 → 转移 → 顺序 → 初值
   ↓
状态的两个口径：
   ├─ 「以 i 结尾」：转移必须从 j < i 来（LIS、最大子段和）
   └─ 「前 i 个中选」：转移可从 i−1 的任意合法态来（LCS、背包）
   ↓
优化套路：贪心二分 LIS · 滚动数组 · 前缀 max
   ↓
计数变体：max 并列时 cnt 相加（数字三角形双问）
```

**为什么这条路径是这样**：线性 DP 是**所有 DP 变体的母体**——
区间 DP 是「状态从点变区间」、背包是「多一维容量」、树形是「线性变树上」、
状压是「下标变集合」。**本篇的状态设计纪律贯穿全阶段。**

## 核心概念与模板

**是什么**：状态沿一 / 二维线性推进的 DP：LIS、LCS、最大子段和、编辑距离、数字三角形。

**为什么**：考研附录 C 已建方法论（两大前提 + 四步法），本篇补竞赛侧三件事：
**常见状态设计库**、**优化套路**（贪心二分 LIS、滚动数组、前缀 max）、
**与爆搜记忆化的转换**。

> **【规律】** **两种口径的本质区别**：「以 i 结尾」的转移源是**所有 j < i**
> （要枚举）；「前 i 个中选」的转移源只有 **i−1 的少量状态**（不枚举）。
> 复杂度差异由此而来。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
const int N = 3005;
typedef long long ll;

/* 1. LIS 最长递增子序列：两种复杂度 */
int a[N], dp[N];
int lisOn2(int n) {                       /* O(n^2)：dp[i] 以 i 结尾 */
    int ans = 0;
    for (int i = 0; i < n; i++) {
        dp[i] = 1;
        for (int j = 0; j < i; j++)
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    return ans;
}

int tail[N], len;                         /* O(n log n)：tail[k] = 长度 k+1 的最小尾 */
int lisLog(int n) {
    len = 0;
    for (int i = 0; i < n; i++) {
        int pos = lower_bound(tail, tail + len, a[i]) - tail;
        if (pos == len) tail[len++] = a[i];
        else tail[pos] = a[i];            /* 替换成更小尾：未来更易接 */
    }
    return len;
}

/* 2. LCS 最长公共子序列：二维推进 + 滚动数组 */
int f[2][N];
int lcs(char A[], int n, char B[], int m) {
    memset(f, 0, sizeof(f));
    int cur = 0;
    for (int i = 1; i <= n; i++) {
        cur ^= 1;
        for (int j = 1; j <= m; j++)
            f[cur][j] = (A[i] == B[j])
                        ? f[cur ^ 1][j - 1] + 1
                        : max(f[cur ^ 1][j], f[cur][j - 1]);
    }
    return f[cur][m];
}
```

> **【类比】** DP 像**填课程表**：每个格子（状态）的值由「已填好的格子」推出——
> 「以 i 结尾」像查「以某门课收尾的方案」，
> 「前 i 个中选」像查「前 i 门课里的任意组合」。
> **填表顺序保证每次查到的格子都已填好**——这就是「无后效性」的表格语言。

## 本章难点

> **【难点】** **LIS 贪心二分版的正确性直觉。**
> tail[k] = 「长度 k+1 的所有上升子序列中，最小的结尾」——
> 替换不改变长度、只让结尾更小（未来更容易接上）。
> **tail 不是任何一个具体方案**——输出 LIS 方案需要另存 pre 链，别混淆「数组」与「方案」。

> **【难点】** **最值与计数的并列更新。**
> `dp` 取 max 时，`cnt[i][j]` 只从**取到 max 的那些转移源**累加——
> 两个源相等时都算（并列）；严格更大时清零重计。
> **先写 max、再在「更新发生处」同步写 cnt 的更新**，两者不能分开想。

---

## 本章易错点

> **【头号易错】** **状态定义含糊**：「以 i 结尾」与「前 i 个中选」是两种 dp[i]——
> 转移方程完全不同，混用必错。**写题先一句话写清 dp[i] 是什么。**

> **【易错】** **LIS 的 O(n log n) 版忘了「替换时长度不变」**（tail 存的是每个长度的最小尾，
> 非方案本身）。

> **【易错】** **滚动数组下标翻转时上轮值未保存**（cur ^= 1 时机错）。

> **【易错】** **求「方案数」时把 max 写成 +（或反之）**。

> **【易错】** **严格递增用 lower_bound，不降用 upper_bound**——一字之差。

## 典型例题

### 例 1　LIS 双版本对照（模板）　难度：模板题

**题干摘要**：n ≤ 10⁵ 求 LIS 长度。
**题源**：LIS 模板（对照练习见配套 T3 合唱队形——LIS 的双向应用）
**涉及知识点**：知识点 2

**解题思路**：

1. **信号**：「子序列 + 递增」→ LIS。
2. **方法**：n ≤ 5×10³ 用 O(n²)；n ≤ 10⁵ 用贪心二分版。

**复杂度**：O(n²) 或 O(n log n)。

> **【易错】** 严格递增用 lower_bound，不降用 upper_bound——一字之差；
> O(n log n) 版输出方案需另存 pre 链。

---

### 例 2　数字三角形 + 路径取模计数（状态推进）　难度：变式题

**题干摘要**：n ≤ 10³ 三角形自顶到底（只能向下 / 右下），求最大路径和与路径条数。
**题源**：同类真源见配套 T1（P1216 数字三角形——最值版）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「网格路径 + 双问」→ 逆推 + 并列计数。
2. **方法**：`dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])`；
   `cnt[i][j]` = 对应取 max 的子项的 cnt 之和（并列都算）；自底向上填表，全程取模。

**复杂度**：O(n²)。

> **【易错】** 逆推自底向上不用判边界（正推要防 j±1 出界）；
> 计数与最值并列更新（两个转移源相等时 cnt 相加）。

## 本章总结

### 核心内容（一页纸）

1. **四步法**：状态 → 转移 → 顺序 → 初值；**状态定义一句话先行**。
2. **两种口径**：「以 i 结尾」（枚举 j < i）vs「前 i 个中选」（少量源）。
3. **LIS 双版本**：O(n²) 直观 / 贪心二分 O(n log n)；lower_bound vs upper_bound 一字之差。
4. **tail 不是方案**：输出 LIS 需另存 pre 链。
5. **LCS + 滚动数组**：cur ^= 1 时机与初值。
6. **逆推自底向上**免边界判断（数字三角形）。
7. **最值与计数并列**：转移源相等 cnt 相加，严格更大清零重计。
8. **计数每步取模**。
9. **变体 = 旧零件新组装**（合唱队形 = 双向 LIS）。
10. **本篇纪律贯穿阶段 7 全部五篇**。
