>
> 例题代码清单：`P4170.cpp`（涂色，CTSC2009）

## 🗺️ 本章地图

> **本章解决一个问题：一整段区间的最优解，怎么由"更短的区间"拼出来？**
> 路线是"套路 → 应用"：先掌握区间 DP 的万能骨架——**枚举区间长度 → 枚举左端点 → 枚举分割点 k**，理解"长区间必由短区间转移"；再用 P4170 涂色走一遍完整推理（从长度 1、2、3 的木板手动推起），学到"首尾相同可一笔涂"的转移技巧。
> 学完请自测三件事：四重循环的顺序能不能默写？k 的范围为什么是 i ≤ k < j？dp 初值该填 0 还是极大值？

## 📌 本章重点（3-5个）

⭐ **区间 DP 的状态定义**：`dp[i][j]` 表示区间 [i, j] 上的最优值（如最小消耗）
⭐ **四重循环骨架**：枚举长度 len（从 2 开始）→ 枚举左端点 i → 右端点 j=i+len-1 → 枚举分割点 k∈[i, j)
⭐ **"先短后长"的枚举顺序**：长区间由短区间合并而来，必须先算完所有短区间
⭐ **分割点的意义**：k 是"子区间的终点和起点"，把 [i,j] 劈成 [i,k] 与 [k+1,j] 两半分别最优再合并
⭐ **首尾相等技巧（P4170）**：`a[i]==a[j]` 时 `dp[i][j]=min(dp[i+1][j], dp[i][j-1])`，两端可一笔顺手涂掉

## 🔥 本章难点（2-3个）

🔥 **为什么按"长度"而非"端点"枚举**：dp[i][j] 依赖的是更短的区间（dp[i+1][j]、dp[i][j-1]、dp[i][k]、dp[k+1][j]），只有保证小区间全部先算完，转移才满足无后效性；按端点双层循环会用到还没算的值
🔥 **首尾相等转移的正确性**：涂 [i,j] 一次时可以同时覆盖首尾（一笔画两端），所以代价等同于"去掉一端后的区间"；但不能想当然写成 dp[i+1][j-1]（见易错点）
🔥 **没有固定模板题**：区间 DP 的难点在"想出状态"而非"写循环"——课件示范的方法是先手动推长度 1、2、3 的小木板，发现"大区间由小区间合并"才定下状态

## ⚠️ 本章易错点（3-5个）

⚠️ **分割点 k 范围写错**：k 从 i 到 **j-1**（因为 k+1 ≤ j），写成 `k<=j` 会访问 dp[j+1][j] 这一非法空区间
⚠️ **漏初始化**：忘记 `memset(dp,0x3f,…)`（求 min 时默认 0 会"假最优"）或忘记 `dp[i][i]=1`（长度 1 的区间要按题意给值）
⚠️ **长度从 1 开始枚举**：长度为 1 不需要合并，len 应从 **2** 开始；且左端点范围是 `i ≤ n-len+1`，否则 j=i+len-1 会越界
⚠️ **首尾相等时写成 dp[i+1][j-1]**：对 "ABA"，dp[2][2]=1 会错答 1；正确是 min(dp[i+1][j], dp[i][j-1])=2——中间那段可能颜色不同，要单独涂
⚠️ **求 min 与求 max 的初值混淆**：求最少消耗要初始化为极大值（0x3f3f3f3f）再转移；照抄"求最多"题的 0 初值会让答案恒为 0

## 📖 知识点讲解

### 1. 区间 DP 的定义与核心思路

**是什么**：区间 DP 是"对区间做的动态规划"——把问题划分为若干**子区间**，定义状态 `dp[i][j]` = 区间 [i,j] 的最优解（一般是最少消耗），通过枚举**分割点**枚举所有合并方式，最终得到整个区间 [1,n] 的最优解。例如 [i,j] 可以劈成 [i,k] 和 [k+1,j]（i ≤ k < j）。

**为什么**：一个区间的合并方式有很多种，无法直接判断哪种最好；但无论哪种方式，最后一步都是"两段已最优的子区间合并"。只要子区间各自最优，枚举全部 k 取最优即可——这正是一维线性 DP"枚举倒数第二步"思想在区间上的推广。

**怎么用**——固定四层循环骨架：

```cpp
memset(dp, 0x3f, sizeof(dp));        // 按题意给初值
for (int i = 1; i <= n; i++) dp[i][i] = 1;   // 长度1的边界
for (int len = 2; len <= n; len++)          // ① 枚举区间长度
    for (int i = 1; i <= n - len + 1; i++)  // ② 枚举左端点
    {
        int j = i + len - 1;                // ③ 右端点
        for (int k = i; k < j; k++)         // ④ 枚举分割点
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j]);
    }
```

> ⚠️ 注意事项：分割点 k 是"左半区的终点 + 右半区的起点减一"，k+1 才是右半区的开头。
> 🎯 规律：长度 → 左端点 → 右端点 → 分割点，四层循环顺序固定。
> 💡 一句话总结：小区间拼出大区间。

---

### 2. "先短后长"：区间 DP 的枚举顺序

**是什么**：区间 DP 必须按**区间长度从小到大**计算：len=1 不用合并（边界），len=2 起逐个计算。原因是所有转移都从"更短的区间"流向"更长的区间"——dp[i+1][j] 短 1 格，dp[i][k] 与 dp[k+1][j] 加起来才 len 格，每个依赖项都比 [i,j] 短。

**为什么**：DP 无后效性要求"算 dp[i][j] 时它依赖的状态必须已算出"。若不按长度而按 i 或 j 的任意顺序枚举，就可能出现 dp[i+1][j] 还没算就被使用的情况，结果错且难查。

**怎么用**——按长度从小到大展开一轮（n=4）：

| 长度 len | 计算的区间 | 依赖的更短区间 |
|---|---|---|
| 1 | [1,1] [2,2] [3,3] [4,4] | 无（初始值） |
| 2 | [1,2] [2,3] [3,4] | 长度 1 的两半 |
| 3 | [1,3] [2,4] | 长度 1+2 / 2+1 的分割 |
| 4 | [1,4] | 长度 1+3 / 2+2 / 3+1 的分割 |

> ⚠️ 注意事项：左端点上界是 n-len+1，保证右端点不超 n；len=1 通常在循环外单独初始化。
> 🎯 规律：转移箭头永远指向"更长"，所以按长度递增填表万无一失。
> 💡 一句话总结：先算短的，再算长的。

### 3. 例题精讲：P4170 涂色

**是什么**：一根 n 格木板，每次可把一段连续区间涂成同一种颜色（后涂覆盖先涂），目标串给出每格最终颜色，求最少涂色次数。`dp[i][j]` = 把 [i,j] 涂成目标颜色的最少次数，答案 `dp[1][n]`。

**为什么**（课件的小规模推理）：木板长度 1 → 涂 1 次；长度 2 → 两格同色则 1 次（顺手涂掉），异色则 2 次；长度 3 → "ABA" 只需 2 次（先一笔涂 "AAA" 再涂中间 B，首尾同色可一笔带过），"ABC" 要 3 次。由此看出**大区间的答案由小区间合并而来** → 区间 DP。转移：首尾同色 `a[i]==a[j]` 时，两端可一笔涂掉，`dp[i][j]=min(dp[i+1][j], dp[i][j-1])`；否则枚举分割点 `dp[i][j]=min(dp[i][k]+dp[k+1][j])`。

**怎么用**——跟着算：目标串 `"ABA"`（n=3），初始化 `dp[i][i]=1`，其余 0x3f：

| 长度 | 区间 | 首尾是否同色 | 转移过程 | 结果 |
|---|---|---|---|---|
| 1 | [1,1] [2,2] [3,3] | — | 初始各涂一次 | dp[1][1]=dp[2][2]=dp[3][3]=1 |
| 2 | [1,2] "AB" | 否 | k=1：dp[1][1]+dp[2][2]=1+1 | dp[1][2]=2 |
| 2 | [2,3] "BA" | 否 | k=2：dp[2][2]+dp[3][3]=1+1 | dp[2][3]=2 |
| 3 | [1,3] "ABA" | **是** | min(dp[2][3], dp[1][2]) = min(2,2) | **dp[1][3]=2** ✓ |

（"先一笔涂 AAA，再涂中间 B"对应 dp[1][2]+dp[3][3] 这类合并方向，而首尾同色转移直接给出更优的 2。）

```cpp
memset(dp, 0x3f, sizeof(dp));
for (int i = 1; i <= n; i++) dp[i][i] = 1;
for (int len = 2; len <= n; len++)
    for (int i = 1; i <= n - len + 1; i++)
    {
        int j = i + len - 1;
        if (a[i] == a[j]) dp[i][j] = min(dp[i+1][j], dp[i][j-1]);
        else
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j]);
    }
printf("%d\n", dp[1][n]);
```

> ⚠️ 注意事项：读入用 `scanf("%s", a+1)` 从下标 1 存，n=strlen(a+1)；首尾同色分支即使为真，dp[i+1][j] 与 dp[i][j-1] 也一定已按长度算出。
> 🎯 规律：区间 DP 的"想状态"靠手动推最小规模（1、2、3），看出合并结构再定义 dp。
> 💡 一句话总结：首尾同色一笔带，否则劈两半取小。

## 🔍 相似概念辨析

### 组一：线性 DP vs 区间 DP

| 对比维度 | 线性 DP | 区间 DP |
|---------|---------|---------|
| 状态形状 | dp[i] 或 dp[i][j]（"前 i 个"） | dp[i][j]（区间 [i,j]） |
| 阶段划分 | 一个维度线性推进 | 按区间长度从小到大 |
| 转移来源 | 左/上/左上等固定邻居 | 去端点或任意分割点 k 劈开的两半 |
| 循环骨架 | 双重循环（枚举元素） | 四重循环（len→i→j→k） |
| 典型问题 | LIS、LCS、编辑距离 | 涂色、石子合并、能量项链 |
| 复杂度量级 | O(n)~O(n²) | 通常 O(n³) |
| 无后效性来源 | 下标递增 | 长度递增 |

### 组二：区间 DP 的两种转移方式

| 对比维度 | 去端点型（P4170） | 分割点型（石子合并类） |
|---------|------------------|----------------------|
| 转移形式 | dp[i+1][j] / dp[i][j-1] | dp[i][k] + dp[k+1][j] |
| 直觉 | 处理完区间的首/尾元素 | 把区间劈成左右两半分别解决 |
| 循环层数 | 三层（无 k） | 四层（多一层 k） |
| 触发条件 | 首尾满足特定关系（如同色） | 一般情形的合并 |
| 复杂度 | O(n²) | O(n³) |
| 常与谁结合 | 贪心/性质观察 | 前缀和、环形展开 |

## 🧩 本章归纳：一条主线串全章

**"大问题劈成两半，小问题先算"**：区间 DP 把 [1,n] 的最优解拆成"哪个分割点、哪两段子区间"的枚举问题，而子区间又递归地拆——于是计算顺序天然定为"长度从小到大"。状态 `dp[i][j]` 定下后，先给长度 1 的区间按题意赋值，再套"len→i→j→k"骨架逐层合并；遇到特殊性质（如 P4170 首尾同色）可以在骨架上加"去端点"的捷径分支。想不出状态时，学 P4170 从长度 1、2、3 手动推起，合并结构会自己浮出水面。这条"短区间 → 长区间"的主线，与线性 DP 的"前 i 个 → 前 i+1 个"是同一条无后效性原理的不同投影。

## 📋 速查表

| 项目 | 内容 |
|------|------|
| 状态 | dp[i][j] = 区间 [i,j] 的最优值 |
| 边界 | dp[i][i] = 按题意赋值（如 1）；求 min 时其余置 0x3f |
| 枚举顺序 | len 从 2 到 n → i 从 1 到 n-len+1 → j=i+len-1 → k 从 i 到 j-1 |
| 分割点转移 | dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j]) |
| 去端点转移（P4170） | a[i]==a[j]：dp[i][j] = min(dp[i+1][j], dp[i][j-1]) |
| 答案 | dp[1][n] |
| 复杂度 | 一般 O(n³)，n 到几百量级可用 |
