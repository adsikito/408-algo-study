>
> 例题代码清单：`P1048.cpp`（采药，01 背包板子）、`P1616.cpp`（疯狂的采药，完全背包板子）

## 🗺️ 本章地图

> **本章解决一个问题：容量有限，物品选哪些，总价值最大？**
> 路线是"两类背包 → 一个降维技巧"：先按 DP 五步法推 01 背包的二维转移（选/不选），再用滚动数组降到一维并回答"为什么倒序枚举"；然后只改一个循环方向得到完全背包（可重复取），最后用两道板子题 P1048 / P1616 落地，注意 P1616 的数据范围坑。
> 学完请自测三件事：01 与完全的转移方程差在哪个下标？一维数组为什么 01 倒序、完全正序？"恰好装满"和"至多装满"初始化有何不同？

## 📌 本章重点（3-5个）

⭐ **01 背包二维转移**：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`——第 i 件"不选 / 选"两分支取 max
⭐ **滚动数组降维**：dp[i][…] 只依赖第 i-1 行，压成一维 `f[j] = max(f[j], f[j-w[i]] + v[i])`
⭐ **枚举方向的决定性**：01 背包一维必须**倒序**（j 从大到小），防止本行已更新的值被再次使用（物品被取多次）；完全背包恰好要重复取，所以**正序**
⭐ **完全背包的视角**：每种物品可取 0、1、2…⌊m/w[i]⌋ 件，本质是"01 背包的推广"，一维正序即得 O(nm)
⭐ **答案与初始化**：至多装满时全 0 初始化，答案 f[m] / dp[n][m]

## 🔥 本章难点（2-3个）

🔥 **同一行代码，方向一字之差两类背包**：`for(j=t; j>=ti[i]; --j)` 是 01，`for(j=w[i]; j<=m; j++)` 是完全——课件原话："正着遍历，前面的数据已发生改变，同样的物品会放多次（这正是完全背包的要求）；倒着遍历则不会动到最初的数据"
🔥 **完全背包三重循环的化简**：枚举取 k 件的 O(n³) 写法可化简为 `dp[i][j] = max(dp[i-1][j], dp[i][j-w[i]] + v[i])`——注意第二项是 **dp[i][…]（本行）**，与 01 背包的 dp[i-1][…] 一字之差，这就是"同一物品可再次选取"的数学表达
🔥 **降维后"为什么还能对"**：二维时 dp[i][j] 用的是上一行旧值；压成一维后，倒序枚举保证 f[j-w[i]] 还没被本行更新（等价于上一行的旧值），这是滚动数组正确性的核心

## ⚠️ 本章易错点（3-5个）

⚠️ **01 背包一维写成正序**：`for(j=1..m)` 会让同一物品被重复装入（实际变成了完全背包），答案是错的且不易察觉——P1048 必须倒序 `for(j=t; j>=ti[i]; --j)`
⚠️ **转移前忘判 j >= w[i]**：二维里不判断会访问 dp[i-1][负数] 越界；一维里要把循环起点设在 w[i]（01 的终点 / 完全的起点）
⚠️ **P1616 的数据范围坑**：m 可到 1e7、价值累加超 int——必须 `#define int long long`（main 用 signed main），f 数组开到 1e7+5，用 scanf/printf 快读快写
⚠️ **两类背包的转移下标记混**：01 是 `f[j-w[i]]`（上一行旧值），完全化简式第二项是本行 dp[i][j-w[i]]；一维写法里这个差别完全由循环方向体现
⚠️ **"恰好装满"的初始化**：若题目要求恰好装满，f 应初始化为负无穷、f[0]=0，答案可能为"不可行"；全 0 初始化求的是"至多装满"——两种题意别用错模板

## 📖 知识点讲解

### 1. 01 背包：选与不选的二维 DP

**是什么**：n 种物品每件**只有一个**，第 i 件重 w[i]、价值 v[i]，容量为 m 的背包最多装多大价值？名字的由来：每件物品最终状态只有 0 件或 1 件。状态 `dp[i][j]` = 从前 i 个物品中任选、装入容量 j 的背包的最大价值，答案 `dp[n][m]`。

**为什么**：只考虑第 i 件选不选——**不选**：等价于从前 i-1 件里选、容量仍是 j，即 dp[i-1][j]；**选**：占掉 w[i] 容量，剩下 j-w[i] 容量交给前 i-1 件，再叠加 v[i]，即 dp[i-1][j-w[i]]+v[i]。两分支取 max，最优子结构成立。

**怎么用**——跟着算：容量 m=4，物品 1(w=1,v=2)、物品 2(w=3,v=4)、物品 3(w=4,v=5)。第 0 行/列全 0：

| dp[i][j] | j=0 | j=1 | j=2 | j=3 | j=4 |
|---|---|---|---|---|---|
| i=0（无物品） | 0 | 0 | 0 | 0 | 0 |
| i=1（1,2） | 0 | max(0, 0+2)=**2** | **2** | **2** | **2** |
| i=2（3,4） | 0 | 2 | 2 | max(2, 0+4)=**4** | max(2, 2+4)=**6** |
| i=3（4,5） | 0 | 2 | 2 | 4 | max(6, 0+5)=**6** |

答案 dp[3][4]=6（选物品 1+2，总重 4、总价值 6）；单选物品 3 只有 5，故不选。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 0; j <= m; j++) {
        dp[i][j] = dp[i-1][j];                    // 不选
        if (j >= w[i])                            // 选（防越界）
            dp[i][j] = max(dp[i][j], dp[i-1][j-w[i]] + v[i]);
    }
```

> ⚠️ 注意事项：初始化 dp[0][j]=dp[i][0]=0（不选任何物品 / 容量为 0 都是 0 价值）。
> 🎯 规律：背包 DP 的转移永远在问"第 i 件选不选"。
> 💡 一句话总结：01 背包，选不选取大。

---

### 2. 滚动数组：降维与"为什么倒序"

**是什么**：dp[i][j] 只从第 i-1 行推来，其余行全无用——用一维 f[j] 滚动覆盖：`f[j] = max(f[j], f[j-w[i]] + v[i])`，全 0 初始化，答案 f[m]。但必须**倒序枚举 j**（从 m 到 w[i]）。

**为什么**：正序时算 f[大 j] 用到的 f[j-w[i]] 是**本行刚更新过的值**，等于把第 i 件物品又放了一次（课件：前面的数据已发生改变，同样的物品会放多次）；倒序时 f[j-w[i]] 尚未被本行碰过，仍是"上一行旧值"，恰好等价于二维的 dp[i-1][j-w[i]]。

**怎么用**——跟着算：只用物品 1(w=1,v=2)，m=4，对比两个方向：

| 正序 j=1→4（错，变完全背包） | 倒序 j=4→1（对，01 背包） |
|---|---|
| f[1]=f[0]+2=2 | f[4]=f[3]+2=2 |
| f[2]=f[1]+2=**4** ← 物品1放了2次！ | f[3]=f[2]+2=2 |
| f[3]=**6**，f[4]=**8** | f[2]=2，f[1]=2 |

```cpp
for (int i = 1; i <= m件物品数; i++)
    for (int j = t; j >= ti[i]; --j)      // 01背包：倒序！
        f[j] = max(f[j], f[j - ti[i]] + v[i]);
cout << f[t];
```

> ⚠️ 注意事项：内层循环起点（完全）或终点（01）是 w[i]，天然规避 j-w[i] 越界。
> 🎯 规律：要"上一行的旧值"就倒序，要"本行的新值"就正序。
> 💡 一句话总结：01 倒序防重复。

---

### 3. 完全背包：正序即重复取

**是什么**：每种物品**无限多件**，可重复放入。策略不再是"选/不选"，而是取 0、1、2……⌊m/w[i]⌋ 件——完全背包是 01 背包的推广。状态同为 dp[i][j]，朴素写法枚举 k 需三重循环 O(n³)。

**为什么**：降维后化简出的转移 `dp[i][j] = max(dp[i-1][j], dp[i][j-w[i]] + v[i])` 中第二项是**本行**——"已放过一个物品 i 的背包可以再放一个"。而 01 背包一维倒序巧妙避开的"本行新值"，正是完全背包想要的，所以**直接把 01 的代码改成 j 从 w[i] 到 m 正序**即可。

**怎么用**——跟着算：容量 4，物品 A(w=1,v=2)、物品 B(w=3,v=4)，一维正序：

| 步骤 | 计算过程 | f[1..4] |
|---|---|---|
| 初始 | 全 0 | 0 0 0 0 |
| 物品 A 正序 | f[1]=2 → f[2]=f[1]+2=4 → f[3]=6 → f[4]=8 | 2 4 6 8（A 被取了多件） |
| 物品 B 正序 | f[3]=max(6, f[0]+4)=6；f[4]=max(8, f[1]+4)=8 | 2 4 6 **8** |

答案 f[4]=8 = 取 4 件 A。对比 01 背包规则下同样的两件物品只能得 6——方向改变直接改变"可取件数"。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= m; j++)       // 完全背包：正序！
        f[j] = max(f[j], f[j - w[i]] + v[i]);
printf("%lld", f[m]);
```

> ⚠️ 注意事项：P1616 中 m 高达 1e7，数组要开够、用 long long、IO 用 scanf/printf；每个物品无限件但"总重不超 m"天然限制了件数。
> 🎯 规律：01 与完全只差内层循环方向——倒序取一次，正序取无限。
> 💡 一句话总结：完全正序可重复。

## 🔍 相似概念辨析

### 组一：01 背包 vs 完全背包

| 对比维度 | 01 背包 | 完全背包 |
|---------|---------|---------|
| 每种物品件数 | 1 件（取 0 或 1） | 无限（取 0…⌊m/w[i]⌋ 件） |
| 转移（二维） | max(dp[i-1][j], dp[i-1][j-w[i]]+v[i]) | max(dp[i-1][j], dp[i][j-w[i]]+v[i]) |
| 一维枚举方向 | j 从 m 倒序到 w[i] | j 从 w[i] 正序到 m |
| 朴素复杂度 | O(nm) | 朴素 O(n³)，化简后 O(nm) |
| 典型例题 | P1048 采药 | P1616 疯狂的采药 |
| 一维正序的后果 | 物品被重复取，答案错 | 这正是想要的语义 |

### 组二：二维写法 vs 一维滚动数组

| 对比维度 | 二维 dp[i][j] | 一维 f[j] |
|---------|--------------|-----------|
| 空间复杂度 | O(nm)（1e7 级会 MLE） | O(m) |
| 转移来源 | 上一行 dp[i-1][…] | 同数组旧值（=上一行） |
| 方向要求 | j 正反皆可 | 01 必须倒序 / 完全必须正序 |
| 能否输出具体方案 | 方便（回溯记录选了哪些） | 需额外记录路径 |
| 初始化 | 第 0 行/列显式赋 0 | 整体 memset 0 |
| 适用场景 | 教学推演、要方案 | 竞赛标准写法 |

## 🧩 本章归纳：一条主线串全章

**"容量是阶段，物品是决策，方向定语义"**：背包问题把 DP 五步法中的状态定为"前 i 个物品、容量 j"（或降维后只剩 j），转移永远是"第 i 件不选 = 继承，选 = 腾出 w[i] 容量再叠加价值"。01 与完全两类背包共用同一状态与几乎同一代码，唯一分水岭是**一维内层的枚举方向**：倒序只许取一次，正序允许取无限。降维的思想又回到第 27 章的老朋友——dp[i] 只依赖 dp[i-1]，所以滚动覆盖。两道板子题 P1048/P1616 提醒我们：竞赛里除了方程，数组大小、long long、IO 速度同样是 AC 的组成部分。
