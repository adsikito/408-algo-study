## 🗺️ 本章地图

> **本章解决一个问题：在一维/二维"线性阶段"上，如何用 DP 求最值？**
> 路线是"方法论 → 三道经典"：先掌握 DP 做题五步法（状态→转移→初始化→转移代码→输出答案）；再用它依次攻下三座山——最长上升子序列 LIS（一维 dp）、最长公共子序列 LCS（二维 dp）、最短编辑距离（二维 dp + 三种操作）。
> 学完请自测三件事：能不能一句话描述状态？转移方程每一项的"最后一步"是什么？边界（空串/单元素）初始化对不对？

## 📌 本章重点（3-5个）

⭐ **DP 五步法**：定状态 → 定转移方程 → 初始化 → 写转移代码 → 输出答案，所有 DP 题统一按此流程拆解
⭐ **"以 i 结尾"的状态设计**：LIS 定义 `dp[i]` = 以 a[i] 结尾的最长上升子序列长度，答案是 max(dp[1..n]) 而非 dp[n]
⭐ **"前 i 个"的状态设计**：LCS/编辑距离定义 `dp[i][j]` = A 前 i 个与 B 前 j 个的答案，答案是 dp[n][m]
⭐ **编辑距离三分支**：字符不等时 添加/删除/替换 三种操作取 min，相等时直接继承 dp[i-1][j-1]
⭐ **状态转移的"无后效性"**：算 dp[i] 时假设前面已求出，只依赖更小的下标

## 🔥 本章难点（2-3个）

🔥 **为什么"相等时不取 max"**：编辑距离中 `a[i]==b[j]` 时直接 `dp[i][j]=dp[i-1][j-1]`，直觉上"不改白不改"；而 LCS 中相等时必须 `dp[i-1][j-1]+1`——两题符号差异的背后是"这一步是否消耗操作次数"
🔥 **初始化的物理含义**：编辑距离第 0 行/第 0 列 `dp[i][0]=i, dp[0][j]=j` 不是随手填 0，而是"全删光/全插入"的空串边界
🔥 **线性 DP 无固定模板**： LIS 是 O(n²) 双重循环枚举"接在谁后面"，二维 DP 是逐格填表——共性只有"阶段线性推进 + 最优子结构"

## ⚠️ 本章易错点（3-5个）

⚠️ **LIS 答案不在 dp[n]**：dp[i] 是"以 i 结尾"，最长者可能结尾在中间，必须 `ans = max(dp[1..n])`，直接输出 dp[n] 是高频 WA
⚠️ **LIS 初始化忘写 `dp[i]=1`**：每个元素自己就是一个长度为 1 的子序列，漏了初始化全为 0，转移后答案恒错
⚠️ **严格上升的判断条件**：`a[i] > a[j]` 才能转移，写成 `>=` 会把相等元素算进"上升"，对"严格上升"题直接错
⚠️ **LCS 相等时忘了 +1**：`dp[i][j] = dp[i-1][j-1] + 1`，只写 `dp[i-1][j-1]` 会导致公共字符没被计数
⚠️ **下标从 0 还是从 1 读入**：P2758 用 `scanf("%s%s", a+1, b+1)` 从 1 开始存，边界 `dp[i][0]、dp[0][j]` 才有位置放；下标混乱会导致访问 dp[-1] 或边界含义错位

## 📖 知识点讲解

### 1. DP 做题五步法（线性 DP 总纲）

**是什么**：动态规划适用的问题有两个标志——**最优子结构**（大问题的最优解由小问题的最优解拼出）+ **重叠子问题**（小问题被反复用到），且答案通常是"最值"。做题固定五步：① 确定状态：用一句话描述问题，句中的参数就是 dp 数组的下标；② 确定状态转移方程；③ 初始化初始状态；④ 写状态转移代码；⑤ 输出题目要求的状态（大多是最终状态）。

**为什么**：线性 DP（线性阶段划分，每个维度都是线性推进）**没有固定模板**，题目千变万化；但五步法是万能骨架，把"想不清楚"变成"按顺序填空"，刷题时不会无从下手。

**怎么用**：以 LIS 为例走一遍五步——
① 一句话："以 a[i] 结尾的最长上升子序列有多长？" → 参数是 i，一维 dp；
② `if(a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1) (j<i)`；
③ `dp[1..n] = 1`（每个元素各自成序列）；
④ 双重循环 i 从 2 到 n，内层 j 从 1 到 i-1；
⑤ `ans = max(dp[1..n])`。

> ⚠️ 注意事项：确定状态时优先尝试"以 i 结尾 / 前 i 个"两种句式；状态设计不同，转移和答案位置完全不同。
> 🎯 规律：会"一句话描述问题"就会定状态，会定状态就会推转移。
> 💡 一句话总结：五步法是 DP 的万能骨架。

### 2. 最长上升子序列 LIS（B3637）

**是什么**：在数组中找最长的严格上升子序列（可不连续）。关键洞察：任何子序列必然以某个 a[i] 结尾，所以"整体最长"= "分别以每个元素结尾的最长"取最大。定义 `dp[i]` = 以 a[i] 结尾的最长上升子序列长度。

**为什么**：以 a[i] 结尾的最长上升子序列，一定是在某个以 a[j]（j<i 且 a[j]<a[i]）结尾的上升子序列后面接上 a[i]；只要 dp[1..i-1] 已求出，枚举接在谁后面取 max 即可——这就是最优子结构。

**怎么用**——跟着算：`a = [3, 1, 2, 1, 4]`，初始 `dp = [1,1,1,1,1]`：

| i（值） | 内层枚举 j | 转移过程 | dp[i] 结果 |
|---|---|---|---|
| i=1（3） | — | 初始 | **1** |
| i=2（1） | j=1：1>3? 否 | 无转移 | **1** |
| i=3（2） | j=1：否；j=2：2>1 ✓ → dp[2]+1=2 | 取 max | **2** |
| i=4（1） | j=1,2,3：1>3? 否；1>1? 否；1>2? 否 | 无转移 | **1** |
| i=5（4） | j=1：3 ✓→2；j=2：1 ✓→2；j=3：2 ✓→dp[3]+1=3；j=4：否 | 取 max | **3** |

`ans = max(1,1,2,1,3) = 3`，对应子序列 `1,2,4`。复杂度 O(n²)。

```cpp
for (int i = 1; i <= n; i++) dp[i] = 1;          // 初始化：各自成序列
for (int i = 2; i <= n; i++)
    for (int j = 1; j <= i - 1; j++)
        if (a[i] > a[j]) dp[i] = max(dp[i], dp[j] + 1);
int ans = 0;
for (int i = 1; i <= n; i++) ans = max(ans, dp[i]); // 答案取全表最大
```

> ⚠️ 注意事项：答案必须扫全表取 max；条件是严格大于；dp[i] 的含义是"结尾"，不是"前 i 个"。
> 🎯 规律：枚举"倒数第二步"接在哪里，是线性 DP 推转移的通用手法。
> 💡 一句话总结：LIS 数结尾，全表取最大。

### 3. 最长公共子序列 LCS（LC LCR 095）

**是什么**：求两个序列公共的（可不连续）子序列的最大长度。用"前 i 个"句式定状态：`dp[i][j]` = A 的前 i 位与 B 的前 j 位的 LCS 长度，答案 `dp[L1][L2]`。

**为什么**：看最后一对字符——若 `A[i]==B[j]`，这个公共字符可以放心当 LCS 的结尾，问题缩小为 `dp[i-1][j-1]+1`；若不等，结尾字符至少有一个不在 LCS 里，取 `max(dp[i-1][j], dp[i][j-1])`（丢弃 A 的末位或 B 的末位）。

**怎么用**——跟着算：`A = "abcde"`，`B = "ace"`，第 0 行/列全 0：

| dp | j=0 | j=1(a) | j=2(c) | j=3(e) |
|---|---|---|---|---|
| i=0 | 0 | 0 | 0 | 0 |
| i=1(a) | 0 | a==a → dp[0][0]+1=**1** | max(0,1)=**1** | max(0,1)=**1** |
| i=2(b) | 0 | max(1,0)=**1** | max(1,1)=**1** | max(1,1)=**1** |
| i=3(c) | 0 | max(1,0)=**1** | c==c → dp[2][1]+1=**2** | max(1,2)=**2** |
| i=4(d) | 0 | **1** | max(2,1)=**2** | max(2,2)=**2** |
| i=5(e) | 0 | **1** | **2** | e==e → dp[4][2]+1=**3** |

答案 `dp[5][3] = 3`，对应 "ace"。

```cpp
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;
        else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
```

> ⚠️ 注意事项：相等分支别忘了 +1；不等分支的两个方向都要 max（只看一个方向会漏解）；复杂度 O(n·m)。
> 🎯 规律：二维线性 DP 的转移只碰"左、上、左上"三个邻居。
> 💡 一句话总结：LCS 看末位，相等加一。

### 4. 最短编辑距离（P2758）

**是什么**：把串 A 变成串 B，每次可以 添加/删除/替换 一个字符，求最少操作次数。状态：`dp[i][j]` = A 前 i 个字符变成 B 前 j 个字符的最少操作数，答案 `dp[n][m]`。

**为什么**：分"最后一步"讨论——若 `a[i]==b[j]`，这对字符什么都不用做，直接继承 `dp[i-1][j-1]`；若不等，三种操作各对应一个子问题 +1：**添加** → 先把 A 前 i 个变成 B 前 j-1 个再加一个 b[j]（`dp[i][j-1]+1`）；**删除** → 把 a[i] 删掉再变（`dp[i-1][j]+1`）；**替换** → 把 a[i] 换成 b[j]（`dp[i-1][j-1]+1`），三者取 min。

**怎么用**——跟着算：`A = "ab"`，`B = "acb"`（在 A 中插入一个 c 即可，答案应为 1）。初始化 `dp[i][0]=i`（全删）、`dp[0][j]=j`（全插）：

| dp | j=0 | j=1(a) | j=2(c) | j=3(b) |
|---|---|---|---|---|
| i=0 | 0 | 1 | 2 | 3 |
| i=1(a) | 1 | a==a → **0** | min(0+1, 2+1, 1+1)=**1** | min(1+1, 3+1, 2+1)=**2** |
| i=2(b) | 2 | min(2+1, 0+1, 1+1)=**1** | min(1+1, 1+1, 0+1)=**1** | b==b → dp[1][2]=**1** |

答案 `dp[2][3] = 1` ✓。

```cpp
for (int i = 1; i <= n; i++) dp[i][0] = i;   // A 前 i 个全删成空串
for (int j = 1; j <= m; j++) dp[0][j] = j;   // 空串全插成 B 前 j 个
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1];
        else dp[i][j] = min(min(dp[i][j-1], dp[i-1][j]), dp[i-1][j-1]) + 1;
    }
```

> ⚠️ 注意事项：初始化是"空串边界"不是 0；相等时不加 1（这步零消耗）；从下标 1 读入字符串，给边界留出第 0 行/列。
> 🎯 规律：字符相等白嫖继承，不等就"增删替"三选一。
> 💡 一句话总结：编辑距离，增删替取小。

## 🔍 相似概念辨析

### 组一：子序列 vs 子串

| 对比维度 | 子序列 | 子串 |
|---------|--------|------|
| 连续性 | 可以不连续，保序即可 | 必须连续 |
| 长度上限 | 最长可达 n | 最长为 n |
| 典型问题 | LIS、LCS | 最长公共子串、字符串匹配 |
| dp 状态特点 | "以 i 结尾"较常用 | 常以"以 i 结尾"且相等时接续 |
| 转移方式 | 跳跃枚举 j<i | 通常只依赖相邻位置 |
| 对应本章题 | B3637、LCR 095 | KMP（第 26 章） |

### 组二：LIS（一维线性 DP）vs LCS / 编辑距离（二维线性 DP）

| 对比维度 | LIS | LCS / 编辑距离 |
|---------|-----|---------------|
| 状态维度 | 一维 dp[i] | 二维 dp[i][j] |
| 状态句式 | 以 a[i] **结尾** | A **前 i 个** 与 B 前 j 个 |
| 转移依赖 | 所有 j<i | 左 / 上 / 左上三邻居 |
| 初始化 | dp[1..n]=1 | 第 0 行/列为空串边界 |
| 答案位置 | max(dp[1..n]) | dp[n][m] |
| 时间复杂度 | O(n²)（可优化 nlogn） | O(n·m) |
| 循环结构 | 双重循环枚举接续点 | 逐行逐格填表 |

### 组三：LCS 的相等分支 vs 编辑距离的相等分支

| 对比维度 | LCS | 编辑距离 |
|---------|-----|---------|
| a[i]==b[j] 时 | dp[i-1][j-1] **+1** | dp[i-1][j-1] **不加** |
| 原因 | 公共字符计入长度 | 该步零操作消耗 |
| 不等时 | max(上, 左) | min(增, 删, 替)+1 |
| 优化目标 | 最大化 | 最小化 |
| 边界含义 | 空串 LCS=0 | 空串需 i/j 次全删/全插 |
| 答案 | dp[n][m] | dp[n][m] |

## 🧩 本章归纳：一条主线串全章

**一切从"一句话描述问题"出发**：把题意压成一句带参数的话，参数就是 dp 下标——"以 a[i] 结尾"得到一维 LIS，"A 前 i 个 vs B 前 j 个"得到二维 LCS 与编辑距离。接着问"最后一步是什么"：LIS 的最后一步是"接在某个 dp[j] 后面"，LCS/编辑距离的最后一步是"看末位字符配不配对"，于是转移方程自然写出；再给边界赋物理含义（单元素自成序列 / 空串全删全插），最后按行列顺序填表、在正确位置取答案。三道题长得完全不同，骨架却是同一个五步法——后面区间 DP、背包、树形 DP，也只是把"阶段"从线性换成了别的形状。
