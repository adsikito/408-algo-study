## 本章地图

本章解决一个问题：**「搜索树指数爆炸，怎么把它压回去？」**

```text
朴素 DFS 的搜索树：O(分支数 ^ 深度)
   ↓
三条压缩路线：
   ├─ 剪枝：整棵子树不搜
   │     ├─ 可行性剪枝：约束已违反 → 回退（知识点 1）
   │     └─ 最优性剪枝：上界 ≤ 已知最优 → 回退（知识点 2）
   ├─ 记忆化：同一状态只算一次（知识点 3）
   │     └─ 状态数从「路径数」降到「状态数」→ 通往 DP
   └─ 换搜索顺序：
         ├─ 折半搜索：2ⁿ 拆两个 2^(n/2)（知识点 4）
         └─ 双向 BFS：b^d 拆 b^(d/2)（知识点 5）
   ↓
共同前提：排序 / 预处理让剪枝与匹配生效
```

**为什么这条路径是这样**：三类优化各压指数的**不同因子**——
剪枝砍「无效分支」、记忆化砍「重复子树」、折半砍「深度」。
**识别一道题该用哪条：看浪费发生在哪（无效分支？重复状态？深度太深？）。**

## 核心概念与模板

**是什么**：朴素搜索的搜索树随深度指数爆炸。三类优化把指数压回可过范围：
1. **可行性剪枝**：当前路径已不可能成解 → 立即回退；
2. **最优性剪枝**：当前代价已 ≥ 已知最优解 → 回退；
3. **记忆化**：同一状态只算一次（重叠子问题，通往 DP 的桥）。
另有双向 BFS（两端同时扩散）与启发式 A*（超本阶段）。

**为什么**：三类优化各压指数的不同因子——剪枝砍无效分支、记忆化砍重复子树、
折半砍深度。**看浪费发生在哪，选哪条。**

> **【规律】** **排序预处理是剪枝生效的前提**：背包按性价比降序后，
> 「全拿剩余也超不过 best」的上界才足够紧——**不排序的剪枝常常形同虚设。**

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
typedef long long ll;
const int N = 55;
int n, W, w[N], v[N];
ll best = 0, suf[N];                     /* suf：后缀权和（可行性上界） */

/* 0-1 背包爆搜 + 双重剪枝（按 w 降序排序后效果最佳） */
void dfs(int i, ll cw, ll cv) {
    if (cv > best) best = cv;            /* 更新答案 */
    if (i > n) return;
    /* 最优性剪枝：全拿剩余也超不过 best，剪 */
    if (cv + suf[i] <= best) return;
    /* 可行性剪枝：放得下才放 */
    if (cw + w[i] <= W) dfs(i + 1, cw + w[i], cv + v[i]);
    dfs(i + 1, cw, cv);                  /* 不放 */
}

/* 记忆化：网格路径计数（重叠子问题 → dp 表） */
ll memo[N][N];
ll pathCnt(int x, int y) {               /* 到 (n,n) 的路径数 */
    if (x > n || y > n) return 0;
    if (x == n && y == n) return 1;
    if (memo[x][y] != -1) return memo[x][y];   /* 命中缓存 */
    return memo[x][y] = pathCnt(x + 1, y) + pathCnt(x, y + 1);
}
```

**双向 BFS 骨架**：两个队列交替扩展（每次扩展较小的一侧），两测相遇即最短步数——
把 O(b^d) 压到 O(b^(d/2))。

> **【类比】** 剪枝像**考试先扫一眼大题**：这道题满分都比已得分少，直接跳过
> （最优性）；这道题超纲做不出来，跳过（可行性）。
> 记忆化像**草稿纸上记答案**：同一道小题算一次，再遇到抄结果。
> **两者的共同点是：先花一分钟「整理题目」（排序 / 状态编号），后面省的是指数。**

## 本章难点

> **【难点】** **上界估计的紧与松。**
> 最优性剪枝必须用「剩余部分的理论上界 ≤ 当前最优」——
> 估高了（上界太松）剪不掉任何分支，估低了（上界不准）**错剪正确解**。
> **纪律：上界必须是「可证明 ≥ 真实最优」的量**（如按性价比重排后的后缀和），
> 绝不用拍脑袋的估计。

> **【难点】** **记忆化的状态定义 = 函数参数的全集**。
> `pathCnt(x, y)` 的状态是坐标二元组——**参数少一维，状态就错**；
> 判断「参数是否够」的方法：问「同一参数组合的返回值是否永远相同」。
> 是 → 可记忆化；否 → 还缺参数。

---

## 本章易错点

> **【头号易错】** **剪枝条件写错方向**：最优性剪枝必须用「上界估计 ≤ 当前最好」，
> 估高了剪不掉、估低了错剪正确解——**宁保守勿激进**。

> **【易错】** **记忆化状态维度不完整**（少一维就错）；memo 初值 −1 忘 memset。

> **【易错】** **排序预处理忘做**（按性价比 / 尺寸降序是剪枝生效的前提）。

> **【易错】** **双向 BFS 两队列交替顺序错**——每次扩展**较小的一侧**才保证复杂度。

> **【易错】** **记忆化答案超 long long**：路径计数 / 方案数按题意取模（题面会说）。

## 典型例题

### 例 1　小数据 0-1 背包（爆搜 + 双剪枝）　难度：变式题

**题干摘要**：n ≤ 40（DP 表 2⁴⁰ 不可行但 O(nC) 反而慢），求最大价值。
**题源**：折半搜索 / 剪枝经典（n ≤ 30 剪枝版可过，n ≤ 40 上折半）
**涉及知识点**：知识点 1、2、4

**解题思路**：

1. **信号**：n ≤ 40 → 折半搜索（前 20 个枚举 2²⁰ 种、后 20 个 2²⁰ 种，
   后侧排序 + 前侧二分匹配）。
2. **对照**：n ≤ 30 时剪枝爆搜可过——核心模板 dfs（先按性价比排序，suf 预处理后缀和）。
3. **两版对照**体会剪枝与折半的适用线。

**复杂度**：剪枝后远小于 2ⁿ；折半版 O(2^(n/2) × n/2)。

> **【易错】** suf 上界估计「按价值降序重排剩余物品」更紧；
> 拍脑袋估计会错剪正确解。

---

### 例 2　记忆化路径计数（重叠子问题）　难度：模板题

**题干摘要**：n ≤ 20 网格从左上到右下（只右 / 下），求路径数。
**题源**：同类真源见配套练习 T2（P1434 滑雪，记忆化搜索进阶版）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：递归参数组合重复出现 → 记忆化。
2. **方法**：见核心模板 `pathCnt`（memo 初值 −1）。

**复杂度**：O(n²) 状态 × O(1) 转移——朴素递归是 O(2^(2n))，记忆化后线性。

> **【易错】** 状态数 = 网格数（不是路径数）——记忆化的本质是「按状态缓存」；
> 答案超 long long 时按题意取模。

## 本章总结

### 核心内容（一页纸）

1. **三类优化压三个因子**：剪枝砍无效分支、记忆化砍重复子树、折半砍深度。
2. **可行性剪枝**：约束提前违反立即回退；**排序预处理是前提**。
3. **最优性剪枝**：上界必须「可证明 ≥ 真实最优」，宁保守勿激进。
4. **记忆化状态定义 = 参数全集**；判据「同参数是否同答案」。
5. **memo 初值 −1 + memset**；答案超界按题意取模。
6. **折半搜索**：n ≤ 40 判据；前半枚举 + 后半排序 + 二分匹配。
7. **双向 BFS**：每次扩展较小的一侧；b^d → b^(d/2)。
8. **记忆化 → 递推 DP**：同一思想换填写顺序——阶段 7 的前门。
9. **剪枝的正确性比激进性重要**：错剪正确解等于零分。
10. **识别浪费在哪**（无效分支 / 重复状态 / 深度太深）→ 选对应优化。
