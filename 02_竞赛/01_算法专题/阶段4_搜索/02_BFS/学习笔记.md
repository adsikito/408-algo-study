> 课件来源：`16.搜索之BFS.pptx`
>
> 例题代码：`例题代码\P1443.cpp`（P1443 马的遍历）、`P8693.cpp`（P8693 小明瘦身走迷宫）

## 🗺️ 本章地图

> **本章解决一个问题：每步代价相同时，怎么一步到位拿到"最短距离"？**
> 路线是"一个原理 → 两道网格题"：先认识 BFS——按圈层搜索、用队列实现、**第一次到达某点的时间就是最短时间**（知识点 1）；P1443 马的遍历学"日字八方向 + 走不到记 -1 + 距离随队传递"（知识点 2）；P8693 小明瘦身学"状态升级：位置 + 时间决定形态，连原地等待也要入队"（知识点 3）。DFS 铺路、BFS 求最短，搜索双雄本章合璧。
> 学完请自测三件事：为什么第一次到达就一定最短？答案数组为什么先填 -1？P8693 的状态比普通迷宫多了哪两样？

## 📌 本章重点（3-5个）

⭐ **BFS 原理**：按圈层搜索——起点为第 0 层，逐层向外扩展；队列保证第 k 层处理完才碰第 k+1 层；边权相同（每步代价 1）时首次到达即最短
⭐ **BFS 模板五件套**：队列、方向数组 dx/dy、距离数组、访问标记 v、合法判断（越界/可走/未访问）
⭐ **P1443 马的遍历**：ans 全部初始化为 -1（马走日有走不到的点），8 个方向由坐标加减生成，新距离 = 出队点的距离 + 1
⭐ **P8693 状态升级**：node{x,y,t,s} 位置+时间+形态；形态由时间决定（t<k→5×5、t<2k→3×3、否则 1×1）；**原地等待也要入队**（瘦身有后效价值），已瘦到 1×1 就不必再等

## 🔥 本章难点（2-3个）

🔥 **"首次到达即最短"的理解**：为什么不用取 min？——队列的层序保证扩展第 k+1 层时第 k 层已全部定稿，任何更晚到达的路径都至少多走一层；想不通就用 3×3 棋盘手动圈层验证
🔥 **P8693 的状态设计**：胖瘦随时间变化导致"能不能走"与时间有关，(x,y) 不再完整描述状态——必须把 t（进而形态 s）塞进队列元素，且"原地等 1 秒"是合法转移（now.s!=0 时入队 (x,y,t+1)）

## ⚠️ 本章易错点（3-5个）

⚠️ **忘初始化 -1 / 初始化顺序错**：P1443 先 `memset(ans,-1,sizeof ans)` 再 `ans[x][y]=0`、标记起点；顺序颠倒起点会被改成 -1，走不到的点也不再是 -1
⚠️ **出队时才标记**：必须在**入队时**就置 v=1；出队才标记的话同一点会被多个邻居重复塞进队列，队列爆炸 TLE
⚠️ **距离忘了 +1 或起点没置 0**：`ans[nx][ny]=ans[p.first][p.second]+1`；起点距离是 0 不是 1
⚠️ **P8693 状态丢时间**：只存 (x,y) 无法知道瘦身进度，形态判定全错；v 的判断也不能脱离当前形态（胖时过不去的口子瘦时能过）
⚠️ **P8693 最瘦还傻等**：`now.s==0` 时不再把原地等待入队——课件原话：此时再等待纯属无意义地耗费时间

## 📖 知识点讲解

### 1. BFS：按圈层扩展，首次到达即最短

**是什么**：白话——往水里丢石头，波纹一圈圈荡开：BFS（图论）= 广度优先搜索，按**圈层**遍历树或图。课件定义：搜索算法中的 BFS 常指**利用队列实现**广度优先搜索，从而**寻找最短距离**；从起点开始，**第一次到达某个点的时间就是最短时间/距离**。网格中也常用 BFS 找最短距离，搜索时考虑 4 或 8 个方向，注意不要越过边界。

**为什么**：队列先进先出 → 距离为 k 的点全部出队之后，距离 k+1 的点才会开始出队；每条边代价相同（走一步 1 秒），所以任何点第一次被碰到的圈层就是它的最短层数。DFS 一条道走到黑，第一次到达未必是最短路，求最短就得把所有路径比一遍——BFS 用层序直接免掉这一步。

**怎么用**——模板：
```cpp
queue<PII> q;                      // 队列
memset(ans,-1,sizeof ans);         // 距离初始化（-1=不可达）
ans[sx][sy]=0; v[sx][sy]=1; q.push({sx,sy});   // 起点入队并标记
while(!q.empty())
{
    PII p=q.front(); q.pop();      // 取队头
    for(int i=0;i<4;i++)           // 枚举方向
    {
        int nx=p.first+dx[i], ny=p.second+dy[i];
        if(不越界 && !v[nx][ny] && 可走)
        {
            ans[nx][ny]=ans[p.first][p.second]+1;  // 距离+1
            v[nx][ny]=1;                            // 入队时标记！
            q.push({nx,ny});
        }
    }
}
```
跟算：6 结点图 A—B、A—C、B—D、C—E、D—F，从 A 出发：
```
第 0 层：出队 A(dist 0) → 入队 B、C(dist 1)
第 1 层：出队 B → 入队 D(dist 2)；出队 C → 入队 E(dist 2)
第 2 层：出队 D → 入队 F(dist 3)；出队 E → 无新点
第 3 层：出队 F → 无新点，队列空，结束
dist：A=0，B=C=1，D=E=2，F=3 —— 每个点都在第一次被碰到时定稿
```

> ⚠️ 注意事项：BFS 求最短的前提是**每步代价相同**；代价不同要上优先队列/Dijkstra（后续最短路章节）。

> 🎯 规律：见"最少步数/最短时间 + 一步步走"→ BFS；队列的层序就是正确性保证。

> 💡 一句话总结：一圈圈荡开，首次即最短。

### 2. 马的遍历：八方向与 -1 初始化（P1443）

**是什么**：白话——n×m 棋盘上一匹马从 (x,y) 出发，求它到每个格子最少几步；马走"日"字。课件思路：(1) 马只能走"日"字，**不是所有格子都能走到**，所以先把答案数组全部赋成 -1，搜索中再改变能走到的点；(2)"日"字的八个方向通过对行列坐标 x、y 做加减得到（dx/dy 数组）；(3) 队列用 STL 实现，BFS 过程中维护距离数组。

**为什么**：-1 一物两用——既是"不可达"的答案，也是"未访问"的标记的补充（代码里另开 v 数组标记）；八个方向写进 dx[8]/dy[8] 一张表，循环一遍就完成全部扩展，比手写八个 if 干净。

**怎么用**——关键代码（`P1443.cpp`）：
```cpp
int dx[8]={2,2,-2,-2,1,1,-1,-1};
int dy[8]={1,-1,1,-1,2,-2,2,-2};
memset(ans,-1,sizeof ans);        // ①先全 -1
ans[x][y]=0; v[x][y]=1; q.push({x,y});
while(!q.empty())
{
    PII p=q.front(); q.pop();
    for(int i=0;i<8;i++)
    {
        nx=p.first+dx[i]; ny=p.second+dy[i];
        if(nx>=1&&nx<=n&&ny>=1&&ny<=m&&v[nx][ny]==0)
        {
            ans[nx][ny]=ans[p.first][p.second]+1;  // ②距离传递
            v[nx][ny]=1; q.push({nx,ny});           // ③入队即标记
        }
    }
}
```
跟算：3×3 棋盘，马从 (1,1) 出发，逐层队列表：

| 层 | 出队点 | 新入队（距离+1） |
|---|---|---|
| 0 | (1,1) | (3,2)、(2,3) |
| 1 | (3,2) | (1,3) |
| 1 | (2,3) | (3,1) |
| 2 | (1,3) | (2,1) |
| 2 | (3,1) | (1,2) |
| 3 | (2,1) | (3,3) |
| 3 | (1,2)、(3,3) | 无新点 |

最终棋盘（-1 的格子是马永远跳不到的）：
```
0 3 2
3 -1 1
2 1 4
```
中心 (2,2) 从任何日字位都跳不到，保持 -1 ✓。

> ⚠️ 注意事项：memset 要覆盖整个 ans 数组；输出按"行优先、空格分隔、行末换行"；起点 (1,1) 是棋盘坐标从 1 开始，越界判断写 `nx>=1&&nx<=n`。

> 🎯 规律：走不到要输出特定值的题（-1 等）→ 先整体初始化再搜索覆盖；方向一律写成 dx/dy 表循环。

> 💡 一句话总结：先填 -1，荡到哪算哪。

### 3. 状态升级：小明瘦身走迷宫（P8693）

**是什么**：白话——n×n 迷宫里小明从 (3,3) 走到 (n-2,n-2)，初始是 5×5 的"大块头"，每过 k 时间瘦一圈（5×5→3×3→1×1）；胖时过不去的窄道瘦身后能过，'*' 是障碍，求最少时间。课件指出相比普通 BFS 的关键点：(1) 小明可以**停在原地不动**，每次耗 1 个单位时间——这个等待有意义（耗时达到 k、2k 时会瘦身，瘦身后能走以前过不去的格子），因此**停留等待的状态也要入队**；但如果已经瘦到 1×1，再等待纯属无意义耗费时间。(2) 身体形态有三种，设变量 s 表示：初始 s=2（5×5），耗时达 k 时 s=1（3×3），达 2k 时 s=0（1×1）——这样设置在后面检测时带来统一的好处。

**为什么**：普通迷宫"能否走上 (x,y)"只看位置；本题能不能走取决于**当时的形态**，形态又由时间决定——所以队列元素必须是 (x,y,t)，s 由 t 推出。"等待"是时间前进、位置不变的合法转移，漏掉它就会得出"卡死在窄口前"的错误答案。

**怎么用**——关键代码（`P8693.cpp`）：
```cpp
struct node{ int x,y,t,s; };           // 位置+时间+形态(2/1/0)
bool check(int nx,int ny,int r)        // 以 (nx,ny) 为中心的整块检测
{
    if(v[nx][ny]==1) return 0;
    for(i=nx-r..nx+r) for(j=ny-r..ny+r)
        if(i<1||i>n||j<1||j>n||map[i][j]=='*') return 0;  // 越界或撞障碍
    return 1;
}
// 出队 now：
if(now.s!=0){                          // 没瘦到最瘦：原地等待也入队
    r = now.t+1<k ? 2 : (now.t+1<2*k ? 1 : 0);
    q.push({now.x,now.y,now.t+1,r});
}
for(4 方向){
    if(check(nex.x,nex.y,now.s))       // 用当前形态检查目标整块
    { v[nex.x][nex.y]=1; nex.t=now.t+1;
      nex.s = now.t+1<k ? 2 : (now.t+1<2*k ? 1 : 0);   // 形态由时间定
      q.push(nex); }
}
```
跟算：t 与形态对照表（设 k=3）：
```
t=0,1,2  → s=2，占 5×5，周围 2 格内不能有 '*'
t=3,4,5  → s=1，占 3×3
t≥6      → s=0，只查自己一格，窄道随便钻
比如卡在窄口前 t=2：原地等 1 秒 → 入队 (x,y,3,s=1)，t=5 再等就 3×3→1×1……
"等一等"就是图上的一条边，代价 1，与其他移动一视同仁。
```
出队时若 `now.x==n-2 && now.y==n-2`，输出 `now.t` 并 break——层序保证这就是最少时间。

> ⚠️ 注意事项：等待入队前判 `now.s!=0`；check 检查的是 (2r+1)² **整块**而不只是目标格；状态三元组缺一不可；终点判定放在出队处（首次到达即最短）。

> 🎯 规律：当"能力随时间/步数变化"时，把变化的量并进状态（位置+时间+形态），等待也是一条转移边——BFS 的框架原封不动。

> 💡 一句话总结：状态不够，时间来凑。

## 🔍 相似概念辨析

**组1：DFS vs BFS（及各自适用场景）**

| 对比维度 | DFS | BFS |
|---|---|---|
| 各自定义 | 每次尝试向更深的结点走（递归/栈） | 按圈层扩展（队列） |
| 核心区别 | 先纵向钻到底再回头 | 先横向铺满一层再下一层 |
| 各自特点 | 第一次到达≠最短；空间为递归深度 | 首次到达即最短；空间为整层宽度 |
| 使用场景 | 所有方案枚举、连通性、回溯类（P1706、LC200） | 最短距离/最少步数（P1443、P8693） |
| 典型示例 | 数岛屿、全排列 | 马的最短跳数、迷宫最短时间 |
| 记忆口诀 | 要方案用 DFS，要最短用 BFS |

**组2：入队时标记 vs 出队时标记**

| 对比维度 | 入队时标记（正确做法） | 出队时标记（错误做法） |
|---|---|---|
| 各自定义 | push 进队列的同时 v=1 | 弹出队头时才 v=1 |
| 核心区别 | 一个点在队列里至多一份 | 同一点被多个邻居重复入队 |
| 各自特点 | 队列长度 O(n+m) | 队列可能指数膨胀 TLE/MLE |
| 使用场景 | 一切 BFS（P1443、P8693 均如此） | 无——写出来就是错 |
| 典型示例 | v[nx][ny]=1; q.push(nx,ny); | q.push 完再在 while 开头判 |
| 记忆口诀 | 进门先登记，出门不补票 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**求最短距离（需求）→ 每步代价相同（前提）→ 队列层序扩展（机制）→ 第一次到达即定稿（性质）→ 模板五件套（实现：队列/方向/距离/标记/判合法）→ 状态不够就升级——(x,y) → (x,y,t,形态)，等待也是边（P8693）**。从 P1443 到 P8693，变的只是"状态里装了什么"，BFS 的骨架一字未改。

跨知识点共性：
1. **承接第十一章的队列**：BFS 是队列最经典的算法应用，front/pop/push 三件套与栈的 DFS（显式栈版）恰成镜像。
2. **与第十五章 DFS 对照**：同为状态空间枚举，DFS 用递归栈保序、BFS 用队列保层序；网格题两章共用 dx/dy、越界判断、标记三件套。
3. **向后铺垫**：边权不同后队列失效，引出最短路章节的 Dijkstra/SPFA（P8693 已埋下"状态=图结点"的建模思想）；"状态升级"还会在 DP 章节以"多维状态"的形式反复出现。

## 📋 速查表

| 要素 | 写法 |
|---|---|
| 队列 | `queue<PII> q;` / `queue<node> q;`（STL） |
| 方向 | `dx[]={…},dy[]={…}`：4 向平移 / 8 向（含马走日） |
| 初始化 | `memset(ans,-1,…)` → 起点距离 0 → 起点入队并标记 |
| 扩展 | 出队 → 枚举方向 → 越界/访问/障碍判掉 → dist+1 → 入队即标记 |
| P8693 | `node{x,y,t,s}`；形态 `t<k→2, t<2k→1, 否则 0`；`s!=0` 时原地等待入队；check 查整块 |

```cpp
// BFS 速记（默写级）
while(!q.empty()){
    p=q.front(); q.pop();
    for(i=0;i<方向数;i++){
        nx=…,ny=…;
        if(界内 && !v && 可走){ v=1; dist[n]=dist[p]+1; q.push(n); }
    }
}
```
