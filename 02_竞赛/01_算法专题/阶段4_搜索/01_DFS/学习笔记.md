## 🗺️ 本章地图

> **本章解决一个问题：数据范围小到暴力也行时，怎么把"所有可能"系统性地枚举一遍？**
> 路线是"一个思想 → 两种姿势"：先认识搜索——对状态空间枚举、构造一棵搜索树（状态树），以及 DFS"每次向更深处走"的定义（知识点 1）；排列型 DFS 学"第 x 个位置填什么"+ 回溯——P1706 全排列（知识点 2）；网格型 DFS 学"四方向扩展 + 标记防重"——LC 200 岛屿数量（知识点 3）。BFS 与剪枝优化分别在后面两章展开。
> 学完请自测三件事：回溯那句 flag[i]=0 为什么必须有、必须放哪？网格 DFS 进函数第一行为什么先改 '0'？排列型和网格型 DFS 的"状态"分别是什么？

## 📌 本章重点（3-5个）

⭐ **搜索 = 对状态空间枚举**：按题目要求构造所有可能答案，穷尽可能找最优解或统计合法解个数；常用搜索树（状态树）描述过程
⭐ **排列型 DFS 模板（P1706）**：dfs(x) 给第 x 个位置填数；ans 存解、flag 标记用过；x>n 输出；"填 → 标记 → 递归 → 撤销"四步
⭐ **回溯**：消除不同可能性对中间变量的影响——搜下一个答案前恢复现场（flag[i]=0 撤销本层做过的事）
⭐ **网格型 DFS（LC 200）**：外层扫描遇 '1' 计数，DFS 向上下左右扩展并**淹岛**（'1'→'0'）防重复统计；注意越界判断

## 🔥 本章难点（2-3个）

🔥 **搜索树的抽象**：看不见摸不着的"所有方案"要画成树——每个结点是一个中间状态，一条根到叶的路径是一个完整方案；初学时不会把"填第 x 个位置"对应到"树的第 x 层"
🔥 **回溯的必要性**：为什么递归回来必须恢复 flag？——不恢复，同一层的其他候选会被上一轮的标记"误伤"，整棵搜索树只剩第一条路；要能手动跟踪 P1706 N=3 的完整递归进出

## ⚠️ 本章易错点（3-5个）

⚠️ **漏写回溯 / 回溯位置错**：flag[i]=0 必须紧跟在 dfs(x+1) 之后、放在同一层 for 循环体内；漏掉后标记无法撤销，只有第一个解
⚠️ **网格 DFS 不先标记**：进 dfs 第一行就改 grid[i][j]='0'；否则相邻两块 '1' 互相调用（你走我、我走你）无限递归爆栈
⚠️ **越界判断顺序**：先判下标合法再取格子（`i-1>=0 && grid[i-1][j]=='1'`）——&& 的短路求值在救命，写反会数组越界
⚠️ **输出格式**：P1706 要求场宽 5（`printf("%5d",ans[i])`），格式不符全 WA；字符网格 LC200 里是 '1'/'0'，别与数字 1/0 混写

## 📖 知识点讲解

### 1. 搜索与 DFS：把所有可能画成一棵树

**是什么**：白话——数据范围小时，把题目要求的"每一种可能答案"都造出来试一遍。课件定义：搜索=按照题目要求构造可能的答案，对**所有可能的答案**进行枚举，通过穷尽所有的可能来找到最优解、或者统计合法解的个数（本质是暴力）；搜索分 DFS 和 BFS，还有很多优化方式（减小状态空间、更改搜索顺序、剪枝等，下一章展开）。DFS（图论）：深度优先搜索，每次都**尝试向更深的结点走**；在搜索算法中，DFS 常指**利用递归函数方便地实现暴力枚举**的算法，与图论中的 DFS 相似但不完全相同——通常是构造一棵**搜索树（状态树）**来进行搜索。

**为什么**：很多题（排列、选数、走格子）方案数是阶乘/指数级，没有贪心指标、没有递推式，唯一保正确的办法就是全枚举；而"递归函数 + 参数"天然就是树的一层，比手写多重循环灵活——循环层数固定，递归层数随输入。

**怎么用**——N=3 全排列的搜索树（每个结点="当前已填的前缀"，一条根到叶路径=一个完整解）：
```
                 （空）
        ┌──────────┼──────────┐
        1          2          3          ← 第 1 位
      ┌─┴─┐      ┌─┴─┐      ┌─┴─┐
      2   3      1   3      1   2       ← 第 2 位
      │   │      │   │      │   │
      3   2      3   1      2   1       ← 第 3 位（叶子=答案）
输出顺序：123 132 213 231 312 321（每层从小到大枚举 → 天然字典序）
```

> ⚠️ 注意事项：写搜索前先回答三问——状态是什么（参数）、分支是什么（for 什么）、出口是什么（什么时候算一个完整方案）。

> 🎯 规律：见"n 很小 + 要所有方案/方案数"→ 直接想搜索树；能画树就能写递归。

> 💡 一句话总结：方案画成树，递归走到黑。

### 2. 排列型 DFS 与回溯（P1706 全排列）

**是什么**：白话——把 1~n 排成一排，输出所有排列。课件分析：以 N=3 为例构造搜索树，用数组存放结果；两个数组——**ans 存合法解、flag 标记该数是否用过**；再写打印函数 print()，找到一个解就输出（注意输出格式——**5 个场宽**）。深搜函数：先判断格子是否填满，填满则 print；没填满就循环枚举候选数，没用过就填入并搜索下一格——**需要回溯**。课件定义回溯：**消除搜索过程中不同可能性之间对中间变量的影响**，即搜索下一个答案之前，保证上一个答案对下一个答案没影响，恢复到之前的状态。

**为什么**：进入下一层前打标记防止本条路径重复用数；但递归返回后如果不撤标记，"1 做过第 1 位"这个事实会污染"1 当第 2 位"的新分支——撤销是让兄弟分支从干净状态出发。

**怎么用**——模板（`P1706.cpp`）：
```cpp
void dfs(int x)                       // 给第 x 个位置填数
{
    if(x>n){ prin(); return; }        // 填满：输出一个解
    for(int i=1;i<=n;i++)             // 枚举所有可填的数
        if(flag[i]==0)                // i 没被用过
        {
            ans[x]=i;                 // 填
            flag[i]=1;                // 标记
            dfs(x+1);                 // 填下一位置
            flag[i]=0;                // 回溯：撤销本层影响
        }
}
```
跟算：N=3 前两个解的产生过程（关注 flag 的进出）：

| 步骤 | 动作 | ans | 已标记 |
|---|---|---|---|
| dfs(1) | i=1 可用：ans[1]=1，flag[1]=1，递归 | 1 _ _ | 1 |
| dfs(2) | i=1 跳过；i=2：ans[2]=2，flag[2]=1 | 1 2 _ | 1,2 |
| dfs(3) | i=3：ans[3]=3，flag[3]=1 | 1 2 3 | 1,2,3 |
| dfs(4) | x>n → 输出 **1 2 3**，返回 | | |
| 回溯 | flag[3]=0；dfs(3) 的 for 无更多候选返回；flag[2]=0 | | 1 |
| dfs(2) 接着枚举 | i=3：ans[2]=3 → dfs(3) 填 2 → 输出 **1 3 2** | 1 3 2 | 1,2,3 |

全部输出：123、132、213、231、312、321。

> ⚠️ 注意事项：`printf("%5d",ans[i])` 的场宽 5 是题目硬性要求；回溯语句只在"做了标记"的地方成对出现；出口判断放函数开头（先判满再枚举）。

> 🎯 规律："第 x 个位置放什么"万能四步：枚举候选 → 可用则填+标记 → 递归下一层 → 撤销标记；每层 for 保证字典序。

> 💡 一句话总结：选它、深入、忘掉它。

### 3. 网格型 DFS：岛屿数量（LC 200）

**是什么**：白话——'1' 是陆地、'0' 是水，上下左右相连的陆地算一个岛，数岛有几个。课件思路：主循环遍历整个矩阵，遇到 '1' 说明遇到一个岛屿，**岛屿数 +1**；但这只是岛的一部分，所以用 DFS 搜索整个岛屿，并把整岛改成 '0' 防止重复计算。DFS 部分：设目前在 (i,j)，向上下左右 (i±1,j)、(i,j±1) 四个方向搜索；若那个点为 '1' 且不越界，就走过去，**把走到的点改为 '0'**，再以它为基础继续搜索。课件提醒：网格中搜索考虑 4 或 8 个方向，注意不要越过边界。

**为什么**：每块陆地只应被计数一次——"淹岛"既是标记（防重复访问）又是计数（从源头消灭这个岛）；改原图省掉单独的 vis 数组，是网格搜索常用技巧。

**怎么用**——模板（`LC 200.cpp`）：
```cpp
void dfs(vector<vector<char> >& grid,int i,int j)
{
    grid[i][j]='0';                          // 第一行：走过就淹，防重复
    if(i-1>=0 && grid[i-1][j]=='1') dfs(grid,i-1,j);
    if(i+1<n  && grid[i+1][j]=='1') dfs(grid,i+1,j);
    if(j-1>=0 && grid[i][j-1]=='1') dfs(grid,i,j-1);
    if(j+1<m  && grid[i][j+1]=='1') dfs(grid,i,j+1);
}
int numIslands(...)
{
    for(i,j 扫全图)
        if(grid[i][j]=='1'){ ans++; dfs(grid,i,j); }   // 见 '1' 计数并淹没
}
```
跟算：4×4 网格（0 号下标）：
```
1 1 0 0        扫到 (0,0)：ans=1 → dfs 淹没 (0,0)(0,1)(1,0)(1,1)
1 1 0 0        继续扫：一路 '0' 直到 (2,2)
0 0 1 0        扫到 (2,2)：ans=2 → dfs 淹没单点
0 0 0 1        扫到 (3,3)：ans=3 → dfs 淹没单点
               输出 3 ✓
```

> ⚠️ 注意事项：dfs 第一行必须先置 '0' 再向四方向扩展（先扩展后标记会死循环）；越界条件写在取格子之前；这里不回溯——'0' 不改回 '1'，因为每个格子终身只属于一个岛。

> 🎯 规律：连通块计数 = 外层扫描 + 每个未访问的种子点触发一次"淹没式"DFS；8 连通只需把四方向数组扩成八个。

> 💡 一句话总结：见 '1' 就数，数完就淹。

## 🔍 相似概念辨析

**组1：搜索（DFS 暴力） vs 循环枚举**

| 对比维度 | 搜索 DFS | 循环枚举（第一章） |
|---|---|---|
| 各自定义 | 构造搜索树，递归地穷尽所有状态 | 用固定层数的循环把答案空间逐个试 |
| 核心区别 | 层数/分支随输入变化，靠递归+回溯切换状态 | 循环层数写死，状态靠下标组合表达 |
| 各自特点 | 天然支持"部分构造+合法性检查+剪枝" | 一板一眼，常需先算方案总数 |
| 使用场景 | 排列组合、迷宫、n 很小的构造题 | 方案能用几重下标直接表示（P1003 找地毯） |
| 典型示例 | P1706 全排列 | 二重循环枚举所有区间 |
| 记忆口诀 | 层数会变用递归，层数固定用循环 |

**组2：排列型 DFS（P1706） vs 网格型 DFS（LC200）**

| 对比维度 | 排列型 DFS | 网格型 DFS |
|---|---|---|
| 各自定义 | 给第 x 个位置选一个没用过的数 | 从 (i,j) 向四方向扩展连通块 |
| 核心区别 | 状态="位置 x + 已用集合 flag" | 状态="坐标 (i,j)" |
| 各自特点 | 需要**回溯**撤销标记，枚举所有方案 | 通常不回溯，走一次标记一次 |
| 使用场景 | 全排列、组合、选数方案 | 岛屿、迷宫可达性、连通块 |
| 典型示例 | flag[i]=0 恢复现场 | grid[i][j]='0' 淹岛 |
| 记忆口诀 | 排列要回头，网格一条道 |

**组3：回溯撤销 vs 破坏性标记**

| 对比维度 | 回溯撤销（P1706） | 破坏性标记（LC200） |
|---|---|---|
| 各自定义 | 递归返回后把本层改动恢复原状 | 访问过就永久改值，不再恢复 |
| 核心区别 | 同一元素要被不同方案重复使用 | 每个格子只属于一个连通块 |
| 各自特点 | 标记与撤销必须成对 | 一次改写终身有效 |
| 使用场景 | 枚举所有排列/组合 | 计数连通块、求可达性 |
| 典型示例 | flag[i]=0 | grid[i][j]='0' |
| 记忆口诀 | 复用就回溯，用完即弃就地淹 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**暴力枚举所有可能（思想）→ 搜索树把"可能"组织成结点与分支（模型）→ 递归函数的参数就是状态、递归深度就是层数（实现）→ 排列型：for+flag+回溯（P1706）/ 网格型：方向数组+标记（LC200）→ 状态太多搜不动？交给第十七章的剪枝与记忆化**。两道例题共同回答了三问：状态（位置/坐标）、分支（候选数/四方向）、出口（填满/四周无 '1'）。

跨知识点共性：
1. **承接第九章递归与分治**：DFS 就是"递归函数 + 全局痕迹数组"，第十三章二叉树递归的三要素（出口/当前层/子调用）在这里原样复用。
2. **与第十四章并查集互为替代**：数连通块既可淹岛 DFS（在线遍历），也可并查集（动态合并）——同一问题的两套工具。
3. **向后铺垫**：下一章 BFS 用队列换掉递归栈，换来的能力是"最短距离"；第十七章在本章模板上加剪枝与记忆化，进入动态规划的前夜。

## 📋 速查表

| 场景 | 模板骨架 | 关键细节 |
|---|---|---|
| 排列/组合 | dfs(位置)：出口 → for 候选 → 填+标记 → 递归 → 撤销 | 回溯与标记成对；输出场宽 |
| 网格连通块 | 外层扫描 → 见 '1' 计数 → dfs 淹岛 | 进函数第一行先改 '0' |
| 方向扩展 | dx={…},dy={…} 配 for(0..k) | 4 向 / 8 向（马走日 8 向） |

```cpp
// 排列型速记（默写级）
if(x>n){ print(); return; }
for(int i=1;i<=n;i++)
    if(!flag[i]){ ans[x]=i; flag[i]=1; dfs(x+1); flag[i]=0; }
// 网格型速记
dfs(i,j){ 标记(i,j); for(方向) if(合法且未访问) dfs(新坐标); }
```
