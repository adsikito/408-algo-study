## 本章地图

本章解决一个问题：**「最少几步到达？」**

```text
「最少步数」问题
   ↓
BFS 逐层扩展：先 1 步的所有状态，再 2 步……
   ↓
第一次到达某状态时的步数 = 最少步数（边权全 1 时）
   ↓
三种形态：
   ├─ 单源网格 BFS    → 迷宫最短路（P1443 / P1135）
   ├─ 多源 BFS        → 所有 0 同时入队，一次扩散（01 矩阵型）
   └─ 布局状态 BFS    → 状态编码 + 判重（八数码）
   ↓
升级：带权 → Dijkstra（阶段 5）· 0-1 边权 → 双端队列 BFS（延伸）
```

**为什么这条路径是这样**：BFS 的正确性来自**「队列的单调性」**——
队列中的 dist 值永远非降，所以第一个到达就是最优到达。
**理解这一点，「入队即标」就不再是死记的细节，而是推论。**

## 题型识别信号

| 题目特征 | 应想到的算法 | 优先级 |
|---------|------------|--------|
| 「最少几步」「最短时间」到达（边权全 1） | BFS | `P0` |
| 马的走法 / 电梯按键 / 转盘锁等状态转移 | 状态图 BFS（转移即边） | `P0` |
| 对每个格子求「到最近某类格子的距离」 | **多源 BFS**（全部源点一起入队） | `P0` |
| 棋盘布局变换求最少操作（八数码） | 布局 BFS + 状态编码判重 | `P1` |
| 要输出具体路径 | BFS + 前驱数组回溯 | `P1` |

> **【规律】** **「最少」+「每步代价相同」= BFS；代价不同 = Dijkstra。**
> 这个判据在阶段 5 依然成立——BFS 是 Dijkstra 在「边权全 1」上的特例。

## 核心概念与模板

**是什么**：BFS 逐层扩展：先访问距起点 1 步的所有状态，再 2 步……
因此**第一次到达某状态时的步数即最少步数**（边权全 1 时）。

**为什么**：这是 BFS 的全部价值：无权图最短路。
带权时升级为 Dijkstra（阶段 5）；「0-1 边权」时升级为双端队列 BFS（延伸）。

> **【规律】** **入队即标 dist（DFS 是进入即标 vis）**——
> 出队才标会让同一状态重复入队，队列按指数膨胀。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
const int N = 1005;
int n, m, dist[N][N];
char grid[N][N];

const int dx[4] = {1, -1, 0, 0}, dy[4] = {0, 0, 1, -1};

int px[1000005], py[1000005];            /* 手写队列（存坐标） */

void bfs(int sx, int sy) {
    memset(dist, -1, sizeof(dist));
    int head = 0, tail = 0;
    px[tail] = sx; py[tail] = sy; tail++;
    dist[sx][sy] = 0;                    /* 入队即标距离 */
    while (head < tail) {
        int x = px[head], y = py[head]; head++;
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (dist[nx][ny] != -1) continue;          /* 已访问 */
            if (grid[nx][ny] == '#') continue;         /* 障碍按题意 */
            dist[nx][ny] = dist[x][y] + 1;
            px[tail] = nx; py[tail] = ny; tail++;
        }
    }
}
```

**多源 BFS**：把所有源点**一起**入队（初始 dist = 0），一次扩散即得各点到最近源点的距离——
「01 矩阵最近 0」类题的标答。

> **【类比】** BFS 像**往水里扔石头的波纹**：第一圈是所有距离 1 的格子，
> 第二圈是距离 2……**波纹到达某格的第一时间，就是最短距离**——
> 水不会跳过近处先淹远处，这就是队列单调性的物理图像。

## 本章难点

> **【难点】** **布局型 BFS 的状态编码**。
> 八数码的「状态」是整个 3×3 布局——必须把它编码成一个可判重的键
> （九位数字串 / 康托展开排名），配 `map` 或 `bool[362880]`。
> **状态数上界先行估算**：9! = 362880，因此判重数组可开——
> 这一步想清楚，转移（交换 0 与邻位）只是工程活。

> **【难点】** **多源 BFS 的「反向思维」。**
> 「每个 1 到最近 0 的距离」——对每个 1 跑一次 BFS 是 O((nm)²) 必炸；
> **把所有 0 当源点一次入队**，波纹扩散一次即得全部答案。
> 悟透这一步，「到最近 XX 的距离」类题就有了统一范式。

---

## 本章易错点

> **【头号易错】** **标记时机**：BFS 在**入队时**标 dist（DFS 在进入时标 vis）——
> 出队才标会导致同一状态重复入队、队列爆炸。

> **【易错】** **dist 忘初始化为 −1**：0 会与「真距离 0」（源点本身）混淆。

> **【易错】** **队列容量不够**：状态数按格数 / 状态上界开（八数码 9! + 余量）。

> **【易错】** **「最少步数」题误用 DFS**：DFS 第一次到达不一定是最短到达。

> **【易错】** **布局题状态编码碰撞 / 漏判**：编码键必须一一对应布局；
> 用 map 判重要先估算状态数上界。

### 例 2　八数码难题（布局 BFS）　难度：进阶题

**题干摘要**：3×3 棋盘 8 子 + 空格（0），求从初始布局到目标布局 123804765 的最少移动步数。
**题源**：同类真源见配套练习 T3（P1379 八数码难题）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「布局变换 + 最少步数」→ 布局 BFS。
2. **状态编码**：九位数字串（如 `map<string,int>` 或展开成 int 判重）。
3. **转移**：找到 0 的位置，与上下左右交换（≤ 4 个后继）。

```cpp
// g++ -std=c++17 -O2
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s, t = "123804765";
    cin >> s;
    if (s == t) { cout << 0; return 0; }
    map<string, int> dist;
    queue<string> q;
    dist[s] = 0;
    q.push(s);
    while (!q.empty()) {
        string u = q.front(); q.pop();
        int p = u.find('0');                     /* 空格位置（0..8） */
        int r = p / 3, c = p % 3;
        static const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
        for (int d = 0; d < 4; d++) {
            int nr = r + dr[d], nc = c + dc[d];
            if (nr < 0 || nr > 2 || nc < 0 || nc > 2) continue;
            string v = u;
            swap(v[p], v[nr * 3 + nc]);          /* 与邻位交换 = 一步 */
            if (dist.count(v)) continue;         /* 判重：编码即键 */
            dist[v] = dist[u] + 1;
            if (v == t) { cout << dist[v]; return 0; }
            q.push(v);
        }
    }
    return 0;
}
```

**复杂度**：状态数 ≤ 9! = 362880，每状态 ≤ 4 转移，总体线性于状态数。

> **【易错】** 三处：目标判重可在**入队时**提前返回（不影响最优性）；
> 编码必须与布局一一对应（用 string 最稳，int 拼接注意前导 0 丢失）；
> 初始即目标要先判。

## 本章总结

### 核心内容（一页纸）

1. **BFS 的全部价值**：边权全 1 时，第一次到达 = 最少步数。
2. **入队即标 dist**（DFS 进入即标 vis）——出队才标则队列爆炸。
3. **dist 初值必须 −1**：0 与源点真距离冲突。
4. **多源 BFS**：所有源点一起入队，一次扩散——「到最近 XX」类题的统一范式。
5. **状态三层次**：坐标 → 一维编号 → 布局编码；状态数上界先行估算。
6. **布局 BFS**：编码即判重键（string 最稳），转移即邻位交换。
7. **前驱数组**记录路径，从终点回溯输出。
8. **选型判据**：「最少」+「代价相同」= BFS；代价不同 = Dijkstra（阶段 5）。
9. **队列容量按状态上界开**（网格 nm、八数码 9!）。
10. **BFS 考的是状态建模，不是队列**——载体在阶段 3，建模在本篇。
