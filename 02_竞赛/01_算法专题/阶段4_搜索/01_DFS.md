## 本章地图

本章解决一个问题：**「所有可达状态 / 所有方案，怎么一个不漏地枚举？」**

```text
需要「有没有」「多少种」「全部方案」
   ↓
DFS：沿一条路走到底 → 失败回溯换路
   ├─ 网格 / 图上    → Flood Fill（连通块、覆盖）   （知识点 1）
   ├─ 方案构造       → 回溯（选择 + 递归 + 撤销）    （知识点 2）
   │     └─ 多重约束 → 标记数组升维（八皇后）        （知识点 3）
   └─ 网格定长匹配   → 方向向量 + 逐位比对           （知识点 4）
   ↓
对照：求「最少步数」→ 换 BFS（知识点 5，02 篇）
```

**为什么这条路径是这样**：DFS 的本质是**「系统化的枚举」**——
它不比枚举聪明，只是把枚举的顺序安排成「一条路走到黑」，
从而天然支持**构造**（沿途回溯出方案）与**空间复用**（一条路径的数据结构）。

## 核心概念与模板

**是什么**：DFS 沿一条路走到底、失败回溯换路：本质是**递归枚举所有状态** + visited 防环。

**为什么**：两个用途：**存在性 / 计数类**（遍历所有可达状态）与**构造类**
（回溯出全部方案）。与 BFS 的选择：求「有没有 / 全部方案 / 树上信息」用 DFS；
求「最少步数」用 BFS（下一专题）。

> **【规律】** **回溯的黄金三行**：做选择 → 递归 → 撤销选择。
> 设置与撤销必须**完全对称**——少撤销则方案漏、多撤销则重复。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 1005;
int n, m;
char grid[N][N];
bool vis[N][N];

/* 1. 网格连通块计数（ Flood Fill ） */
const int dx[4] = {1, -1, 0, 0}, dy[4] = {0, 0, 1, -1};

void dfs(int x, int y) {
    vis[x][y] = true;                    /* 进入即标记 */
    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
        if (!vis[nx][ny] && grid[nx][ny] == 'W')   /* 按题意筛 */
            dfs(nx, ny);
    }
}

/* 2. 回溯枚举（全排列型） */
int path[10];
bool used[10];

void perm(int depth, int n) {
    if (depth == n) {                    /* 收集一个方案 */
        for (int i = 0; i < n; i++) printf("%d ", path[i]);
        printf("\n");
        return;
    }
    for (int v = 1; v <= n; v++)
        if (!used[v]) {
            used[v] = true;              /* 做选择 */
            path[depth] = v;
            perm(depth + 1, n);
            used[v] = false;             /* 撤销选择（回溯） */
        }
}
```

> **【类比】** DFS 像**走迷宫时左手扶墙**：沿一条通道走到头，死路就原路退回最近岔口换一条——
> **「原路退回」就是撤销选择**：退回来时把脚印（标记）擦干净，
> 下一条路才不会误以为这里走过。

## 本章难点

> **【难点】** **标记数组的「维度 = 约束数」。**
> 全排列只需一个 used[]（一个约束：值不重复）；八皇后需要三个
> （列、主对角线 r−c、副对角线 r+c）——**每多一个互斥约束，标记数组加一维**。
> 对角线坐标的两个技巧：r−c 可为负 → 统一 +n 偏移；r+c 天然非负。

> **【难点】** **Flood Fill 的递归深度 = 连通块大小**。
> 10⁶ 格的整图水块会让递归栈爆炸——**规避两解**：
> 编译加大栈（`-Wl,--stack=`）或改 BFS / 显式栈（02 篇）。
> 这是「算法对、工程死」的典型场景，赛场必须形成条件反射。

---

## 本章易错点

> **【头号易错】** **标记时机错**：进入时必标（vis[x][y] = true 在递归前），
> 回溯枚举里「选择与撤销必须配对」——少撤销则方案漏、多撤销则重复。

> **【易错】** **网格四方向数组 dx/dy 写重或漏**（8 连通时 8 项按顺时针写全）。

> **【易错】** **对角线偏移忘 +n**：r−c 为负下标直接 RE。

> **【易错】** **状态去重遗漏**：同一状态多种到达路径时需额外判重（八数码的教训，见 02 篇）。

> **【易错】** **递归深度 = 路径长度**：大迷宫 / 单斜树爆栈，改显式栈或 BFS。

## 典型例题

### 例 1　连通块计数（Flood Fill）　难度：模板题

**题干摘要**：n × m 网格，'W' 为水，统计连通水块数（八连通或四连通按题面）。
**题源**：同类真源见配套练习 T2（P1596 Lake Counting）
**涉及知识点**：知识点 1

**解题思路**：

1. **信号**：「连通块」→ Flood Fill。
2. **方法**：扫每个未访问的 'W' 计数 +1，从它出发 dfs 标记整块。

**复杂度**：O(n × m)——每格至多入递归一次。

> **【易错】** 八连通时方向数组 8 项；n×m 大时递归深可达格数，加大栈或改 BFS。

---

### 例 2　N 皇后（回溯 + 对角线判重）　难度：变式题

**题干摘要**：n ≤ 13 皇后，输出方案数。
**题源**：同类真源见配套练习 T3（P1219 八皇后，需按字典序输出前 3 解）
**涉及知识点**：知识点 2、3

**解题思路**：

1. **信号**：「互斥约束的放置」→ 回溯 + 多维标记。
2. **方法**：按行放 → 只需判列、主对角线（r−c）、副对角线（r+c）三个标记数组。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
int n;
bool col[14], dg[27], udg[27];
long long ways = 0;

void queen(int r) {
    if (r == n) { ways++; return; }
    for (int c = 0; c < n; c++) {
        if (col[c] || dg[r - c + n] || udg[r + c]) continue;
        col[c] = dg[r - c + n] = udg[r + c] = true;
        queen(r + 1);
        col[c] = dg[r - c + n] = udg[r + c] = false;   /* 撤销 */
    }
}
```

**复杂度**：远小于 nⁿ（剪枝后）；n = 13 约 10⁷ 级。

> **【易错】** r−c 可为负，统一 +n 偏移；三数组撤销必须与设置完全对称。

## 本章总结

### 核心内容（一页纸）

1. **DFS = 递归枚举 + visited 防环**；两个用途：存在性 / 计数、构造全部方案。
2. **Flood Fill**：进入即标记，每格至多入递归一次，O(n × m)。
3. **回溯黄金三行**：做选择 → 递归 → 撤销；设置与撤销完全对称。
4. **标记维度 = 约束数**：八皇后三标记（列 / r−c / r+c），r−c 统一 +n。
5. **定长匹配**：dx/dy 8 方向按顺时针写全。
6. **递归深度 = 路径长度**：大迷宫爆栈，加大栈或改 BFS。
7. **选型**：最少步数 → BFS；状态爆炸 → 剪枝（03 篇）。
8. **字典序解**：按序枚举候选即天然字典序，输出前 k 解不冲突。
9. **骗分价值**：正确剪枝的爆搜是小数据点的满分解。
10. **树上递归无重叠子问题**——树 DFS 与网格 DFS 的差异只在「防环」。
