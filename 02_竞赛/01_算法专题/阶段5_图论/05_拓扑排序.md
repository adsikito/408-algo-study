## 本章地图

本章解决一个问题：**「依赖关系（先后次序）怎么排出合法顺序、并在其上做计算？」**

```text
DAG：任务 / 课程 / 编译依赖
   ↓
Kahn：反复摘入度 0 的点（当前「无前置任务」的全部）
   ↓
order[] 即拓扑序；输出个数 < n ⇔ 有环（知识点 2）
   ↓
按拓扑序做 DP（知识点 3）：
   ├─ 正推：u 的答案 → 推给后继（起点型）
   └─ 逆推（逆序遍历 order）：后继的答案 → 汇给 u（汇点型）
   ↓
变体：字典序最小（队列换堆，知识点 4）· 反向图拓扑（知识点 5）
```

**为什么这条路径是这样**：拓扑序的本质是**「一种合法的执行计划」**——
它保证 DP 转移时**「用到的值一定已经算好」**。
理解这一点，「为什么要拓扑序」与「转移方向怎么选」就都是推论。

## 核心概念与模板

**是什么**：DAG 上把顶点排成一列使每条边「从前指向后」：反复摘入度 0 的点。

**为什么**：考研第 5 章已会手算与判环；竞赛侧的真正用途是 **DAG 上做 DP**——
按拓扑序转移保证「算 u 时所有前驱已算完」，是阶段 7 DAG DP（最短路计数、背包 DAG）的执行框架。
判环：输出个数 < n ⇔ 有环。

> **【规律】** **入度数组与建图同步**：`addEdge` 里顺手 `indeg[v]++`——
> 分开写必漏边。**「入度为 0」= 当前无前置任务的点**，也是队列的初始成员。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
const int N = 100005;
int n, m;
int head[N], nxt[2 * N], to[2 * N], tot;
int indeg[N], order[N], cnt = 0;
long long dp[N];                          /* DAG DP 表 */

void addEdge(int u, int v) {
    to[tot] = v; nxt[tot] = head[u]; head[u] = tot++;
    indeg[v]++;
}

bool toposort() {
    int q[N], headq = 0, tailq = 0;
    for (int i = 1; i <= n; i++)
        if (indeg[i] == 0) q[tailq++] = i;
    while (headq < tailq) {
        int u = q[headq++];
        order[cnt++] = u;                 /* order 即拓扑序 */
        for (int e = head[u]; e != -1; e = nxt[e])
            if (--indeg[to[e]] == 0) q[tailq++] = to[e];
    }
    return cnt == n;                      /* 全输出：无环 */
}

/* 按拓扑序跑 DAG DP（示例：最长路） */
void dagLongest() {
    for (int i = 0; i < cnt; i++) {
        int u = order[i];
        for (int e = head[u]; e != -1; e = nxt[e])
            if (dp[u] + 1 > dp[to[e]])
                dp[to[e]] = dp[u] + 1;
    }
}
```

> **【类比】** 拓扑排序像**毕业审核**：每门课有先修要求（入度），
> 审核员每轮把「先修全满足」的课程盖章出列（order），
> 出列一门就给它的后续课程减一条先修（--indeg）。
> **如果最后有课永远盖不了章（cnt < n），课表里必有循环先修——有环。**

## 本章难点

> **【难点】** **正推与逆推的选择。**
> 答案定义在「起点侧」→ 正推（dp[to] 由 dp[u] 更新）；
> 答案定义在「汇点侧」→ 逆推（逆序遍历 order，dp[u] 由 dp[to] 更新）。
> **判断法：写出状态转移方程，看方程引用的是「前驱」还是「后继」**——
> 引用谁，谁就必须先算。

> **【难点】** **「字典序最小」与「最优构造」都要换堆。**
> 队列版拓扑输出的是「任意合法序」；把队列换成小根堆（每次取编号最小的入度 0 点）
> 即得字典序最小；P3243 型「把大的尽量放后」则是**反向图 + 大根堆**——
> **两个变体一个套路：换容器、换方向。**

---

## 本章易错点

> **【头号易错】** **DAG DP 的转移方向写反**：拓扑序正推（u → 后继）还是逆推
> （前驱 → u）要与前驱后继语义一致；反向拓扑序（逆序遍历 order）用于「汇点型 DP」。

> **【易错】** **入度数组随加边同步统计**（漏一条就少一个起点）。

> **【易错】** **有环时 dp 值不可信**（必须先判拓扑成功）。

> **【易错】** **字典序最小拓扑序要用手写小根堆**（`priority_queue`）替代队列——
> 队列版只保证合法不保证字典序。

> **【易错】** **路径计数巨大必须取模**，且加法每步都模（阶段 1 模数意识复用）。

## 典型例题

### 例 1　DAG 最长路（拓扑 + DP 骨架）　难度：模板题

**题干摘要**：DAG n ≤ 10⁵，求最长路径边数。
**题源**：拓扑 DP 模板（同类真源见配套 T1 模板题）
**涉及知识点**：知识点 1、2、3

**解题思路**：

1. **信号**：「DAG + 最值」→ 拓扑 + DP 正推。
2. **方法**：核心模板 toposort + dagLongest，答案 = max(dp)。

**复杂度**：O(n + m)。

> **【易错】** 先 toposort 判环再 DP；dp 初值 0（最长路至少 0 条边，单点合法）。

---

### 例 2　路径计数（DAG 上取模 DP）　难度：变式题

**题干摘要**：DAG 求点 1 到 n 的路径条数 mod 10⁹+7。
**题源**：DAG 计数经典（与 `04_最短路选题.md` 的 P1144 计数思想同源）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「DAG + 条数」→ 按拓扑序累加。
2. **方法**：dp[u] = 到 u 的路径数；按拓扑序 `dp[to] += dp[u]`；dp[1] = 1。

**复杂度**：O(n + m)。

> **【易错】** 加法取模每步都做；起点若可能有入边，dp[1] 的赋值要在转移前
> （或按入边语义加）；「路径数」巨大必须取模——阶段 1 快速幂的模数意识在此复用。

## 本章总结

### 核心内容（一页纸）

1. **Kahn 模板 10 行**：入度 0 入队 → 出队进 order → 后继减入度。
2. **入度与建图同步统计**（addEdge 里 `indeg[v]++`）。
3. **判环免费**：cnt < n ⇔ 有环——DAG DP 前必做。
4. **拓扑序 = 合法执行计划**：保证「用到的值已算好」。
5. **正推 / 逆推**：方程引用前驱 → 正推；引用后继 → 逆推（逆序 order）。
6. **字典序最小**：队列换小根堆；「大的放后」→ 反图 + 大根堆（T2）。
7. **计数 DP 每步取模**；dp 起点赋值在转移前。
8. **dp 初值**：最长路 0（单点合法）；可达计数 dp[1] = 1。
9. **有环输出部分序 / 无解**按题面，不能静默给出错误 DP。
10. **本篇 order[] 是阶段 7 的执行框架**——写法固定直接复用。
