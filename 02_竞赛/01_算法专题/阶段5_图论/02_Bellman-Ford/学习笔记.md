## 第十九章：最短路之Bellman-Ford算法

> 课件来源：`19.最短路之Bellman-Ford算法.pptx`
>
> 例题代码：`例题代码/Ford算法.cpp`（n-1 轮松弛 + flag 提前退出）、`例题代码/Ford算法判断负环.cpp`（第 n 轮仍能松弛 → 有负环）

## 🗺️ 本章地图

本章解决一个问题：图里有**负边权**，Dijkstra 的贪心锁定会翻车，怎么求单源最短路？路线是"复习 → 提炼 → 暴力 → 判环"：先复习 Floyd（O(n³) 多源）与 Dijkstra（O(n²) 单源），提炼出一切最短路算法的公共内核——**松弛** dis[v]=min(dis[v],dis[u]+w)；Bellman-Ford 就是对全图每条边**无脑暴力松弛**，最多 n-1 轮、每轮 O(m)，总复杂度 O(nm)，某轮无更新可提前结束；第 n 轮还能松弛就说明起点可达**负权回路**。本章的边集数组存图与松弛思想，直接喂给第 20 章的 SPFA。

## 📌 本章重点

⭐ **松弛操作**：dis[v]=min(dis[v], dis[u]+w)——Floyd、Dijkstra、Bellman-Ford 共用的内核
⭐ **Bellman-Ford 主流程**：每轮枚举全部 m 条边做松弛，最多 n-1 轮，总复杂度 O(nm)
⭐ **flag 提前退出**：某一轮没有任何松弛成功 → 再轮也不会有 → break
⭐ **负环判定**：第 n 轮仍存在能松弛的边 → 从起点可达负环，最短路不存在
⭐ **边集数组存图**：struct Edge{start,end,w}——Ford 天然按"边的列表"逐条处理，不需要 head/next

## 🔥 本章难点

🔥 **为什么最多 n-1 轮**：一次成功的松弛使最短路的边数至少 +1，而最短路最多只有 n-1 条边——轮数与"路径边数上限"绑定，不是拍脑袋定的循环次数
🔥 **为什么第 n 轮还能松弛就是负环**：n-1 轮后所有正常最短路都已收敛，仍能松弛说明存在"每绕一圈就再降一点"的回路（边权和为负的回路），dis 可以无穷小

## ⚠️ 本章易错点

⚠️ **轮数写错**：求最短路是 `i=1..n-1`；判负环要跑到 `i=n`——多跑的那一轮就是"负环探测器"，两份课件代码只差循环上界
⚠️ **flag 忘每轮清零**：`flag=0` 必须写在第 i 轮循环体开头，否则第一轮置 1 后"提前退出"判断永远失效
⚠️ **inf 要"耐加"且防溢出**：课件取 inf=1001（n≤100、|w|<1000 保证 inf+w 不爆 int）；且 dis[u]=inf 的边也会参与判断，严谨写法应加 `dis[u]!=inf` 限制，防"不可达点"被负边伪松弛
⚠️ **边集数组下标从 1 开始**：课件读入存 e[1..m]、松弛循环 `for j=1..m`，写成从 0 会漏边或错位
⚠️ **负边权 ≠ 负权回路**：有负边权照样能求最短路；只有"边权之和为负的回路"才让最短路变成无穷小

## 📖 知识点讲解

### 1. 复习与提炼：松弛操作是公共内核

**是什么**：白话——"我经过中转点 i 再去 j，会不会比现在记录的到 j 的距离更近？"严格说：设 dis[i] 为源点 s 到 i 的当前最短距离估计，w[i][j] 为边权，**松弛（relax）**即 `dis[j] = min(dis[j], dis[i] + w[i][j])`。Floyd 写作 dis[s][j]=min(dis[s][j],dis[s][i]+w[i][j])，Dijkstra 同理——差别只在"按什么顺序、信任谁的中转结果"。

**为什么**：Floyd O(n³) 多源、能扛负边权但点多了跑不动；Dijkstra O(n²) 单源快，但**不能处理负边权**——它每轮贪心锁定 dis 最小的点认为"定型"，负边会让"绕远路再折返"的路径事后更短，贪心前提被破坏。要扛负边权，就得放弃贪心、改为对边的**暴力松弛**——这就是 Bellman-Ford。

**怎么用**（五种最短路总览表，课件原表）：

| 算法 | 复杂度 | 单源/多源 | 负边权 | 负权回路 |
|---|---|---|---|---|
| Floyd | O(n³) | 多源 | 可以 | 不可以 |
| Dijkstra | O(n²) | 单源 | 不可以 | 不可以 |
| Bellman-Ford | O(nm) | 单源 | 可以 | 可判定 |

> ⚠️ 注意事项：Dijkstra 怕负边权的根源是"锁定即定型"；凡是靠贪心定型的算法，都要先确认贪心前提（这里=边权非负）。

> 🎯 规律：见到 `dis[j]=min(dis[j],dis[i]+w)` 就是松弛；所有最短路算法都绕着它转，差别只在松弛的顺序与轮数。

> 💡 一句话总结：最短路千般变，内核只有松弛。

### 2. Bellman-Ford：暴力松弛全流程

**是什么**：白话——每轮把图上**每一条边**都拿去试一遍松弛，直到某轮啥也更新不动为止。严格说：Bellman-Ford（简称 Ford/福特）做至多 n-1 轮，每轮 O(m) 枚举所有边做松弛，一轮无成功松弛即提前终止，总复杂度 O(nm)。

**为什么**：一次成功的松弛使最短路的**边数至少 +1**：第 1 轮结束后"一条边能到"的点全部正确，第 2 轮结束后"两条边以内能到"的点全部正确……而最短路最多 n-1 条边，所以 n-1 轮必定收敛——这就是"最多循环 n-1 次"的完整论证。

**怎么用**——模板（忠实课件 `Ford算法.cpp`，边集数组存图）：
```cpp
struct Edge{ int start, end, w; } e[10005];
int dis[105];
void Ford()
{
  int u,v,flag;
  for(int i=1;i<n;i++)          // 最多 n-1 轮
  {
    flag=0;
    for(int j=1;j<=m;j++)       // 每轮枚举全部 m 条边
    {
      u=e[j].start;  v=e[j].end;
      if(dis[u]+e[j].w<dis[v])  // 能松弛
      {
        dis[v]=dis[u]+e[j].w;
        flag=1;
      }
    }
    if(flag==0) break;          // 本轮无更新，提前结束
  }
}
// main：dis 全 inf，dis[s]=0，Ford() 后输出
```

**跟着算**（课件样例）：5 个点 5 条有向边，s=1，初始 dis=[0,∞,∞,∞,∞]（inf=1001）。边序：①2→3(w2) ②1→2(w-3) ③1→5(w5) ④4→5(w2) ⑤3→4(w3)：

| 轮 | 边① | 边② | 边③ | 边④ | 边⑤ | 轮末 dis[2..5] | flag |
|---|---|---|---|---|---|---|---|
| 1 | ✗ | dis₂=-3 | dis₅=5 | ✗ | ✗ | -3, ∞, ∞, 5 | 1 |
| 2 | dis₃=-1 | ✗ | ✗ | ✗ | dis₄=2 | -3, -1, 2, 5 | 1 |
| 3 | ✗ | ✗ | ✗ | dis₅=4 | ✗ | -3, -1, 2, 4 | 1 |
| 4 | ✗ | ✗ | ✗ | ✗ | ✗ | 不变 | 0 → break |

输出 `0 -3 -1 2 4` ✓。两个细节：第 1 轮里 dis[2] 还是 ∞，边① 2→3 试图松弛 ∞+2<∞ 不成立（这就是 inf 要足够大的意义）；第 4 轮零更新，flag=0 提前终止——第 4 轮恰好 = n-1=4 轮上限内完成收敛。

> ⚠️ 注意事项：同一轮内的更新会"链式"传给本轮后面的边（第 2 轮 dis₃ 先更新、dis₄ 接着用新值更新），所以轮数只保证"n-1 轮内收敛"。

> 🎯 规律：第 k 轮结束后，"最多 k 条边"的最短路一定已正确——轮数 = 路径边数上限。

> 💡 一句话总结：n-1 轮全边松，无更即停。

### 3. 负权回路与负环判定

**是什么**：白话——绕一圈代价反而变小的回路（边权之和为负）。负权回路会让"最短路"变成无穷小：每绕一圈 dis 就减去该回路的负权和，可以无限绕。所以存在负权回路的图**无法求出最短路径**，但 Bellman-Ford 可以**检测**它。

**为什么**：课件例：②-④-⑤-③-② 回路边权和 -3，问 1 到 6 的最短路？答案是无穷小——绕圈每圈减 3。而对最短路存在的图，前面已论证松弛最多执行 n-1 轮；如果**第 n 轮循环仍存在能松弛的边**，说明从起点 S 出发能够抵达一个负环——判定完成。

**怎么用**——判定模板（忠实课件 `Ford算法判断负环.cpp`）：
```cpp
bool Ford()
{
  int u,v,f=0;
  for(int i=1;i<=n;i++)         // 注意：跑到第 n 轮！
  {
    for(int j=1;j<=m;j++)
    {
      u=e[j].start;  v=e[j].end;
      if(dis[u]+e[j].w<dis[v])
      {
        dis[v]=dis[u]+e[j].w;
        if(i==n) f=1;           // 第 n 轮还在松弛 → 负环
      }
    }
  }
  return f;
}
// main：if(Ford()) 输出"有负环"，否则输出 dis
```

**跟着算**（负环小图）：3 个点 3 条边：1→2(w1)、2→3(w-1)、3→2(w0)。回路 2→3→2 权和 = -1 < 0：

| 轮 | dis[1] | dis[2] | dis[3] | 说明 |
|---|---|---|---|---|
| 1 | 0 | 1 | 0 | 1→2、2→3 各松弛一次 |
| 2 | 0 | 0 | -1 | 3→2 用 dis₃=0 松弛：0+0<1 |
| 3 | 0 | -1 | -2 | **第 n=3 轮仍在更新 → f=1，有负环** |

dis[2]、dis[3] 每轮都在下降——永远收敛不了，被第 n 轮的更新抓个正着。

> ⚠️ 注意事项：判出的条件是"**起点可达**的负环"；起点到不了的负环不引起松弛、判不出来（需要判全图时建超级源点连向所有点）。

> 🎯 规律：正常图 n-1 轮必收敛；"第 n 轮还能松" = 收敛被打破 = 负环。

> 💡 一句话总结：多跑一轮探负环，还能松就是环。

### 4. 例题代码拆解：Ford 求最短路 + 判负环

**是什么**：课件两份代码共用一套骨架：边集数组读入 → dis 全 inf、dis[s]=0 → Ford 主过程 → 按用途输出。差别只有循环上界（n-1 vs n）与返回值。

**为什么**：边集数组（start/end/w 三个字段）最贴合"逐边松弛"的访问模式——不需要知道每个点有哪些出边，只要把 m 条边从头到尾扫一遍；这也解释了本章为什么不用第 18 章的链式前向星。

**怎么用**——做题四步：①边集数组存图（有向一条、无向正反两条且开 2m）；②dis 初始化 inf、dis[s]=0；③套主循环（想清楚轮数）；④按题意输出 dis 或判负环。课件两份代码样例输入相同（5 点 5 边），输出均为 `0 -3 -1 2 4`；判负环版对无负环图同样输出该结果，对含负环图输出"有负环"。

> ⚠️ 注意事项：`#define inf 1001` 是按 n≤100、-1000<边权<1000 量级定的"够用 inf"；换题必须重估——inf 要满足 inf+w 仍明显大于任何真实 dis，且 inf+w 不溢出。

> 🎯 规律：Ford 的灵魂三问——轮数（n-1 还是 n）？每轮扫谁（全部 m 条边）？何时停（无更新 / 第 n 轮更新）？

> 💡 一句话总结：边集数组配 Ford，改个上界判负环。

## 🔍 相似概念辨析

**组1：Bellman-Ford vs Dijkstra**

| 对比维度 | Bellman-Ford | Dijkstra |
|---|---|---|
| 各自定义 | 每轮对全部边松弛，共 n-1 轮 | 每次锁定 dis 最小的未定点，松弛其出边 |
| 核心区别 | 不依赖贪心，负边权安全 | 贪心锁定，负边权会错 |
| 各自特点 | O(nm) 较慢，副产品能判负环 | O(n²)（可堆优化到第 20 章），快但怕负边 |
| 使用场景 | 有负边权 / 判负环 | 边权全非负的常规最短路 |
| 典型示例 | 边权 -3 的图照算不误 | 同图锁定顺序出错 |
| 记忆口诀 | 负边找 Ford，非负用 Dij |

**组2：Bellman-Ford vs Floyd**

| 对比维度 | Bellman-Ford | Floyd |
|---|---|---|
| 各自定义 | 单源：对每条边松弛至多 n-1 轮 | 多源：三重循环借中转点 dis[i][j]=min(dis[i][j],dis[i][k]+dis[k][j]) |
| 核心区别 | 一次只算一个源点 | 一次算出任意两点间距离 |
| 各自特点 | O(nm)，适合稀疏图 | O(n³)，代码 4 行最易写 |
| 使用场景 | 单起点 + 负边权 / 判负环 | 点少（几百内）、要全源距离 |
| 典型示例 | n=m=10⁵：Ford 可跑 | n=10⁵：n³ 直接爆炸 |
| 记忆口诀 | 单源 Ford，全源 Floyd |

**组3：负边权 vs 负权回路**

| 对比维度 | 负边权 | 负权回路 |
|---|---|---|
| 各自定义 | 单条边的权值为负 | 边权之和为负的一条回路 |
| 核心区别 | "一条边"的属性 | "一个环"的整体属性 |
| 各自特点 | 可能让绕路更短，但最短路仍存在 | 最短路无穷小，最短路不存在 |
| 使用场景 | Ford/SPFA 照常求最短路 | 只能检测并报告，不能求值 |
| 典型示例 | 1→2 w=-3：dis₂=-3 合法 | ②④⑤③② 权和 -3：绕圈无穷小 |
| 记忆口诀 | 负边能算，负环完蛋 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**Dijkstra 贪心锁定在负边权下失效（痛点）→ 放弃贪心、对每条边无脑松弛（思路）→ 每轮 O(m)，最短路边数 ≤ n-1 → 至多 n-1 轮，O(nm)（复杂度）→ 某轮无更新说明已收敛 → flag 提前退出（常数优化）→ 第 n 轮仍能更新 = 收敛被破坏 = 负环（副产品能力）**。Bellman-Ford 用"以慢换稳"换来负边权安全感，并把"松弛轮数"与"路径边数"绑定。

跨知识点共性：
1. **与第 17 章搜索优化同思路**：都在问"哪些动作还可能有用？"——搜索剪无用分支，Ford 用 flag 剪无用轮次（第 20 章 SPFA 再剪无用边）。
2. **与第 8 章贪心对照**：Dijkstra 是贪心，Ford 是暴力——"贪心失效时退回暴力保正确"是通用解题策略。
3. **向后铺垫**：SPFA = 队列优化的 Ford；"第 n 轮判负环"在 SPFA 里演变成"点入队次数 > n-1"。

## 📋 速查表

| 版本 | 轮数 | 每轮动作 | 用途 |
|---|---|---|---|
| Ford 求最短路 | i=1..n-1 | 扫全部 m 条边松弛，flag 提前停 | 有负边权的单源最短路 |
| Ford 判负环 | i=1..n | 第 n 轮有更新 → 负环 | 判定起点可达负环 |
| 复杂度 | — | — | O(nm)，边集数组存图 |

```cpp
// Ford 骨架（默写级）
for (int i = 1; i < n; i++) {          // 判负环改为 i <= n 并记录第 n 轮更新
    bool flag = false;
    for (int j = 1; j <= m; j++)
        if (dis[e[j].start] + e[j].w < dis[e[j].end]) {
            dis[e[j].end] = dis[e[j].start] + e[j].w;
            flag = true;               // 判负环：if (i == n) 有负环
        }
    if (!flag) break;                  // 本轮无更新，提前结束
}
```
