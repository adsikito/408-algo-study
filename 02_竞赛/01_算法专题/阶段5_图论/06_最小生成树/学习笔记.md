## 🗺️ 本章地图

> **本章解决一个问题：把 n 个点连成一张网，怎么连总代价最小？**
> 路线是"概念 → 两大算法 → 真题"：先弄清生成树与最小生成树的定义（知识点 1）；再学加边的 Kruskal——并查集判环（知识点 2）；然后学加点的 Prim——类比 Dijkstra（知识点 3）；最后用 P1194（买东西建图）和 P1265（平面城市稠密图）收尾（知识点 4）。

## 📌 本章重点（3-5个）

⭐ **生成树定义**：n 个顶点、n-1 条边的极小连通子图，任加一条边必成环
⭐ **Kruskal 算法**：边按权从小到大排序，并查集判两端点是否连通，不连通才选，O(ElogE)，适合稀疏图
⭐ **Prim 算法**：从一个点开始不断"加点"，每次取离生成树最近（dis 最小）的未访问点，O(V²)，适合稠密图
⭐ **建图转化**：实际问题（买东西优惠、城市修路）转成"图 + 边权"，答案即最小生成树权值和
⭐ **稠密图判断**：n=5000 的平面图用邻接矩阵边算边用，别预处理存矩阵防 MLE

## 🔥 本章难点（2-3个）

🔥 **Kruskal 判环的正确性理解**：为什么"两端点根相同则跳过"不会漏掉最优解（贪心 + 交换论证）
🔥 **P1265 三条规则的抽象**：证明"两两最近连边"不产生交叉，本质就是 MST
🔥 **Prim 的 dis 含义与 Dijkstra 的区别**：dis[i] 是"到树的最短边"而不是"到起点的最短路"

## ⚠️ 本章易错点（3-5个）

⚠️ **Kruskal 不判环直接加**：忘记用并查集比较 find(u) 与 find(v)，选了成环边导致边数超 n-1、答案偏大
⚠️ **Prim 选点后忘记松弛**：vis[now]=1 之后必须遍历 now 的邻边更新 dis，否则后面选点错误
⚠️ **图不连通未处理**：Prim 中若最小 dis 仍为 inf 要返回 -1（输出 orz）；Kruskal 要数选了几条边，不足 n-1 即不连通
⚠️ **无向图只加一条边**：Prim 用链式前向星必须 add(x,y,z) 和 add(y,x,z) 各一次，数组要开 2*maxn
⚠️ **P1265 预存 5000×5000 邻接矩阵 MLE**：边权现用现算（勾股定理），不要存下来

## 📖 知识点讲解

### 1. 生成树与最小生成树

**是什么**：一个 n 个顶点的连通图，保留恰好 n-1 条边、仍把所有点连通，这样的极小连通子图叫**生成树**——"树"意味着无环。边带权时，生成树各边权值总和称为生成树的权，**权值最小的生成树就是最小生成树（MST）**。白话：修路连通 n 个村庄，花钱最少的修法。

**为什么**：生成树有两条关键性质支撑算法——①任意加一条不在树中的边必成环（所以树边恰好 n-1 条）；②砍掉环上最大边仍连通（贪心可交换，保证 Kruskal/Prim 的贪心选择是对的）。

**怎么用**：判断一个子图是不是生成树，数两点：边数 = n-1？全图连通？
```
n=4 个点 {1,2,3,4}，边 {(1,2),(2,3),(3,4)}：3 条边 = n-1，连通 → 是生成树
若再加边 (1,4)：1→2→3→4→1 成环 → 不再是树
```

> ⚠️ 注意事项：最小生成树在边权互不相同时唯一；有权值相同的边时形态可能不唯一，但最小权值和唯一。

> 🎯 规律：n 个点 n-1 条边 + 连通 = 生成树，多一条必环，少一条必断。
> 💡 一句话总结：连通的最便宜骨架就是 MST。

### 2. Kruskal 算法（加边法，并查集判环）

**是什么**：把所有边按权值**从小到大排序**，依次扫描每条边：用**并查集**查两端点的根，根不同（不在同一棵树/集合）就选这条边并合并集合；根相同说明会成环，跳过。选满 n-1 条边即得 MST。本质是贪心。

**为什么**：从小边贪心——当前最小边若不成环，选它一定不亏（若不用它，最终两集合之间也必须靠某条 ≥ 它的边连通）。并查集"同根=同集合=已连通"，是 O(α(n)) 的判环神器。复杂度 O(ElogE)，瓶颈在排序，**边少时快，适合稀疏图**。

**怎么用**（`Kruskal模板.cpp` 核心）：
```cpp
sort(e + 1, e + ecnt + 1, cmp);        // 按边权从小到大
for (int i = 1; i <= ecnt; i++) {
    int u = find(e[i].u), v = find(e[i].v);
    if (u != v) { fa[u] = v; sum += e[i].w; }   // 不同集合才选
}
```
**跟着算**：4 顶点图，边排序后为 (1,2)=1、(2,3)=2、(3,4)=3、(1,4)=4、(1,3)=5：

| 步 | 边 | 权 | find(u) | find(v) | 判定 | 动作 | 已选权和 |
|----|------|---|---------|---------|------|------|---------|
| 1 | (1,2) | 1 | 1 | 2 | 不同 | 选，fa[1]=2 | 1 |
| 2 | (2,3) | 2 | 2 | 3 | 不同 | 选，fa[2]=3 | 3 |
| 3 | (3,4) | 3 | 3 | 4 | 不同 | 选，fa[3]=4 | 6 |
| 4 | (1,4) | 4 | 4 | 4 | 同根 | 成环，跳过 | 6 |
| 5 | (1,3) | 5 | 4 | 4 | 同根 | 成环，跳过 | 6 |

选了 3 条边 = n-1，MST = 6。若继续扫边且已选满 n-1 条，可提前 break。

> ⚠️ 注意事项：并查集要在 Kruskal 函数内初始化 fa[i]=i；统计选边条数可判"图不连通"（< n-1 时无生成树）。

> 🎯 规律：排序 + 贪心选边 + 并查集防环，Kruskal 三件套缺一不可。
> 💡 一句话总结：小边优先，并查集把关。

### 3. Prim 算法（加点法，类比 Dijkstra）

**是什么**：从一个起点开始，维护数组 dis[i] = **未入树点 i 到"当前生成树"的最短边权**。每轮在未入树的点中选 dis 最小的点 now 入树（vis[now]=1），累加 dis[now]，再用 now 的邻边去松弛其他未入树点的 dis。重复 n-1 次全部入树。

**为什么**：与 Dijkstra 结构神似但含义不同——Prim 的 dis 是"点到**树**的距离"（取 min 即可，不用累加），Dijkstra 的 dis 是"点到**起点**的路径长度"（要累加）。朴素 Prim 每轮 O(V) 找最小点，总复杂度 O(V²)，**点少边多时快，适合稠密图**（P1265 n=5000 完全图用它）。

**怎么用**（`Prim模板.cpp` 核心）：
```cpp
dis[1] = 0; vis[1] = 1;                       // 1号点先入树
for (i = head[1]; i; i = e[i].next)           // 先用1号点松弛一轮
    dis[e[i].u] = min(dis[e[i].u], e[i].w);
while (tot < n - 1) {
    mindis = inf;
    for (i = 1; i <= n; i++)                  // O(V) 找离树最近的未入树点
        if (!vis[i] && dis[i] < mindis) { now = i; mindis = dis[i]; }
    if (mindis == inf) return -1;             // 图不连通
    tot++; sum += mindis; vis[now] = 1;
    for (i = head[now]; i; i = e[i].next)     // 松弛：更新各点到树的距离
        if (!vis[e[i].u]) dis[e[i].u] = min(dis[e[i].u], e[i].w);
}
```
**跟着算**：4 点完全图，边 (1,2)=5、(1,3)=1、(1,4)=4、(2,3)=2、(3,4)=7：
- 初始：vis{1}，dis = [–, 5, 1, 4]
- 第1轮：最小 dis 是点3(=1)，入树，sum=1；松弛后 dis = [–, 2, –, 4]
- 第2轮：点2(=2) 入树，sum=3；dis = [–, –, –, 4]
- 第3轮：点4(=4) 入树，sum=7，共 n-1=3 条边 → MST = 7

> ⚠️ 注意事项：松弛时先判断 `!vis[u]` 再更新；入树点数 tot 最多到 n-1（起点已算一个）。

> 🎯 规律：Prim 记"加点不记边"，dis 是到树的最短边，只取 min 不累加。
> 💡 一句话总结：每次捞离树最近的点。

### 4. 例题转化：P1194 购买礼物 与 P1265 公路修建

**是什么**：两道"看穿建图"的真题。**P1194**：n 件物品，单买每件花 A 元；某些物品对之间有优惠价 k[i][j]。求买齐所有物品的最小花费——把每件物品看作节点，"超级源 0"向每件物品连权 A 的边（直接购买），物品 i、j 间连权 k[i][j] 的边（优惠），**答案 = 整张图的最小生成树**。**P1265**：n 个城市平面坐标，按三条规则修路连通全部城市——分析后规则退化成"两两连最近的点"（交叉情况可用三角不等式反证不可能），即平面完全图求 MST。

**为什么**：MST 算法本身是模板，考试考的是**建模**："连通所有点的最小代价"类问题几乎都是 MST。P1265 的关键约束 n≤5000：k=n(n-1)/2≈1250 万条边，是**稠密图**——Kruskal 排序 O(ElogE) 太慢且存边爆内存，必须用 O(V²) 的 Prim，且边权现算现用不存邻接矩阵。

**怎么用**（P1265 现算边权）：
```cpp
// 不预存矩阵，Prim 松弛时直接算距离
double d = sqrt((x[i]-x[j])*(x[i]-x[j]) + (y[i]-y[j])*(y[i]-y[j]));
```
跟着想 P1194：3 件物品，A=2，优惠 k[1][2]=1、k[2][3]=1 → 建边 0-1(2)、0-2(2)、0-3(2)、1-2(1)、2-3(1)，Kruskal 选 1-2(1)、2-3(1)、0-1(2) → 答案 4（先买1号花2，优惠价买2、3各花1）。

> ⚠️ 注意事项：P1194 若优惠价 k 比单买 A 还贵，连不连都不影响 MST 正确性（Kruskal 自动不选劣边）；k[i][i]=0 的对角线要跳过。

> 🎯 规律："把所有点连通的最小代价"= 建图跑 MST，源点权=单件价、关系权=优惠价。
> 💡 一句话总结：先建图，后模板，稠密用 Prim。

## 🔍 相似概念辨析

### Prim vs Kruskal

| 维度 | Prim | Kruskal |
|------|------|---------|
| 生长方式 | 加**点**：一棵树逐步长大 | 加**边**：森林逐步合并 |
| 判环手段 | vis 数组（已入树不再选） | 并查集 find 比较根 |
| 时间复杂度 | O(V²) | O(ElogE) |
| 适用图型 | 稠密图（边多，如完全图） | 稀疏图（边少） |
| 存图方式 | 邻接矩阵 / 链式前向星 | 边表结构体数组 |
| 类比算法 | Dijkstra（但 dis 含义不同） | 贪心 + 并查集（同种并查集） |
| 建模题 | P1265 平面城市 | P1194 购买礼物 |

### 最小生成树 vs 最短路（Dijkstra）

| 维度 | 最小生成树 | 最短路 |
|------|-----------|--------|
| 目标 | 连通**所有**点，总权最小 | 求两**特定**点间路径权最小 |
| 结果形态 | n-1 条边的树（全局骨架） | 一条路径（点到点） |
| dis 含义（Prim/Dijkstra 对照） | 点到**树**的最短边 | 点到**起点**的最短路径长 |
| 松弛方式 | dis[u] = min(dis[u], w) | dis[u] = min(dis[u], dis[now]+w) |
| 是否可累加路径 | 无"路径"概念 | 路径长度可传递累加 |
| 复杂度 | O(V²) 或 O(ElogE) | 堆优化 O((V+E)logV) |
| 典型题 | P3366、P1265 | P4779 等 |

## 🧩 本章归纳：一条主线串全章

> 本章主线一句话：**"连通所有点的最小代价" → 生成树模型 → 加边贪心（Kruskal+并查集）或加点贪心（Prim+vis/dis）**。概念上先认清"n-1 条边、无环、连通"三要素；算法上 Kruskal 靠排序+并查集判环服稀疏图，Prim 靠 dis 数组选最近点服稠密图；建模上 P1194 教你加"超级源点"把购买代价变成边，P1265 教你"规则再花哨，先想 MST + 复杂度选型"。做 MST 题的三连问：这是什么图（稠密/稀疏）？→ 用哪个算法？→ 不连通怎么输出？

## 📋 速查表

| 项目 | Kruskal | Prim |
|------|---------|------|
| 核心代码量 | sort + find + 合并 | 找最小 dis 点 + 松弛 |
| 初始化 | fa[i]=i | dis 全 inf，起点入树 |
| 每轮动作 | 取最小边，同根跳过 | 取最小 dis 点入树并松弛 |
| 不连通判断 | 选边数 < n-1 | mindis == inf 返回 -1 |
| 无向边存储 | 存一次即可 | add 两次，数组开 2 倍 |
| 常用题型 | 稀疏图、带建图转化 | 稠密图、坐标完全图 |
