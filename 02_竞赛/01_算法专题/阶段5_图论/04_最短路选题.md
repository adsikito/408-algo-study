## 本章地图

本章解决一个问题：**「题目不像最短路，怎么把它变成最短路？」**

```text
题目状态里有「额外的维度」？
   ├─ 剩余次数 / 钥匙 / 油量 → 分层图：复制 k 层 + 层间边（知识点 1）
   ├─ 多个出发点 / 目的点   → 虚拟源点 / 汇点收拢（知识点 2）
   ├─ 「步数最少」「概率最大」→ 边权转化：1 / −log（知识点 3）
   └─ 问「到每个 x 的距离」 → 反向建图跑一次（知识点 4）
n ≤ 500？
   └─ 全源 / 中转点动态加入 → Floyd（知识点 5，k 循环的语义）
不等式组？
   └─ xᵢ − xⱼ ≤ c → 建边跑最短路，负环 = 无解（知识点 6）
```

**为什么这条路径是这样**：最短路算法（03 篇）只是「发动机」，
**本篇练的是「把题面翻译成图」的变速箱**——
五大套路的共同本质：**让「原问题的合法决策」恰好对应「图上的一条路径」**。

## 核心概念与模板

**是什么**：五大建图套路——分层图、虚拟源汇、边权转化、反向建图、
（Floyd 时间轴与差分约束两个专属范式）。

**为什么**：竞赛真正的分水岭在「翻译」不在「代码」——
模板写熟后（03 篇），拉开差距的全是**把题面转成图上的点与边**的能力。

> **【规律】** **分层图的编号铁律**：节点 (u, j) 编号为 `u + j × n`——
> 偏移量用「层的编号 × 点数」，数组开 `N × (K+1)`；
> **终点答案在所有层取 min**（没用完次数也合法）。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <queue>
#include <cstring>
using namespace std;
typedef long long ll;
typedef pair<ll, int> P;

/* 经典分层图：k 次免单机会的最短路 */
/* 节点 (u, j) = 在第 j 层的 u；层内边同原图，层间边权 0（用一次免单） */
const int N = 100005, K = 12;
int head[N * K], nxt[N * 40], to[N * 40], wt[N * 40], tot;
ll dist[N * K];

void addEdge(int u, int v, int c) {
    to[tot] = v; wt[tot] = c;
    nxt[tot] = head[u]; head[u] = tot++;
}

void build(int n, int m, int k) {        /* m 条原边 */
    for (int e = 0; e < m; e++) {
        int u, v, c;
        /* 读入 u v c */
        for (int j = 0; j <= k; j++) {
            addEdge(u + j * n, v + j * n, c);        /* 层内：不免费 */
            if (j < k)
                addEdge(u + j * n, v + (j + 1) * n, 0);  /* 层间：免费 */
        }
    }
}

ll solve(int n, int k) {
    memset(dist, 0x3f, sizeof(dist));
    priority_queue<P, vector<P>, greater<P>> heap;
    dist[1] = 0;
    heap.push({0, 1});
    while (!heap.empty()) {
        P p = heap.top(); heap.pop();
        int u = p.second;
        if (p.first > dist[u]) continue;
        for (int e = head[u]; e != -1; e = nxt[e])
            if (dist[u] + wt[e] < dist[to[e]]) {
                dist[to[e]] = dist[u] + wt[e];
                heap.push({dist[to[e]], to[e]});
            }
    }
    ll ans = 1e18;
    for (int j = 0; j <= k; j++)         /* 任一层到达 n 均可 */
        ans = min(ans, dist[n + j * n]);
    return ans;
}
```

> **【类比】** 分层图像**游戏的多周目**：普通层是「一周目」，
> 用一次免单就「转周目」（层间边），**层数就是剩余机会数**——
> 你永远可以待在当前层走普通边，也可以跳到下一层用掉特权。
> 终点在任何一层都算通关（取 min）。

## 本章难点

> **【难点】** **Floyd 的 k 循环语义。**
> `floyd` 的 k 不是「第 k 步」而是「**允许经过 {1..k} 作中转**」——
> 这个语义让 P1119 型题（村庄按时间修复）变得自然：
> **把询问按时间排序，k 循环与询问双指针推进**——修复一个点就解锁它作中转。
> 「k 是中转点集合」想通了，Floyd 的三层循环顺序永远不会再记错。

> **【难点】** **差分约束的翻译方向。**
> `xᵢ − xⱼ ≤ c` ⇒ 建**边 j → i 权 c** ⇒ 跑最短路；
> `xᵢ − xⱼ ≥ c` ⇒ 边 i → j 权 −c 跑最长路（或取负跑最短）。
> **无解 ⇔ 负环**（超源 0 连全图权 0）。方向背错全盘错——
> 推导锚点：**约束的「≤」与最短路的三角不等式 `dist[v] ≤ dist[u] + w` 同构**。

---

## 本章易错点

> **【头号易错】** **状态维度漏层**（节点编号 = u + j×n 的偏移量算错）
> 与数组只开 N 不开 N×K。

> **【易错】** **虚拟源点忘了它的出边方向**（源 → 点 vs 点 → 源）。

> **【易错】** **边权转化的可逆性**：取 log 需正权（0 和负数没有 log）。

> **【易错】** **「至少 / 至多 k 次」的层间连边方向**与终点收集（任一层取 min）。

> **【易错】** **差分约束方向背反**：≤ 建边跑最短、≥ 取负跑最短——
> 无解判负环用 02 篇口径。

## 典型例题

### 例 1　k 次免单的最短路（分层图）　难度：综合题

**题干摘要**：n ≤ 10⁴、m ≤ 5×10⁴、k ≤ 10，可免 k 条边的费用，求最短路。
**题源**：分层图经典（同类骨架；对照练习见配套 T1 / T2 / T3 的建模场景）
**涉及知识点**：知识点 1

**解题思路**：

1. **信号**：「k 次机会」→ 分层图。
2. **方法**：核心套路 `build` + `solve`。

**复杂度**：O((n·k + m·k) log(n·k))。

> **【易错】** 终点答案在 k+1 层取 min（没用完免单也合法）；
> 层间边权 0 但方向单向（用掉次数不返还）。

---

### 例 2　灾后重建的时间轴 Floyd（建模）　难度：综合题

**题干摘要**：n ≤ 200 村庄按 tᵢ 天修复；q 次询问第 x 天 s 到 t 的最短路（未修复输出 −1）。
**题源**：同类真源见配套练习 T2（P1119 灾后重建）
**涉及知识点**：知识点 5

**解题思路**：

1. **信号**：「n ≤ 200（Floyd 可行）」+「中转点集合随时间扩大」→ 时间轴 Floyd。
2. **方法**：询问按 x 排序；k 指针只对「t ≤ x 的村庄」跑松弛——
   **修复一个点 = 解锁它作中转**。

**复杂度**：O(n³ + q log q)。

> **【易错】** 两处：询问必须按时间排序后双指针推进（乱序直接错）；
> s / t 未修复要特判 −1（不在中转语义内）。

## 本章总结

### 核心内容（一页纸）

1. **五大套路**：分层图 / 虚拟源汇 / 边权转化 / 反向建图 / （Floyd 语义、差分约束）。
2. **分层图编号铁律**：`u + j×n`，数组开 N×(K+1)，终点在所有层取 min。
3. **层间边单向**（用掉次数不返还）；「至少 / 至多」决定连边范围。
4. **虚拟源点**收拢多源；**多源 BFS 是它的边权全 1 特例**。
5. **边权转化**：计步 → 1；概率 → −log（需正权）。
6. **Floyd 的 k = 中转点集合**——时间轴题让 k 按时间推进（T2）。
7. **差分约束**：≤ 建边跑最短，无解 = 负环（T3）；方向与三角不等式同构。
8. **建模前先算状态总数**——层数爆炸转状压 DP。
9. **反向建图**回答全体「到 x」型询问。
10. **每题沉淀一句「我把什么翻译成了什么」**——套路库靠积累。
