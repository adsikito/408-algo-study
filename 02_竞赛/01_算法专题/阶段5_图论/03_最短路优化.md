## 本章地图

本章解决一个问题：**「10⁵ 点 10⁵ 边的正权图，最短路怎么从 O(n²) 快下来？」**

```text
O(n²) 贪心 Dijkstra（考研版，稠密图）
   ↓
瓶颈：每轮「线性找最小」占 O(n)
   ↓
用堆把「取最小」降到 O(log m)：堆优化 Dijkstra ★ 本篇主体
   ├─ 堆项 = (dist, 点)；弹出即确定；过期项跳过（懒删除）
   └─ 复杂度：O((n + m) log m)
   ↓
对照：负权 → SPFA / BF（02 篇）；正权大图 → 本篇
   ↓
扩展范式：dist 数组加维 / 堆项带状态（次短路、分层图）
```

**为什么这条路径是这样**：Dijkstra 的贪心命题（已确定点不再变）
**只在非负权下成立**——堆只是把「找最小」加速，不改变命题成立条件。
**「正权用堆优化 Dijkstra、负权用 SPFA/BF」这张取舍表是本篇的最终产出。**

## 核心概念与模板

**是什么**：考研版 Dijkstra 是 O(n²) 逐轮线性找最小（邻接矩阵配 dense 图）。
竞赛侧两点升级：**稀疏图**用邻接表 + **堆**把「取最小」降到 O(log m)，
总复杂度 O((n + m) log m)；负权场景仍归 SPFA / Bellman-Ford 管。堆优化版是正式赛最短路的默认选择。

**为什么**：SPFA 易被卡（02 篇），堆优化 Dijkstra 的 O((n+m) log m) 是**有保证的**——
正式赛默认写法。

> **【规律】** **「过期项跳过」是懒删除**：堆里允许同一个点存在多个过期项，
> 弹出时发现 `p.first > dist[u]` 直接 continue——**一行代码免掉手写可删堆**。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
#include <queue>
#include <vector>
using namespace std;
typedef long long ll;
typedef pair<ll, int> P;                 /* (dist, 顶点) 小根堆 */

const int N = 100005;
int n, m;
int head[N], nxt[2 * N], to[2 * N], wt[2 * N], tot;
ll dist[N];

void addEdge(int u, int v, int c) {
    to[tot] = v; wt[tot] = c;
    nxt[tot] = head[u]; head[u] = tot++;
}

void dijkstra(int s) {
    for (int i = 1; i <= n; i++) dist[i] = 1e18;
    priority_queue<P, vector<P>, greater<P>> heap;
    dist[s] = 0;
    heap.push({0, s});
    while (!heap.empty()) {
        P p = heap.top(); heap.pop();
        int u = p.second;
        if (p.first > dist[u]) continue;    /* 过期堆项：跳过 */
        for (int e = head[u]; e != -1; e = nxt[e])
            if (dist[u] + wt[e] < dist[to[e]]) {
                dist[to[e]] = dist[u] + wt[e];
                heap.push({dist[to[e]], to[e]});
            }
    }
}
```

**复杂度账**：每点出堆一次、每边可能产生一次堆项 → 堆操作 O(m) 次 × O(log m)；
「过期项跳过」是懒删除技巧，免手写可删堆。

> **【类比】** 懒删除像**广播通知的作废**：更新 dist 时发一张新通知（堆项），
> 旧通知不回收；听众（点）处理通知前先核对「这是不是过期的旧版本」——
> **过期就扔，不过期才处理**。省掉昂贵的「通知回收」，代价只是堆里多几张废纸。

## 本章难点

> **【难点】** **「已确定点不再变」为何依赖非负权。**
> Dijkstra 弹出堆顶时宣称「dist[u] 已是最终值」——依据是
> 后续路径必然经过「dist 更大的点」，而非负权下不会绕回更小。
> **负权边直接打破该论证**（考研第 5 章 5-6 的反例）——
> 这是三算法取舍表的正确性根基，要能脱稿讲。

> **【难点】** **状态扩展的分寸。**
> 次短路 = dist 数组 ×2；分层图 = 状态加维（如「还剩 k 次机会」）——
> **状态数膨胀几倍，堆容量与内存同步膨胀**，先算账再写代码。
> 状态维度的来源是「决策的额外约束」，不是凭感觉加的。

## 本章易错点

> **【头号易错】** **负权边用堆优化 Dijkstra**——贪心命题被破坏
> （考研第 5 章 5-6 的反例直接适用）；出题数据含负权时必须换 SPFA / Bellman-Ford。

> **【易错】** **过期项不跳过** → 同一点反复处理、堆爆炸 TLE。

> **【易错】** **dist 用 int 溢出**（10⁵ 条 10⁹ 边累加 = 10¹⁴）；全链路 long long。

> **【易错】** **链式前向星 head 忘清 −1**（多组数据）。

> **【易错】** **pair 比较顺序**：`(dist, 点)` 先比 dist 再比编号——
> 与「按 dist 取最小」的贪心一致；自定义比较器别把第二键放前面。

## 典型例题

### 例 1　稀疏图单源最短路（堆优化模板）　难度：模板题

**题干摘要**：n ≤ 10⁵、m ≤ 2×10⁵，正权，求 1 到各点最短距离。
**题源**：同类真源见配套练习 T1（P4779 标准版——正是本模板的官方靶场）
**涉及知识点**：知识点 1、2、3

**解题思路**：

1. **信号**：正权 + 稀疏大图 → 堆优化 Dijkstra。
2. **方法**：核心模板全量默写。

**复杂度**：O((n + m) log m) ≈ 2×10⁵ × 18。

> **【易错】** pair 的比较先比 dist 再比编号，与松弛方向一致；
> 爆 long long 判断（w 累计 ≤ 10⁵ × 10⁹ = 10¹⁴ < 9.2×10¹⁸ 安全）。

---

### 例 2　次短路（Dijkstra 的状态扩展）　难度：综合题

**题干摘要**：求 1 到 n 的次短路径长度（允许非严格小于最优）。
**题源**：Dijkstra 扩展经典（模型同分层图；对照练习见配套 T1 / T2）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「第 k 短」类 → dist 数组加维（dist1 最短 / dist2 次短）。
2. **方法**：松弛时分别尝试更新两个数组；堆项带状态（双份堆项即可）。

**复杂度**：状态数 × 2，总体 O((n + m) log m) 常数翻倍。

> **【易错】** 更新次短要防止「等于最短的重复项」（题面非严格时允许相等）；
> 状态数 × 2 后堆容量同步翻倍。

## 本章总结

### 核心内容（一页纸）

1. **考研 O(n²) 版 vs 竞赛堆优化版**：稀疏大图必堆优化，O((n+m) log m)。
2. **模板三件套**：pair 堆项 + 过期项跳过 + 松弛入堆。
3. **过期项跳过 = 懒删除**：`if (p.first > dist[u]) continue;` 一行免手写可删堆。
4. **复杂度账**：m 次堆操作 × log m——有保证，故成为正式赛默认。
5. **负权禁用**：贪心命题被破坏（考研反例）——负权找 02 篇。
6. **状态扩展范式**：dist 加维 / 堆项带状态（次短路、分层图），内存同步算账。
7. **全链路 long long**：10⁵ × 10⁹ = 10¹⁴。
8. **pair 比较先 dist 后编号**，与贪心一致。
9. **多组数据重置 head / tot / dist / 堆**。
10. **三算法取舍表**：正权稀疏 → 本篇；负权 → 02 篇；全源小图 → 04 篇 Floyd。
