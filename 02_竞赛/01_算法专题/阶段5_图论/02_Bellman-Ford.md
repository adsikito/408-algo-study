## 本章地图

本章解决一个问题：**「边权是负的，最短路怎么求？有没有『越走越小』的骗局？」**

```text
边权全正     → Dijkstra（03 篇，贪心成立）
边权有负     → 贪心失效 → Bellman-Ford：全体边松弛 n−1 轮
   ↓
n−1 轮的理论来源：最短路至多 n−1 条边（无负环时）
   ↓
第 n 轮仍在更新 ⇒ 某条路径绕环更小 ⇒ 负环
   ↓
SPFA = 只把「dist 刚变小」的点重新排队 → 上界不变、实战常快
   ↓
判负环实战：超源 0 连全图（权 0）+ 入队次数 ≥ n 即负环
```

**为什么这条路径是这样**：松弛的本质是**「三角不等式的反复修正」**——
`dist[v] ≤ dist[u] + w(u,v)` 不满足就修。
Bellman-Ford 全量修 n−1 轮是「蛮力保证」；SPFA 只修「被波及的」是「事件驱动」。
**两者的正确性同源，差别只在「修哪些」。**

## 核心概念与模板

**是什么**：Bellman-Ford 求单源最短路，**允许负权边**，还能检测负环：
对全部边做 n − 1 轮松弛，第 n 轮仍有更新 ⇒ 存在负环。朴素 O(nm)；
**SPFA** = 队列优化的 Bellman-Ford（只松弛「距离刚变小的点」的出边），均摊快、最坏 O(nm)。

**为什么**：考研第 5 章只讲「Dijkstra 禁负权」的定性，本篇补上负权的通用解。

> **【规律】** **松弛前判 `dist[u] != INF`**——INF + 负权 w 反而更小，
> 会把不可达点「松弛」出假距离。**这是本章唯一「一行防全盘错」的代码。**

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
const int N = 1005, M = 5005;
const long long INF = 1e18;

int n, m;
int eu[M], ev[M], ew[M];                 /* 边集数组（Bellman-Ford 天然形态） */
long long dist[N];

bool bellmanFord(int s) {
    for (int i = 1; i <= n; i++) dist[i] = INF;
    dist[s] = 0;
    for (int round = 1; round <= n; round++) {
        bool changed = false;
        for (int e = 0; e < m; e++)
            if (dist[eu[e]] != INF &&
                dist[eu[e]] + ew[e] < dist[ev[e]]) {
                dist[ev[e]] = dist[eu[e]] + ew[e];
                changed = true;
            }
        if (!changed) return true;       /* 提前收敛：无负环 */
        if (round == n) return false;    /* 第 n 轮仍在更新：有负环 */
    }
    return true;
}

/* SPFA：队列优化（同复杂度上界，实战常快） */
int head[N], nxt[2 * M], to[2 * M], wt[2 * M], tot;
#include <deque>
bool inq[N];

bool spfa(int s) {
    for (int i = 1; i <= n; i++) dist[i] = INF;
    std::deque<int> q;
    dist[s] = 0; inq[s] = true; q.push_back(s);
    while (!q.empty()) {
        int u = q.front(); q.pop_front();
        inq[u] = false;
        for (int e = head[u]; e != -1; e = nxt[e])
            if (dist[u] + wt[e] < dist[to[e]]) {
                dist[to[e]] = dist[u] + wt[e];
                if (!inq[to[e]]) {
                    inq[to[e]] = true;
                    q.push_back(to[e]);
                }
            }
    }
    return true;                         /* 判负环需另记入队次数 ≥ n */
}
```

> **【类比】** 松弛像**传八卦的修正**：听到更短的路线就更新自己的「最短认知」，
> 并把消息传给邻居（SPFA 只通知邻居，BF 挨个广播 n−1 轮）。
> **负环 = 一群人互相传「绕一圈更省」的假消息，永远修不完**——这就是判负环的直觉。

## 本章难点

> **【难点】** **「n−1 轮收敛」的论证。**
> 无负环时，最短路至多 n−1 条边（含环必可去环不变差）；
> 第 k 轮结束时，所有「≤ k 条边」的最短路已正确——归纳到 k = n−1 全部正确。
> **第 n 轮仍有更新 ⇔ 某环仍可松弛 ⇔ 负环**。这条论证要能脱稿讲。

> **【难点】** **SPFA 判负环的「超源建法」。**
> 从单一 s 出发，**s 不可达的负环会漏判**——标准解法：建超源 0 向所有点连权 0 的边，
> 再跑 SPFA，**任一点入队次数 ≥ n+1 即负环**。
> 计数数组与 inq 是两个东西，别混用。

---

## 本章易错点

> **【头号易错】** **松弛前不判 `dist[u] != INF`**——
> INF + 负权 w 反而更小，把不可达点「松弛」出假距离。

> **【易错】** **负环判定口径混用**：BF 用「第 n 轮仍有更新」；SPFA 用「单点入队 ≥ n 次」。
> 两套不能拼在一起用。

> **【易错】** **SPFA 判负环不建超源**——「从 s 不可达的负环」会漏判；
> 计数数组随入队清零重置。

> **【易错】** **INF 用 int 版**：1e9 + 负权 −1e9 边相加溢出；统一 1e18 + long long。

> **【易错】** **SPFA 被卡**：正式赛出题人针对性构造网格 / 链状数据让 SPFA 退化 O(nm)
> ——正权场景换 Dijkstra（03 篇）。

### 例 1　含负权边的最短路（模板）　难度：模板题

**题干摘要**：n ≤ 10³、m ≤ 5×10³，边权可负，无负环，求 s 到各点最短路。
**题源**：同类真源见配套练习 T2（P3371 弱化版——注意其数据要求 SPFA / BF 而非 Dijkstra）
**涉及知识点**：知识点 1

**解题思路**：

1. **信号**：「边权可负」→ Bellman-Ford / SPFA。
2. **方法**：核心模板 `bellmanFord` + 输出。

**复杂度**：O(nm) = 5×10⁶。

> **【易错】** INF 用 1e18（int 版会加爆）；不可达仍输出标记值（约定 INF 或 −1）。

---

### 例 2　判负环（SPFA 计数版）　难度：综合题

**题干摘要**：判断图中是否存在负环（可达任意点的超源建法）。
**题源**：同类真源见配套练习 T1（P3385 负环）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「判负环」→ 超源 + SPFA 计数。
2. **方法**：建超源 0 连所有点（权 0）保证全图可达；SPFA 中某点入队次数 ≥ n+1 ⇒ 负环。

**复杂度**：最坏 O(nm)。

> **【易错】** 不建超源时「从 s 不可达的负环」会漏判——这是判负环题最常见的坑；
> 计数数组随入队清零重置。

## 本章总结

### 核心内容（一页纸）

1. **算法选择第一问：有负权吗？** 无 → Dijkstra；有 → 本篇。
2. **松弛**：`dist[v] = min(dist[v], dist[u] + w)`；**先判 `dist[u] != INF`**。
3. **n−1 轮收敛的论证**：无负环时最短路至多 n−1 条边。
4. **负环判定两口径**：BF 第 n 轮仍有更新；SPFA 单点入队 ≥ n 次——不混用。
5. **判负环要建超源**（权 0 连全图），否则漏判不可达负环。
6. **SPFA = 事件驱动的 BF**：只松弛 dist 刚变小的点；上界不变、实战常快、易被卡。
7. **最长路 = 松弛取反**：`<` 换 `>`、INF 换 −INF（T3）。
8. **INF 用 1e18 + long long**（int 版加负权溢出）。
9. **inq 与计数数组是两个东西**，SPFA 判负环两者都要。
10. **考研第 5 章的「Dijkstra 禁负权」反例**，正是本篇存在的理由。
