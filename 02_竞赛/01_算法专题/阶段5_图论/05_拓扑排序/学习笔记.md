## 🗺️ 本章地图

本章解决一个问题：任务之间有先后依赖（先修课、工序、车站级别），怎么排出一个"谁必须在前"的合法顺序？路线是"概念 → 两大算法 → DAG 上 DP"：先复习 **DAG、AOV 网、拓扑序列**三个概念；再学两大求法——**Kahn 算法**用"入度"驱动 BFS（O(V+E)，输出点数 <n 即有环）、**DFS 算法**用"回溯时入栈"取逆序（三态 vis 顺带判环）；最后在 P1113（杂务调度：拓扑 + time 取 max 转移）和 P1983（车站分级：DAG 最长路）里，把拓扑序当成 **DP 的转移顺序**用——拓扑排序是"带依赖的 DP"的地基。

## 📌 本章重点

⭐ **拓扑序列定义**：若从 Vi 到 Vj 有路径，则序列中 Vi 必在 Vj 之前；只有 DAG（有向无环图）存在拓扑序列
⭐ **Kahn 算法**：入度 0 的点入队 → 出队记入 topo[] → 邻接点入度减 1 → 减到 0 入队；O(V+E)
⭐ **判环两法**：Kahn 输出点数 k<n → 有环；DFS 遇到 vis==2 的点 → 有环
⭐ **DFS 求拓扑序**：回溯时入栈，最后自顶向下弹出即拓扑序；vis 三态 0 未走 / 2 正在遍历其后代 / 1 该点及其后面全访问完
⭐ **DAG 上 DP**：拓扑序天然保证无后效性——`ed[y]=max(ed[y], ed[x]+t[y])`（P1113）、`le[y]=max(le[y], le[x]+1)`（P1983）

## 🔥 本章难点

🔥 **DFS 三态 vis 与判环原理**：vis=2 表示"该点还在当前递归栈里"，若再遇到 vis==2 的点，说明走回了正在展开的祖先——这正是有向环；vis=1 只代表"处理完了"，再遇到不算环
🔥 **为什么"回溯时入栈、逆序输出"是拓扑序**：对任意边 u→v，v 的整个后代链先做完、v 先入栈，u 后入栈——栈顶向下的弹出顺序恰好满足"u 在 v 前"
🔥 **P1983 的建图推理**：由"停靠站级别 ≥ 停靠的最小级别"推出"非停靠站级别 < 停靠站级别"，于是从非停靠站 j 向停靠站 s[k] 连有向边，答案 = 该 DAG 的最长路（级数）

## ⚠️ 本章易错点

⚠️ **建边方向**：u→v 表示"u 必须先于 v"，入度加在 v 上（ind[v]++）；P1113 里是"前驱杂务 x → 当前杂务 y"，建反了整题报废
⚠️ **初始化**：h[] 要 memset -1、ind[] 要清零；多组数据时全要重来
⚠️ **P1113 读入格式**：任务编号**不按行序**给出——先读编号 y 再读耗时 t[y]（课件注释"不要同行读入"是强调 scanf 顺序），别想当然 t[i]
⚠️ **P1113 入队时就赋初值**：无前置任务的工作完成时间 ed[i]=t[i]；答案取**所有** ed[i] 的 max（杂务可并行），不是拓扑序最后一个点
⚠️ **P1983 重复建边**：一趟车的"非停靠 × 停靠"会撞车，用 pd[j][s[k]] 去重，否则入度虚高、级数算错
⚠️ **DFS 版标记时机**：进函数先 vis[x]=2，回溯前才 vis[x]=1——顺序颠倒判环必错

## 📖 知识点讲解

### 1. 三个概念：DAG、AOV 网、拓扑序列

**是什么**：白话——把"先做 A 才能做 B"画成箭头，拓扑排序就是给所有任务排一个不违规的队伍。严格说：**DAG** 是有向无环图；**AOV 网**是用顶点表示活动、弧表示活动间优先关系的有向网（Activity On Vertex Network）；**拓扑序列**：G=(V,E) 中顶点序列 V1..Vn 满足"若 Vi 到 Vj 有路径，则序列中 Vi 必在 Vj 之前"；**拓扑排序**就是构造拓扑序列的过程。

**为什么**：工程调度、课程先修、编译依赖……这些"带依赖的排序/计时"问题全部建模为 DAG 上的拓扑结构；无环是底线——一旦成环（A 依赖 B、B 又依赖 A）谁也排不进去。

**怎么用**：拿到题先问三句——①顶点是什么（任务/城市/车站）？②边是谁指向谁（前置→后继）？③要"顺序"还是要"按序算值（DP）"？

> ⚠️ 注意事项：拓扑序**不唯一**（同一入度集合内的点次序任意），输出顺序不同不代表错；判题常见两种问法——输出任意一个，或问"是否存在"。

> 🎯 规律：有环 = 无法拓扑排序；"判断能否完成全部任务"本质是判环。

> 💡 一句话总结：有向无环，才排得了队。

### 2. Kahn 算法：入度驱动的 BFS（含判环）

**是什么**：白话——每次挑"没人拦着"的点（入度 0）出场，出场后把它的下家们的"拦着次数"各减一，减到 0 的接着出场。严格说：①所有入度 0 的点入队；②队首 u 出队记入 topo[]；③枚举 u 的出边，把邻接点 y 的入度减 1，减到 0 就入队；④重复直到队列空。O(V+E)。

**为什么**：入度为 0 ⇔ 所有前驱都已完成 ⇔ 现在轮到它合法出场——队列恰好按"依赖就绪"的顺序放行；若最终出场人数 < n，剩下的人互相等着（成环）。

**怎么用**——模板（忠实课件 `Kahn模板.cpp`）：
```cpp
struct edge{ int to,next; } e[10005];
int h[105], ind[105], topo[105], k=0, cnt;
void add(int u,int v){ e[cnt]={v,h[u]}; h[u]=cnt++; }
bool kahn()
{
  queue<int>q;
  for(int i=1;i<=n;i++) if(ind[i]==0) q.push(i);
  int x,y;
  while(!q.empty())
  {
    x=q.front(); q.pop();
    topo[++k]=x;                       // 记录拓扑序列
    for(int i=h[x]; ~i; i=e[i].next)
    {
      y=e[i].to;
      ind[y]--;                        // 摘掉 x 后，y 少一个前驱
      if(ind[y]==0) q.push(y);
    }
  }
  if(k==n) return 1;                   // 全部出场 → 无环
  else return 0;                       // 出场人数不足 → 有环
}
```

**跟着算**（课件样例：5 点 5 边 1→2、2→4、3→2、3→4、4→5）。初始入度表：ind=[0,2,0,2,1]：

| 步 | 出队→topo | 处理边 | 入度变化 | 新入队 | 队列 |
|---|---|---|---|---|---|
| 0 | — | — | — | 1、3 | [1,3] |
| 1 | 1 | 1→2 | ind₂: 2→1 | 无 | [3] |
| 2 | 3 | 3→2、3→4 | ind₂: 1→0；ind₄: 2→1 | 2 | [2] |
| 3 | 2 | 2→4 | ind₄: 1→0 | 4 | [4] |
| 4 | 4 | 4→5 | ind₅: 1→0 | 5 | [5] |
| 5 | 5 | — | — | — | [] |

输出 `1 3 2 4 5`，k=5=n → 无环 ✓（实测课件代码输出一致）。

> ⚠️ 注意事项：入度为 0 的点**一开始可能有多个**，全部入队——它们的相对顺序任意，所以拓扑序不唯一。

> 🎯 规律：Kahn = BFS + 入度计数器；"出队计数 < n"是判环的最简写法。

> 💡 一句话总结：入度清零才出场。

### 3. DFS 求拓扑序：回溯入栈 + 三态 vis 判环

**是什么**：白话——深搜到底、没路可走时把点压栈；全部压完，从栈顶往下倒就是拓扑序。严格说：DFS 遍历图，**回溯时**将顶点入栈——先入栈的顶点"垫底"（课件：第一个入栈的顶点必定出度为 0，入度为 0 的源点最后入栈），最后将栈自顶向下输出，即为拓扑序列。判环给每个点三种状态：vis=0 未走过；vis=2 这个点走过一次、**正在遍历它后面的点**；vis=1 该点及其后面所有的点已经访问完（回溯时打标）。遇到 vis[y]==2 → 有环。O(V+E)。

**为什么**：对边 u→v：v 的整条后代链先被递归完成、v 先入栈，u 要等所有出边都回来才入栈——所以"先入栈的必被后入栈的指向"，栈顶向下输出时 u 天然排在 v 前。判环则靠"递归栈上的点"（vis=2）：再次撞见它=绕了一圈回到祖先=环。

**怎么用**——模板（忠实课件 `DFS求拓扑序列模板.cpp`）：
```cpp
int vis[105];
/*
vis[i]=0  还未走过        =1  该点及其后面所有的点已经访问完了（回溯时标）
          =2  这个点走过一次了，现在正在遍历该点后面的点（第一次走到时标）
*/
int flag=0;               // 是否有环
stack<int>topo;
void DFS(int x)
{
  vis[x]=2;                        // 第一次访问
  for(int i=h[x]; ~i; i=e[i].next)
  {
    int y=e[i].to;
    if(vis[y]==2){ flag=1; return; }   // 撞上递归栈中的祖先 → 有环
    else if(vis[y]==0){ DFS(y); if(flag) return; }
  }
  topo.push(x);                    // 回溯时入栈，记录拓扑序列
  vis[x]=1;                        // x 及其后面的点访问结束
}
// main：对每个 vis==0 的点 DFS(i)；无环则自顶向下弹出输出
```

**跟着算**（两张样例各跟一遍）：
- **无环图** 1→2、2→4、3→2、3→4、4→5：DFS(1)→DFS(2)→DFS(4)→DFS(5)，5 无出边→入栈 5；回溯 4 入栈、2 入栈、1 入栈；再从 3 出发，3→2、3→4 均 vis=1 跳过，3 入栈。栈（底→顶）= 5,4,2,1,3，弹出顺序 **3 1 2 4 5**——合法拓扑序 ✓。
- **有环图**（课件 DFS 模板样例）1→2、2→4、3→2、**4→3**、4→5：DFS(1)→DFS(2)→DFS(4)→DFS(3)，3 的出边指向 2，而 vis[2]==2（还在递归栈里）→ flag=1，输出"有环" ✓（实测代码输出一致）。

> ⚠️ 注意事项：vis=1 和 vis=2 的赋值时机是判环生死线：进函数立刻 =2，回溯前才 =1；漏写任一句，环可能漏判或误判。

> 🎯 规律：Kahn 用"入度"正向放行，DFS 用"回溯"反向压栈——一正一逆，同一个拓扑结构。

> 💡 一句话总结：回溯压栈，倒着念。

### 4. 例题选讲：P1113 杂务调度 与 P1983 车站分级

**是什么**：
- **P1113**：n 项杂务，有的需要先完成若干准备工作；互相无关的杂务**可同时做**，问全部完成最少多久。解法：Kahn + DP——边"前驱 x→当前 y"，转移 `ed[y]=max(ed[y], ed[x]+t[y])`（y 的开始时间 = 最晚完成的前驱），答案 = max(ed[i])。
- **P1983**：一趟直达车只停靠若干站，**停靠站级别 ≥ 线上一切非停靠站**，求最少把车站分成几级。解法：每趟车从每个非停靠站 j 向每个停靠站 s[k] 连边（去重），在 DAG 上做 `le[y]=max(le[y], le[x]+1)` 求最长链，最大 le 即级数。

**为什么**：两题问的都是"最短总时间/最少级数"，本质是 **DAG 最长路**——依赖链上每条边至少贡献一层，最长的依赖链决定答案；拓扑序保证算到 y 时它所有前驱的 ed/le 都已定型（无后效性）。

**怎么用**——P1113 关键代码（忠实课件 `P1113.cpp`）：
```cpp
void kahn()
{
  queue<int> q;
  for(int i=1;i<=n;i++)
    if(ind[i]==0){ q.push(i); ed[i]=t[i]; }   // 无前置：完成时间=自身耗时
  while(!q.empty())
  {
    x=q.front(); q.pop();
    for(int i=h[x];~i;i=e[i].next)
    {
      y=e[i].to;
      ed[y]=max(ed[y], ed[x]+t[y]);           // y 要等最晚的前驱
      ind[y]--;
      if(ind[y]==0) q.push(y);
    }
  }
}
// 答案：ans = max(ed[i])，可并行 → 取最大而不是最后一个
```
**跟算**（课件 7 杂务样例：1(5)无前置；2(2)←1；3(3)←2；4(6)←1；5(1)←2,4；6(8)←2,4；7(4)←3,5,6）：
ed₁=5 → ed₂=5+2=7 → ed₃=7+3=10 → ed₄=5+6=11 → ed₅=max(7,11)+1=12 → ed₆=max(7,11)+8=19 → ed₇=max(10,12,19)+4=23。答案 **23**（实测课件代码输出一致）。

P1113 还有 **DP 版**（`P1113 - DP版.cpp`）：利用"任务 k 的前驱编号一定小于 k"这一输入保证，读入第 i 项时直接 `ans[i]=max(所有前驱的 ans)+l`，连图都不用存——拓扑序被编号顺序顶替了。

P1983 关键代码（忠实课件，vector 存图 + pd 去重）：
```cpp
for(int j=s[1];j<=s[sn];j++)        // 枚举本趟线路上的所有站
{
  if(flag[j]) continue;             // j 是停靠站，跳过
  for(int k=1;k<=sn;k++)
    if(pd[j][s[k]]==0){             // 避免重复建边！
      g[j].push_back(s[k]);         // 非停靠 j ——→ 停靠 s[k]
      pd[j][s[k]]=1;  ind[s[k]]++;
    }
}
// Kahn 中转移：le[y]=max(le[y], le[x]+1);  答案=max(le[i])
```

> ⚠️ 注意事项：P1113 转移是 **max 不是累加**（前驱并行做，只等最晚的）；P1983 若不去重，同一停靠站入度被多趟车重复加，级数会偏大。

> 🎯 规律：拓扑排序的进阶用法 = **把 topo 顺序当 DP 阶段**：DAG 最长路/最短路/计数，全在 Kahn 出队处做转移。

> 💡 一句话总结：拓扑定顺序，取 max 算答案。

## 🔍 相似概念辨析

**组1：Kahn 算法 vs DFS 求拓扑序**

| 对比维度 | Kahn 算法 | DFS 求拓扑序 |
|---|---|---|
| 各自定义 | 入度 0 入队，出队减后继入度 | 回溯时入栈，栈顶向下输出 |
| 核心区别 | 正向"放行"就绪点 | 反向"压栈"完成点 |
| 各自特点 | 需维护 ind[]，天然判环（k<n） | 需三态 vis，判环靠 vis==2 |
| 各自产物 | topo[] 数组（正序即答案） | 栈（弹出的才是正序） |
| 使用场景 | 需要按序做 DP（P1113 转移顺手） | 只求序列/判环，或数据结构课要求 |
| 典型示例 | 输出 1 3 2 4 5 | 同图输出 3 1 2 4 5（同构合法） |
| 记忆口诀 | 入度清零出队，回溯压栈倒读 |

**组2：拓扑排序 vs 普通 DFS/BFS 遍历**

| 对比维度 | 拓扑排序 | 普通 DFS/BFS |
|---|---|---|
| 各自定义 | 构造"所有前驱在前"的顶点线性序 | 系统访问每个顶点一次 |
| 核心区别 | 输出有约束的**顺序** | 只管"访问过没有" |
| 各自特点 | 仅 DAG 有解，顺带判环 | 任何图都能跑，环照走（需 vis 挡） |
| 各自驱动 | 入度（Kahn）/回溯序（DFS 版） | 队列/递归栈本身 |
| 使用场景 | 依赖调度、DAG 上 DP 的转移顺序 | 连通性、最短路（BFS 无权图） |
| 典型示例 | P1113 排工序 | 无权图求最短步数 |
| 记忆口诀 | 遍历管到没到，拓扑管谁在先 |

**组3：拓扑序转移 vs 编号序转移（P1113 两版）**

| 对比维度 | Kahn 版（P1113.cpp） | DP 版（P1113 - DP版.cpp） |
|---|---|---|
| 各自定义 | 先建图拓扑排序，出队时转移 | 利用"前驱编号 < k"读入即转移 |
| 核心区别 | 通用：任何 DAG 都行 | 依赖输入保证的编号性质 |
| 各自特点 | 存图 + ind[] + 队列 | 不存图，几个变量搞定 |
| 各自风险 | 忘 ed 初值/建反边 | 换一道没有该性质的题就失效 |
| 使用场景 | 一般 DAG DP | 明确"编号递增依赖"的题 |
| 典型示例 | 同一答案 23 | 同一答案 23，代码短一半 |
| 记忆口诀 | 拓扑通用保底，编号能省则省 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**依赖关系画成有向图（建模）→ 有环则无解，无环才有拓扑序（DAG 前提）→ Kahn：入度 0 放行，k<n 判环（算法一）→ DFS：回溯压栈逆读，三态 vis 判环（算法二）→ 拓扑序真正的威力：给 DP 提供无后效的转移顺序——ed[y]=max(ed[y],ed[x]+t[y])（P1113）、le[y]=max(le[y],le[x]+1)（P1983）（应用）**。全章一句话：拓扑排序 = "把依赖图拉直成线"，拉直之后，线性 DP 的十八般武艺全用得上。

跨知识点共性：
1. **与第 16 章 BFS 同骨架**：Kahn 就是 BFS 换了个"入度 0 才入队"的准入条件。
2. **与第 15 章 DFS 呼应**：DFS 求拓扑序 = 搜索回溯序的应用；三态 vis 是"递归栈可视化"。
3. **向后铺垫**：第 27 章线性 DP、第 30 章树形 DP 都依赖"按依赖顺序转移"——拓扑序是它们在图上的通用引擎。

## 📋 速查表

| 组件 | Kahn 版 | DFS 版 |
|---|---|---|
| 数据结构 | 队列 + ind[] | 递归栈 + vis[0/1/2] + stack |
| 核心 | ind[y]==0 入队 | 回溯 topo.push(x)，vis[x]=1 |
| 判环 | 出队计数 k<n | 遇 vis[y]==2 |
| 复杂度 | O(V+E) | O(V+E) |
| DAG DP 转移 | 出队时 ed[y]=max(ed[y],ed[x]+t[y]) | 不便做 DP（顺序在栈里） |

```cpp
queue<int> q;
for (int i = 1; i <= n; i++) if (!ind[i]) q.push(i);
while (!q.empty()) {
    int x = q.front(); q.pop();
    topo[++k] = x;
    for (int i = h[x]; ~i; i = e[i].next)
        if (--ind[e[i].to] == 0) q.push(e[i].to);
}
// k < n ⇒ 有环
```
