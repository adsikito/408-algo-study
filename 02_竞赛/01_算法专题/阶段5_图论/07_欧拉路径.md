## 本章地图

本章解决一个问题：**「每条边恰好走一遍的走法，存在吗？怎么找？」**

```text
七桥问题（哥尼斯堡）⇒ 抽象成「边恰好一遍」
   ↓
判定表（知识点 1）：度数奇偶决定一切
   ├─ 无向：回路 = 全偶；路径 = 恰 0 或 2 个奇度点
   └─ 有向：回路 = 入度=出度；路径 = 恰一出超点 + 恰一入超点
   ↓
构造（知识点 2）：Hierholzer——递归走边，回溯时压栈
   ├─ 当前弧优化：用掉的边不再扫 → O(n + m)
   └─ 无向图配对：边编号从 1 起，id >> 1（知识点 3）
   ↓
变体：字典序最小（知识点 4）· 有向 / 混合图（知识点 5）
```

**为什么这条路径是这样**：欧拉题的框架是**「先判定、后构造」**——
判定是一张四行表（几乎零成本），构造是一个固定模板（Hierholzer）。
**模板里唯一的「聪明」是当前弧引用；唯一的「陷阱」是无向边配对。**

## 核心概念与模板

**是什么**：**欧拉路径**：每条边恰好走一次的路径；首尾相接即**欧拉回路**
（一笔画回到起点）。存在性由**度数奇偶**决定（七桥问题的答案）。
判定优先于构造——先数奇度点，再 DFS 找路；实现上用「当前弧优化」保证 O(n + m)。

**为什么**：判定是四行表；构造是固定模板——
**欧拉题的全部技术含量集中在「当前弧」与「无向边配对」两处。**

> **【规律】** **存在性判定表**（先背它再谈代码）：

| 图类型 | 欧拉回路 | 欧拉路径 |
|--------|---------|---------|
| 无向连通图 | 所有顶点度数为偶 | 恰有 0 或 2 个奇度点（2 个时路径起终点为奇度点） |
| 有向连通图 | 所有点入度 = 出度 | 恰有一个点 出度−入度 = 1（起点）、一个点 入度−出度 = 1（终点），其余相等 |

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
const int N = 100005, M = 400005;        /* 无向边 M 开 2 倍 */
int head[N], nxt[M], to[M], tot = 1;     /* tot 从 1 起：e^1 即反向边 */
int cur[N], stk[M], top = 0;             /* cur：当前弧（用掉的边不再扫） */
bool used[M];

void addEdge(int u, int v) {
    to[tot] = v; nxt[tot] = head[u]; head[u] = tot++;
    to[tot] = u; nxt[tot] = head[v]; head[v] = tot++;   /* e 与 e^1 成对 */
}

void euler(int u, int *path) {
    for (int &e = cur[u]; e; ) {         /* 引用：当前弧随 e 推进 */
        int id = e;                       /* 边编号（1 起） */
        if (used[id >> 1]) { e = nxt[e]; continue; }   /* 成对边同属一条 */
        used[id >> 1] = true;
        euler(to[e], path);
        stk[top++] = id;                  /* 回溯时压边 */
    }
}
/* 主函数：判存在性 → cur 复制 head → euler(起点) → 栈逆序即路径 */
```

> **【类比】** Hierholzer 像**清扫积雪**：扫雪车沿着「还没扫过的路」一路开到底，
> 开不动了就**把这段路线记到账本末尾**、退回上一个岔口换条没扫过的路继续——
> 全部扫完后，账本倒过来读就是一条完整路线。
> **当前弧 = 扫雪车的「进度条」：扫过的路口不再重复检查。**

## 本章难点

> **【难点】** **当前弧优化的引用语义。**
> `for (int &e = cur[u]; e; e = nxt[e])`——**e 是 cur[u] 本尊**：
> 每次推进 e 同时更新 cur[u]，下次回到 u 直接从上次位置继续。
> 少一个 `&`，每回到该点都从头扫已用边，O(n + m) 退化成 O(n × m)——
> **一个字符的复杂度差距**。

> **【难点】** **无向边配对的三件套**。
> ① 边编号**从 1 起**（tot 初值 1）；② 成对加边（e 与 e^1 相邻）；
> ③ 判重用 `used[e >> 1]`（同一无向边的两个方向共用一条「账」）。
> 三件缺一：从 0 起编号会让 `id>>1` 把两条不同边配成一对——**必须成套使用**。

---

## 本章易错点

> **【头号易错】** **无「当前弧优化」的朴素 DFS 是 O(n × m)**——
> 每回到一个点都从头扫已用边；`for (int &e = cur[u])` 一个引用符号决定生死。

> **【易错】** **无向图边编号从 1 起才能用 `id >> 1` 配对**（从 0 起会错判）。

> **【易错】** **孤立点不影响欧拉性**（连通性判定要排除孤立点）；
> 输出的是**边的顺序**还是点序列按题面。

> **【易错】** **递归深度可达 m**——扩栈或改迭代版（与 DFS 篇同一工程纪律）。

> **【易错】** **混合图硬写 DFS**——需网络流定向，超出本阶段；先识别题型再决定投入。

## 典型例题

### 例 1　无向图欧拉回路（模板）　难度：模板题

**题干摘要**：n ≤ 10⁵、m ≤ 2×10⁵ 无向图，判断是否存在欧拉回路并输出一条（边编号序列）。
**题源**：同类真源见配套练习 T1（P2731 骑马修栅栏）
**涉及知识点**：知识点 1、2、3

**解题思路**：

1. **信号**：「每条边恰好一次」→ 判定表 + Hierholzer。
2. **方法**：核心模板 + 判定（连通 + 无奇度点）+ 起点任取非孤立点。

**复杂度**：O(n + m)。

> **【易错】** 先判定后构造（奇度点存在直接退出）；递归深度可达 m，
> 需手动扩栈或改迭代版。

### 例 2　有向图欧拉路径　难度：变式题

**题干摘要**：有向图判断欧拉路径存在性并输出。
**题源**：有向欧拉经典（判定表第二行直接适用）
**涉及知识点**：知识点 1、5

**解题思路**：

1. **信号**：「有向 + 每边一遍」→ 按有向判定表数「出度−入度 = 1」与
   「入度−出度 = 1」的点各恰一个。
2. **方法**：起点即「出超」点；同模板跑（无需 used 成对处理，`id` 直接用）。

**复杂度**：O(n + m)。

> **【易错】** 混合图（有向 + 无向边）需要网络流定方向，超出本阶段——
> 先识别题型再决定投入。

## 本章总结

### 核心内容（一页纸）

1. **判定表 4 行背死**：无向（全偶 / 恰 0 或 2 奇）、有向（平衡 / 恰一出超一入超）。
2. **判定优先于构造**——奇度点不对直接退出，别浪费 DFS。
3. **Hierholzer**：递归走边、回溯压栈，栈逆序即路径。
4. **当前弧 `int &e = cur[u]`**：一个引用符号 = O(n+m) vs O(n×m)。
5. **无向配对三件套**：从 1 起编号 + 成对加边 + `used[e>>1]`——缺一即错。
6. **孤立点不影响欧拉性**；连通判定排除孤立点。
7. **字典序最小**：可行起点取最小 + 邻边按字典序（T1 / T2 同款）。
8. **欧拉管边、哈密顿管点**——一字之差 NP 之别。
9. **混合图止步**：需要网络流定向，识别即止。
10. **阶段 5 收官**：建图 → 最短路 → 生成树 → 拓扑 → 欧拉，图论主体闭环。
