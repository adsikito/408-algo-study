## 本章地图

本章解决一个问题：**「n 个点用 n−1 条边连通，权和怎么最小？」**

```text
生成树 = 连通 + 无环 + n−1 条边
   ↓
Kruskal：边按权升序 → 逐条尝试 → 并查集判环（同根舍）★ 默认
   ├─ picked < n−1 ⇔ 图不连通（必判！）
   └─ 复杂度 O(m log m + m α(n))（排序主导）
   ↓
MST 性质（知识点 2）：
   ├─ 权值和唯一（即使树不唯一）
   └─ 非树边 e：e 的权 ≥ 树上 u→v 路径的最大边
   ↓
性质应用：瓶颈路（知识点 3）· 次小生成树（知识点 4）
   ↓
Prim：逐点长树（low = 到树的最短距离），稠密图 O(n²) / 堆版 O(m log n)
```

**为什么这条路径是这样**：Kruskal 与 Prim 是同一贪心的两个方向——
**Kruskal 全局选最小边（边视角）**，**Prim 局部向最近点生长（点视角）**。
竞赛默认 Kruskal（并查集判环比 Prim 的维护便宜）；Prim 的价值在稠密图与考研手算对照。

## 核心概念与模板

**是什么**：带权连通无向图中权和最小的生成树。

**为什么**：竞赛侧默认 **Kruskal**（排序 + 并查集，O(m log m)）——
代码短、思想清晰、可扩展（瓶颈 MST、最小生成树唯一性）；
Prim（O(n²) 矩阵版 / O(m log n) 堆版）在稠密图更优。
MST 性质：权值和唯一；权互不相同时树唯一。

> **【规律】** **「同集合舍边 = 判环」**：并查集已同根的边加入必成环——
> 这一行同时是 Kruskal 的正确性核心与 03 篇 unite 返回 bool 的经典用场。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
typedef long long ll;
const int N = 5005, M = 200005;

int fa[N], sz[N];
int find(int x) { while (fa[x] != x) x = fa[x] = fa[fa[x]]; return x; }

struct Edge {
    int u, v, w;
    bool operator<(const Edge& o) const { return w < o.w; }
} e[M];

/* Kruskal：返回 MST 权和与是否连通 */
pair<ll, bool> kruskal(int n, int m) {
    for (int i = 1; i <= n; i++) { fa[i] = i; sz[i] = 1; }
    sort(e, e + m);                       /* 按权升序 */
    ll total = 0;
    int picked = 0;
    for (int i = 0; i < m && picked < n - 1; i++) {
        int ra = find(e[i].u), rb = find(e[i].v);
        if (ra == rb) continue;           /* 同集合：成环，舍 */
        if (sz[ra] < sz[rb]) { int t = ra; ra = rb; rb = t; }
        fa[rb] = ra; sz[ra] += sz[rb];
        total += e[i].w;
        picked++;
    }
    return {total, picked == n - 1};      /* 图不连通时 picked < n-1 */
}

/* Prim 堆优化版（稠密图可换 O(n^2) 矩阵版，见考研 5-5） */
```

> **【类比】** Kruskal 像**修路的招标**：所有工程按报价从低到高开标，
> **凡是「两端已经通车」的工程直接作废**（修了也是环路）——
> 最后连起来的 n−1 条就是最便宜的连通方案。
> Prim 则像**城市扩张**：从一座城出发，每次把「离已连通区最近」的新城并进来。

## 本章难点

> **【难点】** **MST 环性质与它的两个应用。**
> 「非树边 e 的权 ≥ 树上 u→v 路径的最大边」——这条性质一步推出：
> ① **最小瓶颈路** = MST 上路径最大边（不用逐对 BFS）；
> ② **次小生成树** = 枚举非树边替换环上最大树边（严格 / 非严格按题面）。
> **论证（交换法）：把 e 放进树成环、去掉环上最大树边，权和不变差。**

> **【难点】** **连通性判定的位置。**
> Kruskal 循环条件 `picked < n−1` 本身就完成了「提前停止」，
> 但**循环结束后必须再看 picked**——`picked < n−1` ⇒ 图不连通 ⇒ 无解（输出 orz / −1）。
> 漏判会输出「部分图的 MST 权」——一个看似合理的错误数字。

---

## 本章易错点

> **【头号易错】** **图不连通的判定漏做**：Kruskal 结束后 `picked < n−1` 就是无解——
> 只输出权和会答出错误数字。

> **【易错】** **边排序比较函数写成 `<=`**（严格弱序要求 `<`）。

> **【易错】** **并查集忘初始化**（多组数据 / 复用数组）。

> **【易错】** **Prim 的 low 数组语义混用**：是「到**树**的最短距离」，
> 不是「到起点的」——手算与代码都要盯紧。

> **【易错】** **生成森林变体**（k 个连通块）：取前 n−k 条边，**不是 k 条**。

## 典型例题

### 例 1　最小生成树模板（Kruskal）　难度：模板题

**题干摘要**：n ≤ 5×10³、m ≤ 2×10⁵，求 MST 权和；不连通输出 "orz"。
**题源**：同类真源见配套练习 T1（P3366）
**涉及知识点**：知识点 1

**解题思路**：

1. **信号**：「连通 + 最小代价」→ Kruskal。
2. **方法**：核心模板 + 连通性判定。

**复杂度**：O(m log m + m α(n))。

> **【易错】** 排序主导复杂度；并查集路径压缩 + 按大小合并（阶段 3 模板原样复用）。

---

### 例 2　拆边与森林（算术变体）　难度：变式题

**题干摘要**：①「拆掉多余网线使任意两点恰一条路径，拆的总长最小」；②「把 n 点图变成 k 个连通块，加边代价最小」。
**题源**：同类真源见配套练习 T3（P2820 局域网）、T4（P1195 口袋的天空之树）
**涉及知识点**：知识点 1、2

**解题思路**：

1. **信号①**：「恰一条路径」= 生成树 → 拆边总长 = 总权 − MST 权。
2. **信号②**：「k 个连通块」= 生成森林 → Kruskal 只取前 n−k 条边。
3. **方法**：模板原样，改「取多少条边」与「答案算式」。

**复杂度**：O(m log m)。

> **【易错】** ① 的答案是「总权 − MST」不是 MST；② 的边数是 **n − k**
> 不是 k——两个算术细节各值一次 WA。

## 本章总结

### 核心内容（一页纸）

1. **竞赛默认 Kruskal**：排序 + 并查集，O(m log m)——代码短、可扩展。
2. **「同集合舍边 = 判环」**：并查集 unite 返回 bool 的经典用场。
3. **连通必判**：循环后 picked < n−1 ⇒ 无解（orz / −1）。
4. **MST 权和唯一**（树可不唯一）；权互异则树唯一。
5. **环性质**：非树边权 ≥ 树上路径最大边——瓶颈路与次小树的共同来源。
6. **拆边 = 总权 − MST**（T3）；**k 个连通块 = 取前 n−k 条边**（T4）。
7. **Prim 两版**：O(n²) 稠密（考研手算对照）/ 堆版 O(m log n)；low = 到树的最短距离。
8. **严格弱序**：边排序比较器用 `<`。
9. **多组数据重置 fa / sz / cnt**。
10. **MST 题考读题不考算法**——算法式不变，算式随题面变。
