> 课件来源：`21.最短路算法题目选讲.pptx`
>
> 例题代码：`例题代码/P8802.cpp`（洛谷 P8802 [蓝桥杯2022 国B] 出差：边权重构）、`例题代码/P1462.cpp`（洛谷 P1462 通往奥格瑞玛的道路：二分答案 + check 跑最短路）

## 🗺️ 本章地图

模板都会了，比赛题却不会"裸考"模板——本章用两道真题示范图论题最常见的**两种变形方向**。方向一：**改边权**——P8802 把"每个城市的隔离时间"（点权）揉进边权 `w+c[v]`，输出时把终点那份减回去；方向二：**改问法**——P1462 问"经过城市收费的最大值最小是多少"，这是**最小化最大值**，用二分答案 + check() 里跑"受限最短路"判定。全章主线一句话：**图论题 = 识别模型 → 做一点变形 → 套模板**。工程细节三连：无向图链式前向星开两倍空间、终点特殊处理、先特判再二分。

## 📌 本章重点

⭐ **选型总表**（五算法复杂度+适用）与口诀：权值非负 → 堆优 Dijkstra（或 SPFA）；有负边权 → SPFA
⭐ **P8802 边权重构**：`add(u,v,w+c[v])` 把"进入 v 的隔离时间"算进边权；输出 `dis[n]-c[n]`（N 点不隔离）
⭐ **P1462 最小化最大值**：二分"允许的最大收费 mid"，check = 跑 Dijkstra（`f[v]<=mid` 才能走），可行条件 `dis[n]<=b`
⭐ **二分前先特判**：先用 maxx=∞ 判 1→n 是否连通，不通直接输出 AFK
⭐ **工程细节**：无向图边数组开 2m（课件注释"开双倍空间"）；去自环（u==v continue）

## 🔥 本章难点

🔥 **二分的单调性**：收费上限 mid 放得越宽，能走的城市越多、血量越安全——check(mid) 随 mid 单调可二分，这是"最大值最小"类题的通行证
🔥 **边权重构的正确性**：隔离时间按"进入该城一次"收一次，挂在**入边**上不重不漏（进城有几条路就各背一次，最短路自动选总账最小的）；终点免隔离 → 最后减 c[n]

## ⚠️ 本章易错点

⚠️ **P8802 忘减 c[n]**：题目明说"到达 N 不需要隔离"；且加对方向——u→v 的边加 c[v]（到达点的），加成 c[u] 直接错
⚠️ **无向图忘开双倍边数组**：每条路正反两条边，e[] 按 m 开会越界
⚠️ **P1462 check 漏判**：①起点城市也收费——`maxx<f[s]` 直接 return 0；②血量判断——返回 `dis[n]<=b`（≤0 算死，边界是扣光）
⚠️ **二分初值与记录**：l=最小收费、r=最大收费（课件取 f 数组的 min/max），别从 0/inf 乱设；check 成功时 `ans=mid; r=mid-1`，失败 `l=mid+1`
⚠️ **可达性先判**：先跑一次 `Dijkstra(1, 0x3f3f3f3f)`（上限无穷大），走不到 n 输出 AFK，否则二分无意义

## 📖 知识点讲解

### 1. 选型总表与"模板变形"方法论

**是什么**：白话——最短路题分三步做：认出"这是单源最短路"、看出"题目改了什么"、把改动揉进模板。严格说：先按数据范围与正负性选算法（下表），再识别变形类型（改边权 / 改约束 / 改问法）。

**为什么**：五算法能力边界（第 19~20 章结论）决定了选型上限——负边权只能 Ford/SPFA，非负用堆优 Dijkstra 最稳；而所有变形题最终都要落回"一张图 + 一次最短路"的骨架。

**怎么用**——课件原表（做题先对照）：

| 算法 | 复杂度 | 单源/多源 | 负边权 | 负权回路 |
|---|---|---|---|---|
| Floyd | O(n³) | 多源 | 可以 | 不可以 |
| Dijkstra（堆优） | O((n+m)log n) | 单源 | 不可以 | 不可以 |
| Bellman-Ford | O(nm) | 单源 | 可以 | 可判定 |
| SPFA | 玄学 | 单源 | 可以 | 可判定 |

> ⚠️ 注意事项：P8802 数据很小，课件明说 Dijkstra 与 SPFA 都能过——但写题仍按标准姿势选堆优 Dijkstra 养成习惯。

> 🎯 规律：题面"最短时间/最小花费"→ 最短路；"最大值最小/最小值最大"→ 二分 + 最短路 check；"到每点的额外代价"→ 点权揉边权。

> 💡 一句话总结：认模型，做变形，套模板。

### 2. P8802 出差：把点权揉进边权

**是什么**：白话——进城要隔离，那就把"隔离时间"算进"进城的路上"。严格说：边 <u,v> 的真实代价 = 交通时间 w + 到达城市 v 的隔离时间 c[v]；建无向图时两条边各背各自到达点的隔离：`add(u,v,w+c[v]); add(v,u,w+c[u])`。跑 1 号点到 n 号点的堆优 Dijkstra，最后输出 `dis[n]-c[n]`（N 点不隔离）。

**为什么**：点权不好直接进最短路模板（模板只会加边权），但"到达该点的开销"天然属于"进入该点的那条边"——揉进边权后模板零修改；唯一例外是终点不隔离，用减法还原。

**怎么用**——关键代码（忠实课件 `P8802.cpp`）：
```cpp
// 建图：无向图，正反边的权各加"到达点"的隔离时间
for(int i=1;i<=m;i++){
  scanf("%d %d %d",&u,&v,&w);
  add(u, v, w + c[v]);    // 进 v 要隔离
  add(v, u, w + c[u]);    // 进 u 要隔离
}
Dijkstra(1);
printf("%d\n", dis[n] - c[n]);   // 终点 N 不隔离，减回去
```

**跟着算**（3 城小例）：c=[2,10,20]（城市 1/2/3 的隔离时间），两条路：1-2 w5、2-3 w7。重构边权：1→2 为 5+10=15，2→1 为 5+2=7；2→3 为 7+20=27，3→2 为 7+10=17。从 1 跑 Dijkstra：dis₂=15，dis₃=15+27=42。输出 dis₃−c₃=42−20=**22**。手账验证：路 5 + 隔离 10 + 路 7 = 22 ✓（起点与终点的隔离都不算）。

> ⚠️ 注意事项：dis 初值用 `memset(dis,0x3f,...)` 时，比较 `dis[u]+w` 前确认不溢出（本题数据小无虞）；图是无向图——`e[]` 开 2 倍空间。

> 🎯 规律：点权型最短路 = "边权 += 到达点的点权 + 终点补偿"；常见变体：进城费、过路关卡时间。

> 💡 一句话总结：点权挂入边，终点减回去。

### 3. P1462 通往奥格瑞玛的道路：二分答案 + check 最短路

**是什么**：白话——带血条闯关：每座城收一次费、每条路扣一次血，问"路上被收的最高单笔费用"最小能压到多少，且总扣血不能掏空 b。严格说：**最小化最大值 → 二分答案**。二分收费上限 mid，check(mid)：只允许走进收费 ≤ mid 的城市跑 Dijkstra，看 `dis[n]≤b`（活着到达）是否成立。

**为什么**：mid 越大，允许走的城市越多、绕路余地越大、血量越安全——check 随 mid **单调**，可二分；而"最高单笔费用"无法用一次普通最短路直接最小化，二分把它变成"可行性判定"。

**怎么用**——关键代码（忠实课件 `P1462.cpp`）：
```cpp
bool Dijkstra(int s,int maxx)          // maxx：本题允许的最大收费
{
  if(maxx < f[s]) return 0;            // 起点城市也收费，进不去就别跑了
  memset(dis,0x3f,sizeof(dis));
  memset(flag,0,sizeof(flag));
  dis[s]=0;  q.push({0,s});
  while(!q.empty())
  {
    ... u=堆顶点; if(flag[u])continue; flag[u]=1;
    for(int i=h[u];i!=-1;i=e[i].next)
    {
      v=e[i].to;  w=e[i].w;
      if(f[v]<=maxx && dis[v]>dis[u]+w)   // 收费超标的城：此路不通
      {
        dis[v]=dis[u]+w;
        q.push({dis[v],v});
      }
    }
  }
  return dis[n]<=b;                    // 活着（血没扣光）才算可达
}
int main(){
  ... 先判连通：Dijkstra(1, 0x3f3f3f3f) 为假 → 输出 "AFK"
  l=min(f[i]);  r=max(f[i]);           // 二分区间 = 收费的 [min, max]
  while(l<=r){
    mid=(l+r)/2;
    if(Dijkstra(1,mid)) { ans=mid; r=mid-1; }   // 可行，压低上限
    else l=mid+1;                                // 不可行，放宽上限
  }
  printf("%d\n",ans);
}
```

**跟着算**（4 城小例）：b=10，收费 f=[3,5,2,4]（城市 1..4），无向路：1-2 w1、2-3 w1、3-4 w1、1-4 w10。先特判 maxx=∞：1→4 可达（不 AFK）。二分：

| l | r | mid | check(mid) 过程 | 动作 |
|---|---|---|---|---|
| 2 | 5 | 3 | 收费≤3 的城只有 {1,3}，2、4 全被挡 → 4 不可达 → 0 | l=4 |
| 4 | 5 | 4 | 可走 {1,3,4}，直连 1→4：dis₄=10 ≤ b=10 → 1 | ans=4，r=3 |
| 4 | 3 | — | l>r 结束 | 输出 4 |

验证：答案 4 恰是路径 1→4 上城市收费的最大值 max(3,4)=4 ✓（绕 1-2-3-4 的最大收费是 5，更差）。

> ⚠️ 注意事项：check 里的堆优 Dijkstra 每次都要重置 dis 和 flag（课件 memset 两连）；去自环（`if(u==v)continue`）；答案 ans 在"可行"分支里记录。

> 🎯 规律："最小化最大值 / 最大化最小值" → 二分答案 + check；check 内部往往是"加一个限制条件的模板跑一遍"。

> 💡 一句话总结：最大值最小，二分套最短路。

## 🔍 相似概念辨析

**组1：边权变形（P8802） vs 过滤变形（P1462）——处理点权的两条路**

| 对比维度 | 边权变形（P8802） | 过滤变形（P1462） |
|---|---|---|
| 各自定义 | 把点权加进边权 w+c[v] 一起最短路 | 点权当门槛：f[v]≤mid 才允许经过 |
| 核心区别 | 点权参与"求和" | 点权参与"筛点" |
| 各自特点 | 模板零修改，终点做减法补偿 | 模板加一个 if，外面套二分 |
| 使用场景 | 进城费/隔离时间按次累计 | 瓶颈限制（最大收费/最大承重） |
| 典型示例 | dis[n]-c[n] 收尾 | check(mid) 返回 dis[n]<=b |
| 记忆口诀 | 点权要累计，揉进边权里；点权当门槛，二分加筛选 |

**组2：最小化最大值 vs 最大化最小值（二分答案两兄弟）**

| 对比维度 | 最小化最大值 | 最大化最小值 |
|---|---|---|
| 各自定义 | 令"路径上最难的一步"尽量小 | 令"最弱的一环"尽量大 |
| 核心区别 | 问"上限最低多少" | 问"下限最高多少" |
| 各自特点 | check(小)难 check(大)易，可行则 r=mid-1 | check(小)易 check(大)难，可行则 l=mid |
| 使用场景 | P1462 收费、路径最大坡度最小 | 跳石头最短跳跃最大（P2678） |
| 典型示例 | ans 在可行分支记录 | ans 在可行分支记录，方向相反 |
| 记忆口诀 | 越松越易过，二分找临界 |

**组3：先特判 vs 直接二分**

| 对比维度 | 先特判可达性 | 直接进二分 |
|---|---|---|
| 各自定义 | 先用 maxx=∞ 跑一次 check 确认连通 | 跳过特判直接二分 [l,r] |
| 核心区别 | 多一次 O(一次最短路) | 少一次跑图 |
| 各自特点 | 彻底排除"AFK"输出分支 | 若完全不可达，二分可能输出错误 l 值 |
| 使用场景 | "到不了输出 -1/AFK"类题 | 保证连通的题可省 |
| 典型示例 | P1462 先判 1→n 连通 | 模板题默认连通 |
| 记忆口诀 | 先问通不通，再问多便宜 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**模板只有"图 + 单源最短路"一个骨架（静态）→ 考题靠"变形"拉开差距（动态）→ 变形方向一：改图的边（P8802 点权揉边权，终点减回去）→ 变形方向二：改问的量（P1462 最大值最小 → 二分 + check 受限最短路）→ 工程兜底：开 2m、去自环、先特判、long long（细节）**。两道题共享同一个心法：**题目多给的每个条件，要么变成边权，要么变成 check 里的一个 if。**

跨知识点共性：
1. **与第 4 章二分呼应**：二分答案 = 二分"答案值域"，check 是"判定函数"——和二分查找里"二分下标"同思想不同对象。
2. **与第 20 章直接衔接**：两题的 check/Dijkstra 就是上一章堆优化模板原样搬运，只加了限制 if。
3. **向后铺垫**：二分 + 图论判定会在最小生成树（P1991 取第 k 大边）等题里再次出现。

## 📋 速查表

| 题目 | 变形 | 核心 one-liner | 易忘点 |
|---|---|---|---|
| P8802 出差 | 点权揉边权 | add(u,v,w+c[v])；输出 dis[n]-c[n] | 终点免隔离；无向图开 2m |
| P1462 奥格瑞玛 | 二分 + check | f[v]<=maxx 才松弛；return dis[n]<=b | 特判起点收费、AFK、去自环 |
| 选型 | — | 非负→堆优 Dijkstra；负权→SPFA | 见负权别硬上 Dijkstra |

```cpp
// 二分答案 + check 骨架（默写级）
int l = min_val, r = max_val, ans = -1;
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) { ans = mid; r = mid - 1; }  // 最小化最大值
    else l = mid + 1;
}
```

★ **跟算**：对 3 城（隔离时间 c=[3,6,9]）、两条路 1-2 w4、2-3 w5，手工列出 4 条重构后的边权，算出 1→3 的最短总时间与最终输出。
提示：每条边的权加"到达点"的隔离；最后减 c[3]；答案应等于 4+6+5=15。

★★ **洛谷 P1396 营救**：n 个点 m 条无向路每条有"拥挤度"，求从 s 到 t 路上拥挤度最大值的最小可能。
提示：又是"最大值最小"——二分拥挤度 + check 跑连通性/BFS，或想想 Kruskal 按序加边到 s、t 连通时最后一条边的权（两种都写写更妙）。

★★★ **力扣 1631. 最小体力消耗路径**：二维网格每格有高度，从左上走到右下，求路径上相邻格高度差绝对值的最大值的最小值。
提示：把"相邻格连边、权=高度差"建图，就是"路径最大边权最小"——二分 + BFS check（或直接堆优 Dijkstra 换松弛式 dis[v]=min(dis[v], max(dis[u],w))）。

★★★★ **洛谷 P1948 [USACO08JAN] Telephone Lines S**：n 个电线杆 m 条线，可以免费 k 条线，求 1→n 路径上最贵的付费线路最小是多少。
提示：二分答案 mid + check：权 ≤ mid 的边当 0 走、超标的当 1 走，跑最短路看"1 的个数"能否 ≤ k；也可以分层图做——两解对照 P4568 与本章 check 思想。
