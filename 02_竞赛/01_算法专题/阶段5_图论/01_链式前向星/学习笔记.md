## 第十八章：图的存储之链式前向星

> 课件来源：`18.图的存储之链式前向星.pptx`
>
> 例题代码：`课上代码/链式前向星.cpp`（4 顶点 5 条边带权无向图：建图 + DFS 遍历，文末附 vector 存无权图版本）

## 🗺️ 本章地图

本章解决一个问题：图怎么存进数组，才能又省空间、又能快速枚举一个点的所有出边？路线是"存图五大家族 → 锁定刷题双雄 → 手搓静态邻接表"：《数据结构》的 5 种存图方式里，邻接矩阵省事但 O(n²) 空间，真指针邻接表易踩空指针/野指针；刷题的答案是**邻接矩阵**（点少边稠）与**链式前向星**（用数组模拟链表的邻接表，存图逻辑不变、实现去指针化）。本章用 4 顶点 5 条边的小图逐边演示 head/edge 数组每一步怎么变——它是第 19~23 章所有图论模板的第一行代码。

## 📌 本章重点

⭐ **存图选型**：邻接矩阵（空间 O(n²)、O(1) 查边）适合点少边稠；链式前向星（空间 O(n+m)）适合稀疏大图，是刷题默认存图法
⭐ **链式前向星两大数组**：边集数组 e[i]（to 终点 / w 权值 / next 同起点的下一条边的编号）+ 头结点数组 head[x]（x 的第一条出边下标，初始全部 -1）
⭐ **头插法加边三行**：`e[cnt].to=y; e[cnt].next=head[x]; head[x]=cnt++;`
⭐ **无向图对称加边**：add(x,y,w) 后再 add(y,x,w)，边数组开 2m
⭐ **遍历出边骨架**：`for(int i=head[x]; i!=-1; i=e[i].next)`，y=e[i].to 即邻接点

## 🔥 本章难点

🔥 **头插法导致链表逆序**：head[x] 永远指向"最后输入的那条边"，链上边的顺序与输入顺序恰好相反，画图、调试、控制访问顺序都要按这个逆序来
🔥 **next 的语义**：它不是内存指针，而是"同起点的下一条边在 e[] 中的下标"——静态链表用下标模拟指针，避开了真指针的空指针/野指针 bug，但新手容易把 i=e[i].next 写成 i++

## ⚠️ 本章易错点

⚠️ **head 忘初始化为 -1**：建图前必须 `memset(head,-1,sizeof(head))`，否则 head 里是随机值，遍历会从"垃圾边"开始甚至死循环
⚠️ **无向图忘加反向边 / 忘开双倍空间**：输入 m 条 = 存储 2m 条，e[] 按 m 开直接越界
⚠️ **遍历写成 i++**：链是靠 next 下标串的，必须 `i=e[i].next` 沿链跳；i++ 会跳到毫不相干的边
⚠️ **判断链尾的条件看 cnt 起点**：课件 cnt 从 0 开始，用 `i!=-1`（或 `~i`）判尾；若 cnt 从 1 开始则 head 初值是 0，要写 `i!=0`
⚠️ **邻接表数组形态与邻接矩阵混淆**：a[x][i]=y 是"顶点 x 的第 i 个邻接点是 y"（邻接表），g[x][y]=w 才是邻接矩阵，下标含义完全不同

## 📖 知识点讲解

### 1. 五种存图方式与刷题选型

**是什么**：白话——把"点和边的关系"塞进内存的五种办法。严格说：《数据结构》涉及 5 种存图方式——**邻接矩阵、邻接表、十字链表、多重邻接表、边集数组**。其中刷题常用的是邻接矩阵和邻接表变形（链式前向星）；邻接矩阵与边集数组本身基于数组，照课上实现即可。

**为什么**：邻接表、十字链表、多重邻接表基于链表实现，涉及指针指向，代码操作复杂，且容易出现空指针、野指针 bug——所以需要对邻接表的代码实现进行改进（**理论（存图逻辑）不变，实现去指针化**），这就是本章链式前向星的由来。

**怎么用**（选型速查）：

| 场景 | 推荐 | 理由 |
|---|---|---|
| 点少（n≤几千）且要 O(1) 查任意边 | 邻接矩阵 g[x][y]=w | 直接下标访问 |
| 无权图、随手写 | vector 二维数组 g[x] | a[x][i]=y：x 的第 i 个邻接点（注意与邻接矩阵区分） |
| 带权图 + 快速枚举出边（最短路/拓扑/MST） | 链式前向星 | O(n+m) 空间，遍历出边只花 O(出边数) |

> ⚠️ 注意事项：无权图也可直接把邻接表转成二维数组 a[x][i]=y；最短路等带权场景几乎只有链式前向星和矩阵两个选项。

> 🎯 规律：竞赛绝大多数图论题用链式前向星（或 vector）；矩阵只在 Floyd、传递闭包、稠密图 Prim 里出场。

> 💡 一句话总结：矩阵查边快，前向星省空间。

### 2. 链式前向星的结构：两个数组

**是什么**：白话——给每个点挂一条"以它为起点的边"串成的链，链头记在 head 里。严格说：链式前向星 = **边集数组 + 邻接表逻辑相结合**的静态链表。①边集数组 e[]：e[i] 存第 i 条边的 to（该边的终点）、w（该边的权值）、next（**和该边同起点的另一条边的下标**，不再是指针）；②头结点数组 head[]：head[x] 存以 x 为起点的**第一条边**的下标（即 e[] 中的下标），初始全部 -1（表示没有边）。head[x]=2 表示 edge[2] 是 x 的一条出边；head[x]=-1 表示 x 暂无出边。

**为什么**：邻接表的本质是"顶点数组 + 每个顶点的所有邻接点构成一个链表挂在后面"。真链表要 malloc/new、要管指针；换成数组后"链"由 next 下标串、"表头"由 head 记——逻辑一模一样，代码全是数组操作，快、稳、好写。

**怎么用**——结构定义（忠实课件 `链式前向星.cpp`）：
```cpp
int n,m;
int head[105];               // head[x]：x 的第一条出边的下标
struct edge{
  int to;    // 该边的终点
  int w;     // 该边的权值
  int net;   // 和该边同起点的另一条边的下标
}e[10005];   // 无向图按 2m 开（也可拆成 to[]/w[]/net[] 三个数组）
int cnt=0;   // 边计数器 = 下一条新边的下标
```

> ⚠️ 注意事项：课件成员名叫 net，与常见写法 next 等价，两套命名都要能读懂。

> 🎯 规律：静态链表三件套——数据数组 + "下一条"下标 + 表头数组；链表的一切操作都翻译成下标赋值。

> 💡 一句话总结：head 记表头，next 串同源边。

### 3. 头插法建图：4 顶点 5 条边逐步跟算

**是什么**：白话——新边插到链的最前面（插队到队头），O(1) 完事。严格说：加边 <x,y,w> 时创建 e[cnt]，令 `e[cnt].next=head[x]`（新边接住旧链头），再 `head[x]=cnt`（x 的链头换成新边），最后 cnt++。这就是模拟链表的头插法。

**为什么**：头插不用走到链尾，加边 O(1)；代价是链上边顺序与输入顺序相反。

**怎么用**——加边模板（无向图正反各一次，忠实课件）：
```cpp
void add(int x,int y,int wi)   // x --wi--> y
{
  e[cnt].to=y;
  e[cnt].w=wi;
  e[cnt].net=head[x];   // 模拟链表的头插法
  head[x]=cnt;
  cnt++;                // 下一条边的下标
}
// 建图：
memset(head,-1,sizeof(head));
for(int i=1;i<=m;i++){ cin>>x>>y>>wi; add(x,y,wi); add(y,x,wi); }
```

**跟着算**（课件同款样例）：4 个顶点，依次输入 5 条无向边：`1 2 5`、`1 4 3`、`2 3 8`、`2 4 12`、`3 4 9`。每条输入产生两条存储边：

| 输入 | 动作 | next 取值 | head 变化 | cnt |
|---|---|---|---|---|
| 1 2 5 | e[0]:1→2；e[1]:2→1 | e[0].net=-1；e[1].net=-1 | head[1]=0；head[2]=1 | 2 |
| 1 4 3 | e[2]:1→4；e[3]:4→1 | e[2].net=0；e[3].net=-1 | head[1]=2；head[4]=3 | 4 |
| 2 3 8 | e[4]:2→3；e[5]:3→2 | e[4].net=1；e[5].net=-1 | head[2]=4；head[3]=5 | 6 |
| 2 4 12 | e[6]:2→4；e[7]:4→2 | e[6].net=4；e[7].net=3 | head[2]=6；head[4]=7 | 8 |
| 3 4 9 | e[8]:3→4；e[9]:4→3 | e[8].net=5；e[9].net=7 | head[3]=8；head[4]=9 | 10 |

建完后从 head 出发沿 next 走（到 -1 停），得到每个点的邻接链：
- 1：e[2](→4,w3) → e[0](→2,w5)
- 2：e[6](→4,w12) → e[4](→3,w8) → e[1](→1,w5)
- 3：e[8](→4,w9) → e[5](→2,w8)
- 4：e[9](→3,w9) → e[7](→2,w12) → e[3](→1,w3)

每条链都是输入的**逆序**——对比邻接表可以发现：链式前向星实际上是用静态链表实现的邻接表，建图过程就是模拟头插法；图中虚线箭头只表示链接关系，不是指针。

> ⚠️ 注意事项：无向图每条输入都要 add 两次；对照上表检查"反向边的 next 是不是也接对了 head[y]"。

> 🎯 规律：head 是"最新头条"，next 是"上一条同源边"——链表天然倒序。

> 💡 一句话总结：新边插队头，cnt 步步加一。

### 4. 遍历出边与例题：建图后 DFS

**是什么**：白话——从 head[x] 进链、沿 next 走到 -1，就把 x 的所有出边看了一遍。例题（课上代码）：建立上面的带权无向图后，从每个未访问点出发 DFS 并输出访问序列。

**为什么**：后面最短路（松弛）、拓扑（减入度）、MST（松弛）全靠这一个循环枚举出边——它是图论代码里出现频率最高的一行，必须形成肌肉记忆。

**怎么用**——例题关键代码（忠实课件）：
```cpp
int v[105];
void dfs(int x)
{
  if(v[x]) return;
  printf("%d ",x);
  v[x]=1;
  int y;
  for(int i=head[x]; i!=-1; i=e[i].net)  // 枚举x所有的出边，找x的邻接点
  {
    y=e[i].to;
    dfs(y);
  }
}
int main(){
  memset(head,-1,sizeof(head));
  cin>>n>>m;
  for(int i=1;i<=m;i++){ cin>>x>>y>>wi; add(x,y,wi); add(y,x,wi); }
  for(int i=1;i<=n;i++) if(v[i]==0) dfs(i);  // 非连通图每个连通块都要跑
}
```
**跟算**（用知识点 3 的图）：dfs(1)：输出 1 → head[1]=2，先访问 e[2].to=4：输出 4 → head[4]=9，先访问 e[9].to=3：输出 3 → head[3]=8 先看 e[8].to=4（已访问），再看 e[5].to=2：输出 2 → 2 的出边全部已访问 → 逐层回溯结束。输出 **1 4 3 2**（顺序由"链表逆序 + 先到先访"共同决定）。

> ⚠️ 注意事项：图不连通时必须 `for` 每个点尝试 DFS（课件 main 里的写法），只 dfs(1) 会漏掉其他连通块。

> 🎯 规律：所有"枚举 u 的出边"都是 `for(i=head[u]; ~i; i=e[i].next)` 一副骨架，后面的算法只是往循环体里填不同动作。

> 💡 一句话总结：进链走到 -1，出边一个不漏。

## 🔍 相似概念辨析

**组1：邻接矩阵 vs 链式前向星**

| 对比维度 | 邻接矩阵 | 链式前向星 |
|---|---|---|
| 各自定义 | n×n 二维数组，g[x][y]=w | 边集数组+head 表头，静态链表实现的邻接表 |
| 核心区别 | 空间 O(n²)，与边数无关 | 空间 O(n+m)（无向图 2m），按边存 |
| 各自特点 | O(1) 查任意边；枚举邻居扫整行 O(n) | 枚举出边只花 O(出边数)；查任意边要顺链找 |
| 使用场景 | 稠密图、点少（Floyd、稠密 Prim） | 稀疏图、大点数（最短路/拓扑全家桶） |
| 典型示例 | n=100 完全图：10⁴ 格正好 | n=10⁵：矩阵开不下，前向星轻松 |
| 记忆口诀 | 点小边稠用矩阵，点大边稀前向星 |

**组2：vector 邻接表 vs 链式前向星**

| 对比维度 | vector 邻接表 | 链式前向星 |
|---|---|---|
| 各自定义 | vector g[x]，g[x][i]=y 存邻接点 | e[i]{to,w,next}+head[] 静态链表 |
| 核心区别 | 变长数组 push_back，天生不带权 | 纯数组预开空间，一条边一条记录 |
| 各自特点 | 代码最短，无权图首选；带权要套 pair | 带权自然（w 字段）；边有编号可反查（反向边技巧） |
| 使用场景 | 无权图遍历/BFS、建边少的题 | 最短路、网络流等需要边权与边编号的题 |
| 典型示例 | g[2].push_back(3) 存 2→3 | add(2,3,8) 存 2→3 权 8 |
| 记忆口诀 | 无权用 vector，带权用前向星 |

**组3：真指针邻接表 vs 静态链表（链式前向星）**

| 对比维度 | 真指针邻接表（数据结构课） | 链式前向星（刷题实战） |
|---|---|---|
| 各自定义 | 顶点数组+链表节点（malloc/new，next 是指针） | 数组模拟链表，next 是同起点下一条边的下标 |
| 核心区别 | 动态内存、指针操作 | 静态数组、下标操作 |
| 各自特点 | 直观但易空指针/野指针/忘释放 | 存图逻辑不变，代码稳、无内存管理 |
| 使用场景 | 《数据结构》教学、工程动态结构 | OI/刷题几乎全部图论题 |
| 典型示例 | p->next->to 访问邻居 | e[e[i].net].to 访问邻居 |
| 记忆口诀 | 指针换下标，理论不变形 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**图要进数组（需求）→ 邻接矩阵 O(n²) 装不下大图（痛点）→ 邻接表逻辑好但真指针危险（痛点）→ 用数组模拟链表 = 静态链表（方案）→ e[] 存边、head[] 存表头、头插法 O(1) 加边（实现）→ for(i=head[x];~i;i=e[i].next) 统一遍历骨架（应用）**。链式前向星是"理论（存图逻辑）不变、实现（指针→下标）改造"的典范。

跨知识点共性：
1. **与第十章链表同源**：头插法、表头 head、"顺着 next 走到空"就是链表操作，只是把指针换成下标。
2. **与第十四章并查集呼应**：都是"用数组表达动态连接关系"，一个管边、一个管点的集合。
3. **向后铺垫**：第 19~21 章最短路、第 22 章拓扑、第 23 章 Prim 的模板，全部建立在本章 add() 与遍历骨架之上——这一章不熟，后面章章卡壳。
