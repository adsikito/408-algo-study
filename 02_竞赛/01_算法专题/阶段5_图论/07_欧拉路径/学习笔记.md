## 🗺️ 本章地图

> **本章解决一个问题：能否"一笔画"不重复地走完所有边？怎么把这条路线打印出来？**
> 路线是"概念 → 判定 → 求解 → 真题"：先分清欧拉路径/欧拉回路/半欧拉图/欧拉图四个词（知识点 1）；再用**度数**判定存在性并定起点（知识点 2）；然后用 Hierholzer 算法（DFS 死路回溯入栈、倒序输出）把路径求出来，附带弧优化（知识点 3）；最后用 P2731（无向骑栅栏）和 P7771（有向字典序）收尾（知识点 4）。
> 学完自测：拿到一张图，能否 30 秒内数奇度点判定并指出起点？

## 📌 本章重点（3-5个）

⭐ **四个概念的包含关系**：欧拉回路 ⊂ 欧拉路径；欧拉图 ⊂ 半欧拉图；一笔画问题
⭐ **度数判定充要条件**：无向图奇度点 0 个=回路、2 个=路径；有向图所有点入度=出度=回路、恰一点出-入=1 且一点入-出=1=路径
⭐ **起点选择**：回路从任一点（习惯 1 号）；路径必须从"奇度点/出度大 1 的点"出发，选错路径不完整
⭐ **Hierholzer 算法**：DFS 走一条边删一条边，走投无路时才把点入栈，最后**倒序弹栈**得路径
⭐ **弧优化**：用 head[u]/del[x] 记录"访问到哪条边"，真的删除已走边，复杂度降到 O(n+m)

## 🔥 本章难点（2-3个）

🔥 **为什么必须"先 DFS 后记录答案"**：正着输出会遇到"死胡同"——某点入边被删后没有出边了，但图中还有边没走；倒序记录时保证记录该点时它的出边已全部走完
🔥 **弧优化的正确写法**：`for(i=head[u]; i!=-1; i=head[u])` 循环变量不走 next 而是**永远从 head[u] 重新开始**，删边时真的把 head[u] 前移，等价于每次只面对"还没走过的第一条边"
🔥 **有向图判定与起点的推导**：出-入=1 的点是多出去一条出边（起点），入-出=1 是终点；两类点必须各恰有一个

## ⚠️ 本章易错点（3-5个）

⚠️ **忘了判定前提是连通**：度数条件只对"非零度节点连通"的图有效；有向图还需基图连通，建议并查集先验
⚠️ **无向图删边只删了一条**：成对存储时必须 `e[i].del = e[i^1].del = true` 同时删反向边，否则会重复走
⚠️ **起点选错**：半欧拉图从非奇度点出发只能走出一部分路径；有向图要选出度-入度=1 的点
⚠️ **输出顺序搞反**：点在**回溯时入栈**，栈底是路径末端，必须从栈顶往下弹；正着输出样例都对不上
⚠️ **P7771 两连坑**：邻接表不 sort → 字典序不是最小；不写弧优化 → 已删边被反复扫描 TLE

## 📖 知识点讲解

### 1. 欧拉路径、欧拉回路与半欧拉图、欧拉图

**是什么**：**欧拉路径** = 一条不重复遍历完**所有边**的路径（像一笔画）；**欧拉回路** = 还要**回到起点**的欧拉路径，所以欧拉回路也是欧拉路径。图的层面：存在欧拉路径的图叫**半欧拉图**，存在欧拉回路的图叫**欧拉图**（欧拉图也是半欧拉图）。注意走的是"边"不重，点可以重复经过。

**为什么**：一笔画是很多实际问题的原型（扫马路、修栅栏、DNA 序列拼接），判定它只用度数，求它只用一次 DFS，是性价比极高的图论模型。

**怎么用**：做题先问三句——有向还是无向？要求路径还是要求回路？数据保证存在还是要我判定输出 No？

> ⚠️ 注意事项：孤立点不影响（判定只看非零度节点）；题目保证有解时可跳过判定（如 P2731）。

> 🎯 规律：边不重→欧拉，点不重→哈密顿，别混。
> 💡 一句话总结：一笔画完所有边，回到原点是回路。

### 2. 度数判定法与起点选择

**是什么**：一笔画时，中途每个点"进一条边、出一条边"成对消耗度数，所以度数必须是偶数；只有起点（多出去的度）和终点（多进来的度）可以是奇数。由此得到充要条件——
- **无向图**：奇度点**0 个** ⇔ 有欧拉回路；奇度点**恰 2 个** ⇔ 有欧拉路径（起点终点就是这俩）。
- **有向图**：所有点入度=出度 ⇔ 欧拉回路；恰有一个点出-入=1（起点）、一个点入-出=1（其余全相等）⇔ 欧拉路径。

**为什么**：奇度点>2 时，每经过一个奇度点就"净消耗"一条没法配对的边，一笔必然断开，所以 4 个奇度点至少要 2 笔（这正是"几笔画"问题的原理）。

**怎么用**——**跟着算**：无向图 5 个点 6 条边：(1,2)(2,3)(3,4)(4,1)(2,5)(5,4)。

| 点 | 1 | 2 | 3 | 4 | 5 |
|----|---|---|---|---|---|
| 度 | 2 | **3** | 2 | **3** | 2 |

奇度点 = {2, 4}，恰 2 个 → 半欧拉图，存在欧拉路径；**起点必须选 2 或 4**（字典序最小选 2）。一条可行路线：2→1→4→3→2→5→4，6 条边不重不漏，从 2 出发到 4 结束。

> ⚠️ 注意事项：自环给度数 +2（课件强调"一条边两端同一节点算两次"）；先数奇度点再定起点，起点错了 Hierholzer 结果不完整。

> 🎯 规律：数奇度点——0 个从 1 号跑回路，2 个从奇度点跑路径。
> 💡 一句话总结：偶度通吃，奇度只有一头一尾。

### 3. Hierholzer 算法（DFS + 倒序入栈）与弧优化

**是什么**：求欧拉路径的算法。流程：从合理起点 DFS，**每走一条边就删掉它**；当前点**没有边可走（死路）时才把它入栈**；回溯继续找别的边。全部结束后，栈从顶往下弹就是欧拉路径。本质：先找到一条子回路，再把其他回路逐步合并进来。

**为什么**：若走一条边就立刻输出当前点（正序记录），会一头栽进死胡同——终点提前出现，剩余的边没走。而"死路才入栈"意味着**入栈时该点的出边已全部走完**，最先入栈的是真终点，倒着读恰好从起点开始且衔接自然。

**怎么用**（`Hierholzer模板.cpp`，弧优化版）：
```cpp
void DFS(int u) {
    for (int i = head[u]; i != -1; i = head[u]) {   // 弧优化：每轮从head[u]重来
        if (e[i].del) { head[u] = e[i].next; continue; }  // 真删除：head前移
        e[i].del = e[i ^ 1].del = true;             // 无向边成对删（i^1是反向边）
        DFS(e[i].v);
    }
    ansv.push(u);                                   // 死路/回溯完才入栈
}
// 输出：while(!ansv.empty()){ cout<<ansv.top(); ansv.pop(); }  倒序弹栈
```
**跟着算**：5 点图，边 (1,2)(2,3)(3,1)(1,4)(4,3)，奇度点 {1,3}，从 1 出发。邻接表已排序：

| 过程 | 走的边 | 栈（底→顶） |
|------|--------|-------------|
| dfs(1)→dfs(2)→dfs(3)→dfs(1)→dfs(4)→dfs(3) | 1-2,2-3,3-1,1-4,4-3 | 空 |
| 3 号无边 → 入栈 | — | 3 |
| 依次回溯入栈 | — | 3, 4, 1, 3, 2 |
| 回到 dfs(1) 结束入栈 | — | 3, 4, 1, 3, 2, 1 |

弹栈输出：**1 2 3 1 4 3**——正好 5 条边不重不漏，从 1（起点）到 3（终点）。

> ⚠️ 注意事项：弧优化前复杂度 O(m(n+m))（死边反复扫），弧优化后 O(n+m)；P7771 用 vector 时对应写法是 `for(i=del[x]; i<g[x].size(); i=del[x]) del[x]=i+1;`。

> 🎯 规律：边随手删、点回溯记、答案倒着读。
> 💡 一句话总结：走投无路才记账，倒读即正路。

### 4. 例题：P2731 骑马修栅栏 与 P7771 有向图欧拉路径

**是什么**：**P2731**：栅栏=边、交点=点，无向连通图，题目保证有解 → 数奇度点定起点（最小奇度点，无奇度点则 1 号），数据范围小直接**邻接矩阵 + Hierholzer**，输出字典序最小的路径。**P7771**：**有向图**、**不保证有解**：先按入度出度判定（不是半欧拉图输出 No）；要求**字典序最小** → 每个点的出边 sort；数据大 → 必须**弧优化** Hierholzer（del[] 记录访问位置）。

**为什么**：这两题恰好覆盖模板的四种变体——无向/有向、保证存在/需判定、邻接矩阵/vector 邻接表。字典序最小靠"邻接表有序 + 从小起点出发"自然获得：每一步都先试小编号点。

**怎么用**（P7771 判定骨架）：
```cpp
for (i = 1; i <= n; i++)
    if (ind[i] != outd[i]) {
        flag = 0;                                   // 不是回路
        if (abs(ind[i]-outd[i]) != 1) { puts("No"); return 0; }
        if (outd[i]-ind[i] == 1) { c1++; st = i; }  // 起点
        else c0++;                                  // 终点
    }
if (flag == 0 && (c1 != 1 || c0 != 1)) { puts("No"); return 0; }
dfs(st);
```
跟着想：度检查通过后 st 若从未被更新仍是初值 1——这正是"欧拉回路从 1 号出发"的巧妙处理。

> ⚠️ 注意事项：P2731 的答案要输出点序列（交点编号）；P7771 输出 No 时注意大小写与换行格式。

> 🎯 规律：先判度、再定起点、排序保字典序、弧优化防 TLE。
> 💡 一句话总结：判定靠度数，求解靠 Hierholzer。

## 🔍 相似概念辨析

### 欧拉路径 vs 欧拉回路（半欧拉图 vs 欧拉图）

| 维度 | 欧拉路径 | 欧拉回路 |
|------|---------|---------|
| 定义 | 不重复走完所有边 | 不重复走完所有边且回到起点 |
| 图的名称 | 半欧拉图 | 欧拉图（也是半欧拉图） |
| 无向图条件 | 恰 2 个奇度点 | 0 个奇度点 |
| 有向图条件 | 一点出-入=1，一点入-出=1 | 所有点入度=出度 |
| 起点 | 必须是奇度点/出度大 1 的点 | 任意点（习惯 1 号） |
| 起终点关系 | 起点 ≠ 终点 | 起点 = 终点 |
| 典型题 | P2731、P7771 | P1341 中奇度点为 0 的情形 |

### 欧拉路径 vs 哈密顿路径

| 维度 | 欧拉路径 | 哈密顿路径 |
|------|---------|-----------|
| 不重复的对象 | **边** | **点** |
| 判定难度 | 度数判定，O(n) 充要条件 | NP 完全，无简洁充要条件 |
| 求解算法 | Hierholzer 一次 DFS | 搜索/状压 DP/随机化 |
| 复杂度 | O(n+m)（弧优化后） | 指数级或 O(n2ⁿ) |
| 起点确定 | 度数直接给出 | 需枚举/题目指定 |
| 性质直觉 | "进=出"配对守恒 | 经过点数=总点数 |
| 典型题 | P7771 | 旅行商类（如状压 DP 模板题） |

## 🧩 本章归纳：一条主线串全章

> 本章主线一句话：**"能否一笔画" → 数度数判定（无向数奇度点，有向比入出度） → 定起点（回路任选/路径选特殊点） → Hierholzer 删边 DFS、死路入栈、倒序输出**。概念上四个词两两包含；判定上度数条件是充要的、但有"非零度连通"前提；求解上唯一的精神是"先 DFS 后记录"避开死胡同，弧优化只是把"扫过死边"变成"真删边"提速。P2731 教你无向+字典序，P7771 教你有向+判定+弧优化三合一。做题口诀：一判有向无向，二判路径回路，三定起点，四选存图，五想弧优化。

## 📋 速查表

| 项目 | 无向图 | 有向图 |
|------|--------|--------|
| 欧拉回路条件 | 奇度点 0 个 | 所有点入度=出度 |
| 欧拉路径条件 | 奇度点恰 2 个 | 一点出-入=1，一点入-出=1 |
| 起点选择 | 无奇度→1 号；否则最小奇度点 | 回路→1 号；路径→出-入=1 的点 |
| 删边写法 | e[i].del = e[i^1].del = true | 只删当前边 e[i]（无反向边） |
| 弧优化（前向星） | for(i=head[u]; i!=-1; i=head[u]) | for(i=del[x]; i<g[x].size(); i=del[x]) |
| 输出 | 回溯入栈，弹栈输出 | 同左，出边先 sort 保字典序 |
