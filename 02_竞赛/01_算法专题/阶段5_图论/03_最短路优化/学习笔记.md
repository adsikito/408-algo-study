## 第二十章：对最短路算法的优化

> 课件来源：`20.对最短路算法的优化.pptx`
>
> 例题代码：`例题代码/P3371-SPFA算法.cpp`（洛谷 P3371 [模板] 单源最短路·弱化版）、`例题代码/P4779-Dijkstra堆优化.cpp`（洛谷 P4779 [模板] 单源最短路·标准版，注释含朴素版）

## 🗺️ 本章地图

本章解决一个问题：朴素 Dijkstra 每轮**找 dis 最小的点**要 O(n) 遍历、朴素 Ford 每轮**扫全部边**太浪费——怎么优化？路线是"两个瓶颈 → 两个数据结构"：Dijkstra 的三连优化——"找最小点"交给**小根堆**（O(n)→O(log n)）、"枚举邻接点"交给**链式前向星**、"点会重复入堆"用 **v[] 出堆标记**跳过，得 O((n+m)log n)；Bellman-Ford 的优化靠一个观察——"本轮 dis 减小的点，只会是上一轮 dis 减小点的邻接点"，于是把"可能更新别人的点"放进**队列**，这就是 SPFA。最后用一张五算法总表 + 选型口诀收官。

## 📌 本章重点

⭐ **Dijkstra 三处优化**：小根堆找最小点（遍历 O(n)→堆 O(log n)）+ 链式前向星枚举出边 + v[] 标记出堆点跳过重复
⭐ **堆优化 Dijkstra 模板**：pair<dis,点> 进优先队列，`greater<PII>` 变小根堆，复杂度 O((n+m)·log n)
⭐ **SPFA 的核心观察**：本轮 dis 减小的点是上一轮 dis 减小点的邻接点 → 队列只存"dis 被更新的点"，每次只松它的出边
⭐ **两种标记语义不同**：Dijkstra 的 v[]="已出堆定型"，SPFA 的 v[]="当前在队列中"（出队置 0）
⭐ **选型结论**：边权非负 → 堆优 Dijkstra；有负边权 → SPFA（课件原话：权值非负堆优 Dijkstra→SPFA；有负边权 SPFA）

## 🔥 本章难点

🔥 **堆里的陈旧数据**：一个点可被更新多次、入堆多次，只有**最后一次入堆（最小 dis）才是正确的**，且它一定最先出堆（小根堆性质）——出堆时 `v[k]==1` 就 continue 跳过陈旧副本
🔥 **SPFA 复杂度玄学**：最好 O(m)，最坏退回 O(nm)（课件"优化了个寂寞"）；无负权的比赛图会被出题人刻意卡 SPFA（"SPFA 已经死"），但负边权场景仍离不开它

## ⚠️ 本章易错点

⚠️ **优先队列默认大根堆**：必须写 `priority_queue<PII, vector<PII>, greater<PII>>`；pair 先比 first（dis）再比 second（点号）
⚠️ **出堆忘判 `v[k]==1` 就 continue**：陈旧堆元素会把已定型点再松弛一遍，轻则变慢重则答案错
⚠️ **SPFA 的 v[] 时机写反**：出队时 `v[u]=0`（不在队列了），入队时 `v[k]=1`；若忘置 0，该点永远无法再次入队，结果错
⚠️ **松弛用的距离值**：堆优化版课件用刚出堆的 `minn=now.first` 做基准（此刻它等于 dis[k] 且最小）；SPFA 用 `dis[u]`——两版别抄混
⚠️ **dis 的类型与初值**：P3371 边权大，dis 开 long long、初值 INT_MAX/inf；边数组按有向图 m 开（无向图才要 2m，第 21 章 P8802 的教训）

## 📖 知识点讲解

### 1. 朴素 Dijkstra 的两个瓶颈与三处优化

**是什么**：白话——朴素 Dijkstra 每轮干两件事：在全图里**找** dis 最小的未定点（遍历 O(n)），然后**枚举**它的邻接点做松弛（邻接矩阵 O(n)）。优化就是给这两件事各换一件好工具：找最小用**小根堆**，枚举邻居用**链式前向星**；外加一个细节——点可能重复入堆，要标记跳过。

**为什么**：完全图里一个点最多 n-1 条边，但大部分图远没有这么稠密——遍历邻接矩阵是"陪跑"大量不存在的边；链式前向星只存真实边，枚举成本 = O(出边数) < O(n)。同理，堆取最小 O(log n) 完胜线性扫描 O(n)。

**怎么用**（课件三问三答）：
1. 如何找到 dis[i] 最小的 i？——遍历，O(n)
2. 如何快速找到？——**小根堆**（优先队列），O(log n)
3. 如何快速遍历 i 点的邻接点？——**链式前向星（邻接表）**存图，小于 O(n)

第 4 点（课件原话）：点可能被更新多次而入堆多次，**只有最后一次入堆才是正确的 dis**，同时它一定在所有入堆操作结束后才出堆（小根堆保证）——所以开个数组判断"有没有出堆过"，出过就跳过。

> ⚠️ 注意事项：三处优化缺一不可——只换堆不换存图，枚举邻居仍 O(n)，复杂度白优化。

> 🎯 规律："反复取最值"找堆/优先队列；"只遍历真实存在的关系"找邻接表——数据结构换得对，复杂度才降得动。

> 💡 一句话总结：堆找最小，前向星找邻居。

### 2. 堆优化 Dijkstra：模板与跟着算

**是什么**：白话——把"(当前距离, 点)"当元素放进小根堆，每次弹堆顶即得全局 dis 最小的未定点。严格说：出堆 k 若已定型则跳过；否则标记定型，沿链式前向星枚举 k 的出边做松弛，被更新的点 push 新的 (dis,点) 副本。复杂度 O((n+m)·log n)。

**为什么**：堆保证"取最小"高效；重复副本无害——最小副本先出堆完成定型，之后的陈旧副本被 v[] 拦截，正确性不受影响。

**怎么用**——模板（忠实课件 `P4779-Dijkstra堆优化.cpp`）：
```cpp
typedef pair<ll,int> PII;                            // (距离, 点)
priority_queue<PII, vector<PII>, greater<PII>> q;    // greater → 小根堆！
void dij(int x)
{
  for(int i=1;i<=n;i++) dis[i]=inf;
  dis[x]=0;
  q.push({dis[x], x});
  while(q.size())
  {
    PII now=q.top(); q.pop();
    int minn=now.first, k=now.second;
    if(v[k]==1) continue;    // 陈旧副本：k 已出堆定型过
    v[k]=1;
    for(int i=h[k]; i!=-1; i=e[i].next)
    {
      int u=e[i].to;
      if(dis[u] > minn + e[i].w)     // 用出堆的 minn 松弛
      {
        dis[u]=minn+e[i].w;
        q.push({dis[u], u});         // 新副本入堆
      }
    }
  }
}
```

**跟着算**（4 点 5 条有向边：1→2 w2、1→3 w5、2→3 w1、2→4 w6、3→4 w2，s=1）：

| 步 | 出堆 (dis,点) | 松弛动作 | 堆内剩余 (dis,点) |
|---|---|---|---|
| 1 | (0,1) | dis₂=2 入堆；dis₃=5 入堆 | (2,2) (5,3) |
| 2 | (2,2) | dis₃=2+1=3 入堆；dis₄=2+6=8 入堆 | (3,3) (5,3) (8,4) |
| 3 | (3,3) | dis₄=3+2=5 入堆 | (5,3) (5,4) (8,4) |
| 4 | (5,3) | v[3]=1 已定型 → **跳过（陈旧）** | (5,4) (8,4) |
| 5 | (5,4) | 4 无出边 | (8,4) |
| 6 | (8,4) | v[4]=1 → **跳过（陈旧）** | 空 |

最终 dis=[0,2,3,5]——注意第 3 步 dis₃ 从 5 变 3，第 1 步入堆的 (5,3) 变成陈旧数据，第 4 步被 v[] 拦截。

> ⚠️ 注意事项：对比朴素版（课件注释保留）：外层 `for j=1..n` 轮、内层 O(n) 扫描找最小——堆版把这两层换成了堆操作，逻辑骨架完全一致。

> 🎯 规律：出堆的 (minn,k) 里 minn 就是"k 的最终最短路"——用它松弛等价于朴素版的 dis[k]+w。

> 💡 一句话总结：小根堆出顶，陈旧副本跳过。

### 3. SPFA：队列优化的 Bellman-Ford

**是什么**：白话——Ford 每轮扫全部边太浪费；其实"本轮能更新别人的点"只会是"上一轮 dis 变小的点"的邻居，那就把 **dis 被更新的点放进队列**，每次只处理队首点的出边。严格说：SPFA（队列优化 Bellman-Ford）中每点松弛后被更新且不在队列就入队，直到队列空。最好 O(m)，最坏 O(nm)（不稳定、玄学）。

**为什么**：只有 dis[u] 变小，u 的出边才可能引起新的松弛——dis 没变过的点的出边试了也白试。队列恰好维护"dis 变小过、还没扩散出去"的点集，这正是 Ford 各轮的差分。

**怎么用**——模板（忠实课件 `P3371-SPFA算法.cpp`）：
```cpp
int v[100005];      // v[i]=1 表示 i 点在队列中
bool spfa(int x)
{
  for(int i=1;i<=n;i++) dis[i]=INT_MAX;
  dis[x]=0;  v[x]=1;  q.push(x);
  while(!q.empty())
  {
    u=q.front(); q.pop();
    v[u]=0;                          // u 不在队列中了（以后还能再入）
    for(int i=h[u]; i!=-1; i=e[i].next)
    {
      k=e[i].to;
      if(dis[k] > dis[u]+e[i].w)
      {
        dis[k]=dis[u]+e[i].w;        // k 点被更新
        cur[k]=cur[u]+1;             // 记录起点到 k 的边数
        if(cur[k]>n-1) return 0;     // 边数超 n-1 → 有负环（Ford 判据的翻版）
        if(v[k]==0){ q.push(k); v[k]=1; }   // 不在队列才入队
      }
    }
  }
  return 1;
}
```

**跟着算**（与知识点 2 同一张图）：

| 步 | 出队 | 更新与入队 | 队列 |
|---|---|---|---|
| 初始 | — | dis=[0,∞,∞,∞]，1 入队 | [1] |
| 1 | 1 | dis₂=2（2 入队）；dis₃=5（3 入队） | [2,3] |
| 2 | 2 | dis₃=3（**3 已在队，不重复入队**）；dis₄=8（4 入队） | [3,4] |
| 3 | 3 | dis₄=5（4 已在队） | [4] |
| 4 | 4 | 无出边 | [] |

最终 dis 同为 [0,2,3,5]。对比堆版：**队列里每点最多一个**（v[] 挡"已在队"），堆里同一可有多个副本（v[] 只挡"出堆过"）。

> ⚠️ 注意事项：SPFA 判负环用 cur[k]>n-1（起点到 k 的边数超过 n-1 必绕了环），正是第 19 章"第 n 轮仍能松弛"判据的逐点版；无负环时该数组可省。

> 🎯 规律：Ford 的"轮"→SPFA 的"队列"：谁 dis 变小谁入队，出队只松出边——轮次感消失，更新按需进行。

> 💡 一句话总结：谁变小谁入队，出队松邻居。

### 4. "SPFA 已死"与五算法总表

**是什么**：课件小八卦——SPFA 全称 Shortest Path Faster Algorithm，源自西南交通大学段同学 1994 年的论文；但其复杂度证明（O(kE)）是错误的，且 1957 年 Bellman-Ford 提出后不久已有队列优化，国际上不承认是段同学提出。SPFA 最坏 O(VE)、最好 O(E)，**不稳定**。

**为什么**：正因为复杂度玄学、给人"骗分"感，题目不出现负边权时各大比赛的出题人会**刻意卡 SPFA**（尊重选手、尊重 Dijkstra）——"SPFA 已经死"。但堆优 Dijkstra 再快也**不能处理负边权**，所以遇到负边权仍要考虑 SPFA。

**怎么用**——五算法总表（课件原表，背下来）：

| 算法 | 复杂度 | 单源/多源 | 负边权 | 负权回路 |
|---|---|---|---|---|
| Floyd | O(n³) | 多源 | 可以 | 不可以 |
| Dijkstra | O(n²) | 单源 | 不可以 | 不可以 |
| Bellman-Ford | O(nm) | 单源 | 可以 | 可判定 |
| 堆优化 Dijkstra | O((n+m)·log n) | 单源 | 不可以 | 不可以 |
| SPFA | 玄学（最坏 O(nm)） | 单源 | 可以 | 可判定 |

选型口诀（课件）：**权值非负 → 堆优化 Dijkstra；有负边权 → SPFA**。

> ⚠️ 注意事项：P3371（弱化版）SPFA 能过，P4779（标准版）卡 SPFA 用堆优 Dijkstra——两道模板题就是这条选型规则的实物教材。

> 🎯 规律：负权是分水岭：无负权堆优 Dijkstra 稳又快；有负权只剩 Ford/SPFA 一族。

> 💡 一句话总结：非负堆 Dij，负权才 SPFA。

## 🔍 相似概念辨析

**组1：朴素 Dijkstra vs 堆优化 Dijkstra**

| 对比维度 | 朴素 Dijkstra | 堆优化 Dijkstra |
|---|---|---|
| 各自定义 | 每轮 O(n) 遍历找 dis 最小未定点 | 小根堆 O(log n) 取堆顶为最小点 |
| 核心区别 | 找最小靠线性扫描 | 找最小靠堆，配链式前向星枚举出边 |
| 各自特点 | O(n²)，实现直白，配邻接矩阵 | O((n+m)log n)，需处理重复入堆 |
| 使用场景 | n 小（几百）或稠密图 | n、m 大（10⁵ 量级）的稀疏图 |
| 典型示例 | P4779 用朴素版会 TLE | P4779 标准解法 |
| 记忆口诀 | 朴素扫全场，堆优取堆顶 |

**组2：Bellman-Ford vs SPFA**

| 对比维度 | Bellman-Ford | SPFA |
|---|---|---|
| 各自定义 | 每轮松弛全部 m 条边，至多 n-1 轮 | 队列维护"dis 被更新的点"，只松其出边 |
| 核心区别 | 暴力扫全部边 | 按需松弛，剪掉无更新的边 |
| 各自特点 | O(nm) 稳定，代码最短 | 最好 O(m)、最坏 O(nm)，玄学 |
| 使用场景 | 负边权且数据小 / 差分约束 | 负边权大图 / 判负环 |
| 典型示例 | 第 19 章 5 点小图 | P3371 弱化版模板 |
| 记忆口诀 | Ford 扫全边，SPFA 发传单 |

**组3：SPFA vs 堆优化 Dijkstra**

| 对比维度 | SPFA | 堆优化 Dijkstra |
|---|---|---|
| 各自定义 | 队列优化 Bellman-Ford | 堆优化贪心 Dijkstra |
| 核心区别 | 点可反复入队（dis 再变小就再来） | 点定型一次，堆里只多副本 |
| 各自特点 | 能扛负边权，复杂度不稳 | 复杂度稳定 O((n+m)log n)，怕负边权 |
| 各自的 v[] | "在不在队列中"（出队清 0） | "出没出过堆"（永不清 0） |
| 使用场景 | 有负边权（含差分约束） | 边权非负的绝大多数最短路 |
| 典型示例 | 卡 SPFA 的图上会 TLE | 同图稳过 |
| 记忆口诀 | 队列可重来，堆顶定型快 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**朴素算法各有一处"冤枉工"（痛点）→ Dijkstra 冤在找最小点 O(n)+矩阵陪跑 → 堆 + 链式前向星 + 出堆标记三连（优化一）→ Ford 冤在每轮扫全部边 → "只有 dis 变小的点能更新别人" → 队列按需松弛 = SPFA（优化二）→ 但贪心遇负边必翻车、SPFA 复杂度玄学 → 选型定论：非负堆优 Dijkstra、负权 SPFA（边界）**。两个优化共用一个母题：**只对"还可能引起更新"的对象做功**。

跨知识点共性：
1. **与第 17 章搜索优化同源**：都是剪掉"肯定无用"的工作（剪枝 / 剪边）。
2. **与第 11 章栈和队列呼应**：BFS 的队列、堆优 Dijkstra 的堆、SPFA 的队列——"待处理容器"决定遍历顺序与复杂度。
3. **向后铺垫**：第 21 章两道真题直接套用堆优 Dijkstra；SPFA/Ford 判负环在第 19 章差分约束中继续出场。
