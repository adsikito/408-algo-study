## 🗺️ 本章地图

本章解决"怎么开始刷题"：先明确课程目标与"集训"的学习方式（做题 = 分析题意 → 确定算法 → 转成代码），再掌握贯穿全课的做题四步法。然后学会用 1s=10^8 估算复杂度防 TLE，并认识 OJ 的各种返回结果以便快速定位错误。最后是刷题方法论：题解怎么用、错题怎么复盘、模板怎么攒——全章是方法论，但它的习惯决定后面每一章的上限。

## 📌 本章重点

⭐ **做题四步法**：读题面 → 看样例 → 看数据范围（1s=10^8、数据类型）→ 写代码、本地测试、提交
⭐ **复杂度估算法**：把 n 代入复杂度算出运算量，与 10^8 比较，超量级就换算法
⭐ **刷题方法论**：题解看思路不抄代码、错题写解题报告、整理算法模板、按"算法标签+难度"找题
⭐ **OJ 返回结果判读**：AC/WA/TLE/MLE/RE/CE 各代表什么错，对症下药

## 🔥 本章难点

🔥 **由数据范围反推算法**：看到 n≤10^5 就该知道 O(n²) 必挂、O(n log n) 稳过——要把"复杂度×n"练成条件反射，这是贯穿全课的核心能力
🔥 **"集训"学习模式的转变**：从"上课听懂"到"课下大量训练"——课件原话：自身水平和有效刷题量成正比，模板要整理到能默写

## ⚠️ 本章易错点

⚠️ **用刷题网站自带的编译器/编辑器写代码**：课件 Tips 第一条明确"不要！！！"——本地写好、本地测好再提交
⚠️ **忽略数据范围**：不看 n 的范围就上手写暴力；或 n 大时忘开 long long 溢出
⚠️ **抄题解**：看懂思路后必须关掉题解自己写，养成抄题解的习惯等于没学；这个题解看不懂就换一个
⚠️ **只做课上例题就停**：每个算法课上只带刷 2~4 题，远远不够，要按算法标签自主加练
⚠️ **对返回结果乱猜**：WA 是思路/边界错，TLE 是复杂度超，RE 是运行崩溃——先分类再动手

## 📖 知识点讲解

### 1. 课程目标与"集训"学法

**是什么**：一句话——这门课教你"把题目变成代码"的完整流程。课件列的课程目标四条：①学会做题：分析题意，寻找思路/确定算法，把思路转换成代码；②巩固《数据结构》课内算法（直接带刷经典题）；③学习课内没涉及但常用的算法（先讲算法再带刷题），即算法比赛（不含 ACM-ICPC/CCPC）、春/秋招笔试、考研复试上机常考的算法；④结课后能独立在 OJ 上刷题。

**为什么**：课件 Q&A 说得很直白——"集训"的重点在"训"，课上时间有限，每个算法只讲 2~4 个例题，远远不够；自身水平和有效刷题量成正比。课堂只负责"带你见过、带你会写"，提升在课下。

**怎么用**：
- 课前：每节课结束会发下节课例题号，先把例题做一做，至少读一遍题意（课上不留读题时间）
- 课中：跟着把思路和代码推一遍，同步记模板
- 课后：独立做完课上例题 → 按"算法标签选题，再按难度排序"自主找题加练
- 贯穿始终：整理算法模板；错题写解题报告

> ⚠️ 注意事项：课件 Q&A 明确——本课程覆盖蓝桥杯等比赛的大部分出题范围，但对 ACM（ICPC/CCPC）是远远不够的；做错题时"参考题解（不是照抄）"，合理利用题解，不要养成抄题解的习惯。

> 🎯 规律：一切算法学习的闭环都是"学思路 → 默写模板 → 换题套用 → 错题复盘"。

> 💡 一句话总结：课领进门，修行靠刷题。

### 2. 做题四步法（每道题的固定流程）

**是什么**：一句话——拿到题先别写代码，按课件给的顺序走完四步。①读题面，分析题意；②看示例（样例），分析样例；③看数据范围，确定时间复杂度（1s=10^8）和数据类型；④找思路，写代码，本地运行测试，提交。

**为什么**：四步各挡一种死法——不读题（思路全错）、不看样例（理解有偏差）、不看范围（TLE 或类型溢出）、不本地测（CE/低级错误浪费提交次数）。

**怎么用**：以第一章例题 P1003 走一遍：读题面知道是"铺 n 张地毯，问某点最上面是谁"；看样例验证自己对覆盖关系的理解；看数据范围 n≤10^4，O(n) 枚举地毯就够，坐标不大 int 可存；写代码本地过样例再提交。

> ⚠️ 注意事项：数据范围同时决定两件事——算法复杂度、数据类型（要不要 long long）。

> 🎯 规律：先看范围再想算法，永远不要写完代码再回头改复杂度。

> 💡 一句话总结：题面→样例→范围→代码。

### 3. 时间复杂度与超时判断

**是什么**：一句话——判断算法会不会 TLE，就是把数据范围 n 代入复杂度算出总运算量，和 **1s ≈ 10^8 次基本运算** 比。课件原文只有两行：时间复杂度的计算（数据结构课程复习）、1s=10^8。

**为什么**：OJ 时限一般 1s，运算量超出 10^8 一个量级基本必挂；反过来，由 n 的范围也能反推出题人放行的复杂度，从而缩小"该用哪个算法"的搜索范围。

**怎么用**（常用对照，建议背熟）：

| 数据范围 n | 可接受复杂度 | 常见对应算法 |
|---|---|---|
| ≤ 10~20 | O(2^n)、O(n!) | 搜索、全排列枚举 |
| ≤ 500 | O(n³) | 三重循环枚举 |
| ≤ 5000 | O(n²) | 枚举/模拟、二重循环 |
| ≤ 10^5~10^6 | O(n log n)、O(n) | 排序、二分、双指针、筛法 |
| 10^7 以上 | O(log n) 或 O(√n) | 数学、二分、试除 |

跟算：n=10^5 时，O(n²)=10^10 ≫ 10^8 → 必 TLE；O(n log n)≈10^5×17≈1.7×10^6 → 稳过；O(n)=10^5 → 稳过。

> ⚠️ 注意事项：估算要"宁小勿大"——循环内有排序、取模、字符串等重操作时实际常数更大，预算留余量。

> 🎯 规律：见 n=10^5 就想 O(n log n)；n≤5000 才敢想 O(n²)；n≤20 才考虑指数级搜索。

> 💡 一句话总结：一秒一亿次，代入便知生死。

### 4. OJ 返回结果判读

**是什么**：课件 Tips 第 2 条"提交后的返回结果"（幻灯片为图示，此处按通用 OJ 约定整理）。平台对每次提交给出一个判定，认识它们才能快速定位问题。

**为什么**：不同结果的排查方向完全不同：答案对不对看 WA，跑不跑得完看 TLE，崩没崩看 RE/CE——先分类再动手，改错效率翻倍。

**怎么用**：

| 结果 | 全称 | 含义 | 排查方向 |
|---|---|---|---|
| AC | Accepted | 通过 | ——（下一步：整理模板/写解题报告） |
| WA | Wrong Answer | 答案错 | 思路、边界、特判、输出格式 |
| TLE | Time Limit Exceeded | 超时 | 复杂度太高 → 换算法 |
| MLE | Memory Limit Exceeded | 超内存 | 数组开太大 |
| RE | Runtime Error | 运行错误 | 数组越界、除零、爆栈 |
| CE | Compile Error | 编译错误 | 语法，本地先编译一遍 |

> ⚠️ 注意事项：CE 是最低级也最容易避免的错误——这正是课件 Tips 第一条"不要用刷题网站自带的编译器写代码"的原因。

> 🎯 规律：WA 查边界，TLE 查复杂度，RE 查越界。

> 💡 一句话总结：先看结果分类，再对症下药。

### 5. 题解、解题报告与模板整理

**是什么**：课件 Q&A 给出的三件套方法论。①遇到不会的题：参考题解（不是照抄）——看题解中的思路并学习思路，然后关掉题解自己写代码；不局限于一个题解，这个看不懂就换一个。②错题整理解题报告：粘贴题目链接、简单描述题意、错误思路及错误原因总结、正确思路、AC 代码、反思。③整理算法模板——本笔记每章的"📋 速查表"就是为这个准备的。

**为什么**：错题的价值在"错误原因"，模板的价值在"下次直接默写"；这两件事把一道题的价值放大成一类题的经验。

**怎么用**：以 P1003 若 WA 为例写报告："错误思路：正着枚举地毯找到就输出——错在先铺的不一定在最上层；错误原因：枚举顺序没结合'后铺覆盖先铺'的题意；正确思路：从后往前枚举，找到即输出，否则 -1。"模板整理则把代码抽成与题目无关的通用形态（见各章速查表）。

> ⚠️ 注意事项：不留课后作业——先独立做完课上例题，再根据实际情况自行刷题。

> 🎯 规律：题解学思路，报告存教训，模板攒兵器。

> 💡 一句话总结：看懂不等于会写，关题解自己敲。

## 🔍 相似概念辨析

**组1：WA vs TLE**

| 对比维度 | WA | TLE |
|---|---|---|
| 各自定义 | Wrong Answer，程序跑完但输出与期望不符 | Time Limit Exceeded，程序未能在时限内跑完 |
| 核心区别 | "想错了"：算法思路或边界处理有误 | "跑不动"：复杂度超出时限 |
| 各自特点 | 改动小：多半是边界、特判、格式 | 改动大：通常要换算法/数据结构 |
| 使用场景 | 输出不一致时的排查入口 | 数据范围大、循环太深时的排查入口 |
| 典型示例 | P1003 地毯边界漏写等号 | n=10^5 硬上 O(n²) 枚举 |
| 记忆口诀 | WA 查边界，TLE 查复杂度 |

**组2：课内算法（带刷）vs 新算法（新授）**

| 对比维度 | 课内学过的算法 | 集训新学的算法 |
|---|---|---|
| 各自定义 | 《数据结构》课程已覆盖的算法 | 数据结构课没涉及、但笔试/比赛常用的算法 |
| 核心区别 | 教学方式：直接带刷经典题 | 教学方式：先讲算法，再带刷题 |
| 各自特点 | 重在巩固与提速 | 重在从零建立认知并攒模板 |
| 使用场景 | 上课例题可当复习检验 | 先吃透课件原理再动笔 |
| 典型示例 | 前缀和、简单枚举 | 尺取法、二分答案、线性筛 |
| 记忆口诀 | 旧算法刷熟，新算法先懂再刷 |

## 📋 速查表

| 项目 | 内容 | 条件/频率 |
|---|---|---|
| 做题四步法 | 读题面→看样例→看数据范围→写码测试提交 | 每题必走 |
| 复杂度估算 | 运算量 = 复杂度(n)，对比 1s=10^8 | 超一个量级必 TLE |
| 解题报告 | 链接/题意/错误思路及原因/正确思路/AC代码/反思 | 每道错题 |
| 找题 | 按"算法标签+难度排序" | 先专项后综合 |

```text
本地写码 → 本地编译测试 → 提交 OJ
   ├─ CE：语法错，回本地改
   ├─ WA：思路/边界/特判
   ├─ TLE：换更快的算法
   ├─ MLE：数组开小/开大
   ├─ RE：越界/除零
   └─ AC：整理模板 & 写解题报告
```
