## 本章地图

本章解决一个问题：**「动态前缀和，怎么比线段树更轻？」**

```text
需求：单点加 + 前缀和查（或差分改装：区间加 + 单点查）
   ↓
lowbit 把前缀 [1, x] 拆成 O(log n) 段（t[x] 管 (x − lowbit(x), x]）
   ↓
update：x += lowbit(x) 向上爬（管它的区间都更新）
query： x −= lowbit(x) 向下跳（不重不漏拼前缀）
   ↓
三件事：
   ├─ 单点加 + 区间和（queryRange = 两次前缀相减）
   ├─ 差分改装 → 区间加 + 单点查
   └─ 离散化 + BIT → 逆序对
   ↓
分工：区间最值 / 区间加区间和 → 线段树（01 篇）
```

**为什么这条路径是这样**：BIT 的全部魔法在**「下标与覆盖区间的二进制对应」**——
lowbit 的 2^k 决定了每个 t[x] 管多长一段，加减 lowbit 恰好沿二进制树上下移动。
**理解 t[x] 覆盖图，两个循环就不需要背。**

## 核心概念与模板

**是什么**：树状数组（BIT）：用 `lowbit(x) = x & (−x)` 把前缀和拆成 O(log n) 段——
**区间和查询 + 单点修改 O(log n)**，代码只有十几行，常数远小于线段树。

**为什么**：能做的三件事：单点加 + 前缀和查、差分改装后「区间加 + 单点查」、
配合离散化数逆序对。区间最值与区间加区间和交给线段树——两树分工。

> **【规律】** **t[x] 管 (x − lowbit(x), x]**——覆盖长度恰为 lowbit(x)。
> update 向上「谁管我我通知谁」（x += lowbit），
> query 向下「我管的段拼起来」（x −= lowbit）。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
typedef long long ll;
const int N = 500005;
int n;
ll t[N];                                  /* t[x] 管 (x - lowbit(x), x] */

int lowbit(int x) { return x & (-x); }

void update(int x, ll v) {                /* 单点加 v */
    for (; x <= n; x += lowbit(x)) t[x] += v;
}

ll query(int x) {                         /* 前缀 [1, x] 的和 */
    ll s = 0;
    for (; x > 0; x -= lowbit(x)) s += t[x];
    return s;
}
ll queryRange(int l, int r) { return query(r) - query(l - 1); }

/* 差分改装：区间加 + 单点查（维护差分数组的 BIT） */
void rangeAdd(int l, int r, ll v) {
    update(l, v);
    update(r + 1, -v);                    /* 差分两端（阶段 1 2-2 同款） */
}
ll pointQuery(int x) { return query(x); } /* 前缀和还原差分 */

/* 逆序对：离散化 + 从右往左数「已插入的更小值」 */
```

**逆序对（离散化 + BIT）**：

```cpp
/* 值域大先离散化（sort + unique + lower_bound，阶段 0 延伸）：
   从右往左扫，ans += query(rk[i] - 1)，再 update(rk[i], 1)；
   逆序对也可用归并（阶段 2 02_递归与分治）——两法对照 */
```

> **【类比】** BIT 像**公司的分层汇报线**：每个员工（下标）向上汇报给
> 「管辖范围恰含自己」的主管（x += lowbit）；
> 查询时老板（query）只找「恰好拼出前缀」的几位主管（x −= lowbit）——
> **层级数 = 二进制位数 = log n**，谁都不多跑一步。

## 本章难点

> **【难点】** **差分改装的语义。**
> BIT 维护「差分数组」而非原数组：区间加 = 差分两端点修改（O(1) 次更新）；
> 单点查 = 差分前缀和（BIT 查询 O(log n)）。
> **与阶段 1 差分对照**：差分数组的「还原 O(n)」被 BIT 的前缀查询降成 log——
> 这就是「前缀和的差分改装」的全部含义。

> **【难点】** **逆序对的方向选择。**
> 从右往左扫、查「已插入的更小值」；或从左往右扫、查「已插入的更大值」——
> 两法对称。**离散化必须先做**（值域 10⁹ 开不下数组），
> 且相同元素的 rank 分配按题面（严格 / 非严格逆序）。

---

## 本章易错点

> **【头号易错】** **下标 0 死循环**：lowbit(0) = 0，update 从 x = 0 起 for 永不终止——
> **BIT 全程 1 起下标**。

> **【易错】** **区间加改装的「update 两端」写成 update(l) + update(r)**
> （漏 +1：应为 update(r+1, −v)）。

> **【易错】** **逆序对忘记离散化**（值域 10⁹ 直接开数组 RE）；
> long long 溢出（逆序对可达 n(n−1)/2 ≈ 1.25×10¹¹）。

> **【易错】** **queryRange 的 l = 1 边界**：query(l − 1) = query(0) = 0 天然正确
> ——前提是循环条件 `x > 0`。

> **【易错】** **多组数据 / 重置**：t 数组逐点 update 撤销或 memset（按量选）。

## 典型例题

### 例 1　单点加 + 区间和（模板）　难度：模板题

**题干摘要**：n, m ≤ 5×10⁵，单点加 / 前缀和查询混合。
**题源**：同类真源见配套练习 T1（P3374 树状数组 1）
**涉及知识点**：知识点 1、2

**解题思路**：

1. **信号**：「单点加 + 前缀和」→ BIT 模板。
2. **方法**：核心模板 update / query / queryRange。

**复杂度**：每操作 O(log n)，常数约为线段树 1/3。

> **【易错】** 读入用快读（数据量 10⁶ 级，竞赛 C++ B 模块三板斧）；
> 查询区间和 = 两次前缀相减。

---

### 例 2　区间加 + 单点查 + 逆序对（改装与离散化）　难度：综合题

**题干摘要**：①m 次区间加、最后单点查；②统计序列逆序对。
**题源**：树状数组 2 / 逆序对（P1908 在库——逆序对主挂 2-2 归并，此为 BIT 对照）
**涉及知识点**：知识点 3、4

**解题思路**：

1. **信号**：「区间加 + 单点查」→ 差分改装；「逆序对」→ 离散化 + BIT。
2. **方法**：核心模板 rangeAdd / pointQuery + 逆序对段。

**复杂度**：均 O((n + m) log n)。

> **【易错】** 差分改装后「单点查」= 差分前缀和——与阶段 1 差分的「还原 O(n)」对照：
> BIT 把还原也降到 log，这就是「前缀和的差分改装」的全部含义。

## 本章总结

### 核心内容（一页纸）

1. **lowbit(x) = x & (−x)**；t[x] 管 (x − lowbit(x), x]。
2. **update 向上爬（+= lowbit）、query 向下跳（−= lowbit）**——方向相反的两个 for。
3. **下标必须 1 起**（lowbit(0) = 0 死循环）。
4. **区间和 = query(r) − query(l−1)**。
5. **差分改装**：区间加 = 两端点 update；单点查 = 前缀和——还原从 O(n) 降到 log。
6. **逆序对**：离散化 + 从右往左数「已插入的更小值」；答案 long long。
7. **两树分工**：BIT 轻快窄（前缀可减的聚合）、线段树重稳宽（最值 / 区间加区间和）。
8. **与归并计数对照**：同一逆序对两种统计视角。
9. **快读必配**（10⁶ 级输入）。
10. **全书收官**：35 篇是「数据范围反推」的完整反推链。
