## 🗺️ 本章地图

> **本章解决一个问题：线段树又长又费空间，能不能用更短的代码同样做到 O(log n) 的单点修改+前缀和？**
> 路线是"动机 → 灵魂 → 操作 → 变形"：先看暴力 O(mn) 和线段树"空间大代码多"的痛点（知识点 1）；再挖出全章的灵魂——lowbit 与 t[x] 的管辖区间（2）；然后走通两大基本操作——add 单点加、ask 前缀和（3）；最后用差分给树状数组"改装"，拿下区间修改+单点查询（4）。
> 学完请自测三件事：lowbit(x)=x&(-x) 的补码原理说得出吗？sum[7]=t[7]+t[6]+t[4] 这条链会推吗？为什么下标必须从 1 开始？

## 📌 本章重点（3-5个）

⭐ **lowbit(x)**：x 二进制中最低位的 1 及其后所有 0 组成的数，`x & (-x)` 一行搞定
⭐ **t[x] 的管辖区间**：t[x] = 原数组区间 `[x-lowbit(x)+1, x]` 的和；父亲是 `x+lowbit(x)`，左兄弟是 `x-lowbit(x)`
⭐ **两大基本操作**：add 沿 `x += lowbit(x)` 更新所有祖先；ask 沿 `x -= lowbit(x)` 累加拼出前缀和，均 O(log n)
⭐ **建树 = 逐个单点修改**：初始全 0，把 a[i] 一个个 add 进去
⭐ **差分改装**：树状数组维护差分数组 → 区间修改+单点查询；`ask(r)-ask(l-1)` → 任意区间和

## 🔥 本章难点（2-3个）

🔥 **树状数组是怎么"推导"出来的**：分层两两求和 → 发现每层偶数下标用不到 → 删掉后右对齐 → 恰好 n 个节点的树形结构——这个从"暴力分层"到"一棵树"的过程是理解 lowbit 规律的钥匙
🔥 **差分变形的语义转换**：区间加 [l,r]+k 变成差分数组的两个单点改 `d[l]+k, d[r+1]-k`；单点查 a[x] 变成差分前缀和——对象换了，add/ask 一行不用改
🔥 **能力边界**：树状数组能解决的问题是线段树的**子集**（能做的线段树都能做，反之不行，如区间最值不能直接维护）；"区间修改+区间查询"要建两个树状数组，极其复杂，课件建议直接上线段树

## ⚠️ 本章易错点（3-5个）

⚠️ **下标从 0 开始存数**：lowbit(0)=0，`x += lowbit(x)` 永远等于 0，建树和查询双双**死循环**——必须从 1 开始（课件 tips 1）
⚠️ **区间查询写错减法对象**：求 [l,r] 的和要用 `ask(r) - ask(l-1)`，写成 `ask(r)-ask(l)` 会少算 a[l]
⚠️ **差分区间加漏掉 r+1**：只写 `add(l,k)` 不写 `add(r+1,-k)`，后面所有点全被污染；同时注意 r+1 可能等于 n+1，数组要留够（循环条件 `i<=n` 会自动挡住越界访问）
⚠️ **以为树状数组万能**：它本质只擅长"前缀和信息"，直接维护区间最值不行（要改 update 思路，得不偿失）——先问自己"这信息能拼前缀吗"
⚠️ **忘记 long long**：n、m 到 5×10^5 时累加和轻松超过 int（两份模板代码全用 ll 不是摆设）

## 📖 知识点讲解

### 1. 为什么需要树状数组：暴力的两难与第三条路

**是什么**：问题原型：n 个数的数组，m 次操作——①单点修改某元素；②求前 k 个元素的和。暴力：改 O(1) 但求和 O(n)，总 O(mn) 超时；线段树：O(m logn) 但空间大（4n）、代码几十行。树状数组：复杂度同样 O(m logn)，空间只有 **n**，核心代码不到 20 行。

**为什么**：课件的推导思路是"两两求和"——把相邻两个数求和存进上一层，求前缀和时利用上层结果省一半计算；不够快就再加一层，对第二层再两两求和……这其实就是一棵线段树！随后发现一个隐蔽规律：**求前缀和时，每层偶数下标的元素永远用不到**（如 sum[1,11]=31+5+1、sum[1,10]=31+5、sum[1,8]=31，全是奇下标）。把没用的偶下标删掉、靠右对齐，剩下的恰好是 **n 个节点**的树——合进一个数组 t，这就是树状数组。

**怎么用**：选型判断——问题只需要"单点修改+前缀和（及它们的差分/前缀变形）"时，无脑选树状数组；需要区间修改、区间最值、复杂区间信息时，回头用线段树。

> ⚠️ 注意事项：树状数组和线段树可以互相印证——从"分层求和"的角度看，线段树删掉无用的偶下标节点就是树状数组。

> 🎯 规律：只要前缀和可拼，树状数组就是最短解。
> 💡 一句话总结：线段树瘦身版，n 个节点的树。

### 2. lowbit：树状数组的灵魂

**是什么**：lowbit(x) = x 二进制表示中**最低位的 1 以及后面所有 0** 组成的数。树状数组中最隐蔽的规律：t[x] 管辖的区间长度恰好等于 lowbit(x)，右端点是 x，即 t[x] = a[x-lowbit(x)+1] + ... + a[x]。观察实例：t[1]=a[1]→[1,1]，t[2]=a[1]+a[2]→[1,2]，t[3]=a[3]→[3,3]，t[4]=a[1..4]→[1,4]，t[5]=a[5]→[5,5]，t[6]=a[5]+a[6]→[5,6]……右边界都是 x，左边界 = x-lowbit(x)+1。由此还得到：**x 的父亲是 x+lowbit(x)，x 的左兄弟是 x-lowbit(x)**。

**为什么**：lowbit 怎么求？利用补码：内存中数据以补码存储，(~x)+1 恰好是 -x 的补码。以 x=01011000 为例：
```
x      = 01011000
取反   = 10100111
+1     = 10101000   （即 -x）
x & -x = 00001000   = 8
```
与运算把 x 高位的 1 全部消掉，只留下最低位的 1 及其身后的 0。

**怎么用**：
```cpp
int lowbit(int x) { return x & (-x); }   // 等价写法：x & ((~x)+1)
```
跟着算几个：lowbit(7=111)=1，lowbit(6=110)=2，lowbit(12=1100)=4，lowbit(8=1000)=8。

> ⚠️ 注意事项：lowbit(0)=0 是一切死循环的根源，操作前保证 x≥1。

> 🎯 规律：管辖长度看最低位 1，父亲加、兄弟减。
> 💡 一句话总结：x&(-x)，管多长、找爹妈。

### 3. 两大基本操作：add 单点加 与 ask 前缀和

**是什么**：**add(x,k)** 实现 a[x]+k：因为 t[x] 及其所有祖先都管辖位置 x，所以从 x 出发不断 `x += lowbit(x)` 把沿途节点全部 +k。**ask(x)** 求前 x 项和：从 x 出发不断 `x -= lowbit(x)`，把沿途每个 t 的管辖区间首尾相接拼成 [1,x]。建树不必单独写——**建树就是 n 次单点修改**（初始全 0，逐个 add(i, a[i])）。

**为什么**：修改必须通知"所有管到 x 的节点"（全部祖先链）；查询则把 [1,x] 按 lowbit 从大到小切成 O(log n) 段，每段正好对应一个 t 节点。两个方向恰好互逆，共用 lowbit 跳跃。

**怎么用**——lowbit 分解图 + 跟着算（n=8，a = 1 2 3 4 5 6 7 8）：

```
t[x] 的树形管辖（子节点 → 父节点 = x+lowbit(x)）：

lowbit=1 层:  t[1]=1   t[3]=3   t[5]=5   t[7]=7     （单元素）
lowbit=2 层:     t[2]=3        t[6]=11             （管2个）
lowbit=4 层:        t[4]=10                        （管4个）
lowbit=8 层:           t[8]=36                     （管8个）
链：1→2→4→8   3→4→8   5→6→8   7→8
```

单点加：a[3] += 5（3→4→8）：
```
i=3: t[3]+=5 (3→8)  →  i=3+lowbit(3)=4: t[4]+=5 (10→15)  →  i=4+4=8: t[8]+=5 (36→41)  →  i=8+8=16>8 停
```

前缀和查询：ask(7)：
```
7 = 111₂： +t[7]=7，  i=7-lowbit(7)=6
6 = 110₂： +t[6]=11， i=6-2=4
4 = 100₂： +t[4]=15， i=4-4=0  停
sum[7] = 7+11+15 = 33   （验算：1+2+...+7 = 28，+5 = 33 ✓）
```

```cpp
void add(int x, ll k) {              // a[x] += k
    for (int i = x; i <= n; i += lowbit(i)) t[i] += k;
}
ll ask(int x) {                      // a[1..x] 之和
    ll ans = 0;
    for (int i = x; i > 0; i -= lowbit(i)) ans += t[i];
    return ans;
}
// 区间和 [l,r]：ask(r) - ask(l-1)
// 建树：for (i = 1..n) add(i, a[i]);
```

> ⚠️ 注意事项：ask 的循环条件是 `i > 0`——到 0 必须停；add 的循环条件是 `i <= n`——超出 n 的祖先不存在。

> 🎯 规律：加法向上跳，求和向下砍，lowbit 定步长。
> 💡 一句话总结：两个循环，正负 lowbit，全都会了。

### 4. 差分加持：从"单点改"到"区间改"（P3368）

**是什么**：树状数组原生只会"单点修改+前缀查询"。引入**差分数组** d（d[i]=a[i]-a[i-1]）后身份互换：区间修改 a[l..r]+k 变成差分上的**两个单点修改** `d[l]+k、d[r+1]-k`；单点查询 a[x]=d[1]+...+d[x] 变成差分上的**前缀和查询 ask(x)**。add/ask 代码一行不改，只是维护的对象从 a 换成 d。

**为什么**：差分的精髓——整体加 k 时，区间内部相邻差不变，只有**边界处**的差变了（d[l] 多 k，d[r+1] 少 k）；而任意 a[x] 恰好是差分的前缀和。两类操作正好落在树状数组最擅长的两件事上。

**怎么用**——P3368 的核心逻辑跟着走（a = 0 0 0 0 0，执行 [2,4]+3，再查 a[3]）：

```
d 初始全 0
区间加 [2,4] +3：add(2,+3)  →  add(5,-3)      （两次单点修改）
查询 a[3] = ask(3) = d[1]+d[2]+d[3] = 0+3+0 = 3 ✓
再查 a[5] = ask(5) = 0+3+0+0+(-3) = 0 ✓ （区间外不受影响）
```

```cpp
if (op == 1) { cin >> x >> y >> k; add(x, k); add(y+1, -k); }  // 区间修改
else         { cin >> x; cout << ask(x) << endl; }             // 单点查询
```

更进一步（课件总结）：任意区间和用 `ask(r)-ask(l-1)`；"区间修改+区间查询"可以通过推导建**两个**树状数组实现，但极其复杂——课件原话：这一类建议直接使用线段树。

> ⚠️ 注意事项：此时 ask(x) 的含义已从"a[1..x] 的和"变成"a[x] 本身"，做题时先想清楚树状数组里存的到底是谁。

> 🎯 规律：区间加只动两端差，单点查即差分前缀和。
> 💡 一句话总结：差分换对象，操作零改动。

## 🔍 相似概念辨析

**组1：树状数组 vs 线段树**

| 维度 | 树状数组 | 线段树 |
|------|----------|--------|
| 底层思想 | 二进制低位分解（lowbit 跳跃） | 分治二叉树 |
| 代码量 | 十几行，两个循环 | 几十行（Build/down/Update/query） |
| 空间 | n | 4n |
| 区间修改 | 原生不支持，需差分改装 | 原生支持（懒标记） |
| 可维护信息 | 前缀和类（和、差分、靠变形扩展） | 任意可合并信息（和/max/min/平方和…） |
| 能力关系 | 是线段树功能的子集 | 全覆盖树状数组的能力 |
| 选型口诀 | 单点改+前缀查、逆序对 → 树状数组 | 区间改+区间查、最值 → 线段树 |

**组2：维护原数组 vs 维护差分数组（同一个 t，两种语义）**

| 维度 | 维护原数组 a（P3374） | 维护差分数组 d（P3368） |
|------|----------------------|------------------------|
| t[i] 含义 | a 上一段区间的和 | d 上一段区间的和 |
| ask(x) 的答案 | 前缀和 a[1..x] | 单点值 a[x] |
| 单点修改 a[x]+=k | add(x, k) 一次 | add(x,k)、add(x+1,-k) 两次 |
| 区间修改 [l,r]+k | 做不到（逐点 add 退化 O(n)） | add(l,k)、add(r+1,-k) 两次 |
| 区间和 [l,r] | ask(r)-ask(l-1) | 需两个树状数组，建议线段树 |
| 建树方式 | add(i, a[i]) | add(i, a[i]-a[i-1]) |
| 适用题目 | 单点改+区间查 | 区间改+单点查 |

## 🧩 本章归纳

一条主线：**"分层求和 → 删偶下标 → n 个节点的树 → lowbit 定一切"**。从暴力两两求和出发，删掉前缀和中永远用不到的偶数下标、右对齐后得到恰好 n 个节点的树形结构，压进一个数组 t；lowbit(x)=x&(-x) 解释了一切——t[x] 管 [x-lowbit(x)+1, x]，父亲 x+lowbit(x)，兄弟 x-lowbit(x)；于是单点加向上跳、前缀和向下砍，各 O(log n)；再借差分把"区间修改+单点查询"也纳入射程。能力边界牢记：树状数组 ⊂ 线段树，但胜在**代码短、空间省**——"单点改+前缀查"类问题永远首选它。

## 📋 速查表

| 项目 | 内容 |
|------|------|
| lowbit | `x & (-x)`（补码原理：(~x)+1 = -x） |
| t[x] 管辖区间 | `[x - lowbit(x) + 1, x]` |
| x 的父亲 / 左兄弟 | `x + lowbit(x)` / `x - lowbit(x)` |
| 单点加 | `for(i=x; i<=n; i+=lowbit(i)) t[i]+=k` |
| 前缀和 | `for(i=x; i>0; i-=lowbit(i)) ans+=t[i]` |
| 区间和 [l,r] | `ask(r) - ask(l-1)` |
| 建树 | `for(i=1..n) add(i, a[i])`（n 次 O(logn)） |
| 差分区间加 [l,r]+k | `add(l,k); add(r+1,-k)` |
| 差分单点查询 a[x] | `ask(x)` |
| 纪律 | 下标从 1 起；long long；复杂区间问题回线段树 |
