> 课件来源：`26.字符串匹配之KMP算法.pptx`（文本：`26_字符串匹配之KMP算法__26.字符串匹配之KMP算法.txt`）

> 例题代码清单：`KMP模板.cpp`（返回首个匹配下标）、`P3375.cpp`（输出所有出现位置+next 数组，另含 `P4391.cpp`）

## 🗺️ 本章地图

> **本章解决一个问题：模式串 s 是主串 p 的子串吗？所有匹配位置在哪？——匹配从 O(nm) 优化到 O(n+m)。**
> 路线是"数组含义 → 数组求法 → 匹配过程 → 真题"：先吃透 next 数组=最长相同前后缀（知识点 1）；再学"自己匹配自己"的 DP 式求法（知识点 2）；然后走一遍主串指针不回退的匹配流程（知识点 3）；最后用 P3375 模板题和 P4391 周期问题（答案 n−next[n]）收尾（知识点 4）。
> 学完自测：能否手算 "abab" 的 next 表？能否说清失配时"j 回退、i 不动"为什么不丢解？

## 📌 本章重点（3-5个）

⭐ **next 数组的含义**：next[j] = s[0..j−1] 的**最长相同前后缀**长度；失配时 j 应回退到 next[j] 继续匹配
⭐ **next 的求法**：next[0]=−1、next[1]=0；s[y]==s[i−1] 时 next[i]=next[i−1]+1，否则 y=next[y] 继续试（自己匹配自己）
⭐ **KMP 匹配主过程**：i（主串指针）从不回退，失配只让 j=next[j]，均摊 O(n+m)
⭐ **周期结论**：最短循环元长度 = n − next[n]（P4391）
⭐ **找全部出现位置**：匹配成功后 j=next[n]（而非归零），利用已匹配前缀继续

## 🔥 本章难点（2-3个）

🔥 **为什么失配后回退到 next[j] 不丢解**：已匹配部分的最长相同前后缀意味着"退到 next[j] 后，前面 next[j] 个字符必然已配好"，且比它短的候选都被它覆盖
🔥 **求 next 时 k=next[k] 的嵌套回退**：本质是模式串自己与自己做 KMP，回退链条在找"次长的相同前后缀"
🔥 **P4391 的 n−next[n] 推导**：自匹配时"空过一个周期再比"，next[n] 恰好跳过完整周期，前缀减去它剩下的就是周期

## ⚠️ 本章易错点（3-5个）

⚠️ **next 是关键字**：C++ 里有 std::next，变量名要写成 `nex / net / kmp`，否则编译报错（课件点名提醒）
⚠️ **next[j] 的区间看错一位**：它是 s[0..**j−1**] 的最长相同前后缀，不是含 s[j] 的；下标约定（0 起还是 1 起）两套代码不同，抄模板前先对齐含义
⚠️ **前后缀取了全串**：最长相同前后缀必须是**真**前缀/真后缀（不能等于整个子串），否则 next 恒等于长度、回退失效
⚠️ **j==−1 没处理**：回退越界时哨兵生效，要 i++、j++ 重新开始；漏写会死循环
⚠️ **求所有出现位置时 j 归零**：正确写法 `if(j==n){ 记录 i−n+1; j=net[n]; }`，j=0 会漏掉跨边界重叠的匹配

## 📖 知识点讲解

### 1. KMP 思想与 next 数组的含义

**是什么**：KMP 解决字符串匹配——模式串 s 是主串 p 的子串吗？朴素做法失配就把 i 退回去重来，最坏 O(nm)；KMP 让 **i 永不回退**，失配时只把 j 回退到 next[j]。**next[j] = x 的两层含义**（下标从 0 存）：①模式串前缀子串 s[0..j−1] 的最长相同前后缀长度为 x；②s[j] 与主串失配时，j 回退到 s[x] 位置继续匹配。

**为什么**：失配前 j 个字符已经匹配上了，即主串里有一段 = s[0..j−1]。这段的**最长相同前后缀**告诉我们：把模式串"往左缩"到用前缀对齐后缀，前 next[j] 个字符**无需再验**（后缀已等于前缀），匹配从 s[next[j]] 直接续——所有被跳过的检查都由数学保证不可能成功，所以不丢解。

**怎么用**——**跟着算**：s = "abab"，next[0]=−1、next[1]=0 起步，逐位填表：

| j | 已匹配子串 s[0..j−1] | 可能的相同前后缀 | next[j] |
|---|---------------------|------------------|---------|
| 0 | —（约定） | — | −1 |
| 1 | "a" | 无（不许取全串） | 0 |
| 2 | "ab" | 无 | 0 |
| 3 | "aba" | "a" | 1 |
| 4 | "abab" | "ab" | 2 |

失配演练：拿 "abab" 匹配 "ababab…"，若在 j=4 处失配，j 回退到 next[4]=2——因为已匹配的 "abab" 后缀 "ab" = 前缀 "ab"，这两位不用重比，直接从 s[2] 接着比。

> ⚠️ 注意事项：同一思想有两种约定——模板代码 next[0]=−1（哨兵），P3375 代码 net[1]=0（1 起下标），含义一致但下标错 1 位，读代码先看约定。

> 🎯 规律：next 存的不是"匹配答案"而是"失败后该退哪"。
> 💡 一句话总结：最长相同前后缀，是回退的路标。

### 2. next 数组的求法（自己匹配自己）

**是什么**：next 数组用**递推（DP 思想）**求：算 next[i] 时 next[0..i−1] 已知。设 next[i−1]=y：若 s[y]==s[i−1]，则 next[i]=y+1（前后缀各延长一位）；若不等，则 y 位置失配，令 **y=next[y]** 回退重试——这正是模式串**自己匹配自己**，代码与主匹配完全同构。

**为什么**：s[0..i−2] 的最长相同前后缀是 s[0..y−1]，若再添的两位 s[y] 与 s[i−1] 相等，前后缀同步变长一位；不相等就要找**次长的**相同前后缀——它恰好是 s[0..y−1] 这个前缀自己的最长相同前后缀，即 next[y]，一路回退直到相等或越界（−1，置 next[i]=0）。

**怎么用**（`P3375.cpp` 求法，1 起下标版）：
```cpp
net[1] = 0;
int k = 0, j = 1;                 // k=上一项回退位置, j=当前算到哪
while (j + 1 <= n) {
    if (k == -1 || s[j] == s[k]) { net[j+1] = k + 1; k++; j++; }
    else k = net[k];              // 失配回退：找次长前后缀
}
```
**跟着算**：s = "abeabf"（课件原例），先上帝视角：next = [−1, 0, 0, 0, 1, 2, 0]。再用递推验证后三位：
- 求 next[4]：y=next[3]=0，s[0]='a' == s[3]='a' → next[4]=0+1=**1**
- 求 next[5]：y=next[4]=1，s[1]='b' == s[4]='b' → next[5]=1+1=**2**
- 求 next[6]：y=next[5]=2，s[2]='e' != s[5]='f' → y=next[2]=0；s[0]='a' != s[5]='f' → y=next[0]=−1 越界 → next[6]=**0** ✓ 对上了

> ⚠️ 注意事项：比较的是 s[y] 与 s[i−1]（新来的一位），不是 s[y] 与 s[i]；while 越界条件与数组开界要配套。

> 🎯 规律：求 next = 模式串自己 KMP 自己，相等延长、失配跳 next。
> 💡 一句话总结：相等加一，不等跳脚，自己考自己。

### 3. KMP 匹配主过程（i 不回退）

**是什么**：双指针扫描——i 走主串、j 走模式串：字符相等（或 j==−1 越界）则 i++、j++ 同时前进；失配则 **j=next[j]** 回退，i 不动。j 走到 n（模式串末尾）即匹配成功，出现位置为 i−n+1（1 起下标）/ i−j（0 起）。

**为什么**：i 不回退所以主串只扫 O(n) 遍；j 每次回退虽然可能连跳多次，但总回退次数 ≤ 总前进次数（j 每次前进才可能回退），均摊下来整个过程 O(n+m)——这就是 KMP 的线性复杂度来源。

**怎么用**（`KMP模板.cpp` 核心，返回首个匹配下标）：
```cpp
int i = 0, j = 0;
while (i < lenStr && j < lenSub) {
    if (j == -1 || str[i] == sub[j]) { i++; j++; }  // j==-1 哨兵：重头比
    else j = next[j];                               // 失配：只退 j
}
if (j >= lenSub) return i - j;   // 匹配成功的起点
return -1;
```
**跟着算**：p="abeababeabf"，s="abeabf"（模板注释样例）。匹配到主串下标 5 时 s[5]='f' 与 p[5]='a' 失配，j=next[5]=2：已匹配的 "abeab" 后缀 "ab" = 前缀 "ab"，i=5 不动、从 s[2]='e' 续比——后续一路相等，返回起点 i−j=5。"上帝视角"下主串的 i 一步都没有往回走。

> ⚠️ 注意事项：`j==−1` 的判断要放在相等判断同支（哨兵的作用就是"退无可退则双双前进"）；求所有出现位置在 `j==n` 分支里处理。

> 🎯 规律：i 永不回头，j 按 next 抄近路，均摊线性。
> 💡 一句话总结：主串不回头，模式串会瞬移。

### 4. 例题：P3375 模板 与 P4391 无线传输（周期问题）

**是什么**：**P3375**【模板】KMP：输出模式串在主串中的**所有**出现位置（1 起），再输出 next 数组——匹配中 `if(j==n){ printf i−n+1; j=net[n]; }`，最后 for 输出 net[1..n]。**P4391**：给一个由某周期子串循环得到的串 s1，求最短周期长度——结论 **答案 = n − next[n]**。

**为什么**：P3375 考"匹配成功后怎么办"——j=net[n] 让已匹配的后缀（=前缀）保留下来，重叠的下次匹配也不会漏。P4391 的直觉：自匹配求 next 相当于"空过一个周期开始匹配"（周期内必然错位，实际是第 i 个周期和第 i+1 个周期比），所以 next[n] 恰好空出一整个周期，前缀去掉这段长度即为周期：n−next[n]。样例 "cabcabca" 看成 "cabcabcab" 的子串，周期 "cab"，n−next[n]=3。

**怎么用**（P4391 只需两行核心）：
```cpp
GetNext(s);            // 自己匹配自己
printf("%d\n", n - next[n]);   // 最短循环节长度
```
跟着算：s="abab"（长度 4），第 1 点的表得 next[4]=2 → 最短周期 = 4−2 = 2，即 "ab" ✓；若串无循环节（next[n]=0），答案就是 n 本身。

> ⚠️ 注意事项：n−next[n] 给出的是**最短**循环元（可能整串）；"cycle 性质"类题（如 Power Strings）同源，都靠 next[n] 发力。

> 🎯 规律：next[n] 是"前缀与全串的最大重合"，全串减它就是周期。
> 💡 一句话总结：判周期，一步式 n−next[n]。

## 🔍 相似概念辨析

### KMP vs 朴素匹配（BF 暴力）

| 维度 | 朴素匹配 BF | KMP |
|------|------------|-----|
| 失配处理 | i、j 都退回（i=i−j+1, j=0） | 只退 j=next[j]，i 不动 |
| 已匹配信息的利用 | 全部丢弃重比 | 靠相同前后缀保留 |
| 时间复杂度 | 最坏 O(n·m) | O(n+m) 严格线性 |
| 额外空间 | O(1) | O(m) 存 next |
| 实现难度 | 一分钟写完 | next 数组易错 |
| 数据敏感 | 对 "aaaa…b" 型数据爆炸 | 任何数据都稳 |
| 典型题 | 小数据水过 | P3375、P4391 |

### next[j] vs next[n]（同一个数组的两种用法）

| 维度 | next[j]（中途失配） | next[n]（全串算完） |
|------|--------------------|---------------------|
| 含义 | s[0..j−1] 的最长相同前后缀 | 整串的最长相同前后缀 |
| 用途 | 失配时 j 的回退目标 | 求/验最短循环节 |
| 使用时机 | 匹配过程、求 next 自身 | 匹配成功后、结束后 |
| 相关操作 | j = next[j] | 周期 = n − next[n] |
| 物理直觉 | "前面哪些白比了" | "串去掉头尾重叠剩什么" |
| 典型应用 | P3375 匹配 | P4391 无线传输 |

## 🧩 本章归纳：一条主线串全章

> 本章主线一句话：**"失配了怎么办" → 已匹配段的最长相同前后缀（next）告诉我退到哪 → 求next 就是模式串自己匹配自己（相等加一、失配跳 next） → 主匹配 i 不回退、j 抄近路 → next[n] 升华为周期结论 n−next[n]**。全章只有一个核心对象 next 数组：中途的 next[j] 是回退路标，末尾的 next[n] 是周期钥匙。与上一章哈希匹配对照：哈希用"变整数"规避逐字符比较，KMP 用"历史信息"让每次失败都有价值——P3375 练全流程，P4391 练 next[n] 的灵光一现。口诀：先背含义再背代码，手算 "abab" 过一遍胜过看十遍。

## 📋 速查表

| 项目 | 内容 |
|------|------|
| next 含义 | next[j] = s[0..j−1] 最长相同（真）前后缀长度 |
| 边界 | 0 起下标：next[0]=−1, next[1]=0；1 起下标：net[1]=0 |
| 求 next 递推 | s[y]==s[i−1] → next[i]=y+1；否则 y=next[y] 重试 |
| 匹配主循环 | 相等(或 j==−1)→i++,j++；失配→j=next[j] |
| 首个出现位置 | j==n 时起点为 i−n（0 起）/ i−n+1（1 起） |

| 最短循环节 | n − next[n] |
| 变量命名 | 禁用 next（关键字），用 nex/net/kmp |
| 复杂度 | 预处理 O(m) + 匹配 O(n)，空间 O(m) |
