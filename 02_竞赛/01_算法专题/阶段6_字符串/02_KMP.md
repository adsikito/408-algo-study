## 本章地图

本章解决一个问题：**「文本里找模式串，怎么不回退文本指针？」**

```text
朴素匹配：失配回退文本指针 → O(n × m)
   ↓
关键观察：失配时模式串「自己该退到哪」与文本无关
   ↓
next（nxt）：模式串每个前缀的最长相等真前后缀 —— 自匹配预处理
   ↓
匹配：文本指针 i 只进不退；模式串指针 j 沿 nxt 链回退
   → O(n + m)（j 每轮至多 +1，累计回退 ≤ +1）
   ↓
产出三形态：
   ├─ 全部匹配位置（P3375）
   ├─ 周期 / 循环节（P4391：n − nxt[m−1]）
   └─ 失配链统计（前缀出现次数 → AC 自动机前传）
```

**为什么这条路径是这样**：KMP 的本质是**「失败信息复用」**——
每次失配，已匹配部分的内部结构（真前后缀）告诉我们模式串最多能「省着退」多少。
**把这个结构预处理成 nxt 数组，匹配就是线性扫描。**

## 核心概念与模板

**是什么**：考研第 3 章讲「next 手算与 nextval」，竞赛侧补三件事：
**0 起下标口径**（fail[i] = 最长相等真前后缀长度，直接用长度不再 +1）、
**失配链的 DP 应用**（统计每个前缀出现次数）、**Z 函数对照**（延伸）。
竞赛口径下 next 数组语义更干净：`nxt[i]` = 模式串 [0, i] 的最长相等真前后缀长度。

**为什么**：`nxt[i]` 告诉失配时模式串指针的最优回退位——
「已经匹配的尾巴」同时也是「模式串的开头」，这就是不用回退文本的原因。

> **【规律】** **口径对照（考研 ⇔ 竞赛）**：考研 `next[j] = 真前后缀长 + 1`
> （下标 1 起，next[1] = 0）；竞赛 `nxt[i] = 真前后缀长`（下标 0 起，nxt[0] = −1）。
> **转换：考研值 = 竞赛值 + 1（整体错一位）**。做不同来源的题先认口径。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
const int N = 1000005;
char s[N], p[N];                          /* s 文本串、p 模式串，0 起下标 */
int nxt[N], f[N];                         /* nxt：自匹配；f：文本匹配位置 */

void getNext(const char *p, int m) {
    nxt[0] = -1;                          /* 竞赛口径：-1 表示无处可退 */
    for (int i = 1, j = -1; i < m; i++) {
        while (j >= 0 && p[i] != p[j + 1]) j = nxt[j];
        if (p[i] == p[j + 1]) j++;
        nxt[i] = j;
    }
}

void kmp(const char *s, int n, const char *p, int m) {
    getNext(p, m);
    for (int i = 0, j = -1; i < n; i++) {
        while (j >= 0 && s[i] != p[j + 1]) j = nxt[j];
        if (s[i] == p[j + 1]) j++;
        if (j == m - 1) {                 /* 完整匹配（结束于 i） */
            printf("%d\n", i - m + 2);    /* 起点（1 起输出） */
            j = nxt[j];                   /* 继续找（可重叠） */
        }
    }
}
```

> **【类比】** nxt 像**接线员的话术手册**：和客户（文本）对不上话时，
> 手册告诉你「退回到第几个标准话术」继续——
> **退多一步浪费时间，退少一步说错话**。
> 手册（nxt）提前按模式串自己跟自己排练（自匹配）写好。

## 本章难点

> **【难点】** **getNext 的循环不变量。**
> 任何时刻 j = 已匹配长度 = p[0..j] 与「以 i−1 结尾的真前后缀」重合——
> `while` 沿 nxt 链退到「还能接上新字符」的最深处，`if` 尝试接上。
> **这两步与主匹配逐字相同**——所以 getNext 又叫「模式串自己匹配自己」。

> **【难点】** **失配链的聚合顺序。**
> 统计前缀出现次数时，`cnt[i] = f[i] + cnt[nxt[i]]` 必须**从深到浅**递推
> （先算 nxt[i] 的 cnt 再算 i）——链的深度方向与下标方向相反，
> **递推顺序写反是本题唯一的坑**（也是 AC 自动机 fail 树统计的前传）。

---

## 本章易错点

> **【头号易错】** **两套口径混用**（考研手算惯性带进竞赛代码：next[0] 写成 0 而非 −1）——
> 样例能碰对、边界全错。

> **【易错】** **匹配成功后 `j = nxt[j]` 漏写**（不可重叠题要 `j = -1` 重置）；
> getNext 的 while 条件 `j >= 0` 漏判导致负下标。

> **【易错】** **输出起点换算**：i 是结束位（0 起），起点 = i − m + 2（1 起输出）——
> 转换只在这一处做（阶段 1 纪律）。

> **【易错】** **周期结论的边界**：n − nxt[m−1] 只在「nxt[m−1] > 0 且 n % 周期 == 0」时
> 才是完整循环节——部分周期与完全周期是两问。

> **【易错】** **f 的累加位置在 j++ 之前**（失配链统计题）——错一位全表错。

## 典型例题

### 例 1　模式串出现位置（模板）　难度：模板题

**题干摘要**：文本与模式串长 10⁶，输出全部匹配起点（1 起）。
**题源**：同类真源见配套练习 T1（P3375 KMP）
**涉及知识点**：知识点 1、2

**解题思路**：

1. **信号**：「找全部出现位置」→ KMP 模板。
2. **方法**：核心模板。

**复杂度**：O(n + m)——i 只进不退，j 每轮至多 +1、累计回退 ≤ +1。

> **【易错】** 可重叠继续 `j = nxt[j]`；不可重叠 `j = -1`；
> 输出起点 = i − m + 2（i 为结束位、0 起）。

---

### 例 2　前缀出现次数统计（失配链 DP）　难度：综合题

**题干摘要**：求模式串每个前缀在文本中出现次数（n ≤ 10⁶）。
**题源**：失配链经典（周期 / 计数类题的共同底座）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「每个前缀的出现次数」→ f 标记 + nxt 链聚合。
2. **方法**：①f[j] 记「匹配到 j 的次数」——匹配推进时 f[j]++；
   ②f 沿 nxt 链向上累加：`cnt[i] = f[i] + cnt[nxt[i]]`（以 i 结尾的匹配里，
   长度 nxt[i] 的前缀也出现）；③答案按前缀长度输出。

```cpp
// g++ -std=c++17 -O2
long long cnt[N];                         /* cnt：沿失配链聚合 */
void countOcc(int n, int m) {
    /* kmp 过程中：if (s[i] == p[j + 1]) f[j]++（j 推进前累加） */
    for (int i = m - 1; i >= 0; i--)
        cnt[i] = f[i] + (nxt[i] >= 0 ? cnt[nxt[i]] : 0);
    /* cnt[i] 即前缀 p[0..i] 的出现次数 */
}
```

**复杂度**：O(n + m)。

> **【易错】** 链上累加必须**从深到浅**（先算 nxt[i] 再算 i）——
> 递推顺序错是本题唯一难点；f 的累加位置在 j++ 之前。

## 本章总结

### 核心内容（一页纸）

1. **nxt[i] = 模式串 [0, i] 的最长相等真前后缀长度**；失配时沿 nxt 链回退。
2. **getNext = 模式串自己匹配自己**——两段代码骨架逐字相同。
3. **文本指针只进不退**：O(n + m)（j 累计回退 ≤ 累计前进）。
4. **口径换算**：考研值 = 竞赛值 + 1（整体错一位）；做题先认口径。
5. **可重叠** `j = nxt[j]`；**不可重叠** `j = -1`。
6. **输出起点 = i − m + 2**（i 为 0 起结束位）。
7. **周期结论**：n − nxt[m−1] 为最小周期（注意「完全循环节」要 n % 周期 == 0）。
8. **失配链计数**：f 沿链聚合，从深到浅（AC 自动机前传）。
9. **删除类复合**（T3）：栈记录历史，删除后 j 回失配位。
10. **哈希 vs KMP**：好写 vs 恒稳；需要结构信息（周期 / 次数）时 KMP 不可替代。
