## 本章地图

本章解决一个问题：**「两个很长的东西是否相等」，能不能不逐位比就回答出来？**

```text
逐位比较是 O(n) → 想把「比较」降到 O(1)
   ↓
思路：把整个串压成一个数（哈希值），比数就是比串
   ↓
但压成一个数会丢信息 → 冲突必然存在 → 需要防范
   ↓
前缀哈希让「任意子串」也能 O(1) 取哈希（不只是整串）
   ↓
有了子串 O(1) 比较，就能与二分复合 → 回文、LCP
```

**为什么这条路径是这样**：哈希的本质是**用「可接受的错误率」换「比较速度」**。
理解这一点，才能理解为什么「防卡哈希」是本章的必掌握项而非可选优化——
**你在用一个不保证正确的工具，就必须自己控制它的失效概率。**

## 核心概念与模板

**是什么**：把字符串看成一个 `b` 进制数，再对一个模数取余，得到一个「指纹」。

```text
前缀哈希： h[i] = h[i-1] × b + s[i]      （s 为字符的数值，如 ASCII）
子串哈希： hash(l, r) = h[r] − h[l-1] × b^(r−l+1)
```

**为什么**：`hash(l, r)` 把长度为 `r-l+1` 的子串压成一个数，**取用是 O(1)**。
这就是「把逐位比较的 O(n) 降为 O(1)」的全部机制。

**怎么用**：

1. 预处理：一遍扫描算出 `h[]` 与 `b` 的幂 `pw[]`。
2. 取子串：直接用公式，**注意幂次是 `r-l+1` 而不是 `r-l`**。
3. 比较：`getHash(l1,r1) == getHash(l2,r2)`，**先比长度再比哈希**。
4. 复合：把 `getHash` 当作 O(1) 的「相等判定函数」，套用二分的框架。

**自然溢出版（最简，也最常被卡）**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
typedef unsigned long long ull;
const int N = 1000005;
const ull BASE = 131;                     /* 常用 131 / 13331 / 1313131 */
char s[N];
ull h[N], pw[N];                          /* 前缀哈希与基的幂 */

/* 预处理：O(n) */
void build(int n) {
    pw[0] = 1;
    for (int i = 1; i <= n; i++) {
        h[i] = h[i - 1] * BASE + (ull)s[i];   /* 自然溢出 = 自动取模 2^64 */
        pw[i] = pw[i - 1] * BASE;             /* 幂同样溢出，但两边口径一致 */
    }
}

/* 取子串 [l, r] 的哈希：O(1) */
ull getHash(int l, int r) {
    /* 边界：l ≥ 1，r ≤ n；幂次必须为 r-l+1 */
    return h[r] - h[l - 1] * pw[r - l + 1];
}
```

**双哈希版（正式赛推荐）**：用两套互不相干的 `(BASE, MOD)` 各算一次，
存成 `pair<ull,ull>` 比对。**单哈希被卡的概率从「可构造」降到「实际不可构造」**。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <utility>
using namespace std;
typedef unsigned long long ull;
typedef pair<ull, ull> Hash;               /* 两个模数下的哈希拼成一对 */

const int N = 1000005;
const ull B1 = 131,  M1 = 1000000007ULL;   /* 模数 1：1e9+7 */
const ull B2 = 137,  M2 = 998244353ULL;    /* 模数 2：998244353 */
char s[N];
ull h1[N], h2[N], p1[N], p2[N];

void build2(int n) {
    p1[0] = p2[0] = 1;
    for (int i = 1; i <= n; i++) {
        h1[i] = (h1[i - 1] * B1 + (ull)s[i]) % M1;   /* 显式取模，不依赖溢出 */
        h2[i] = (h2[i - 1] * B2 + (ull)s[i]) % M2;
        p1[i] = p1[i - 1] * B1 % M1;
        p2[i] = p2[i - 1] * B2 % M2;
    }
}

Hash get2(int l, int r) {
    /* 边界：减法可能为负，加 M 再取模修正 */
    ull x = (h1[r] + M1 - h1[l - 1] * p1[r - l + 1] % M1) % M1;
    ull y = (h2[r] + M2 - h2[l - 1] * p2[r - l + 1] % M2) % M2;
    return Hash(x, y);
}
```

> **【规律】** **两套哈希的 h 不能互相比较。** 自然溢出与显式取模属于**两套口径**，
> 混用会让「本应相等」的两个子串算出不同值。要么全用溢出，要么全用显式取模。

## 本章难点

> **【难点】** **为什么自然溢出不安全，而显式取模也不必安全。**
> 自然溢出相当于模 `2⁶⁴`，其基数存在**极短的循环节**，攻击者可以构造出冲突串；
> 但显式取模同样可能被卡（外部题源 Hash Killer 系列专门构造此类攻击）。
> **结论：安全性不来自「模数大」，而来自「不可预测」**——
> 随机化基数（开赛时用时间戳随机取 `BASE`）比固定大模数更有效。

> **【难点】** **子串哈希公式的推导**。`h[r] - h[l-1] * b^(r-l+1)` 中
> 「为什么是乘法而不是减法」需要理解：前缀哈希是按位「左高右低」排列的，
> 要让 `h[l-1]` 与 `h[r]` 对齐，必须把前者**左移 `r-l+1` 位**。
> **画一次数轴对齐图，这个公式就不会记错。**

---

## 本章易错点

> **【头号易错】** **`getHash` 的幂次写错**。
> 写成 `pw[r - l]` 而非 `pw[r - l + 1]` 时，长度较短的模式串仍可能巧合匹配，
> **小样例通过、大数据必然 WA**。这是本专题的头号失分点。

> **【易错】** **下标 0 / 1 起始混用**。1 起始时 `h[0] = 0`；若代码里出现 `h[-1]` 则越界。

> **【易错】** **单哈希被对拍卡**。本地随便生成的数据几乎撞不出冲突，
> 但外部题源有**专门构造冲突的攻击数据**（Hash Killer 系列，VNOJ 等）。**正式赛一律双哈希。**

> **【易错】** **比较「长度不同但哈希相同」的假相等**。
> 哈希相同的两个串**长度必须相同**才可能真正相等。**先比长度再比哈希。**

> **【易错】** **两套哈希口径混用**。自然溢出与显式取模得到的 h 数组不可互相比较。

## 典型例题

### 例 1　哈希匹配：模式串出现次数　难度：模板题

**题干摘要**：文本串长 `n`、模式串长 `m`（均 ≤ 10⁶），求模式串在文本串中出现的次数（可重叠）。
**题源**：哈希匹配模板题（同类真源见配套练习 T2、T3）
**涉及知识点**：知识点 1、2

**解题思路**：

1. **信号**：「模式串在文本串中出现几次」→ 子串比较问题。
2. **排除**：逐位比较是 O(nm)，n、m 均 10⁶ 时是 10¹²，必然超时。
3. **方法**：先算模式串整串哈希 `hp`，再对文本串每个起点用 `getHash` 取长度 m 的子串
   与 `hp` 比对。**每次比较 O(1)，总计 O(n + m)。**

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
typedef unsigned long long ull;
const int N = 1000005;
const ull BASE = 131;
char t[N], p[N];
ull ht[N], hp[N], pw[N];

int main() {
    int n, m;
    scanf("%d %s %d %s", &n, t + 1, &m, p + 1);   /* 1 起始读入 */
    pw[0] = 1;
    for (int i = 1; i <= n; i++) {
        ht[i] = ht[i - 1] * BASE + (ull)t[i];
        pw[i] = pw[i - 1] * BASE;
    }
    for (int i = 1; i <= m; i++) hp[i] = hp[i - 1] * BASE + (ull)p[i];
    ull target = hp[m];                            /* 模式串整串哈希 */

    int cnt = 0;
    for (int i = 1; i + m - 1 <= n; i++) {         /* 边界：i + m - 1 ≤ n */
        ull cur = ht[i + m - 1] - ht[i - 1] * pw[m];
        if (cur == target) cnt++;
    }
    printf("%d\n", cnt);
    return 0;
}
```

**复杂度**：时间 O(n + m)，空间 O(n)。

> **【易错】** 循环上界必须是 `i + m - 1 <= n`，写成 `i <= n` 会越界取到不存在的字符。

### 例 2　最长回文子串（哈希 + 二分）　难度：综合题

**题干摘要**：求长度 ≤ 10⁶ 的字符串的最长回文子串长度。
**题源**：哈希 + 二分经典复合（同类真源见配套练习 T4）
**涉及知识点**：知识点 2、5

**解题思路**：

1. **信号**：「最长回文」+ 规模 10⁶ → O(n²) 的「枚举中心向两边扩」不行。
2. **关键观察**：以某位置为中心，**若半径 r 是回文，则任意 r' < r 也是回文** ——
   **单调性成立**，可以二分。
3. **方法**：正串哈希 + 反串哈希；枚举中心，二分半径；
   每次判「正串 [i-r, i-1] 与反串对应段是否相等」是 O(1)。总复杂度 O(n log n)。

**解答过程**：

```text
枚举中心 i（含奇偶两种情况）
  二分半径 r ∈ [0, 上界]
     判：以 i 为中心的半径 r 是否回文（用正反哈希 O(1) 判定）
     是 → 记录并尝试更大；否 → 缩小
```

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;
typedef unsigned long long ull;
const int N = 2000005;
const ull BASE = 131;
char s[N], rs[N];
ull h[N], rh[N], pw[N];
int n;

/* 正串子串哈希 */
ull gh(int l, int r) { return h[r] - h[l - 1] * pw[r - l + 1]; }
/* 反串子串哈希 */
ull grh(int l, int r) { return rh[r] - rh[l - 1] * pw[r - l + 1]; }

/* 判断正串 [l, r] 是否回文：与反串的对称段比较 */
bool isPal(int l, int r) {
    int rl = n - r + 1, rr = n - l + 1;    /* 反串中的对应区间 */
    return gh(l, r) == grh(rl, rr);
}

int main() {
    scanf("%s", s + 1);
    n = 0; while (s[n + 1]) n++;
    for (int i = 1; i <= n; i++) rs[i] = s[n - i + 1];   /* 构造反串 */

    pw[0] = 1;
    for (int i = 1; i <= n; i++) {
        h[i]  = h[i - 1]  * BASE + (ull)s[i];
        rh[i] = rh[i - 1] * BASE + (ull)rs[i];
        pw[i] = pw[i - 1] * BASE;
    }

    int best = 1;
    for (int i = 1; i <= n; i++) {
        /* 奇数长度中心 */
        int lo = 0, hi = min(i - 1, n - i);       /* 边界：受两侧长度限制 */
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (isPal(i - mid, i + mid)) lo = mid; else hi = mid - 1;
        }
        best = max(best, 2 * lo + 1);

        /* 偶数长度中心（以 i 与 i+1 之间为中心） */
        lo = 0; hi = min(i, n - i);
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (isPal(i - mid + 1, i + mid)) lo = mid; else hi = mid - 1;
        }
        best = max(best, 2 * lo);
    }
    printf("%d\n", best);
    return 0;
}
```

**复杂度**：时间 O(n log n)，空间 O(n)。

> **【易错】** 三处：
> 1. **奇偶中心必须分开处理**。奇数中心是单点，偶数中心是两个字符之间，半径定义不同。
> 2. **二分上界**是 `min(i-1, n-i)`（奇数）与 `min(i, n-i)`（偶数），写错会越界。
> 3. **反串下标映射**要画图验证一次：`rl = n - r + 1`、`rr = n - l + 1`。

## 本章总结

### 核心内容（一页纸）

1. **前缀哈希**：`h[i] = h[i-1] × b + s[i]`；**子串哈希**：`h[r] − h[l-1] × b^(r−l+1)`。
2. **幂次是 `r-l+1`**，不是 `r-l`。**这是头号易错点，小样例查不出来。**
3. **`getHash` 是 O(1) 的「相等判定函数」** —— 有了它，二分就能用在字符串上。
4. **比较前先比长度**。长度不同则必然不等，哈希相同只是巧合。
5. **自然溢出 = 模 2⁶⁴**，**与显式取模是两套口径，不可混用**。
6. **单哈希可被主动构造冲突**，不是「概率低」而是「可攻击」。外部 Hash Killer 攻击数据即为此设计；本题表用 P12197（加强版）与 P12198（双哈希）承载同一位教学。
7. **正式赛一律双哈希**（两套 `BASE + MOD`，存 `pair` 比对）；更稳妥的做法是**随机化基数**。
8. **安全性来自不可预测，不来自模数大小。**
9. **两种基本复合**：哈希 + 二分求最长回文 / LCP（单调性成立即可二分）。
10. **选型**：现场求快用哈希；会被 hack 用双哈希；要求绝对正确用 KMP。
