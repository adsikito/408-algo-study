## 第一章：枚举与模拟

> 课件来源：`1.枚举&模拟.pptx`
>
> 例题代码：`P1003.cpp`（铺地毯）、`LC59.cpp`（螺旋矩阵 II）、`P1328.cpp`（生活大爆炸版石头剪刀布）

## 🗺️ 本章地图

本章解决"没有巧方法时的正解"：数据范围小，就直接把所有可能试一遍（枚举），或按题意一步步照做（模拟）。学习顺序：先掌握枚举四要素与枚举顺序（P1003），再练模拟的边界管理（LC59），最后学"打表+取模"处理周期（P1328）。三题共用第零章的做题四步法；枚举与模拟有时统称暴力，可以不做严格区分——先会暴力，才懂后面章节的优化。

## 📌 本章重点

⭐ **枚举四要素**：找对答案集合 → 答案成立条件 → 减小枚举范围 → 选择合适的枚举顺序
⭐ **枚举顺序即正确性**：P1003 从后往前枚举地毯，因为"后铺的盖在上层"，找到即 break
⭐ **模拟的边界管理**：LC59 用 l/r/t/b 四边界"填一圈缩一边"，循环直到 num>n*n
⭐ **打表 + 取模**：P1328 把 25 组胜负关系补全成 f[5][5] 表；两出拳序列周期不等，各自独立取模

## 🔥 本章难点

🔥 **LC59 边界收缩时机**：每条边"先填完、再缩界"，四个方向的 ++/-- 位置极易写乱，必须手推 n=3
🔥 **P1328 双周期取模**：两方周期 na≠nb，必须 (x+1)%na、(y+1)%nb 各自循环，且胜负要查两个方向 f[a[x]][b[y]] 与 f[b[y]][a[x]]

## ⚠️ 本章易错点

⚠️ **边界漏等号**：P1003 判点在地毯内必须写 `a[i]<=x && x<=a[i]+g[i]`，右下角也是覆盖范围，两个 <= 少一个就 WA
⚠️ **break 后忘收尾**：找到答案 break 后，还要靠 flag 判断"一个都没找到"输出 -1
⚠️ **模拟边界缩错**：LC59 若把 t++ 写在填数前（或漏掉），下一圈就会覆盖已填格子；必须"行→缩→列→缩"交替推进
⚠️ **周期取模用错模数**：P1328 两序列周期不同，统一用一个模数（如 n）直接 WA
⚠️ **没看数据范围就枚举**：枚举前先按 1s=10^8 估算，n 大时暴力会 TLE——"暴力"不等于"无脑"

## 📖 知识点讲解

### 1. 枚举：把可能的答案一个个试

**是什么**：一句话——不知道答案是谁，就把所有候选挨个叫出来验明正身。课件定义：枚举是基于已有知识来猜测答案的一种问题求解策略，思想是不断地猜测，从可能的答案集合中一一尝试，判断题目的条件是否成立。

**为什么**：答案集合不大、或没有更聪明的算法时，枚举就是正解（"暴力出奇迹"）；它还是检验其他算法的对照器——写完优化解法，拿暴力对拍。

**怎么用**——课件给的枚举四要素：
1. 找对答案集合（枚举对象是谁？如"1~100 最大的质数"应从 100 往下枚举）
2. 答案成立的条件（题目给出，翻译成 if）
3. 减小枚举范围（提高效率）
4. 选择合适的枚举顺序（从大到小、从后往前，找到即停）

模板：
```cpp
for (每个候选答案 ans)          // ①答案集合
    if (check(ans)) {           // ②成立条件
        记录/输出 ans; break;   // ③④范围合适、顺序正确时找到即停
    }
if (没找到) 输出特殊值;          // 如 -1
```
例题 P1003（铺地毯）：n 张地毯按时间顺序铺，问点 (x,y) 最上面是哪张。枚举对象=每张地毯；条件=点在矩形内（含边界）；顺序=**从后往前**（后铺的盖在上层，正好是所求），第一块满足的直接输出。关键代码：
```cpp
for (int i = n; i >= 1; i--)
    if (a[i] <= x && x <= a[i]+g[i] && b[i] <= y && y <= b[i]+k[i]) {
        printf("%d\n", i); flag = 1; break;
    }
if (!flag) printf("-1\n");
```
跟算：地毯 1 覆盖 (1,1)~(4,4)、地毯 2 覆盖 (2,2)~(3,3)、地毯 3 覆盖 (3,3)~(3,3)，问点 (3,4)。从后往前：i=3 时 y=4 不在 [3,3] 不覆盖；i=2 时 y=4 不在 [2,3] 不覆盖；i=1 时 (3,4)∈[1,4]×[1,4] 覆盖 → 输出 1。若正着枚举，即使遇到地毯 1 也不能停，必须记"最后一块满足的"——枚举顺序不同，代码和效率都不同。

> ⚠️ 注意事项：矩形是闭区间（右下角 a+g、b+k 也算覆盖），两个等号不能省；数据范围决定枚举总次数能否过 1s=10^8。

> 🎯 规律：凡问"最上层/最后一次/覆盖后留下"，倒着枚举 + 找到即停。

> 💡 一句话总结：枚举四步走，顺序定对错。

### 2. 模拟：照着题意一步步做

**是什么**：一句话——题目让你干什么你就干什么，代码是题意的忠实翻译。课件定义：直接模拟题目中要求的操作来求解；模拟题通常码量大、操作多，难以查错，但思路一般较简单，具体操作步骤可能需要自己分析得出。

**为什么**：很多过程类题（构造、填图、走格子）没有公式解，唯一出路是复现过程；模拟练的正是代码组织力——把复杂操作拆成清晰的步骤和边界。

**怎么用**——例题 LC59（螺旋矩阵 II）：把 1~n² 顺时针螺旋填进 n×n 矩阵。课件思路：定义左右上下边界 l,r,t,b；num 从 1 到 n*n；按"从左到右、从上到下、从右到左、从下到上"循环填入，每填完一条边把对应边界向内缩 1（如从左到右填完后 t+=1）。
```
n=3 的填入次序（→ ↓ ↑ ← 表示方向）：
 →  →  →      上边第 t 行：i=l..r，填完 t++
 ↑        ↓    右边第 r 列：i=t..b，填完 r--
 ↑        ↓    下边第 b 行：i=r..l，填完 b--
 ←  ←  ←      左边第 l 列：i=b..t，填完 l++
1  2  3
8  9  4      ← 填到 9 时 num>n*n，循环结束
7  6  5
```
```cpp
int t=0, b=n-1, l=0, r=n-1, num=1;
while (num <= n*n) {
    for (int i=l; i<=r; i++) mat[t][i] = num++;  t++;  // 先填满，再缩界
    for (int i=t; i<=b; i++) mat[i][r] = num++;  r--;
    for (int i=r; i>=l; i--) mat[b][i] = num++;  b--;
    for (int i=b; i>=t; i--) mat[i][l] = num++;  l++;
}
```
跟算 n=3：第一圈填 1~8（上 1,2,3；右 4,5；下 6,7；左 8）；此时 t=b=l=r=1，num=9≤9，第二圈只有"上边"非空（for 区间 i=1..1）填 mat[1][1]=9；num=10 结束。第二圈的"右边/下边/左边"因区间为空被 for 条件自然跳过——"先填后缩 + for 区间判断"让单行单列无需特判。

> ⚠️ 注意事项：四个 for 的区间端点与缩界语句一一对应，任何一处 ++/-- 错位都会重复填或漏填；提交前手推 n=1、n=2、n=3。

> 🎯 规律：平面过程类模拟，用"边界变量 + 收缩"代替"第几圈"的计算，天然规避中心行列特判。

> 💡 一句话总结：填完一边缩一边，四边循环到填满。

### 3. 打表 + 取模：处理周期性（P1328）

**是什么**：一句话——打表是把题目里繁琐的规则预先算成表格，查询 O(1)；取模是利用周期性，把无限进行的过程压进循环下标。课件思路（P1328 石头剪刀布加强版）：把题目的得分表补全，整理成整型二维数组 f[5][5]，查结果时取 f[a][b] 即可；出拳有周期性规律，但**周期长度不一定相等**——取模循环。

**为什么**：5 种手势两两胜负共 25 组，硬写 if-else 又长又易错；两人周期 na、nb 一般不同，必须各模各的长度，才能对齐"每轮各出第几个手势"。

**怎么用**：
```cpp
int f[5][5] = { ... };            // 打表：补全 25 组胜负，f[a][b]=1 表示 a 赢 b
x = y = 0;                        // 各自当前出的是序列第几个
for (int i = 1; i <= n; i++) {
    suma += f[a[x]][b[y]];        // A 对 B 的结果
    sumb += f[b[y]][a[x]];        // 反方向再查一次！
    x = (x + 1) % na;             // 各自按自己的周期取模
    y = (y + 1) % nb;
}
```
跟算：na=3，a={0,4,2}；nb=2，b={0,3}。第 1 轮查 f[a[0]][b[0]]=f[0][0]；第 2 轮 f[a[1]][b[1]]=f[4][3]；第 3 轮 f[a[2]][b[0]]=f[2][0]（y 已回绕）；第 4 轮 f[a[0]][b[1]]=f[0][3]（x 已回绕）——两个下标像两根齿距不同的齿轮，各转各的。

> ⚠️ 注意事项：胜负表必须双向都查（A 对 B 与 B 对 A 是表中两个不同格子）；两人得分用两个计数器分开累计。

> 🎯 规律：见"两两关系规则"→ 打表，把 if-else 变查表；见"循环/周期出招"→ (下标 % 周期) 索引。

> 💡 一句话总结：规则进表格，周期进取模。

## 🔍 相似概念辨析

**组1：枚举 vs 模拟**

| 对比维度 | 枚举 | 模拟 |
|---|---|---|
| 各自定义 | 从可能的答案集合中一一尝试，判断条件是否成立 | 直接模拟题目中要求的操作来求解 |
| 核心区别 | 枚举的对象是"答案"，逐一验证 | 复现的对象是"过程"，逐步执行 |
| 各自特点 | 核心在"集合+条件+范围+顺序"四要素 | 核心在"操作步骤+边界"的忠实翻译 |
| 使用场景 | 找满足条件的解（P1003 找最上层地毯） | 求过程终态/全程结果（LC59 螺旋填数） |
| 典型示例 | 枚举 1~n 判质数 | 按规则一圈圈填矩阵 |
| 记忆口诀 | 枚举试答案，模拟走过程（课件：统称暴力，可不做严格区分） |

**组2：枚举（循环暴力）vs 暴搜（搜索枚举）**

| 对比维度 | 枚举（循环暴力） | 暴搜（搜索算法） |
|---|---|---|
| 各自定义 | 用多重 for 循环遍历答案空间 | 课件：用搜索算法枚举答案（找到符合条件的答案） |
| 核心区别 | 适合"每个维度取值独立"的规则空间 | 适合"步骤有依赖、需要回溯"的空间 |
| 各自特点 | 代码直白，维度一多循环爆炸 | 天然处理不定长/组合类问题 |
| 使用场景 | P1003 枚举地毯、P1387 枚举边长（第二章） | 后续 DFS/BFS 章节的方案枚举 |
| 典型示例 | 二重循环枚举 (i,j) | 从每个起点搜所有路径 |
| 记忆口诀 | 定长循环枚举，不定长交给搜索 |

## 📋 速查表

| 模板 | 复杂度 | 适用条件 |
|---|---|---|
| 枚举答案 + 条件判断 | O(集合大小 × 单次判断) | 集合可枚举且总量过得了 1s=10^8 |
| 倒序枚举 + 找到即停 | 同上（常数更小） | 求"最上层/最后一次"满足条件的对象 |
| 四边界螺旋模拟 | O(n²) | 平面按圈/螺旋处理 |
| 打表 + 取模循环 | O(n + 预处理) | 规则可表化；过程有周期 |

```cpp
// 枚举骨架（默写级）
for (int i = n; i >= 1; i--)          // 顺序按题意选
    if (满足条件(i)) { ans = i; break; }
if (没找到) 输出特殊值(-1 等);
```
