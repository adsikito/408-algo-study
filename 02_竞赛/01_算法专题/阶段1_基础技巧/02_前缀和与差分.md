## 本章地图

本章解决一个问题：**「区间操作」能不能不做区间操作？**

```text
最朴素：区间求和 → 遍历区间 O(n)
       区间整体加 → 遍历区间 O(n)
   ↓
关键观察：区间操作可以拆成「端点操作」的差
   ↓
求和：把区间拆成两个前缀之差        → 前缀和，查 O(1)
加分：把区间拆成两个端点上的加减    → 差分，改 O(1)
   ↓
两者互为逆运算：对差分求前缀和 = 还原原数组
   ↓
推广到二维：把「区间」换成「矩形」
   求和使用容斥；修改使用四角标记
```

**为什么这条路径是这样**：前缀和与差分**不是两种技巧，而是同一件事的两个方向**。
「前缀和 = 累积」，「差分 = 相邻差」——一个求导，一个积分。
**理解这层对偶关系，就只需要记一套代码的推导，而不是背四段模板。**

## 核心概念与模板

**是什么**：
- **前缀和** `s[i] = a[1] + … + a[i]`：把区间和从 O(n) 压到 **O(1)**。
- **差分** `d[i] = a[i] − a[i−1]`：把区间整体加减从 O(n) 压到 **O(1)**。

**为什么**：两者是**逆运算**——对 `d` 求前缀和即还原 `a`。
因此「区间求和」与「区间修改」可以用同一套数学结构解决两个方向的问题。

> **【记忆】** **查多用前缀和，改多用差分。**

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 100005;
long long a[N], s[N], d[N];

/* 一维前缀和：建 O(n)，查 O(1) */
void build(int n) {
    for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];
}
long long query(int l, int r) { return s[r] - s[l - 1]; }   /* 注意 l-1 */

/* 一维差分：[l, r] 整体加 x，改 O(1)，还原 O(n) */
void add(int l, int r, long long x) {
    d[l] += x;
    d[r + 1] -= x;                       /* r+1 处抵消，闭区间必须写这一行 */
}
```

**二维前缀和（容斥）**——「多加了要减，多减了要加」：

```text
建：s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1]
查：(x1,y1)-(x2,y2) 的和
    = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]
```

**二维差分（四角标记）**——矩形 (x1,y1)-(x2,y2) 整体加 x：

```text
d[x1][y1]     += x
d[x1][y2+1]   -= x
d[x2+1][y1]   -= x
d[x2+1][y2+1] += x          ← 右下角是「加」（因为被减了两次）
随后对 d 求二维前缀和即还原
```

> **【类比】** 前缀和像**银行流水**：想知道某段区间内花了多少，
> 用「截至今天的总额」减去「截至昨天之前的总额」即可（两数相减 O(1)），
> 不必把这段的每笔都加一遍。
> 差分像**记账时的调整凭证**：要给人人加 100 元，
> 不必逐个改余额，只需记「从第 3 天起 +100，从第 8 天起 −100」——
> **改动只落在两个端点上，最后统一结算。**

## 本章难点

> **【难点】** **二维容斥的符号方向**。四个项的加减对应「多加了要减、多减了要加」，
> 但哪一项是加哪一项是减，纯靠记忆极易写错。
> **可靠做法：画一个 2×2 的小矩阵手推一次**，四个项的来源就清楚了，
> 之后不必再背（见典型例题 2 的手推表）。

> **【难点】** **二维差分的四角符号**。三个角是减、只有右下角是加，
> 原因是「右下角那块被左上、右上、左下各减了一次，需要补回来」。
> **不理解这一点，就会写成四个角两两配对，导致矩形内数据全错。**

---

## 本章易错点

> **【头号易错】** **查询写成 `s[r] - s[l]`**（应为 `s[l-1]`）；
> **差分忘记在 `r+1` 处减**。两者都把「闭区间」错成了「左闭右开」。
> **自测方法：写完立刻用长度为 1 的区间（`l == r`）测一次** ——
> 这类错误在长区间上往往看不出。

> **【易错】** **前缀和数组不用 `long long`**。10⁵ 个 10⁹ 累加可达 10¹⁴，
> 远超 `int` 上限 2.1×10⁹。**差值与和值都必须 `long long`。**

> **【易错】** **差分数组开小了**。`add(l, r, x)` 会写 `d[r+1]`，当 `r == n` 时越界。
> **数组要开 `n + 2`。**

> **【易错】** **差分修改后直接输出 `d`**。`d` 只是「调整凭证」，
> **必须求一次前缀和才能得到修改后的原数组。**

> **【易错】** **在有修改的场景下仍用前缀和**。每次修改后重建是 O(n)，
> 总代价 O(nq)——**这不是优化，是没优化。**

## 典型例题

### 例 1　区间和查询（一维前缀和）　难度：模板题

**题干摘要**：n, q ≤ 10⁵，q 次询问 `[l, r]` 的和。
**题源**：同类真源见配套练习 T1
**涉及知识点**：知识点 1

**解题思路**：

1. **信号**：「q 次区间求和」+ 数组不变 → 前缀和。
2. **排除**：每次遍历区间是 O(nq) = 10¹⁰，必然超时。
3. **方法**：读入时边读边建前缀和，查询 O(1)。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 100005;
long long s[N];                          /* 必须是 long long */

int main() {
    int n, q;
    scanf("%d %d", &n, &q);
    for (int i = 1; i <= n; i++) {
        long long x;
        scanf("%lld", &x);
        s[i] = s[i - 1] + x;             /* 边读边建，省一个数组 */
    }
    while (q--) {
        int l, r;
        scanf("%d %d", &l, &r);
        printf("%lld\n", s[r] - s[l - 1]);   /* 边界：l-1，且 l=1 时用 s[0]=0 */
    }
    return 0;
}
```

**复杂度**：时间 O(n + q)，空间 O(n)。

> **【易错】** `l = 1` 时用到 `s[0]`，因此 `s[0]` 必须存在且为 0——
> 这正是「1 起始 + 留出下标 0」约定的用处。

### 例 2　二维前缀和求最大全 1 正方形　难度：变式题

**题干摘要**：n × m 的 0/1 矩阵（n, m ≤ 100），求不包含 0 的最大正方形的边长。
**题源**：洛谷 P1387 最大正方形（同类真源见配套练习 T2）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「子矩阵内是否全为 1」→ 二维前缀和 + 枚举。
2. **观察**：若某边长的正方形内元素和恰等于**面积**，则该正方形内全为 1。
3. **方法**：预处理二维前缀和 → 枚举左上角与边长 → O(1) 判和。

**解答过程**（容斥的来历，用 2×2 手推）：

```text
要求 1 行 1 列到 2 行 2 列的四个格子之和：

   s[2][2]  = 红 + 黄 + 蓝 + 绿        （左上角到右下角的全部）
   s[0][2]  = 0
   s[2][0]  = 0
   s[0][0]  = 0

若求 (2,2)-(2,2) 单格：s[2][2] - s[1][2] - s[2][1] + s[1][1]
                        = 全部 - 上方 - 左方 + 左上（被减了两次要补回）
```

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 105;
int s[N][N];

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            int x; scanf("%d", &x);
            /* 建：上加左加自己，再减去重复的左上 */
            s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + (x == 0);
        }
    int ans = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            for (int k = 1; i + k - 1 <= n && j + k - 1 <= m; k++) {
                /* 边界：正方形右下角不越界 */
                int x2 = i + k - 1, y2 = j + k - 1;
                int sum = s[x2][y2] - s[i - 1][y2] - s[x2][j - 1] + s[i - 1][j - 1];
                if (sum == 0) ans = (k > ans) ? k : ans;   /* 全 0 则无 1，合法 */
            }
    printf("%d\n", ans);
    return 0;
}
```

**复杂度**：时间 O(n·m·min(n,m))（n, m ≤ 100 时约 10⁶），空间 O(n·m)。

> **【易错】** 两处：
> 1. **二维前缀和的减项漏写**。只写 `s[i-1][j] + s[i][j-1] + a[i][j]`
>    会把左上角区域重复计算一次。
> 2. **判定条件**：本题求「不含 0 的最大正方形」，
>    因此统计的是 **0 的个数**，`sum == 0` 才合法（若统计 1，则应 `sum == k*k`）。

## 本章总结

### 核心内容（一页纸）

1. **前缀和** `s[i] = s[i-1] + a[i]`；区间和 `s[r] - s[l-1]`。**注意 `l-1`。**
2. **差分** `d[i] = a[i] - a[i-1]`；区间加 `d[l] += x, d[r+1] -= x`。**注意 `r+1` 那一行。**
3. **两者互为逆运算**：对差分求前缀和 = 还原原数组。只需记这一层，不必背两套。
4. **口诀：查多用前缀和，改多用差分。**
5. **差分数组要开 `n + 2`**，因为会写到 `d[r+1]`（`r == n` 时越界）。
6. **前缀和与差分数组都必须 `long long`**，10⁵ 个 10⁹ 累加达 10¹⁴。
7. **写完立刻用长度为 1 的区间自测**（`l == r`），可发现「闭/开区间」类错误。
8. **二维前缀和**（容斥）：建时「上加左加自己减左上」；查时「多加了减、多减了加」。
9. **二维差分**（四角标记）：三个角减、**右下角是加**。
10. **差分修改后必须求一次前缀和**才能得到终态，不能直接输出 `d`。
11. **适用边界**：数组必须静态（不变）。**有在线修改时必须转线段树/树状数组**（阶段 8）。
12. **复合套路**：二分答案的 `check` 里用差分 O(n) 判定 → 得到「差分 + 二分」这一高频组合（T5）。
