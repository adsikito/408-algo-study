## 第三章：尺取法

> 课件来源：`3.尺取法.pptx`
>
> 例题代码：`例题代码\LC LCR 008.cpp`（和大于等于 target 的最短子数组，即 LC 209 同题）、`例题代码\LC 713.cpp`（乘积小于 K 的子数组）、`例题代码\LC 2379.cpp`（得到 K 个黑块的最少涂色色）

## 🗺️ 本章地图

本章解决一个问题：把所有区间枚举一遍是 O(n²)，n 一大就死，能不能一遍扫完？尺取法（滑动窗口/双指针法）的答案：记 (l, r) 为以 r 结尾的合法区间，**r 主动右扩、l 被动右缩、谁都不回头**，每个元素进出窗口各一次，O(n) 完事。前提是课件强调的**单调性**：固定一个边界时，区间越长区间权值和越大（或越小）。三道例题练三种问法：LCR 008 求最短合法窗口、LC 713 数合法窗口个数、LC 2379 定长窗口取最值。

## 📌 本章重点

⭐ **尺取流程**：外层枚举 r（每轮右移一格），内层在前提下尽量右移 l；l 从不回退是 O(n) 的根源
⭐ **适用前提——单调性**：固定一个边界，区间越长指标越"过"（权值和随区间长度单调变化）；不单调先别滑
⭐ **变长窗口求最短（LCR 008）**：sum≥target 时尽量缩 l，ans=min(ans, r-l+1)；全部元素和 <target 答案为 0
⭐ **变长窗口计数（LC 713）**：以 r 为右端点的合法子数组恰有 r-l+1 个，逐右端点累加
⭐ **定长窗口增量维护（LC 2379）**：先建 k 长窗，滑动一次"出 blocks[l]、进 blocks[r]"，白块数取最小

## 🔥 本章难点

🔥 **`ans += (r-l+1)` 为什么不重不漏**：以 r 结尾的子数组左端点只能取 l..r 共 r-l+1 个，且窗口乘积 <K 时其中任何前缀更小、全部合法——一次累加恰好数完
🔥 **收缩条件的两种语义**：LCR 008 用 `sum-nums[l]>=target`（去头仍合法才去头），l 停下时窗口恰是"以 r 结尾的最短合法窗"；条件写错（如 `sum>target`）会把合法窗口缩没
🔥 **单调性破坏即失效**：区间和含负数时"越长越大"不成立，尺取可能漏最优解（LC 862 要改前缀和+单调队列）

## ⚠️ 本章易错点

⚠️ **忘记无解边界**：nums 全部元素之和 <target 时无合法窗口，必须返回 0（代码 `ans==INT_MAX` 兜底转 0）
⚠️ **LC713 内层漏 `l<=r`**：k 很小（0 或 1）时要把 l 缩到 r+1，使 r-l+1=0 计"空窗零个"；少了它既可能死循环又可能越界
⚠️ **出窗进窗的下标写错**：LC2379 先 `blocks[l]` 减（l 还没 ++）再 `blocks[r]` 加、最后 l++；顺序或下标错一个，窗口就错
⚠️ **乘积溢出**：LC713 的 int 能活，靠的是 p≥k 立刻收缩把 p 压在 k×1000≤10^9 内；若元素范围更大必须 long long
⚠️ **无符号比较陷阱**：`r+1<=blocks.size()-1` 中 size() 是无符号数，int 与它比较会隐式转换，边界处要留心

## 📖 知识点讲解

### 1. 尺取法：r 扩 l 缩，一遍扫完

**是什么**：白话——像一把卡尺的两脚卡在数组上滑：右脚 r 负责扩张（吞进新元素），左脚 l 负责收缩（吐掉旧元素），始终维护一个满足条件的区间（滑动窗口）。严格说：枚举每个 r，(l, r) 表示以 r 为终点的合法区间；l 只在需要时右移、直到"再移就不合法"为止。l、r 都只前进不后退，课件定义为线性算法 O(n)。

**为什么**：暴力二重循环枚举所有 (l, r) 是 O(n²)，其中大量区间"一看就不可能合法"或"合法但绝不是答案"。课件总结尺取法两大优点：**不会枚举到一定不满足条件的区间；不会枚举到虽然满足条件但一定不是答案的区间**。而 l 不回退的依据是单调性：若 (l, r) 不合法，则更长的 (l, r+1) 更不合法——所以 r 右移后 l 不必回头，两根指针总移动量 O(n)。

**怎么用**——通用骨架（三步：扩 → 缩 → 统计）：
```cpp
int l = 0, r = 0;              // 双指针
while (r <= n-1)
{
    sum += nums[r];            // 1. r 扩：新元素进窗
    while (窗口不满足条件)      // 2. l 缩：只右移、不回头
        sum -= nums[l++];
    // 3. 此刻 [l, r] 合法，按题意统计 / 更新 ans
    r++;
}
```
**跟算**：nums=[2,3,1,2,4,3]，s=7（这就是 LCR 008 代码在本组数据上的真实执行轨迹）：

| r | 进窗元素 | sum（扩后） | ≥7？ | l 的移动 | 窗口 [l,r] | 长度 r-l+1 | ans |
|---|---|---|---|---|---|---|---|
| 0 | 2 | 2 | 否 | 不动 | [0,0] | 1 | ∞ |
| 1 | 3 | 5 | 否 | 不动 | [0,1] | 2 | ∞ |
| 2 | 1 | 6 | 否 | 不动 | [0,2] | 3 | ∞ |
| 3 | 2 | 8 | 是 | 8-2=6<7，缩不动 | [0,3] | 4 | 4 |
| 4 | 4 | 12 | 是 | 去 2→sum=10；去 3→sum=7；再去 1 就 <7 停 | [2,4] | 3 | 3 |
| 5 | 3 | 10 | 是 | 去 1→sum=9；去 2→sum=7；再去 4 就 <7 停 | [4,5] | 2 | **2** |

r 走到头，答案 2（子数组 [4,3]）。观察：l 从 0 一路走到 4 从未回头，l、r 各最多走 n 步——这就是 O(n) 的来历。

> ⚠️ 注意事项：三步顺序固定——先扩（进窗）、再缩（出窗）、后统计；统计永远发生在"窗口合法"的时刻，别在缩到不合法后还拿去更新答案。
> 🎯 规律：连续区间 + 指标随长度单调 + 求最短/最长/计数 → 先想尺取；指标不单调（含负数）→ 尺取失效。
> 💡 一句话总结：r 扩 l 缩，一遍扫完。

### 2. LCR 008：和大于等于 target 的最短子数组

**是什么**：正整数数组里找"元素和 ≥ target 的最短连续子数组"，返回其长度；不存在返回 0。白话——最短的"凑够 7 斤"的一段连续货。

**为什么**：正数保证"区间越长和越大"（单调性成立），所以对每个 r：不够就去扩（r 前进），够了就去试缩（l 前进），最优答案一定在某个"刚够"的窗口上被取到。暴力 O(n²) 由此被压成 O(n)。

**怎么用**——思路 + 关键代码（`LC LCR 008.cpp`）：
```cpp
while (r <= n-1)
{
    sum += nums[r];                        // 扩：nums[r] 进窗
    if (sum >= target)                     // 合法了才谈"最短"
    {
        while (l <= r && sum - nums[l] >= target)  // 去掉头仍合法才去头
        {
            sum -= nums[l];
            l++;
        }
        ans = min(ans, r - l + 1);         // 此刻 = 以 r 结尾的最短合法窗
    }
    r++;                                   // 下一个右端点
}
if (ans == INT_MAX) ans = 0;               // 全体之和 <target：无解 → 0
```
收缩条件 `sum-nums[l]>=target` 的语义是"去掉 nums[l] 之后窗口依然合法"——内层 while 停下时，窗口恰是"再缩一格就不合法"的最短合法窗口。知识点 1 的跟算表（[2,3,1,2,4,3]，target=7）正是这段代码的完整执行轨迹。

> ⚠️ 注意事项：ans 初值 INT_MAX 是"哨兵"——既当无穷大参与 min，又在最后转成 0 报告无解；两职一体别拆散。
> 🎯 规律：约束是"≥ 下限"型 → 越长越易满足 → r 扩求达标、l 缩求最短。
> 💡 一句话总结：先扩够，再缩短。

### 3. LC 713：乘积小于 K 的子数组个数

**是什么**：正整数数组里数"乘积 < k 的连续子数组"个数。注意问法从"最值"变成"**计数**"——尺取照用，统计方式换掉。

**为什么**：乘积随长度单调增（元素 ≥1），所以以 r 结尾的合法子数组一定是 [l..r], [l+1..r], …, [r..r] 这一整段，共 r-l+1 个——把每个 r 的账加起来就是总数，不重不漏。逐个枚举子数组是 O(n²)，这里 O(n)。

**怎么用**——思路 + 关键代码（`LC 713.cpp`）：
```cpp
while (r <= n-1)
{
    p *= nums[r];                 // 扩：乘进 nums[r]
    while (l <= r && p >= k)      // 不合法就缩；l 最多被推到 r+1
    {
        p /= nums[l];
        l++;
    }
    ans += (r - l + 1);           // 以 r 结尾的合法子数组个数
    r++;
}
```
**跟算**：nums=[10,5,2,6]，k=100：

| r | 进窗 | p（扩后） | ≥100？ | l 的移动 | 窗口 | r-l+1 | ans |
|---|---|---|---|---|---|---|---|
| 0 | 10 | 10 | 否 | — | [0,0] | 1 | 1 |
| 1 | 5 | 50 | 否 | — | [0,1] | 2 | 3 |
| 2 | 2 | 100 | 是 | 除掉 10 → p=10 | [1,2] | 2 | 5 |
| 3 | 6 | 60 | 否 | — | [1,3] | 3 | **8** |

共 8 个：[10]、[5]、[2]、[6]、[10,5]、[5,2]、[2,6]、[5,2,6] ✓（[10,5,2] 乘积恰好 100，不算）。

> ⚠️ 注意事项：内层 `l<=r` 是双保险——k 很小（如 0、1）时连单个元素都不合法，l 被推到 r+1，此时 r-l+1=0 表示"以 r 结尾的合法子数组为零"，既防死循环又保正确；除法收缩还要求乘法可逆（本题 nums[i]≥1 无 0 元素）。
> 🎯 规律：计数题固定右端点分段统计——每个 r 收一次 r-l+1，天然不重不漏。
> 💡 一句话总结：右端点收账，r-l+1。

### 4. LC 2379：定长窗口——出 l 进 r

**是什么**：blocks 由 'B'（黑）/'W'（白）组成，问最少把几个 'W' 涂成 'B'，能出现长度恰为 k 的全黑连续块。课件点破本质：**就是求所有长度为 k 的窗口里，白块数量的最小值**。

**为什么**：窗口长度固定为 k，根本不需要伸缩——从 [0, k-1] 出发，每滑一格只有一个元素出窗、一个元素进窗，白块数 O(1) 增量维护；共 n-k+1 个窗口，总 O(n)。

**怎么用**——思路 + 关键代码（`LC 2379.cpp`）：
```cpp
int wl = 0;                              // 当前窗口内 W 的个数
for (int i = 0; i <= k-1; i++)           // 1. 建第一个窗口 [0, k-1]
    if (blocks[i] == 'W') wl++;
r = k-1; ans = wl;                       // ans 初值 = 第一个窗口的白块数
while (r+1 <= blocks.size()-1)           // 2. 还能右滑就滑
{
    r++;
    if (blocks[l] == 'W') wl--;          // 左端出窗（注意 l 此刻还没 ++）
    if (blocks[r] == 'W') wl++;          // 右端进窗
    l++;
    ans = min(ans, wl);                  // 3. 定长窗口取最值
}
```
**跟算**：blocks="WBWBBW"，k=3：

| 步 | 出（blocks[l]） | 进（blocks[r]） | wl | 窗口 | ans |
|---|---|---|---|---|---|
| 建窗 | — | — | 2（W,B,W） | [0,2] | 2 |
| 滑 1 | 'W'（下标0）→1 | 'B'（下标3）→1 | 1 | [1,3] | 1 |
| 滑 2 | 'B'→1 | 'B'→1 | 1 | [2,4] | 1 |
| 滑 3 | 'W'（下标2）→0 | 'W'（下标5）→1 | 1 | [3,5] | 1 |

答案 1（把 [3,5] 里的那个 W 涂黑即可）。

> ⚠️ 注意事项：出窗读的是 blocks[l]，且必须在 l++ 之前；ans 的初值是第一个窗口的 wl，不是 0 也不是 INT_MAX。
> 🎯 规律：定长窗口 = 建窗一次 + 滑 n-k 次，每次"出一个、进一个、查一个"，增量维护 O(1)。
> 💡 一句话总结：出 l 进 r，定长也滑。

## 🔍 相似概念辨析

**组1：尺取法 vs 双循环暴力枚举**

| 对比维度 | 尺取法（滑动窗口） | 双循环暴力枚举区间 |
|---|---|---|
| 各自定义 | l、r 双指针同向不回退，维护满足条件的窗口 | i、j 两重循环把每个 (l,r) 都算一遍 |
| 核心区别 | 跳过"必不合法/必非最优"的区间 | 全枚举，绝不漏但大量无用功 |
| 各自特点 | O(n)，要求指标随长度单调 | O(n²)，任何指标都正确 |
| 使用场景 | n 达 10^5~10^6 的区间最值/计数 | n≤10³~10⁴ 的小数据、对拍暴力 |
| 典型示例 | LCR 008 n=10^5 一遍扫完 | 同题两重循环 TLE |
| 记忆口诀 | 单调才滑窗，暴力保底慢 |

**组2：变长窗口 vs 定长窗口**

| 对比维度 | 变长窗口（LCR 008 / LC 713） | 定长窗口（LC 2379） |
|---|---|---|
| 各自定义 | l 随合法性伸缩，窗长不固定 | 窗长恒为 k，l、r 同步各进一格 |
| 核心区别 | 内层 while 负责收缩 l | 无内层循环，出入均 O(1) |
| 各自特点 | 统计发生在"刚变合法"的时刻 | 先建窗，再增量维护 |
| 使用场景 | 求最短/最长/计数 | 求"恰好长 k"的窗口最值 |
| 典型示例 | LCR 008 缩到 sum-nums[l]<target 为止 | LC 2379 出 W 减、进 W 加 |
| 记忆口诀 | 变长看条件，定长同步走 |

**组3：求最值型 vs 计数型（统计方式）**

| 对比维度 | 求最值型（LCR 008 / LC 2379） | 计数型（LC 713） |
|---|---|---|
| 各自定义 | 维护最优窗口，ans 取 min/max | 数以每个 r 结尾的合法子数组个数 |
| 核心区别 | ans=min(ans, r-l+1) 更新一次 | ans+=r-l+1 逐右端点累加 |
| 各自特点 | 缩到"再缩就不合法"为止 | 合法就整段一次收账 |
| 使用场景 | 问"最……的区间/最少改几个" | 问"有多少个子数组" |
| 典型示例 | 和≥7 最短 [4,3] 长 2 | 乘积<100 共 8 个 |
| 记忆口诀 | 最值取 min/max，计数累加 r-l+1 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**区间问题暴力 O(n²)（痛点）→ 指标随长度单调（观察）→ l 不必回头（原理）→ r 扩 l 缩的滑动窗口（机制）→ 每元素进出各一次 → O(n)（复杂度）→ 按问法选统计：最短取 min（LCR 008，无解报 0）、计数累加 r-l+1（LC 713）、定长增量维护（LC 2379）**。

跨知识点共性：
1. **与第二章前缀和互补**：区间和既能前缀和 O(1) 查询，也能窗口内增量维护——尺取还省掉一个数组，代价是要求单调性。
2. **向后铺垫**：单调栈、单调队列同属"指针/元素不回退"的线性家族；LC 862（和 ≥K 但含负数）正是尺取失效后用"前缀和+单调队列"补位的经典。
3. **与第四章衔接**：LCR 008 也能用"前缀和 + 二分"做；课件末尾预告的下节课例题 P1873、LCR 073，正是二分答案的主场。
