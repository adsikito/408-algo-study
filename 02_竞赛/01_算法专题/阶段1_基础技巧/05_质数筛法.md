## 本章地图

本章解决一个问题：**「要判一百万次素数，怎么不超时？」**

```text
判素需求出现
   ├─ 只判几次 / n ≤ 10¹²  → 试除法（知识点 1）
   ├─ 判 [1, n] 内所有数，n ≤ 10⁷ → 埃氏筛（知识点 2）
   │     └─ 追求严格 O(n) / 需要最小质因子 → 线性筛（知识点 3）
   ├─ 多次区间统计 [l, r] 素数个数 → 筛 + 前缀和（知识点 4）
   └─ L、R 巨大但 R − L 小 → 区间筛（知识点 5）
   ↓
另配：试除质因数分解（√n 循环 + 剩余大素数）
```

**为什么这条路径是这样**：筛法的本质是**把「逐个判素」改成「按倍数批量排除」**。
判 k 次素数，试除是 O(k√n)；筛一次是 O(n log log n)，之后每次判素 O(1)。
**k 越大，筛越划算**——这条成本曲线决定了上面每一档的落点。

## 核心概念与模板

**是什么**：
- **试除法**：对单个 n，用 2 到 √n 逐个试除，O(√n)。
- **埃氏筛**：把每个质数的倍数批量标记为合数，O(n log log n)。
- **线性筛**：保证每个合数**恰被其最小质因子**标记一次，严格 O(n)。

**为什么**：批量判素场景下（哈希容量选质数、统计素数个数、预处理因子），
逐个试除是 O(n√n)——n = 10⁷ 时约 3×10¹⁰ 次运算，必然超时；
筛法把成本摊到一次 O(n) 的预处理上。

> **【规律】** **筛法的第一性问题：每个合数被标记几次？**
> 埃氏筛：质数 p 的倍数被每个 ≤ 其因子的质数各标一次 → 有重复。
> 线性筛：让每个合数只被**最小质因子**筛掉 → `i % primes[j] == 0` 时 break。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 10000005;
bool comp[N];                        /* comp[i] = true 表示合数 */
int primes[700000], cnt = 0;         /* 10^7 内素数约 62 万个，π(n) ≈ n/ln n */

/* 线性筛：每个合数只被最小质因子筛掉 */
void sieve(int n) {
    for (int i = 2; i <= n; i++) {
        if (!comp[i]) primes[cnt++] = i;
        for (int j = 0; j < cnt && (long long)i * primes[j] <= n; j++) {
            comp[i * primes[j]] = true;
            if (i % primes[j] == 0) break;   /* 核心：保证最小质因子 */
        }
    }
}

/* 埃氏筛（对照）：内层从 p*p 起 */
void sieveE(int n) {
    for (int i = 2; (long long)i * i <= n; i++)
        if (!comp[i])
            for (long long j = (long long)i * i; j <= n; j += i)
                comp[j] = true;
}

/* 单点判素（试除，配合筛外场景：n 大且判素次数少） */
bool isPrime(long long n) {
    if (n < 2) return false;
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
```

> **【类比】** 埃氏筛像**贴封条**：每个质数见到自己的倍数就贴一张，
> 同一扇门可能被贴好几张（重复劳动）；线性筛像**户籍登记**：
> 每个合数只由它的「最小质因子监护人」登记一次，**一次到位**。

## 本章难点

> **【难点】** **线性筛的 break 语义。**
> `i % primes[j] == 0` 时 break，不是「剪枝优化」，而是**正确性保证**：
> 若继续用更大的质数标记 `i * primes[j+1]`，该合数的最小质因子就不是 `primes[j+1]`，
> 「恰被最小质因子筛一次」的性质被破坏，复杂度退回 O(n log n)。
> **这行代码是本专题唯一「删一行就错」的代码。**

> **【难点】** **区间筛的倍数定位。**
> 筛 [L, R] 时，质数 p 的最小倍数不是 2p，而是 **max(p², ⌈L/p⌉·p)**——
> 写成 `j = 2p` 会把 [2, L) 的倍数算进数组越界，写成 `j = p²` 会漏掉 L 附近被 p 整除的合数。
> **正确姿势：`long long st = max((long long)p * p, ((L + p - 1) / p) * p)`。**

---

## 本章易错点

> **【头号易错】** **线性筛漏写 `i % primes[j] == 0 break`**——退化为 O(n log n) 且失去最小质因子性质；
> 或埃氏筛内层从 2p 起标记（应为 p² 起）——慢近一倍。

> **【易错】** **乘法溢出**：`i * primes[j]` 不转 `long long`（10⁵ × 10⁵ = 10¹⁰ 超 `int`）；
> 试除的 `i * i` 不转（i ≥ 46341 时溢出）。

> **【易错】** **数组只开到题目 n 却筛到更大**；或 primes 数组按 n 预估——
> 应按 π(n) ≈ n / ln n 预估（10⁷ 约 62 万，开 7×10⁵ 有余量）。

> **【易错】** **试除分解漏掉剩余大素数**：循环结束后 `n > 1` 必是质因子，
> 漏写只输出一半分解。

> **【易错】** **0 和 1 的边界**：`isPrime` 必须先挡 `n < 2`；筛法从 i = 2 起。
> 区间筛的 L = 1 时，1 不是素数要单独处理。

## 典型例题

### 例 1　统计区间内素数个数（筛 + 前缀和）　难度：模板题

**题干摘要**：求 [1, n] 的素数个数，n ≤ 10⁷，多次区间询问。
**题源**：同类真源见配套练习 T1（P3912 素数个数）、T2（P1865 A % B Problem）
**涉及知识点**：知识点 2、4

**解题思路**：

1. **信号**：「多次询问区间素数个数」→ 筛 + 前缀和组合拳。
2. **方法**：埃氏筛标记合数，再做一遍前缀和 `pre[i] = pre[i-1] + (!comp[i])`，每问 O(1)。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 10000005;
bool comp[N];
int pre[N];                              /* pre[i] = [1, i] 的素数个数 */

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 2; (long long)i * i <= n; i++)
        if (!comp[i])
            for (long long j = (long long)i * i; j <= n; j += i)
                comp[j] = true;
    for (int i = 2; i <= n; i++)
        pre[i] = pre[i - 1] + (comp[i] ? 0 : 1);
    int q;
    scanf("%d", &q);
    while (q--) {
        int l, r;
        scanf("%d %d", &l, &r);
        printf("%d\n", pre[r] - pre[l - 1]);
    }
    return 0;
}
```

**复杂度**：时间 O(n log log n + q)，空间 O(n)。

> **【易错】** `pre[l - 1]` 在 l = 1 时是 `pre[0] = 0`，天然正确——
> 但前提是 pre 数组全局初始化。局部数组未清零会全错。

### 例 2　质因数分解（试除配对）　难度：变式题

**题干摘要**：把 n ≤ 10¹² 分解为质因数乘积并输出指数。
**题源**：数论基本功（题面见本章「题型识别信号」第 4 行）
**涉及知识点**：知识点 1

**解题思路**：

1. **信号**：单点分解，n 达 10¹² → **试除**（筛 10¹² 会 MLE）。
2. **方法**：p 从 2 递增到 √n，整除则除尽计数；结束后 n > 1 即剩余大素数。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

int main() {
    long long n;
    scanf("%lld", &n);
    for (long long p = 2; p * p <= n; p++)
        if (n % p == 0) {
            int e = 0;
            while (n % p == 0) { n /= p; e++; }
            printf("%lld^%d ", p, e);
        }
    if (n > 1) printf("%lld^1", n);      /* 剩余的必是大素数 */
    return 0;
}
```

**复杂度**：时间 O(√n) ≈ 10⁶，空间 O(1)。

> **【易错】** p 递增保证找到的都是质数——**合数的因子早已被除尽**，
> 这句论证要能对面试官 / 队友讲出来，否则 break 与除尽的边界容易写错。

## 本章总结

### 核心内容（一页纸）

1. **先看判素次数**：判几次 → 试除 O(√n)；判一片 → 筛一次 O(n log log n)。
2. **试除三件套**：`n < 2` 挡边界、循环到 `i * i <= n`（记得 long long）、分解后 `n > 1` 补大素数。
3. **埃氏筛内层从 p² 起**——小于 p² 的合数已被更小的质数标记过。
4. **线性筛的核心是 break**：`i % primes[j] == 0` 时停，保证每个合数恰被最小质因子筛一次。
5. **primes 数组按 π(n) ≈ n / ln n 预估**（10⁷ 约 62 万）。
6. **筛 + 前缀和是区间统计的标准组合拳**，每问 O(1)。
7. **区间筛的倍数定位**：从 `max(p², ⌈L/p⌉·p)` 起，L = 1 时单独处理 1。
8. **所有 `i * i`、`i * primes[j]` 转 long long**——筛法是溢出重灾区。
9. **筛的对象是候选，不是值域**：R 巨大但 R − L 小时用区间筛。
10. **本专题很少单独成题，但处处是底座**：哈希容量、因子预处理、数论大题都靠它。
