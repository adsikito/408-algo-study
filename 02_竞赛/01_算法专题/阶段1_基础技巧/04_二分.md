## 本章地图

本章解决一个问题：**「答案的候选空间太大，逐个试太慢，怎么办？」**

```text
候选答案有 10⁹ 个 → 逐个试是 O(10⁹)
   ↓
观察：如果「答案越大越容易满足」（或反之），那么候选空间是单调的
   ↓
于是可以每次排除一半 → O(log 10⁹) = 30 次
   ↓
每次「试」需要判定一个候选值是否可行 → 写 check 函数
   ↓
到此，问题从「求最优解」变成了「判定某个值是否可行」
```

**为什么这条路径是这样**：二分答案做的事情是**把「求解问题」转成「判定问题」**。
判定通常比求解容易得多——例如「最小化最大段和」很难直接求，
但「给定上限 x，能否分完？」只需一遍贪心。
**理解这个转换，就理解了二分答案为什么威力这么大。**

## 核心概念与模板

**是什么**：
- **二分查找**：在**有序序列**中 O(log n) 定位。
- **二分答案**：当答案本身**单调**（x 可行 ⇒ 更宽松的也可行）时，对**值域**二分，
  每轮用 O(n) 的 `check` 验证。

**为什么**：二分答案把「求最优解」转成「判定是否可行」。
判定通常只需一遍贪心或一次差分，比直接求解容易得多。
总复杂度 O(n log V)，其中 V 是值域大小。

> **【记忆】** 「**最小的最大 / 最大的最小 / 恰好 K 段 / 至少 T 天**」全是二分答案的行话。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;

/* 有序查找：lower_bound 返回第一个 >= x 的迭代器 */
int findGE(int a[], int n, int x) {
    return lower_bound(a + 1, a + n + 1, x) - a;
}

/* 二分答案：求满足 check 的【最小】x —— 下取整写法 */
long long bisectMin(long long lo, long long hi) {
    while (lo < hi) {
        long long mid = (lo + hi) / 2;   /* 下取整：不会跳过 lo */
        if (check(mid)) hi = mid;        /* mid 可行，答案 ≤ mid */
        else lo = mid + 1;               /* mid 不可行，答案 > mid */
    }
    return lo;
}

/* 二分答案：求满足 check 的【最大】x —— 上取整写法 */
long long bisectMax(long long lo, long long hi) {
    while (lo < hi) {
        long long mid = (lo + hi + 1) / 2;   /* 上取整：不会卡在 lo */
        if (check(mid)) lo = mid;        /* mid 可行，答案 ≥ mid */
        else hi = mid - 1;               /* mid 不可行，答案 < mid */
    }
    return lo;
}
```

> **【规律】** **两套写法必须成套使用，不能各取一半。**
>
> | 目标 | `mid` 取整 | 可行时 | 不可行时 |
> |------|----------|-------|---------|
> | 求**最小** | `(lo+hi)/2` 下取整 | `hi = mid` | `lo = mid + 1` |
> | 求**最大** | `(lo+hi+1)/2` 上取整 | `lo = mid` | `hi = mid - 1` |
>
> **配错必死循环**：例如「求最大」却用下取整，当 `hi = lo + 1` 时 `mid == lo`，
> 若可行则 `lo = mid` 不变——**区间永不收缩**。

**写 `check` 之前，先在注释里答三问**：

```text
1. check(x) 是否随 x 单调？     —— 不单调就不能二分
2. 单调方向如何？               —— 决定用 lo=mid 还是 hi=mid
3. 可行域是否连续？             —— 有空洞则不能二分（如「恰好等于」类）
```

> **【重点】** **三问答不出来，说明二分对象选错了**，应换待二分的量，
> 而不是硬写一个「看起来像」的 check。

## 本章难点

> **【难点】** **把「非单调的最值」误当成可二分。**
> 例如「最多能选几个」若约束是「两两不相邻」，可行域随数量**不连续**，
> 二分答案会得到错误结果。**判据：可行域必须是一段连续区间**（要么「小的都可行」，
> 要么「大的都可行」），中间不能有空洞。

> **【难点】** **值域上下界的确定**。下界设 `0` 是最常见的错误——
> 若「段和上限」下界应为「最大单元素」，设 0 会让 `check(0)` 恒假，
> 但循环仍能收敛，只是**多跑几轮**；真正的问题是**上界设小了会漏解**。
> **原则：下界取「一定可行」的最小候选，上界取「一定可行」的最大候选。**

---

## 本章易错点

> **【头号易错】** **两套边界写法混用**：求最大用上取整 + `lo = mid`，
> 求最小用下取整 + `hi = mid`；**配错必死循环**。
> **纪律：每题先在注释写「求最大还是最小」，再落笔。**

> **【易错】** **值域下界不是 0**。如「段和上限」的下界是**最大单元素**，
> 因为任何一段都必须容纳它。设 0 虽不致命，但设小了上界会漏解。

> **【易错】** **`check` 忘了「单元素就超限」的可行性短路**。
> 例如元素值为 10⁹ 而上限设为 10⁸ 时，任何分法都不可行——
> 应在 `check` 开头直接判 `if (a[i] > x) return false`。

> **【易错】** **实数二分用 `eps` 而迭代次数不足**。
> 常见做法是固定迭代 **100 次**（`for (int t = 0; t < 100; t++)`），
> 比用 `while (hi - lo > eps)` 更稳（避免死循环与精度不足）。

> **【易错】** **`(lo + hi)` 溢出**。两者均为 `long long` 时安全，
> 但若为 `int` 且值域接近 `INT_MAX`，`lo + hi` 会溢出。**统一用 `long long`。**

## 典型例题

### 例 1　分段最小化最大段和（二分答案）　难度：变式题

**题干摘要**：n ≤ 10⁵ 正整数序列分成至多 m 段，最小化最大段和。
**题源**：同类真源见配套练习 T5（跳石头）、T6（数列分段）
**涉及知识点**：知识点 2、3、4、5

**解题思路**：

1. **信号**：「最小化最大段和」→ 典型的**最小的最大**，二分答案。
2. **单调性三问**：
   - 单调吗？是。上限 `x` 越大，越容易把序列分完。
   - 方向？求**最小**的可行 `x`。
   - 可行域连续吗？是。`x` 大于某个阈值后全部可行。
3. **`check(x)`**：给定上限 `x`，用贪心「能塞就塞」算最少段数，判断是否 ≤ m。
4. **上下界**：下界 = 最大单元素（任何段都得容纳它）；上界 = 总和（一段到底必然可行）。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 100005;
int a[N], n;
long long m;

bool check(long long x) {                 /* 上限 x 时，段数能否 ≤ m？ */
    long long used = 0, seg = 1;
    for (int i = 1; i <= n; i++) {
        if (a[i] > x) return false;       /* 单元素超限：直接不可行 */
        if (used + a[i] <= x) used += a[i];   /* 能塞就塞（贪心） */
        else { seg++; used = a[i]; }          /* 塞不下，开新段 */
    }
    return seg <= m;
}

int main() {
    scanf("%d %lld", &n, &m);
    long long lo = 0, hi = 0;
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        hi += a[i];
        if (a[i] > lo) lo = a[i];         /* 下界 = 最大单元素，不是 0 */
    }
    while (lo < hi) {                     /* 求最小：下取整写法 */
        long long mid = (lo + hi) / 2;
        if (check(mid)) hi = mid;
        else lo = mid + 1;
    }
    printf("%lld\n", lo);
    return 0;
}
```

**复杂度**：时间 O(n log Σa) ≈ 10⁵ × 40，空间 O(n)。

> **【易错】** 三处：① 下界是最大单元素不是 0；② 本题求最小，必须用下取整写法；
> ③ `check` 开头的单元素短路不可省——没有它，`x` 小于最大元素时贪心会给出「段数=1」的假可行。

### 例 2　有序数组中 x 的出现次数（二分查找）　难度：模板题

**题干摘要**：升序数组，q 次询问 x 出现次数。
**题源**：同类真源见配套练习 T1（A-B 数对，二分查找 + 计数）
**涉及知识点**：知识点 1

**解题思路**：

1. **信号**：「有序」+「查值」→ 二分查找。
2. **方法**：`lower_bound` 得第一个 ≥ x 的位置，`upper_bound` 得第一个 > x 的位置，
   两者之差即出现次数（左闭右开口径）。
3. **优雅之处**：**x 不存在时两者相等，差为 0**，因此无需特判。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;
const int N = 100005;
int a[N];

int main() {
    int n, q;
    scanf("%d %d", &n, &q);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    while (q--) {
        int x;
        scanf("%d", &x);
        int lo = lower_bound(a + 1, a + n + 1, x) - a;   /* 第一个 >= x */
        int hi = upper_bound(a + 1, a + n + 1, x) - a;   /* 第一个 > x  */
        printf("%d\n", hi - lo);          /* [lo, hi) 即 x 的区间 */
    }
    return 0;
}
```

**复杂度**：每问 O(log n)，总 O(q log n)，空间 O(n)。

> **【易错】** `upper_bound - lower_bound` 是**左闭右开区间长度**，
> 直接得出现次数。**不存在时两者相等输出 0，无需特判**——
> 这一点与手写二分不同（手写二分通常需要额外判断）。

## 赛事适配

| 赛事 | 出现形式 | 应对 |
|------|---------|------|
| 洛谷 | 与 CSP 的核心考技，题量极大 | 先默写两套模板再刷题 |
| CSP-J / CSP-S | S 组压轴常为二分答案；J 组常见二分查找 | 注意与差分复合（T5 型） |
| 蓝桥杯 | 编程题「至少几天 / 最大最小」高频 | 优先套模板 |
| 百度之星 | 把二分藏进数学题（**判定式含快速幂**） | 先推出单调性再写 check |
| ICPC / CF | **二分经常嵌套**（二分套二分、二分 + 前缀和） | 注意内层复杂度与总预算 |

> **【规律】** **二分是「万能工具」，但它只把问题降一个数量级。**
> `check` 的复杂度决定总复杂度：O(n) 的 check 得到 O(n log V)，
> **O(n²) 的 check 只会得到 O(n² log V)——那跟不优化没区别。**
> **写 check 时同时评估它的复杂度，这是本章的隐性要求。**

## 本章总结

### 核心内容（一页纸）

1. **二分答案 = 把「求最优解」转成「判定可行性」**，再靠单调性每次砍半。
2. **前提是单调性 + 可行域连续**。**不单调的问题不能二分**——这是第一道关卡。
3. **两套写法必须成套**：
   求**最小** → `mid = (lo+hi)/2` + `hi = mid` / `lo = mid+1`；
   求**最大** → `mid = (lo+hi+1)/2` + `lo = mid` / `hi = mid-1`。
   **配错必死循环。**
4. **写 `check` 前先答三问**：单调吗？方向？可行域连续吗？
5. **值域下界不是 0**。如「段和上限」下界 = **最大单元素**。
6. **`check` 开头要短路**：单元素就超限时直接 `return false`。
7. **`lower_bound` 与 `upper_bound` 是左闭右开口径**，差值即出现次数；
   **不存在时差为 0，无需特判**。
8. **实数二分固定迭代 100 次**，不要依赖 `eps` 比较。
9. **`(lo + hi)` 可能溢出**，统一用 `long long`。
10. **`check` 的复杂度决定总复杂度**：O(n) 的 check → O(n log V)。
    **O(n²) 的 check 等于没优化。**
11. **「差分 + 二分」是高频复合**：`check` 内用差分 O(n) 完成区间判定（见 `02_前缀和与差分.md` T5）。
12. **先写注释再落笔**：「本题求最大还是最小」——这一行注释能消掉大半死循环。
