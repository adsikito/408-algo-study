## 第七章：高精度

> 课件来源：`7.高精度.pptx`
>
> 例题代码：`模版代码\高精度加法.cpp`（P1601）、`高精度减法.cpp`（P2142）、`高精度乘法.cpp`（P1303）、`高精度除法.cpp`

## 🗺️ 本章地图

本章解决一个问题：long long 只有约 19 位，算 1 万位的大数加减乘除怎么办？课件定性：**这本质是模拟题**——用字符串读入、数组一位一位存下，再模拟竖式运算。路线按运算难度递进：先搭好"字符串读入+数组倒序存储"的地基（知识点 1）；再练加减法的进位/借位（2、3）；然后是乘法的错位累加 c[i+j]（4）；最后用"减法试商"啃下除法（5）。课件干货：理解原理后模板是固定的，背熟照打即可。

## 📌 本章重点

⭐ **存储三件事**：输入用字符串、存储用数组（个位存 a[0] 的倒序）、位数=字符串长度
⭐ **加法竖式模拟**：`c[i]+=a[i]+b[i]`，满 10 则 `-10` 且 `c[i+1]++`，结果位数 max(la,lb)+1
⭐ **减法两大前提**：先比大小定符号（保证大减小）、输出前过滤前导 0（1006-1000=6 而非 0006）
⭐ **乘法错位规律**：`c[i+j]+=a[i]*b[j]` 累加完再统一进位，结果位数 la+lb
⭐ **除法=减法模拟**：数组第 0 位存长度，补 0 对齐后逐位试减，减几次商就是几

## 🔥 本章难点

🔥 **前导 0 的多处处理**：去前导 0 出现在"运算结果、被除数/除数、商"至少三处，循环 `while(c[lc]==0&&lc>0)` 的 `lc>0` 不能丢——否则结果本身为 0 时会一路减到越界
🔥 **高精度除法模板**：换了一套下标体系（x[0] 存长度、数据存 x[1..x[0]]），check 比大小、sub 借位减、补 i-1 个 0 对齐三件事叠加，是全章最难默写的模板

## ⚠️ 本章易错点

⚠️ **忘去前导 0**：课件原例 1006-1000 输出 0006 就是 WA；必须从最高位往下找第一个非 0 位再开始输出
⚠️ **去前导 0 循环漏写 `&&lc>0`**：结果为 0 时 lc 会一直自减越界；正确写法保证至少保留 1 位
⚠️ **减法不比大小**：小减大逐位都出负数；必须先比（先比长度、等长比字典序 `s1<s2`），需要时先输出负号再 `swap` 两串
⚠️ **加法结果位数忘 +1**：lc=max(la,lb)+1 是给最高位进位留的位置，漏掉则 99+1 输出 00
⚠️ **乘法 c 数组开小 / 边乘边进位**：结果可达 la+lb 位，数组要开 2 万；进位必须等 c[i+j] 全部累加完后统一做，边乘边 %10 会破坏还没加完的累加值
⚠️ **倒序映射写反**：`x[i]=s[l-1-i]-'0'` 让个位落进 x[0]；顺手写成 `s[i]` 则全部按高位存，竖式从低位算起直接全错

## 📖 知识点讲解

### 1. 高精度的存储：字符串读入 + 数组倒序

**是什么**：白话——把大数当"一串数字字符"读进来，每一位拆开倒着放进数组，让个位住进 a[0]。课件定义：**大数**指计算的数值非常大或对运算精度要求非常高、用已知数据类型无法精确表示的数值（如 Fibonacci 第 1000 项、π 到小数点后 2000 位）；解法是**数组保存数字的每一位，模拟竖式运算**。

**为什么**：long long 上限约 9.2×10^18（19 位），万位大数存不下；而竖式运算从低位往高位进行，倒序存储（下标小=位低）后，"向高位进位"恰好对应"下标 +1"，模拟竖式最顺手。课件总结大整数计算的三个问题：①输入方法=字符串；②存储方法=数组；③位数=字符串长度，运算中处理好进位、借位。

**怎么用**——init 读入模板（照抄例题代码）：
```cpp
int a[10010], b[10010], c[10010];
int init(int x[])              // 读入数据，返回位数
{
    string s; cin >> s;
    int l = s.size();          // 位数 = 字符串长度
    for (int i = 0; i < l; i++)
        x[i] = s[l-1-i] - '0'; // 倒序：个位存 x[0]
    return l;
}
```
跟算：读入 "9876"（l=4）→ a[0]=s[3]='6'（个位）、a[1]=s[2]='7'（十位）、a[2]=s[1]='8'、a[3]=s[0]='9'（千位）：
```
字符串 s:   s[0]='9'  s[1]='8'  s[2]='7'  s[3]='6'
数组 a:     a[3]=9    a[2]=8    a[1]=7    a[0]=6
              千位      百位      十位      个位   ← 下标小 = 位低
```

> ⚠️ 注意事项：`-'0'` 把字符转数字；全局数组自动清零，a 比 b 短时高位自然补 0，正好对齐。

> 🎯 规律：竖式类题 = "位对齐 + 从低位往高位逐位模拟"，倒序存储是模拟竖式的标准姿势。

> 💡 一句话总结：字符串读入，倒序存数组。

### 2. 高精度加法（P1601 A+B）

**是什么**：白话——逐位相加，满十往前一位进 1，就是小学竖式的代码化。课件给了两种等价的进位写法：方法 1 用变量 x 记录进位（`x=1`/`x=0`），方法 2 直接 `c[i+1]++`——模板采用方法 2。

**为什么**：竖式加法从个位算到最高位，倒序数组从下标 0 加到 lc-1，方向完全一致；最高位还可能再进一位，所以结果位数要多开 1 位。

**怎么用**——模板（`高精度加法.cpp` 核心）：
```cpp
int la = init(a), lb = init(b);
int lc = max(la, lb) + 1;          // 结果最大位数：多留1位给最高进位
for (int i = 0; i < lc; i++)
{
    c[i] += a[i] + b[i];
    if (c[i] >= 10) { c[i] -= 10; c[i+1]++; }  // 进位
}
lc--;                              // 回到最后一个下标
while (c[lc]==0 && lc>0) lc--;     // 去前导0（至少保留1位）
for (int i = lc; i >= 0; i--) cout << c[i];    // 从高位往低位输出
```
跟算：9989+87 → a=[9,8,9,9]，b=[7,8]：
```
i=0: c[0]=9+7=16 ≥10 → c[0]=6, c[1]++
i=1: c[1]=8+8+1=17  → c[1]=7, c[2]++
i=2: c[2]=9+0+1=10  → c[2]=0, c[3]++
i=3: c[3]=9+0+1=10  → c[3]=0, c[4]++
i=4: c[4]=1
结果 1 0 0 7 6 → 10076 ✓（lc 初值 5，无需去前导0）
```

> ⚠️ 注意事项：两个板子题 P1601（A+B）、P2142（减法）就是默写检验；输入不含负号，按非负整数处理。

> 🎯 规律：`c[i] += a[i] + b[i]` 再统一判进位，比"先算进位变量再加"少出错——累加式写法在乘法里同样复用。

> 💡 一句话总结：逐位相加，满十进一。

### 3. 高精度减法（P2142）

**是什么**：白话——逐位相减，不够就向高位借 1 当 10；但要先解决两件课件点名的麻烦：①a 与 b 大小关系未知，结果可能为负；②结果高位可能有一串前导 0。

**为什么**：竖式减法默认"大减小"；若直接小减大，每一位都会出负数，借位逻辑全乱。前导 0 是"位数多的被减数"留下的：1006-1000 按 4 位算出 0006，正确答案只有 6——输出前必须过滤。

**怎么用**——模板（`高精度减法.cpp` 核心）：
```cpp
cin >> s1 >> s2;
if (s1.size() < s2.size() || (s1.size()==s2.size() && s1 < s2))
{
    cout << '-';        // 小减大：先打负号
    swap(s1, s2);       // 保证 s1 大，转成大减小
}
int la = init(a, s1), lb = init(b, s2);
int lc = max(la, lb);
for (int i = 0; i < lc; i++)
{
    c[i] += a[i] - b[i];
    if (c[i] < 0) { c[i] += 10; c[i+1]--; }    // 借位
}
lc--;
while (c[lc]==0 && lc>0) lc--;     // 去前导0
for (int i = lc; i >= 0; i--) cout << c[i];
```
跟算 1：1006-1000 → c=[6,0,0,0]，去前导 0 后 lc=0，输出 6 ✓（不去就输出 0006）。
跟算 2（连续借位）：1000-6 → a=[0,0,0,1]，b=[6,0,0,0]：
```
i=0: 0-6<0 → +10 得 4, c[1]--
i=1: 0-1<0 → +10 得 9, c[2]--
i=2: 0-1<0 → +10 得 9, c[3]--
i=3: 1-1=0
结果 c=[4,9,9,0] → 去前导0 → 994 ✓
```

> ⚠️ 注意事项：等长时 string 的字典序比较 `s1<s2` 恰好就是数值比较（位数相同、都是数字字符）；负号在 swap 之前输出。

> 🎯 规律：减法三步曲——**先比大小、再做借位竖式、最后去前导 0**；借位的累加写法 `c[i]<0 → +10、c[i+1]--` 与加法完全对称。

> 💡 一句话总结：大减小，借一当十，去前导零。

### 4. 高精度乘法（P1303 A*B）

**是什么**：白话——把 a 的每一位和 b 的每一位两两相乘，乘积落在结果的第 i+j 位上，全部累加完再统一进位。核心规律：**a 的第 i 位 × b 的第 j 位 贡献给 c[i+j]**（下标从 0 计）。

**为什么**：a 的第 i 位代表 a[i]×10^i，b 的第 j 位代表 b[j]×10^j，相乘得 a[i]b[j]×10^(i+j)——指数相加，所以落点是 i+j。累加阶段 c[i+j] 可能攒到很大（约 10^4 位 × 81 ≈ 10^6，不爆 int），必须**累加完再统一进位**，若边乘边 %10 会把后续累加截断。

**怎么用**——模板（`高精度乘法.cpp` 核心）：
```cpp
int la = init(a), lb = init(b);
int lc = la + lb;                       // 结果位数最多 la+lb
for (int i = 0; i < la; i++)
    for (int j = 0; j < lb; j++)
        c[i+j] += a[i] * b[j];          // 错位累加，先不进位
for (int i = 0; i < lc; i++)            // 统一进位
    if (c[i] >= 10)
    {
        c[i+1] += c[i] / 10;
        c[i] %= 10;
    }
while (c[lc]==0 && lc>0) lc--;          // 去前导0
for (int i = lc; i >= 0; i--) cout << c[i];
```
跟算：12×34 → a=[2,1]，b=[4,3]：
```
累加阶段：
  c[0] += a[0]*b[0] = 2*4 = 8
  c[1] += a[0]*b[1] = 2*3 = 6
  c[1] += a[1]*b[0] = 1*4 = 4   → c[1]=10
  c[2] += a[1]*b[1] = 1*3 = 3
  → c = [8, 10, 3]
统一进位：
  i=0: 8<10 不动
  i=1: 10≥10 → c[2]+=1, c[1]=0
  i=2: 3+1=4<10 不动
  → 输出 4 0 8 = 408 ✓（12×34=408）
```

> ⚠️ 注意事项：c 数组要开 20005（la+lb 可达 2 万）；`c[i+1]+=c[i]/10; c[i]%=10;` 的进位可能连锁，靠 for 从低到高扫描自然传导。

> 🎯 规律：凡"两两配对、落点下标相加"的乘法结构都写 `c[i+j]+=…`（多项式乘法、卷积同源）；先累加后进位是通用顺序。

> 💡 一句话总结：错位累加 i+j，末了统一进位。

### 5. 高精度除法：减法模拟试商

**是什么**：白话——商的每一位不"算"出来，而是"减"出来：把除数补 0 对齐到被除数的对应位，能减几次商就是几。模板（`高精度除法.cpp`）换了一套下标体系：**数组第 0 位存长度，数据存 x[1..x[0]]**。

**为什么**：除法竖式 = "试商 + 减法"。q = a÷b 等价于"从 a 里不断减去对齐后的 b，数减了多少次"；从商的最高位试到最低位，每确定一位就把剩余被除数缩小一截。

**怎么用**——模板四件套：
```cpp
// 1) check：比较大小，x>=y 返回 1（先比位数 x[0]，再从高位比到低位）
// 2) sub：x -= y（不够减就 +10、x[i+1]-- 借位），并重算 x[0] 去前导0
// 3) init 读入后先给 a、b 各去一遍前导0 —— 防 "005/9" 这类输入
// 4) 主流程：
if (check(a,b)==0) { cout << 0; return 0; }   // 小数除大数商为0
c[0] = a[0] - b[0] + 1;                        // 商的最多位数
for (int i = c[0]; i >= 1; i--)                // 从商的最高位试起
{
    int t[10005] = {0};
    for (int j = 1; j <= b[0]; j++)            // 把 b 补 i-1 个0 对齐
        t[j+i-1] = b[j];
    t[0] = b[0] + i - 1;
    while (check(a,t) == 1) { sub(a,t); c[i]++; }  // 减几次商几
}
while (c[c[0]]==0 && c[0]>1) c[0]--;           // 商去前导0
```
跟算：56÷4 → a=[_,6,5]（a[0]=2），b=[_,4]（b[0]=1），c[0]=2：
```
i=2：b 补 1 个0 → t=40。56-40=16（减1次），16<40 停 → 商十位 c[2]=1
i=1：t=b=4。16-4=12-4=8-4=4-4=0（减4次）→ 商个位 c[1]=4
商 c=[_,4,1] → 输出 14 ✓（56÷4=14）
```

> ⚠️ 注意事项：课件明确"理解原理即可，代码固定、直接背模板照打"；这个朴素试商版效率不高，但结构最清晰。有余力可学 Java 的 BigInteger/BigDecimal 类，日常大数运算极方便。

> 🎯 规律：除法=补 0 对齐 + 反复减法；"check 决定能不能减、sub 执行减并计数"的二件套，在除法取模、进制转换里都能复用。

> 💡 一句话总结：补零对齐，减几次商几。

## 🔍 相似概念辨析

**组1：高精度加法 vs 高精度减法**

| 对比维度 | 高精度加法 | 高精度减法 |
|---|---|---|
| 各自定义 | 逐位相加、满 10 进 1 的竖式模拟 | 逐位相减、不够借 1 当 10 的竖式模拟 |
| 核心区别 | 无需比较大小，直接算 | 必须先比大小定符号，保证大减小 |
| 各自特点 | 结果位数 max(la,lb)+1（给进位留位） | 结果位数 max(la,lb)，需过滤前导 0 |
| 使用场景 | P1601 A+B | P2142 减法（可能输出负号） |
| 典型示例 | 9989+87=10076（连续进位） | 1006-1000 要去 000（前导0） |
| 记忆口诀 | 加法管进位，减法先比再去零 |

**组2：高精度乘法 vs 高精度加法**

| 对比维度 | 高精度乘法 | 高精度加法 |
|---|---|---|
| 各自定义 | 每位两两相乘累加到 c[i+j] 的竖式模拟 | 逐位相加累加到 c[i] 的竖式模拟 |
| 核心区别 | 落点下标是 i+j（错位），双重循环 | 落点下标是 i，单层循环 |
| 各自特点 | 先全部累加、再统一进位（c[i]/10） | 逐位即时进位（-10 后 c[i+1]++） |
| 使用场景 | P1303 A*B | P1601 A+B |
| 典型示例 | 12×34：c=[8,10,3]→408 | 9989+87 逐位进位 |
| 记忆口诀 | 加法位对位，乘法错开位 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**数太大存不下（痛点）→ 字符串读入、数组逐位存（地基）→ 倒序让"高位进位"等于"下标+1"（关键设计）→ 加减法只是"逐位+进/借位"的竖式翻译 → 乘法把"逐位"升级为"两两配对落 i+j" → 除法反着用减法"试"出商 → 全程共享同一套收尾：去前导 0 + 从高位倒着输出**。四种运算 = 一套存储 + 四种竖式翻译。

跨知识点共性：
1. **与第一章模拟思想一脉相承**：课件原话"该问题属于模拟题"——竖式怎么算，代码就怎么写；高精度是"模拟规则最清晰"的练习场。
2. **与第六章取模思维互补**：快速幂解决"值大但 mod 后可算"，高精度解决"值大且必须精确"——看到题目先问"要精确值还是余数"，决定用哪件武器。
3. **与第九章衔接**：Fibonacci 第 1000 项（课件引入例）既考高精度也考递推；P1096 Hanoi 双塔问题将同时用到递推和高精度加法，是两章的天然交汇题。

## 📋 速查表

| 模板 | 复杂度 | 适用条件 |
|---|---|---|
| 高精度加法 | O(max(la,lb)) | 两数各 ≤1 万位，非负（P1601） |
| 高精度减法 | O(max(la,lb)) | 先比大小定符号，去前导 0（P2142） |
| 高精度乘法 | O(la×lb) | 结果位数 la+lb，c 数组开 2 万（P1303） |
| 高精度除法（试商） | O(商位数 × 每位试减次数) | 数组 0 位存长度；小÷大先判商 0 |

```cpp
// 高精度骨架（默写级）：读入 → 竖式逐位 → 去前导0 → 倒序输出
int lc = 预估位数;                       // 加法max+1 / 减法max / 乘法la+lb
for (逐位运算) { 累加 + 进位或借位; }
while (c[lc]==0 && lc>0) lc--;           // lc>0 必须保留！
for (int i = lc; i >= 0; i--) cout << c[i];
```

## ✏️ 练习题

★ **洛谷 P1601 A+B Problem（高精）**：默写加法模板直接过。
提示：重点自查三处——init 倒序映射、lc=max+1、去前导 0 的 `lc>0`。

★★ **洛谷 P2142 高精度减法**：默写减法模板，数据可能触发负号与前导 0。
提示：先比字符串长度、等长比字典序；负号输出在 swap 之前；1006-1000 型数据专门测去零。

★★★ **洛谷 P1303 A*B Problem**：默写乘法模板。
提示：c 开 20005；先把 `c[i+j]+=a[i]*b[j]` 全部跑完，再统一进位；最后结果可能为 0，去前导 0 要保留一位。

★★★★ **洛谷 P1480 A/B Problem（高精除以低精）**：除数 b 是普通 int，比本章高精÷高精简单得多。
提示：把被除数从高位往低位扫，维护余数 r，每一位的商 = (r×10+当前位)/b，然后 r=(r×10+当前位)%b——想想它和"减法试商"的联系（试商减的次数就是商，余数就是剩下的 a）。
