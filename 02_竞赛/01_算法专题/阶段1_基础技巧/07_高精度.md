## 本章地图

本章解决一个问题：**「数大到 long long 装不下，四则运算怎么做？」**

```text
数超过 long long（19 位）？
   ├─ 20 ~ 38 位            → __int128 兜底（先试这个！）
   ├─ 更大 / 需要精确值      → 高精度四则（本篇）
   │     ├─ 加法：add（进位统一处理）
   │     ├─ 减法：先比大小 → 大减小 → 补负号 → 去前导零
   │     ├─ 乘法：× 低精（90% 场景）→ 逐位累加；× 高精 → 错位累加
   │     └─ 除法：÷ 低精，从高位往低位逐位试商
   └─ 只要答案 mod p        → 别写高精度，走阶段 6 取模
   ↓
典型场景：n!（20! 已超 long long）、大斐波那契、组合数精确值
```

**为什么这条路径是这样**：高精度**没有算法含量，只有实现纪律**。
因此学习路径按「运算种类」而不是「难度」组织，
且每一步都先问「能不能用更便宜的手段替代」（`__int128`、取模）——
**把高精度当最后手段，是它最大的使用技巧。**

## 核心概念与模板

**是什么**：用数组按位存数（低位在前），逐位模拟竖式计算。

**为什么**：20! ≈ 2.4 × 10¹⁸ 已到 `long long` 上限；
阶乘、组合数、大斐波那契的精确值必然越界。

> **【规律】** **四条统一约定**（四个运算共享，背下它们=写对一半）：
> ① 低位在前存储；② 进位 / 借位用「先累加再逐位落位」统一处理；
> ③ 减法先比大小、结果去前导零；④ 先写「× / ÷ 低精度」版本，覆盖 90% 题目。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

typedef vector<int> Big;                 /* 低位在前 */

Big toBig(string& s) {
    Big A;
    for (int i = (int)s.size() - 1; i >= 0; i--) A.push_back(s[i] - '0');
    return A;
}

Big add(const Big& A, const Big& B) {
    Big C;
    int carry = 0;
    for (size_t i = 0; i < A.size() || i < B.size() || carry; i++) {
        if (i < A.size()) carry += A[i];
        if (i < B.size()) carry += B[i];
        C.push_back(carry % 10);
        carry /= 10;
    }
    return C;
}

Big mulInt(const Big& A, int b) {        /* 高精度 × 低精度（最常用） */
    Big C;
    long long carry = 0;
    for (size_t i = 0; i < A.size() || carry; i++) {
        if (i < A.size()) carry += (long long)A[i] * b;
        C.push_back(carry % 10);
        carry /= 10;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();  /* 去前导零 */
    return C;
}

bool lessEq(const Big& A, const Big& B) {  /* A ≤ B？ */
    if (A.size() != B.size()) return A.size() < B.size();
    for (int i = (int)A.size() - 1; i >= 0; i--)
        if (A[i] != B[i]) return A[i] < B[i];
    return true;
}

Big sub(const Big& A, const Big& B) {      /* 需 A ≥ B，大减小 */
    Big C;
    int borrow = 0;
    for (size_t i = 0; i < A.size(); i++) {
        int cur = A[i] - borrow - (i < B.size() ? B[i] : 0);
        if (cur < 0) { cur += 10; borrow = 1; } else borrow = 0;
        C.push_back(cur);
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

> **【类比】** 高精度像**手工列竖式**：个位对齐（低位在前就是让「个位在数组第 0 格」），
> 从右往左逐位算，进位 / 借位记在手上（carry / borrow）。
> **机器与人唯一的区别是：它必须把「手上的进位」也写成变量。**

## 本章难点

> **【难点】** **减法的负号判定链**。
> 先比大小（`lessEq`）→ 大减小 → **若原式是小减大，输出负号再输出 sub(|A−B|)**。
> 三步少一步就是 WA；且「结果为零」时不能输出 `-0`——
> 判零要在去前导零之后（`C.size() == 1 && C[0] == 0`）。

> **【难点】** **高 × 高乘法的下标对应**。
> C[i + j] += A[i] × B[j] 的错位关系是本篇最容易写错的一行——
> 记忆锚点：**A 的第 i 位乘 B 的第 j 位，贡献落在结果的第 i + j 位**
> （小学竖式里「第几位 × 第几位落在第几位」的机械版本）。
> 中间累加量必须 long long（10⁹ 量级 × 多位叠加会爆 int）。

---

## 本章易错点

> **【头号易错】** **忘去前导零**（输出 "0012"）或**比较函数没处理长度不等**。
> 每个「产生结果」的运算结尾都要有 `while (C.size() > 1 && C.back() == 0) C.pop_back();`。

> **【易错】** **乘法中间量用 int 累加**——多位叠加与 9 位数 × 9 位数都会爆，
> carry 用 long long。

> **【易错】** **减法借位后忘了清 borrow**（else 分支漏写 `borrow = 0`）——
> 错误会向后传播到所有高位。

> **【易错】** **除法试商的余数更新错序**：余数先乘 10 加当前位，再试商；
> 顺序颠倒商全错。

> **【易错】** **输入带前导零**（P1303 明示可能有）——读入后先清，
> 否则比较与去前导零逻辑都要被打一次补丁。

## 典型例题

### 例 1　大数阶乘（高精 × 低精循环连乘）　难度：模板题

**题干摘要**：求 n!（n ≤ 1000）的精确值，答案可达 2568 位。
**题源**：同类真源见配套练习 T1（P1601 A+B）、T4（P1009 阶乘之和）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：n! 精确值 → × 低精循环连乘（把 n! 看作 1×2×…×n，每步高精 × 低精）。
2. **方法**：从 1 开始逐个乘 i，位数增长靠 push_back 兜底，最后高位往低位输出。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <vector>
using namespace std;
typedef vector<int> Big;

int main() {
    int n;
    scanf("%d", &n);
    Big a = {1};                          /* 0! = 1 */
    for (int i = 2; i <= n; i++) {
        long long carry = 0;
        for (size_t j = 0; j < a.size() || carry; j++) {
            if (j < a.size()) carry += (long long)a[j] * i;
            if (j == a.size()) a.push_back(0);
            a[j] = carry % 10;
            carry /= 10;
        }
    }
    for (int j = (int)a.size() - 1; j >= 0; j--) printf("%d", a[j]);
    return 0;
}
```

**复杂度**：时间 O(n × 位数摊还) ≈ 10⁶ 量级，空间 O(位数)。

> **【易错】** 输出**从高位往低位**（数组倒序遍历）——存储低位在前、输出高位在前，
> 这个「方向翻转」是本章所有输出题的共同动作。

### 例 2　高精 × 高精（P1303 型）　难度：模板题

**题干摘要**：两个不超过 2000 位（可能有前导零）的非负整数相乘。
**题源**：同类真源见配套练习 T3（P1303 A*B Problem）
**涉及知识点**：知识点 1、4

**解题思路**：

1. **信号**：两个乘数都是高精度 → 错位累加版乘法（mulInt 不够用）。
2. **方法**：C[i + j] += A[i] × B[j]，全部累加完再统一处理进位；先清输入前导零。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <cstring>
const int N = 4005;
int A[N], B[N];
long long C[N];

int main() {
    char sa[N], sb[N];
    scanf("%s %s", sa, sb);
    int la = (int)strlen(sa), lb = (int)strlen(sb);
    for (int i = 0; i < la; i++) A[i] = sa[la - 1 - i] - '0';   /* 低位在前 */
    for (int i = 0; i < lb; i++) B[i] = sb[lb - 1 - i] - '0';
    for (int i = 0; i < la; i++)
        for (int j = 0; j < lb; j++)
            C[i + j] += (long long)A[i] * B[j];                /* 错位累加 */
    int lc = la + lb;                                          /* 积最多 la+lb 位 */
    for (int i = 0; i < lc; i++) {                             /* 统一进位 */
        C[i + 1] += C[i] / 10;
        C[i] %= 10;
    }
    while (lc > 1 && C[lc - 1] == 0) lc--;                     /* 去前导零 */
    for (int i = lc - 1; i >= 0; i--) printf("%d", (int)C[i]);
    return 0;
}
```

**复杂度**：时间 O(位数²)（2000² = 4×10⁶），空间 O(位数)。

> **【易错】** 三处：输入前导零先清或靠「去前导零」兜底（全零积输出 0）；
> C 数组开 la + lb（积的位数上界）；统一进位必须**累加完再做**——
> 边乘边进位会把还没累加完的位进错。

## 本章总结

### 核心内容（一页纸）

1. **先排除**：取模能解决 → 阶段 6；位数 ≤ 38 → `__int128`；都不行才写高精度。
2. **四条统一约定**：低位在前 / 进借位统一处理 / 减法先比大小去前导零 / 先低精后高精。
3. **每个产生结果的运算结尾**都要去前导零：`while (C.size() > 1 && C.back() == 0)`。
4. **减法负号链**：比大小 → 大减小 → 补负号 → 判零（不输出 `-0`）。
5. **乘法错位**：C[i + j] += A[i] × B[j]；**累加完统一进位**，中间量 long long。
6. **除法顺序**：余数先乘 10 加当前位，再试商——顺序颠倒全错。
7. **存储低位在前、输出高位在前**——方向翻转只许出现在输出一处。
8. **carry / borrow 用 long long**（乘法中间量），借位记得 else 清零。
9. **输入可能带前导零**（题面会写），读入后先清或靠去前导零兜底。
10. **梯度看运算种类**（加 → 减含负号 → 乘高 → 除低），不看平台难度档。

```text
前置：vector · 字符串转换 · 函数封装 · 整型范围
   │
   └─→ 1 低位在前存储（toBig 倒序）★ 四则共同入口
         │
         ├─→ 2 add（进位统一）
         │     └─→ 3 sub（比大小 + 借位 + 负号）
         ├─→ 4 mulInt（× 低精）→ 高×高（错位累加）
         └─→ 5 ÷ 低精（逐位试商）
                    │
                    └─ 联动：06 快速幂（__int128 兜底对照）· 阶段 7（大数计数）
```
