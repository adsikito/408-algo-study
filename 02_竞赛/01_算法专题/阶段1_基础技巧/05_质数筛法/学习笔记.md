## 第五章：质数筛法

> 课件来源：`5.质数筛法.pptx`
>
> 例题代码：`线性筛.cpp`（欧拉筛 O(n) 主代码，文件注释附埃氏筛完整版）；课件板子题：P3383 [模板] 线性筛素数

## 🗺️ 本章地图

本章解决一个问题：1~n 里谁是质数？逐个试除 O(n√n) 太慢。思路反转：**不逐个判"谁是质数"，改批量删"谁必是合数"**——已找到的质数，它的倍数一定是合数（唯一分解定理）。三级升级链：朴素试除（单点 O(√n)，靠"因数成对"砍到平方根）→ 埃氏筛（删质数的倍数，O(n log log n)，但 6 会被 2、3 各删一次）→ 欧拉筛/线性筛（规定每个合数只被**最小质因数**筛掉，break 两行保证不重不漏，O(n)）。用 n=20 把标记过程完整跟一遍，是本章的基本功。

## 📌 本章重点

⭐ **质数定义与特判**：大于 1 且约数只有 1 和本身；0 和 1 既不是质数也不是合数
⭐ **试除判定**：因数成对出现（一个 ≤√n、一个 ≥√n），判单个数试到 √n 即可
⭐ **埃氏筛**：从小到大读"剩余最小数"（必是质数），删掉它的所有倍数；正确性根源是算术基本定理（唯一分解定理）
⭐ **线性筛灵魂两行**：`x=i*p[j]>n` 提前 break；`i%p[j]==0` 立刻 break——保证每个合数只被最小质因数标记一次，O(n)
⭐ **反向标记语义**：例题代码 `isPrime[i]=0` 表示 i 是质数、`=1` 表示不是，全局数组默认 0 恰好"天生全是质数"

## 🔥 本章难点

🔥 **break 那一行的证明**（课件代码注释原文）：若 i=p[j]·k 时还不 break，则 x'=i·p[j+1]=p[j]·k·p[j+1] 的最小质因数仍是 p[j]（≤p[j+1]），轮不到 p[j+1] 来筛——不 break 就破坏"最小质因数负责制"，合数被重复筛
🔥 **每个合数恰好被筛一次**：合数 x 写成 x=i·p[j]（i=x/最小质因数，p[j]=最小质因数）的方式唯一，枚举到那个 i 时 x 恰被标记且仅标记一次——这就是"线性"的来源
🔥 **埃氏筛的重复功**：6 是 2 和 3 的倍数被删两次（课件原例）；一般地每个合数被它每个 ≤最小质因数的质数各删一次，总复杂度 O(n log log n)——比线性多出的正是这个"重复"

## ⚠️ 本章易错点

⚠️ **忘特判 0 和 1**：代码开头 `isPrime[1]=1`（0 同理），漏掉会把 1 当质数混进素数表
⚠️ **break 放错侧**：必须先 `isPrime[x]=1` 再 `if(i%p[j]==0)break`——先 break 的话 i·p[j] 本身漏筛
⚠️ **素数表数组开小**：π(n)≈n/ln n，n=10^6 就有 78498 个质数；例题代码 p 开 10005 只够 n=10^5 量级——数组按 π(n) 估算着开
⚠️ **√n 的写法**：`int tmp=sqrt(n)`（sqrt 返回 double，小心精度）或循环条件 `i*i<=n`（i*i 防溢出要 long long）
⚠️ **埃氏筛内层起点**：课件代码从 `j=i*2` 开始删；可优化成 `j=i*i`（更小的倍数已被更小质数删过）——但线性筛必须从 p[1]=2 的 i 倍枚举起，不能跳

## 📖 知识点讲解

### 1. 质数与试除判定：朴素法三连优化

**是什么**：质数（素数）——大于 1 的自然数，除 1 和本身外没有其他因数；0 和 1 既不是质数也不是合数。试除判定：按定义拿 2..n-1 逐个去除，除得尽就是合数。白话——查户口，查到一个"外人"（约数）就出局。

**为什么**：朴素全查每个数 O(n)，筛 1~n 总共 O(n²)。两次免费优化：①一个数除以比它一半还大的数必除不尽 → 只查到 n/2；②因数成对（若 n=a×b，则一个 ≤√n、一个 ≥√n），左边查不到约数右边也不会有 → 只查到 √n。课件给出三档复杂度：O(n²) → O(n²)（常数减半）→ O(n^1.5)（批量逐个判）。

**怎么用**——课件 isPrime 代码（试除到 √n）：
```cpp
bool isPrime(int n) {
    if(n < 2) return 0;              // 0 和 1 不是质数
    int tmp = sqrt(n);               // 试除到 sqrt(n)
    for(int i = 2; i <= tmp; i++)
        if(n % i == 0) return 0;     // 除得尽 → 合数
    return 1;                        // 都除不尽 → 质数
}
```
**跟算**：判 36——i=2 一除就尽，合数；判 97——√97≈9.8，试 2..9 全除不尽，质数。再看因数对：36=3×12=4×9=6×6，每对都一个 ≤6 一个 ≥6，6×6 恰好骑在 √36 上——这就是"试到平方根"的几何直观。

> ⚠️ 注意事项：试除是"单点判定"利器，但筛 1~n 逐个调用是 O(n√n)——批量需求请翻篇换筛法。
> 🎯 规律：判一个数 → 试除到 √n；判一批数 → 筛法预处理。
> 💡 一句话总结：试除到根号，因数必成对。

### 2. 埃氏筛：质数的倍数全是合数

**是什么**：白话——"坏人家族一锅端"：确认 2 是质数，就划掉 2 的所有倍数；下一个没被划掉的最小数 3 必是质数（若它是合数，早该被更小的质数划掉了），再划 3 的倍数……严格说：基于算术基本定理（唯一分解定理）——任何合数都能分解成若干质数的乘积，所以**质数的倍数一定是合数**；把每个质数的倍数删光，剩下的自然全是质数。课件步骤：(1) 先删 1（既非质数也非合数）；(2) 读当前最小数 2，删 2 的倍数；(3) 读当前最小数 3，删 3 的倍数；(4) 读 5，删 5 的倍数……直到读完。

**为什么**：相比逐个试除，筛法把"判定"变成"批量删除"，一次删除同时服务多个数。代价是重复功：6 既是 2 的也是 3 的倍数，被删两次（课件原例）——这个重复正是线性筛要消灭的对象。

**怎么用**——埃氏筛代码（`线性筛.cpp` 注释版，反向标记）：
```cpp
isPrime[1] = 1;                            // 约定：0=质数，1=不是质数
for(int i = 2; i <= n; i++)
    if(isPrime[i] == 0)                    // i 没被划掉 → i 是质数
    {
        p[++sum] = i;                      // 收进素数表
        for(int j = 2*i; j <= n; j += i)   // 删 i 的倍数
            isPrime[j] = 1;
    }
```
**跟算**：n=20，看谁删了谁：
```
i=2 质数 → 删 4,6,8,10,12,14,16,18,20
i=3 质数 → 删 9,15           （6,12,18 已被 2 删过——重复！）
i=4 已被划掉，跳过
i=5 质数 → 删 10,15,20        （全是重复）
i=6,8,9,10 已划掉；i=7 质数 → 删 14（重复）
i=11,13,17,19 质数（倍数全 >20）
素数表：2,3,5,7,11,13,17,19 ✓
```
同一个数被反复删（10 被删两次、15 两次、6 三次），这就是 O(n log log n) 里那个 log log 的身形。

> ⚠️ 注意事项：课件代码对"已删元素"照删不误（没有跳过检查）——正确性无碍，但这就是多余功；删除起点 `j=i*2` 可优化成 `j=i*i`，n 大时常数差距明显。
> 🎯 规律：读到"未被删的最小数"必是质数——它没被前面任何质数整除过。
> 💡 一句话总结：质数一出手，倍数全带走。

### 3. 欧拉筛（线性筛）：每个合数只死一次

**是什么**：白话——给每个合数指定唯一"责任人"：它的**最小质因数**。枚举 i 和素数表 p[j]，用 x=i·p[j] 合成合数去标记；一旦发现 p[j] 是 i 的因子（`i%p[j]==0`）立刻 break，后面的合成留给未来。严格说：规定每个合数只被它最小的质因数筛去——x=i·p[j] 且 p[j] 是 x 的最小质因数，这种表示唯一，故不重不漏，总标记次数 = 合数个数，O(n)。

**为什么**：埃氏筛 O(n log log n) 已很快，但 n=10^7 量级时重复删除仍可观；线性筛把重复压到零，还是后面筛欧拉函数 φ、求最小质因数等积性函数的底座——数论题的标配预处理。

**怎么用**——主代码（`线性筛.cpp`，变量名忠实原码）：
```cpp
bool isPrime[1000005];              // 反向：0=质数，1=不是质数
int p[80000], sum = 0;              // 素数表（n=10^6 时 π(n)=78498，要开够！）
isPrime[1] = 1;                     // 1 不是质数
for(int i = 2; i <= n; i++)         // i：合数的"另一半"因子
{
    if(isPrime[i] == 0)             // i 是质数：先收表
    {
        sum++;
        p[sum] = i;
    }
    for(int j = 1; j <= sum; j++)   // 用素数表合成合数
    {
        int x = i * p[j];
        if(x > n) break;            // 超范围：后面的更大，直接换 i
        isPrime[x] = 1;             // 先标记！
        if(i % p[j] == 0) break;    // p[j] 是 i 的因子：再往后合成的数
    }                               // 最小质因数不是 p[j]，必须留给未来
}
```
**跟算**：n=20，完整标记过程（课件第 10 页同款表的缩小版）：

| i | 入表？ | 本轮标记的 x=i×p[j] | 为什么停 |
|---|---|---|---|
| 2 | ✓ {2} | 4 | 2%2==0 → break |
| 3 | ✓ {2,3} | 6, 9 | 3%3==0 → break |
| 4 | ✗ | 8 | 4%2==0 → break |
| 5 | ✓ {2,3,5} | 10, 15 | 5×5=25>20 → break |
| 6 | ✗ | 12 | 6%2==0 → break |
| 7 | ✓ {2,3,5,7} | 14 | 7×3=21>20 → break |
| 8 | ✗ | 16 | 8%2==0 → break |
| 9 | ✗ | 18 | 9%2≠0 继续；9×3=27>20 → break |
| 10 | ✗ | 20 | 10%2==0 → break |
| 11~20 | 入表：11,13,17,19；其余跳过 | 无 | i×2 已 >20 → break |

4~20 的每个合数（4,6,8,9,10,12,14,15,16,18,20）在表中恰好出现一次 ✓；素数表 2,3,5,7,11,13,17,19 ✓。对比埃氏筛：6 只在 i=3、p[j]=2 时被 2×3 标记一次——它不再被 3 重复标记（3×2 根本不会出现，因为 i=2 时 2%2==0 提前 break 了）。

> ⚠️ 注意事项：break 两行的顺序是"先标记 x、再判断是否 break"——顺序颠倒 i·p[j] 本身漏筛；`x>n` 的 break 必须放最前，防数组越界。
> 🎯 规律：合数 x 只由"x/最小质因数 × 最小质因数"这一种方式生成——唯一责任人制。
> 💡 一句话总结：每个合数，只死一次。

### 4. 模板细节账单与选型

**是什么**：三种方法一条升级链：朴素试除（单点 O(√n)，批量 O(n√n)）→ 埃氏筛（O(n log log n)，代码最短）→ 线性筛（O(n)，数论标配）。细节账单四笔：反向标记语义、特判 0 和 1、素数表按 π(n) 开大小、break 顺序。

**为什么**：竞赛里筛法是"预处理"——n 高达 10^6~10^8 时只有筛法活得下来；而 P3383 这类模板题还追问"第 k 小的质数"，素数表 p[] 存着，答案就是 p[k]。

**怎么用**——做题三步：①看数据范围选筛（n≤10^6 无脑线性筛）；②按 π(n)≈n/ln n 开素数表（n=10^6 → 78498，开 8 万以上）；③查询类题目筛完直接查表或做前缀和。**跟算**：n=20 筛完后 p={2,3,5,7,11,13,17,19}，sum=8——问"第 5 小的质数"→ 直接答 p[5]=11，O(1)。

> ⚠️ 注意事项：例题代码 p 开 10005、注释却写 n≤10^6，两者不匹配——10005 只装得下 n=10^5 的 9592 个质数；真给 n=10^6 必须开大（易错点清单里那条）。P3383 的 n 高达 10^8，bool 数组 10^8 字节约 100MB 会 MLE，要用 bitset（1 字节记 8 个标记）。
> 🎯 规律：预处理换查询——筛一遍，此后"是不是质数 / 第几个质数 / 区间质数个数"全是 O(1) 或 O(log) 级。
> 💡 一句话总结：筛一次，查一世。

## 🔍 相似概念辨析

**组1：朴素试除 vs 埃氏筛 vs 线性筛**

| 对比维度 | 朴素试除 | 埃氏筛 | 线性筛（欧拉筛） |
|---|---|---|---|
| 各自定义 | 按定义逐个除 2..√n | 删每个质数的所有倍数 | 每合数只被最小质因数标记 |
| 核心区别 | 单点即时判定 | 允许重复删（6 删两次） | 不重不漏 |
| 各自特点 | 无预处理、即到即判 | 代码最短好记 | break 两行是灵魂 |
| 时间复杂度 | 单点 O(√n)，批量 O(n√n) | O(n log log n) | O(n) |
| 使用场景 | 判单个数/个数很少 | n≤10^6 且只要质数表 | n 大或要配合积性函数 |
| 记忆口诀 | 单点试除，批量上筛，极致线性 |

**组2：判单个质数 vs 筛一批质数**

| 对比维度 | 试除判定 isPrime(n) | 筛法预处理 |
|---|---|---|
| 各自定义 | 对单个 n 试除到 √n | 一次性预处理 1~n 的全部质数 |
| 核心区别 | 即时计算一次 | 一次预付、终身查询 |
| 各自特点 | 无空间开销 | bool 数组 + 素数表 |
| 时间复杂度 | O(√n) 每次 | O(n)~O(n log log n) 总共 |
| 使用场景 | 查询次数极少 | 查询多 / 要第 k 小 / 区间计数（配前缀和） |
| 典型示例 | 判 97 → 试 2..9 | P3383 直接查 p[k] |
| 记忆口诀 | 问一次就除，问一生就筛 |

**组3：埃氏筛从 2i 起 vs 从 i² 起**

| 对比维度 | 内层 j 从 2i 开始（课件写法） | 内层 j 从 i² 开始 |
|---|---|---|
| 各自定义 | 删 i 的 2,3,4,… 倍 | 从 i×i 删起 |
| 核心区别 | i×(2..i-1) 已被更小质数删过，属重复功 | 跳过必然重复的段 |
| 各自特点 | 直观、贴课件 | 常数更小；i² 注意溢出 |
| 时间复杂度 | O(n log log n) | 同左（只省常数） |
| 使用场景 | 教学/默写按课件 | 实战常用 |
| 典型示例 | i=5 删 10,15,20 全是重复 | i=5 直接从 25 删（n=20 时无事可做） |
| 记忆口诀 | 平方起删，少做废功 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**批量判质数太慢（痛点）→ 因数成对，单点砍到 √n（朴素优化）→ 换视角"删合数"：质数的倍数必是合数（唯一分解定理）→ 埃氏筛 O(n log log n)，但有重复功 → 给合数指定唯一责任人（最小质因数）→ break 两行实现"只死一次" → 线性筛 O(n)**。

跨知识点共性：
1. **与第六章快速幂互相呼应**：快速幂复用"平方结果"、筛法复用"最小质因数"——本质都是记忆/空间换时间，避免重复劳动。
2. **唯一分解定理是全章地基**：埃氏筛的正确性（质数的倍数必是合数）与线性筛的"唯一表示"都从它来——一个定理撑起三种算法的升级。
3. **向后铺垫**：线性筛骨架（i 枚举 + 素数表 + break）直接升级为欧拉函数 φ、最小质因数分解等积性函数筛；后面的逆元、组合数等数论专题全靠它打底。

## 📋 速查表

| 模板 | 复杂度 | 适用条件 |
|---|---|---|
| 试除 isPrime | O(√n)/次 | 判单个数 |
| 埃氏筛 | O(n log log n) | 筛 1~n，代码最短 |
| 线性筛 | O(n) | n≥10^6 / 数论预处理 |
| 朴素试除到 n-1 | O(n)/次，批量 O(n²) | 仅教学演示，实战勿用 |

```cpp
// 线性筛骨架（默写级）
bool isPrime[N];              // 0=质数 1=不是（反向）
int p[N/10], sum = 0;         // 素数表按 π(n)≈n/ln n 开
isPrime[1] = 1;
for (int i = 2; i <= n; i++) {
    if (!isPrime[i]) p[++sum] = i;          // 先收质数
    for (int j = 1; j <= sum; j++) {
        int x = i * p[j];
        if (x > n) break;                    // 超界先退
        isPrime[x] = 1;                      // 先标记
        if (i % p[j] == 0) break;            // 最小质因数负责制
    }
}
```
