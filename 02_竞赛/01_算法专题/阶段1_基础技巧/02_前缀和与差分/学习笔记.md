## 第二章：前缀和与差分

> 课件来源：`2.前缀和&差分.pptx`
>
> 例题代码：`P1387.cpp`（最大正方形）、`P3397.cpp`（地毯）；课上例题 B3612（一维区间和，课件给了思路）

## 🗺️ 本章地图

本章解决两类高频问题：多次查询"一段区间的和"用前缀和，多次执行"给一段区间整体加减"用差分。学习顺序：一维前缀和（B3612）→ 二维前缀和与容斥（P1387）→ 一维差分 → 二维差分（P3397）。核心关系：差分是前缀和的逆运算——前缀和"预处理一次、查询千次"，差分"修改千次、还原一次"，且差分还原靠的正是前缀和。

## 📌 本章重点

⭐ **一维前缀和**：sum[i] = A[1..i] 之和；区间和 = sum[r]-sum[l-1]；下标从 1 开始，S[0]=0 兜底
⭐ **二维前缀和（容斥）**：预处理 sum[i][j]=sum[i-1][j]+sum[i][j-1]-sum[i-1][j-1]+a[i][j]；矩形和四角公式
⭐ **一维差分**：区间 [l,r]+x → b[l]+=x、b[r+1]-=x，最后前缀和还原；用于"区间修改+单点查询"
⭐ **二维差分**：四角打标 ++b[x1][y1]、--b[x2+1][y1]、--b[x1][y2+1]、++b[x2+1][y2+1]，再二维前缀和还原
⭐ **前缀和做枚举优化**：P1387 用二维前缀和把 O(nml³) 优化到 O(nml)

## 🔥 本章难点

🔥 **容斥原理的正负号**：二维预处理与查询都是"加上两条边、减去重叠角"，符号错一个全盘皆错——用"大矩形 = 上边 + 左边 - 重叠左上 + 自己"理解
🔥 **二维差分四角标记**：为什么恰好是两加两减、为什么还原时做的是二维前缀和——本质是"每个标记的势力范围是其右下方的整个矩形"

## ⚠️ 本章易错点

⚠️ **下标从 0 开始写**：l=1 时 S[l-1]=S[0] 必须合法——课件约定下标从 1 开始、S[0]=0，从 0 开始会访问 S[-1] 越界
⚠️ **矩形和四角符号写错**：sum[rx][ry]-sum[rx][ly-1]-sum[lx-1][ry]+sum[lx-1][ly-1]，最后一项是 +，被减了两次的重叠角要补回来
⚠️ **差分数组开小**：修改 r=n 时要写 b[n+1]，数组至少开到 n+2
⚠️ **修改与查询顺序颠倒**：课件强调差分"修改操作一定要在查询操作之前"——所有区间修改完成后才能还原查询
⚠️ **还原忘做前缀和**：差分打完标记直接输出 b 是错的，必须先求一遍（二维）前缀和得到新序列/修改量

## 📖 知识点讲解

### 1. 一维前缀和：O(1) 回答区间和

**是什么**：一句话——先把"从头到每个位置的累加和"存成一张表，以后问任何区间和只是两个表项相减。课件定义：前缀和可以简单理解为"数列的前 n 项的和"，是一种重要的预处理方式；sum[i] 是原数组 A 第 1 到第 i 个数的和。

**为什么**：朴素做法每次问 [l,r] 都要现加 O(r-l+1)，m 次询问最坏 m·n；预处理 O(n) 后每次询问 O(1)——把"反复求区间和"的代价一次性摊掉。

**怎么用**：
```cpp
sum[0] = 0;
for (int i = 1; i <= n; i++)      // 边读入边求前缀和（课件思路）
    sum[i] = sum[i-1] + a[i];
// [l, r] 的区间和：
ans = sum[r] - sum[l-1];
```
跟算：A = 3 1 4 1 5 → S = 0 3 4 8 9 14。区间 [2,4] 的和 = S[4]-S[1] = 9-3 = 6 = 1+4+1 ✓；区间 [1,3] = S[3]-S[0] = 8 = 3+1+4 ✓。
例题 B3612（课上讲）：读入即建 S，每次询问直接输出 S[r]-S[l-1]。

> ⚠️ 注意事项：下标从 1 用到 n，S[0]=0 使 l=1 时公式天然成立；看数据范围决定是否 long long。

> 🎯 规律：凡"静态数组 + 多次区间求和/统计"，一律先前缀和预处理。

> 💡 一句话总结：预处理一遍，查询一步到位。

### 2. 二维前缀和与容斥原理

**是什么**：一句话——把一维"前 i 项和"推广成"左上角 (1,1) 到 (i,j) 的矩形总和"，扩展和查询时多算的部分用容斥加减回来。课件定义：二维数组 sum[i][j] 是 A[1][1] 到 A[i][j] 的和（矩形范围）；多维前缀和的求解几乎都基于容斥原理——计数不重复、不遗漏。

**为什么**：以 (i,j) 为右下角的矩形 = 上方长条 + 左方长条 + 重叠的左上矩形 + 当前格；重叠部分被加了两次必须减掉。查询反向同理：大矩形减两条边，再补回多减的角。

**怎么用**：
```cpp
// 预处理（i、j 从 1 顺着推一遍）
sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i][j];
// 查询 (lx,ly)-(rx,ry) 矩形和
ans = sum[rx][ry] - sum[rx][ly-1] - sum[lx-1][ry] + sum[lx-1][ly-1];
```
ASCII 图示（查询公式，最外框 = sum[rx][ry]）：
```
┌───────────────────────┐
│ 减: sum[lx-1][ry]     │
│   ┌───────────┬───────┤
│   │ 重叠左上   │ 目标  │
│   │ +补回      │ 矩形  │
│   └───────────┴───────┤
│ 减: sum[rx][ly-1]      │
└───────────────────────┘
减上下两条边时，左上重叠角被减了两次 → 最后 +sum[lx-1][ly-1] 补回
```
例题 P1387（最大正方形）：01 矩阵中找最大全 1 正方形。思路（课件）：先枚举左上角 (i,j) 和边长 l，判断正方形内元素和是否等于 l²（元素非 0 即 1，全 1 时和恰为面积），是则 ans=max(ans,l)；朴素 O(nml³)；用二维前缀和把"求正方形内和"变成 O(1)，整体 O(nml)。
```cpp
while (l <= min(n,m))                  // 枚举边长
    for (int i = l; i <= n; i++)
        for (int j = l; j <= m; j++) { // 枚举正方形右下角
            int x = i-l+1, y = j-l+1;  // 反推左上角
            if (sum[i][j]-sum[i][y-1]-sum[x-1][j]+sum[x-1][y-1] == l*l)
                ans = max(ans, l);
        }
```
跟算：矩阵某处有 3×3 全 1 块。l=2 时任一 2×2 内和=4=2² 命中，ans=2；l=3 时在 3×3 处内和=9=3²，ans=3；l=4 时所有 4×4 内和 <16，停止，答案 3。

> ⚠️ 注意事项：预处理公式末尾 "+a[i][j]"，查询公式四端点全是 sum——两个公式形状相近，别互相串。

> 🎯 规律：二维"矩形区域内某统计量"→ 二维前缀和；"区域内和==面积"是 01 矩阵判全 1 的通法。

> 💡 一句话总结：上加左减重叠角，查询一减两补。

### 3. 一维差分：O(1) 完成区间修改

**是什么**：一句话——差分是前缀和的逆运算：把"对区间每个数加 x"变成"只在区间两头记账"。课件定义：差分可以维护多次对序列的一个区间加上一个数，并在最后询问某一位置的数；注意修改操作一定要在查询操作之前。差分多用于区间修改+单点查询。

**为什么**：m 次区间加，朴素每次 O(r-l+1) 最坏 m·n；差分每次修改只动两个格子 O(1)，最后求一遍前缀和 O(n) 统一还原——把修改成本从 O(n) 压到 O(1)。

**怎么用**——课件区分两种等价写法：
- **差分数组**：初始由 a 差分得出（b[i]=a[i]-a[i-1]），在 b 上修改，最后对 b 求前缀和直接得到修改后的 a
- **差分标记数组**：初始 b 全 0，修改打标记，前缀和得 sum[i]（= a[i] 的修改量），再加回原 a 得新序列
```cpp
// 差分标记数组版
b[l] += x;  b[r+1] -= x;                    // 区间 [l,r] 整体 +x
for (int i = 1; i <= n; i++) sum[i] = sum[i-1] + b[i];  // 修改量
a[i] += sum[i];                              // 新 a = 原 a + 修改量
```
跟算：a 全 0，操作 [2,4]+3、[1,2]-1。打标：b[2]+=3、b[5]-=3；b[1]-=1、b[3]+=1 → b = [-1, 3, 1, 0, -3]。前缀和 sum = [-1, 2, 3, 3, 0]。新 a = [-1, 2, 3, 3, 0]：[2,4] 段全是 3 ✓，[1,2] 段各减 1 ✓。

> ⚠️ 注意事项：r+1 最大到 n+1，数组开 n+2；差分天生"离线"——改完才能查，边改边查要线段树（后续章节）。

> 🎯 规律：特征"多次区间整体加减 + 最后才问" → 差分；"边改边问" → 线段树。

> 💡 一句话总结：区间修改两头记，一次前缀和还原。

### 4. 二维差分（P3397 地毯）

**是什么**：一句话——把一维"两头记账"升级成"四角记账"：给矩形整体加标记，只在四个角落笔。课件思路：设差分标记数组 b[i][j]，每次修改 ++b[x1][y1]、--b[x2+1][y1]、--b[x1][y2+1]、++b[x2+1][y2+1]；最后 a[i][j]=a[i-1][j]+a[i][j-1]-a[i-1][j-1]+b[i][j] 还原出原序列。

**为什么**：标记 b[i][j] 的含义是"给以 (i,j) 为左上角的所有右下区域各 +1"；四个角两加两减，恰好让目标矩形内为 +1、矩形外抵消为 0；还原用的正是二维前缀和——差分与前缀和互逆在此闭环。

**怎么用**（P3397：n×n 地面铺 m 块地毯，问每格被覆盖几次）：
```cpp
for (每块地毯 lx,ly,rx,ry) {
    b[lx][ly]++;      b[lx][ry+1]--;
    b[rx+1][ly]--;    b[rx+1][ry+1]++;
}
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++) {
        a[i][j] = a[i-1][j] + a[i][j-1] - a[i-1][j-1] + b[i][j];
        printf("%d ", a[i][j]);   // 还原即输出
    }
```
ASCII 图示（对 (x1,y1)-(x2,y2) 打 +1 标记后做二维前缀和的"势力范围"）：
```
        y1        y2   y2+1
  x1    +1   ....  +1   -1
        +1  (覆盖)  +1   -1     ← 竖着看：-1 拦住下方
  x2    +1   ....  +1   -1
 x2+1    0     0     0    0    ← 横竖双向抵消，矩形外恒为 0
```
跟算：2×2 网格铺一块 (1,1)-(2,2) 地毯 → b[1][1]++、b[1][3]--、b[3][1]--、b[3][3]++（数组开到 3）。还原：a[1][1]=1；a[1][2]=a[0][2]+a[1][1]-a[0][1]+b[1][2]=1；a[1][3]=1-1=0 ✓；同理 a[2][*] 均为 1，第 3 行/列全 0 ✓。

> ⚠️ 注意事项：四角符号为 +、-、-、+（左上加、右上减、左下减、右下加）；b 与 a 都开到 n+2 防 rx+1、ry+1 越界。

> 🎯 规律：一维差分记两头，二维差分记四角；谁打了标记，谁就欠一次前缀和。

> 💡 一句话总结：四角落笔，前缀和收账。

## 🔍 相似概念辨析

**组1：前缀和 vs 差分**

| 对比维度 | 前缀和 | 差分 |
|---|---|---|
| 各自定义 | S[i]=A[1..i] 的和，重要的预处理方式 | 求和的逆运算，维护多次区间整体加 |
| 核心区别 | 优化"查询"：预处理后 O(1) 求区间和 | 优化"修改"：O(1) 打标记，最后统一还原 |
| 各自特点 | 静态数组，建表后不再改 | 修改必须在查询之前，改完不再动 |
| 使用场景 | 多次问 [l,r] 的和/统计（B3612、P1387） | 多次区间加 + 最后问（P3397） |
| 典型示例 | S[r]-S[l-1] 秒出区间和 | b[l]+=x、b[r+1]-=x |
| 记忆口诀 | 查得多用前缀和，改得多用差分 |

**组2：差分数组 vs 差分标记数组**

| 对比维度 | 差分数组 | 差分标记数组 |
|---|---|---|
| 各自定义 | 初始由 a 差分得出（b[i]=a[i]-a[i-1]） | 初始全 0，只记录修改量 |
| 核心区别 | 前缀和后直接得到"修改后的 a" | 前缀和后得到"修改量 sum"，需再加回 a |
| 各自特点 | 多一步初始差分构造 | 少一步构造，多一步加回 |
| 使用场景 | 序列从零建（读入时顺手差分） | 在已有数组上追加区间修改 |
| 典型示例 | 读入 a 后做 b[i]=a[i]-a[i-1] | P3397 的 b 全 0 起步打四角标 |
| 记忆口诀 | 差分数组装全量，标记数组只装改动 |
