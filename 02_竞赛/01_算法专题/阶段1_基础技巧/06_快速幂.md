## 本章地图

本章解决一个问题：**「b = 10¹⁸，a^b mod p 怎么在 60 次乘法内算完？」**

```text
要算 a^b mod p
   ├─ b 小（≤ 10⁷）       → 朴素循环连乘
   └─ b 大（≤ 10¹⁸）      → 快速幂：指数二进制拆分 + 底数逐轮平方（知识点 1）
         ├─ 顺带解决「除法取模」 → 费马小定理求逆元（知识点 3）
         │     └─ 组合计数 → 阶乘 + 阶乘逆元预处理（知识点 4）
         └─ 把「数」换成「矩阵」 → 矩阵快速幂加速递推（知识点 5）
   ↓
判断档位：p ≤ 10⁹ 直接乘；p 近 10¹⁸ 用 __int128 中转（知识点 2）
```

**为什么这条路径是这样**：b 的二进制只有约 60 位（10¹⁸ < 2⁶⁰），
「平方 60 次 + 在二进制为 1 的位上选乘」就覆盖了全部幂次。
**快速幂的价值不在快，而在它把「指数」从循环变量变成了位运算对象**——
这个视角迁移到矩阵、多项式，就是后面所有「快速幂加速」类算法的种子。

## 核心概念与模板

**是什么**：
- **快速幂**：把指数按二进制拆分，底数逐轮平方，只在当前位为 1 时把当前底数乘进答案。
- **逆元**：满足 a·x ≡ 1 (mod p) 的 x；p 为素数时 x = a^(p−2)。

**为什么**：b 达 10¹⁸ 时朴素连乘 10¹⁸ 次必然超时；
而「除以 a 取模」不能直接做（模意义下除法不封闭），必须转化为乘逆元。

> **【规律】** **取模三定律贯穿全章**：加減乘都可以「先模再算」；
> **除法不行**（逆元解决）；**每步乘完立刻取模**（链式中间值不膨胀）。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
typedef long long ll;

ll qpow(ll a, ll b, ll p) {
    ll res = 1 % p;                  /* 坑一：p = 1 时答案为 0 */
    a %= p;                          /* 坑二：底数先归约 */
    while (b > 0) {
        if (b & 1) res = res * a % p;
        a = a * a % p;               /* 底数逐轮平方 */
        b >>= 1;
    }
    return res;
}

/* 大模数（接近 10^18）时乘法中转 __int128 */
ll qpowBig(ll a, ll b, ll p) {
    ll res = 1 % p;
    a %= p;
    while (b > 0) {
        if (b & 1) res = (__int128)res * a % p;
        a = (__int128)a * a % p;
        b >>= 1;
    }
    return res;
}

/* 配套：费马小定理求逆元（p 为素数、a 非 p 的倍数） */
ll inv(ll a, ll p) { return qpow(a, p - 2, p); }
```

> **【类比】** 快速幂像**复印放大**：想要 13 份文件，不印 13 次，
> 而是印 1 → 2 → 4 → 8 份（逐轮平方），再把 8 + 4 + 1 凑成 13（按二进制选乘）。
> **60 次操作覆盖 10¹⁸ 个幂次，这就是对数级压缩。**

## 本章难点

> **【难点】** **逆元的使用前提是「三查」**：p 是不是素数（05 篇判素）？
> a 是不是 p 的倍数（倍数没有逆元）？要不要换用扩展欧几里得（p 非素数时）？
> **三查少一查，答案错一半还不报错**——这是数论题最隐蔽的失分点。

> **【难点】** **矩阵快速幂的构造**。
> 难点不在幂（模板原封不动换成矩阵乘），而在**把递推写成矩阵形式**：
> 状态向量取「转移所需的历史 k 项」，转移矩阵第 i 行描述 f(n−i+1) 的组合系数。
> 构造错了模板再对也白搭——**先在纸上写出矩阵等式，再写代码**。

---

## 本章易错点

> **【头号易错】** 忘写 `res = 1 % p`（p = 1 时应输出 0 而输出 1）
> 或忘写 `a %= p`（a ≥ p 时首个乘积就错）。

> **【易错】** **模数近 10¹⁸ 时 `res * a` 溢出**——两个接近 10¹⁸ 的数相乘达 10³⁶，
> 必须 `__int128` 中转。判档口诀：**p² ≤ 9×10¹⁸ 用 long long，否则上 `__int128`**。

> **【易错】** **把快速幂当万能**：a ≡ 0 (mod p) 且 b = 0 的约定按题意处理
> （0⁰ 有的题定义为 1，有的要求特判）。

> **【易错】** **逆元前提忘验证**：p 合数时费马小定理失效；
> a 是 p 的倍数时逆元不存在。

> **【易错】** **阶乘逆元每项各调一次快速幂**——正确写法是「单个求逆 + 逆序递推」，
> 省一个 log 因子；n = 10⁶ 时差距明显。

## 典型例题

### 例 1　幂取模（qpow 直用）　难度：模板题

**题干摘要**：多组询问求 a^b mod p，a, b ≤ 10¹⁸，p ≤ 10⁹。
**题源**：同类真源见配套练习 T1（P1226 【模板】快速幂）
**涉及知识点**：知识点 1、2

**解题思路**：

1. **信号**：b 达 10¹⁸ → 快速幂；p ≤ 10⁹ → 乘积 ≤ 10¹⁸ 压 long long 上限内，**无需 `__int128`**。
2. **方法**：qpow 原样使用，注意三个坑。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
typedef long long ll;

ll qpow(ll a, ll b, ll p) {
    ll res = 1 % p;
    a %= p;
    while (b > 0) {
        if (b & 1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        ll a, b, p;
        scanf("%lld %lld %lld", &a, &b, &p);
        printf("%lld\n", qpow(a, b, p));
    }
    return 0;
}
```

**复杂度**：每问 O(log b) ≈ 60 次乘法，空间 O(1)。

> **【易错】** a、b、p 全部 `long long` 读入——把 b 读进 `int` 是本章最高频的 RE/WAE 来源。

### 例 2　组合数取模（阶乘 + 阶乘逆元）　难度：变式题

**题干摘要**：求 C(n, m) mod p（p 为素数且 > n），n ≤ 10⁶，多次询问。
**题源**：逆元标准应用（组合计数题的公共底座）
**涉及知识点**：知识点 3、4

**解题思路**：

1. **信号**：「计数 + 取模 + 除法（组合数定义含除法）」→ 逆元。
2. **方法**：O(n) 预处理阶乘；阶乘逆元**单次求逆 + 逆序递推**；
   每问 O(1)：C(n, m) = n! × inv(m!) × inv((n−m)!)。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
typedef long long ll;
const int N = 1000005;
ll fact[N], invf[N], p;

ll qpow(ll a, ll b, ll p) {
    ll r = 1 % p;
    a %= p;
    while (b) {
        if (b & 1) r = r * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return r;
}

int main() {
    int n;
    scanf("%d %lld", &n, &p);
    fact[0] = 1 % p;
    for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % p;
    invf[n] = qpow(fact[n], p - 2, p);           /* 单次求逆 */
    for (int i = n; i >= 1; i--) invf[i - 1] = invf[i] * i % p;  /* 逆序递推 */
    int q;
    scanf("%d", &q);
    while (q--) {
        int m, k;
        scanf("%d %d", &m, &k);
        printf("%lld\n", fact[m] * invf[k] % p * invf[m - k] % p);
    }
    return 0;
}
```

**复杂度**：预处理 O(n)，每问 O(1)，空间 O(n)。

> **【易错】** 乘法链 `fact[m] * invf[k] % p * invf[m-k] % p` **每步都取模**——
> 少写中间那个 `% p`，两个 10⁹ 级因子相乘再乘第三个就会溢出。

## 本章总结

### 核心内容（一页纸）

1. **b 的二进制只有约 60 位**（10¹⁸ < 2⁶⁰）——快速幂 60 次乘法覆盖任意幂次。
2. **qpow 三个坑**：`res = 1 % p`、`a %= p`、大模数上 `__int128`。
3. **判档口诀**：p² ≤ 9×10¹⁸ 用 long long，否则 `__int128` 中转。
4. **取模三定律**：加減乘可先模；**除法必须走逆元**；乘法链每步取模。
5. **逆元三查**：p 素吗？a 是 p 的倍数吗？要不要扩展欧几里得？
6. **费马小定理**：p 素、a 非 p 倍数 ⇒ inv(a) = a^(p−2)。
7. **阶乘逆元**：单次求逆 + 逆序递推 `invf[i-1] = invf[i] * i % p`，别每项调幂。
8. **组合数取模**：C(n,m) = fact[n] × invf[m] × invf[n−m]，每问 O(1)。
9. **矩阵快速幂**：模板不变，难点在把递推写成矩阵等式；内层取模防溢出。
10. **「mod 大质数」是本章最强题型信号**——看到先查：除法？递推？模数多大？
