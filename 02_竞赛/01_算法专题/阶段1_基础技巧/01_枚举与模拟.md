## 本章地图

本章解决一个问题：**「我想不出高级算法时，怎么保证拿到分？」**

```text
想不出算法 → 先看数据范围
   ├─ n ≤ 20        → 子集枚举（2ⁿ）
   ├─ n ≤ 100       → 三重循环（n³）
   ├─ n ≤ 5000      → 二重循环（n²）
   ├─ n ≤ 10⁵       → 需要一个 O(n log n) 技巧，纯枚举不行
   └─ 模拟类题目    → 与数据范围无关，关键是把题面规则转成状态变量
   ↓
把暴力写对 → 拿到部分或全部分数
   ↓
再考虑剪枝与「生成式枚举」把暴力变快
```

**为什么这条路径是这样**：竞赛的得分规则是**按通过的数据点给分**，
而不是「解法高级才给分」。因此**一个写对的暴力，价值高于一个想不出的正解**。
理解这一点，才能理解为什么「枚举与模拟」被排在阶段 1 的第 1 篇——
**它是唯一一种「不需要任何算法知识就能拿分」的解法。**

## 核心概念与模板

**是什么**：
- **枚举** = 把所有候选答案遍历一遍，挑出正确的。
- **模拟** = 按题面规则一步步执行，记录状态变化。

**为什么**：数据范围小时（组合枚举 n ≤ 20、线性模拟 n ≤ 10⁶），**笨办法就是正解**。
CSP 前两题、蓝桥杯填空题大量是送分的枚举模拟。

> **【规律】** **先保正确，再谈聪明。**
> 一个写对的暴力能拿到部分分甚至满分；一个想不出的正解得零分。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

/* 模板一：组合枚举 —— n 个数选 k 个（i 从 start 起，保证升序不重复） */
int a[25], n, k;
long long ans = 0;

void dfs(int start, int picked, long long sum) {
    if (picked == k) {                   /* 选满：判定是否为解 */
        if (sum % 2 == 0) ans++;         /* 按题意替换判定 */
        return;
    }
    if (n - start + 1 < k - picked) return;  /* 剪枝：剩余不够选，直接回退 */
    for (int i = start; i <= n; i++)     /* 起点是 start，不是 1 —— 这是防重的关键 */
        dfs(i + 1, picked + 1, sum + a[i]);
}

/* 模板二：子集枚举（位运算）—— n ≤ 20 时合法 */
int b[21];
long long subsetWays(int m, long long S) {
    long long ways = 0;
    for (int mask = 0; mask < (1 << m); mask++) {      /* 2^m 个状态 */
        long long sum = 0;
        for (int i = 0; i < m; i++)
            if (mask >> i & 1) sum += b[i];            /* 取第 i 位 */
        if (sum == S) ways++;
    }
    return ways;
}
```

**模拟题三板斧**（动手前必须做完）：

1. **状态变量清单**：开写前在纸上列全（位置、方向、计数、标志）。
   **缺一个状态必然 WA**，且这类错误在样例上不一定暴露。
2. **边界单独测**：第一轮、最后一轮、空输入、单元素。
3. **样例当单元测试**：逐行手推样例，与程序输出对齐后再提交。

> **【类比】** 枚举像**在整本电话簿里找一个人**——笨但一定能找到，前提是簿子不太厚。
> 模拟像**照着菜谱做菜**——只要没漏掉任何一步配料与顺序，结果必然正确；
> **漏一步（漏状态），菜就不是那道菜了。**

## 本章难点

> **【难点】** **模拟题的「状态完整性」无法靠样例验证。**
> 样例通常只覆盖「典型路径」，而漏掉的状态往往只在**边界路径**上暴露。
> 因此模拟题的正确做法是：**先把状态清单写全，再写代码**——
> 而不是「先写代码，出错再补状态」。**顺序反了会反复返工。**

> **【难点】** **「生成式枚举」的思维转换**。
> 常规枚举是「遍历候选空间，逐个判定」；
> 生成式枚举是「**直接构造合法解，跳过非法候选**」。
> 例如求回文质数：遍历 10⁸ 个数逐一判定必然超时，
> 但**先按位数构造回文数**（数量少几个数量级），再判质数，复杂度骤降。
> **识别信号：合法解的比例极低。**

---

## 本章易错点

> **【头号易错】** **漏状态**。
> 环形问题忘记「回到起点」的特判、过程量没随操作同步更新。
> **这类错误不会报错、不一定被样例发现，只在特定输入上给出错误答案。**

> **【易错】** **下标 0 起与 1 起混用**。内部用 0 起、输出需要 1 起时漏写 `+1`。
> **纪律：口径转换只在一处做。**

> **【易错】** **循环边界多跑或少跑一轮**。`<` 与 `<=` 混用是本章最高频的低级错误。

> **【易错】** **结果用 `int` 存溢出**。方案数、累加和经常超过 2×10⁹，必须 `long long`。

> **【易错】** **子集枚举的空集**。`mask = 0` 时和为 0；若 S = 0，空集应计入方案数。

## 典型例题

### 例 1　约瑟夫环（模拟类）　难度：模板题

**题干摘要**：n 人围圈从 1 报数，报 m 的出列，输出出列顺序。n ≤ 1000。
**题源**：同类真源见配套练习 T4（乒乓球，状态机模拟）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「围成一圈」+「数到 m 出列」→ 环形模拟。
2. **状态清单**（动手前在纸上列）：
   当前位置 `cur`、已出列标记 `out[]`、本轮已报数计数 `cnt`、已出列人数 `round`。
3. **方法**：指针环形前进（取模），跳过已出列者；每轮出列 1 人，共 n 轮。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 1005;
bool out[N];

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    int cur = 0;                          /* 内部下标 0 起 */
    for (int round = 1; round <= n; round++) {
        int cnt = 0;
        while (cnt < m) {
            cur = (cur + 1) % n;          /* 环形前进：取模实现回绕 */
            if (!out[cur]) cnt++;         /* 跳过已出列者，只对未出列的计数 */
        }
        out[cur] = true;                  /* 出列，状态必须同步更新 */
        printf("%d ", cur + 1);           /* 恢复 1 起编号，此处是唯一转换点 */
    }
    return 0;
}
```

**复杂度**：时间 O(n × m) ≤ 10⁶，空间 O(n)。

> **【易错】** 内部下标 0 起、输出 1 起，**两处口径只许在一处转换**（本题在输出处）。
> 若两处都转，编号会整体偏移 1。

### 例 2　子集枚举求方案数（枚举类）　难度：变式题

**题干摘要**：n ≤ 20 个数，选若干个使和恰为 S，求方案数。
**题源**：同类真源见配套练习 T3（烤鸡，剪枝枚举）
**涉及知识点**：知识点 1、3

**解题思路**：

1. **信号**：n ≤ 20 → **由数据范围反推**：2²⁰ ≈ 10⁶，子集枚举合法（见阶段 0 基准表）。
2. **排除**：若 n = 100，此法不可用，需换 DP。
3. **方法**：用位运算枚举 0 到 2ⁿ−1 的每个掩码，逐位判定取或不取。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
int a[21];

int main() {
    int n;
    long long S;
    scanf("%d %lld", &n, &S);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    long long ways = 0;
    for (int mask = 0; mask < (1 << n); mask++) {   /* 边界：mask = 0 是空集 */
        long long sum = 0;                          /* 必须 long long，见易错点 */
        for (int i = 0; i < n; i++)
            if (mask >> i & 1) sum += a[i];         /* 取第 i 位对应的元素 */
        if (sum == S) ways++;
    }
    printf("%lld\n", ways);
    return 0;
}
```

**复杂度**：时间 O(2ⁿ × n) ≈ 2×10⁷（n = 20 时），空间 O(n)。

> **【易错】** 三处：
> 1. `sum` 必须 `long long`。n 个数累加极易超出 `int`（模块 A-1）。
> 2. **空集**（`mask = 0`）的和为 0；若 S = 0，空集应计入方案数。
> 3. `1 << n` 在 n = 31 时溢出 `int`，但 n ≤ 20 时安全。

## 本章总结

### 核心内容（一页纸）

1. **先看数据范围，再选解法。** n ≤ 20 子集枚举；n ≤ 100 三重循环；n ≤ 5000 二重循环。
2. **n ≥ 10⁵ 还要枚举所有区间 → 立刻换方法**（前缀和 / 尺取法）。
3. **枚举的两种形态**：线性组合枚举（`i` 从 `start` 起防重）、子集枚举（位运算）。
4. **组合枚举防重的关键**：递归的循环起点是 `start`，不是 `1`。
5. **子集枚举**：`mask` 从 0 到 `2ⁿ−1`，用 `mask >> i & 1` 判位。
   注意 **空集（`mask = 0`）和为 0**。
6. **累加和必须 `long long`**，方案数与和都容易超 `int`。
7. **模拟题三板斧**：状态变量清单 → 边界单独测 → 样例当单元测试。
8. **模拟的难点是「状态完整性」，不是逻辑复杂度。**
   漏状态不报错、不一定被样例发现，**只在边界路径暴露**。
9. **口径转换只在一处做**（内部 0 起、输出 1 起，只在一处 `+1`）。
10. **枚举的是「候选解」而非「候选空间」** —— 合法解比例极低时改用生成式枚举。
11. **剪枝与预处理让暴力能过**：剩余不够选则回退；先打表再枚举。
12. **本专题的价值是保底分**：想不出正解时先写暴力提交，再优化。
