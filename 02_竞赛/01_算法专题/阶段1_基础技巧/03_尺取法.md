## 本章地图

本章解决一个问题：**「枚举所有连续区间」是 O(n²)，能不能只走一遍就找完？**

```text
枚举左右端点是 O(n²) → 想省掉重复计算
   ↓
观察：若区间合法性能随端点移动「单调变化」
      则右端点前进时，左端点不必回退 —— 两个指针各自单向前进
   ↓
于是总步数从 n² 降到 2n = O(n)
   ↓
但「单调变化」是前提，不是所有题都有
   ↓
所以第一步永远是：验单调性
```

**为什么这条路径是这样**：尺取法**不是一种算法，而是一个前提下的优化**。
它没有独立的数学结构，全部的效力来自「左指针不回退」这一个观察。
理解这一点，就能理解为什么**验证前提比背模板更重要** —— 前提不成立时模板必然出错。

> 看到「连续子数组和」但**元素可能为负**，立刻放弃尺取法 ——
> 此时「右端点前进使和增大」不成立，左指针不能只顾右移。

## 核心概念与模板

**是什么**：维护左右指针 `l`、`r`；每轮 **`r` 前进一格**，
`l` 在条件被破坏时尽量右缩。两指针各单向前进，总步数 O(n)。

**为什么**：`l` 之所以能不回退，是因为**区间合法性随端点移动单调变化** ——
「加长更难满足」（或更容易满足）。一旦不单调，`l` 就可能需要左移，方法失效。

**怎么用**：

1. **先验单调**（知识点 1）。举反例：含负数时 `sum` 不随长度单调，不能用。
2. **选定窗口类型**：和型（维护 `sum`）还是计数型（维护 `cnt[]` 与 `kinds`）。
3. **确定条件方向**：求最长 → `while (不满足) 收缩`；求最短 → `while (满足) 收缩并更新答案`。
4. **配对维护**：`cnt[]` 与 `kinds` 必须与指针同进同出。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;

int a[100005], cnt[100005];              /* cnt：窗口内元素出现计数 */

/* 模板一：和 >= S 的最短子数组（前提：a 全为正） */
int minLen(int n, long long S) {
    int l = 1, ans = n + 1;              /* ans 初值取「不可能值」 */
    long long sum = 0;
    for (int r = 1; r <= n; r++) {
        sum += a[r];                     /* 固定动作：r 每轮进一格 */
        while (l <= r && sum - a[l] >= S) {   /* 若去掉 a[l] 仍合法，则缩 */
            sum -= a[l];                 /* 边界：先减再动 l，顺序不能反 */
            l++;
        }
        if (sum >= S) ans = min(ans, r - l + 1);
    }
    return ans == n + 1 ? 0 : ans;
}

/* 模板二：含 K 种不同数字的最长区间（计数型窗口） */
int longestK(int n, int K) {
    int l = 1, kinds = 0, ans = 0;
    for (int r = 1; r <= n; r++) {
        if (cnt[a[r]]++ == 0) kinds++;   /* 先加后判：新元素进窗则种类 +1 */
        while (kinds > K)                /* 超限：缩左端直到重新合法 */
            if (--cnt[a[l++]] == 0) kinds--;
        if (kinds == K) ans = max(ans, r - l + 1);
    }
    return ans;
}
```

> **【规律】** **两种方向的 `while` 条件刚好相反，这是实操中最容易写反的一处**：
>
> | 目标 | `while` 条件 | 更新答案的位置 |
> |------|------------|--------------|
> | 求**最短** | `while (窗口仍满足条件) 收缩` | 在 `while` **内**每次收缩前更新 |
> | 求**最长** | `while (窗口不满足条件) 收缩` | 在 `while` **之后**更新 |
>
> 记忆：**「缩到不行为止」是求最短，「缩到行为止」是求最长。**

## 本章难点

> **【难点】** **为什么「单调性」是必需的，而非「通常成立」。**
> 尺取法的正确性证明依赖一个不变量：**对于固定的 `r`，若区间 `[l, r]` 不满足条件，
> 则所有更小的 `l` 也不满足**（或反之）。这个不变量一旦被破坏，
> 被跳过的区间里就可能藏着更优解，而算法永远不会回头检查。
> **含负数的和型窗口恰好破坏它**：`sum` 随长度既不单调增也不单调减。

> **【难点】** **计数型窗口的「可逆性」**。窗口内维护的种类数 `kinds`
> 必须能**在元素移除时正确回退**。这要求「某元素在窗口内出现次数」可精确计数，
> 因此值域太大时必须先离散化（否则 `cnt[]` 开不下），
> 或用哈希表替代数组——**这会让常数因子显著上升**。

## 本章易错点

> **【头号易错】** **不验单调直接套模板**。
> 遇到「连续子数组和」但元素含负数时，「右端点前进 ⇒ 和增大」不成立，
> 左指针不能只顾右移——**算法会静默给出错误答案，不报错、不崩溃。**
> **纪律：动手前先问一句「元素全正吗 / 有序吗 / 计数可逆吗」。**

> **【易错】** **`l` 越过 `r` 的边界漏判**。`while` 条件里必须带 `l <= r`，
> 否则空窗口参与比较会得到错误结果。

> **【易错】** **窗口计数数组未与指针同步增减**。只加不减会让 `kinds` 虚高，
> 只减不加会让 `kinds` 虚低。**配对习惯：`cnt` 的加减必须紧贴指针的移动语句。**

> **【易错】** **`ans` 初值未设「不可能值」**。最短型应设 `n + 1`，最长型应设 `0`；
> 设成 `0` 会让最短型永远返回 0。

> **【易错】** **两种方向的 `while` 条件写反**。见「核心概念与模板」的方向对照表。

## 典型例题

### 例 1　最短子数组和（和型窗口）　难度：模板题

**题干摘要**：正整数序列，求和 ≥ S 的最短连续子序列长度。n ≤ 10⁵。
**题源**：同类真源见配套练习 T1（连续自然数和，双指针固定和窗口）
**涉及知识点**：知识点 1、2、4

**解题思路**：

1. **信号**：「最短连续子序列」+ 「和 ≥ S」→ 尺取法。
2. **先验前提**：**题目明确「正整数序列」**，因此 `sum` 随长度单调不减，前提成立。
3. **方法**：`r` 每轮进一格；只要「去掉最左元素仍满足和 ≥ S」就把 `l` 右移。

**完整代码**：见「核心概念与模板」的 `minLen`。

**复杂度**：时间 O(n)（`l` 与 `r` 各前进至多 n 步，总步数 2n），空间 O(n)。

> **【易错】** `while` 里的减法与指针移动**顺序不能反**：
> 先 `sum -= a[l]` 再 `l++`。若先 `l++`，减掉的就成了下一个元素。

---

### 例 2　K 种数字的最长区间（计数型窗口）　难度：变式题

**题干摘要**：序列含至多 10⁵ 种值，求恰好含 K 种数字的最长区间。
**题源**：同类真源见配套练习 T2、T3
**涉及知识点**：知识点 3、4

**解题思路**：

1. **信号**：「最长区间」+ 「恰好 K 种」→ 计数型窗口。
2. **先验前提**：**种类数随长度单调不减**（加元素只会增加或保持种类数），前提成立。
3. **方法**：`r` 每轮进一格并更新 `cnt[]` 与 `kinds`；`kinds > K` 时缩 `l` 直到合法。

**解答过程**：以 `a = [1, 2, 1, 3, 2]`、`K = 2` 手推：

| 轮次 | r | a[r] | kinds | l | 窗口与长度 |
|------|---|------|-------|---|-----------|
| 1 | 1 | 1 | 1 | 1 | [1,1]，长 1 |
| 2 | 2 | 2 | 2 | 1 | [1,2]，长 **2** |
| 3 | 3 | 1 | 2 | 1 | [1,3]，长 **3** |
| 4 | 4 | 3 | 3（缩到 2） | 2 | [2,4]，长 3 |
| 5 | 5 | 2 | 2 | 2 | [2,5]，长 **4** |

最终答案 **4**（区间 `[2, 5]` = `2, 1, 3, 2`，恰含 2 种值）。

**完整代码**：见「核心概念与模板」的 `longestK`。

**复杂度**：时间 O(n)，空间 O(值域)（值域过大时需离散化）。

> **【易错】** `if (cnt[a[r]]++ == 0)` 是**先加后判**：
> 自增发生在比较之前，因此比较的是「加之前的值」。写反会漏计种类数。

## 本章总结

### 核心内容（一页纸）

1. **尺取法的全部效力来自一个观察**：`l` 不必回退。因此总步数是 2n 而非 n²。
2. **前提是单调性**，不是「通常成立」。含负数的和型、无序的最值型都会破坏它。
3. **动手前先问三句**：元素全正吗（和型）／有序吗／计数可逆吗。
4. **两种模板**：和型维护 `sum`；计数型维护 `cnt[]` 与 `kinds`。
5. **两种方向的 `while` 条件相反**：
   求最短 → `while (仍满足) 收缩`，在循环**内**更新；
   求最长 → `while (不满足) 收缩`，在循环**后**更新。
   记忆：**缩到不行为止是求最短。**
6. **`cnt[]` 必须与指针配对增减**，只加不减或只减不加都不报错，只出错。
7. **`ans` 初值**：最短型取 `n + 1`，最长型取 `0`。
8. **`while` 条件里带 `l <= r`**，防空窗口。
9. **`sum -= a[l]` 必须在 `l++` 之前**，顺序反了会减错元素。
10. **计数可逆，最值不可逆** —— 求窗口最值请改用单调队列。

### 知识点串联图

```text
前置：前缀和 · 复杂度估算 · 1 起始约定
   │
   └─→ 1 单调性判据（第一步，最容易被跳过）
         │
         ├─→ 2 和型窗口 ──┐
         │                ├─→ 4 条件方向（最长 / 最短）
         └─→ 3 计数型窗口 ┘        │
                                   └─→ 5 排序后窗口变体
              （求最值 → 转单调队列，属阶段 3）
```
