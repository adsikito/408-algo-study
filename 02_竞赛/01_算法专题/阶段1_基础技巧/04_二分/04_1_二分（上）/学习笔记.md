## 🗺️ 本章地图

本章解决一个问题：从值域里找"那个答案"，一个一个试太慢，能不能每次砍掉一半？上半场（4.1）先学**二分查找**——有序数组找数的 bs 三分支模板；再升级到**二分答案**——把"求最值"变成"猜答案 + check 验证"（P1873 砍树：最大的 H；LCR 073 吃香蕉：最小的速度 k）。下半场（4.2）把套路练到"最大化最小值"（P2678 跳石头），并总结二分三大用途：求最值、最小化最大值/最大化最小值、把枚举优化成 O(logn)；同时盯死防死循环的细节配合。学完请自测：check 为什么单调？求最大和求最小时，收缩方向各往哪边？

## 📌 本章重点

⭐ **二分查找模板**：前提有序；`while(l<=r) + mid=(l+r)/2` 三分支——相等返回、偏大 `r=mid-1`、偏小 `l=mid+1`，找不到返回 -1
⭐ **二分答案 = 猜答案**：假定一个解判断是否可行；信号词"最值 / 最小化最大值 / 最大化最小值"
⭐ **ans 记录法**：check 通过就 `ans=mid` 并向更优方向收缩——求最大可行（P1873、P2678）`l=mid+1`，求最小可行（LCR 073）`r=mid-1`
⭐ **check 函数每题一写**：砍树算木材和 ≥m；吃香蕉每堆向上取整累加时间 ≤h；跳石头贪心数需移走的石头 ≤m
⭐ **答案范围的上下界**：P1873 取 0~最大树高；LCR 073 取 1~最大堆（每小时至少吃 1 根）

## 🔥 本章难点

🔥 **可行域的 01 单调性是正确性根基**：H 越大木材越少，于是"可行、可行、…、可行、不可行"一刀切开——二分才不会错过答案；单调性要自己论证，不是天然成立
🔥 **两个方向别写反**：最大化可行解，check 通过 → `l=mid+1`（往大试探）；最小化可行解，check 通过 → `r=mid-1`（往小试探）；写反了 ans 停在错误半区
🔥 **死循环与边界配合**：mid=(l+r)/2 下取整必须配 `l=mid+1、r=mid-1` 才能保证区间严格缩小（课件：注意细节的配合避免死循环——手推代码）

## ⚠️ 本章易错点

⚠️ **P1873 的 H 下界是 0**：l 从 0 起（"不砍"也是候选），r 取最大树高；无解靠 ans 初值 -1 兜底
⚠️ **LCR 073 速度下界是 1 不是 0**：每小时至少吃 1 根，k=0 会除零；上界取最大堆（再快也是一口一堆）
⚠️ **check 的累加和要 long long**：P1873 木材总量可达 10^15（`ll sum`）、LCR 073 时间 t 可达 10^13（`long long t`），int 必爆
⚠️ **P2678 忘了终点**：`a[n+1]=s; n++` 把终点当最后一块石头——少了它最后一跳不计，答案偏大
⚠️ **向上取整别手滑**：`piles[i]/k + (piles[i]%k ? 1 : 0)` 才是 ceil(piles[i]/k)；直接整除会少算"吃不完整一堆"的那一小时

## 📖 知识点讲解

### 1. 二分查找：有序数组里的"猜数游戏"

**是什么**：白话——猜 1~100 的数，先猜 50，一句"大了"就砍掉一半。严格说：在**有序**数组中，每次考察当前区间的中间元素：正好是目标就结束；中间元素小于目标，则左侧只会更小、只需到右侧找；大于目标同理去左侧。课件强调两条：**前提是有序**；中间元素不是目标时，注意接下来应该往哪边找。

**为什么**：每轮比较淘汰一半，n 个元素至多 log₂n+1 轮——10^9 个元素也只要约 30 次；线性扫描要 10^9 次，这就是"有序"换来的暴力折扣。

**怎么用**——课件 bs 模板（闭区间 [l,r] + 三分支）：
```cpp
int bs(int a[], int n, int tg) {
    int l = 0, r = n-1;
    while(l <= r) {
        int mid = (l+r)/2;
        if(a[mid] == tg) return mid;      // 中间就是它：返回下标
        else if(a[mid] > tg) r = mid-1;   // 中间偏大：目标只在左半
        else l = mid+1;                   // 中间偏小：目标只在右半
    }
    return -1;                            // 区间空了：不存在
}
```
**跟算**（猜数场景）：a=[1,3,5,7,9]，分别找 7 和找 6：

| 轮 | l | r | mid | a[mid] | 判定 | 动作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 4 | 2 | 5 | 5<7 偏小 / 5<6 偏小 | 两者都 l=3 |
| 2 | 3 | 4 | 3 | 7 | 7==7 | **返回 3**（找 7） |
| 2' | 3 | 4 | 3 | 7 | 7>6 偏大 | r=2（找 6） |
| 3' | 3 | 2 | — | — | l>r 区间空 | **返回 -1**（找 6） |

找 7 两轮命中（线性扫描要 4 步）；找 6 三轮判"不存在"——找到与找不到都以 l>r 收场，模板天然安全。

> ⚠️ 注意事项：`while(l<=r)` 的等号与 `r=mid-1、l=mid+1` 配套，漏等号会漏查 mid 指向的元素；mid 用下取整 `(l+r)/2`。
> 🎯 规律：见到"有序 + 查找/边界"先想二分；只查一次的无序数组，排序 O(nlogn) 可能不如直接扫，先算账再动手。
> 💡 一句话总结：有序才能砍一半。

### 2. 二分答案：把"求最值"变成"猜答案 + 判断题"

**是什么**：白话——不直接算答案，而是"猜一个答案，验证它行不行"。课件定义：二分查找的应用（二分答案---猜答案）——**假定一个解判断是否可行**，典型问法是最值、最小化最大值、最大化最小值。严格说：若答案的可行域 01 单调（前段全不可行、后段全可行，或反之），就能对"答案本身"二分：猜 mid → check(mid) 判可行 → 按方向收缩，ans 记下的就是分界点上的最优解。

**为什么**：最值问题的答案往往推不出来，但"给定候选解，判断可不可行"通常很好写（贪心/累加扫一遍 O(n)）；值域高达 10^9 时逐个试必超时，二分只要约 30 次 check。**check 的单调性**是全套逻辑的地基：比如砍树，H 越大木材越少——"可行…"一段与"不可行…"一段被一刀切开，二分夹出来的就是最大可行 H。

**怎么用**——ans 记录法骨架（三道例题代码的共同形状）：
```cpp
int l = 下界, r = 上界, mid = 0, ans = 兜底初值;
while (l <= r)
{
    mid = (l + r) / 2;
    if (check(mid))
    {
        ans = mid;          // mid 可行：先记账
        l = mid + 1;        // 求"最大可行"：再往大试
        // 求"最小可行"改写：r = mid - 1;
    }
    else
        r = mid - 1;        // 求"最小可行"改写：l = mid + 1;
}
```
判别流程：题目问"最大的 xx / 最小的 xx / 最小化最大值 / 最大化最小值" → 猜它、二分它；check 是每题的灵魂，自己动手写。

> ⚠️ 注意事项：ans 必须在 check 通过的当下记账——循环结束时 l、r 已交错，最后那个 mid 未必是答案。
> 🎯 规律：答案单调（check 01 分界）+ check 好写 → 二分答案；三件套 = 猜 mid、check 验证、ans 记录收缩。
> 💡 一句话总结：把最值变判断题。

### 3. 上半场例题：P1873 砍树 & LCR 073 吃香蕉（一最大、一最小）

**是什么**：P1873——n 棵树、要 m 米木材，定砍伐高度 H：每棵高于 H 的部分被砍下，求**最大**的 H（课件：如果再升高 1 米，就得不到 m 米木材）。LCR 073——n 堆香蕉、h 小时，速度 k 表示每小时吃 k 根（同一小时只吃一堆，吃不完可留到下一小时，但每小时至少吃 1 根），求**最小**的 k 使 h 小时内吃完。一"最大"一"最小"，正好是一对方向。

**为什么**：P1873 里 H 越大木材越少 → check(H)="木材和 ≥m" 前真后假，二分最大真值；LCR 073 里 k 越大用时越少 → check(k)="总时间 ≤h" 前假后真，二分最小真值。方向相反，收缩也相反。

**怎么用**——P1873 的 check（`P1873.cpp`）：
```cpp
bool check(int h) {
    ll sum = 0;                        // 木材总量：long long！
    for(int i = 1; i <= n; i++)
        if(a[i] - h > 0) sum += a[i] - h;
    return sum >= m;                   // 够 m 米才可行
}
// 主程序：l=0，r=最大树高；check 通过 → ans=mid, l=mid+1（往大试）
```
**跟算**（分木头 mid 迭代表）——样例：n=5, m=20, a={4,42,40,26,46}：

| 轮 | l | r | mid | check(mid)：木材和 | 可行？ | 动作 | ans |
|---|---|---|---|---|---|---|---|
| 1 | 0 | 46 | 23 | 19+17+3+23=62 | ✓ | ans=23, l=24 | 23 |
| 2 | 24 | 46 | 35 | 7+5+11=23 | ✓ | ans=35, l=36 | 35 |
| 3 | 36 | 46 | 41 | 1+5=6 | ✗ | r=40 | 35 |
| 4 | 36 | 40 | 38 | 4+2+8=14 | ✗ | r=37 | 35 |
| 5 | 36 | 37 | 36 | 6+4+10=20 | ✓ | ans=36, l=37 | **36** |
| 6 | 37 | 37 | 37 | 5+3+9=17 | ✗ | r=36 | 36 |

l=37>r=36 退出，ans=36=官方样例答案 ✓。可行/不可行的分界被 6 次 check 夹了出来。

**怎么用**——LCR 073 的 check 与方向（`LC LCR 073.cpp`）：
```cpp
bool check(vector<int>& piles, int k, int h) {
    long long t = 0;
    for(int i = 0; i < n; i++) {
        t += piles[i] / k;
        if(piles[i] % k) t++;          // 向上取整：吃不完整堆也要占一小时
    }
    return t <= h;                     // h 小时内吃得完才可行
}
// 主程序：l=1（每小时至少 1 根），r=最大堆；
// check 通过 → ans=mid, r=mid-1   ← 方向与 P1873 相反！
```
**跟算**：piles=[3,6,7,11]，h=8，从 l=1、r=11 起：
- mid=6：用时 1+1+2+2=6 ≤8 可行 → ans=6, r=5
- mid=3：用时 1+2+3+4=10 >8 不可行 → l=4
- mid=4：用时 1+2+2+3=8 ≤8 可行 → ans=4, r=3
- l=4>r=3 结束，ans=4 ✓（力扣样例答案）

> ⚠️ 注意事项：P1873 的 l 从 0 开始——H=0 即"全砍"，也是候选；树高 10^9 时 l+r 逼近 int 上限，保险写法 `mid=l+(r-l)/2`。P1873 的 sum、LCR 073 的 t 都必须 long long。
> 🎯 规律：最大值型"check 真 → l=mid+1"，最小值型"check 真 → r=mid-1"——先判类型，再写收缩方向。
> 💡 一句话总结：猜 mid，check 说话。

### 4. 下半场例题：P2678 跳石头（最大化最小值）

**是什么**：起点到终点长 L，中间 N 块石头，至多移走 M 块，使"相邻两块（含起点、终点）的最小距离"**尽量大**——标准**最大化最小值**。课件思路：二分跳跃距离，把这个距离"认为"是最短跳跃距离，以它为标准移石头，用 judge（check）判断这个解是不是可行解。

**为什么**：mi（假想的最短间距）越大，需要移走的石头越多——"需移数 ≤m"关于 mi 前真后假，01 单调，可二分。check 是贪心：从起点出发，下一块石头离当前位置 <mi 就移走（sum++），否则跳上去（now=nex）；扫完全程（终点也当一块石头），最后比对 sum 与 m。贪心直观：遇到太近的石头移"当前这一块"，保留刚站住的 now，后续比较从当前位置接着算。

**怎么用**——关键代码（`P2678.cpp`）：
```cpp
a[n+1] = s; n++;                     // 终点也当一块石头放进数组（a[0]=0 是起点）
bool check(int mi) {                 // mi：假想的最短跳跃距离
    int sum = 0, now = 0, nex = 0;   // now：现在站的石头；nex：下一块
    while(nex < n) {
        nex++;
        if(a[nex] - a[now] < mi) sum++;   // 太近：移走
        else now = nex;                   // 够远：跳上去
    }
    return sum <= m;
}
// 主程序：l=1，r=s；check 通过 → ans=mid, l=mid+1（最大化）
```
**跟算**（课件特殊数据）：输入 8 3 1，石头在 2、4、7；加终点后 a=[0,2,4,7,8]，n=4：
- check(1)：2-0、4-2、7-4、8-7 全部 ≥1 → 移 0 块 ≤1 ✓
- check(2)：只有 7→8 差 1<2 → 移走石头 7（sum=1 ≤1）✓
- check(3)：2-0=2<3 移走（sum=1）；4-0=4≥3 跳；7-4=3≥3 跳；8-7=1<3 移走（sum=2 >1）✗
- → mi 最大可行 2；二分 l=1, r=8：mid=4 ✗（r=3）→ mid=2 ✓（ans=2, l=3）→ mid=3 ✗（r=2）→ 输出 2，与课件特殊数据答案一致 ✓

> ⚠️ 注意事项：忘写 `a[n+1]=s; n++` 是本题头号事故——最后一跳不算，最小间距虚高；起点 a[0]=0 靠全局数组默认 0，别覆盖。
> 🎯 规律："最大化最小值/最小化最大值" = 二分那个"最值" + check 里贪心验证——二分管猜，贪心管验。
> 💡 一句话总结：二分问距离，贪心验货。

## 🔍 相似概念辨析

**组1：二分查找 vs 二分答案**

| 对比维度 | 二分查找 | 二分答案 |
|---|---|---|
| 各自定义 | 有序数组中定位某个确定元素 | 对答案值域二分，check 验证可行性 |
| 核心区别 | 答案是数组里的下标，== 直接命中返回 | 答案不一定在数组里，靠 ans=mid 记录边界 |
| 各自特点 | 三分支，找不到返回 -1 | 两分支（可行/不可行），check 自己写 |
| 使用场景 | 排序后查找、找边界 | 求最值/最小化最大值/最大化最小值 |
| 典型示例 | bs(a, n, tg) 返回下标 | P1873 二分 H、P2678 二分距离 |
| 记忆口诀 | 查找找等于，答案试可行 |

**组2：最大化可行 vs 最小化可行（收缩方向）**

| 对比维度 | 最大化可行（P1873、P2678） | 最小化可行（LCR 073） |
|---|---|---|
| 各自定义 | 求最大可行解（最大 H / 最大最短间距） | 求最小可行解（最小速度 k） |
| 核心区别 | check 真 → ans=mid, l=mid+1 | check 真 → ans=mid, r=mid-1 |
| 各自特点 | 可行域"前不可行后可行"，夹最后真 | 可行域"前可行后不可行"，夹最先真 |
| 使用场景 | "越大越省事"的资源类最值 | "越小越省事"的代价类最值 |
| 典型示例 | H=37 不可行 → r=36；H=36 可行 → ans=36 | 速度 3 不够 → l=4；速度 4 够 → ans=4 |
| 记忆口诀 | 求大往右压，求小往左压 |

**组3：while(l<=r)+ans 记录 vs while(l<r) 夹逼（边界两种写法）**

| 对比维度 | while(l<=r) + ans 记录 | while(l<r) 夹逼 |
|---|---|---|
| 各自定义 | 闭区间 [l,r]，l<=r 循环，可行时 ans=mid | 循环到 l==r 收敛，结束时的 l 即答案 |
| 核心区别 | l=mid+1 / r=mid-1 使区间严格缩，天然无死循环 | 需按 mid 取整方向配 r=mid 或 l=mid+1，细节更险 |
| 各自特点 | ans 初值兼作无解兜底，逻辑直白 | 少一个变量，但手滑就死循环/漏解 |
| 使用场景 | 本章三份例题代码全部采用 | 求左/右边界、手写 lower_bound 时常见 |
| 典型示例 | P1873 `while(l<=r){...ans=mid;...}` | `while(l<r){if(check(mid)) r=mid; else l=mid+1;}` |
| 记忆口诀 | 闭区间配 ans 记录，最不易死循环 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**逐个试太慢（痛点）→ 有序/单调可砍一半（原理）→ 二分查找模板（4.1 起点）→ 换视角：答案也可 01 单调 → 二分答案三件套：猜 mid + check 验证 + ans 记录收缩（4.1 主体）→ 一对方向：最大化 l=mid+1（P1873）对最小化 r=mid-1（LCR 073）→ 最大化最小值 + check 内嵌贪心（4.2 P2678）→ 细节配合防死循环，靠手推保平安**。

跨知识点共性：
1. **check 是万能接口**：内部可以是累加取整（LCR 073）、贪心扫一遍（P2678）——后继课程"二分+贪心""二分+图论"复用同一骨架，变的只是 check。
2. **单调性贯穿线性算法家族**：第三章尺取靠"区间指标单调"，本章二分答案靠"可行域单调"——先证单调，再谈算法。
3. **课件总结三大用途**逐一对应：①求最值（P1873）②最大化最小值/最小化最大值（P2678、LCR 073）③把枚举优化成 O(logn)——值域 10^9 也只要约 30 次 check。

## 📋 速查表

| 模板 | 复杂度 | 适用条件 |
|---|---|---|
| bs 二分查找 | O(logn) | 有序数组找数/找边界 |
| 二分答案·最大化 | O(logV × check) | 最大可行值（P1873、P2678） |
| 二分答案·最小化 | O(logV × check) | 最小可行值（LCR 073） |
| check·贪心扫一遍 | O(n) | 数石头/累加取整（每题自写） |

```cpp
// 二分答案骨架（默写级）——最大化版
int l = 下界, r = 上界, ans = 兜底;
while (l <= r) {
    int mid = l + (r - l) / 2;                    // 防 (l+r) 溢出
    if (check(mid)) { ans = mid; l = mid + 1; }   // 可行 → 往大试
    else            { r = mid - 1; }              // 不可行 → 往小压
}
// 最小化版：两处对调 → { ans = mid; r = mid - 1; } else { l = mid + 1; }
```
