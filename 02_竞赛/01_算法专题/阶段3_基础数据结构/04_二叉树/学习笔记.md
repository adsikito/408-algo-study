## 🗺️ 本章地图

> **本章解决一个问题：树形的问题怎么写？——课件第一页就给定调："二叉树的题目多是基于递归的"。**
> 路线是"一个结构 → 两套递归模板"：先看懂二叉树的递归定义与递归三要素（知识点 1）；再用"双指针对称递归"判定镜像对称——LCR 145（知识点 2）；再用"左右子树返回值自底向上拼答案"求最近公共祖先——LC 236（知识点 3）。
> 学完请自测三件事：对称判定的三个等式写得出吗？LCA 递归函数 f(root,p,q) 的三种返回情况背得出吗？为什么 root 命中 p 或 q 就能直接返回 root？

## 📌 本章重点（3-5个）

⭐ **递归处理二叉树的三要素**：递归出口（root==NULL 返回什么）→ 当前层做什么 → 递归 left/right 并利用返回值
⭐ **对称（镜像）判定**：左右子树镜像对称 ⟺ 根值相等 + 左的左==右的右 + 左的右==右的左；用 p、q 两个指针对称地递归
⭐ **最近公共祖先（LCA）**：按 p、q 的分布分三种情况——分居 root 两侧则 root 是答案；同在一侧则递归进该子树；空树返回 NULL
⭐ **用返回值回传信息**：LCR145 回传 bool、LC236 回传 TreeNode*——"子问题答案拼当前答案"是树形递归的通用骨架

## 🔥 本章难点（2-3个）

🔥 **LCA 递归语义的理解**：f(root,p,q) 返回的可能是"p/q 本尊"，也可能是"已找到的答案"，还可能是 NULL——三种含义共用一个返回值，必须想清"root==p 时直接 return root"为什么两种情况（q 在/不在 root 子树里）都对
🔥 **把"对称"翻译成递归等式**：人眼看是镜像，代码里必须写成 p->val==q->val && check(p->left,q->right) && check(p->right,q->left) 的交叉比较，初学极易写成"左对左、右对右"

## ⚠️ 本章易错点（3-5个）

⚠️ **结构体定义漏分号**：本地补 `struct TreeNode {...};` 时末尾分号不能少（例题代码里是从课件摘的片段；力扣平台已内置 TreeNode，无需自己定义）
⚠️ **空树特判**：对称题的空树也算对称（课件明确"空树也满足条件"），入口先判 `root==NULL` 返回 1，再进 check(left,right)
⚠️ **check 判空顺序**：先判"都空 return 1"，再判"有一个空 return 0"——顺序颠倒会对空指针取 `p->val` 直接崩溃（例题代码正是这个顺序：`if(p==NULL&&q==NULL)return 1; if(!q||!p)return 0;`）
⚠️ **LCA 的 l、r 组合漏分支**：l、r 有一个为空必须**返回另一个**（说明答案已在另一边找到），全部返回 NULL 会把已找到的答案丢掉
⚠️ **命中目标后还想继续找另一个**：root==p 直接 return root 不是偷懒——q 若在 root 子树里则 root 就是答案，若不在则真正的 LCA 在更上层，两种情况返回 root 都正确

## 📖 知识点讲解

### 1. 二叉树的递归结构与递归三要素

**是什么**：白话——树是"一小撮 + 更小的树"套起来的：二叉树要么为空，要么由**根结点 + 左子树 + 右子树**组成，而左右子树又是一棵二叉树。定义本身是递归的，所以课件开篇就说"二叉树的题目多是基于递归的"。树上递归的三要素：①**递归出口**：root==NULL（空树）返回什么；②**当前层做什么**：怎么用左右子树的结果拼出当前子树的结果；③**递归调用**：f(root->left)、f(root->right) 并接住返回值。

**为什么**：树上的路径会分叉且需要"回头"，循环难以表达；而"以 root 为根的子树的答案"天然是"以 root->left 为根"与"以 root->right 为根"两个同型小问题——递归是树的母语。

**怎么用**——通用骨架：
```cpp
int solve(TreeNode* root)
{
    if(root==NULL) return 空树的答案;            // ①出口
    int L=solve(root->left);                     // ③相信递归
    int R=solve(root->right);
    return f(root,L,R);                          // ②当前层拼接
}
```
跟算：三结点树 `1(左2,右3)` 求最大深度（同套路的热身）：solve(1) 先问 solve(2)——2 是叶子，左右都是 NULL 各返回 0，取 max+1=1 返回；solve(3) 同理返回 1；回到 1：max(1,1)+1=2。三层信息自底向上浮上来。

> ⚠️ 注意事项：写递归先写出口再写递归调用；别在递归里用全局循环变量乱改状态，优先用返回值传信息。

> 🎯 规律：见树先想"空树怎么办、左右子树答案怎么拼"——这两问答出来，代码就写完了一半。

> 💡 一句话总结：树的答案，左右拼出来。

### 2. 对称二叉树：双指针对称递归（LC LCR 145）

**是什么**：白话——判断一棵树沿中轴照镜子是否和自身重合。课件思路四步：①一棵树镜像对称 ⟺ **左子树与右子树镜像对称**；②左右子树镜像对称的条件：两根值相同、**左的左子树 == 右的右子树**、**左的右子树 == 右的左子树**（== 指镜像对称）；③用两个指针 p、q 对称地递归遍历并比较，初始 p=root->left、q=root->right，递归出口：p、q 都空 return 1，有一个空 return 0，递归条件即第②步三条；④特殊情况：**空树也满足条件**。

**为什么**：镜像会把"左右"互换，所以比较必须**交叉**：p 的外侧（left）对 q 的外侧（right）、p 的内侧（right）对 q 的内侧（left）。单指针先序遍历只能访问自己，没法比较"两棵子树之间"的关系，所以要成对发指针。

**怎么用**——模板（`LC LCR 145.cpp`）：
```cpp
bool check(TreeNode* p,TreeNode* q)
{
    if(p==NULL&&q==NULL)return 1;   // 都空：对称
    if(!q||!p)return 0;             // 一空一非空：不对称
    return (p->val==q->val)
        && check(p->left,q->right)  // 外侧对外侧
        && check(p->right,q->left); // 内侧对内侧
}
bool checkSymmetricTree(TreeNode* root)
{
    if(root==NULL)return 1;         // 空树也算对称
    else return check(root->left,root->right);
}
```
跟算：对称树 `1(左2{左3,右4},右2{左4,右3})`：
```
check(2a,2b)：值 2==2 ✓
  ├─ check(3,3)：值相等，check(NULL,NULL)=1，check(NULL,NULL)=1 → 1
  └─ check(4,4)：同理 1
→ 全真，对称 ✓
```
反例 `1(左2{右3},右2{右3})`：check(2a,2b) 值相等，但 check(2a->right=3, 2b->left=NULL) 一空一非空 → 0 → 不对称 ✓（镜像后 3 应出现在右侧结点的左边）。

> ⚠️ 注意事项：判空顺序"先双空后单空"不能反；入口必须单独判 root==NULL，否则 check(NULL,NULL) 虽然碰巧对，但语义上空树是对称的要写明。

> 🎯 规律：凡是"两棵树之间的关系"（对称、相同、镜像翻转相等），都用双指针成对递归。

> 💡 一句话总结：镜像即内外交叉比。

### 3. 最近公共祖先：左右子树返回值拼答案（LC 236）

**是什么**：白话——树上两个结点 p、q，往根走第一次"会师"的结点就是最近公共祖先。课件思路：按 p、q 的**分布**判断——①p、q 分别在 root 左右子树中，则 root 是答案；②p、q 同时在 root 的某一棵子树 x 中，则问题转化为在 x 中找公共祖先（递归）。于是定义 f(root,p,q)：在以 root 为根的树中找 p、q——①root==NULL 返回 NULL；②root==p 或 root==q 直接返回 root（若另一个在其子树中，root 是答案；若不在，返回找到的这个结点）；③否则递归左右：l=f(left)、r=f(right)——l、r 全空返回空；有一个空返回另一个；都不空说明 p、q 一边一个，**root 是答案**。

**为什么**：p、q 的相对位置只有"分居两侧 / 同侧 / 其中一个是祖先"三种，而 f 的返回值恰好把这三种情况都编码了：分居两侧在"l、r 都非空"处收网；同侧问题原样缩小到子树；命中 p/q 先登记、等另一半的消息传上来再定夺。

**怎么用**——模板（`LC 236.cpp`）：
```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q)
{
    if(root==NULL)return NULL;          // ①空树
    if(root==p||root==q)return root;    // ②命中目标，登记
    TreeNode* l=lowestCommonAncestor(root->left ,p,q);   // ③分头去找
    TreeNode* r=lowestCommonAncestor(root->right,p,q);
    if(l==NULL)return r;    // 左边没消息，答案（或目标）在右边
    if(r==NULL)return l;    // 右边没消息，答案在左边
    return root;            // 两边都有：p、q 一边一个，root 是答案
}
```
跟算：经典 7 结点树
```
          3
        /   \
       5     1
      / \   / \
     6   2 0   8
        / \
       7   4
```
求 LCA(5,4)：
```
f(3)：不是 p/q → l=f(5)，r=f(1)
  f(5)：root==p → 返回 5           （先登记）
  f(1)：l=f(0)=NULL，r=f(8)=NULL → 返回 NULL
回到 f(3)：l=5，r=NULL → 返回 5 ✓（4 在 5 的子树里，祖先就是 5）
再求 LCA(5,1)：f(5) 返回 5，f(1) 返回 1 → 都非空 → 返回 3 ✓
```

> ⚠️ 注意事项：`root==p||root==q` 的判断必须放在递归**之前**（先登记再往下找）；l、r 的三种组合一个都不能漏；本题是普通二叉树（没有大小性质），别和二叉搜索树版本的 LCA（235 题，可按值大小迭代）混为一谈。

> 🎯 规律：后序位置（先拿左右信息再下结论）适合"答案取决于子树分布"的题——LCA、树高、直径全是这一家。

> 💡 一句话总结：两边都找到，当前就是根。

## 🔍 相似概念辨析

**组1：双指针对称递归 vs 单指针递归遍历**

| 对比维度 | 双指针对称递归 | 单指针递归遍历 |
|---|---|---|
| 各自定义 | p、q 两个指针同步走，比较发生在两棵子树之间 | 一个指针先左后右访问每个结点 |
| 核心区别 | 处理"两棵树/两个结点的关系" | 处理"单个结点的统计" |
| 各自特点 | 递归参数成对出现，判空要分"双空/单空" | 参数只有一个，只需判 root==NULL |
| 使用场景 | 对称、相同、镜像类判定（LCR145、LC100） | 求深度、计数、求和（LC104） |
| 典型示例 | check(p->left, q->right) | solve(root->left) |
| 记忆口诀 | 判关系发双指针，做统计用单指针 |

**组2：自底向上（LC236 后序式） vs 自顶向下**

| 对比维度 | 自底向上 | 自顶向下 |
|---|---|---|
| 各自定义 | 先递归左右子树拿到信息，再在当前结点下结论 | 从根出发带着信息往下走，边走边判断 |
| 核心区别 | 答案在"回程"上产生 | 答案在"去程"上产生 |
| 各自特点 | 用返回值组合出答案（l、r 三分支） | 常带深度/路径等参数往下传 |
| 使用场景 | LCA、树高、子树统计 | 路径存在性、带深度的判定、路径序列 |
| 典型示例 | l、r 都非空 → root 是答案 | 根到叶逐层累计路径和 |
| 记忆口诀 | LCA 自底向上，左右一拼出答案 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**二叉树的递归定义（结构）→ 递归三要素（方法）→ 信息用返回值回传（骨架）→ 两棵树的关系就发一对指针（LCR145 的 check(p,q)）→ 答案取决于子树分布就在后序位置拼（LC236 的 l、r 三分支）**。两道例题是同一句话：把"整棵树的问题"改写成"左子树的答案 + 右子树的答案 + 当前结点"。

跨知识点共性：
1. **承接第九章递归与分治**：树的递归就是分治——"分"成左右子树、"治"在当前结点拼接，出口即最小子问题（空树）。
2. **与第十一章链表/树结构呼应**：TreeNode 的 left/right 指针就是链表 next 思想的二叉化，指针域的读写规则一致。
3. **向后铺垫**：第十五章 DFS 在网格上递归搜索，递归出口+四方向扩展的写法与本章同源；第三十章树形 DP 把"左右子树答案拼当前"推广成带最值的版本（树的最大路径和=124 题即本框架）。

## 📋 速查表

| 题型 | 递归出口 | 当前层逻辑 | 返回值 |
|---|---|---|---|
| 对称判定 check(p,q) | 双空→1；单空→0 | val 相等 && check(l,r 交叉两条) | bool |
| LCA f(root,p,q) | 空树→NULL；root==p/q→root | l 空返 r；r 空返 l；都有返 root | TreeNode* |

```cpp
// 树递归速记（默写级）
if(root==NULL) return 空树答案;          // 先写出口
TreeNode* l=f(root->left);              // 相信递归
TreeNode* r=f(root->right);
return 按情况拼接(l,r,root);             // 后序位置下结论
```

★ **力扣 104. 二叉树的最大深度**：求根到最远叶子经过的结点数。

★★★ **力扣 235. 二叉搜索树的最近公共祖先**：p、q 在一棵二叉搜索树中，求 LCA。

★★★★ **力扣 124. 二叉树中的最大路径和**：路径可从任意结点到任意结点（每个结点至多经过一次），求路径和最大值。
