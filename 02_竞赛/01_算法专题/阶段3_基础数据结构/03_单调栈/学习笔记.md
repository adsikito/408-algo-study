## 第十二章：单调栈

> 课件来源：`12.单调栈.pptx`
>
> 例题代码：`例题代码\damo.cpp`（向左找第一个比自身大的数）、`P5788.cpp`（P5788 【模板】单调栈）、`LC42.cpp`（力扣 42 接雨水）

## 🗺️ 本章地图

> **本章解决一个问题：向两边瞪眼找"第一个更大/更小"要 O(n²)，能不能一趟 O(n) 扫完？**
> 路线是"一个定义 → 四类问题 → 两道例题"：先认识"底到顶严格单调"的栈和"破坏单调就连续弹栈"的维护套路（知识点 1）；再对齐课件给的四类边界问题与"方向 × 栈型"两张对照表、两种取答案视角（2）；P5788 用"下标入栈 + 从右往左"把模板打到 n≤3×10⁶（3）；LC42 接雨水把"弹栈瞬间"变成"结算凹槽"（4）。
> 学完请自测三件事：四种"第一个更大/更小"各配什么扫描方向和栈型？什么时候必须存下标？接雨水凹槽三要素（左柱、槽底、右柱）的宽高公式能否默写？

## 📌 本章重点（3-5个）

⭐ **单调栈的定义与维护操作**：底到顶严格递增/递减；新元素破坏单调性时连续弹栈，每个元素至多进出各一次，整趟 O(n)
⭐ **四类边界问题对照**：向左/向右 × 第一个更大/更小 = 4 种，对应"扫描方向 + 栈型 + 取答案时机（入栈前取 / 出栈时填）"
⭐ **下标入栈**：答案要"位置/距离/宽度"时栈里必须存下标（P5788 存下标、LC42 靠下标差算宽度）
⭐ **P5788 模板**：从右往左扫 + 递减栈，弹出条件含等号，栈空记 0
⭐ **LC42 按行结算凹槽**：弹栈时 高 = min(左柱,右柱) − 槽底、宽 = i − 新栈顶 − 1，且结算前再判栈空

## 🔥 本章难点（2-3个）

🔥 **弹栈时机的两套视角**：是"入栈前把栈顶当自己的答案"（当前数找答案），还是"出栈时把当前数填给被弹的元素"（当前数是栈顶的答案）？两套视角扫描方向相反，混用必错——必须像课件幻灯片 2 那样列表对齐
🔥 **LC42 凹槽结算**：一次弹栈只结算"一层"水；弹出槽底后左边柱可能不存在（栈空则这层接不住）；宽、高的下标几何关系极易画错，必须手推 [2,1,2]

## ⚠️ 本章易错点（3-5个）

⚠️ **弹出条件忘写等号**：P5788 求"第一个**大于**"，必须 `a[s.top()]<=a[i]` 才弹；去掉等号后相等的元素会互相挡住答案
⚠️ **方向与栈型配错**："向左找第一个更大"配 左→右 + 递减栈；换成"向右"就要改从右往左扫，死记不如理解"栈顶 = 被挡住的那个候选答案"
⚠️ **取栈顶前忘判空**：必须 `!s.empty()`；无答案时 P5788 输出 0、damo 输出 -1，按题目约定来
⚠️ **LC42 弹完一层不检查栈空**：弹出槽底后若栈已空，说明左边没有柱子，这层水直接流走，停止结算
⚠️ **数组开小**：P5788 的 n≤3×10⁶，a 与 ans 都要开 3×10⁶+5；栈里存的是下标，stack<int> 别当成存值用

## 📖 知识点讲解

### 1. 单调栈：从栈底到栈顶严格单调的栈

**是什么**：白话——普通栈"来者不拒"，单调栈"不合格全赶走"：从栈底到栈顶，元素的值严格递增或严格递减。课件定义：单调栈多用于求解元素的**左右大小边界问题**——向左/向右找第一个比自身大/小的数，共 4 种。操作（以底到顶递增为例，课件原文）：新元素比栈顶大就直接入栈；新元素较小就**一直弹出**栈顶，直到栈顶比新元素小，再让它入栈。递减栈完全对称。

**为什么**：对每个元素向两边逐个比较是 O(n²)，P5788 的 n 达 3×10⁶ 必超时。单调栈里每个元素至多入栈一次、出栈一次，操作总数 ≤ 2n，整趟扫描 O(n)——被弹掉的元素**永远不需要再看第二眼**。

**怎么用**——以"向左找第一个比自身大的数"为例，用底到顶**递减**栈（`damo.cpp`）：
```cpp
stack<int> s;              // 本例存值
for(int i=1;i<=n;i++)
{
    while(!s.empty()&&s.top()<=a[i])  // 栈顶不比我大，挡不住我，弹走
        s.pop();
    if(s.empty()) ans[i]=-1;          // 左边没有更大的
    else          ans[i]=s.top();     // 此时的栈顶就是答案
    s.push(a[i]);                     // 自己入栈，去挡后面的人
}
```
跟算：a=[3,1,4,5,2]，递减栈存值，逐元素走一遍入栈出栈表：

| i | a[i] | 连续弹出 | 栈（底→顶） | ans[i] |
|---|---|---|---|---|
| 1 | 3 | 栈空不弹 | 3 | -1 |
| 2 | 1 | 无（3>1） | 3 1 | 3 |
| 3 | 4 | 弹 1、弹 3 | 4 | -1 |
| 4 | 5 | 弹 4 | 5 | -1 |
| 5 | 2 | 无（5>2） | 5 2 | 5 |

答案 `-1 3 -1 -1 5`：1 左边第一个更大是 3，2 左边第一个更大是 5，4 和 5 左边没有更大的。总代价 O(n)。

> ⚠️ 注意事项：弹栈条件 `s.top()<=a[i]` 的**等号不能丢**——"第一个比自身大"要求严格更大，相等的元素留着会挡住后面的人；栈空时答案不存在，按题目约定输出 -1 或 0。

> 🎯 规律：找"第一个比我大"→ 比我小/相等的全弹走；栈里剩下的恰好都是"还可能成为别人答案"的候选。

> 💡 一句话总结：破坏单调全弹光，栈顶即答案。

### 2. 四类边界问题：方向 × 栈型 × 取答案时机

**是什么**：课件把边界问题列成 4 类（向左更大 / 向左更小 / 向右更大 / 向右更小），并给出**两种视角**：视角一"对于当前遍历到的数，栈顶为答案"（入栈前取答案）；视角二"对于栈顶，当前遍历到的数为答案"（出栈时填答案）。视角不同，扫描方向正好相反。

**为什么**：视角一是"我找谁挡我"，当前数是提问者；视角二是"我在挡谁"，当前数是答案提供者。同一物理过程（入栈+弹栈）从两个方向读出信息，所以一个问题的两种写法扫描方向对调。

**怎么用**——课件对照表（务必背熟）：

视角一：当前数找答案（入栈前取栈顶）
| 问题 | 扫描方向 | 栈型 |
|---|---|---|
| 向左找第一个比自身大的数 | 左→右 | 底到顶递减 |
| 向左找第一个比自身小的数 | 左→右 | 底到顶递增 |
| 向右找第一个比自身大的数 | 右→左 | 底到顶递减 |
| 向右找第一个比自身小的数 | 右→左 | 底到顶递增 |

视角二：出栈时当前数是被弹栈顶的答案
| 问题 | 扫描方向 | 栈型 |
|---|---|---|
| 向左找第一个比自身大的数 | 右→左 | 底到顶递减 |
| 向左找第一个比自身小的数 | 右→左 | 底到顶递增 |
| 向右找第一个比自身大的数 | 左→右 | 底到顶递减 |
| 向右找第一个比自身小的数 | 左→右 | 底到顶递增 |

跟算：同一个 [3,1,4,5,2]、"向左找第一个更大"，改用视角二（右→左、递减栈、下标入栈，`damo.cpp` 注释里的版本）：

| i | a[i] | 出栈（填答案） | 栈内下标（底→顶） |
|---|---|---|---|
| 5 | 2 | 无 | 5 |
| 4 | 5 | 弹 5 号 → ans[5]=a[4]=5 | 4 |
| 3 | 4 | 无（a[4]=5>4） | 4 3 |
| 2 | 1 | 无 | 4 3 2 |
| 1 | 3 | 弹 2 号 → ans[2]=a[1]=3 | 4 3 1 |

扫完后栈里剩下的 4、3、1 号（3、4 号左边无更大值）最后统一置 -1。答案同样是 `-1 3 -1 -1 5`。

> ⚠️ 注意事项：视角二必须"先弹出填答案、再入栈"，且结束后要清栈补默认值；两套视角别在同一份代码里混用。

> 🎯 规律：向左的问题视角二从右往左扫、向右的问题视角二从左往右扫——"当前数"总是站在答案的对面。

> 💡 一句话总结：一表两视角，方向正好反。

### 3. P5788 【模板】单调栈：下标入栈

**是什么**：白话——一排人站好后，每人问"我右边第一个比我高的是几号"。课件思路：求每个数**后**第一个大于它的数，底到顶**递减栈**，从后往前扫，对每个元素：①弹出栈顶比它小（≤）的元素 ②此时栈顶就是答案（放进答案数组）③这个元素入栈。输出答案数组，没有则输出 0。

**为什么**：答案是"第几个数"（下标）而不是值，所以**下标入栈**；从右往左扫时，栈里存的都是"右边待认领的候选"，弹出条件 `a[s.top()]<=a[i]` 把不够高的全部结清。

**怎么用**——模板（`P5788.cpp`）：
```cpp
for(int i=n;i>=1;i--)                 // 从右往左
{
    while(!s.empty()&&a[s.top()]<=a[i])
        s.pop();                      // ①弹掉不比我高的
    if(s.empty()) ans[i]=0;           // ②没有答案记 0
    else          ans[i]=s.top();     //   栈顶下标就是答案
    s.push(i);                        // ③下标入栈
}
```
跟算：a={1,4,2,3,5}，从 i=5 扫到 1：

| i | a[i] | 弹出 | 栈内下标（底→顶） | ans[i] |
|---|---|---|---|---|
| 5 | 5 | 无（空） | 5 | 0 |
| 4 | 3 | 无（a[5]=5>3） | 5 4 | 5 |
| 3 | 2 | 无（a[4]=3>2） | 5 4 3 | 4 |
| 2 | 4 | 弹 3 号、弹 4 号（2≤4，3≤4） | 5 2 | 5 |
| 1 | 1 | 无（a[2]=4>1） | 5 2 1 | 2 |

输出 `2 5 4 5 0`：1 的右边第一个更大是 4 号、4 的右边是 5 号、2 的右边是 3 号、3 的右边是 5 号、5 没有更大的记 0。

> ⚠️ 注意事项：弹出条件里的 `<=` 对应"严格大于"的答案语义；n≤3×10⁶，数组和答案数组都要开够；cin 建议配 `ios::sync_with_stdio(false)` 或改快读防卡常。

> 🎯 规律：求"右边第一个"→ 从右往左扫 + 入栈前取答案；或从左往右扫 + 出栈时填答案，两写法等价。

> 💡 一句话总结：右边找更大，从右往左扫。

### 4. LC42 接雨水：弹栈瞬间结算凹槽

**是什么**：白话——一排高低不齐的柱子，凹下去的地方能盛水，求总水量。课件思路：**按行计算**——每个凹槽需要"右边最大元素"和"左边最大元素"；单调栈取**底到顶递减**，并且**下标入栈**（为了求宽度）。当将要入栈的元素大于栈顶时，说明出现了凹槽：凹槽右边是将入栈的元素，左边是新栈顶，槽底是刚弹出的旧栈顶。

**为什么**：递减栈里压着的都是"还没等到右边柱子"的左墙候选；一旦来了一根更高的，栈顶那段凹槽的右墙就齐了——在弹栈的这一瞬间，宽（下标差）和高（左右较矮者减槽底）都能算，立刻结算。

**怎么用**——关键代码（`LC42.cpp`）：
```cpp
while(!s.empty()&&height[i]>height[s.top()])   // 来了更高的，出现凹槽
{
    int m=s.top(); s.pop();                    // m：槽底
    if(!s.empty())                             // 左墙必须存在
    {
        h=min(height[i],height[s.top()])-height[m];  // 水高=左右较矮-槽底
        w=i-s.top()-1;                               // 水宽=右-左-1
        sum+=h*w;
    }
}
s.push(i);
```
跟算：height=[2,1,2]：
```
i=0: 栈空 → 下标 0 入栈，栈 [0]
i=1: h[1]=1 ≤ h[0]=2，不成凹槽 → 入栈，栈 [0,1]
i=2: h[2]=2 > h[1]=1 → 弹出槽底 m=1，新栈顶 0 是左墙：
     水高 = min(2,2)-1 = 1，水宽 = 2-0-1 = 1，sum=1
     继续判：h[2]=2 > h[0]=2 不成立（等高不成凹槽）→ 弹栈结束，下标 2 入栈
答案 sum = 1 ✓（两根 2 之间夹住 1 格水）
```

> ⚠️ 注意事项：弹出槽底后**必须再判 `!s.empty()`**——左墙不存在时这层水接不住，直接丢弃；触发条件是严格大于（`>`），等高柱子之间没有凹槽；每根柱子都可能参与多层结算（弹栈要写成 while）。

> 🎯 规律：横向逐层接水 = 每次弹栈结算一个凹槽；另一条路是竖向按列算 min(左max,右max)-h[i]，两思路可互相对拍。

> 💡 一句话总结：凹槽 = 两根高柱夹一块低地。

## 🔍 相似概念辨析

**组1：单调栈 vs 普通栈**

| 对比维度 | 单调栈 | 普通栈 |
|---|---|---|
| 各自定义 | 栈底到栈顶元素严格递增/递减的栈 | 只满足"后进先出"的线性结构 |
| 核心区别 | 入栈前维护单调性，必要时连续弹栈 | 来者不拒，直接压栈 |
| 各自特点 | 元素至多进出各一次，整趟扫描 O(n) | 单次操作 O(1)，但元素间无任何顺序保证 |
| 使用场景 | 左右大小边界问题（P5788、LC42） | 括号匹配、表达式求值、逆序输出 |
| 典型示例 | 3 要入栈时弹光 ≤3 的元素 | 依次 push 1,2,3 原样 pop 3,2,1 |
| 记忆口诀 | 普通栈管顺序，单调栈管大小 |

**组2：单调栈 vs 暴力双重循环**

| 对比维度 | 单调栈 | 暴力枚举边界 |
|---|---|---|
| 各自定义 | 一趟扫描，用单调性一次性结清候选 | 对每个元素向左/右逐个比较找边界 |
| 核心区别 | 被弹掉的元素不再参与比较 | 相邻元素被反复比较 |
| 各自特点 | 要背模板、选对方向与栈型 | 思路直白，几乎不用想 |
| 使用场景 | n 达 3×10⁶ 量级（P5788） | n≤10³ 的小数据或对拍验证 |
| 典型示例 | P5788 一遍 O(n) 通过 | 同题 O(n²) 必 TLE |
| 记忆口诀 | 找边界别瞪眼，栈里走一趟 |

**组3：存值入栈 vs 存下标入栈**

| 对比维度 | 存值入栈 | 存下标入栈 |
|---|---|---|
| 各自定义 | 栈元素是数组元素的数值 | 栈元素是数组位置 i |
| 核心区别 | 答案是"值"时直接取 top | 答案涉及"位置/距离/宽度"时必须存下标 |
| 各自特点 | damo.cpp 主版本存值，代码更短 | P5788、LC42 存下标 |
| 使用场景 | 只问"第一个更大/更小的数" | 问"第几个""相距多远""矩形/水宽" |
| 典型示例 | ans[i]=s.top() | ans[i]=s.top() 是下标，w=i-s.top()-1 |
| 记忆口诀 | 要宽度、要位置，就存下标 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**"找左右第一个更大/更小"（题型）→ 单调栈（数据结构）→ 一趟扫描、破坏单调就弹栈（操作）→ 弹栈瞬间是信息的结算点（P5788 在入栈前收答案、LC42 在出栈时算水）→ 存值还是存下标由答案的形态决定**。四个知识点其实是同一套 while-pop-push 的四次变装。

跨知识点共性：
1. **承接第十一章的栈**：单调栈只是给普通栈加了一条"入栈前维护单调性"的纪律，push/pop/top 的用法完全一致。
2. **与第三章尺取法同理**：都靠"每个元素至多进出一次"把 O(n²) 压成 O(n)——内层 while 的总弹栈次数被均摊掉，这是"均摊分析"的第一次实战。
3. **向后铺垫**：接雨水的"左右最大"还能用前缀最大值做（第二章思想）；柱状图最大矩形（84 题）是 LC42 的直接前置，也会在后面的动态规划（最大矩形面积）里再相遇。

★★ **力扣 496. 下一个更大元素 I**：nums1 是 nums2 的子集，对 nums1 每个元素找它在 nums2 中右侧第一个更大值。
