## 第十章：链表

> 课件来源：`10.链表.pptx`
>
> 例题代码：`例题代码\LC206.cpp`（反转链表）、`LCR140.cpp`（训练计划：链表中倒数第 k 个结点）

## 🗺️ 本章地图

本章学链式存储：数据不再排在连续数组里，而是每个结点拽着 next 指针找到下一个。路线：先会"造链"——struct ListNode 定义+尾插法建表（知识点 1）；再练两件刷题高频武器——双指针反转链表（LC206，2）和快慢指针找倒数第 k（LCR140，3）；最后拓展两种变体——静态链表（数组实现链表）与跳表（有序链表的"二分"）（4）。链表题的核心能力只有一个：**画图 + 不丢指针**。

## 📌 本章重点

⭐ **建表与遍历**：`struct ListNode { int val; struct ListNode *next; }`；尾插法：第一个结点 l=r=s，之后 `r->next=s; r=s;`
⭐ **反转链表双指针三件套**：t 先存 `pre->next` 防断链 → `pre->next=cur` 掉头 → cur、pre 双双右移（课件：循环中必须记录 pre->next，不能丢失结点）
⭐ **头插法原地逆置**（课件思路1）：摘下头结点后，从第一个结点起挨个摘下、头插建新链
⭐ **快慢指针定距 k**：fast 先走到第 k+1 个结点（与 slow 间隔 k），再同步后移，fast 到尾部空节点时 slow 即倒数第 k 个
⭐ **静态链表与跳表**：静态链表=结构体数组实现的链表；跳表=多层有序链表，实现有序链表的"二分"

## 🔥 本章难点

🔥 **反转中的断链时机**：若不先用 t 保存 pre->next 就执行 `pre->next=cur`，后半段链表从此无人引用、永久丢失——顺序：存 t、掉头、双移，一步都不能换
🔥 **快慢指针的差一问题**：LCR140 中"fast 指向第 k+1 个结点"= 从 head 走 k 步（t 从 1 计数到 cnt+1）；步数多一少一，答案就从倒数第 k 错成倒数第 k±1，必须手推验证

## ⚠️ 本章易错点

⚠️ **先改 next 后存 t**：`pre->next=cur` 之前没有 `t=pre->next`，原链后半段直接断链（课件红字提示）
⚠️ **循环条件写成 `pre->next!=NULL`**：最后一个结点永远没被反转；正确条件是 `pre!=NULL`，走到尾后新头是 cur
⚠️ **malloc 后忘置 `s->next=NULL`**：尾结点的 next 是野指针，遍历时越走越飞
⚠️ **快指针先走步数差一**：倒数第 k ⇔ fast 与 slow 间隔 k ⇔ fast 先走 k 步停在"第 k+1 个结点"；把"走 k 步"和"停在第 k 个"混为一谈必错
⚠️ **返回值错拿原 head**：反转完成后应 `head=cur` 返回新头；返回原 head 得到的是原链表尾部（只剩一个结点）

## 📖 知识点讲解

### 1. 链表与建表：struct ListNode + 尾插法

**是什么**：白话——一串结点，每个结点装着"数据+下一个结点的地址"，靠 next 指针手拉手。课件/例题的结点定义：`struct ListNode { int val; struct ListNode *next; };`。刷题时 LC 题目给的就是 `ListNode* head`，会建表、会遍历是一切链表题的前提。

**为什么**：数组插入/删除要整体搬移，链表只改指针；但链表失去了"下标随机访问"，只能从 head 顺着 next 走——这决定了链表题几乎全靠**指针操作+画图**。

**怎么用**——尾插法建表模板（照抄例题代码）：
```cpp
ListNode* l = NULL;             // 头指针
ListNode* r = NULL;             // 尾指针（尾插法的灵魂）
for (int i = 1; i <= n; i++)
{
    cin >> x;
    ListNode* s = (ListNode*)malloc(sizeof(ListNode));
    s->val = x;
    s->next = NULL;             // 新结点必置空！
    if (i == 1) { l = s; r = s; continue; }   // 第一个结点
    r->next = s;                // 尾巴接上新结点
    r = s;                      // r 跟着后移
}
// 遍历：从头走到尾
for (ListNode* p = l; p != NULL; p = p->next) cout << p->val;
```
跟算：依次插入 1、2、3：
```
i=1: l=r=s(1)          1 → NULL
i=2: r->next=s(2), r=2   1 → 2 → NULL
i=3: r->next=s(3), r=3   1 → 2 → 3 → NULL
```

> ⚠️ 注意事项：malloc 不会初始化，`s->next=NULL` 必须手动写；r 忘记后移会把所有结点串在同一位置后面，遍历死循环。

> 🎯 规律：链表题动手前先画指针图——箭头指向谁、谁被断开，代码就是把图上的箭头改来改去。

> 💡 一句话总结：结点拖 next，尾插建表。

### 2. 反转链表（LC206）：双指针迭代

**是什么**：白话——把 1→2→3 掰成 3→2→1，用 pre（右，待反转头）和 cur（左，已反转头）两个指针逐个"掉头"。课件思路 2：每次让 pre 的 next 指向 cur 实现一次局部反转，然后 pre、cur 同时右移，循环至 pre 到达链表尾部；**循环中必须记录 pre->next，不能丢失结点**。课件思路 1（头插法）：摘下头结点，从第一个结点起挨个摘下、头插法建新链——链表原地逆置。

**为什么**：单链表只能单向走，改成"回指"必须逐结点掉头；而一旦执行 `pre->next=cur`，pre 原来后面的结点就没人指着了——所以三行顺序（存、掉、移）是本题唯一的坑。

**怎么用**——模板（`LC206.cpp`）：
```cpp
ListNode* reverseList(ListNode* head)
{
    ListNode* cur = NULL;      // 左侧：已反转部分的头
    ListNode* pre = head;      // 右侧：待反转部分的头
    ListNode* t = NULL;
    while (pre != NULL)
    {
        t = pre->next;         // ① 先存，防断链
        pre->next = cur;       // ② 掉头：指回左边
        cur = pre;             // ③ cur 右移一格
        pre = t;               //    pre 右移一格
    }
    head = cur;                // 新头
    return head;
}
```
跟算 1→2→3：
```
初始:   cur=NULL   pre=1 → 2 → 3
第1轮:  t=2; 1->next=NULL; cur=1; pre=2      NULL ← 1    2 → 3
第2轮:  t=3; 2->next=1;    cur=2; pre=3      NULL ← 1 ← 2    3
第3轮:  t=NULL; 3->next=2; cur=3; pre=NULL   NULL ← 1 ← 2 ← 3
循环结束（pre==NULL），返回 cur=3 ✓ 新链 3→2→1
```
头插法（思路 1）等价视角：每轮从旧链摘下一个结点，插到新链头部——摘下顺序 1,2,3，插入后自然成 3,2,1。

> ⚠️ 注意事项：空链表（head=NULL）时循环一次不进，返回 cur=NULL，天然正确；单结点同理。

> 🎯 规律：链表就地重排类题（反转、每 k 个一组反转）都是同一套三件套：**暂存 next → 改指向 → 双指针推进**。

> 💡 一句话总结：存 next、掉头、双移。

### 3. 快慢指针：找倒数第 k 个（LCR140 训练计划）

**是什么**：白话——两个指针一前一后拉开固定距离 k，手拉手齐步走，前面的撞到链表尾（NULL）时，后面的正好停在倒数第 k 个。课件思路：fast 指向链表第 k+1 个结点、slow 指向第一个结点，二者间隔 k 个结点；同步后移，fast 到尾部空节点时 slow 即倒数第 k 个。

**为什么**：链表没有下标、不知道长度，"倒数第 k"没法直接算；用"距离差"代替"长度减 k"，一趟扫描 O(n) 解决，不用先数长度再走第二遍。

**怎么用**——模板（`LCR140.cpp`）：
```cpp
ListNode* trainingPlan(ListNode* head, int cnt)
{
    ListNode* f = head;
    ListNode* s = head;
    int t = 1;
    while (f != NULL && t < cnt + 1)   // f 先走 cnt 步
    {                                   // 停在"第 cnt+1 个结点"
        f = f->next;
        t++;
    }
    while (f != NULL)                  // 同步后移
    {
        f = f->next;
        s = s->next;
    }
    return s;                          // 倒数第 cnt 个
}
```
跟算：1→2→3→4→5，cnt=2：
```
阶段1：f 走 2 步，f 停在第 3 个结点（值3），与 s（值1）间隔 2
阶段2（同步走）：
  f:3→4→5→NULL，共 3 步
  s:1→2→3
f 为 NULL 时 s 指向 3 = 倒数第 2 个 ✓
```
原理：链表共 n 个，fast 从第 k+1 个走到第 n+1 个（NULL）要走 n-k 步，slow 同步走 n-k 步，从第 1 个走到第 n-k+1 个——正是倒数第 k 个。

> ⚠️ 注意事项：先走阶段必须判 `f!=NULL`（k 可能等于链表长，题目保证 k≤长度时 f 恰好走到 NULL 附近）；这个模式原样适用于"删倒数第 k 个"（LC19，slow 停在前驱）与"找中间结点"（快的一次走两步，LC876）。

> 🎯 规律：见"倒数第 k / 中点 / 判环"→ 快慢指针；"倒数第 k"用**定距同步**，"中点/判环"用**异速**（快指针步长 2）。

> 💡 一句话总结：快行 k 步，同步到尾。

### 4. 静态链表与跳表：链表的两种变体

**是什么**：课件定义——**静态链表**：用数组描述的链表。分配一整片连续内存，各结点集中安置，元素只允许在这块空间中随机存放；即用数组实现链式存储结构，**实际上就是一个结构体数组**（下标当地址，`nxt[i]` 当 next）。**跳表（Skip List）**：又叫跳跃表/跳跃列表，在有序链表基础上增加"跳跃"功能，实现有序链表的二分查找——多层链表，每层有序，最下层含所有数据，从下往上结点数逐渐减少。

**为什么**：静态链表省去 malloc/free，下标稳定、好调试，竞赛中常用（第 18 章链式前向星同思想）；普通有序链表查找仍要 O(n)（课件：数组有序可折半查找 O(logn)，链表有序却只能从头一个个找），跳表用"上层索引"把复杂度降到 O(logn)，代价是多层指针的空间。

**怎么用**——跳表特性（课件列出的六条）：
1. 一个跳表由若干层链表组成；2. 每一层链表都是有序的；3. 最下面一层包含所有数据；4. 上一层元素指向下层的元素必须相同；5. 头指针 head 指向最上面一层的第一个元素。（对应 LC1206 设计跳表）
```
head ──────────────→ 30 ─────────────→ NULL      第2层（索引，稀疏）
head → 10 ──────────→ 30 ─────→ 50 ───→ NULL     第1层
head → 10 → 20 → 30 → 40 → 50 → NULL            第0层（原始链表，全量）
查找 40：第2层 30<40 走到 30 → 下一层 → 40 ✓  跳过了 10、20
```

> ⚠️ 注意事项：静态链表的下标 0 常留作"空"标志（第 18 章链式前向星也这样做）；跳表是空间换时间，增删要同时维护多层索引。

> 🎯 规律：链式结构 = "数据 + 邻居地址"，把地址从指针换成数组下标就是静态链表；有序结构查找慢时，加"索引层"跳着找（跳表、B 树同思想）。

> 💡 一句话总结：数组也能链，跳层查得快。

## 🔍 相似概念辨析

**组1：头插法 vs 尾插法**

| 对比维度 | 头插法 | 尾插法 |
|---|---|---|
| 各自定义 | 新结点插到链表头部（新头 = 新结点） | 新结点接到链表尾部（r=r->next） |
| 核心区别 | 结点顺序与插入顺序相反 | 结点顺序与插入顺序一致 |
| 各自特点 | 只需维护头指针，天然逆置 | 需额外维护尾指针 r |
| 使用场景 | 原地逆置（LC206 思路1） | 按输入顺序建表（例题代码建表） |
| 典型示例 | 依次头插 1,2,3 得 3→2→1 | 依次尾插 1,2,3 得 1→2→3 |
| 记忆口诀 | 头插倒着排，尾插顺着来 |

**组2：动态链表 vs 静态链表**

| 对比维度 | 动态链表 | 静态链表 |
|---|---|---|
| 各自定义 | malloc/new 逐个分配结点，指针 next 相连 | 数组描述的链表：结构体数组+下标当地址（课件） |
| 核心区别 | 结点在堆上、地址运行期才知 | 结点在连续数组里、下标即地址 |
| 各自特点 | 长度灵活，但要防野指针/泄漏 | 无 malloc、好调试，需预开数组长度 |
| 使用场景 | LC 链表题标准形态（LC206） | 竞赛模拟删除/游标（P7912、链式前向星） |
| 典型示例 | ListNode* s = malloc(sizeof(ListNode)) | nxt[i] 存"第 i 个元素的下一个下标" |
| 记忆口诀 | 动态堆上连，静态数组牵 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**数组要连续大空间、插入删除要搬移（痛点）→ 结点+next 指针的链式结构（方案）→ 失去随机访问，只能从头顺着走（代价）→ 一切操作归结为"改箭头"，改前必须先保存（三件套）→ "倒数/中点"这类位置问题用指针速度与距离差解决（快慢指针）→ 查找慢的先天缺陷再用"变体"补：数组化（静态链表）与分层索引（跳表）**。全章一句话：链表的一切 = 画图 + 保存断口 + 不丢指针。

跨知识点共性：
1. **与第二章指针地基呼应**：next 指针的步长、malloc/free 配对、结构体定义，全是 C 语言基础章的直接应用——链表就是指针的练兵场。
2. **与第九章递归呼应**：链表天然递归定义（"一个结点 + 一条更短的链表"），LC206 也可写成递归反转；快慢指针、递归都是"用结构自身的规律省一遍遍历"。
3. **向后铺垫**：第十一章栈/队列的链式实现复用本章结点；第十八章链式前向星就是静态链表存图；二叉树的左右孩子指针是 next 的分叉版。

## 📋 速查表

| 模板 | 复杂度 | 适用条件 |
|---|---|---|
| 尾插法建表 | O(n) | 按输入顺序建链，需 l、r 两指针 |
| 双指针反转 | O(n) | LC206；三件套：存t、掉头、双移 |
| 快慢指针定距 k | O(n) 一趟 | 倒数第 k 个（LCR140）；间隔 k 同步走 |
| 头插法逆置 | O(n) | 思路1；摘下+头插，顺序天然倒置 |
| 跳表查找 | O(logn) | 有序链表高频查询（LC1206） |

```cpp
// 反转三件套（默写级）
ListNode* cur = NULL, * pre = head, * t;
while (pre != NULL) {
    t = pre->next;      // ① 存断口
    pre->next = cur;    // ② 掉头
    cur = pre; pre = t; // ③ 双移
}
return cur;             // 新头（不是 head！）
```

提示：快慢指针异速版——fast 一次走两步、slow 一步；fast 或 fast->next 为空时停，slow 就在中点，手推 4 个结点的链验证。

★★★ **力扣 19. 删除链表的倒数第 N 个结点**：一趟扫描实现删除。
