## 本章地图

本章解决一个问题：**「树给到手，怎么把信息算出来？」**

```text
树的读入（格式各异）→ 建成孩子表 / 编号数组
   ↓
递归遍历 = 「子问题天然独立」的分治
   ├─ 信息自叶向上聚合   → 子树和 / 子树最值（知识点 2）★ 树形 DP 雏形
   ├─ 路径自根向下延伸   → 根到叶路径和 / 最大路径
   └─ 两侧对照           → 镜像判定（知识点 4）
   ↓
遍历序的性质：前序定根、中序分侧 → O(n) 重构（知识点 3）
   ↓
工程兜底：深树爆栈 → 大栈 / 迭代（知识点 5）
```

**为什么这条路径是这样**：树是**天然无环、子树独立**的结构——
递归在树上没有「重叠子问题」，所以树的递归**永远可以直接写**（这是它与一般分治的区别）。
**把「子树信息聚合」写成肌肉记忆，树形 DP 就只剩状态设计。**

## 核心概念与模板

**是什么**：竞赛侧的二叉树 = 数组存树 + 递归分治 + 遍历序性质。

**为什么**：考研第 4 章讲「结构与手算」，竞赛侧讲三件事：
**数组存树**（父子下标公式，省指针）、**递归分治解树题**（子树信息合并）、
**树的遍历序**（前序定根、中序分侧的重构在竞赛同样常用）。

> **【规律】** **树是「子问题天然独立」的分治**——树上的递归没有重叠子问题，
> 可以直接写，不必记忆化（与斐波那契对比）。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;
const int N = 100005;

/* 数组存二叉树（完全二叉树编号口径：i 的孩 2i、2i+1） */
/* 一般树用「子结点表」：chl[i] 左孩 / 右孩存编号，0 表空 */
int chl[N][2], val[N];
long long dp[N];                          /* dp[i]：以 i 为根的子树信息 */

/* 递归遍历与信息聚合（树形 DP 的雏形） */
long long dfs(int u) {
    if (u == 0) return 0;
    long long l = dfs(chl[u][0]);
    long long r = dfs(chl[u][1]);
    /* 子树信息在此合并：示例 = 子树权值和 */
    return dp[u] = l + r + val[u];
}

/* 通用二叉树输入格式：每个结点给 值 左孩 右孩 */
void readTree(int n) {
    for (int i = 1; i <= n; i++)
        scanf("%d %d %d", &val[i], &chl[i][0], &chl[i][1]);
}
```

**由前序 + 中序重构（竞赛版，递归切分）**：

```cpp
/* pre 前序、in 中序（下标 1 起），输出后序 */
int pre[N], in[N], posIn[N];              /* posIn：值 -> 中序位置 */

void build(int pl, int pr, int il, int ir) {
    if (pl > pr) return;
    int root = pre[pl];                   /* 前序首为根 */
    int k = posIn[root];                  /* 中序切分点 */
    build(pl + 1, pl + k - il, il, k - 1);          /* 左子树 */
    build(pl + k - il + 1, pr, k + 1, ir);          /* 右子树 */
    printf("%d ", root);                  /* 后序输出：最后打根 */
}
```

> **【类比】** 树的 dfs 像**单位述职**：每个结点听完两个下属的汇报（左右子树），
> 汇总成自己的报表（子树信息）再上报——**报表内容就是你的 dfs 返回值语义**。
> 「聚合型」报表是总量，「延伸型」报表是路径。

## 本章难点

> **【难点】** **两种 dfs 返回语义不能混写**。
> 「子树聚合」返回以 u 为根的总量（后序，两儿子结果相加）；
> 「路径延伸」返回从 u 往下的最优链（max 取一侧再 + val），全局答案在**返回之外**用
> `best = max(best, ...)` 收集。**一个函数里混两种返回语义是树题最隐蔽的 bug。**

> **【难点】** **重构的区间切分。**
> 左子树前序区间长 `k − il`（中序中根左侧的长度），因此切点分别是
> `pl + k − il` 与 `pl + k − il + 1`——**这组边界要用「长度不变量」推，不要背**：
> 前序与中序被切分后，左右子树的长度必须逐段相等。

---

## 本章易错点

> **【头号易错】** **递归不判空结点**（0 号 / NULL 即 return）导致越界；
> 树高 10⁵ 的单斜树递归爆栈——竞赛中深树要开大栈或改迭代 / 手动栈。

> **【易错】** **重构时子树长度切分错 1**（`pl + k - il` 与 `pl + k - il + 1` 的边界）。

> **【易错】** **结点编号 0 起与 1 起混用**：`2i / 2i+1` 公式只对 1 起编号成立；
> 孩子表用 0 表空时，编号必须从 1 开始。

> **【易错】** **权值可为负时路径初值**：`best` 初值 −∞ 而非 0，
> 且路径至少含一个结点。

> **【易错】** **n ≥ 10⁶ 的输入不写快读**（P5018 层序给 n 个权值）——
> 读入超时与爆栈并列为本专题两大工程死法。

## 典型例题

### 例 1　子树权值和 + 最大路径（树形聚合）　难度：变式题

**题干摘要**：n ≤ 10⁵ 点权二叉树，求每个结点的子树权值和，并求整树最大「根到叶路径和」。
**题源**：树形聚合基本功（可对照配套练习 T2 的镜像判定练第二种语义）
**涉及知识点**：知识点 2

**解题思路**：

1. **信号**：「每个结点的子树 XX」→ 后序聚合；「根到叶最值」→ 路径延伸。
2. **方法**：两次独立 dfs——聚合型返回子树和；延伸型返回向下最大链并收集全局最优。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;
const int N = 100005;
int chl[N][2], val[N];
long long sub[N], best = -1e18;

long long dfsSum(int u) {                 /* 子树和（后序聚合） */
    if (u == 0) return 0;
    return sub[u] = dfsSum(chl[u][0]) + dfsSum(chl[u][1]) + val[u];
}
long long dfsPath(int u) {                /* 向下最大路径 */
    if (u == 0) return 0;
    long long d = max(dfsPath(chl[u][0]), dfsPath(chl[u][1])) + val[u];
    best = max(best, d);
    return d;
}
```

**复杂度**：各 O(n)。

> **【易错】** 权可为负时路径至少含一个结点（`best` 初值 −∞ 而非 0）；
> 子树和与路径是两次独立 dfs，别在一个函数里混返回。

---

### 例 2　由前序中序输出后序（重构）　难度：模板题

**题干摘要**：给前序与中序（互异整数），输出后序。n ≤ 10⁵。
**题源**：同类真源见配套练习 T2（P1827 血统记录，同型题）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「前序 + 中序 → 后序」→ 前定根、中分侧递归切分。
2. **方法**：见核心模板 `build`，主函数加读入与 `posIn` 预处理。

**复杂度**：O(n)（`posIn` 数组免线性查找根）。

> **【易错】** 不预处理 `posIn` 的写法是 O(n²)，n 大必炸——
> 这是模板与暴力的分水岭；前序 + 中序才唯一，前序 + 后序不唯一
> （考研第 4 章 4-6 同源结论）。

## 本章总结

### 核心内容（一页纸）

1. **竞赛树题的统一骨架**：孩子表 / 编号数组建树 → dfs 聚合。
2. **树上递归无重叠子问题**，可直接写（对照一般分治需判独立性）。
3. **两种 dfs 返回语义**：子树聚合（后序相加）与路径延伸（max 一侧 + val）——不能混写。
4. **全局答案在返回之外收集**（`best = max(best, ...)`），负权时初值 −∞。
5. **重构口诀：前序定根、中序分侧**；`posIn` 预处理把 O(n²) 降到 O(n)。
6. **前序 + 中序才唯一**；前序 + 后序不唯一（考研 4-6 同源）。
7. **`2i / 2i+1` 编号公式只对 1 起成立**；孩子表 0 表空时编号从 1 起。
8. **深树爆栈两解**：大栈 / 迭代遍历；n = 10⁶ 必考（P5018）。
9. **n ≥ 10⁶ 先写快读**。
10. **竞赛树题 80% 时间在建树与输入**——三种输入格式各练一遍。
