## 本章地图

本章解决一个问题：**「序列频繁插删，怎么不动全身？」**

```text
数组：随机访问 O(1)，但插删要整体搬移 O(n)
   ↓
链表：插删 O(1)（定位后），随机访问 O(n) —— 互补
   ↓
竞赛落地：数组模拟（静态链表）—— 值 / 左右指针各一个数组
   ├─ 哨兵结点（0 号左、1 号右）→ 头尾特判全部消失
   ├─ 动态序列维护：插入、按标记删除（P1160 型）
   └─ 指针型基本功：翻转三指针（P206）、快慢判环（P141）
```

**为什么这条路径是这样**：链表题的难点**从来不在「链」的概念**，
而在**指针修改的顺序与边界**。哨兵与「先存后继再改指」两条纪律，
覆盖了本专题 90% 的错误来源。

## 核心概念与模板

**是什么**：链表 = 指针串起的结点序列：插入删除 O(1)（定位后）、随机访问 O(n)——与数组互补。
竞赛三类用法：手写单 / 双链表维护动态序列（配合删除标记）、邻接表建图（阶段 5 的前置）、模拟题的状态串。

**为什么**：数组模拟链表（静态链表）比 new/free 快且省事，是竞赛首选。

> **【规律】** **哨兵结点是链表题的免费午餐**：两端各放一个不存值的哨兵，
> 「插在头 / 删尾」的特判全部消失——**多花两个下标，省掉一半边界代码。**

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 100005;

int val[N], L[N], R[N], idx;      /* 值、左指针、右指针（存下标） */

void init() {                     /* 0 号左哨兵、1 号右哨兵 */
    R[0] = 1; L[1] = 0; idx = 2;
}
void insert(int k, int x) {       /* 在下标 k 的右侧插入 x */
    val[idx] = x;
    L[idx] = k; R[idx] = R[k];
    L[R[k]] = idx; R[k] = idx++;
}
void remove(int k) {              /* 删除下标 k 结点 */
    R[L[k]] = R[k];
    L[R[k]] = L[k];               /* 不物理回收，标记式 */
}
```

**单链表经典双指针三件套**：

```cpp
/* 快慢指针找中点：慢步 1 快步 2，快到尾时慢在中点 */
LNode *mid(LNode *head) {
    LNode *slow = head, *fast = head;
    while (fast->next && fast->next->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

> **【类比】** 数组模拟链表像**班级座次表**：每个座位只记「左邻座号 / 右邻座号」，
> 插人 = 改三个座位的邻居记录（没人真的搬桌子）；
> 翻转像**广播操向后转**——每个同学只记住「我原来指向谁、现在指向谁」，
> **先把新指向备好（nxt），再转身，队伍才不会断。**

## 本章难点

> **【难点】** **指针修改顺序的唯一安全序**。
> 双链表插入：**先接新结点的 L / R（指向邻居），再让邻居指向自己**——
> 顺序颠倒会先丢掉原邻居信息。三指针翻转同理：**nxt 必须在改 `cur->next` 之前存下**。
> 判据：改任何指针前问一句「这个值我待会儿还要用吗」。

> **【难点】** **判环的「先动后判」**。
> 快慢指针起点相同时，若「先比较再走」首轮即判相遇（假阳性）——
> 必须**两指针各走一步后再比较**。这是 Floyd 判圈实现里唯一的顺序陷阱。

---

## 本章易错点

> **【头号易错】** **指针修改顺序错**：双链表插入要先接新结点的 L / R 再改邻居，
> 顺序颠倒即断链。单链表翻转的三指针（pre / cur / nxt）少了 nxt 必丢链。

> **【易错】** **删除头 / 尾的边界**——无哨兵写法的经典错误；用哨兵后自动消失。

> **【易错】** **「第 k 个」从 0 还是 1 数**——题面口径转换只在一处做（阶段 1 纪律）。

> **【易错】** **静态链表 idx 用尽没扩 / 数组开小**——按题目操作数开余量。

> **【易错】** **判环循环条件漏一个判空**：`fast != NULL && fast->next != NULL` 两个都要。

## 典型例题

### 例 1　单链表原地逆置（迭代三指针）　难度：模板题

**题干摘要**：不带头结点的单链表原地逆置。
**题源**：同类真源见配套练习 T2（leetcode-206 反转链表）
**涉及知识点**：知识点 2

**解题思路**：

1. **信号**：「原地」「O(1) 空间」→ 三指针迭代（递归深度 n 会爆栈）。
2. **方法**：nxt 先存后继 → cur 指向 pre → 双指针整体右移。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
struct LNode { int v; LNode *next; };

LNode* reverse(LNode *head) {
    LNode *pre = NULL, *cur = head;
    while (cur != NULL) {
        LNode *nxt = cur->next;    /* 先存后继 */
        cur->next = pre;           /* 翻转 */
        pre = cur;
        cur = nxt;
    }
    return pre;                    /* 新头 */
}
```

**复杂度**：时间 O(n)，空间 O(1)。

> **【易错】** 返回 **pre** 不是 cur（cur 已是 NULL）；递归版深度 n 会爆栈，竞赛用迭代。

### 例 2　链表判环（快慢指针）　难度：模板题

**题干摘要**：判断单链表是否有环。
**题源**：同类真源见配套练习 T3（leetcode-141 环形链表）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「是否有环」+ O(1) 空间 → Floyd 判圈。
2. **方法**：快 2 慢 1；有环则两指针在环内必相遇（相对速度 1），先动后判。

```cpp
// g++ -std=c++17 -O2
bool hasCycle(LNode *head) {
    LNode *slow = head, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

**复杂度**：时间 O(n)，空间 O(1)。

> **【易错】** 循环条件两个判空都不能省；起点相同需**先动后判**（否则首轮假阳性）。

## 本章总结

### 核心内容（一页纸）

1. **链表与数组互补**：插删 O(1) vs 随机访问 O(1)——按操作分布选型。
2. **竞赛首选数组模拟（静态链表）**：三个数组搞定，免内存管理。
3. **哨兵结点消灭头尾特判**：两端各一个，省一半边界代码。
4. **指针修改唯一安全序**：先接新结点、再改邻居；翻转先存 nxt。
5. **三指针翻转**：pre / cur / nxt，返回 pre；递归版爆栈用迭代。
6. **快慢判环**：快 2 慢 1、先动后判；找中点同款。
7. **删除用标记式**（不物理回收），idx 按操作数开余量。
8. **「第 k 个」访问否决链表**——链表的价值只在插删。
9. **408-2019-41 链表重排 = 中点 + 翻转 + 交叉合并**，本篇三件套的真题落点。
10. **链表思想的延伸**：邻接表（阶段 5）、跳表、删除标记模拟。
