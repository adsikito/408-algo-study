## 本章地图

本章解决一个问题：**「不断合并的等价类，怎么快速查『谁和谁一伙』？」**

```text
朴素：每个集合存成员链表 → 合并 O(n)
   ↓
双亲表示：fa[x] 指向代表元 → 查找沿 fa 上溯
   ↓
两大优化：
   ├─ 路径压缩（find 时把链拍扁）→ 查找近 O(1)
   └─ 按大小 / 秩合并（小挂大）  → 树高压到 O(log n)
   ↓
均摊 O(α(n))，α 可视为 ≤ 4 的常数 —— 近似常数时间
   ↓
三大应用形态：
   ├─ 连通块计数（初始 n、真合并减一）
   ├─ 判环（unite 返回假 = 已同根 = 有环）→ Kruskal 前置
   └─ 关系扩展（多种关系 → 06 篇种类并查集）
```

**为什么这条路径是这样**：并查集的价值在**「合并后不破坏查询效率」**——
两大优化各管一半（压缩管深度、按大小管树形），缺一个最坏都会退化。
**理解「α(n) 为什么近似常数」不必深究证明，但要记住这是双优化的共同功劳。**

## 核心概念与模板

**是什么**：维护不相交集合：Find 查代表元、Union 合并集合。

**为什么**：考研第 4 章 4-11 已讲结构与复杂度，竞赛侧补三件事：
**完整双优化模板**、**启发式合并维护集合信息**（size / 最大值 / 标记）、
**可撤销与带权变种**的方向。均摊近 O(α(n))，α 可视为 ≤ 4 的常数。

> **【规律】** **unite 返回 bool 是本模板的灵魂**：
> 「已同根 → 返回假」一行同时服务判环（Kruskal）、重边跳过、连通计数三个场景。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 100005;
int fa[N], sz[N];                         /* 双优化：路径压缩 + 按大小合并 */

void init(int n) {
    for (int i = 1; i <= n; i++) { fa[i] = i; sz[i] = 1; }
}

int find(int x) {
    while (fa[x] != x) {                  /* 迭代版压缩：两遍法 */
        x = fa[x] = fa[fa[x]];            /* 跳一步省一半深度 */
    }
    return x;
}

bool unite(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra == rb) return false;           /* 已同集合：返回假（判环用） */
    if (sz[ra] < sz[rb]) { int t = ra; ra = rb; rb = t; }
    fa[rb] = ra;                          /* 小挂大 */
    sz[ra] += sz[rb];
    return true;
}
```

**维护集合信息的启发式合并**（例：集合最大值随合并更新）：

```cpp
int mx[N];                                /* mx[根] = 集合最大值 */
void uniteInfo(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra == rb) return;
    if (sz[ra] < sz[rb]) { int t = ra; ra = rb; rb = t; }
    fa[rb] = ra;
    sz[ra] += sz[rb];
    if (mx[rb] > mx[ra]) mx[ra] = mx[rb]; /* 信息随合并聚合 */
}
```

> **【类比】** 并查集像**公司并购**：find = 顺着汇报线找到董事长（代表元）；
> 路径压缩 = 合并后全员直接向新董事长汇报（老中间层裁撤）；
> 按大小合并 = **小公司并入大公司**（反过来会让汇报线变长）；
> sz[] 就是人事系统里的总人数，并购时自动累加。

## 本章难点

> **【难点】** **迭代 find 的压缩写法**。
> `x = fa[x] = fa[fa[x]]` 一行同时完成「跳一步」与「路径减半」——
> 递归写法更直观但 10⁶ 链上爆栈。**两种都要会**：
> 先写对递归理解语义，再背迭代版上赛场。

> **【难点】** **「信息随根聚合」的设计模式。**
> 集合的任何可合并信息（size / max / min / 异或和 / 标记惰性）都挂根上，
> unite 时把小根的信息聚合到大根——**这一模式直接通向 06 篇（关系值）与
> 可撤销并查集（栈回滚）**。

---

## 本章易错点

> **【头号易错】** **find 里递归写法在 10⁶ 链上爆栈**——
> 竞赛用迭代两遍法或先找根再回填。

> **【易错】** **unite 前忘判同根**：自并会把根指到自己造成信息（sz / max）丢失。

> **【易错】** **初始化 fa[i] = i 忘写**——多组数据 / 复用数组时的经典 WA。

> **【易错】** **按大小合并的 swap 忘做**——只有路径压缩时最坏仍有 O(log n)
> （可接受），但双优化才是标准配置。

> **【易错】** **连通计数在同根重边上误减**——只在「真合并」（unite 返回真）时减一。

## 典型例题

### 例 1　连通块个数动态维护（模板）　难度：模板题

**题干摘要**：n 点 m 条边依次加入，每次加边后输出连通块个数。
**题源**：并查集标准应用（同类真源见配套练习 T2 村村通、T3 亲戚）
**涉及知识点**：知识点 2、4

**解题思路**：

1. **信号**：「动态加边 + 连通性」→ 并查集；块数 = n − 真合并次数。
2. **方法**：初始块数 = n；每次 unite 成功（返回真）块数减一。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 100005;
int fa[N], sz[N];

int find(int x) { while (fa[x] != x) x = fa[x] = fa[fa[x]]; return x; }

int main() {
    int n, m, blocks;
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) { fa[i] = i; sz[i] = 1; }
    blocks = n;
    while (m--) {
        int a, b;
        scanf("%d %d", &a, &b);
        int ra = find(a), rb = find(b);
        if (ra != rb) {
            if (sz[ra] < sz[rb]) { int t = ra; ra = rb; rb = t; }
            fa[rb] = ra;
            sz[ra] += sz[rb];
            blocks--;                     /* 每次成功合并减一 */
        }
        printf("%d\n", blocks);
    }
    return 0;
}
```

**复杂度**：时间 O(m α(n))，空间 O(n)。

> **【易错】** 块数只在「真合并」时减；同根重边不影响计数。

### 例 2　最少修路数（连通计数变式）　难度：变式题

**题干摘要**：n 个村庄 m 条已有路，最少再修几条使全连通。
**题源**：同类真源见配套练习 T2（P1536 村村通，同型题）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「最少连几条使全连通」→ 连通块数 − 1（块间各连一条即可）。
2. **方法**：全量读入建并查集 → 输出「连通块数 − 1」。

**复杂度**：O(m α(n))。

> **【易错】** 答案是**块数 − 1** 不是块数；已在同一块的村庄间的路是重边，直接跳过。

## 本章总结

### 核心内容（一页纸）

1. **并查集 = 等价类的机器实现**：Find 查代表元、Union 合并集合。
2. **双优化缺一不可**：路径压缩管深度、按大小合并管树形——合起来均摊 O(α(n))。
3. **迭代 find 是赛场标配**（`x = fa[x] = fa[fa[x]]`）；递归版 10⁶ 链爆栈。
4. **unite 返回 bool**：已同根返回假——一行服务判环 / 重边 / 计数三场景。
5. **信息挂根上随合并聚合**（size / max / 标记）——通用设计模式。
6. **连通计数**：初始 n 块、真合并一次减一；村村通答案 = 块数 − 1。
7. **字符串场景先映射**（map<string,int> 建编号），并查集只处理整数。
8. **传递性是入场券**：不可传递的关系走 06 篇扩域。
9. **初始化 fa[i] = i 与多组重置**是最低级却最高频的 WA。
10. **应用三件套**：等价查询、连通计数、判环（Kruskal 前置）。
