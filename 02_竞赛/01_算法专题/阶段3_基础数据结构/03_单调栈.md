## 本章地图

本章解决一个问题：**「对每个元素找最近的更大 / 更小元素，怎么不写双重循环？」**

```text
朴素：每个 i 向右扫到第一个更大 → O(n²)
   ↓
关键观察：被弹出者的答案 = 弹出它的元素（从左往右扫）
   ↓
栈内保持单调 → 每个元素至多一进一出 → O(n) 摊还
   ↓
三种产出形态：
   ├─ 最近元素下标      → 模板题（P5788）
   ├─ 计数 / 贡献        → 可见牛（P2866）：可见数 = 栈顶下标距离
   └─ 以 i 为最值的区间  → min × len（P2659）：左右第一个更矮的夹逼
```

**为什么这条路径是这样**：单调栈的本质是**「用一次遍历清算所有未决事项」**——
每个元素入栈时带着「还没找到答案」的状态，被弹出即被清算。
**理解「出栈 = 结算」，三种形态就都是同一件事的变体。**

## 核心概念与模板

**是什么**：栈内元素保持单调（递增或递减）：新元素入栈前把破坏单调性的栈顶弹出。

**为什么**：把「双重循环找最近更大元素」的 O(n²) 压到 O(n)——
每元素至多入栈出栈一次，**总操作数 2n**。

> **【规律】** **单调栈的产出是「最近的支配者」，不是排序。**
> 栈里存**下标**而非值（答案要下标、比较要值，存下标两者兼得）。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 100005;
int a[N], stk[N], top = 0, ans[N];       /* stk 存下标；栈底到栈顶 a 值递减（配「找更大」） */

/* 求右侧第一个比 a[i] 大的下标（不存在记 0 或 n+1） */
void nextGreater(int n) {
    top = 0;
    for (int i = n; i >= 1; i--) {       /* 从右往左扫 */
        while (top > 0 && a[stk[top]] <= a[i]) top--;  /* 弹掉不大的 */
        ans[i] = (top > 0) ? stk[top] : 0;             /* 栈顶即答案 */
        stk[++top] = i;
    }
}

/* 同题的另一扫法：从左往右，出栈时结算 */
void nextGreater2(int n) {
    top = 0;
    for (int i = 1; i <= n; i++) {
        while (top > 0 && a[stk[top]] < a[i]) {
            ans[stk[top]] = i;           /* i 就是它们的答案 */
            top--;
        }
        stk[++top] = i;
    }
    /* 留在栈里的 ans 默认为 0 */
}
```

> **【类比】** 单调栈像**排队时回头找高个子**：你入队时，把队尾所有比你矮的人请出——
> 他们等的「第一个比你高的人」就是你；
> 请出的人越多，说明他们的疑问被你一次清算得越多。
> **队伍始终保持「从队头到队尾越来越矮」的单调性。**

## 本章难点

> **【难点】** **min × len 型的两侧夹逼。**
> 对每个 i，求「以 a[i] 为最小值」的最大区间 = 左侧第一个更矮 与 右侧第一个更矮 之间——
> 两次单调栈（方向相反）各算一遍，再 O(n) 合并。
> **两侧口径必须一致**：左边判 `>=`、右边判 `>=`（相等柱归哪边不影响正确性，
> 但两边必须同规则，否则相等段会被重复或漏算）。

> **【难点】** **相等元素：弹还是留。**
> 找「严格更大」→ 相等的弹出（`<` 判弹）；找「≥ 的最近」→ 相等的留下（`<=` 判弹）。
> **不是背哪边对，而是按题意选口径后，确认两侧扫描用同一口径。**

---

## 本章易错点

> **【头号易错】** **单调方向与「找更大 / 更小」配错**：找右侧第一个更大 → 维护**递减栈**
> （出栈时结算）；找更小 → 递增栈。方向反了样例都过不了。

> **【易错】** **栈里存值不存下标**——答案要下标、比较要值，**存下标两者兼得**。

> **【易错】** **min × len 型面积不用 `long long`**：10⁵ 高 × 10⁵ 宽 = 10¹⁰ 必炸。

> **【易错】** **大输入不写快读**：P2659 n ≤ 2×10⁶，`scanf` 都可能吃紧，
> 必须手写快读（模块 B-4）。

> **【易错】** **留栈者的默认值**：从左往右扫时，留在栈里的元素没有右侧更大者，
> `ans` 必须预先初始化（0 或 n+1 按题意）。

**解题思路**：

### 例 2　柱状图中最大矩形（min × len）　难度：综合题

**题干摘要**：n 根柱子高 h[i]，求最大矩形面积（底连续）。
**题源**：同类真源见配套练习 T3（P2659 美丽的序列，同框架）
**涉及知识点**：知识点 4

**解题思路**：

1. **信号**：「以某柱为高的最大宽度」→ 左右第一个更矮的夹逼。
2. **方法**：两次单调栈算 lft[i] / rgt[i]，答案 = max(h[i] × (rgt[i] − lft[i] − 1))。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;
const int N = 100005;
long long h[N];
int stk[N], top = 0, lft[N], rgt[N];

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%lld", &h[i]);
    /* 左侧第一个更矮：递增栈 */
    top = 0;
    for (int i = 1; i <= n; i++) {
        while (top > 0 && h[stk[top]] >= h[i]) top--;
        lft[i] = (top > 0) ? stk[top] : 0;
        stk[++top] = i;
    }
    /* 右侧第一个更矮 */
    top = 0;
    for (int i = n; i >= 1; i--) {
        while (top > 0 && h[stk[top]] >= h[i]) top--;
        rgt[i] = (top > 0) ? stk[top] : n + 1;
        stk[++top] = i;
    }
    long long ans = 0;
    for (int i = 1; i <= n; i++)
        ans = max(ans, h[i] * (rgt[i] - lft[i] - 1));
    printf("%lld\n", ans);
    return 0;
}
```

**复杂度**：时间 O(n)，空间 O(n)。

> **【易错】** 面积用 `long long`；两侧「第一个更矮」判 `>=` 的口径一致。

## 本章总结

### 核心内容（一页纸）

1. **单调栈产出「最近的支配者」**：每元素 O(1) 摊还，总操作 2n。
2. **方向配平口诀**：找更大 ↔ 递减栈（出栈结算）；找更小 ↔ 递增栈。
3. **栈存下标不存值**——答案要下标、比较要值。
4. **两种扫法**：从右往左查栈顶；从左往右出栈结算（少一个判空分支）。
5. **出栈 = 结算**：被弹出者的答案就是弹出它的元素。
6. **计数型**：可见数 = 栈内距离；答案最坏 ~N²/2，必须 `long long`。
7. **min × len 型**：左右第一个更矮夹逼，两侧口径必须一致。
8. **相等元素**：弹 / 留按「严格 or 非严格」的题意定，两侧同规则。
9. **n ≥ 10⁶ 先写快读**（P2659 实战）。
10. **静态清算**：数组可修改时单调栈失效 → 线段树。
