## 本章地图

本章解决一个问题：**「处理顺序与到达顺序不同时，用什么结构缓冲？」**

```text
后进先出的需求（括号、撤销、递归、表达式）→ 栈
先进先出的需求（排队、调度、BFS）         → 队列
   ↓
实现：数组模拟（栈 top、循环队列 head/tail）
   ↓
四大应用形态：
   ├─ 括号匹配（栈：最近的未闭合者必须先闭合）
   ├─ 表达式求值（双栈：数栈 + 运算符栈，优先级弹出）
   ├─ 出入栈序列验证（模拟入栈，弹栈比对目标序列）
   └─ FIFO 调度（队列：机器翻译的内存淘汰）
```

**为什么这条路径是这样**：栈与队列的本质是**「访问顺序的约定」**——
栈把「最近」放在指尖（解决嵌套配对），队列把「最早」放在指尖（解决公平排队）。
**读题时先问「该先处理谁」，结构就选好了。**

## 核心概念与模板

**是什么**：栈 LIFO、队列 FIFO。

**为什么**：竞赛侧考点与考研侧（第 2 章）分工：考研考**结构定义与手算**，
竞赛考**应用编排**——括号匹配、表达式求值、单调性预处理（下一专题）、BFS 队列、模拟调度。

> **【规律】** **竞赛实现直接用 STL**（`stack` / `queue` / `deque`，竞赛 C++ C 模块），
> **或数组模拟**（更快）；两者都要会——模拟版是理解单调栈的台阶。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

/* 栈：top 指向栈顶（初始 -1） */
int stk[100005], top = -1;
void push(int x) { stk[++top] = x; }
void pop()       { top--; }
int  peek()      { return stk[top]; }
bool emptyS()    { return top == -1; }

/* 循环队列：牺牲一格（与考研第 2 章 2-5 同款公式） */
int q[100005], head = 0, tail = 0;
void enqueue(int x) { q[tail] = x; tail = (tail + 1) % 100005; }
void dequeue()      { head = (head + 1) % 100005; }
bool emptyQ()       { return head == tail; }
```

**表达式求值（双栈，考研第 2 章 2-8 的竞赛落地）**：

```cpp
#include <stack>
#include <cctype>
#include <cstdio>
using namespace std;

int calc(const char *s) {                /* 无括号简化版思路：双栈同型 */
    stack<int> num;
    stack<char> op;
    auto level = [](char c) { return (c == '+' || c == '-') ? 1 : 2; };
    for (int i = 0; s[i]; i++) {
        if (isdigit(s[i])) {
            int x = 0;
            while (isdigit(s[i])) x = x * 10 + s[i++] - '0';
            i--;
            num.push(x);
        } else {
            while (!op.empty() && level(op.top()) >= level(s[i])) {
                int b = num.top(); num.pop();
                int a = num.top(); num.pop();
                char o = op.top(); op.pop();
                num.push(o == '+' ? a + b : o == '-' ? a - b : o == '*' ? a * b : a / b);
            }
            op.push(s[i]);
        }
    }
    while (!op.empty()) {
        int b = num.top(); num.pop();
        int a = num.top(); num.pop();
        char o = op.top(); op.pop();
        num.push(o == '+' ? a + b : o == '-' ? a - b : o == '*' ? a * b : a / b);
    }
    return num.top();
}
```

> **【类比】** 栈像**羽毛球筒**——只能从同一端取，最后放进去的最先出来；
> 队列像**食堂窗口**——先来的先打饭。
> 表达式求值像**厨师备菜**：数栈是备好的食材，运算符栈是点菜单，
> **新点的菜优先级不高于手里的，就把手里的全部做完**——这就是「同级 >= 弹出」的含义。

## 本章难点

> **【难点】** **双栈求值的左结合细节**。
> 同级运算符必须**先弹栈里的**（`level(op.top()) >= level(s[i])` 用 `>=`），
> 否则 `5 - 3 + 2` 会算成 `5 - (3 + 2) = 0`——左结合被破坏。
> **验证法：拿 `8 / 4 / 2` 手推一遍**，正确的代码应得 1。

> **【难点】** **出入栈序列验证的模拟口径**。
> 把目标序列当作「出栈愿望单」：按序入栈，栈顶等于愿望单当前项就反复弹出；
> 走完后栈空则合法。**「愿望单指针只在弹栈时前进」是唯一正确的驱动方式。**

---

## 本章易错点

> **【头号易错】** **出栈前不判空**（`top()` / `pop()` 对空栈是未定义行为）
> 与循环队列判满公式与牺牲格约定不配套。

> **【易错】** **表达式求值里 `level` 的 `>=` 写成 `>`**——同级不先算，左结合被破坏。

> **【易错】** **减法除法不可交换，弹栈顺序是先 b 后 a**——
> `a op b` 的 a 在栈更深一层，先弹出的是 b。

> **【易错】** **括号匹配只判「右括号时有得配」**——扫完后栈非空（左多）也要返回 false。

> **【易错】** **循环队列判满与判空同形**（head == tail）——牺牲一格换区分，
> 或用 size 计数器；两种方案不可混用。

## 典型例题

### 例 1　括号匹配（栈）　难度：模板题

**题干摘要**：判断含 `( ) [ ] { }` 的串是否匹配。
**题源**：同类真源见配套练习 T1（P1739 表达式括号匹配）
**涉及知识点**：知识点 2

**解题思路**：

1. **信号**：「嵌套配对」→ 栈（最近的未闭合者必须先闭合）。
2. **方法**：左括号入栈；右括号查栈顶配对；结束时栈必须为空。

```cpp
// g++ -std=c++17 -O2
#include <stack>
#include <cstdio>
#include <cstring>
using namespace std;

bool match(const char *s) {
    stack<char> st;
    for (int i = 0; s[i]; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else {
            if (st.empty()) return false;
            char t = st.top(); st.pop();
            if ((c == ')' && t != '(') || (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return false;
        }
    }
    return st.empty();                   /* 左括号多也不匹配 */
}
```

**复杂度**：时间 O(n)，空间 O(n)。

> **【易错】** 扫完后栈非空 = 左括号多，也要返回 false——两类失败都要判。

### 例 2　FIFO 内存调度（队列）　难度：模板题

**题干摘要**：内存容量 M 的先进先出缓存，单词序列依次到达，
不在内存则查外存并入库（队满删最早），求查外存次数。
**题源**：同类真源见配套练习 T3（P1540 机器翻译）
**涉及知识点**：知识点 5

**解题思路**：

1. **信号**：「先进先出 + 容量上限」→ 队列 + 标记数组判重。
2. **方法**：在内存标志 `in[]`；查外存时入队、标志置真；队满出队并清标志。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int SZ = 1005;
int q[SZ], head = 0, tail = 0;           /* 循环队列 */
bool inMem[1005];                        /* 单词值 ≤ 1000，直接值作下标 */

int main() {
    int m, n, cnt = 0;
    scanf("%d %d", &m, &n);
    while (n--) {
        int x;
        scanf("%d", &x);
        if (inMem[x]) continue;          /* 内存中有：不查外存 */
        cnt++;                           /* 查外存一次 */
        if ((tail - head + SZ) % SZ == m) {   /* 队满：删最早 */
            inMem[q[head]] = false;
            head = (head + 1) % SZ;
        }
        q[tail] = x; tail = (tail + 1) % SZ;
        inMem[x] = true;
    }
    printf("%d\n", cnt);
    return 0;
}
```

**复杂度**：时间 O(n)，空间 O(M + 值域)。

> **【易错】** 删「最早进入」的单词必须**同时清标志**——只出队不清标志，
> 判重数组会误报「在内存」。

## 本章总结

### 核心内容（一页纸）

1. **选型口诀**：嵌套配对 → 栈；公平排队 → 队列；单调窗口 → 单调队列（下一专题）。
2. **数组模拟三要素**：栈 top 初值 −1；循环队列牺牲一格；size 计数器二选一不混用。
3. **出栈前必判空**——`top()` / `pop()` 空栈是未定义行为。
4. **括号匹配两类失败**：右括号无得配（中途空栈）+ 左括号多（结束栈非空）。
5. **双栈求值**：数栈 + 运算符栈；同级 `>=` 先弹（左结合）。
6. **减除不可交换**：先弹的是 b，后弹的是 a。
7. **出入栈序列验证**：愿望单指针只在弹栈时前进，走完栈空即合法。
8. **FIFO 调度**：队列 + 标志数组判重，**出队必须同时清标志**。
9. **考研对照**：2-2 出入栈序列、2-5 循环队列公式、2-8 表达式求值——本篇是它们的代码化。
10. **升级方向**：单调栈（03）、单调队列（阶段 7）、BFS（阶段 4）。
