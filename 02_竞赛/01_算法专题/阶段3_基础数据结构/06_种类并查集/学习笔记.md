> 课件来源：`14.种类并查集.pptx`
>
> 例题代码：`例题代码\P3367.cpp`（P3367 【模板】并查集）、`P1525.cpp`（P1525 关押罪犯 / 种类并查集）

## 🗺️ 本章地图

> **本章解决一个问题：并查集会管"亲戚"，怎么让它管"敌人"？**
> 路线是"一块板子 → 一个扩展 → 一道好题"：先把 P3367 的并查集模板（初始化、find 路径压缩、合并、查询）打到默写级（知识点 1）；再学种类并查集（扩展域并查集）——把域扩一倍，用"敌人的敌人是朋友"表达对立关系（知识点 2）；最后 P1525 关押罪犯把"矛盾值降序排序 + 扩域合并"拼成完整解法（知识点 3）。
> 学完请自测三件事：find 的路径压缩那一句怎么写？x 与 y 是敌人要合并哪两对域？P1525 为什么第一条"拆不开"的矛盾值就是答案？

## 📌 本章重点（3-5个）

⭐ **并查集模板（P3367 板子题）**：fa[i]=i 初始化；find 找根 + 路径压缩 `return fa[x]=find(fa[x])`；合并"根连根" fa[fx]=fy；查询即比较两根
⭐ **种类并查集（扩展域）**：域扩一倍，[1,n] 与 [n+1,2n] 两个种类；同域合并=朋友，跨域合并=敌人；某元素属于哪个种类不确定，两种类都试试
⭐ **"敌人的敌人是朋友"的实现**：x 与 y 敌对 ⟺ merge(x, y+n) 且 merge(y, x+n)
⭐ **P1525 套路**：矛盾值从大到小排序，逐条判定——两人已在同一集合则输出当前矛盾值；否则交叉合并敌域；全处理完输出 0

## 🔥 本章难点（2-3个）

🔥 **扩域的语义翻译**：f[fa]=fbd 究竟在说什么？——"x 的代表挂到 y+n 的代表下"= x 与"y 的敌域"同组 = x 与 y 是敌人；必须能口头翻译每条合并的含义
🔥 **P1525 的正确性逻辑**：为什么第一条无法分开的矛盾值就是所求的最小值？——矛盾值降序处理，比它大的矛盾都已保证"分开关押"，当前这条已是无法回避的最贵代价

## ⚠️ 本章易错点（3-5个）

⚠️ **初始化范围不够**：扩域后要初始化 1..2n（P1525 里 `for(i=1;i<=2*n;i++) f[i]=i`），只初始化到 n 会让敌域全是"无父野结点"
⚠️ **合并写成 fa[x]=y**：必须**根连根** `fa[find(x)]=find(y)`；直接把结点挂过去会破坏集合结构
⚠️ **find 忘写路径压缩**：课件注释里的朴素版 `return find(fa[x])` 链状退化时 O(n)；压缩版 `return fa[x]=find(fa[x])` 一字之差
⚠️ **P1525 先合并后取代表**：四个 find（fa、fb、fad、fbd）必须**全部先算完**再执行合并，边找边改会把刚改过的父亲又拿来用
⚠️ **忘记无冲突输出 0**：所有矛盾都能分开时程序要输出 0 结束，漏掉直接没有输出

## 📖 知识点讲解

### 1. 并查集与 P3367 模板

**是什么**：白话——"朋友圈管理器"：只回答"x 和 y 是不是一伙的"，并支持"把两伙合成一伙"。用 fa[] 数组存"父亲"，根的父亲是自己；课件定义：并查集能维护**连通性、传递性**——通俗地说，亲戚的亲戚是亲戚。P3367 是板子题：z=1 合并 x,y；z=2 查询 x,y 是否同集合（是输出 Y 否输出 N）。

**为什么**：n 个点 m 次合并/查询，用"每次 BFS/DFS 判连通"代价太大；并查集把合并与查询都做到近似 O(1)（路径压缩后均摊极小），一维数组就够。

**怎么用**——模板（`P3367.cpp`）：
```cpp
int find(int x)
{
    if(x==fa[x]) return x;              // 我就是根
    else return fa[x]=find(fa[x]);      // 路径压缩：顺手挂到根上
}
int main()
{
    for(int i=1;i<=n;i++) fa[i]=i;      // 初始化：各自成家
    if(z==1){ fa[find(x)]=find(y); }    // 合并：根连根
    else{ find(x)==find(y) ? Y : N; }   // 查询：同根即同家
}
```
跟算：n=4，依次"合并(1,2)、合并(3,4)、合并(2,3)、查询(1,4)"：
```
合并(1,2)：find(1)=1，find(2)=2 → fa[1]=2        {1,2}
合并(3,4)：fa[3]=4                               {3,4}
合并(2,3)：find(2)=2，find(3)=4 → fa[2]=4        {1,2,3,4}
查询(1,4)：find(1)：f[1]=2→f[2]=4，顺手 f[1]=4；find(4)=4
          两根同为 4 → 输出 Y
```
注意最后一步：find(1) 顺路把 1 也直接挂到 4——这就是路径压缩，下次查询 1 只需一步。

> ⚠️ 注意事项：初始化必须覆盖全部结点；合并是集合代表互挂，不是把 x 直接挂在 y 下；朴素 find（课件注释掉的版本）链长时 O(n)，正式题一定写压缩版。

> 🎯 规律：只要关系满足传递性（A~B、B~C ⟹ A~C），都能用并查集维护。

> 💡 一句话总结：父亲数组找根，根同是一家。

### 2. 种类并查集（扩展域）：敌人的敌人是朋友

**是什么**：白话——给每个人同时开一个"本体"和一个"影子（敌域）"：课件原文——并查集能维护连通性、传递性（亲戚的亲戚是亲戚），但要维护**对立关系**（比如"敌人的敌人是朋友"）时普通并查集很难满足，于是种类并查集（扩展域并查集）诞生：把原并查集**扩大一倍规模**划成两个种类，[1,n] 表示一个种类，[n+1,2n] 表示另一个种类。同种类内合并和普通并查集一样表达"是朋友"；在**不同种类的并查集中合并**就表达"是敌人"；某元素到底属于哪个种类不清楚，那就**两个种类都试试**。

**为什么**：普通并查集只会"合"不会"反"——它只能表示"是一伙的"，无法存"互为敌人"这条反向信息。扩域用"结点+影子"把对立信息编码成可合并的朋友关系：x 与 y+n 同组，等价于声明"x 与 y 不同类"；再靠传递性自动推出"敌人的敌人是朋友"。

**怎么用**——规则与模板：
```cpp
// x 与 y 是敌人：
f[find(x)]   = find(y+n);   // x 与 y 的敌域同组 → x、y 分开
f[find(y)]   = find(x+n);   // y 与 x 的敌域同组 → 对称补一条
// 查询：find(x)==find(y)        → 同类（朋友）
//      find(x)==find(y+n) 且…   → 敌对
```
跟算：n=3（域 1..6），已知敌人 (1,2)、敌人 (2,3)：
```
敌人(1,2)：f[find(1)]=find(5) → f[1]=5；f[2]=4
敌人(2,3)：f[find(2)]=find(6)：find(2)=4 → f[4]=6；f[3]=5
验证"敌人的敌人是朋友"：find(1)：f[1]=5 → 5；find(3)：f[3]=5 → 5
→ 1 和 3 同根：2 的两个敌人 1、3 自动成了朋友 ✓
```

> ⚠️ 注意事项：数组开 2n（P1525 的 f[40005] 对应 n≤20000）；若有 k 类环状关系（如食物链 A吃B、B吃C、C吃A）就扩 k 倍；每条敌对关系要**对称地合两条**。

> 🎯 规律：关系有"正反两面"就扩域；扩 r 倍可表达模 r 循环的 k 类关系——本质是给状态空间多开几个"身份槽位"。

> 💡 一句话总结：一人两域，敌域连敌，传出生友。

### 3. P1525 关押罪犯：降序排序 + 扩域判定

**是什么**：白话——n 名罪犯、m 对"冤家"各有矛盾值，关进两座监狱，同狱的冤家会打架，求"爆发的最大矛盾值"最小能压到多少。课件思路：我们要尽可能让矛盾值大的罪犯在两个监狱里——**矛盾值排序**。具体：①先把所有矛盾关系按矛盾值**从大到小**排序；②逐条取出关系 (x,y,c)：若 x、y 已在同一集合（find 找父亲相同）则必然打起来，**直接输出当前矛盾值 c**（已排序，保证这是最小的"最大矛盾值"）；③若不同组，按"敌人的敌人就是朋友"：把 **x 与 y 的其他敌人**分在同一组、**y 与 x 的其他敌人**分在同一组（即交叉合并敌域）。不断操作直到得到答案；全部处理完没冲突则输出 0。

**为什么**：这是"贪心 + 判定"。矛盾值大的优先拆散，处理到第 i 条时，前面所有更大的矛盾都已妥善"分关"；若这条仍拆不开（x、y 已被之前的关系绑进同一集合），它就是无法避免的最贵代价——答案就是它。

**怎么用**——关键代码（`P1525.cpp`）：
```cpp
bool cmp(crime &x,crime &y){ return x.c>y.c; }   // 矛盾值降序
sort(e+1,e+m+1,cmp);
for(int i=1;i<=m;i++)
{
    fa=find(e[i].a);  fb=find(e[i].b);           // 先把四个代表全找出来
    fad=find(e[i].a+n); fbd=find(e[i].b+n);
    if(fa==fb){ cout<<e[i].c; return 0; }        // 拆不开了：答案就是它
    f[fa]=fbd;   // a 与 b 的敌域合并 → a、b 分开
    f[fb]=fad;   // b 与 a 的敌域合并 → 对称补上
}
cout<<0;
```
跟算：n=4（域 1..8），矛盾关系 (1,2,5)、(2,3,3)、(1,3,1)，已按降序排好：
```
处理(1,2,5)：fa=1, fb=2, fad=5, fbd=6，不同 → f[1]=6, f[2]=5
             含义：1 与"2的敌域"同组（1、2 分开），2 与"1的敌域"同组
处理(2,3,3)：fa=find(2)=5, fb=3, fad=6, fbd=7 → f[5]=7, f[3]=6
             含义：2 与 3 分开；顺带 1（在 6 组）与 3 同组了
处理(1,3,1)：fa=find(1)：f[1]=6 → 6；fb=find(3)：f[3]=6 → 6
             fa==fb → 1、3 已在同一集合，必然打起来 → 输出当前矛盾值 1 ✓
人工验证：1 进 A 牢 →(1,2,5) 2 进 B →(2,3,3) 3 进 A →(1,3,1) 1、3 同在 A 爆矛盾；
3 个人两两有仇无法两两分开，只能让最便宜的那对（矛盾值 1）关一起 → 答案 1 ✓
```

> ⚠️ 注意事项：cmp 按 c 降序别写反；输出 c 后立刻 `return 0`；四个 find 必须在合并前全部完成；无冲突记得输出 0。

> 🎯 规律：求"最小化最大代价"→ 降序排序逐条判定，第一条撑不住的就是答案；种类并查集负责维护"已定关系"的传播。

> 💡 一句话总结：矛盾大的先拆，拆不开即答案。

## 🔍 相似概念辨析

**组1：普通并查集 vs 种类并查集**

| 对比维度 | 普通并查集 | 种类并查集（扩展域） |
|---|---|---|
| 各自定义 | fa 数组维护"同属一个集合"（连通、传递） | 域扩 k 倍分种类，跨域合并表达对立关系 |
| 核心区别 | 只能表达"是一伙的" | 能表达"是敌人/对立"，靠传递性推敌友 |
| 各自特点 | 数组开 n，一套 find 全通用 | 数组开 2n/3n，合并要"本体对影子" |
| 使用场景 | 亲戚、连通块（P3367、P1551） | 敌人敌人是朋友（P1525、P1892、P2024） |
| 典型示例 | fa[find(x)]=find(y) | f[fa]=fbd; f[fb]=fad 交叉合并 |
| 记忆口诀 | 敌人是朋友关系的反页，域扩一倍翻页 |

**组2：路径压缩 find vs 朴素 find**

| 对比维度 | 路径压缩 find | 朴素 find |
|---|---|---|
| 各自定义 | 回溯时把沿途结点直接挂到根：fa[x]=find(fa[x]) | 一层一层跟父亲走到根，不做任何改动 |
| 核心区别 | 树几乎被压扁，均摊近似 O(1) | 链状退化时一次 find 要 O(n) |
| 各自特点 | 课件代码一行之差（注释里给了对比版） | 实现同样简单，但只适合极小数据 |
| 使用场景 | 一切正式题目（P1525 也在用） | 教学演示、理解 find 的递归结构 |
| 典型示例 | P3367.cpp 的正式版 | P3367.cpp 注释掉的 O(n) 版 |
| 记忆口诀 | 找完根，顺手把全家挂根上 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**传递性（亲戚的亲戚是亲戚）→ 普通并查集（P3367 模板四件套：初始化/find/合并/查询）→ 对立关系不满足"只会合"的表达力 → 种类并查集扩域（敌人关系=本体与影子交叉合并）→ 降序排序把"关系网"变成"逐条判定"（P1525：第一条拆不开的就是答案）**。三个知识点是同一条进化链：先会"合"，再会"反"，最后学会"按优先级合与反"。

跨知识点共性：
1. **与第十五章网格 DFS 对照**：LC200 的"淹没式 DFS"也能数连通块，并查集是它的"离线版"——适合边读边合并、动态加边的场景。
2. **与第八章贪心同款骨架**：P1525 的"排序 + 从最优的开始逐条判定"正是贪心章"把组合选择压成排序问题"的又一实例（对比 LC2611 的差值排序）。
3. **向后铺垫**：带权并查集（边权记录相对关系）与种类并查集可互相改写（食物链两写法皆可）；并查集还会在最小生成树（Kruskal，第二十三章）里当核心部件登场。

## 📋 速查表

| 操作 | 代码 | 含义 |
|---|---|---|
| 初始化（扩 2 倍） | for(i=1;i<=2*n;i++) f[i]=i; | 自己是自己的根 |
| find（带压缩） | return fa[x]=find(fa[x]); | 找根 + 沿途挂根 |
| 合并朋友 | f[find(x)]=find(y); | 同类合并 |
| 表达敌对 | f[find(x)]=find(y+n); f[find(y)]=find(x+n); | 本体连对方影子 |
| P1525 判定 | fa==fb → 输出当前 c | 已同集合必打架 |

```cpp
// 并查集速记（默写级）
int find(int x){ return fa[x]==x ? x : fa[x]=find(fa[x]); }
fa[find(x)] = find(y);        // 合并：根连根
find(x)==find(y);             // 查询：同根即同集合
```
