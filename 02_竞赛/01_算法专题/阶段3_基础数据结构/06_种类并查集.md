## 本章地图

本章解决一个问题：**「关系有三种且循环（A 吃 B、B 吃 C、C 吃 A），怎么维护？」**

```text
普通并查集：fa[x] 只能表达「同伙」
   ↓
关键观察：关系是环的 → 给每个元素开 k 个「关系副本」
   ↓
扩域法（知识点 2）              带权法（知识点 4）
   x 的同类域 = x                  par[x] + rel[x]（与根的关系值）
   x 的猎物域 = x + N              压缩时关系沿路径叠加（% k）
   x 的天敌域 = x + 2N
   「x 吃 y」⇒ 三对域同时合并       合并时推导新根的关系值
   ↓
每条叙述先 find 判矛盾（知识点 3），不矛盾才 unite
   ↓
矛盾计数 / 阵营划分（二域退化，知识点 5）
```

**为什么这条路径是这样**：扩域法把「关系」翻译成「集合的交」——
x 的猎物域与 y 的同类域合并，就是「x 吃 y」的集合论表达。
**它牺牲 3 倍内存换来零推导**；带权法反过来，省内存但要在压缩时传递关系值。
**先用扩域法建立直觉，再学带权法，是几乎无损的学习路径。**

## 核心概念与模板

**是什么**：普通并查集只答「谁和谁一伙」，种类并查集回答「谁和谁是什么**关系**」
（同类 / 异类 / 猎物等循环关系）。两种实现：**扩域法**（每元素开 k 个副本域，关系转成域间合并，
简单好写）、**带权法**（边上存与根的关系值，路径压缩时异或 / 取模传递，省内存）。

**为什么**：核心 invariant：**同一域内 = 关系确定；不同域 = 由并查集结构传递**。

> **【规律】** **「关系」的集合论翻译**：x 与 y 同类 ⇔ 同类域同根；
> x 吃 y ⇔ x 的猎物域与 y 同根、x 的天敌域与 y 的猎物域同根（环形对称）。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 50005;                       /* 每元素 k 域：k=3 时开 3N */

/* ===== 扩域法：三域版（同类 / 猎物 / 天敌，环形关系） ===== */
int fa[3 * N];

int find(int x) { while (fa[x] != x) x = fa[x] = fa[fa[x]]; return x; }
void unite(int a, int b) { fa[find(a)] = find(b); }

/* x 域定义：x 同类域 = x；x 猎物域 = x + N；x 天敌域 = x + 2N */
/* 「x 吃 y」⇒ unite(x + N, y)（x 的猎物域含 y）
             ⇒ unite(x + 2N, y + N)（y 的猎物域含 x）
             ⇒ unite(x, y + 2N)（x 是 y 的天敌）——三对环形成对合并 */

/* ===== 带权法：rel[x] = x 与根的关系（0 同类 1 被吃 2 吃） ===== */
int par[N], rel[N];

int findW(int x) {
    if (par[x] == x) return x;
    int root = findW(par[x]);
    rel[x] = (rel[x] + rel[par[x]]) % 3;   /* 压缩时传递关系 */
    return par[x] = root;
}
/* 合并时新关系推导：rel[ra] = (3 - rel[a] + d - rel[b]) % 3 */
/* 其中 d = a 与 b 应有关系；推导基于关系加法封闭 */
```

> **【类比】** 扩域法像**给每人发三张身份卡**（自己 / 猎物名单 / 天敌名单）：
> 「x 吃 y」就是把 x 的猎物名单、y 的天敌名单等三对名单钉在一起——
> **名单（域）一旦钉在一起，名单上的所有人共享同一种关系**。
> 带权法则只发一张卡，卡上写着「和队长的关系值」，队长换人时关系值累加换算。

## 本章难点

> **【难点】** **三域环形合并的对称性。**
> 「x 吃 y」必须**三对域同时合并**（猎物、天敌、同类各一对），
> 只合一对会导致后续矛盾判定漏报。**可靠做法：在纸上画 3×3 域矩阵，
> 把关系环画出来，每条叙述对照矩阵写三行 unite。**

> **【难点】** **带权法的关系推导。**
> 路径压缩时 `rel[x] += rel[par[x]]`（沿链叠加）；
> 合并时新根关系由「a 与 b 的应有关系 d」与「各自到根的关系」解方程得出。
> **推导基于关系加法在模 k 意义下封闭**——先验证封闭性（3 进制环成立）再写公式。

## 本章易错点

> **【头号易错】** **域的语义映射写错**（谁吃谁的方向反了）——
> 扩域法先在纸上画三个域的环形箭头再写 unite；带权法的关系加法表（3 进制环）推错一格全盘错。

> **【易错】** **矛盾判定在 unite 之后做**——顺序反了矛盾会被合并动作吞掉。
> **纪律：每条叙述先 find 比较所有相关域，再决定 unite。**

> **【易错】** **数组只开 N 忘开 kN**：三域版必须 `fa[3 * N]`，越界即 RE。

> **【易错】** **多组数据忘重置 fa 与 rel**——并查集状态跨组泄漏是 WA 重灾区。

> **【易错】** **「x 吃 x」「x 与 x 敌对」类自反矛盾**：先特判 `x == y` 的情况。

## 典型例题

### 例 1　关系矛盾判定（扩域法，食物链型）　难度：模板题

**题干摘要**：n 只动物、k 条叙述（「x y 同类」或「x 吃 y」），
叙述与已有信息矛盾或 x、y 越界则该条为假，统计假话数。
**题源**：同类真源见配套练习 T1（P2024 食物链）、T2（P1892 团伙，二域版）
**涉及知识点**：知识点 1、2、3

**解题思路**：

1. **信号**：循环关系 + 假话计数 → 三域扩域。
2. **方法**：矛盾两种——说同类但已有「吃」关系（x 与 y 的敌对域同根）；
   说吃但已有同类关系。判定在 unite 之前。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 50005;
int fa[3 * N];

int find(int x) { while (fa[x] != x) x = fa[x] = fa[fa[x]]; return x; }

int main() {
    int n, k, lies = 0;
    scanf("%d %d", &n, &k);
    for (int i = 1; i <= 3 * n; i++) fa[i] = i;
    while (k--) {
        int d, x, y;
        scanf("%d %d %d", &d, &x, &y);
        if (x > n || y > n) { lies++; continue; }       /* 编号越界 */
        if (d == 1) {                                    /* x y 同类 */
            if (find(x) == find(y + N) || find(x + 2 * N) == find(y)) lies++;
            else { unite(x, y); unite(x + N, y + N); unite(x + 2 * N, y + 2 * N); }
        } else {                                         /* x 吃 y */
            if (x == y || find(x) == find(y) || find(x) == find(y + 2 * N)) lies++;
            else { unite(x + N, y); unite(x + 2 * N, y + N); unite(x, y + 2 * N); }
        }
    }
    printf("%d\n", lies);
    return 0;
}
```

**复杂度**：O(k α(n))，空间 O(3N)。

> **【易错】** 三域必须**环形**成对 unite（同类、猎物、天敌三条链各一）；
> 「x 吃 x」天然是假话。

### 例 2　阵营划分（二域简化）　难度：变式题

**题干摘要**：n 人两类关系（敌 / 友），朋友的朋友是朋友、敌人的敌人是朋友，
问最大可能团伙数。
**题源**：同类真源见配套练习 T2（P1892 团伙）
**涉及知识点**：知识点 5

**解题思路**：

1. **信号**：两种关系 + 传递规则 → 扩域法退化为 **2 域**（自我域 + 敌对域）。
2. **方法**：「x y 朋友」⇒ unite(x, y)、unite(x+N, y+N)；
   「x y 敌人」⇒ unite(x, y+N)、unite(x+N, y)；
   最后统计「自我域为根」的个数即最大团伙数。

**复杂度**：O(m α(n))，空间 O(2N)。

> **【易错】** 与阶段 5 的二分图染色（BFS 染色法）是同一问题的两种实现：
> **扩域并查集支持在线合并，染色法需要先建全图**——按输入顺序选择工具。

## 本章总结

### 核心内容（一页纸）

1. **关系种类是钥匙**：一种 → 普通并查集；k 种循环 → k 域扩域或带权。
2. **扩域法 = 关系的集合论翻译**：x 吃 y ⇒ 三对域环形合并，缺一对就漏报矛盾。
3. **先画域矩阵再写代码**——语义映射写反是本篇唯一死法。
4. **矛盾判定在 unite 之前**：先 find 比较所有相关域。
5. **二域退化**：敌人的敌人是朋友 ⇒ 扩域 2 份，团伙数 = 连通块数。
6. **带权法**：rel 存与根的关系值，压缩时 % k 叠加；合并解一次模方程。
7. **数组开 kN**；多组数据重置 fa / rel。
8. **自反矛盾先特判**（x 吃 x）。
9. **扩域 vs 带权取舍**：好写 vs 省内存——赛场选扩域。
10. **与二分图染色的对照**：同问题不同实现，在线合并选并查集。
