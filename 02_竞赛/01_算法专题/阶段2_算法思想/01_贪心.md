## 本章地图

本章解决一个问题：**「每步都取当前最优，凭什么全局最优？」**

```text
问题有「每步做一个选择」的结构
   ├─ 能证明「局部最优 ⇒ 全局最优」（交换论证 / 归纳）
   │     ├─ 选择是「排序次序」   → 排序型贪心（知识点 2）★ 最大宗
   │     ├─ 选择是「区间取舍」   → 区间调度，按右端点（知识点 3）
   │     ├─ 最优元素动态变化     → 堆辅助（知识点 4）
   │     └─ 选择是「一层一层垫」 → 递推型贪心（知识点 5）
   └─ 证不出来 / 找到反例       → 不要贪心，转 DP（阶段 7）
   ↓
写代码：排序（或建堆）→ 一遍扫 → 30 行以内
```

**为什么这条路径是这样**：贪心与 DP 的分界线是**「最优子结构里保几条路」**——
DP 保全所有子问题的状态，贪心只保一条「当前最优」的路。
**证明就是验证丢掉的那些路确实不可能更优。**
理解这一点，就理解了为什么「证明」不是学术洁癖，而是正确性的全部。

## 核心概念与模板

**是什么**：
- **贪心** = 每步取「当前看起来最优」的选择，不回溯，期望全局最优。
- 成立前提：**贪心选择性质**（局部最优能引导全局最优）+ **最优子结构**。

**为什么**：贪心把「保所有子问题」的 DP 压成「只保一条路」，
**复杂度通常从 O(n²) 降到 O(n log n)（排序主导）**。

> **【规律】** **与 DP 的分界**：DP 保所有子问题，贪心只保一条路——
> **能贪就贪（快），贪不成就 DP（稳）。**

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;

/* 1. 区间调度：不重叠区间最多选多少个 —— 按右端点排序 */
struct Seg { int l, r; };
bool cmp(Seg a, Seg b) { return a.r < b.r; }

int schedule(Seg s[], int n) {
    sort(s, s + n, cmp);
    int cnt = 0, last = -2e9;
    for (int i = 0; i < n; i++)
        if (s[i].l >= last) {        /* 不重叠（相接允许；按题面定 >= 或 >） */
            cnt++;
            last = s[i].r;
        }
    return cnt;
}

/* 2. 找零（货币系统 Canonical）：从大到小拿 —— 需证明无后效性 */
int change(int amount, int c[], int k) {   /* c 降序 */
    int cnt = 0;
    for (int i = 0; i < k && amount > 0; i++) {
        cnt += amount / c[i];
        amount %= c[i];
    }
    return amount == 0 ? cnt : -1;   /* 拿不出 */
}

/* 3. 交换排序论证模型：相邻交换决定次序（如拼最大数） */
/* 比较函数 a+b 与 b+a 拼接后比字典序，代替直接比较 */
```

> **【类比】** 贪心像**自助餐先夹最贵的**：只要「贵的菜品不会让你错过更划算的组合」
> （贪心选择性质），一路夹贵的就是最优策略；
> 若「便宜的组合餐反而更值」，这就是反例——**该改用 DP 精打细算。**

## 本章难点

> **【难点】** **交换论证怎么落笔。**
> 标准三步：① 设最优解中存在相邻两项 a、b 不满足比较序；
> ② 证明**交换 a、b 后其余不变、总代价不变或变优**；
> ③ 由「逆序对可不断消除」推出按比较序排列的解最优。
> **写不出第 ② 步就不要提交**——排序型贪心错一个字就是全盘错。

> **【难点】** **区间调度为什么按右端点而不是左端点 / 长度。**
> 直觉证法：最早结束的活动给后面留的空间**一定不小于**任何其他选择留下的；
> 归纳到底即最优。按左端点 / 按长度排序都有反例——
> **课后自己各构造一个反例，比背十遍结论都管用。**

## 本章易错点

> **【头号易错】** **不证明就贪**：找零对非规范货币系统（如 {1, 3, 4} 凑 6：
> 贪心拿 4+1+1 = 3 枚，正确是 3+3 = 2 枚）会错——
> **先证「贪心选择性质」或举反例，再写代码。**

> **【易错】** **排序关键字选错**：区间调度按左端点排是错的，必须按右端点。

> **【易错】** **相等元素的 `>=` 与 `>`** 影响计数口径（区间「相接」算不算重叠），
> 按题面明确。

> **【易错】** **合并类贪心忘记用 `long long`**：代价累加（合并果子）很快超 `int`。

> **【易错】** **比较函数不满足严格弱序**（如拼数的 `a + b > b + a` 必须是全序），
> 不满足时 `sort` 行为未定义。

## 典型例题

### 例 1　区间调度（活动安排）　难度：模板题

**题干摘要**：n ≤ 10⁵ 个活动，选最多的两两不重叠活动数。
**题源**：同类真源见配套练习 T4（P1803 凌乱的yyy / 线段覆盖）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「最多不重叠区间」→ 按右端点贪。
2. **证明**：最早结束的活动必然出现在某个最优解中（换上去不会使解变差），归纳。
3. **方法**：右端点排序，一遍扫，`last` 记录上一个选中活动的结束时刻。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;
const int N = 100005;
struct Seg { int l, r; } s[N];
bool cmp(Seg a, Seg b) { return a.r < b.r; }

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d %d", &s[i].l, &s[i].r);
    sort(s, s + n, cmp);
    int cnt = 0, last = -2e9;
    for (int i = 0; i < n; i++)
        if (s[i].l >= last) { cnt++; last = s[i].r; }
    printf("%d\n", cnt);
    return 0;
}
```

**复杂度**：时间 O(n log n)（排序主导），空间 O(n)。

> **【易错】** 「相接」算不算重叠按题面定 `>=` 或 `>`——
> 本题 `s[i].l >= last` 允许端点相接。

### 例 2　拼最大数（交换论证）　难度：综合题

**题干摘要**：n ≤ 50 个非负整数拼成最大数（可达 10³ 位，需字符串）。
**题源**：同类真源见配套练习 T5（`04_二分.md` 所在阶段 1 的 P1012 拼数，同型题）
**涉及知识点**：知识点 2

**解题思路**：

1. **信号**：「排次序使拼接结果最大」→ 交换论证。
2. **证明**：两元素相邻交换不改变其他位置 → 只需证 a+b ≥ b+a（字符串拼接字典序）即有序最优。
3. **方法**：比较函数 `a + b > b + a`，全零特判。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    vector<string> v(n);
    for (auto& s : v) {
        int x;
        scanf("%d", &x);
        s = to_string(x);
    }
    sort(v.begin(), v.end(), [](const string& a, const string& b) {
        return a + b > b + a;            /* 拼接后大者在前 */
    });
    if (v[0] == "0") { printf("0"); return 0; }   /* 全零特判 */
    for (auto& s : v) printf("%s", s.c_str());
    return 0;
}
```

**复杂度**：时间 O(n log n × 拼接比较)，空间 O(n)。

> **【易错】** 全零输出一个 0；比较函数必须满足严格弱序（`a + b > b + a` 是全序）。

## 本章总结

### 核心内容（一页纸）

1. **贪心 = 每步取当前最优，不回溯**；成立前提是贪心选择性质。
2. **与 DP 的分界**：DP 保所有子问题，贪心只保一条路——能贪就贪，贪不成就 DP。
3. **交换论证三步**：设相邻逆序 → 交换不变优 → 逆序对可消尽。
4. **区间调度按右端点**：最早结束给后面留最多空间；左端点 / 长度排序都有反例。
5. **找零反例**：{1, 3, 4} 凑 6，贪心 3 枚、正确 2 枚——不证明就贪必翻车。
6. **堆辅助贪心**处理「最优元素动态变化」（合并果子）。
7. **递推型贪心**（铺设道路）：答案 = Σ max(0, dᵢ − dᵢ₋₁)。
8. **比较函数必须满足严格弱序**（拼数的 `a + b > b + a`）。
9. **合并代价累加用 `long long`**。
10. **赛场上先花 2 分钟找反例**：找到转 DP，找不到才提交贪心。
