## 第九章：递归与分治

> 课件来源：`9.递归&分治.pptx`
>
> 例题代码：`例题代码\LC面试题08.06. 汉诺塔问题.cpp`、`LC53.cpp`（最大子数组和）

## 🗺️ 本章地图

本章学两个互相咬合的概念：**递归**（函数调用自身的技巧/思维方式）和**分治**（基于递归、把问题切成独立子问题再合并的算法思想）。路线：先立递归三要素——出口、递归式、递归树理解工具（知识点 1）；用汉诺塔练"n-1 个看成一个整体"的整体思想（2）；再上分治的"分-治-合"框架（3）；最后用 LC53 最大子数组和的三种解法（暴力 O(n²) / 分治 O(nlogn) / DP O(n)）看同一问题如何被逐级优化（4）。

## 📌 本章重点

⭐ **递归三要素**：递归出口（边界条件）要**找全**；递归式把问题缩小；理解靠画递归调用图/递归树
⭐ **汉诺塔整体思想**：把上面 n-1 个盘子看成一个"大盘子"——甲让路（A→B）、乙就位（A→C）、甲归位（B→C）
⭐ **分治三步**：分（子问题相互独立）→ 治（递归求解）→ 合（原问题的解=子问题解的合并），前提是最优子结构
⭐ **LC53 分治三分法**：最大区间只在左、在右、或横跨中心 mid；横跨用贪心从 mid 向两侧延伸取 lmax+rmax

## 🔥 本章难点

🔥 **递归调用图/递归树的画法与信任**：不能顺着展开硬想到底（2^n-1 步人脑存不下），要相信"子调用返回的解是对的"，只管当前层
🔥 **汉诺塔参数轮换**：`move(x-1,s,h,e)` 与 `move(x-1,h,e,s)` 中源/目的/媒介三柱轮换，B、C 写反递归照样跑但结果全错
🔥 **LC53 横跨情形的构造**：左延必须**包含** mid、右延必须**不含** mid，横跨解与左右递归解才不重不漏

## ⚠️ 本章易错点

⚠️ **忘写递归出口**：无限自我调用直接爆栈 RE；出口必须写在递归调用**之前**
⚠️ **出口找不全**：n=1 会挪、n=0 是空塔——汉诺塔若输入可能为 0，`x==1` 的出口就不够
⚠️ **递归调用时参数不趋向出口**：如 move 里仍传 x 而不是 x-1，永远到不了边界
⚠️ **汉诺塔媒介柱写错**：把 n-1 个盘子 A→B 时媒介是 C、B→C 时媒介是 A，三柱角色每层都在轮换
⚠️ **LC53 横跨区间算重/算漏**：左右两段都包含 mid 会重复计 mid；lmax/rmax 初值要用 INT_MIN 而不是 0（全负数组时 0 是假解）

## 📖 知识点讲解

### 1. 递归：自己调用自己

**是什么**：白话——把大问题整个托付给"小一号的自己"，自己只处理最外层那一步。课件定义：递归（Recursion）指在函数的定义中使用**函数自身**的方法，也是通过重复将问题**分解为同类的子问题**而解决问题的方法。

**为什么**：汉诺塔 n 个盘子的完整步骤有 2^n-1 步，人力无法直接铺开；但"n 层怎么办"的一句话规律极简单——会挪 n-1 层就会挪 n 层。递归把"写完整过程"换成"写一层规律 + 一个出口"，代码极短。

**怎么用**——递归三要素模板：
```cpp
返回值 f(问题规模参数)
{
    if (终止条件) return 边界值;      // ①出口：边界条件要找全
    ...拆出更小的同类子问题...
    return 合并( f(更小的参数), ... ); // ②递归式：规模必须趋向出口
}                                     // ③理解：画递归调用图/递归树
```
理解示例—— factorial(3) 的递归树：
```
factorial(3)
├─ 3 * factorial(2)
│        ├─ 2 * factorial(1)
│        │        └─ 返回 1        ← 出口
│        └─ 返回 2
└─ 返回 6
```
例题 LC面试题08.06（汉诺塔）就是这套骨架：出口 `x==1` 时把 s 栈顶搬到 e；否则两次递归夹一次搬运。

> ⚠️ 注意事项：出口写在递归调用前；调用自身的参数必须向出口逼近；不能顺着调用链硬展开，要"信任递归"——相信子调用给出正确解，自己只拼当前层。

> 🎯 规律：定义"自己像自己"的问题（汉诺塔、树、表达式）先用递归；三要素缺一即错，出口找全是底线。

> 💡 一句话总结：出口加递归式，画树好理解。

### 2. 汉诺塔：把 n-1 个看成一个整体（LC面试题08.06）

**是什么**：白话——n 个盘子从 A 挪到 C（大盘不能压小盘，B 可中转），秘诀是把**上面 n-1 个看成一个整体（甲）**，第 n 个大盘是（乙），三步走：甲让路、乙就位、甲归位。

**为什么**：课件从简单情况归纳——n=1：直接 A→C；n=2（甲上乙下）：甲 A→B、乙 A→C、甲 B→C；一般 n：完全复用 n=2 的三步结构，只是"甲"从 1 个盘子变成 n-1 个盘子——搬甲的每一步又是一个"挪 n-1 个盘子"的同类小问题，天然递归。

**怎么用**——模板（`LC面试题08.06.cpp`，参数：源 s、目的 e、媒介 h）：
```cpp
void move(int x, vector<int>& s, vector<int>& e, vector<int>& h)
{                                   // 把 x 个盘子 s ---经 h---> e
    if (x == 1)                     // 出口：直接搬
    {
        int d = s.back(); s.pop_back(); e.push_back(d);
        return;
    }
    move(x-1, s, h, e);             // ① 甲（n-1个）s --e--> h，让路
    int d = s.back(); s.pop_back(); e.push_back(d);   // ② 乙就位 s->e
    move(x-1, h, e, s);             // ③ 甲 h --s--> e，归位
}
void hanota(vector<int>& A, vector<int>& B, vector<int>& C)
{
    move(A.size(), A, C, B);        // n 个盘子 A ---> C，B 帮忙
}
```
跟算 n=3（A→C，B 中转），递归树与移动序列：
```
move(3, A→C 借B)
├─ move(2, A→B 借C)
│  ├─ move(1, A→C)   第1步 A→C
│  ├─ 底盘           第2步 A→B
│  └─ move(1, C→B)   第3步 C→B
├─ 底盘              第4步 A→C
└─ move(2, B→C 借A)
   ├─ move(1, B→A)   第5步 B→A
   ├─ 底盘           第6步 B→C
   └─ move(1, A→C)   第7步 A→C
共 7 步 = 2^3 - 1；一般地 f(n)=2f(n-1)+1 → 2^n - 1
```

> ⚠️ 注意事项：两次递归的柱子顺序不同——①是 (s,h,e)、③是 (h,e,s)，媒介在轮换；原题 LC 要求用栈操作（back/pop_back/push_back 恰是栈顶进出）。

> 🎯 规律：遇"步骤数爆炸但 n→n-1 规律只有一句话"的问题，把 n-1 个打包成整体、写出三步骨架，剩下交给递归。

> 💡 一句话总结：n-1 个让路，底盘到位，再归位。

### 3. 分治：分而治之

**是什么**：白话——大问题切成几块互相独立的小问题，各自解决后把答案拼起来。课件定义：分治（Divide and Conquer）字面"分而治之"，把复杂问题分成两个或更多相同/不相同的子问题，**子问题相互独立**，直到子问题可以直接求解，**原问题的解=子问题解的合并**——即具有**最优子结构**性质。递归与分治的关系（课件原话）：递归是一种编程技巧、解决问题的思维方式；分治很大程度上基于递归，是解决更具体问题的算法思想。

**为什么**：子问题独立时，规模从 n 降到两个 n/2，递归树只有 O(log n) 层，总工作量从"全排列式爆炸"降为 O(nlogn)（分治排序、LC53 分治解法都是这个账）；若子问题相互纠缠（有公共部分），合并就不是"简单拼接"，分治不适用。

**怎么用**——三步框架：
```
分 Divide：   按某个中心/标准切成独立子问题（LC53 用 mid=(l+r)/2 切两半）
治 Conquer：  递归求解子问题（规模足够小就直接解 = 递归出口）
合 Combine：  把子问题的解合并成原问题的解（LC53 取三者最大值）
```

> ⚠️ 注意事项：判断能不能分治先问两句话——子问题独立吗？子问题的解能方便地合并吗？两问有一个"否"就得换思路（如最长公共子序列的子问题不独立，分治失效、要上 DP）。

> 🎯 规律：分治的复杂度账 = "分/合的代价 × 层数"——每层 O(n)、log n 层 → O(nlogn)；这个账在归并排序、快速排序、线段树里反复出现。

> 💡 一句话总结：分而治之，独立子问题。

### 4. 最大子数组和：一题三解看优化阶梯（LC53）

**是什么**：白话——在数组里找一段连续区间使和最大。课件给出三种解法：**暴力**枚举起点终点 O(n²)；**分治** O(nlogn)；**动态规划** O(n)（dp[i]=以第 i 个元素结尾的最大区间和，dp[i]=max(dp[i-1]+nums[i], nums[i])，答案 max(dp[i])，DP 细节预告第 27 章）。

**为什么**：分治的关键洞察——取中心点 m=(l+r)/2，最大区间**要么全在左边、要么全在右边、要么横跨中心**；左右两种和原问题同构（递归），横跨的不能递归（不独立），但它有特殊结构：必然包含 m 和 m+1——于是从中心往两边延伸，各自记录过程中的最大和 lmax、rmax，横跨最大区间和 = lmax+rmax（这一小步用的是**贪心**）。

**怎么用**——分治模板（`LC53.cpp`）：
```cpp
int maxxmid(vector<int>& nums, int l, int mid, int r)
{   // 横跨 mid 的最大区间和
    int lmax = INT_MIN, sum = 0;
    for (int i = mid; i >= l; i--)        // 含 mid 往左延伸
    {   sum += nums[i]; lmax = max(lmax, sum); }
    int rmax = INT_MIN; sum = 0;
    for (int i = mid+1; i <= r; i++)      // 不含 mid 往右延伸
    {   sum += nums[i]; rmax = max(rmax, sum); }
    return lmax + rmax;
}
int maxxans(vector<int>& nums, int l, int r)
{
    if (l == r) return nums[l];           // 出口：单元素
    int mid = (l + r) / 2;
    int a1 = maxxans(nums, l, mid);       // 左
    int a2 = maxxans(nums, mid+1, r);     // 右
    int a3 = maxxmid(nums, l, mid, r);    // 横跨
    return max(max(a1, a2), a3);          // 合并
}
```
跟算：nums=[-2,1,-3,4,-1,2,1,-5,4]，顶层 l=0, r=8, mid=4（nums[4]=-1）：
```
左延（从-1往左）：-1 → -1+4=3 → +(-3)=0 → +1=1 → +(-2)=-1
                 过程最大 lmax=3（区间[4,-1]）
右延（从2往右）：2 → 2+1=3 → -5+3=-2 → 4-2=2
                 过程最大 rmax=3（区间[2,1]）
横跨最优 = 3+3 = 6（区间 4,-1,2,1）
左右递归最终也给出 6（区间[3..6]）→ 答案 6 ✓
```
DP 跟算（对照）：dp=[-2, 1, -2, 4, 3, 5, 6, 1, 5]，max=6 ✓——三解法答案一致，复杂度 O(n²)→O(nlogn)→O(n) 逐级下降。

> ⚠️ 注意事项：lmax 从 mid 开始（含）、rmax 从 mid+1 开始（不含），保证横跨区间不与左右递归重复计数；lmax/rmax 初值 INT_MIN，防止全负数组误得 0；暴力枚举在 n 大时会超时，分治是面试常考的"中间档"。

> 🎯 规律：区间问题分治的经典三分法——"在左、在右、跨中线"；跨中线的情形必含中线端点，用一次线性扫描（贪心延伸）合并，整套骨架可搬到"最大子段乘积""区间计数"等题。

> 💡 一句话总结：左、右、跨中，三取最大。

## 🔍 相似概念辨析

**组1：递归 vs 分治**

| 对比维度 | 递归 | 分治 |
|---|---|---|
| 各自定义 | 函数定义中使用函数自身；重复分解为同类子问题 | 分而治之：分成独立子问题，解的合并=原问题的解 |
| 核心区别 | 编程技巧、解决问题的思维方式 | 基于递归的具体算法思想（课件原话） |
| 各自特点 | 只管"出口+递归式"，不管子问题是否独立 | 额外要求子问题独立 + 可合并（最优子结构） |
| 使用场景 | 一切自相似问题（汉诺塔、树遍历） | 子问题独立的规模缩减（LC53、归并排序） |
| 典型示例 | move() 调用 move() | maxxans() 把区间切成两半 |
| 记忆口诀 | 递归是手，分治是棋谱 |

**组2：分治 vs 枚举（LC53 的两种解法）**

| 对比维度 | 分治（LC53 解法2） | 枚举（LC53 解法1） |
|---|---|---|
| 各自定义 | 取 mid 切半，左/右/横跨三类递归讨论 | 枚举起点和终点，逐区间求和取最大 |
| 核心区别 | 子问题解可复用，O(nlogn) | 所有区间重算一遍，O(n²) |
| 各自特点 | 需设计"横跨"的合并方式 | 直白无脑，n 大必超时 |
| 使用场景 | n 大 + 有最优子结构 | n 小对拍、或作为理解问题的起点 |
| 典型示例 | n=2×10^4 轻松通过 | n=10^4 就要算 5×10^7 次 |
| 记忆口诀 | 枚举全试慢，分治砍一半 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**问题规模大到没法直接处理（痛点）→ 发现"n 层解"能用"n-1 层解"拼出来（自相似）→ 写出递归式+出口，把展开工作丢给计算机（递归三要素）→ 子问题若相互独立，还能按层数账复杂度 O(nlogn)（分治成立条件）→ 分治真正难在"合并"一步，横跨中心的情形要用局部规律单独构造（LC53 的 lmax+rmax）**。递归管"怎么缩小"，分治管"怎么切+怎么合"，两者是技巧与思想的关系。

跨知识点共性：
1. **与第八章贪心互相补位**：LC53 分治里"横跨中心"恰是用贪心（两侧延伸取最大）解决的——分治管结构切分，贪心管局部最优，一道题里两思想协作。
2. **与第六章快速幂同源的"减半"**：快速幂指数每轮除 2、分治区间每层切一半——"规模减半 → log 层 → 复杂度乘 log"是倍增家族的共同账本。
3. **向后铺垫**：LC53 的 DP 解法（dp[i]=max(dp[i-1]+nums[i], nums[i])）是第 27 章线性 DP 的第一块积木；归并排序、树与图的遍历（第 13、15、16 章）全部运行在递归框架上。

## 📋 速查表

| 模板 | 复杂度 | 适用条件 |
|---|---|---|
| 递归三要素骨架 | 视问题而定 | 自相似+有出口；参数趋向出口 |
| 汉诺塔 move(s,e,h) | O(2^n-1) 步 | n-1 个打包成整体，三步走 |
| 分治"左/右/跨中" | O(nlogn) | 子问题独立+可合并（LC53） |
| 跨中线性扫描合并 | O(r-l) | 合并项必含中线端点 |
| 暴力枚举区间 | O(n²) | n 小或对拍验证 |

```cpp
// 分治骨架（默写级）
int solve(int l, int r) {
    if (l == r) return 基准值;              // 出口
    int mid = (l + r) / 2;
    int a1 = solve(l, mid);                 // 治：左
    int a2 = solve(mid + 1, r);             // 治：右
    int a3 = 合并特有情形(l, mid, r);       // 合：如 lmax+rmax
    return max({a1, a2, a3});
}
```
