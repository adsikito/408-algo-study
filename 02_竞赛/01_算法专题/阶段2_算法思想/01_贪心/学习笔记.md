> 课件来源：`8.贪心.pptx`

> 例题代码：`例题代码\P1090.cpp`（合并果子）、`P4995.cpp`（跳跳！）、`LC2611.cpp`（老鼠和奶酪）

## 🗺️ 本章地图

本章学一种决策思想：像"贪心的人"做选择——每一步都拿眼前最优，绝不回头。课件定义它为"多步决策 + 每步局部最优"，并警告：局部最优不保证全局最优，用贪心必须能证明正确性。路线是"一种思想 + 两件工具 + 三种贪法"：先掌握贪心的适用特征与证明意识（知识点 1）；P1090 学"反复取最小"配优先队列（2）；P4995 学"排序后高低交替"（3）；LC2611 学"基准方案 + 差值排序选前 k"（4）。

## 📌 本章重点

⭐ **贪心的题型信号**：求最值 + 过程可分步 + 每步局部最优能拼出全局最优（要能说清理由）
⭐ **合并果子**：每次合并当前最小的两堆 → 优先队列（小根堆）O(nlogn)；每次重排的暴力 O(n²logn) 超时
⭐ **priority_queue 用法**：默认大根堆；小根堆写 `priority_queue<int,vector<int>,greater<int>>`（基于堆实现）
⭐ **排序后贪心两种姿势**：P4995 高低交替最大化相邻差；LC2611 差值排序取前 k 大

## 🔥 本章难点

🔥 **贪心策略的证明**：为什么"每次合并最小两堆"总代价最小？（不证明就想当然，换道题就翻车——课件强调"使用贪心法要确保能证明其正确性"）
🔥 **P4995 高低交替序列的实现**：排序后 l=0、r=n 双端交替取值，两次累加的先后（先跳最高再 l++ 再跳最低再 r--）极易写错，必须手推一遍

## ⚠️ 本章易错点

⚠️ **想当然贪心不验证**：贪心只在"局部最优=全局最优"的题里正确；换个指标就错，做题先问"能不能证明/举不出反例"
⚠️ **P1090 用"每次合并后 sort"**：排序 O(nlogn) 要排 n-1 次，总 O(n²logn) 超时；反复"取最值+插回新值"应换优先队列
⚠️ **小根堆写法记错**：`priority_queue<int>` 默认大数优先；要小数优先必须写全三个模板参数 `priority_queue<long long,vector<long long>,greater<long long>>`
⚠️ **P4995 忘了地面**：第一跳从地面（高度 0）起跳，必须 `h[0]=0` 且对 n+1 个元素整体 sort，否则第一段体力漏算
⚠️ **ans 开 int**：P1090 的总代价可达所有果子之和的量级，必须 long long（例题代码 `long long ans,x,y`）

## 📖 知识点讲解

### 1. 贪心：每步拿眼前最优，不回头

**是什么**：白话——用计算机模拟一个"贪心的人"：每一步行动按某种指标选当前最优的操作，目光短浅、只看眼前、绝不反悔。课件定义：贪心法把一个最优决策过程变成**多步决策**过程，每步做出**当前看来最好**的选择；它不从全局最优考虑，所做的只是**局部最优**选择——所以并非所有时候都能得到最优解，使用时必须确保能证明其正确性。

**为什么**：很多最值问题（合并、跳跃、分配）全局搜索量爆炸，但若能找到一条"每步最优 ⇒ 全局最优"的指标，就能一遍扫完；贪心代码短、复杂度低，代价是**策略要自己想、正确性要自己证**。

**怎么用**——三步套路：
1. **识别题型信号**：求最值问题 + 过程可拆成多步（课件："题型：求最值问题；分步 + 局部最优"）；
2. **定贪心指标**：每一步"按什么选最优"？本章三题的指标分别是——每次合并**最小**的两堆（P1090）、每次跳**差值最大**的一步（P4995）、每次换**增益最大**的一块奶酪（LC2611）；
3. **证明/验证**：交换论证（换任何别的选法都不更优）或举反例自查；实现上常配合**排序**或**堆**。

> ⚠️ 注意事项：贪心错了不报错、只 WA——三个例题的指标换错一个就全盘皆输，比如 P4995 改成"每次跳最近的石头"总体力立刻变小。

> 🎯 规律：见"分步做决策 + 求最值 + 每步选择互不影响后效"先想贪心；证明靠交换论证——最优解里相邻两步交换后不亏，指标就站得住。

> 💡 一句话总结：分步取局部最优，敢贪须能证明。

### 2. 合并果子与优先队列（P1090）

**是什么**：白话——n 堆果子每次花"两堆之和"的体力合并两堆，求最小总体力；贪心指标：**每次合并当前最小的两堆**（课件：要使总体力最小，每次合并的体力值应尽可能小）。小堆早合并会被反复"记费"，所以越小的越要先合并。

**为什么**：暴力"每次合并后重新排序（升序），取最前两个"——排序 O(nlogn) 要排 n-1 次，总 O(n²logn) 超时；优先队列基于堆实现，取最小 O(logn)、插入 O(logn)，总 O(nlogn)。

**怎么用**——STL 与模板（`P1090.cpp`）：
```cpp
priority_queue<int> q;                                  // 默认：大数优先（大根堆）
priority_queue<int, vector<int>, greater<int>> q;       // 小数优先（小根堆）✓ 本题用
#include <queue>

int main()
{
    cin >> n;
    for (i=1..n) { cin >> x; q.push(x); }               // 全部入队
    for (i=1; i<n; i++)                                 // 共合并 n-1 次
    {
        x = q.top(); q.pop();                           // 最小
        y = q.top(); q.pop();                           // 次小
        ans += x + y;                                   // 这一次的体力
        q.push(x + y);                                  // 新堆回队
    }
    cout << ans;
}
```
跟算：4 堆 {1,2,5,9}：
```
取 1,2 → 费 3，剩 {3,5,9}
取 3,5 → 费 8，剩 {8,9}
取 8,9 → 费 17，剩 {17}
总 3+8+17 = 28
反例（先合大堆）：9+5=14 → 14+2=16 → 16+1=17 → 47 > 28 ✗
```
每个数被合并的次数=它在"合并树"里的深度，越小的数放得越深被加得越多——这就是"小堆先合"的正确性直观。

> ⚠️ 注意事项：大根堆是默认形态，小根堆的三个模板参数必须写全；ans 用 long long；n-1 次循环别写成 n 次（最后一次只剩一堆，无意义还可能 RE）。

> 🎯 规律：反复"取最值 + 插回新值"→ 优先队列；哈夫曼编码的带权路径长与本模型完全同构。

> 💡 一句话总结：反复取最小，交给小根堆。

### 3. 跳跳！：排序后高低交替（P4995）

**是什么**：白话——跳到不同高度的花费是高度差平方，要总花费最大，就每一步都跳"差最远"的：课件策略——**先跳最高，再跳最低，再跳次高，再跳次低……**排序后两端交替。

**为什么**：差值平方对"大差"有放大效应（差 6 的平方 36 远超差 2+差 4 的 4+16=20），所以把最大差、次大差……逐个吃掉才最赚；排序后最大差在"最低↔最高"之间，次大差在"最低↔次高"或"次低↔最高"之间，交替跳正好全吃到。

**怎么用**——模板（`P4995.cpp`）：
```cpp
h[0] = 0;                    // 地面高度 0，第一跳从地面起！
sort(h, h + n + 1);          // n+1 个元素整体排序
int l = 0, r = n;
long long ans = 0;
while (l < r)
{
    ans += (h[r]-h[l]) * (h[r]-h[l]);   // 跳向当前最高
    l++;                                // 低位用掉一个
    ans += (h[r]-h[l]) * (h[r]-h[l]);   // 跳向当前最低
    r--;                                // 高位用掉一个
}
```
跟算：n=3，h={1,3,5}，地面 0 → sort 后 [0,1,3,5]：
```
l=0,r=3: 0→5，费 (5-0)²=25；l=1
l=1,r=3: 5→1，费 (5-1)²=16；r=2
l=1,r=2: 1→3，费 (3-1)²=4；l=2 → l==r 结束
总 25+16+4 = 45（跳跃路径：地面→5→1→3）
```

> ⚠️ 注意事项：`h[0]=0` 必须在 sort 之前写、且 sort 范围是 h+h+n+1；n 为 1 时第一轮就是"0→唯一石头"一步完成。

> 🎯 规律：求"相邻差/相邻代价"的最值 → 排序后大数小数交错排（最大-最小-次大-次低……），双端指针 l/r 交替取。

> 💡 一句话总结：排序完，高低高低跳。

### 4. 老鼠和奶酪：基准方案 + 差值排序（LC2611）

**是什么**：白话——两只能各吃 k 块与 n-k 块奶酪，得分不同；先让 2 号"全包"，再把其中 k 块"改判"给 1 号，改判第 i 块的净赚额是差值 r1[i]-r2[i]，把**差值最大的 k 块**改给 1 号即可（课件思路）。

**为什么**：直接枚举"哪 k 块给 1 号"是组合爆炸；引入基准方案（全给 2 号，总得分 sum2）后，任何方案都可以写成 sum2 + 若干差值之和，选 k 块的问题就变成"从 n 个差值里挑最大的 k 个"——排序解决。

**怎么用**——模板（`LC2611.cpp`）：
```cpp
int miceAndCheese(vector<int>& reward1, vector<int>& reward2, int k)
{
    int n = reward1.size();
    vector<int> d(n);
    int ans = 0;
    for (int i = 0; i < n; i++)
    {
        d[i] = reward1[i] - reward2[i];   // 改判第 i 块的增益
        ans += reward2[i];                // 基准：全给 2 号
    }
    sort(d.begin(), d.end());
    for (int i = n-1; i >= n-k; i--)      // 差值最大的 k 个
        ans += d[i];
    return ans;
}
```
跟算：r1=[2,1,3,4]，r2=[3,2,1,2]，k=2：
```
差值 d = [-1, -1, 2, 2]，基准 sum2 = 3+2+1+2 = 8
排序后取前 2 大：2 + 2 = 4
答案 8 + 4 = 12
验证：1 号吃第 3、4 块（3+4），2 号吃第 1、2 块（3+2）→ 12 ✓
```

> ⚠️ 注意事项：差值可能为负，k 接近 n 时也得选（"最大的负差值"损失最小）——排序取前 k 大天然处理了这种情况；本题用 sort 即可，数据更大时可用 nth_element 或堆。

> 🎯 规律："先给一个基准方案 + 按改选增益排序选前 k"——把组合选择压成排序问题，是"反悔/替换"类贪心的雏形（后续作业调度、任务分配同款）。

> 💡 一句话总结：先全给一方，按差值换 k 个。

## 🔍 相似概念辨析

**组1：贪心 vs 枚举（第一章）**

| 对比维度 | 贪心 | 枚举 |
|---|---|---|
| 各自定义 | 多步决策，每步按指标取局部最优、不回头 | 把答案/方案集合一一尝试，验证条件 |
| 核心区别 | 只走一条路，赌"局部最优=全局最优" | 全部走一遍，天然全局最优 |
| 各自特点 | 快（常 O(nlogn)），但要证明正确性 | 慢（O(方案总数)），但绝不选错 |
| 使用场景 | 能证明指标正确时（P1090 合并果子） | 数据范围小、方案可数时（P1003 找地毯） |
| 典型示例 | 每次合并最小两堆 | 二重循环枚举所有区间 |
| 记忆口诀 | 枚举保平安，贪心快但须证明 |

**组2：优先队列 vs 每次重新排序（P1090 的两种实现）**

| 对比维度 | 优先队列（堆） | 每次合并后排序 |
|---|---|---|
| 各自定义 | 基于堆的容器，最高优先级先出（课件） | 每轮用 sort 把序列排成升序再取前两个 |
| 核心区别 | 取最值/插入各 O(logn)，堆序不全排 | 每轮 O(nlogn) 全排序，只为拿两个最小 |
| 各自特点 | `greater<int>` 小根堆三参数写全 | 思路直白，n 稍大必超时 |
| 使用场景 | 反复取最值+插回：P1090 O(nlogn) | 只取一次最值、或 n≤10³ 的小数据 |
| 典型示例 | 合并果子 n-1 次取双最小 | 同题 TLE：O(n²logn) |
| 记忆口诀 | 反复取最值，排序换堆 |

## 🧩 本章归纳：一条主线串全章

主线因果链：**求最值 + 分步决策（题型）→ 每步定一个"贪心指标"（思想）→ 指标是否成立决定对错（证明意识）→ 实现上，能一遍排好序就 sort（P4995、LC2611），要反复取最值+插回就上堆（P1090）**。三个例题共享同一句潜台词：把"选哪 n 个/怎么选"翻译成"每次按 xx 指标选 yy"。

跨知识点共性：
1. **与第一章打表取模同理的"预处理"**：排序/建堆都是预处理，把"每次现找最优"变成"每次 O(logn) 取现成最优"——预处理换查询，是算法提速的万能思路。
2. **与第六章快速幂同源的"局部拼全局"**：快速幂的每一位二进制独立决定收不收集，贪心的每一步独立决定选不选——两者都靠"子决策互不拖累"把全局问题拆成局部问题。
3. **向后铺垫**：第九章 LC53 的"横跨中心"情形用贪心两侧延伸求解；第十一章优先队列再登场；后面区间调度、哈夫曼树全是本章"排序+指标"套路的变体。
