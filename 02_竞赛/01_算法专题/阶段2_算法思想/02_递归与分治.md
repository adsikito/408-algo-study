## 本章地图

本章解决一个问题：**「问题太大，怎么让「更小的自己」替你干活？」**

```text
原问题规模 n
   ├─ 能否拆成几个「同型的小问题」+「合并」？
   │     ├─ 拆 2 份、合 O(n)  → T(n) = 2T(n/2) + O(n) = O(n log n)（归并 / 逆序对）
   │     ├─ 拆 1 份、合 O(1)  → T(n) = T(n/2) + O(1) = O(log n)（二分）
   │     └─ 拆 4 份、合 O(1)  → T(n) = 4T(n/2) + O(1) = O(n²)（棋盘覆盖）
   ├─ 子问题独立吗？
   │     ├─ 独立   → 放心分治
   │     └─ 重叠   → 别分治，转 DP（附录 C 提示）
   └─ 自相似结构（表达式 / 图形）→ 递归构造（知识点 4）
   ↓
三段式落地：终止 → 分 → 治 → 合
```

**为什么这条路径是这样**：分治的收益来自**「合并比直接求解便宜」**——
归并的合并 O(n) 便宜于找逆序对 O(n²)。
**判断分治值不值，就是比较「合并的成本」与「直接解的成本」**，
这也是递归式里那个 O(n^d) 的真实含义。

## 核心概念与模板

**是什么**：
- **递归** = 函数调用自身（终止条件 + 更小的同类子问题）。
- **分治** = 递归的工程化三步：**分**（切成独立子问题）、**治**（递归解子问题）、**合**（合并结果）。

**为什么**：复杂度由递归式决定：T(n) = 2T(n/2) + O(n) → O(n log n)（归并）；
T(n) = T(n/2) + O(1) → O(log n)（二分）。

> **【规律】** **分治的收益 = 「合并比直接解便宜」。**
> 归并的合 O(n) 便宜于直接找逆序对的 O(n²)——这一句话判断所有分治值不值。

**怎么用**：

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;

/* 归并排序：分治的标准形状（分-治-合） */
void mergeSort(int a[], int lo, int hi, int *tmp) {
    if (lo >= hi) return;                    /* 终止：单元素 */
    int mid = (lo + hi) / 2;                 /* 分 */
    mergeSort(a, lo, mid, tmp);              /* 治 */
    mergeSort(a, mid + 1, hi, tmp);
    inplace_merge(a + lo, a + mid + 1, a + hi + 1);  /* 合 */
}

/* 逆序对计数：归并时顺带统计（分治的附加产出） */
long long cnt = 0;
void mergeCount(int a[], int lo, int hi, int *tmp) {
    if (lo >= hi) return;
    int mid = (lo + hi) / 2;
    mergeCount(a, lo, mid, tmp);
    mergeCount(a, mid + 1, hi, tmp);
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi)
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else { tmp[k++] = a[j++]; cnt += mid - i + 1; }  /* 右小跨左：逆序对 */
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi)  tmp[k++] = a[j++];
    for (int t = lo; t <= hi; t++) a[t] = tmp[t];
}

/* 快速幂：递归版（更直观的分治） */
long long qpow(long long a, long long b, long long p) {
    if (b == 0) return 1 % p;
    long long half = qpow(a, b / 2, p);
    long long r = half * half % p;
    return (b & 1) ? r * a % p : r;
}
```

> **【类比】** 分治像**公司组织架构**：大项目拆给两个部门（分），
> 部门内部再层层拆解（治），最后开合并会汇总（合）。
> **合并会（合）开得贵不贵，决定这套架构值不值**——
> 如果各部门的结果必须反复交叉核对（子问题重叠），那该改用「查备忘录」（DP）。

## 本章难点

> **【难点】** **「合」的过程中统计信息（逆序对）。**
> 计数发生在**归并的交叉处**：右半的元素先于左半剩余元素出列时，
> 它与左半剩余的**每一个**都构成逆序对，所以一次加 `mid − i + 1`——
> 不是数「对」，而是数「一段」。理解这一点，CDQ 分治等进阶形态才学得动。

> **【难点】** **递归深度的工程判断。**
> 归并深度 log n ≈ 20 安全；线性递归（如链表遍历）深度 n = 10⁵ 必爆栈。
> **判据：深度 × 每层栈帧大小 vs 栈空间（默认约 1 MB）**——
> 过深改迭代、显式栈，或编译时加 `ulimit` / 开线程栈。

---

## 本章易错点

> **【头号易错】** **递归无终止或参数不收缩**——爆栈 / 死循环；
> 递归深度 n 级时栈溢出。**每个递归函数写下前先答「参数怎么变小」。**

> **【易错】** **「合」写错方向**：归并的稳定条件是 `a[i] <= a[j]` 取左——
> 写成 `<` 会破坏稳定性并让逆序对计数翻倍。

> **【易错】** **计数不用 `long long`**：n = 5×10⁵ 的逆序对最坏 1.25×10¹¹，`int` 必炸。

> **【易错】** **棋盘覆盖的中央 L 与虚拟缺格不互斥**——递归参数错位后，
> 错误会指数放大到整张棋盘。

> **【易错】** **子问题重叠仍硬分治**（朴素斐波那契）——指数级复杂度，
> 应转记忆化 / DP。

## 典型例题

### 例 1　逆序对计数（分治附加产出）　难度：变式题

**题干摘要**：n ≤ 5×10⁵，求逆序对数。暴力 O(n²) 必炸。
**题源**：同类真源见配套练习 T1（P1908 逆序对）
**涉及知识点**：知识点 3

**解题思路**：

1. **信号**：「逆序对」+ n 大 → 归并计数（或树状数组，阶段 8 对照）。
2. **方法**：归并排序，「合」的交叉处右半元素出列时累计 `mid − i + 1`。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
const int N = 500005;
int a[N], tmp[N];
long long cnt = 0;

void mergeCount(int lo, int hi) {
    if (lo >= hi) return;
    int mid = (lo + hi) / 2;
    mergeCount(lo, mid);
    mergeCount(mid + 1, hi);
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi)
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else { tmp[k++] = a[j++]; cnt += mid - i + 1; }  /* 右小跨左 */
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi)  tmp[k++] = a[j++];
    for (int t = lo; t <= hi; t++) a[t] = tmp[t];
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    mergeCount(1, n);
    printf("%lld\n", cnt);
    return 0;
}
```

**复杂度**：时间 O(n log n)，空间 O(n)。

> **【易错】** 计数用 `long long`；相等元素不算逆序（`<=` 取左）——
> 两处合起来才是完整正确性。

### 例 2　棋盘覆盖（分治构造）　难度：综合题

**题干摘要**：2ᵏ × 2ᵏ 棋盘缺一格，用 L 形骨牌铺满其余格，输出方案。
**题源**：分治构造经典（构造型递归的标准形状）
**涉及知识点**：知识点 2、4

**解题思路**：

1. **信号**：自相似分解 + 「构造方案」→ 分治构造。
2. **方法**：十字切四份；**用一块 L 骨牌盖住中央三角**，
   使三份无缺陷的子棋盘各「获得」一个虚拟缺格——递归到 2×2。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
int board[130][130], tile = 0;

void cover(int r, int c, int dr, int dc, int size) {
    /* (r,c) 左上角，(dr,dc) 缺格，size 边长 */
    if (size == 2) {
        tile++;
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++)
                if (r + i != dr || c + j != dc)
                    board[r + i][c + j] = tile;
        return;
    }
    int s = size / 2, id = ++tile;
    int mr = r + s, mc = c + s;
    /* 中央 L：盖住不含缺格象限的三个内角 */
    int dq1 = (dr < mr && dc < mc);      /* 缺格在左上象限？ */
    int dq2 = (dr < mr && dc >= mc), dq3 = (dr >= mr && dc < mc), dq4 = (dr >= mr && dc >= mc);
    if (!dq1) board[mr - 1][mc - 1] = id;
    if (!dq2) board[mr - 1][mc] = id;
    if (!dq3) board[mr][mc - 1] = id;
    if (!dq4) board[mr][mc] = id;
    cover(r, c, dq1 ? dr : mr - 1, dq1 ? dc : mc - 1, s);
    cover(r, mc, dq2 ? dr : mr - 1, dq2 ? dc : mc, s);
    cover(mr, c, dq3 ? dr : mr, dq3 ? dc : mc - 1, s);
    cover(mr, mc, dq4 ? dr : mr, dq4 ? dc : mc, s);
}
```

**复杂度**：T(n) = 4T(n/2) + O(1) = O(n²)，空间 O(n²)。

> **【易错】** 中央 L 的三格必须与「含缺格象限」的虚拟缺位严格互斥，
> 否则递归参数错位。

## 本章总结

### 核心内容（一页纸）

1. **递归三要素**：终止条件、参数收缩、（分治的）合并语义——写下前先答三问。
2. **分治三段式**：分、治、合；复杂度看递归式 T(n) = aT(n/b) + O(n^d)。
3. **分治的收益 = 「合并比直接解便宜」**——归并的合 O(n) 便宜于 O(n²)。
4. **逆序对计数在归并交叉处**：右半元素出列时加 `mid − i + 1`（数「一段」不是数「对」）。
5. **稳定归并取左用 `<=`**——写成 `<` 破坏稳定性且计数翻倍。
6. **计数用 `long long`**：5×10⁵ 的逆序对上限 ≈ 1.25×10¹¹。
7. **递归深度 × 栈帧 vs 栈空间**：n 级深度必爆栈，改迭代或显式栈。
8. **递归构造**（幂次方）：自相似结构的终止点选「最小表达单元」。
9. **平面最近点对**：按 x 切分 + 带状区按 y 归并 + 只查 7 邻居。
10. **子问题重叠就转 DP**——「独立」是分治的入场券。
