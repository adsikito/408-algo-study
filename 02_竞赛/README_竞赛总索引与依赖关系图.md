## 一、本分类包含什么

`02_竞赛` 是**竞赛相关的全部笔记**的唯一归属地，内含两个并列子分类：

| 子分类 | 内容 | 笔记数 | 素材来源 |
|--------|------|-------|---------|
| `01_算法专题` | 算法集训 34 章，按知识依赖重排为八阶段 | 35 篇 | `资料\03_算法集训\` |
| `01_算法专题\_MOC_主题索引.md` | 笔记 × 素材章 × 知识点 × 题目的主题双向索引，四种检索路径 | 1 篇（八节，含改造进度） | 2026-09-13 建立 |
| `02_竞赛C++` | C++ 语言与 STL 能力，六大模块 | 7 篇（六模块 + `_MOC_知识点索引.md`）**已完成** | `资料\03_算法集训\` 例题代码、`资料\C++\C++基础篇\` |
| `03_题库` | 题目登记与题解代码，按阶段分组 | **189 道**（竞赛 124 + 408 真题 65，生产侧收官） | 洛谷、力扣、Codeforces、真题（无公开网址） |
| `99_附录` | 跨阶段的题源与速查总表 | 2 篇 | 汇总自上述三侧 |

> **【要点】** 前三者是**分工关系**：
> `01_算法专题` 回答「用什么算法」，`02_竞赛C++` 回答「怎么把代码写对写快」，
> `03_题库` 回答「用什么检验是否学会」。
>
> 三者的连接点是**知识点**：知识点归属某个笔记，同时被多道题考核。
> 完整关系见 `33_笔记题库知识点组织方案.md` 第二节。

### 四条关键前置依赖

这四条是原资料目录顺序中**看不出来**的依赖关系，必须显式遵守：

1. **阶段 3 并查集 → 阶段 5 Kruskal 最小生成树**
   并查集是 Kruskal 判环的唯一手段，不先学并查集则 Kruskal 无法实现。

2. **阶段 1 二分 → 阶段 5 堆优化 Dijkstra**
   二分答案与最短路结合是常见题型；且堆优化的边界处理依赖二分养成的边界直觉。

3. **阶段 3 二叉树 + 阶段 2 递归 → 阶段 7 树形 DP**
   树形 DP 的本质是「DFS 回溯时合并子树状态」，两个前置缺一不可。

4. **阶段 1 前缀和差分 → 阶段 8 树状数组差分改装**
   树状数组从「单点改」扩展到「区间改」，靠的正是差分思想。
