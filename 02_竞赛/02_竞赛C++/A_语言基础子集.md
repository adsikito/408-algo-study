## 零、本模块的取舍原则

**语言特性的取舍标准只有一条：它在赛场上能直接用上吗。**

C++ 的特性远多于竞赛所需。本模块刻意**只保留 11 个知识点**，把类与继承、虚函数与多态、模板元编程、异常处理、命名空间的组织艺术**全部划出**。

划出的依据不是「难」或「不重要」，而是**投入产出比**：

| 特性 | 划出理由 |
|------|---------|
| 类与继承、虚函数与多态 | 竞赛代码几乎不用继承体系；需要封装时 `struct` 足够 |
| 模板元编程 | 赛场上没有「编译期计算」的需求；手写几个模板函数就够 |
| 异常处理 | OJ 崩溃就是 RE，没有 `catch` 的机会；反而拖慢运行 |
| 命名空间的组织艺术 | 竞赛统一 `using namespace std;`，不需要设计 |

> **【重点】** 这不是「C++ 学习方法」，而是「**在 4 小时里写完 5 道题**所需的最小语言子集」。
> 本模块的每一个知识点，都能对应到一类具体的失分原因。

## 三、知识点逐讲

### A-1　整型范围与溢出　`P0`　熟练　`[未学]`

> **【重点】** 溢出是竞赛的头号隐性错误。它不报错、不崩溃，只是**答案悄悄变小或变负**。

**是什么**：每种整型能表示的数的范围是有限的，超出范围后结果会「绕回去」。

| 类型 | 字节 | 范围 | 赛场上够用吗 |
|------|------|------|------------|
| `int` | 4 | 约 ±2.1×10⁹（±2^31−1） | 只够存单个数 |
| `long long` | 8 | 约 ±9.2×10¹⁸（±2^63−1） | **竞赛默认选择** |
| `unsigned int` | 4 | 0 至 4.3×10⁹ | 只在按位处理时用 |
| `unsigned long long` | 8 | 0 至 1.8×10¹⁹ | 几乎只在哈希时用 |

**为什么**：`int` 的乘加运算都会在 `int` 里完成，**与接收结果的变量类型无关**。这是最反直觉的一点。

**怎么用**：

1. 看到「求和」「乘积」「路径数」三个信号词，直接把累加变量声明为 `long long`。
2. 乘法时在**最左边**乘一个 `1LL`，把整个表达式提升为 `long long`。
3. 判断「会不会溢出」，用这个公式：**最大值 × 最大值 × 项数 > 9.2×10¹⁸ 就必须换更大的类型**（而更大的类型只有 `__int128`，见【延伸】）。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

int main() {
    int a = 100000;                 // 10^5，int 能存
    int b = 100000;

    // 错误写法：a * b 先按 int 算，得 10^10 超出 int，已溢出，再赋给 long long 也救不回来
    long long bad = a * b;
    printf("错误写法：%lld\n", bad);   // 输出 1410065408（一个莫名其妙的数）

    // 正确写法：1LL 把整个表达式提升为 long long
    long long good = 1LL * a * b;
    printf("正确写法：%lld\n", good);  // 输出 10000000000

    // 另一种正确写法：先把一个操作数声明成 long long
    long long x = a;                  // 此时 x 是 long long
    printf("先提升：  %lld\n", x * b); // 输出 10000000000

    // 边界：n 项求和，n 最大 10^6，每项最大 10^9，总和最大 10^15
    //       10^15 < 9.2*10^18，long long 够用
    return 0;
}
```

> **【易错】** 「先定义成 `long long` 就不会溢出」是**错的**。
> 溢出发生在**计算过程中**，而 `int` 计算只看操作数类型。
> 下面三种写法只有后两种正确：
>
> ```cpp
> long long s1 = n * (n + 1) / 2;      // 错：n*(n+1) 在 int 里算完才提升
> long long s2 = 1LL * n * (n + 1) / 2; // 对：先提升
> long long s3 = (long long)n * (n + 1) / 2; // 对：强制转换
> ```
> 第 1 种在 n = 10⁵ 时结果无异常（因为 10⁵×10⁵ = 10¹⁰ 超了 int，实际会出错）。
> **这类 bug 在样例上不复现，只在评测的大数据上炸。**

> **【类比】** 溢出像汽车的里程表：跑到 999999 再加 1 公里，读数会变成 000000，
> 车没坏，表也没报错，但你不知道它已经跑过多少了。

> **【记忆】** **看见求和求乘积，先写 `1LL`。** 三个字符，省一次 WA。

**关联**

- `[后续]` 见 A-4 数组与多维数组。数组元素类型选小了同样会溢出。
- `[组合]` 与 A-2 运算符组合时，提升要写在**最左**，因为乘法左结合。
- `[易混]` 见 A-9 指针基础。`size_t` 是无符号类型，做减法会绕回巨大正数，是另一个隐蔽陷阱。
- `[延伸]` `__int128` 可表示约 ±1.7×10³⁸，GCC 支持但 `cin` / `cout` 不支持，需手写读写。
  超出 `long long` 的场景极少，遇到时优先考虑换算法（如取模运算）而非换类型。

### A-2　运算符与优先级　`P0`　熟练　`[未学]`

> **【重点】** 优先级写错不会报错，只会算错。**位运算与比较运算混用时，几乎一定需要括号。**

**是什么**：C++ 有约 50 个运算符，优先级分 15 级。竞赛只需要记住下面几条容易混淆的。

| 优先级 | 运算符 | 记忆点 |
|-------|--------|-------|
| 高 | `()` `[]` `.` `->` | 最高，无需担心 |
| ↓ | `!` `~` `++` `--` 一元负号 | 一元运算 |
| ↓ | `*` `/` `%` | 乘除取模同级，**从左到右** |
| ↓ | `+` `-` | 加减 |
| ↓ | `<<` `>>` | **移位** |
| ↓ | `<` `<=` `>` `>=` | 比较 |
| ↓ | `==` `!=` | 相等性 |
| ↓ | `&` | **按位与** |
| ↓ | `^` | **按位异或** |
| ↓ | `\|` | **按位或** |
| ↓ | `&&` | 逻辑与 |
| 低 | `\|\|` | 逻辑或 |

**为什么**：致命的三处是 —— **移位的优先级低于加减**、**按位运算低于比较**、**按位运算低于相等性**。

**怎么用**：

1. 只要一行里出现两类运算符（位运算类 + 算术/比较类），**无条件加括号**。
2. 判断奇偶**不要**写 `n & 1 == 0`，要写 `(n & 1) == 0`。
3. 位移**不要**写 `1 << k + 1`，要写 `1 << (k + 1)`。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

int main() {
    int n = 6, k = 2;

    // 错误：n & 1 == 0 实际是 n & (1 == 0)，即 n & 0，恒为 0，恒判为「偶数」
    printf("错误写法：%d\n", n & 1 == 0);    // 输出 0 —— 对 n=6 恰好也对，掩盖了 bug

    n = 7;                                    // 换成奇数，错误立刻暴露
    printf("错误写法：%d\n", n & 1 == 0);    // 输出 0（仍判为偶数，错）
    printf("正确写法：%d\n", (n & 1) == 0);  // 输出 0（7 是奇数，正确）

    // 错误：1 << k + 1 实际是 1 << (k + 1)，因为 + 比 << 优先级高
    printf("1<<k+1  = %d\n", 1 << k + 1);    // 输出 8（1 左移 3 位）

    // 想要两倍的 2^k，正确写法
    printf("1<<k<<1 = %d\n", 1 << k << 1);   // 输出 8 → 同结果，但过程符合直觉
    return 0;
}
```

> **【易错】** `n & 1 == 0` 在**偶数**上恰好给出正确结果，在**奇数**上给出错误结果。
> 这是最恶毒的一类 bug —— 小样例（往往是偶数）通过，大数据（含奇数）WA。
> **纪律：位运算出现在条件里，一律加括号。**

> **【类比】** 优先级像交通规则里的「让行顺序」。你不知道规则时，车照样能开，
> 只在路口才会撞——而竞赛的数据就是那个路口。

> **【记忆】** **位运算进条件，先套括号。** 括号不要钱。

**关联**

- `[前置]` 见 A-1。移位超过类型位宽是未定义行为，与溢出同源。
- `[后续]` 见 A-5 位运算。那种写法默认全程加括号。
- `[易混]` `&&` / `||` 有短路特性（左边为假则右边不执行），`&` / `|` 没有。**两者不能互换**。
- `[组合]` 与 A-11 宏组合时更危险：宏展开后无括号会吃掉外层运算，见 A-11。

### A-3　控制流　`P0`　熟练　`[未学]`

> **【重点】** 控制流的错误几乎全是**边界错一位**，而不是语法错。

**是什么**：`if` / `for` / `while` / `break` / `continue` 的组合，用于描述「按条件重复执行」。

**为什么**：竞赛代码 90% 的体积是循环。循环的**起止下标**和**终止条件**是失分最密集的地方。

**怎么用**：

1. 统一约定：**读入 1 起始的数据，循环从 1 到 n（含）**，用 `i <= n`。
2. 统一约定：**读入 0 起始的数据（`vector`、`string`），循环从 0 到 n-1**，用 `i < n`。
3. `break` 只跳出**最内层**循环；需要跳出多层时用标志位或 `goto`（竞赛中 `goto` 是可接受的）。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

int main() {
    int n = 5;

    // 写法一：1 起始（输入数组常用），闭区间 [1, n]
    int a[10] = {0, 10, 20, 30, 40, 50};
    long long sum1 = 0;
    for (int i = 1; i <= n; i++) sum1 += a[i];   // 边界：1 到 n 含两端
    printf("1 起始求和：%lld\n", sum1);           // 150

    // 写法二：0 起始（vector / string 常用），左闭右开 [0, n)
    int b[5] = {10, 20, 30, 40, 50};
    long long sum2 = 0;
    for (int i = 0; i < n; i++) sum2 += b[i];    // 边界：0 到 n-1
    printf("0 起始求和：%lld\n", sum2);           // 150

    // break 只跳出最内层：找出第一个和超过 100 的 (i, j)
    bool found = false;                          // 用标志位跳出两层
    for (int i = 0; i < n && !found; i++) {      // 边界：外层也要检查标志位
        for (int j = 0; j < n; j++) {
            if (b[i] + b[j] > 100) { found = true; break; }
        }
    }
    printf("找到两数和超 100：%d\n", (int)found);

    // continue 只跳过本次迭代
    int cnt = 0;
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) continue;                // 跳过 3 的倍数
        cnt++;
    }
    printf("非 3 的倍数个数：%d\n", cnt);         // 7
    return 0;
}
```

> **【易错】** 三类边界错误：
> 1. `i <= n` 与 `i < n` 混用 —— 前者对 1 起始正确、对 0 起始越界。
> 2. 循环内修改了循环变量的上界（如 `v.size()` 在循环里增长）—— 条件每次都重算。
> 3. 空循环体写成 `for (...) ;`，分号后跟了本该在循环内的语句。

> **【类比】** 循环的边界像切面包：`[1, n]` 是两头都切，`[0, n)` 是只切左边。
> 两种切法都能得到完整的面包，但**同一块面包不能混用两种切法**。

> **【记忆】** **1 起始用 `<=`，0 起始用 `<`。** 选定一种，全文统一。

**关联**

- `[前置]` 见 A-2 运算符与优先级。
- `[后续]` 见 A-4 数组与多维数组。循环边界与数组大小直接相关。
- `[易混]` `while(n--)` 与 `while(--n)` 差一次迭代，且前者在 n 为 `unsigned` 时会死循环。
- `[组合]` 与 A-8 递归组合：循环可以改写成递归，递归也可以改写成循环。

### A-4　数组与多维数组　`P0`　熟练　`[未学]`

> **【重点】** 数组**开小**是 RE 的首因。经验公式：**按题面上限的 1.1 倍开，且至少多开 5 个**。

**是什么**：一组连续存储的同类型元素；多维数组是「数组的数组」。

**为什么**：竞赛里数组开在**全局**（静态存储区，约 256 MB）而非函数内（栈，约 1–8 MB）。开在函数内的大数组会直接爆栈 RE。

**怎么用**：

1. **大数组一律开在 `main` 外面**（全局）。
2. 大小按题面上限，**加 5 到 10 的余量**（防越界一位）。
3. 需要「访问 `i-1` 和 `i+1`」的题目（如 DP、差分），下标从 1 开始，天然避开 `i-1 = -1`。
4. 多维数组的**最后一维变化最快**，循环顺序要与内存布局一致，否则缓存命中率下降。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

// 全局数组：在静态存储区，可开到 10^7 量级
const int MAXN = 100000 + 10;      // 边界：题面上限 10^5，加 10 的余量
int a[MAXN];                        // 一维，约 400 KB
long long pre[MAXN];                // 前缀和，注意用 long long 防溢出

// 二维：网格题常用，注意总元素数别超过内存
int grid[1005][1005];               // 约 4 MB，安全

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) a[i] = i;      // 边界：1 起始，避开 a[0]

    // 前缀和：pre[i] = a[1] + ... + a[i]
    for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + a[i];
    printf("区间 [2,4] 的和 = %lld\n", pre[4] - pre[1]);   // 2+3+4 = 9

    // 二维：行优先填充
    for (int i = 1; i <= 3; i++)
        for (int j = 1; j <= 3; j++)
            grid[i][j] = i * 10 + j;
    printf("grid[2][3] = %d\n", grid[2][3]);    // 23

    // 维度换算：一维数组模拟二维，网格题提速常用
    // 编号 = (i-1)*列数 + (j-1)，注意这里用的是 0 起始换算
    int cols = 3;
    int id = (2 - 1) * cols + (3 - 1);          // 对应 (2,3)
    printf("(2,3) 的一维编号 = %d\n", id);       // 4
    return 0;
}
```

> **【易错】** 三种数组相关的 RE：
> 1. **开小**。题面上限是 10⁶，只开了 10⁵ —— 小样例照过，大数据越界。
> 2. **局部大数组**。`int a[1000000];` 写在 `main` 里，栈放不下，直接 RE。
> 3. **二维开成 `[n][n]`**（变长数组）。有些 OJ 的编译器不接受非编译期常量作数组大小。

> **【类比】** 数组像停车位：连续编号，`a[i]` 就是第 i 个车位。
> 开小了是车位不够、车停到别人位上（越界）；开在栈上是临时停车区太小、停不下就塌了。

> **【记忆】** **全局 + 加 10 + 1 起始。** 三件事一起做，能消掉大半数组类 RE。

**关联**

- `[前置]` 见 A-1（元素类型）、A-3（循环边界）。
- `[后续]` 见 C-1 `vector`。`vector` 动态扩容，但每次扩容会重新分配，性能与手写数组不同。
- `[易混]` 数组名与指针的关系见 A-9。
- `[组合]` 与 A-9 位运算组合 → `bitset` 与状态压缩；与算法专题阶段 1 组合 → 前缀和与差分。

### A-5　位运算　`P0`　熟练　`[未学]`

> **【重点】** 位运算是**模块 C 的 `bitset`、模块 D 的 `__builtin_`、算法专题的树状数组与状压 DP**
> 四处的共同地基。跳过它，后面会连续卡四处。

**是什么**：直接对整数的二进制位做运算。

| 运算 | 符号 | 含义 | 典型用途 |
|------|------|------|---------|
| 按位与 | `a & b` | 两位都是 1 才得 1 | 取某一位、判断奇偶 |
| 按位或 | `a \| b` | 任意一位是 1 就得 1 | 置某一位为 1 |
| 按位异或 | `a ^ b` | 两位不同才得 1 | 翻转某位、消重 |
| 按位取反 | `~a` | 0 变 1，1 变 0 | 取反掩码 |
| 左移 | `a << k` | 左移 k 位，相当于乘 2^k | 构造掩码、快速乘 |
| 右移 | `a >> k` | 右移 k 位，相当于除以 2^k | 折半、取高位 |

**为什么**：位运算比除法取模快数倍，且**能表达「集合」**——一个整数可以存 64 个「有/没有」的状态。

**怎么用**：

1. 记住六个常用位操作的固定写法（见下表）。
2. 用 `1 << k` 表示「第 k 位为 1」的掩码。**记住 `1` 是 `int`，需要 32 位以上时要写 `1LL`**。
3. 判断、置位、清位、取位、翻转都写成小函数或宏，避免每次手写出错。

| 操作 | 写法 | 说明 |
|------|------|------|
| 判断第 k 位是否为 1 | `(x >> k) & 1` | 或 `x >> k & 1`（移位优先于与） |
| 把第 k 位置为 1 | `x \|= (1 << k)` | 或起来 |
| 把第 k 位清为 0 | `x &= ~(1 << k)` | 与上取反 |
| 翻转第 k 位 | `x ^= (1 << k)` | 异或 |
| 取最低位的 1（lowbit） | `x & -x` | 树状数组的核心 |
| 去掉最低位的 1 | `x &= x - 1` | 求二进制中 1 的个数 |

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

int main() {
    int x = 0b101100;                    // 二进制字面量 C++14 起支持，便于验证

    printf("判断第 3 位：%d\n", (x >> 3) & 1);   // 1
    printf("置第 0 位：  %d\n", x | (1 << 0));   // 45
    printf("清第 5 位：  %d\n", x & ~(1 << 5));  // 12+16=28
    printf("翻转第 2 位：%d\n", x ^ (1 << 2));   // 40

    // lowbit：取出最低位的 1 及其后面所有 0 组成的数
    printf("lowbit(44) = %d\n", x & -x);         // 4，因为二进制尾部是 100

    // 统计二进制中 1 的个数：每次去掉最低位的 1
    int t = x, cnt = 0;
    while (t) { t &= t - 1; cnt++; }
    printf("1 的个数 = %d\n", cnt);              // 3

    // 边界：1 是 int，超过 30 位要写 1LL
    // 边界：1 << 31 在 int 上是未定义行为（符号位），用 1LL << 31
    printf("1LL<<40 = %lld\n", 1LL << 40);
    return 0;
}
```

> **【易错】** 三处：
> 1. **`1 << k` 的 `1` 是 `int`**。`k >= 31` 时溢出，结果未定义。要写 `1LL << k`。
> 2. **负数右移**。`-1 >> 1` 在多数实现上是 `-1`（算术右移，补符号位），不是 0。**不要对有符号负数移位**。
> 3. **忘记括号**。`if (x & 1 == 0)` 是错的，见 A-2。

> **【类比】** 位运算像一整排电灯开关。按位与是「两个都按下的开关」，
> 按位或是「至少一个按下的」，异或是「状态不一样的那些」。
> 而 `1 << k` 就是「只把第 k 个开关拨上去」的动作。

> **【记忆】** **lowbit 就是 `x & -x`**，树状数组全靠它。

**关联**

- `[前置]` 见 A-1（位宽与类型）。
- `[后续]` 见 C-9 `bitset`（用位运算实现集合）、D-10 `__builtin_` 系列（编译器内置的位函数）。
- `[组合]` 与 A-7 结构体组合 → 状态压缩 DP；与算法专题阶段 8 组合 → 树状数组。
- `[延伸]` 位运算还能实现快速幂（见算法专题阶段 1）与状态压缩 DP（阶段 7）。

### A-6　函数与参数传递　`P0`　熟练　`[未学]`

> **【重点】** **大结构体、大数组传参一律用引用（`&`），否则每次调用都整体拷贝一次。**

**是什么**：函数把一段逻辑封装起来；参数传递分「传值」（拷贝一份）和「传引用」（传别名，不拷贝）。

| 传递方式 | 写法 | 是否拷贝 | 能否修改原值 |
|---------|------|---------|------------|
| 传值 | `void f(int x)` | 拷贝 | 不能 |
| 传引用 | `void f(int &x)` | **不拷贝** | **能** |
| 常量引用 | `void f(const int &x)` | **不拷贝** | 不能（只读） |
| 数组传参 | `void f(int a[], int n)` | 退化为指针，不拷贝 | 能 |

**为什么**：一个含 10⁵ 个元素的 `vector` 传值，每次调用都要复制 10⁵ 个元素。
若在循环里调用，总代价会从 O(n) 变成 O(n²)，直接把可通过的程序变成 TLE。

**怎么用**：

1. 基本类型（`int` / `double` / `char`）直接传值，简单不易错。
2. **结构体、`vector`、`string` 一律用 `const &`**（只读）或 `&`（要改）。
3. 数组传参必须**同时传长度**，因为数组在函数内退化为指针，`sizeof` 失效。
4. 递归函数如果修改全局数组，参数列表可以省掉数组，直接用全局的。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <vector>
using namespace std;

// 错误示范：传值，每次调用拷贝整个 vector
long long sumByValue(vector<int> v) {
    long long s = 0;
    for (int x : v) s += x;
    return s;
}

// 正确示范：常量引用，不拷贝
long long sumByRef(const vector<int> &v) {
    long long s = 0;
    for (int x : v) s += x;
    return s;
}

// 要修改原容器时用普通引用
void addOne(vector<int> &v) {
    for (int &x : v) x += 1;      // 这里 x 也必须是引用，否则改的是副本
}

// 数组传参：必须额外传长度
long long sumArray(int a[], int n) {   // a 在这里已退化为 int*
    long long s = 0;
    for (int i = 0; i < n; i++) s += a[i];   // 边界：靠外部传入的 n 控制
    return s;
}

int main() {
    vector<int> v = {1, 2, 3, 4, 5};
    printf("传引用求和：%lld\n", sumByRef(v));
    addOne(v);
    printf("加一后首元素：%d\n", v[0]);        // 2，证明引用生效

    int a[5] = {1, 2, 3, 4, 5};
    printf("数组求和：%lld\n", sumArray(a, 5)); // 靠 n=5
    return 0;
}
```

> **【易错】** 三处：
> 1. **范围 for 不加引用**。`for (int x : v) x++` 改的是副本，原容器不变。要写 `for (int &x : v)`。
> 2. **数组传参后用 `sizeof(a)/sizeof(a[0])` 求长度**。此时 `a` 是指针，结果恒为 2 或 1，不是元素个数。
> 3. **递归函数里传大结构**。递归 + 传值拷贝 = 指数级的时间与栈空间开销。

> **【类比】** 传值像把整本书复印一份给对方；传引用像把书的页码告诉对方，让他去看同一本。
> 书只有几页时复印无所谓，书有十万页时差别就是「能过」与「超时」。

> **【记忆】** **见过 `const &` 就放心用。** 大对象传参的默认答案。

**关联**

- `[前置]` 见 A-4 数组（退化）、A-1（返回类型范围）。
- `[后续]` 见 A-7 结构体（最需要引用传参的类型）、E-9 移动语义（更极致的避免拷贝）。
- `[组合]` 与 A-8 递归组合时，参数设计决定栈深度。
- `[易混]` `const &` 与 `&` 的区别是「能否修改」，前者不能改。

### A-7　结构体与自定义类型　`P0`　熟练　`[未学]`

> **【重点】** 结构体是「把相关数据绑在一起」的工具。**比较运算符重载是它配合 `set` / `map` / `sort` 的前提**，
> 见 E-8。

**是什么**：把多个不同类型的变量组合成一个新类型。

**为什么**：图论的边、DP 的状态、坐标点，都是「几个数一起用」。
用结构体后可以整体传递、整体排序、整体入队，代码量与出错率同时下降。
实测现有 75 个竞赛代码文件中 `struct` 出现 **37 次**，说明这个工具已经在用，但**没有配套的排序与比较写法**。

**怎么用**：

1. 定义时用 `struct`，成员默认 `public`（竞赛不需要 `class`）。
2. 构造函数可选；需要快速构造时写一个。
3. **要放进 `set` / `map` 或直接 `sort`，必须重载 `operator<`**。
4. 图论里的边，习惯写成「终点 + 权值」，或用 `to` / `w` 命名。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>
#include <algorithm>
using namespace std;

struct Edge {
    int to;         // 终点
    int w;          // 边权
    // 构造函数：方便写 Edge{1, 2}
    Edge(int t = 0, int ww = 0) : to(t), w(ww) {}
};

// 图论里更常见的写法：全局边数组 + 边数计数
const int MAXM = 100000 + 10;
struct RawEdge { int u, v, w; } e[MAXM];
int m = 0;

int main() {
    // 构造与访问
    Edge a(2, 7);
    printf("a.to=%d a.w=%d\n", a.to, a.w);

    // 整体赋值（同类型可直接拷）
    Edge b = a;
    b.w = 9;
    printf("b.w=%d（a.w 不受影响=%d）\n", b.w, a.w);

    // 全局边数组：读入 3 条边
    int data[3][3] = {{1, 2, 5}, {2, 3, 8}, {1, 3, 3}};
    for (int i = 0; i < 3; i++) {
        // 边界：边数组下标从 0 开始，共 m 条边
        e[m].u = data[i][0];
        e[m].v = data[i][1];
        e[m].w = data[i][2];
        m++;
    }
    printf("共 %d 条边，第 2 条的权 = %d\n", m, e[1].w);

    // 结构体排序需要比较规则：这里按权值升序
    // 用 lambda 就地写比较器（E-3），比单独定义函数更紧凑
    sort(e, e + m, [](const RawEdge &x, const RawEdge &y) {
        return x.w < y.w;      // 升序：小的在前
    });
    printf("按权排序后首条边权 = %d\n", e[0].w);   // 3
    return 0;
}
```

结构体重载 `operator<`（放 `set` / `map` 的必需前提）：

```cpp
struct Node {
    int x, y;
    // 先比 x，x 相同再比 y —— 这个顺序决定了「谁更小」
    bool operator<(const Node &o) const {   // 末尾 const 不能漏
        if (x != o.x) return x < o.x;
        return y < o.y;
    }
};
```

> **【易错】** 四处：
> 1. **`operator<` 漏了末尾的 `const`**。放进 `set` 时编译报一堆看不懂的错。
> 2. **比较规则不是严格弱序**。写 `return x <= o.x;` 会让 `set` 判定两个不同元素相等，导致丢元素。
>    **必须用 `<`，不能用 `<=`。**
> 3. **结构体数组开成局部变量**。与 A-4 同一个坑。
> 4. **用 `struct` 存 `bool` 标记**。`bool` 数组按字节存，`int` 才 4 字节，但 `bool` 也没做位压缩，
>    要位压缩请用 C-9 `bitset`。

> **【类比】** 结构体像一张表格的一行：姓名、年龄、分数各自是列，合起来是一条记录。
> `operator<` 就是「比大小的规则」——比身高还是比体重，由你定，但**必须定死且一致**。

> **【记忆】** **进 `set` 就要 `<`，且必须严格，不能用 `<=`。**

**关联**

- `[前置]` 见 A-4 数组、A-6 函数与参数传递。
- `[后续]` 见 E-8 运算符重载（完整的重载写法）、C-8 `map`（结构体作值）。
- `[组合]` 与 C-6 `priority_queue` 组合时，也可以用 `operator<` 反向定义「优先级」。
- `[易混]` 结构体传参是否需要引用，见 A-6。

### A-8　递归与递归深度　`P0`　理解　`[未学]`

> **【重点】** 递归爆栈是 RE 的次因。**递归深度超过约 10⁵ 时，必须警惕栈空间**。

**是什么**：函数调用自身。每次调用都会在栈上压入一帧（保存参数、局部变量、返回地址）。

**为什么**：栈的默认大小在多数环境是 1 MB 至 8 MB。一帧若占 100 字节，最多约 10⁴ 至 8×10⁴ 层。
**深度超过这个量级，程序直接 RE，且不给出任何提示。**

**怎么用**：

1. 先写**终止条件**（什么时候不再递归），再写递归体。顺序反过来极易漏掉终止。
2. 估算深度：**线性递归深度 = 数据规模**；**分治递归深度 = log₂(规模)**。
3. 深度可能达到 10⁵ 以上时，**改写成显式栈的迭代**，或在本地把栈调大（见下）。
4. 递归带返回值时，确认每一条分支都有 `return`（漏了会返回随机值）。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

// 例一：线性递归，深度 = n。n = 10^5 时已接近栈上限
long long fact(int n) {
    if (n <= 1) return 1;              // 终止条件写在最前
    return 1LL * n * fact(n - 1);      // 1LL 防溢出（A-1）
}

// 例二：改写为迭代，深度恒为 1，不受 n 限制
long long factIter(int n) {
    long long r = 1;
    for (int i = 2; i <= n; i++) r *= i;
    return r;
}

// 例三：分治递归，深度 = log2(n)
long long fastPow(long long base, long long exp) {
    if (exp == 0) return 1;            // 终止条件
    long long half = fastPow(base, exp / 2);
    if (exp & 1) return half * half * base;   // 注意括号：& 优先级低于 *
    return half * half;
}

int main() {
    printf("递归阶乘 20! = %lld\n", fact(20));
    printf("迭代阶乘 20! = %lld\n", factIter(20));
    printf("快速幂 2^30 = %lld\n", fastPow(2, 30));
    // 边界：fact(100000) 极可能爆栈，改 factIter 或手写快读式的迭代版本
    return 0;
}
```

本地放大栈空间（仅用于本地验证深度是否爆栈）：

```bash
# Windows MinGW：在编译时指定更高的栈大小（单位字节，这里给 256 MB）
g++ -std=c++17 -O2 -Wl,--stack=268435456 -o main main.cpp

# Linux：用 ulimit 放开
ulimit -s unlimited
```

> **【易错】** 四处：
> 1. **漏终止条件**，或终止条件写错（如 `if (n == 0)` 但实际只会走到 `n < 0`）→ 无限递归 RE。
> 2. **深度估错**。以为「递归比循环优雅」，结果在 10⁵ 的链式图 DFS 上爆栈。
> 3. **返回值分支不全**。`if` 里 `return`，`else` 分支忘了 → 返回未定义值。
> 4. **递归里拷贝大对象**。与 A-6 同一个坑，且递归会放大后果。

> **【类比】** 递归像叠盘子：每递归一层就多叠一个盘子。叠到 10 万个盘子必然倒。
> 迭代像把所有盘子摊在桌上——占地方，但不会倒。

> **【记忆】** **深度过万，先想迭代。** 递归不是免费的。

**关联**

- `[前置]` 见 A-6 函数与参数传递。
- `[后续]` 见算法专题阶段 2「递归与分治」、阶段 4「DFS」（DFS 深度 = 图的最长链）。
- `[易混]` 递归与递推（迭代）的区别：递归自顶向下，递推自底向上。
- `[组合]` 与 A-5 位运算组合的快速幂，是「分治递归深度低」的正面例子。

### A-9　指针基础　`P1`　会用　`[未学]`

> **【重点】** 竞赛里指针的场景很少。**只需要会「数组名即指针」和「引用是别名」两件事。**

**是什么**：指针是存放内存地址的变量；`*p` 取地址处的值，`&x` 取 x 的地址。

**为什么**：竞赛中指针几乎被三个东西替代了：**引用传参**（A-6）、**`vector` / `string`**（C-1、C-2）、
**下标访问**。但有一处绕不开：**链表、树、图如果用指针实现，必须会**。
不过更常见的做法是用数组模拟，所以指针的重要性被进一步压低。

**怎么用**：

1. 记住等价关系：`a[i]` 等价于 `*(a + i)`，所以**数组名可以当指针用**。
2. 需要修改外部变量时用**引用**（`int &x`），不要用指针。
3. 链表等结构**优先用数组模拟**（`nxt[]` 数组），避免 `new` 与内存管理。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

// 数组名作参数：退化为指针，这是唯一需要理解的指针用法
void addOneAll(int *a, int n) {
    for (int i = 0; i < n; i++) a[i] += 1;      // 等价于 *(a + i) += 1
}

int main() {
    int arr[5] = {1, 2, 3, 4, 5};

    // 三种等价写法
    printf("arr[2]     = %d\n", arr[2]);
    printf("*(arr+2)   = %d\n", *(arr + 2));
    int *p = arr;                                // 数组名即首元素地址
    printf("p[2]       = %d\n", p[2]);

    addOneAll(arr, 5);                           // 原数组被修改
    printf("加一后 arr[2] = %d\n", arr[2]);       // 4

    // 数组模拟链表：竞赛首选，无需指针与 new
    // nxt[i] 表示「i 的下一个节点」，0 表示空
    const int N = 5;
    int nxt[N + 1] = {0, 2, 3, 0, 5, 0};         // 1→2→3，4→5
    for (int cur = 1; cur != 0; cur = nxt[cur]) {
        printf("链表节点：%d\n", cur);            // 1 2 3
    }
    return 0;
}
```

> **【易错】** 三处：
> 1. **`delete` 之后继续用**（悬垂指针）。竞赛中用 `new` 就必然要管释放，建议干脆不用。
> 2. **指针未初始化就用**。野指针指向随机地址，行为不可预测。
> 3. **把 `&` 的两个含义搞混**：`int &r = x;` 是引用声明，`&x` 是取地址。

> **【类比】** 引用像「给同一个人起了个外号」——叫外号就是叫本人。
> 指针像「存了对方的家庭住址的小纸条」——纸条可能写错、可能过期。

> **【记忆】** **能引用就别指针，能数组模拟就别 `new`。**

**关联**

- `[前置]` 见 A-4 数组（退化关系）。
- `[后续]` 见 A-10 `const`（`const int *` 与 `int * const` 的区别）。

### A-10　`const` 与 `static`　`P1`　会用　`[未学]`

> **【重点】** `const` 在本模块的唯一用途是**防止常量被误改**；
> `static` 在竞赛中的唯一实用场景是**局部静态数组**（避免在栈上开大数组）。

**是什么**：`const` 表示「不可修改」，`static` 表示「生命周期贯穿全程、只初始化一次」。

| 用法 | 位置 | 效果 | 竞赛用途 |
|------|------|------|---------|
| `const int N = 1e5 + 10;` | 全局 | 编译期常量 | **指定数组大小的标准写法** |
| `const int &x` | 参数 | 只读引用（A-6） | 避免拷贝 |
| `const int MOD = 1e9 + 7;` | 全局 | 取模常量 | 取模题的必需 |
| `static int a[1000005];` | 函数内 | 数组移到静态区 | **函数内开大数组的救法** |
| `static` 局部变量 | 函数内 | 只初始化一次，跨调用保留 | 极少用 |

**为什么**：`const` 让「魔数」变成有名字的常量，改一处即可全改，且编译器能帮你查错。
`static` 解决一个具体问题：**函数内不能开大数组（栈不够），但又不想用全局变量污染命名空间**。

**怎么用**：

1. 数组大小、模数、无穷大一律定义成全局 `const`。
2. 需要在函数内开大数组时，加 `static`。
3. **`const` 变量不能用作运行时才能确定的数组大小**（那是变长数组，见 A-4 易错 3）。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

const int MAXN = 100000 + 10;          // 数组大小：标准写法
const int MOD  = 1000000007;           // 模数：1e9+7 取整，不要写浮点的 1e9+7
const int INF  = 0x3f3f3f3f;           // 无穷大：见下方【规律】

void useStaticArray() {
    // 局部大数组必须加 static，否则栈溢出
    static int buf[MAXN];               // 在静态存储区，安全
    for (int i = 0; i < MAXN; i++) buf[i] = i;
    printf("static 数组末尾：%d\n", buf[MAXN - 1]);
}

int main() {
    printf("MAXN=%d MOD=%d INF=%d\n", MAXN, MOD, INF);

    // INF 的妙处：两个 INF 相加仍不溢出 int
    printf("INF + INF = %d（%s）\n",
           INF + INF, (INF + INF > 0 ? "未溢出" : "已溢出"));

    // 取模运算别写成 (a + b) % MOD 而漏了负数的处理
    int a = -5, b = 3;
    printf("负数取模修正：%d\n", ((a + b) % MOD + MOD) % MOD);

    useStaticArray();
    return 0;
}
```

> **【规律】** 无穷大用 **`0x3f3f3f3f`**（约 1.06×10⁹），这是竞赛惯例。
> 理由：**两个 `0x3f3f3f3f` 相加仍小于 `int` 上限 2.14×10⁹**，所以松弛操作
> （`if (d[u] + w < d[v])`）不会因为 `INF + w` 溢出而误判。
> 相比 `1e9`（浮点字面量）与 `INT_MAX`（相加即溢出），它是最实用的选择。

> **【易错】** 三处：
> 1. **函数内直接开大数组不加 `static`** → 栈溢出 RE。
> 2. **用 `1e9 + 7` 定义 `int` 常量**。`1e9` 是 `double`，赋给 `int` 有精度隐患；写 `1000000007`。
> 3. **`const` 数组大小写成变量**：`int n; const int N = n; int a[N];` —— 这是变长数组，部分 OJ 不支持。

> **【类比】** `const` 像把值刻在石头上，`static` 像给变量发一张「终身通行证」——
> 出了函数也不销毁，下次进来还是上一次的值。

> **【记忆】** **无穷大用 `0x3f3f3f3f`。** 加两次不溢出。

**关联**

- `[前置]` 见 A-7 结构体（`const` 成员函数）。
- `[后续]` 见 F-1 比赛代码模板（`const` 常量集中定义）。
- `[组合]` 与算法专题阶段 5 组合时，`INF` 是 Dijkstra 的必需常量。
- `[易混]` `const int*` 是「指向常量的指针」，`int* const` 是「常量指针」，前者更常用。

### A-11　宏与预处理　`P1`　熟练　`[未学]`

> **【重点】** 宏的**参数与整体都必须加括号**，否则展开后会吃掉外层运算。
> 实测现有代码中宏出现 23 次，但**无统一体系**，且存在无括号的隐患写法。

**是什么**：`#define` 是**文本替换**，发生在编译之前。它不理解类型、不理解优先级。

**为什么**：宏的价值在两处 —— **写短代码**（`#define rep(i,a,b)`）与
**调试开关**（本地开输出、提交自动关）。但它也是最容易出隐蔽错误的工具，
因为它**不是函数**，没有参数求值、没有类型检查。

**怎么用**：

1. **只用两种宏**：无参数的常量、带完整括号的短缩写。**不要用宏写有副作用的逻辑**。
2. 带参数的宏，**每个参数加括号，整体再加一层括号**。
3. 调试输出用条件编译宏（`#ifdef LOCAL`），提交时直接不定义，不产生任何输出。
4. 需要「函数行为」时用 `inline` 函数或 lambda，不用宏。

```cpp
// g++ -std=c++17 -O2
#include <cstdio>

// 正确：参数与整体都加括号
#define MAX2(a, b) ((a) > (b) ? (a) : (b))
#define SQ(x) ((x) * (x))

// 错误示范：不加括号（不要这样写）
#define BAD_MAX(a, b) a > b ? a : b
#define BAD_SQ(x) x * x

// 调试开关：本地编译加 -DLOCAL 打开，提交时不加则全部消失
#ifdef LOCAL
  #define DBG(fmt, ...) fprintf(stderr, "[%s:%d] " fmt "\n", __FILE__, __LINE__, ##__VA_ARGS__)
#else
  #define DBG(fmt, ...)   // 展开为空，零开销
#endif

int main() {
    int i = 3;

    printf("SQ(3)      = %d\n", SQ(i + 1));       // ((3+1)*(3+1)) = 16，正确
    printf("BAD_SQ(3+1)= %d\n", BAD_SQ(i + 1));    // 3+1*3+1 = 7，错误！

    printf("MAX2(1,2)  = %d\n", MAX2(1, 2));

    // 危险：宏参数被求值两次
    int x = 5;
    printf("BAD 写法会二次求值：x 变化前后不可控\n");
    int y = 5;
    int r = MAX2(y++, 10);      // y++ 可能执行两次！结果与副作用都不可预期
    printf("MAX2(y++, 10) = %d, y 现在是 %d\n", r, y);

    DBG("仅本地可见：i=%d", i);                    // 提交时这一行不产生任何输出
    printf("程序输出里看不到 DBG\n");
    return 0;
}
```

配套的编译方式：

```bash
# 本地调试：定义 LOCAL，打上 -Wall 让警告变成线索
g++ -std=c++17 -O2 -Wall -DLOCAL -o main main.cpp

# 提交用：不定义 LOCAL，宏自动失效
g++ -std=c++17 -O2 -o main main.cpp
```

> **【易错】** 四处：
> 1. **参数不加括号**。`SQ(i+1)` 变成 `i+1*i+1`。
> 2. **参数被求值两次**。`MAX2(y++, 10)` 里 `y++` 可能执行两次，值直接错乱。
>    **这是宏与函数的本质区别，也是「宏不能替代函数」的根本原因。**
> 3. **宏名与变量名冲突**。宏是文本替换，会连变量声明一起替换。
> 4. **多语句宏没用 `do { } while(0)` 包裹**，在 `if` 后只执行第一条。

> **【类比】** 宏像「查找替换」：你在正文里搜到 `SQ` 就换成 `((x)*(x))`，
> 它不看你换进去的上下文。函数则像「叫一个助手去算」——他拿到的是**已经算好的值**。

> **【记忆】** **宏的每个参数都加括号；有副作用就用函数。**

**关联**

- `[前置]` 见 A-2 运算符与优先级（不加括号的后果）、A-6 函数（宏的替代方案）。
- `[后续]` 见 E-3 lambda（更安全的「就地写逻辑」方式）、F-1 比赛代码模板、F-2 调试技巧。
- `[组合]` 与 F-1 组合：比赛模板中的 `#define rep` 类宏。
- `[易混]` `#define` 与 `const` 的区别：前者是文本替换无类型，后者是真变量有类型。

## 五、本章总结

### 5.1 核心内容（一页纸）

1. **看见求和求乘积，先写 `1LL`。** 溢出发生在计算过程中，与接收变量的类型无关。
2. **位运算进条件，先套括号。** `n & 1 == 0` 是错的，必须写 `(n & 1) == 0`。
3. **1 起始用 `<=`，0 起始用 `<`。** 选定一种约定，全文统一，不混用。
4. **数组三件套：全局 + 加 10 的余量 + 1 起始。** 消掉大半数组类 RE。
5. **`1 << k` 的 `1` 是 `int`**，`k ≥ 31` 要写 `1LL << k`。
6. **lowbit 就是 `x & -x`**，这是树状数组的核心，也是位运算最常用的一条。
7. **大对象传参一律 `const &`。** 传值拷贝会从 O(n) 变成 O(n²)。
8. **进 `set` 就要 `operator<`**，且必须用 `<` 不能用 `<=`，末尾 `const` 不能漏。
9. **深度过万，先想迭代。** 递归爆栈是 RE 次因，且不给任何提示。
10. **无穷大用 `0x3f3f3f3f`**，因为两个它相加仍不溢出 `int`。
11. **函数的每个参数都加括号，有副作用就用函数而不是宏。**
