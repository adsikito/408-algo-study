## 四、学习顺序与模块依赖

### 4.1 五阶段

```text
阶段 1　语言基础子集与输入输出        模块 A + 模块 B
        目标：能写出正确、读入不超时的代码
        验收：独立完成 5 道纯模拟题，全部通过且无 IO 超时
              ↓
阶段 2　STL 容器                     模块 C
        目标：知道每种容器在什么场景用，能默写常用操作
        验收：见到题目能立刻说出该用哪个容器及理由
              ↓
阶段 3　STL 算法                     模块 D
        目标：能用现成算法替代手写循环
        验收：能不用手写循环完成排序、查找、去重、统计
              ↓
阶段 4　现代语法糖                   模块 E
        目标：编码速度提升，代码长度下降
        验收：同一道题的代码长度与出错率明显下降
              ↓
阶段 5　竞赛工程化                   模块 F
        目标：具备自查与排查能力
        验收：能对一个错误程序完成对拍并定位错误
```

### 4.2 模块依赖

| 模块 | 前置 | 被谁依赖 |
|------|------|---------|
| A 语言基础子集 | 无 | 全部模块 |
| B 输入输出与性能 | A（部分） | 全部模块 |
| C STL 容器 | A | D、E、F |
| D STL 算法 | C | E、F |
| E 现代语法糖 | A、C | F |
| F 竞赛工程化 | A 至 E | — |

### 4.3 四处关键前置（易被忽略）

| 前置知识点 | 被谁依赖 | 跳过后果 |
|-----------|---------|---------|
| A-5 位运算 | C-9 `bitset`、D-10 `__builtin_`、算法专题阶段 8 树状数组 | 连续卡三处 |
| C-3 `pair` | C-5 `priority_queue`、C-8 `map` | 堆与映射的载体缺失 |
| E-8 运算符重载 | C-7 `set`、C-8 `map` | 自定义类型无法进关联容器 |
| D-1 `sort` | D-3 `lower_bound`、D-4 `unique` | 二者都要求区间有序 |

> **【规律】** 优先级的**实际**等级要叠加「被依赖次数」。
> 例如 C-3 `pair` 标称 P1，但被两个 P0 知识点依赖，其实际学习优先级高于标称。

### 5.1 与现有代码的差距

笔记写完了，但**既有代码的实际水平**与笔记要求之间仍有明显差距。
依据 `31_竞赛C++学习内容方案.md` §0.2 对竞赛代码（75 个 `.cpp`）的统计：

| 知识点 | 现有代码表现 | 主要缺口 |
|--------|-------------|---------|
| B-2 关同步 | 仅 1 次（`cin` 用了 114 次） | **最大缺口** |
| B-3 `endl` | `endl` 41 次 / `"\n"` 78 次，无规范 | 混用 |
| C-7 `set` | **0 次** | 完全空白 |
| C-8 `map` / `unordered_map` | 各 1 次 | 严重不足 |
| D-3 `lower_bound` | **1 次** | 严重不足 |
| D-4 `unique` | **0 次** | 完全空白 |
| D-5 `reverse` / `fill` | **各 0 次** | 完全空白 |
| D-10 `__builtin_` | 3 次 | 使用不足 |
| E-1 `auto` | **0 次** | 完全空白 |
| E-3 lambda | **0 次** | 完全空白 |
| E-8 `operator<` | **0 次** | 完全空白 |

> **【重点】** 十一个知识点在现有代码中**接近空白**。
> 因此本索引的「掌握状态」全部为 `[未学]` 是**准确的**——
> **笔记已写出 ≠ 能力已具备**。
>
> 状态提升的唯一路径是：**读笔记 → 改既有代码 → 做题 → 复盘**。

## 六、与算法专题的衔接

竞赛 C++ 不是独立目标，它服务于算法专题。两套笔记的对应关系：

| 竞赛 C++ 模块 | 直接支撑的算法专题阶段 |
|--------------|---------------------|
| A 语言基础子集 | 全部阶段（地基） |
| B 输入输出与性能 | 全部阶段（读入超时是最常见的失败原因） |
| C STL 容器 | 阶段 3（单调栈 / 队列）、阶段 4（BFS 队列）、阶段 5（堆优化 Dijkstra）、阶段 6（哈希） |
| D STL 算法 | 阶段 1（二分、离散化、LIS）、阶段 7（状压 DP） |
| E 现代语法糖 | 全阶段的代码风格 |
| F 竞赛工程化 | 全阶段的自查能力 |

**总览关系图**见 `02_竞赛\README_竞赛总索引与依赖关系图.md`。

> **【补充】** 学习顺序上有一个建议的**插入点**：
> 学完竞赛 C++ 阶段 1（模块 A、B）之后，即可开始算法专题阶段 1 的题；
> 不必等六个模块全部学完。**边学边用比学完再用效果好。**
