# 408 考研数据结构 + 算法竞赛学习工程

一套「提示词驱动产出」的结构化学习工程：**考研 408 数据结构**（12 篇）+ **算法竞赛八阶段专题**（35 篇）+ **竞赛 C++**（7 篇）三线笔记，配套**题目真源库**（189 道，含 2015–2022 五年 408 数据结构真题）、速查手册与主题索引（MOC）。

## 使用方式

1. 从 `10_提示词/11_提示词执行顺序与使用说明.md` 进入，按六步流水线理解工程结构。
2. 学习按 `02_竞赛/01_算法专题/_MOC_主题索引.md`（MOC）的依赖顺序推进；每篇笔记内含前置知识点表、自测清单与配套题库练习。
3. 题目状态在 `02_竞赛/03_题库/_题库总表.md` 维护（`未做 → 已做 → 已通过`），`已通过` 需在 `03_题库/代码/` 留存代码。
4. 校验（四道门禁，发布前须全通过）：

```bash
python 50_工具与模板/52_检查_跨平台兼容.py .          # 格式层
python 50_工具与模板/54_检查_讲解与题型.py .          # 内容层
python 50_工具与模板/56_检查_交付完整性与版本.py .     # 交付与版本层
python 02_竞赛/03_题库/check_bank.py 02_竞赛/03_题库   # 题库层
```
