## 本章地图

树处理「一对多的分层」，图处理「任意多对多」：城市公路网、课程先修关系、社交网络。图没有根、没有层级，结点之间的关系可以是任意的，因此**存储**（怎么把任意关系放进内存）与**遍历**（怎么不重不漏访问）都成了新问题；在存储与遍历之上，本章给出四大应用：最小生成树（修路最省钱）、最短路径（导航）、拓扑排序（任务先后）、关键路径（工程工期）。

学习路径：先建立图的术语与两种主存储（邻接矩阵管稠密、邻接表管稀疏），再用 DFS / BFS 打通「防环访问」的手感，然后逐个攻克四大应用——**每个应用先记「适用条件与复杂度」再记过程**，手算题按表格推演走。**全章枢纽：遍历防环 + 四大应用的复杂度表。**

## 本章重点

> **【重点】** **度的守恒**：无向图全部顶点度数之和 = 2 × 边数（每条边贡献两个度）；有向图入度和 = 出度和 = 边数。握手定理是所有「求边数 / 度数」题的钥匙。

> **【重点】** **两种存储的选型**：邻接矩阵 O(V²) 空间，**稠密图**用，判边 O(1)；邻接表 O(V + E) 空间，**稀疏图**用，找所有邻接点快但判边要扫链。

> **【重点】** **DFS 用栈（递归），BFS 用队列**；都必须配 `visited[]` 防环。BFS 按层扩展，**无权图的单源最短路就是 BFS**。

> **【重点】** **四大应用一句话分工**：Prim / Kruskal 求连通带权图的最小生成树；Dijkstra 单源最短路（**禁负权**）；Floyd 多源最短路（**可负权、禁负环**）；拓扑排序处理 **AOV 有向无环图**；关键路径在 **AOE 网**上求工期。

> **【重点】** **Dijkstra 与 Prim 的同构**：都是「每轮从候选集挑最近的进集合、再松弛邻居」——一个挑距离最近的点（Dijkstra），一个挑跨割最短的边（Prim）。

---

## 本章难点

> **【难点】** **Dijkstra 为什么不能处理负权边**：它基于「已确定的距离不会再变小」的贪心命题；负权边会让后加入的路径反而更短，命题失效。反例必会举（见例题 5-4）。

> **【难点】** **关键路径的四组量**：事件（顶点）的最早 / 最迟发生时间 ve、vl，活动（边）的最早 / 最迟开始时间 e、l；关键活动 l − e = 0，其路径即关键路径。**ve 从源点正推取 max，vl 从汇点逆推取 min**——方向与取法是手算题全部难点。

> **【难点】** **拓扑序列不唯一**：同一 AOV 网可有多个拓扑序列；**能拓扑排序 ⇔ 无环**（有向图是 DAG ⇔ 存在拓扑序列），这个等价关系是判断题高频点。

---

## 本章易错点

> **【易错】** **头号易错：n 个顶点的图边数上界算错**。无向简单图 C(n,2) = n(n−1)/2；有向简单图（无环简单图）为 n(n−1)（每对顶点两个方向）。把有向图也算成 n(n−1)/2 是最常见丢分。

> **【易错】** **邻接表存无向图边结点数 = 2E**（每条边存两次），出度好数、**入度要扫全表**；逆邻接表反过来。选择题爱问「邻接表中求入度的时间」。

> **【易错】** **Floyd 主循环次序**：k 在**最外层**（允许经过的中转点逐个放开），i、j 在内层；写反了结果错但样例可能碰对——记住「k 是阶段」。

> **【易错】** **Prim 与 Kruskal 复杂度记反**：Prim（邻接矩阵）O(V²)，**适合稠密图**；Kruskal O(E log E)，**适合稀疏图**。跟存储选型的方向一致。

> **【易错】** **连通与强连通混用**：无向图说「连通分量」，有向图说「强连通分量」（任意两点互相可达）；有向图另有「单向连通 / 弱连通」。n 个顶点的强连通图**最少 n 条边**（一个有向环）。

## 知识点讲解

### 5-1　图的定义、分类与度　【P0】

**是什么**：图 G = (V, E)：顶点集 V 与边集 E。无向图边是顶点对 {u, v}，有向图边是有序对 ⟨u, v⟩（弧：u 尾，v 头）。简单图：无自环、无重边。完全图：任意两顶点间都有边。度：与顶点关联的边数（有向图分入度 / 出度）；有向图入度和 = 出度和 = |E|。

**为什么**：度守恒与边数上界是一切图论手算题的第一反应；分类（稠密 / 稀疏、DAG）直接决定后面每个算法的选型。

**怎么用**：
- 无向连通图至少 V − 1 条边（生成树），最多 n(n−1)/2 条（完全图）。
- 有向强连通图至少 V 条边（有向环）。
- 度为奇数的顶点个数必为**偶数**（度之和为偶数的推论，判断题）。
- 稀疏 / 稠密的工程分界：E 接近 V² 用矩阵，E 接近 V 用邻接表（考题常给 n、e 让选存储）。

> **【规律】** 「n 个顶点、e 条边的无向图至少多少个连通分量」：极少数情形 k = n − e（e 条边最多让 e 对分量合并），这也是常考的极端构造题。

**前置与延伸**：
- 前置：无
- 延伸：第 4 章并查集可动态维护连通分量个数

### 5-2　邻接矩阵与邻接表　【P0】

**是什么**：邻接矩阵：V × V 的二维数组，`A[i][j] = 1`（或权值 w，无边记 ∞）表示 i 到 j 有边。邻接表：每个顶点挂一条单链表，链上依次是它的所有邻接点（边结点含邻接点编号 + 权 + next）。

**为什么**：矩阵判边、查权 O(1)，空间 O(V²)——稠密图不浪费；邻接表空间 O(V + E)，遍历邻居只看链——稀疏图不浪费。**选型逻辑与数组 / 链表一致。**

**怎么用**：

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXV 100
#define INF  0x3f3f3f3f

/* 邻接矩阵（带权，网） */
typedef struct {
    int n, e;                    /* 顶点数、边数 */
    int edge[MAXV][MAXV];        /* 无边为 INF，自身为 0 */
} MGraph;

/* 邻接表 */
typedef struct ArcNode {
    int adjvex;                  /* 邻接点编号 */
    int w;                       /* 权值 */
    struct ArcNode *next;
} ArcNode;

typedef struct {
    ArcNode *first[MAXV];        /* 每个顶点的边链表头 */
    int n, e;
} ALGraph;

void addArc(ALGraph *g, int u, int v, int w) {   /* 有向边 u->v */
    ArcNode *p = (ArcNode *)malloc(sizeof(ArcNode));
    p->adjvex = v;
    p->w = w;
    p->next = g->first[u];       /* 头插：O(1) */
    g->first[u] = p;
}
```

> **【注意】** 无向图的邻接矩阵是**对称矩阵**（可压缩存储，呼应第 2 章 2-9）；邻接表中无向图每条边出现在两条链上，**边结点共 2E 个**。
> 度的计算：矩阵中无向图第 i 行和 = 度；有向图行和 = 出度、列和 = 入度。邻接表中出度 = 链长，入度需扫全表（或建逆邻接表）。

> **【规律】** 「邻接表中两顶点是否相邻」要扫链，最坏 O(V)——判断题「邻接表判边 O(1)」是**错**的（那是有 `set` 或矩阵才有的性质）。

**前置与延伸**：
- 前置：知识点 5-1；二维数组（第 2 章 2-9）；单链表（第 1 章 1-4）
- 延伸：十字链表（5-3）；竞赛侧链式前向星（阶段 5）

### 5-3　十字链表与邻接多重表　【P2】

**是什么**：十字链表 = **有向图**的链式存储，每条弧同时挂进「弧尾的出边链」与「弧头的入边链」，容易同时取入度与出度；邻接多重表 = **无向图**的存储，**每条边只存一个结点**（挂进两端的边链），解决邻接表「一条边存两遍」的冗余。

**为什么**：两者都是「既要又要」的产物：既要快速找邻接（链式），又要另一侧信息（入边 / 避免重复）。408 只考结构与适用对象的辨析，不考完整实现。

**怎么用（辨析表）**：

| 存储 | 适用对象 | 每条边存几次 | 特长 |
|------|---------|-------------|------|
| 邻接矩阵 | 有向 / 无向 | 1（对称图为 2 个对称单元） | 判边 O(1) |
| 邻接表 | 有向 / 无向 | 无向 2 次，有向 1 次 | 空间省、找出边快 |
| 逆邻接表 | 有向 | 1 次 | 找入边快 |
| 十字链表 | **有向** | 1 次 | 出边入边都快 |
| 邻接多重表 | **无向** | **1 次** | 对边的操作（如标记删边）高效 |

**前置与延伸**：
- 前置：知识点 5-2
- 延伸：竞赛实现几乎不用这两个结构，链式前向星以更少的指针达到同等效率

### 5-4　DFS 与 BFS　【P0】

**是什么**：DFS 沿一条路走到底再回溯（递归 / 显式栈）；BFS 逐层扩展（队列）。二者都要 `visited[]` 标记已访问，防止环导致的死循环。

**为什么**：遍历是一切图算法的骨架——连通性、路径、生成树、环检测都建立在它上面；BFS 的「按层」性质直接给出无权最短路。

**怎么用**：

```c
#include <stdio.h>
#define MAXV 100

int n;                                   /* 顶点数 */
int vis[MAXV];                           /* visited */

/* DFS（邻接矩阵版） */
void DFS_M(MGraph *g, int v) {
    vis[v] = 1;
    printf("%d ", v);                    /* 访问时机：进入即访 */
    for (int j = 0; j < g->n; j++)
        if (g->edge[v][j] != INF && g->edge[v][j] != 0 && !vis[j])
            DFS_M(g, j);
}

/* BFS（邻接表版 + 循环队列） */
void BFS_AL(ALGraph *g, int v) {
    int queue[MAXV], front = 0, rear = 0;
    vis[v] = 1;
    queue[rear++] = v;
    while (front != rear) {
        int u = queue[front++];
        printf("%d ", u);                /* 访问时机：出队即访 */
        for (ArcNode *p = g->first[u]; p; p = p->next)
            if (!vis[p->adjvex]) {
                vis[p->adjvex] = 1;      /* 入队时就标记，防重复入队 */
                queue[rear++] = p->adjvex;
            }
    }
}
```

> **【规律】** 四个必考结论：
> ①邻接矩阵的 DFS / BFS 序列**唯一**（按编号从小到大找邻居）；邻接表的序列**不唯一**（依赖建表时的边插入次序）。
> ②空间复杂度都是 O(V)（栈 / 队列 + visited）；时间都是 O(V²)（矩阵）或 O(V + E)（邻接表）。
> ③非连通图一次遍历不完，**调用 DFS / BFS 的次数 = 连通分量个数**（对非强连通有向图为「从各点出发可达性」的综合）。
> ④BFS 求出的单源路径在**无权图**上就是最短路径（层数即边数）。

> **【类比】** DFS 是走迷宫时沿右手墙摸到底再折返；BFS 是水波纹从起点一圈圈荡开。

**前置与延伸**：
- 前置：知识点 5-2；栈（第 2 章 2-2）、队列（第 2 章 2-5）；树遍历（第 4 章 4-5）
- 延伸：阶段 4 搜索（剪枝、记忆化）；Tarjan 强连通分量（超纲）

### 5-5　最小生成树：Prim 与 Kruskal　【P0】

**是什么**：带权连通无向图的生成树中权值和最小的那棵。**Prim**：从某顶点起，每轮把「距离生成树最近的顶点」拉进来（加点）；**Kruskal**：边按权排序，从小到大选不构成环的边（加边）。

**为什么**：两者都是贪心，且都依赖「切分定理」（横跨任意割的最短边必在某棵 MST 中）；选型差异来自复杂度结构——Prim 吃稠密，Kruskal 吃稀疏。

**怎么用**：

```c
#include <stdio.h>
#define MAXV 100
#define INF  0x3f3f3f3f

/* Prim（邻接矩阵，O(V^2)）：返回 MST 总权值 */
int Prim(MGraph *g, int s) {
    int low[MAXV], in[MAXV] = {0}, total = 0;
    for (int j = 0; j < g->n; j++) low[j] = g->edge[s][j];
    in[s] = 1;
    for (int k = 1; k < g->n; k++) {
        int u = -1;
        for (int j = 0; j < g->n; j++)       /* 挑最近的树外顶点 */
            if (!in[j] && (u == -1 || low[j] < low[u])) u = j;
        in[u] = 1;
        total += low[u];
        for (int j = 0; j < g->n; j++)       /* 更新到树的最短距离 */
            if (!in[j] && g->edge[u][j] < low[j])
                low[j] = g->edge[u][j];
    }
    return total;
}

/* Kruskal：边排序 + 并查集，O(E log E) */
typedef struct { int u, v, w; } Edge;
int fa[MAXV];

int find(int x) { return fa[x] == x ? x : (fa[x] = find(fa[x])); }

int Kruskal(Edge *e, int n, int m) {
    for (int i = 0; i < n; i++) fa[i] = i;
    /* 按 w 从小到大排序后： */
    int total = 0, picked = 0;
    for (int i = 0; i < m && picked < n - 1; i++) {
        int ra = find(e[i].u), rb = find(e[i].v);
        if (ra != rb) {                      /* 不在同一集合：选这条边 */
            fa[ra] = rb;
            total += e[i].w;
            picked++;
        }
    }
    return total;
}
```

> **【规律】** 三个对比必背：①Prim 加**点**、Kruskal 加**边**；②Prim O(V²) 适合稠密、Kruskal O(E log E) 适合稀疏；③MST **不唯一但权值和唯一**（权值互不相同时 MST 唯一）。Kruskal 判环的依据就是并查集——第 4 章 4-11 的直接应用。

**前置与延伸**：
- 前置：知识点 5-2；并查集（第 4 章 4-11）
- 延伸：堆优化 Prim（O(E log V)）；竞赛侧 Kruskal 重构树（超纲）

### 5-6　最短路径：Dijkstra 与 Floyd　【P0】

**是什么**：Dijkstra 求单源最短路：维护「已确定最短距离」集合，每轮把候选中 dist 最小的顶点确定下来，并松弛其出边；Floyd 求多源：动态规划 `d[i][j] = min(d[i][j], d[i][k] + d[k][j])`，k 逐个放开。

**为什么**：Dijkstra 是「确定一个、松弛一圈」的贪心，O(V²)；Floyd 是阶段化的 DP，三重循环 O(V³) 换来一次算出所有点对——**边数接近完全图时反而划算**。

**怎么用**：

```c
#include <stdio.h>
#define MAXV 100
#define INF  0x3f3f3f3f

/* Dijkstra（O(V^2)）：dist[v] 即源点 s 到 v 的最短距离 */
void Dijkstra(MGraph *g, int s, int dist[], int path[]) {
    int done[MAXV] = {0};
    for (int i = 0; i < g->n; i++) {
        dist[i] = g->edge[s][i];
        path[i] = (dist[i] < INF) ? s : -1;   /* path 记前驱 */
    }
    dist[s] = 0;
    done[s] = 1;
    for (int k = 1; k < g->n; k++) {
        int u = -1;
        for (int j = 0; j < g->n; j++)        /* 挑未确定中 dist 最小者 */
            if (!done[j] && (u == -1 || dist[j] < dist[u])) u = j;
        done[u] = 1;
        for (int j = 0; j < g->n; j++)        /* 松弛 u 的出边 */
            if (!done[j] && dist[u] + g->edge[u][j] < dist[j]) {
                dist[j] = dist[u] + g->edge[u][j];
                path[j] = u;
            }
    }
}

/* Floyd（O(V^3)）：k 在最外层 */
void Floyd(MGraph *g, int d[MAXV][MAXV], int pre[MAXV][MAXV]) {
    for (int i = 0; i < g->n; i++)
        for (int j = 0; j < g->n; j++)
            d[i][j] = g->edge[i][j];
    for (int k = 0; k < g->n; k++)
        for (int i = 0; i < g->n; i++)
            for (int j = 0; j < g->n; j++)
                if (d[i][k] + d[k][j] < d[i][j]) {
                    d[i][j] = d[i][k] + d[k][j];
                    pre[i][j] = pre[k][j];    /* 经 k 中转 */
                }
}
```

**手算模板（综合题表格推演）**：Dijkstra 画一张「轮次 × 顶点」的 dist 表——每轮：①在未确定行里挑最小画圈（该列自此不变）；②用被圈顶点松弛其余列，写本轮新值。**每轮只确定一个顶点**，n − 1 轮结束。

> **【规律】** 对比表（选择题与手算题都从这张表出）：

| 算法 | 求解范围 | 复杂度 | 负权 | 典型载体 |
|------|---------|--------|------|---------|
| BFS | 无权单源 | O(V + E) | 可 | 队列 |
| Dijkstra | 非负权单源 | O(V²)（堆优化 O((V+E)log V)） | **不可** | 矩阵 / 堆 |
| Floyd | 任意权多源 | O(V³) | 可（禁负环） | 邻接矩阵 |
| Bellman-Ford | 任意权单源 | O(VE) | 可（可判负环） | 边集数组 |

> **【注意】** Dijkstra 负权反例：V = {A, B, C}，边 A→B = 4，A→C = 1，C→B = −10。真实最短 A→B 是 −9，但 Dijkstra 第一轮就确定 dist[B] = 4 且不再改——**贪心命题被负权破坏**。

**前置与延伸**：
- 前置：知识点 5-2；堆（第 4 章 4-10，堆优化版）
- 延伸：阶段 5 的 SPFA、堆优化 Dijkstra 与选题

### 5-7　拓扑排序与关键路径　【P0】

**是什么**：拓扑序列：AOV 网（顶点 = 活动，弧 = 先后约束）中把所有顶点排成一条线，使每条弧都「从前指向后」。算法：反复摘除**入度为 0** 的顶点并删其出边。关键路径：AOE 网（边 = 活动，顶点 = 事件）中源点到汇点**最长路径**，决定工程最短工期；其上的活动（l − e = 0）为关键活动。

**为什么**：拓扑排序解决「依赖调度」，是编译依赖、课程先修的模型；关键路径回答「哪条链拖住了整个工期」——压缩非关键活动不缩短工期，压缩关键活动才行（直到它不再是关键路径）。

**怎么用**：

```c
#include <stdio.h>
#define MAXV 100

/* 拓扑排序（邻接表 + 入度数组 + 栈存零入度顶点） */
int toposort(ALGraph *g, int order[]) {
    int indeg[MAXV] = {0}, stack[MAXV], top = -1, cnt = 0;
    for (int i = 0; i < g->n; i++)
        for (ArcNode *p = g->first[i]; p; p = p->next)
            indeg[p->adjvex]++;              /* 统计入度 */
    for (int i = 0; i < g->n; i++)
        if (indeg[i] == 0) stack[++top] = i;
    while (top != -1) {
        int u = stack[top--];
        order[cnt++] = u;
        for (ArcNode *p = g->first[u]; p; p = p->next)
            if (--indeg[p->adjvex] == 0)     /* 删出边 = 入度减一 */
                stack[++top] = p->adjvex;
    }
    return cnt == g->n;                      /* 全部输出：无环；否则有环 */
}
```

> **【规律】** 拓扑排序三考点：①**输出顶点数 < n ⇔ 有环**（这是判环手段之一）；②用**栈或队列**存零入度顶点皆可，选择不同得到的序列不同——**序列不唯一**；③时间 O(V + E)。DFS 也能产生拓扑序（按完成时间逆序，超纲了解）。

**关键路径手算四步（综合题模板）**：
1. **正推 ve**（事件最早发生时间）：源点 ve = 0；按拓扑序，`ve[j] = max{ ve[i] + w(i,j) }`（取 max：前面的活动全完成）。
2. **逆推 vl**（事件最迟发生时间）：汇点 vl = ve(汇点)；按逆拓扑序，`vl[i] = min{ vl[j] − w(i,j) }`（取 min：不能拖累后继）。
3. 活动a(i,j)：`e = ve(i)`（最早开始 = 尾事件最早发生）；`l = vl(j) − w(i,j)`。
4. **关键活动：l − e = 0**；全部关键活动连成的源汇路径即关键路径（可能不止一条）。

> **【注意】** 缩短工期的判断：只有**所有**关键路径都压缩，工期才缩短；关键活动速度提升可能使另一条路径变成新的关键路径。判断题高频。

**前置与延伸**：
- 前置：知识点 5-1、5-4；第 7 章排序（拓扑序是偏序的线性化，可对照）
- 延伸：竞赛侧拓扑 + DP（阶段 7）、欧拉路径（阶段 5）

## 典型例题

### 例题 5-1　（度数计算题 · 选择题风格）
**题干**：(1) 具有 6 个顶点的无向连通图至少有几条边？(2) 6 个顶点的无向简单图最多有几条边？(3) 某无向图有 16 条边，度数为 4 的顶点最多有几个（顶点数不限）？

**解题思路**：三问分别套「生成树边数 = n − 1」「完全图 C(n,2)」「度之和 = 2e」。

**解答过程**：
1. 连通至少 **n − 1 = 5** 条边（生成树）。
2. 完全图最多 **6×5/2 = 15** 条边。
3. 度之和 = 2 × 16 = 32。设 4 度顶点 x 个，其余顶点度数各至少为 1，故 4x + (其余顶点度数之和) = 32 且其余部分 ≥ 其余顶点个数。要 x 最大，让其余顶点尽量少：极端情形全部顶点都是 4 度，即 4x = 32 → **x = 8**（8 顶点 4 正则图存在，如 K₄,₄），所以最多 **8 个**。

**复杂度分析**：O(1) 公式计算。
**易错提示**：拿到边数先对照上界 n(n−1)/2（给定顶点数时）；求「最多几个某度数顶点」时，把其余顶点的度数压到最小（1 度顶点两两配对即可存在）。

### 例题 5-2　（手算题 · 最小生成树）
**题干**：无向网 V = {A, B, C, D}，边与权：A-B = 1，B-C = 2，A-C = 3，C-D = 4，B-D = 5。分别用 Prim（从 A）与 Kruskal 求最小生成树并给出权值和。

**解题思路**：Prim 记「每次挑离树最近的点」；Kruskal 记「边排序、选不成环的」。

**解答过程**：
Prim：树 = {A}，候选边 A-B(1)、A-C(3) → 选 A-B；树 = {A,B}，候选 B-C(2)（A-C 的 3 被 2 替换）→ 选 B-C；树 = {A,B,C}，候选 C-D(4)（B-D 的 5 被 4 替换）→ 选 C-D。MST 边：{A-B, B-C, C-D}，权和 **1+2+4 = 7**。
Kruskal：排序 A-B(1)、B-C(2)、A-C(3)、C-D(4)、B-D(5)。选 A-B（A、B 异集）；选 B-C（C 并入）；A-C 的两端 A、C 已同集，**舍**；选 C-D。同一条 MST，权和 7。
两算法结果一致（权值互异时 MST 唯一）。

**复杂度分析**：Prim O(V²) = 16 次比较量级；Kruskal O(E log E)。

### 例题 5-3　（手算题 · Dijkstra 表格推演）
**题干**：有向网 V = {1,2,3,4}，边：1→2 = 1，1→3 = 4，2→3 = 2，3→4 = 1，2→4 = 5。从顶点 1 出发用 Dijkstra 求 1 到各点最短距离，写出每轮 dist 表。

**解题思路**：每轮「挑最小、画圈、松弛一圈」，确定过的列不再变。

**解答过程**（dist 表，括号内为路径）：
| 轮 | 确定顶点 | 1 | 2 | 3 | 4 |
|----|---------|---|---|---|---|
| 0（初始） | 1 | 0 | 1 | 4 | ∞ |
| 1 | 2（dist=1） | 0 | 1 | min(4, 1+2)=3 | min(∞, 1+5)=6 |
| 2 | 3（dist=3） | 0 | 1 | 3 | min(6, 3+1)=4 |
| 3 | 4（dist=4） | 0 | 1 | 3 | 4 |

结果：1→2 = 1，1→3 = 3（经 2），1→4 = 4（经 2、3）。注意 1→4 的直接边权 5 被「1→2→3→4 = 4」淘汰。

**复杂度分析**：O(V²)；本题 n = 4 共 3 轮。

### 例题 5-4　（辨析题 · 负权反例）
**题干**：说明 Dijkstra 不能处理负权边的原因，并构造一个最小反例。

**解题思路**：从贪心命题「一旦确定不再修改」入手，构造「后到反而更短」的图。

**解答过程**：命题依据是所有边权非负——已确定顶点的 dist 是当前所有路径中最小的，且任何后续路径都要经过已确定顶点、只会更长。负权破坏它：
顶点 A、B、C；边 A→B = 4，A→C = 1，C→B = −10。
Dijkstra 第 1 轮确定 dist[C] = 1，第 2 轮确定 dist[B] = 4（候选中 4 最小），随后用 C 松弛 B：dist[C] + (−10) = −9 < 4，**但 B 已标记 done，不再更新**。真实最短 A→B = −9。故 Dijkstra 仅适用于**非负权**图；含负权改用 Bellman-Ford（可判负环）或 Floyd（禁负环）。

**复杂度分析**：概念 + 构造，O(1)。

## 本章总结

### 核心内容（一页纸）

- 无向边数上界 **n(n−1)/2**，有向 **n(n−1)**；度之和 = **2e**；强连通至少 **n** 条边。
- **邻接矩阵** O(V²) 稠密、判边 O(1)、无向对称；**邻接表** O(V+E) 稀疏、判边 O(V)、无向边结点 2E 个。
- 十字链表管**有向**（入出边都快）、邻接多重表管**无向**（边只存一次）。
- DFS 栈 / BFS 队列，均需 visited；矩阵序列**唯一**、邻接表**不唯一**；遍历次数 = 连通分量个数；BFS 即无权最短路。
- **Prim 加点 O(V²) 稠密**；**Kruskal 加边 O(E log E) 稀疏**，判环用并查集；MST 形态可不唯一、权值和唯一。
- **Dijkstra 非负权单源 O(V²)**，手算画 dist 表每轮定一点；**Floyd 多源 O(V³)**，k 在最外层、可负权禁负环。
- **拓扑排序**摘零入度点，输出 < n ⇔ 有环，序列不唯一，O(V + E)。
- **关键路径** = AOE 最长路径：ve 正推取 max、vl 逆推取 min、关键活动 l − e = 0；只有压缩**所有**关键路径才缩短工期。
