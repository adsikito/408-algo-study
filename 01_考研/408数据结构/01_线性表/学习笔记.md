> 线性表是数据结构的起点：**顺序表（数组实现）与链表（指针实现）** 的取舍贯穿全书，后面的栈、队列、树都是这一章思想的延伸。

## 🗺️ 本章地图

本章回答一个问题：**一串数据（线性表）到底该用数组存，还是用指针链着存？** 先用 ADT 和线性结构搭好概念框架（第 1~2 节），再学顺序表（第 3~4 节）看清它"读得快、改得慢"，然后学链表（第 5~6 节）看清它"改得快、找得慢"，最后用双链表、循环链表（第 7 节）补齐单链表"回不了头"的短板。这个顺序不是随便排的——**每一种新结构都是为了修上一种的缺陷**，两条路线的总对决（🔍 辨析组1）要等两边都学完才立得起来。

## 📌 本章重点（3-5个）

⭐ **抽象数据类型（ADT）与线性结构**：ADT = 数学模型 + 模型上的一组操作；线性结构三条件（首无前驱、尾无后继、中间一对一）
⭐ **顺序表的插入与删除**：插入整体后移腾位、删除整体前移覆盖，按最坏情况分析均为 O(N)；下标随机读取 O(1)
⭐ **头指针、头结点、首元结点**：三个概念逐字区分；带头结点使空表/非空表/首元结点的操作统一
⭐ **单链表的建表与插删**：头插法（次序相反）、尾插法（保序）、后插、删除找前驱"绕指针 + free"
⭐ **四种链表（单链/双链/循环单链/循环双链）的判定条件**：判空、找尾、遍历终止各不相同

## 🔥 本章难点（2-3个）

🔥 **插入删除的指针操作顺序**：必须"先接后断"（`s->next=p->next; p->next=s;`），顺序颠倒直接断链丢表
🔥 **循环链表的边界**：遍历终止条件从 `p!=NULL` 变成 `p!=L`，写错就死循环；空表是"头结点自指"而非 NULL
🔥 **双链表 pre 指针的维护**：插删要同步改 next/pre 两个方向；普通双链表要判 NULL，循环双链表不用判

## ⚠️ 本章易错点（3-5个）

⚠️ **顺序表插入"正着"后移**：`for(j=i; j<=s-1; j++) data[j+1]=data[j];` 是代码注释里的"典型的错误"——从前往后移会把后面元素全部覆盖；必须**倒着枚举** `for(j=s-1; j>=i; j--)`
⚠️ **头结点建在栈上**：`Node head; return &head;` 返回局部变量地址成野指针；头结点必须 malloc 到堆上
⚠️ **查找从头结点开始**：头结点数据域是脏数据，Find 必须从首元结点 `L->next` 开始，且**先判空再比数据**（`p!=NULL && p->data!=x` 顺序不能反）
⚠️ **删除后不收尾**：free 后要 `p=NULL` 防野指针；链式队列删到尾结点时还要把尾指针拉回，否则悬空
⚠️ **头插法顺序想反**：头插法建表，结点顺序与插入顺序**相反**；要保序必须用尾插法

## 📖 知识点讲解

### 1. 数据类型与抽象数据类型（ADT）

**是什么**：先说白话——数据类型是语言写好的"说明书"：写明这类数据**能取哪些值、能对它做哪些运算**；抽象数据类型（Abstract Data Type，ADT）则是自己定义的更高级的说明书，只声明**"存的是什么数学模型 + 能做哪组操作"**，不规定底层怎么实现。严格定义：ADT 是一个**数学模型以及定义在模型上的一组操作**——定义了数据对象、对象中各元素之间的关系及对数据元素的操作。至于具体是哪些操作，由设计者根据实际需要来定（课件"超级玛丽"例子：马里奥最初只定义"走、跳"，后来加"打子弹"，再后来又有了按住打子弹键前后走就跑的操作）。处理手法：**对数据归一化处理**（把五花八门的数据统一纳入"数据 + 操作"这套框架来描述）。

**为什么**：机器语言时代数据没有类型，程序员要亲自找存储地址、手动存 0/1，低效易错；高级语言引入数据类型后，存储时不必再直接和存储器地址打交道，编译器还能在编译时检测运算合法性。ADT 再进一步：把"数据长什么样"与"能对它做什么"打包描述。

**怎么用**：拿线性表 ADT 当例子，跟着走一遍"声明一个 ADT"的思路：
第1步 写**数据集合**：{a0, a1, ..., an}，元素之间一对一排列；
第2步 写**操作集合**：增 add、删 remove、改 set、查 find、插 insert；
第3步 到此为止——底层用数组实现还是链表实现，ADT 说明书里一个字都不提。
线性表抽象数据类型就是这两个方面：**数据集合** + **该数据集合上的操作集合**。

| 对比 | 基本数据类型 | 抽象数据类型（ADT） |
|------|------------|-------------------|
| 关注点 | 取值范围 + 可施加的运算 | 数学模型 + 一组操作 |
| 层次 | 语言自带 | 对数据的抽象，可自定义 |
| 例子 | int（范围与加减乘除） | 线性表（数据集合 + 操作集合） |

> ⚠️ 注意事项：ADT 只描述"做什么"（逻辑），不规定"怎么存"（物理）——同一个线性表 ADT 既可用顺序表实现，也可用链表实现。

> 🎯 规律：先约定"做什么"（接口），再挑"怎么存"（实现）——说明书和实现永远分开写。

> 💡 一句话总结：ADT=数学模型+操作集合。

### 2. 线性结构与线性表

**是什么**：先说白话——线性结构就是"排成一队"的关系：队里任何人，前面只有一个人、后面只有一个人；排头前面没人，队尾后面没人。严格说，如果一个数据元素序列满足：
1. 除第一个和最后一个数据元素外，每个数据元素**只有一个前驱数据元素和一个后继数据元素**；
2. 第一个数据元素**没有前驱**；
3. 最后一个数据元素**没有后继**；

这样的结构就叫做**线性结构**。按这种关系排好的元素序列就是线性表 (a0, a1, ..., an)。

**为什么**：线性关系是最简单的元素间关系，是后面栈/队列（仍线性）、树（一对多）、图（多对多）分类的参照系。

**怎么用**（跟着验证一遍：取最小的线性表 (a0, a1, a2) 逐条对照）：
第1步 查中间元素 a1：前驱只有 a0，后继只有 a2 → 一对一 ✓
第2步 查队首 a0：前面没有元素 → 无前驱 ✓
第3步 查队尾 a2：后面没有元素 → 无后继 ✓
三条全过，判定为线性结构。

```
线性表 (a0, a1, a2, ..., an)
a0 → a1 → a2 → ... → an      逻辑上依次排队
↑首元没有前驱            ↑尾元没有后继
```

> ⚠️ 注意事项："线性"说的是**逻辑结构**；顺序存储、链式存储说的是**存储结构**，两件事互不绑定。

> 🎯 规律：判断线性结构只查三件事——首无前驱、尾无后继、中间一对一，逐条对照即可。

> 💡 一句话总结：一对一关系，首无前驱尾无后继。

### 3. 顺序表：定义、优劣势与效率分析

**是什么**：先说白话——顺序表就是给数据安排一排**连号的储物柜**（数组）：元素挨个放进去，柜号（下标）直接对应位置，报号即取。严格定义：顺序表是**以数组的形式保存的线性表**——用一组**地址连续的存储单元依次存储**数据元素的线性结构。基本操作五种：增（add）、删（remove）、改（set）、查（find）、插（insert）。

**为什么（课件效率分析）**：
- **优势**：数据按顺序存储，可以通过**数组下标直接访问**，查找定位元素很快；支持随机访问，读取一个元素 **O(1)**（下标访问时间固定，与问题规模无关）。为什么下标直取是 O(1)？跟着算一笔账：设数组首地址为 1000、每个 int 占 4 字节，那么 data[3] 的地址 = 1000 + 3×4 = 1012——一次乘加就定位，不用挨个找，耗时自然与元素个数无关。
- **劣势**：插入和删除元素都需要大量的操作（移动）；数组声明时就要确定长度，顺序表长度是确定的，扩大长度要把原数组元素**全部 copy 到另外一个数组**，不够灵活；数据大小不可测，有时会浪费大量空间。
- 结论：**最大的优点是空间利用率高，最大的缺点是大小固定**；顺序表适用于**不需要对数据进行大量改动**的结构。

**怎么用**：
```c
typedef struct ArrayList {
    int *data;   // 动态数组（连续空间）
    int s;       // 表长（当前元素个数）
} Array;

Array InitArray(Array a) {                 // 初始化空顺序表
    a.data = (int*)malloc(sizeof(int) * maxx);
    a.s = 0;
    return a;
}
void Add(Array *a, int k) {                // 末尾添加
    if (a->s == maxx) { printf("数组已满\n"); return; }  // 先判满
    a->data[a->s] = k;
    a->s++;
}
```

> ⚠️ 注意事项：表长 s（当前元素个数）与容量 maxx（malloc 的大小）是两回事；一切写入操作前先判满。

> 🎯 规律：连续存储让"下标即地址"，同一枚硬币的反面是"一动就得整体搬"。

> 💡 一句话总结：连续存储读得快，改得慢大小死。

### 4. 顺序表的插入与删除（含复杂度）

**是什么**：先说白话——插删像在一排坐满的影院座位里塞人/请走人：塞一个人，他后半排全部右移一格；请走一个人，他后半排全部左移一格——队伍中不许留空隙。严格定义：
- **删除**：找到目标元素，将其**后续的所有元素整体前移 1 个位置**——本质是"间接删除"（用后继覆盖目标）。
- **插入**：按位置分 3 种情况（插入到表头、表中中间位置、尾随已有元素作为最后一个插入），统一两步：① 将插入位置及其后续元素**整体向后移动一个位置**；② 将元素放到腾出来的位置上。

**为什么**：连续存储必须维持"依次存放"，中间动一个就要整体搬移——这是保序的代价。

**怎么用**（课件配图 + 跟着算 + 代码模板）：

跟着算插入：在 {1,2,4,5,6,7} 的第 3 个位置（下标 2）插入 3（s=6）：
第1步 从最后一个元素开始**倒着**移：j=5，执行 data[6]=data[5]，7 右移
第2步 j=4，data[5]=data[4]，6 右移
第3步 j=3，data[4]=data[3]，5 右移
第4步 j=2，data[3]=data[2]，4 右移（下标 2 的位置空出来了）
第5步 data[2]=3，s 从 6 变 7 → {1,2,3,4,5,6,7}

```
在 {1,2,4,5,6,7} 的第 3 个位置插入 3：
1 2 [4 5 6 7]         ← 4~7 整体向后移动
1 2 [ ] 4 5 6 7       ← 腾出目标位置
1 2 [3] 4 5 6 7       ← 放入元素
```

```
下标    0   1   2   3   4   5   6
初始    1   2   4   5   6   7   □
移动后  1   2   □   4   5   6   7   ← 4~7 依次右移一格
插入后  1   2   3   4   5   6   7
```

反过来验证"正着移"为什么是典型错误（j 从 2 往右枚举）：
data[3]=data[2] → 4 盖到 3 号位；接着 data[4]=data[3] 还是 4……一路复制下去
得到 {1,2,4,4,4,4,4}，5、6、7 全被 4 覆盖丢失——所以必须倒着枚举。

删除也走一遍：删 {1,2,3,4,5} 中的 2（Find 得 i=1，s=5）：
第1步 j=2，data[1]=data[2]，3 左移补到 1 号位（**从前往后**挪）
第2步 j=3，data[2]=data[3]，4 左移
第3步 j=4，data[3]=data[4]，5 左移
第4步 s 从 5 变 4 → {1,3,4,5}，2 被"覆盖式"删掉

```c
void Insert(Array *a, int i, int k) {
    if (a->s == maxx) { printf("数组已满\n"); return; }
    // for(j=i; j<=s-1; j++) ...  ← 典型的错误（正着移会覆盖）
    for (int j = a->s - 1; j >= i; j--)   // 倒着枚举移动
        a->data[j+1] = a->data[j];
    a->data[i] = k;
    a->s++;
}
void Delet(Array *a, int k) {
    int i = Find(a, k);                    // 空表时 k 一定不存在
    if (i == -1) { printf("%d不存在,无法删除\n", k); return; }
    for (int j = i+1; j <= a->s-1; j++)    // i+1..s-1 挨个前移
        a->data[j-1] = a->data[j];
    a->s--;
}
```

**复杂度（课件：分析时间复杂度的原则是分析最坏情况，这样才有意义）**：
| 操作 | 最好情况 | 最坏情况 | 结论 |
|------|---------|---------|------|
| 删除 | 恰好删最后一个（不移动，size-1 即可） | 删第一个（后面全部前移 + size-1） | O(N) |
| 插入 | 尾随插入（不移动） | 表头插入（全部后移） | O(N) |
| 读取 | — | — | O(1) 随机访问 |

> ⚠️ 注意事项：方向记牢——**插入后移（从尾往头挪），删除前移（从头往尾挪）**；插完 s+1，删完 s-1。

> 🎯 规律：移动方向永远背向操作点——插入让后面元素右移（从尾往头枚举），删除让后面元素左移（从头往尾枚举）。

> 💡 一句话总结：插入后移删除前移，均O(N)。

### 5. 链表与单链表：头指针、头结点、首元结点

**是什么**：先说白话——链表像寻宝游戏：每个结点（结点 = 一个数据元素 + 一个指针的组合）藏两条信息：自己的数据、以及"下一个结点在哪"的线索，线索断了游戏就断了。严格说，链表是**继数组之后第二种使用最广泛的通用数据结构**（数组缺陷：无序数组搜索低效、有序数组插入效率低、删除效率都低、大小无法改变）。链表结构：**物理上不连续，逻辑上连续；大小不固定**。链式存储基于指针实现，**一个数据元素 + 一个指针 = 结点**：
- **数据域**：存数据元素的区域
- **指针域**：存储直接后继位置的区域

链式存储就是**用指针将相互关联的结点链接起来**；按构造分为**单向链表、单向循环链表、双向链表、双向循环链表**。单链表：每个节点只包含一个指针域（只有一个指向后继节点的指针）。三个易混概念（课件逐字定义，白话对照着记）：
- **头指针**：链表中第一个结点存储的位置；如果链表有头结点，头指针就是指向头结点的指针——它是"门牌号"，是进链表的入口
- **头结点**：头指针所指的**不存在数据元素**的第一个结点（它又指向首元结点）；一般不放数据（有时也放，如链表长度，用做监视）——它是站第一排不干活的"门卫/哨兵"（哨兵 = 不存业务数据、专门占位帮忙统一管理的结点）
- **首元结点**：存放第一个数据元素的结点——"第一位住户"

单链表分**带头结点**与**不带头结点**两种结构：
```
带头结点：  头指针 → [空|●](头结点) → [a0|●](首元) → ... → [an|^]
不带头结点：头指针 → [a0|●](首元) → ... → [an|^]
空链（带头结点）：头指针 → [空|指针域(空)]
```

**为什么**：不带头结点时，在**第一个结点之前插入**必须让头指针等于新插入的结点，与在非第一个结点前插入（新结点指向 a(i)，a(i-1) 指向新结点）情况不同，需要**分别设计实现方法**；带头结点时 p 指向头结点，改变 p 的 next 即可，**头指针 head 的值不变**，操作与其他结点统一。**带头结点的好处：方便链表操作——空表、非空表以及对首元结点都可以统一处理。**

**怎么用**：
```c
typedef struct Node {
    int data;            // 数据域
    struct Node *next;   // 指针域
} Node, *LinkList;       // LinkList 等价 Node*，声明头指针增强可读性

Node* InitLink() {       // 初始化：声明头结点
    /* 错误示范：Node head; head.next=NULL; return &head;
       —— 局部变量在栈上，函数结束自动回收，L 成野指针 */
    Node *head = (Node*)malloc(sizeof(Node));
    head->next = NULL;
    return head;
}
```
带头结点的好处，用"往空表插入第一个元素 a0"这个最小场景看得最清楚：
带头结点：第1步 malloc 新结点 s 存 a0；第2步 s->next = head->next（原本是 NULL）；第3步 head->next = s——**头指针 L 全程没动**。
不带头结点：第1步 malloc 新结点 s 存 a0；第2步 s->next = L；第3步 **L = s——头指针本身被改写**。
一个动头指针、一个不动，这就是"操作不统一"的具体含义。

| 对比 | 头指针 | 头结点 |
|------|--------|--------|
| 各自定义 | 指向链表第一个结点（有头结点时即头结点）的指针 | 头指针所指、不存数据元素的结点 |
| 核心区别 | 是指针，链表的入口 | 是结点，哨兵 |
| 各自特点 | 任何链表都必须有 | 数据域可空或放表长做监视 |
| 使用场景 | 遍历、定位整表 | 统一空表/非空表/首元操作 |
| 典型示例 | `LinkList L` | `head->next = 首元结点` |
| 记忆口诀 | 头指针是门牌，头结点是门卫 | |

> ⚠️ 注意事项：头指针必须存在，头结点不是必须的；首元结点才是第一个**存数据**的结点。

> 🎯 规律：给链表安排一个不干活的哨兵结点，所有"特殊情况"就都变成了普通情况。

> 💡 一句话总结：头结点是哨兵，统一空与非空操作。

### 6. 单链表核心操作：建表、查找、插入、删除

**是什么**：先说白话——单链表没有下标，一切操作都得"顺藤摸瓜"：从首元结点出发沿 next 一格一格摸到目标，再动一两次指针完成插删。以下为带头结点单链表标准操作（源自配套代码）：
- **头插法**：新结点插到头结点之后——① `s->next = L->next`（指向原首元结点）② `L->next = s`；**链表结点顺序与插入顺序相反**
- **尾插法**：① 找尾结点 p（`while(p->next != NULL) p = p->next`）② `s->next = p->next; p->next = s`；保持插入顺序
- **查找**：从**首元结点**开始，不能从头结点开始（头结点数据域的脏数据会有影响）；首元结点不一定存在，**先判空再比较**：`while(p != NULL && p->data != x) p = p->next`
- **指定插入**（在数据 x 之后插入 k）：Find(x) 得 p，`s->next = p->next; p->next = s`
- **删除**：找 k 所在结点 p 及其上一个结点 q（前驱，即 p 的上一个结点），`q->next = p->next`（绕过 p），`free(p)`（把结点占的内存还给系统）后 `p = NULL` 防野指针

**为什么**：单链表没有下标，一切定位靠**从头遍历**；单向指针回不去，删除必须先拿到**前驱**；free 后置 NULL 防野指针。

**怎么用**：

跟着算建表（头插法）：依次插入 1、2、3（L 为头结点）：
第1步 插 1：L → [1|^]
第2步 插 2：s->next=L->next（2 先牵手 1）；L->next=s（头结点改指 2）→ L → [2] → [1|^]
第3步 插 3：同上 → L → [3] → [2] → [1|^]
插入顺序 1,2,3，链表顺序 3,2,1——"头插反序"就是这么来的。

跟着算插入（在值为 5 的结点后插 9，before/after 指针图）：

```
before：  L → [3|●] → [5|●] → [7|^]
                    ↑ p（Find 定位到 5）

第1步 s->next = p->next   （9 先牵手 7，后半张表保住）
第2步 p->next = s         （5 再改口牵 9）

after：   L → [3|●] → [5|●] → [9|●] → [7|^]

两步颠倒的后果：若先执行 p->next = s，5 到 7 的旧链已被覆盖；
再执行 s->next = p->next 只会得到 s->next = s（自己指自己），
7 及以后的结点全部丢失。
```

跟着算删除（删值为 5 的结点）：
第1步 p、q 从头同步出发：p 停在 [5]，q 停在前驱 [3]
第2步 q->next = p->next   （3 直接牵手 7，绕过 5）
第3步 free(p)，再 p = NULL

```
before：  L → [3|●] → [5|●] → [7|^]
after：   L → [3|●] ──────→ [7|^]
```

```c
LinkList Head_insert(LinkList L, int k) {   // 头插
    Node *s = (Node*)malloc(sizeof(Node));
    s->data = k;
    s->next = L->next;      // 先接：新结点指向原首元
    L->next = s;            // 后断：头结点改指新结点
    return L;
}
LinkList Delete(LinkList L, int k) {        // 删除值为k的结点
    Node *p = L->next, *q = L;              // p首元、q前驱，同步走
    while (p != NULL && p->data != k) { p = p->next; q = q->next; }
    if (p == NULL) printf("%d不存在,无法删除\n", k);
    else {
        q->next = p->next;   // 前驱绕过p
        free(p);  p = NULL;  // 释放并防野指针
    }
    return L;
}
```
指针变化图：
```
在 a1 前插 obj：  a0 ──✂──▶ a1   ⇒   a0 ──▶ obj ──▶ a1   （先 s->next=a1，后 a0->next=s）
删除 a1：        a0 ──▶ [a1] ──▶ a2  ⇒  a0 ──────▶ a2   （a0->next = a1->next，free(a1)）
```

| 对比 | 头插法 | 尾插法 |
|------|--------|--------|
| 各自定义 | 在头结点后面插入新结点 | 在尾结点后面插入新结点 |
| 核心区别 | 两步搞定，无需找尾 | 要先遍历找尾结点 |
| 各自特点 | 结点顺序与插入顺序**相反** | 结点顺序与插入顺序**一致** |
| 使用场景 | 逆序建表、实现链栈 | 顺序建表、实现链队列 |
| 典型示例 | 依次插 1,2,3 → 链表 3,2,1 | 依次插 1,2,3 → 链表 1,2,3 |
| 记忆口诀 | 头插反序，尾插保序 | |

> ⚠️ 注意事项："**先接后断**"是铁律——先 `s->next = p->next` 再 `p->next = s`，反过来后半张表直接丢失；Find 条件 `p != NULL && p->data != x` 顺序不能换，否则空表时先解引用空指针。

> 🎯 规律：改链先保后半截——新结点先牵手旧后继，前驱最后才改口；删除同理先牵后断再释放。

> 💡 一句话总结：先接后断，删除先找前驱。

### 7. 双向链表与循环链表

**是什么**：先说白话——单链表是单行道，想看上一个结点必须从起点重走；双链表给每个结点装上"倒车镜"，循环链表则把末站的路直接修回首站。严格定义：
- **双链表**：结点 = 数据域 + **next（存下一个结点地址）** + **pre（存上一个结点地址）**
- **循环单链表**：尾结点指针域指回头结点；**空表 = 头结点自己指向自己**（`head->next == head`）
- **循环双链表**：`head->next = head; head->pre = head`，首尾双向成环

**为什么**：单链表单向，删 p 要从头找前驱 O(N)；双链表给每个结点装上"回程票"，**拿到 p 即可删除 p 自身**，不用再找前驱；循环链表从任意结点出发都能遍历全表，尾结点一步回到头。

**怎么用**（与单链表的差异点）：

双链表删除 p 的指针变化（before/after）：
```
before：  A ⇄ [p] ⇄ B        （A = p->pre，B = p->next）
第1步 p->pre->next = p->next （A 的 next 越过 p 牵住 B）
第2步 p->next->pre = p->pre  （B 的 pre 越过 p 牵住 A）
第3步 free(p)、p = NULL
after：   A ⇄ B              （p 被摘下；普通双链表 A/B 可能不存在，要先判空）
```

循环单链表的结构（尾结点指回头结点）：
```
空表：  L → [头|●]─┐
            ↑──────┘            head->next == L 即空表
非空：  L → [头|●] → [a0|●] → [a1|●]─┐
            ↑────────────────────────┘  尾结点 next == L
```

```c
/* 双链表头插：多维护 pre，且要判原首元是否存在 */
s->next = L->next;  s->pre = L;
if (L->next != NULL) L->next->pre = s;    // 非循环：判空！
L->next = s;

/* 双链表删除 p：无需前驱 */
p->pre->next = p->next;
if (p->next != NULL) p->next->pre = p->pre;  // 非循环：判空！
free(p);  p = NULL;

/* 循环单链表：所有 NULL 判断换成 L */
head->next = head;                     // 空表：自指
while (p->next != L) p = p->next;      // 找尾
while (p != L) { ...; p = p->next; }   // 遍历（Find/Print 同理）

/* 循环双链表删除 p：成环保证前后结点都在，无需判 NULL */
p->pre->next = p->next;  p->next->pre = p->pre;
```

| 四种链表判定速览 | 空表条件 | 尾结点特征 | 遍历终止 |
|------------------|----------|-----------|----------|
| 单链表 | `L->next == NULL` | `p->next == NULL` | `p != NULL` |
| 循环单链表 | `L->next == L` | `p->next == L` | `p != L` |
| 双链表 | `L->next == NULL` | `p->next == NULL` | `p != NULL` |
| 循环双链表 | `L->next == L`（且 `L->pre == L`） | `p->next == L` | `p != L` |

> ⚠️ 注意事项：普通双链表插删要判 NULL（首元/尾结点边界），循环双链表因成环**天然不用判**；循环双链表尾插后还要 `L->pre = 新尾`。

> 🎯 规律：把"判 NULL"整体换成"判是否回到头结点 L"，普通链表的代码几乎原封不动搬进循环链表。

> 💡 一句话总结：双向免找前驱，循环判回头结点。

### 🧩 本章归纳：一条主线串全章

全章主线是一场存储结构的对决：**顺序表用"连续内存"换来 O(1) 随机读取，代价是插删整体搬移；链表用"指针"换来 O(1) 的插删，代价是查找必须从头遍历**。选谁，取决于场景"读多还是改多、大小是否可测"。

| 你的需求 | 选谁 | 付出什么 |
|----------|------|----------|
| 下标直取、空间省 | 顺序表 | 插删 O(N)，大小固定 |
| 插删频繁、大小未知 | 单链表 | 查找 O(N)，每结点多付一个指针域 |
| 删除时不想回头找前驱 | 双链表 | 多维护 pre，更费空间 |
| 从任意结点走全表 | 循环链表 | 判空/遍历终止条件全部改写 |

回头看才看得见的三条联系：
1. **存储结构决定允许的操作**：连续存储才有"下标即地址"，指针结构才有"改两个指针完成插删"——逻辑上是同一个线性表 ADT，物理实现决定了各操作的成本。
2. **每种结构的缺陷催生下一种结构**：首元操作不统一 → 加头结点当哨兵；单链表回不了头 → 双链表装 pre；走到底回不了家 → 循环链表接成环。
3. **所有指针操作共享一条铁律"先接后断"**：无论单链、双链、循环，先把新链接稳、再拆旧链，违者后半张表当场丢失。

## 🔍 相似概念辨析

### 组1：顺序表 vs 链表

| 对比维度 | 顺序表 | 链表 |
|----------|--------|------|
| 各自定义 | 以数组形式保存、地址连续依次存储的线性表 | 用指针链接结点、物理不连续逻辑连续的线性表 |
| 核心区别 | 空间连续、大小固定 | 物理不连续、大小不固定 |
| 各自特点 | 下标随机访问 O(1)；插删要整体搬移 O(N)；空间利用率高 | 只能从头遍历 O(N)；定位后插删只改指针；每结点多付一个指针域 |
| 使用场景 | 不需要对数据大量改动、频繁读取 | 频繁插删、元素个数运行时才知道 |
| 典型示例 | 第 3 位插 3：4~7 整体后移 | 改两个指针即完成插入 |
| 记忆口诀 | 顺序读快改慢，链表改快找慢 | |

### 组2：带头结点 vs 不带头结点

| 对比维度 | 带头结点 | 不带头结点 |
|----------|----------|-----------|
| 各自定义 | 头指针指向一个不存数据的哨兵结点 | 头指针直接指向首元结点 |
| 核心区别 | 首元结点前始终有"垫片"，头指针值永不变 | 在首元结点前插入即修改头指针 |
| 各自特点 | 空表/非空表/首元结点操作统一 | 首元前插入需单独设计实现方法 |
| 使用场景 | 教材与工程默认首选 | 极简场合 |
| 典型示例 | 空表判定 `L->next == NULL` | 空表判定 `L == NULL` |
| 记忆口诀 | 加个门卫，操作统一 | |

### 组3：单链表 vs 双链表

| 对比维度 | 单链表 | 双链表 |
|----------|--------|--------|
| 各自定义 | 每个节点只含一个指向后继的指针域 | 结点含 next（后继）与 pre（前驱）两个指针域 |
| 核心区别 | 单向：找前驱必须从头遍历 | 双向：拿到 p 即知前后 |
| 各自特点 | 结点省空间；删除需先找前驱 | 删 p 自身一步到位；插删要多维护 pre、费空间 |
| 使用场景 | 只需顺序遍历（链栈、链队列） | 需要前后双向访问（双端队列、LRU） |
| 典型示例 | `q->next = p->next`（q 为前驱） | `p->pre->next = p->next; p->next->pre = p->pre` |
| 记忆口诀 | 单向回头难，双向来回窜 | |

### 组4：单向链表 vs 循环单链表

| 对比维度 | 单向链表 | 循环单链表 |
|----------|----------|-----------|
| 各自定义 | 尾结点指针域为空（^） | 尾结点指针域指回头结点，成环 |
| 核心区别 | 遍历终点是 NULL | 遍历终点是回到头结点 L |
| 各自特点 | 空表 `L->next==NULL`，遍历判 `p!=NULL` | 空表头结点自指 `L->next==L`，遍历判 `p!=L` |
| 使用场景 | 普通线性序列 | 从任意结点出发可走全表、轮转处理 |
| 典型示例 | `while(p != NULL)` | `while(p != L)` |
| 记忆口诀 | 判空看 NULL，循环看回头 | |

## 📋 速查表

### 顺序表模板
```c
typedef struct { int *data; int s; } Array;   // data数组 + 表长s
初始化：malloc(sizeof(int)*maxx);  s = 0;
尾加  ：判满(s==maxx) → data[s]=k; s++;
插入  ：for(j=s-1; j>=i; j--) data[j+1]=data[j]; data[i]=k; s++;   // 倒移！
删除  ：i=Find(k); for(j=i+1; j<=s-1; j++) data[j-1]=data[j]; s--;
查找  ：顺序扫描返回下标，不存在返回 -1
```

### 单链表插删四句模板
```c
头插：s->next = L->next;  L->next = s;                 // 先接后断，反序
尾插：while(p->next) p=p->next;  s->next=p->next;  p->next=s;   // 保序
后插：s->next = p->next;  p->next = s;                 // p之后插s
删除：q->next = p->next;  free(p);  p=NULL;            // q为p前驱
```

### 四种链表判定速览
| 结构 | 空表 | 找尾循环 | 遍历终止 |
|------|------|----------|----------|
| 单链表 | `L->next==NULL` | `while(p->next!=NULL)` | `p!=NULL` |
| 循环单链表 | `L->next==L` | `while(p->next!=L)` | `p!=L` |
| 双链表 | `L->next==NULL` | `while(p->next!=NULL)` | `p!=NULL` |
| 循环双链表 | `L->next==L 且 L->pre==L` | `while(p->next!=L)` | `p!=L` |

### 复杂度速览
```
顺序表：读取 O(1)；插入/删除 O(N)；查找 O(N)
链  表：查找/定位 O(N)；定位后插入/删除 O(1)
空间：顺序表一次性分配 maxx；链表按结点动态 malloc
```

### 建表口诀
```
头插反序尾插保序；先接后断；free 置 NULL；查找从首元开始；头结点必须建在堆上。
```
