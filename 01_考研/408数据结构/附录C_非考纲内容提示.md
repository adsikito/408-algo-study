## C-1　动态规划：方法论与两大前提【非考纲】

**是什么**：把「求全局最优」拆成「求一系列子问题的最优」，子问题解存表复用。两大前提：
1. **最优子结构**：全局最优解由子问题最优解构成；
2. **重叠子问题**：朴素递归会反复解同一个子问题（计数即可验证）。

**为什么**：分治无重叠（快排左右互不相干），贪心无回溯（每步局部定全局）；DP 介于其间——重叠子问题 + 需要跨步决策。判断「该不该 DP」先验这两条。

**怎么用（解题四步法）**：
1. **定义状态**：`dp[i]` / `dp[i][j]` 表示什么（一句话说清、无歧义）；
2. **找转移**：`dp[i]` 由哪些更小的 dp 决定（转移方程）；
3. **定序**：保证算 dp[i] 时依赖项已算好（正推 / 逆推 / 逐层）；
4. **定初值与答案**：边界态、最终取哪个格子。

```c
/* 最大子段和：dp[i] = 以 i 结尾的最大子段和（状态定义的示范） */
long long maxSub(int a[], int n) {
    long long best = a[0], cur = a[0];
    for (int i = 1; i < n; i++) {
        cur = (cur > 0) ? cur + a[i] : a[i];   /* 前缀为负则弃 */
        if (cur > best) best = cur;
    }
    return best;
}
```

> **【规律】** 「递归 → 记忆化 → 递推表」是一条流水线：先写朴素递归，加个缓存数组成记忆化，再把调用顺序翻转成填表——三种形态对应同一转移方程，竞赛侧常用记忆化打表省去定序烦恼。

## C-2　0-1 背包【非考纲】

**是什么**：n 件物品，各重 w[i]、值 v[i]，容量 C，每件至多选一次，求最大总价值。

**状态**：`dp[i][c]` = 前 i 件、容量 c 的最大价值。
**转移**：`dp[i][c] = max(dp[i−1][c], dp[i−1][c−w[i]] + v[i])`（不选 / 选）。
**初值**：`dp[0][*] = 0`；答案 `dp[n][C]`。

```c
/* 二维版（教学用） */
long long dp[105][100005];
void knap2(int n, int C, int w[], long long v[]) {
    for (int i = 1; i <= n; i++)
        for (int c = 0; c <= C; c++) {
            dp[i][c] = dp[i - 1][c];
            if (c >= w[i] && dp[i - 1][c - w[i]] + v[i] > dp[i][c])
                dp[i][c] = dp[i - 1][c - w[i]] + v[i];
        }
}

/* 一维优化：容量必须【倒序】——正序会让本物品被选两次 */
long long f[100005];
void knap1(int n, int C, int w[], long long v[]) {
    for (int i = 1; i <= n; i++)
        for (int c = C; c >= w[i]; c--)      /* 倒序！ */
            if (f[c - w[i]] + v[i] > f[c])
                f[c] = f[c - w[i]] + v[i];
}
```

> **【规律】** **一维倒序的原因**（选择/填空级理解）：倒序时 `f[c−w[i]]` 还是「上一行」（未含第 i 件）的值，保证每件至多选一次；正序则 `f[c−w[i]]` 已被本轮更新过，等于**完全背包**。0-1 背包倒序、完全背包正序——一字之差，考过辨析。

**表格推演示范**（w = {1,2,3}，v = {6,10,12}，C = 5，0-1）：
| c | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| i=1 (w1,v6) | 6 | 6 | 6 | 6 | 6 |
| i=2 (w2,v10) | 6 | 10 | 16 | 16 | 16 |
| i=3 (w3,v12) | 6 | 10 | 16 | 18 | 22 |

（c = 0 列恒为 0，省略。）

答案 f[5] = 22（选 2、3 两件：10 + 12）。

## C-3　完全背包与常见变体【非考纲】

- **完全背包**（每件无限件）：一维**正序**；`f[c] = max(f[c], f[c−w[i]] + v[i])`，c 从小到大。
- **多重背包**（第 i 件至多 s[i] 件）：s[i] 拆成二进制捆（1,2,4,…）化归 0-1 背包。
- **分组背包**：每组至多选一件，组间正序组内枚举。
- 求方案数：把 max 换成 `+`（`f[c] += f[c−w[i]]`）；求恰好装满：初值 `f[0]=0` 其余 −∞。

> **【规律】** 四种背包共用一个状态定义，差异全部浓缩在「循环顺序 + 转移取值」两处——背一张表即可：

| 变体 | 循环顺序 | 转移 |
|------|---------|------|
| 0-1 | 容量倒序 | max |
| 完全 | 容量正序 | max |
| 方案数 | 同上两行 | +（求和） |
| 恰好装满 | 同上 | max / +，初值 −∞ |

## C-5　真题里的「超纲伪装」识别
