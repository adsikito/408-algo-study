## 本章地图

本章解决一个问题：**「一串数据要按顺序存起来，用连续的内存还是散开的内存？」**

## 本章重点

> **【重点】** **顺序表插入删除的元素移动方向与次数**：
> 插入要**从后往前**移动，删除要**从前往后**移动；平均移动约 **n/2** 个元素。
> 这是本章最容易失分的计算点。
>
> **【重点】** **链表的四种插入位置**：表头、表尾、结点前、结点后。
> 其中「**在结点前插入**」在没有前驱指针时需要**先交换数据再插入**（不能只改指针）。
>
> **【重点】** **时间复杂度要区分「查找」与「插入」**：
> 顺序表的插入是 O(n)（移动元素），链表的插入是 O(1)（改指针），
> **但链表找到插入位置本身要 O(n)**。所以「链表插入是 O(1)」这句话**必须附带前提**：
> **已知前驱结点**。

## 本章难点

> **【难点】** **头结点的作用**。为什么链表要设一个不存数据的头结点？
> 它有四个作用：统一空表与非空表的操作、统一首元结点与其他结点的插入删除、
> 便于在表头操作、简化边界判断。**不设头结点的链表，所有操作都要分情况讨论。**
>
> **【难点】** **链表操作中指针的修改顺序**。改错顺序会让结点「失联」或「成环」，
> 这是链表题的主要错误来源。

## 本章易错点

> **【易错】** 顺序表插入时**正着**移动元素。正着移动会用前一个元素覆盖后一个，
> 整段数据被污染。**插入从后往前，删除从前往后。**
>
> **【易错】** **`malloc` 之后不判 `NULL`**，以及 **`free` 之后继续使用指针**。
>
> **【易错】** 链表遍历时用 `p == NULL` 还是 `p->next == NULL` 作为终止条件搞错，
> 导致漏掉最后一个结点或访问空指针。
>
> **【易错】** 认为「链表一定比顺序表好」。链表的每个结点要额外存指针（存储密度 < 1），
> 且不支持随机访问。**要按运算特点选。**

## 知识点讲解

### 1-1　线性表的定义与基本操作　【P1】

**是什么**：n 个**相同数据类型**的数据元素的**有限序列**。

严格定义：若线性表记为 `(a₁, a₂, ..., aₙ)`，则：

- `a₁` 是**唯一**的「第一个」元素（表头元素），无前驱
- `aₙ` 是**唯一**的「最后一个」元素（表尾元素），无后继
- 除 `a₁` 外，每个元素**有且仅有一个**直接前驱
- 除 `aₙ` 外，每个元素**有且仅有一个**直接后继

**关键点**：

| 特征 | 含义 |
|------|------|
| 有序 | 元素之间**有次序**，位置不能随意交换 |
| 有限 | 元素个数 n 有限，n = 0 时称**空表** |
| 同类型 | 每个元素占用相同的空间、有相同的数据类型 |

**九种基本操作**：

| 操作 | 含义 | 是否改变表长 |
|------|------|------------|
| `InitList(&L)` | 初始化，构造空表 | — |
| `Length(L)` | 求表长 | 否 |
| `LocateElem(L, e)` | 按值查找，返回位置 | 否 |
| `GetElem(L, i)` | 按位查找，返回第 i 个元素 | 否 |
| `ListInsert(&L, i, e)` | 在第 i 个位置插入 e | **是（+1）** |
| `ListDelete(&L, i, &e)` | 删除第 i 个元素，用 e 返回其值 | **是（-1）** |
| `PrintList(L)` | 输出全部元素 | 否 |
| `Empty(L)` | 判空 | 否 |
| `DestroyList(&L)` | 销毁 | — |

> **【重点】** **参数中带 `&` 的表示「引用了表本身，操作会改变表」**。
> `InitList(&L)`、`ListInsert(&L, ...)`、`ListDelete(&L, ...)`、`DestroyList(&L)`
> 都会改变表；而 `Length(L)`、`GetElem(L, i)` 只读不改，因此不带 `&`。
> **这个细节在算法设计题的答题模板中要写对。**

**为什么**：线性表是**最基础的数据结构**。408 考纲把它单列一章，
目的不是让你背定义，而是让你掌握**「同一逻辑结构的两种存储实现」这一分析范式** ——
这个范式会在树、图等章节反复使用。

> **【类比】** 线性表像**一列队伍**：有明确的排头与排尾，
> 除了排头每个人都有唯一的前一个人，除了排尾每个人都有唯一的后一个人。
> **队伍可以排成一条直线（顺序表），也可以手拉手散开站（链表）。**

> **【记忆】** **一对一，有头有尾，头无前驱，尾无后继。**

**前置与延伸**：
- 前置：无
- 延伸：栈与队列是「操作受限的线性表」（第 2 章）；串是「内容受限的线性表」（第 3 章）

### 1-2　顺序表的定义与随机访问　【P0】

**是什么**：用**一组地址连续**的存储单元依次存储线性表的数据元素。

**核心公式**（设首地址为 `LOC(a₁)`，每个元素占 `sizeof(ElemType)` 字节）：

```text
第 i 个元素的地址：LOC(aᵢ) = LOC(a₁) + (i - 1) × sizeof(ElemType)

若数组下标从 0 开始（C 语言）：
    LOC(a[i]) = LOC(a[0]) + i × sizeof(ElemType)
```

> **【重点】** **这个公式就是「随机访问」的全部秘密。**
> 因为地址能**直接算出来**，所以访问任意位置都是 O(1)，不需要从头找。

**为什么**：随机访问是顺序表**唯一的、决定性的优势**。
只要题目需要「按下标访问」，顺序表就是答案。

**怎么用**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>
#include <stdlib.h>

#define MAXSIZE 100              /* 顺序表的最大容量 */

typedef struct {
    int data[MAXSIZE];           /* 静态分配的数组 */
    int length;                  /* 当前长度 */
} SqList;

/* 初始化：把长度置 0 即可，不需要清空数组内容 */
void InitList(SqList *L) {
    L->length = 0;
}

/* 按位查找：返回第 i 个元素（i 从 1 开始），O(1) */
int GetElem(SqList *L, int i, int *e) {
    if (i < 1 || i > L->length) return 0;    /* 边界：i 的有效范围是 [1, length] */
    *e = L->data[i - 1];                     /* 下标换算：第 i 个 → data[i-1] */
    return 1;
}

/* 按值查找：返回第一个等于 e 的位置，找不到返回 0，O(n) */
int LocateElem(SqList *L, int e) {
    for (int i = 0; i < L->length; i++) {
        if (L->data[i] == e) return i + 1;   /* 换算回 1 起始 */
    }
    return 0;
}

int main(void) {
    SqList L;
    InitList(&L);

    for (int i = 1; i <= 5; i++) {           /* 手工填 5 个元素 */
        L.data[i - 1] = i * 10;
        L.length++;
    }

    int e;
    if (GetElem(&L, 3, &e)) printf("第 3 个元素 = %d（O(1)）\n", e);
    printf("值 40 的位置 = %d（O(n)）\n", LocateElem(&L, 40));
    printf("表长 = %d\n", L.length);
    return 0;
}
```

> **【规律】** **地址计算题的两条口径**：
>
> | 情形 | 公式 |
> |------|------|
> | 下标从 1 开始 | `LOC(aᵢ) = LOC(a₁) + (i-1) × size` |
> | 下标从 0 开始 | `LOC(a[i]) = LOC(a[0]) + i × size` |
>
> **408 常考「第 i 个元素的地址」，若题面说「第 i 个」则用 1 起始公式。**

> **【易错】** 三处：
> 1. **`i` 与 `i-1` 混用** —— 题面说「第 i 个」时，数组下标是 `i-1`。
>    **这是 408 最常见的低级错误。**
> 2. **忘记判 `i` 的范围** —— 有效范围是 `[1, length]`，不是 `[1, MAXSIZE]`。
>    访问未使用的位置虽然不越界，但读到的是无效数据。
> 3. **静态分配溢出** —— `length` 达到 `MAXSIZE` 后不能再插入。动态分配版本见附录。

> **【类比】** 顺序表像**字典的连续页码**：知道第 100 页在第几页之后，
> 能直接翻到；但要插一页进去，后面所有页码都得重编。

> **【记忆】** **地址 = 首地址 + (序号 - 1) × 元素大小。随机访问 O(1) 全靠它。**

**前置与延伸**：
- 前置：知识点 1
- 延伸：第 2 章的多维数组地址计算是本章公式的推广（行优先、列优先）

### 1-3　顺序表的插入与删除　【P0】

**是什么**：在顺序表中间插入或删除元素时，为保持**物理连续性**，
必须移动受影响的全部元素。

**为什么**：这是顺序表的**根本代价** —— 随机访问 O(1) 是用「插入删除 O(n)」换来的。
理解这一点，就理解了顺序表与链表的分工。

**怎么用**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>

#define MAXSIZE 100

typedef struct {
    int data[MAXSIZE];
    int length;
} SqList;

/* 插入：在第 i 个位置插入 e（i 从 1 开始） */
int ListInsert(SqList *L, int i, int e) {
    if (i < 1 || i > L->length + 1) return 0;   /* 边界：可插在表尾之后，故上界是 length+1 */
    if (L->length >= MAXSIZE) return 0;         /* 边界：表满 */

    /* 关键：从后往前移动，为 e 腾出位置 data[i-1] */
    for (int j = L->length; j >= i; j--) {
        L->data[j] = L->data[j - 1];            /* 后一个 ← 前一个 */
    }
    L->data[i - 1] = e;
    L->length++;
    return 1;
}

/* 删除：删除第 i 个元素，用 e 返回其值 */
int ListDelete(SqList *L, int i, int *e) {
    if (i < 1 || i > L->length) return 0;       /* 边界：上界是 length，不是 length+1 */
    *e = L->data[i - 1];

    /* 关键：从前往后移动，填补被删元素留下的空位 */
    for (int j = i; j < L->length; j++) {
        L->data[j - 1] = L->data[j];            /* 前一个 ← 后一个 */
    }
    L->length--;
    return 1;
}

void Print(SqList *L) {
    for (int i = 0; i < L->length; i++) printf("%d ", L->data[i]);
    printf("\n");
}

int main(void) {
    SqList L = {{1, 2, 3, 4, 5}, 5};

    ListInsert(&L, 3, 99);       /* 在第 3 个位置插 99 */
    printf("插入后："); Print(&L);      /* 1 2 99 3 4 5 */

    int e;
    ListDelete(&L, 1, &e);       /* 删除第 1 个元素 */
    printf("删除的元素 = %d，删除后：", e); Print(&L);   /* 99，2 99 3 4 5 */
    return 0;
}
```

**平均移动次数（必考计算）**：

设表长为 n，在位置 i 插入（i 取值 1 至 n+1，共 n+1 种）：

| 情形 | 移动次数 |
|------|---------|
| 插入 | `n - i + 1` |
| 删除 | `n - i` |

**等概率假设下（每种位置概率 1/(n+1) 与 1/n）**：

```text
插入平均移动 = 1/(n+1) × Σ(i=1 到 n+1)(n-i+1) = n/2
删除平均移动 = 1/n     × Σ(i=1 到 n)(n-i)      = (n-1)/2
```

> **【重点】** **结论：平均移动约 n/2 个元素，时间复杂度 O(n)。**
> 这个「n/2」是考试的固定考点，需要能推出过程，不只是背结论。

> **【易错】** 三处，前两条是致命的：
> 1. **插入时正着移动元素** —— 会用一个元素覆盖后一个，数据被污染。
>    **记忆：插入「从后往前」，删除「从前往后」，都是「腾位置」。**
> 2. **插入与删除的 `i` 上界搞反** —— 插入上界是 `length + 1`（可在表尾后插入），
>    删除上界是 `length`（不能删不存在的元素）。
> 3. **忘记判表满** —— `length >= MAXSIZE` 时插入会越界。

> **【类比】** 插队像**给一队人腾位置**：新来的人要插到第 3 位，
> 那么从**队尾往队头**逐个后移一人，最后第 3 个位置才空出来。
> 若从队头往后移，第 3 个人会被第 2 个人直接挤掉（覆盖）。

> **【记忆】** **插后往前，删前往后；插入均值 n/2，删除均值 (n-1)/2。**

**前置与延伸**：
- 前置：知识点 2
- 延伸：链表的插入删除**不需要移动元素**，代价换成「找到位置要 O(n)」，见知识点 5

### 1-4　单链表的建立与查找　【P0】

**是什么**：用一组**任意的**存储单元存放线性表元素，每个结点除数据外还存**指向后继的指针**。

**结点定义**：

```c
typedef struct LNode {
    int data;               /* 数据域 */
    struct LNode *next;     /* 指针域，指向后继 */
} LNode, *LinkList;
```

**头结点**：在首元结点之前附加的一个结点，**数据域不存有效数据**。

| 有无头结点 | 空表表示 | 首元结点插入 | 影响 |
|-----------|---------|------------|------|
| **有**（推荐） | `L->next == NULL` | 与在中间插入**写法相同** | 操作统一，边界少 |
| 无 | `L == NULL` | **需单独处理**（要改头指针） | 每个操作都要分两种情况 |

> **【重点】** **头结点的四个作用**（简答题常考）：
> 1. 统一空表与非空表的处理（空表也有头结点，`next` 为 `NULL`）
> 2. 统一首元结点与其他结点位置的插入删除（都有前驱结点可依附）
> 3. 便于在表头插入与删除（不需要改头指针本身）
> 4. 简化边界判断，减少分支

**为什么**：链表用**指针**代替了顺序表的「物理位置」，
因此插队不再需要挪动别人，但也失去了「下标直算地址」的能力。

**怎么用**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

/* 头插法建表：每次新结点都插在头结点之后 */
/* 注意：头插法得到的链表顺序与输入顺序【相反】 */
LinkList CreateByHead(int a[], int n) {
    LinkList L = (LinkList)malloc(sizeof(LNode));   /* 头结点 */
    if (L == NULL) return NULL;                     /* 边界：申请失败 */
    L->next = NULL;

    for (int i = 0; i < n; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        if (s == NULL) return L;
        s->data = a[i];
        s->next = L->next;      /* 新结点接上原来的首元 */
        L->next = s;            /* 头结点指向新结点 */
    }
    return L;
}

/* 尾插法建表：用尾指针 r 挂在末尾，顺序与输入一致 */
LinkList CreateByTail(int a[], int n) {
    LinkList L = (LinkList)malloc(sizeof(LNode));
    if (L == NULL) return NULL;
    L->next = NULL;
    LNode *r = L;               /* r 始终指向当前尾结点 */

    for (int i = 0; i < n; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        if (s == NULL) return L;
        s->data = a[i];
        s->next = NULL;
        r->next = s;            /* 挂到尾部 */
        r = s;                  /* 更新尾指针 */
    }
    return L;
}

/* 按序号查找：返回第 i 个结点（i 从 1 开始），O(n) */
LNode *GetElem(LinkList L, int i) {
    if (i < 1) return NULL;
    LNode *p = L->next;                     /* p 指向首元结点 */
    int j = 1;
    while (p != NULL && j < i) {            /* 边界：p 为空即到头 */
        p = p->next;
        j++;
    }
    return p;                               /* 返回 NULL 表示未找到 */
}

/* 按值查找：返回第一个数据为 e 的结点，O(n) */
LNode *LocateElem(LinkList L, int e) {
    LNode *p = L->next;
    while (p != NULL && p->data != e) p = p->next;
    return p;
}

void Print(LinkList L) {
    for (LNode *p = L->next; p != NULL; p = p->next) printf("%d ", p->data);
    printf("\n");
}

void Destroy(LinkList L) {
    LNode *p = L;
    while (p != NULL) { LNode *t = p->next; free(p); p = t; }
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};

    LinkList h = CreateByHead(a, 5);
    printf("头插法（顺序相反）："); Print(h);

    LinkList t = CreateByTail(a, 5);
    printf("尾插法（顺序一致）："); Print(t);

    LNode *p = GetElem(t, 3);
    printf("第 3 个结点 = %d（O(n)，因为要逐个走）\n", p ? p->data : -1);

    Destroy(h); Destroy(t);
    return 0;
}
```

> **【重点】** **头插法与尾插法的顺序差异**是必考细节：
>
> | 建表方法 | 结果顺序 | 需要的额外指针 |
> |---------|---------|--------------|
> | 头插法 | **与输入顺序相反** | 无（只改 `L->next`） |
> | 尾插法 | 与输入顺序一致 | 需要一个尾指针 `r` |
>
> **应用**：需要「逆序」时用头插法（如链表反转的简化写法）；
> 需要保持原顺序时用尾插法。

> **【易错】** 四处：
> 1. **遍历终止条件写错**。
>    - 要**处理所有结点**：`while (p != NULL)`
>    - 要**在最后一个结点停止**（如需访问 `p->next`）：`while (p->next != NULL)`
>    - 写错会导致**漏掉最后一个结点**或**访问空指针**。
> 2. **忘记给新结点的 `next` 赋 `NULL`**（尾插法）—— 链表尾部连接了随机内存。
> 3. **`malloc` 不判空** —— 内存不足时返回 `NULL`，直接解引用会崩溃。
> 4. **头插法误以为顺序一致** —— 见上表。

> **【类比】** 头结点像**队伍的「举旗人」**：他不算队员，
> 但所有人都站在他后面。有了他，「插在队首」和「插在队中」的动作就完全一样了。

> **【记忆】** **头结点是「举旗人」，不算队员但统一了所有操作。**

- 前置：知识点 2、3
- 延伸：第 2 章的链栈、链队列都用本章的结点结构与头结点技巧

### 1-5　单链表的插入与删除　【P0】

**是什么**：修改指针以改变结点之间的连接关系，**不需要移动数据**。

**为什么**：这是链表相对顺序表的**核心优势**。但要注意前提 ——
**已知前驱结点**时插入删除才是 O(1)；若需先查找位置，整体仍是 O(n)。

**怎么用**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>
#include <stdlib.h>

typedef struct LNode { int data; struct LNode *next; } LNode, *LinkList;

LinkList CreateByTail(int a[], int n) {
    LinkList L = (LinkList)malloc(sizeof(LNode));
    L->next = NULL;
    LNode *r = L;
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = a[i]; s->next = NULL;
        r->next = s; r = s;
    }
    return L;
}

void Print(LinkList L) {
    for (LNode *p = L->next; p; p = p->next) printf("%d ", p->data);
    printf("\n");
}

/* 在结点 p 之后插入 s */
/* 关键：先接后，再接前 —— 顺序反了会丢失 p 原来的后继 */
void InsertAfter(LNode *p, LNode *s) {
    s->next = p->next;        /* 第 1 步：s 接上 p 的后继 */
    p->next = s;              /* 第 2 步：p 指向 s */
}

/* 在结点 p 之前插入 s（无前驱指针的经典技巧） */
/* 做法：把 s 插到 p 之后，然后【交换 p 与 s 的数据】 */
/* 结果：逻辑上等价于「s 插在 p 之前」，代价 O(1) */
void InsertBefore(LNode *p, LNode *s) {
    s->next = p->next;
    p->next = s;
    /* 交换数据域，使 p 位置上的值变成新值，s 位置上的值变成原 p 的值 */
    int tmp = p->data; p->data = s->data; s->data = tmp;
}

/* 删除结点 p 的后继结点 */
int DeleteAfter(LNode *p, int *e) {
    LNode *q = p->next;
    if (q == NULL) return 0;        /* 边界：p 已是尾结点 */
    *e = q->data;
    p->next = q->next;              /* 跳过 q */
    free(q);                        /* 释放被删结点 */
    return 1;
}

/* 删除结点 p 本身（无前驱指针的经典技巧） */
/* 做法：把后继结点的数据复制到 p，然后删除后继结点 */
/* 限制：p 不能是尾结点（尾结点无后继可复制） */
int DeleteNode(LNode *p, int *e) {
    LNode *q = p->next;
    if (q == NULL) return 0;        /* 边界：尾结点无法用此法删除 */
    *e = p->data;                   /* 返回的是原 p 的值 */
    p->data = q->data;              /* 后继的值搬到 p */
    p->next = q->next;              /* p 跳过 q */
    free(q);
    return 1;
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};

    LinkList L = CreateByTail(a, 5);
    printf("原链表：        "); Print(L);

    LNode *s = (LNode *)malloc(sizeof(LNode)); s->data = 99;
    InsertAfter(L->next, s);                 /* 在首元结点后插 99 */
    printf("首元后插 99：   "); Print(L);

    LNode *s2 = (LNode *)malloc(sizeof(LNode)); s2->data = 77;
    InsertBefore(L->next, s2);               /* 在首元结点前插 77（交换数据法） */
    printf("首元前插 77：   "); Print(L);

    int e;
    DeleteAfter(L->next, &e);
    printf("删后继得 %d：    ", e); Print(L);

    DeleteNode(L->next->next, &e);
    printf("删当前得 %d：    ", e); Print(L);
    return 0;
}
```

> **【重点】** **两个「无前驱指针」的经典技巧**（算法设计题高频）：
>
> | 需求 | 做法 | 代价 | 限制 |
> |------|------|------|------|
> | 在 p **之前**插入 s | 把 s 插到 p 之后，**交换 p 与 s 的数据** | O(1) | 无 |
> | 删除 p **本身** | 把后继的数据复制到 p，**删除后继** | O(1) | **p 不能是尾结点** |
>
> 这两个技巧的**共同思想**：把「改前驱」转化为「改后继 + 搬数据」。
> **因为单链表只能沿 `next` 前进，无法回退。**

> **【易错】** 四处：
> 1. **插入时指针修改顺序反了**。必须先 `s->next = p->next` 再 `p->next = s`。
>    反过来会让 `p->next` 先被覆盖，**s 与链表后半段失联**。
>    **记忆：先接后，再接前。**
> 2. **删除后忘记 `free`** —— 内存泄漏（408 算法设计题会扣分）。
> 3. **`free(q)` 之后继续用 `q`** —— 悬垂指针。
> 4. **对尾结点用「交换数据法」删除** —— 尾结点无后继，此法失效，必须从头找前驱。

> **【类比】** 改指针像**改接力赛的交接顺序**：必须先把新人接到下一个人手里（先接后），
> 再让前一个人把棒交给新人（再接前）。顺序反了，新人就拿着棒跑丢了。

> **【记忆】** **先接后，再接前；删自身就搬后继的数据。**

**前置与延伸**：
- 前置：知识点 4
- 延伸：算法设计题常考「链表反转」「找中间结点」「判环」，都建立在本知识点之上

### 1-6　顺序表与链表的对比与选型　【P0】

**是什么**：把两种实现放在同一张表上比较，得出选型规则。

| 对比维度 | 顺序表 | 链表 |
|---------|--------|------|
| 存储方式 | 连续内存，逻辑相邻即物理相邻 | 任意内存，靠指针连接 |
| **随机访问** | **O(1)** | **O(n)** |
| 按值查找 | O(n) | O(n) |
| 按位查找 | **O(1)** | O(n) |
| 插入删除（已知位置） | **O(n)**（移动元素） | **O(1)**（改指针） |
| 存储密度 | **1**（无额外开销） | **< 1**（每结点多一个指针） |
| 容量 | 需预分配，可能溢出 | 动态申请，不受预分配限制 |
| 是否需要 `malloc` | 否 | **是**（有失败风险） |

**选型规则（三条）**：

```text
1. 需要频繁按下标访问        → 顺序表
2. 需要频繁在中间插入删除    → 链表
3. 数据规模可预估且不大变    → 顺序表；否则链表
```

**408 中的实际分布**：

| 题型 | 更常用 |
|------|-------|
| 数组类算法设计题（第 41 题常见） | 顺序表 |
| 链表类算法设计题 | 链表 |
| 求第 k 小 / 二分查找 | 顺序表 |
| 频繁插入删除的模拟 | 链表 |

> **【重点】** **「链表插入删除是 O(1)」这句话必须附带前提：已知前驱结点。**
> 若需要先查找位置，则查找本身是 O(n)，整体仍是 O(n)。
> **这是本知识点最容易被追问的一点。**

> **【易错】** 三处：
> 1. **不附带前提地说「链表更快」** —— 见上。
> 2. **忘记存储密度** —— 链表的每个结点为存一个指针付出额外空间，
>    在内存受限时顺序表可能反而更优。
> 3. **认为顺序表不能动态扩容** —— 可以用动态分配（`malloc` 一个数组）实现，
>    但那又变成一个「需要预分配 + 可能重新分配」的结构。

> **【类比】** 顺序表像**纸质通讯录**：按姓氏页码排好，查得快，
> 但加一个人就得重抄后面所有页。
> 链表像**纸条接力**：加人只改两张纸条，但想找第 100 个人得从头问。

> **【记忆】** **顺序快在「找」，链式快在「插」；链式的前提是「已知前驱」。**

**前置与延伸**：
- 前置：知识点 3、5
- 延伸：第 6 章的查找、第 7 章的排序都会反复用到这张对比表

### 1-7　双链表　【P1】

**是什么**：每个结点除后继指针外，还有一个**指向前驱**的指针。

```c
typedef struct DNode {
    int data;
    struct DNode *prior, *next;    /* 前驱 + 后继 */
} DNode, *DLinkList;
```

**为什么**：单链表**只能前进不能后退**，因此「找前驱」必须从头遍历（O(n)）。
双链表用**多存一个指针**的代价，换来了 O(1) 找前驱。

**怎么用**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>
#include <stdlib.h>

typedef struct DNode { int data; struct DNode *prior, *next; } DNode, *DLinkList;

/* 在结点 p 之后插入 s —— 四步，顺序有讲究 */
void InsertAfterD(DNode *p, DNode *s) {
    s->next = p->next;                 /* 1. s 接后继 */
    if (p->next != NULL) p->next->prior = s;  /* 2. 后继回指 s（边界：p 是尾结点时跳过） */
    s->prior = p;                      /* 3. s 回指 p */
    p->next = s;                       /* 4. p 指向 s */
}

/* 删除结点 p —— 两步 */
void DeleteD(DNode *p) {
    if (p->prior != NULL) p->prior->next = p->next;   /* 前驱跨过 p */
    if (p->next != NULL)  p->next->prior = p->prior;  /* 后继回指 p 的前驱 */
    free(p);
}

void PrintD(DLinkList L) {
    for (DNode *p = L->next; p; p = p->next) printf("%d ", p->data);
    printf("\n");
}

int main(void) {
    /* 建表：1 2 3，带头结点 */
    DLinkList L = (DLinkList)malloc(sizeof(DNode));
    L->prior = NULL; L->next = NULL;
    DNode *r = L;
    for (int i = 1; i <= 3; i++) {
        DNode *s = (DNode *)malloc(sizeof(DNode));
        s->data = i;
        s->prior = r; s->next = NULL;
        r->next = s; r = s;
    }
    printf("双链表："); PrintD(L);

    DNode *s = (DNode *)malloc(sizeof(DNode)); s->data = 99;
    InsertAfterD(L->next, s);
    printf("首元后插 99："); PrintD(L);

    /* 双链表的优势：找前驱 O(1) */
    DNode *p = L->next->next->next;             /* 指向 99 */
    printf("99 的前驱 = %d（O(1)，单链表要 O(n)）\n", p->prior->data);

    DeleteD(p);
    printf("删除 99 后："); PrintD(L);
    return 0;
}
```

> **【易错】** 三处：
> 1. **插入时漏判 `p->next != NULL`** —— 在尾结点后插入时空指针解引用会崩溃。
> 2. **四步顺序写错** —— 若先执行 `p->next = s`，
>    第 2 步就再也拿不到原来的后继结点了。**必须「先接后，再接前」。**
> 3. **删除时漏改一侧指针** —— 前驱的 `next` 与后继的 `prior` 都要改。

> **【类比】** 双链表像**双人自行车**：两个人都能用力（双向可走），
> 但车更重（多一个指针）。单链表像单人车：轻，但只能往前骑。

> **【记忆】** **双链表插入四步：s 接后 → 后回指 s → s 回指 p → p 指 s。**

**前置与延伸**：
- 前置：知识点 5
- 延伸：第 5 章的邻接表用「十字链表」表示有向图，就是双链表思想在图的推广

### 1-8　循环链表　【P1】

**是什么**：尾结点的 `next` 指向**头结点**（而不是 `NULL`），使链表成环。

**为什么**：从**任意结点**出发都能遍历全表。特别地，若只设**尾指针** `rear`，
则 `rear->next` 就是头结点，访问**表头与表尾都是 O(1)**。

**怎么用**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>
#include <stdlib.h>

typedef struct LNode { int data; struct LNode *next; } LNode, *LinkList;

/* 用尾指针建的循环链表：rear->next 是头结点 */
typedef struct { LNode *rear; } CirList;

/* 遍历的终止条件是「回到起点」，不是 NULL */
void PrintCir(LNode *rear) {
    if (rear == NULL) return;
    for (LNode *p = rear->next->next; p != rear->next; p = p->next) {
        printf("%d ", p->data);
        if (p == rear) break;          /* 边界：绕回时停止，防止死循环 */
    }
    printf("\n");
}

/* 两个循环链表合并（O(1)）：把 B 接到 A 的尾部 */
LNode *MergeCir(LNode *ra, LNode *rb) {
    if (ra == NULL) return rb;
    if (rb == NULL) return ra;
    LNode *headA = ra->next;           /* A 的头结点 */
    LNode *headB = rb->next;           /* B 的头结点 */
    ra->next = headB->next;            /* A 尾接 B 的首元 */
    rb->next = headA;                  /* B 尾接 A 的头结点，成环 */
    free(headB);                       /* 释放 B 多余的头结点 */
    return rb;                         /* 新尾是 B 的原尾 */
}

int main(void) {
    /* 建 1 2 3 的循环链表 */
    LNode *head = (LNode *)malloc(sizeof(LNode));
    head->next = NULL;
    LNode *r = head;
    for (int i = 1; i <= 3; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = i; s->next = NULL;
        r->next = s; r = s;
    }
    r->next = head;                    /* 关键：尾指回头结点，成环 */

    printf("循环链表："); PrintCir(r);

    /* 从尾结点出发，O(1) 得到表头与表尾 */
    printf("表尾 = %d（O(1)）\n", r->data);
    printf("表头 = %d（O(1)，即 rear->next->next）\n", r->next->next->data);
    return 0;
}
```

> **【易错】** 四处：
> 1. **遍历条件用 `p != NULL`** —— 循环链表永远不为 `NULL`，会**死循环**。
>    正确条件：`p != 头结点`。
> 2. **建表时忘记让尾指回头结点** —— 那就成了普通单链表。
> 3. **合并时忘记 `free` 多余的头结点** —— 链表出现两个头结点。
> 4. **从尾结点出发时误以为不能访问表头** —— 恰恰相反，这正是设尾指针的价值。

> **【类比】** 循环链表像**转盘**：转到哪里都能继续转下去。
> 普通链表像**一列火车**：开到终点就停了，要回起点得倒车。

> **【记忆】** **循环链表遍历看「是否回到起点」，不看 `NULL`。**

**前置与延伸**：
- 前置：知识点 5
- 延伸：约瑟夫环问题用循环链表求解最自然

### 1-9　静态链表　【P1】

**是什么**：用**数组**模拟链式结构 —— 数组元素含数据域与「游标」（下一个元素的下标），
游标代替指针。

```c
#define MAXSIZE 100
typedef struct {
    int data;      /* 数据域 */
    int next;      /* 游标，存下标而非地址。0 表示空（相当于 NULL） */
} SLinkList[MAXSIZE];
```

**为什么**：在没有指针的语言（如早期 BASIC、FORTRAN）中实现链式结构。
**408 考它是为了考「链式思想的通用性」** —— 链式结构的关键是「用额外信息表示逻辑关系」，
这个额外信息可以是指针（地址），也可以是数组下标（游标）。

**怎么用**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>

#define MAXSIZE 10
#define NIL 0                       /* 用 0 表示空指针（下标 0 不用来存数据） */

typedef struct { int data; int next; } SLinkList[MAXSIZE];

/* 用游标遍历：与指针遍历结构完全一致，只是 p = p->next 变成 i = a[i].next */
void PrintS(SLinkList a, int head) {
    for (int i = head; i != NIL; i = a[i].next) {
        printf("%d ", a[i].data);
    }
    printf("\n");
}

int main(void) {
    SLinkList a;
    /* 手工构造：下标 1→2→3，数据 10 20 30，尾结点的游标为 NIL */
    a[1].data = 10; a[1].next = 2;
    a[2].data = 20; a[2].next = 3;
    a[3].data = 30; a[3].next = NIL;

    printf("静态链表（游标 1→2→3）：");
    PrintS(a, 1);

    /* 在 20 之后插入 99：申请一个空闲下标 4 */
    a[4].data = 99;
    a[4].next = a[2].next;      /* 与指针插入逻辑完全相同 */
    a[2].next = 4;
    printf("插入 99 后：");
    PrintS(a, 1);
    return 0;
}
```

> **【重点】** **指针与游标的对应关系**（考试常考「游标是几」）：
>
> | 指针写法 | 静态链表写法 |
> |---------|------------|
> | `p = p->next` | `i = a[i].next` |
> | `p->next = q` | `a[i].next = j` |
> | `p == NULL` | `i == NIL`（通常取 0） |

> **【易错】** 三处：
> 1. **把游标当作下标 1 起始** —— 游标的取值取决于约定，本实现中 0 表示空，
>    因此有效数据从下标 1 开始。**但题面若用 `-1` 表示空，则从 0 开始。**
> 2. **忘记维护「空闲链表」** —— 完整实现需要把未使用的下标串成一条空闲链，
>    插入时从空闲链取结点，删除时归还。
> 3. **认为静态链表支持随机访问** —— 虽然靠数组实现，
>    但访问逻辑上第 i 个元素仍需沿游标走 i 步，**是 O(n)，不是 O(1)**。

> **【类比】** 静态链表像**停车场的车位表**：车位是预先画好的格子（数组），
> 每格里写着「下一辆车停在几号位」。**格子是固定的，车的顺序却能自由调整。**

> **【记忆】** **游标代替指针；遍历用 `i = a[i].next`；仍然是 O(n) 访问。**

**前置与延伸**：
- 前置：知识点 5
- 延伸：第 5 章的「邻接表」与第 6 章的「静态树」都用同样的游标思想

> **【重点】** 例题 1-1　链表反转（算法设计题，408 第 41 题常考题型）

**题干**：设计一个算法，将带头结点的单链表**就地逆置**（辅助空间 O(1)），
不得递归。

**题源**：408 常考题型（题型来源为大纲要求，非真题原题）
**涉及知识点**：1-5、1-6

**解题思路**：

1. **从题面信号切入**：「就地逆置 + 辅助空间 O(1)」→ 排除新建链表、排除递归（栈深 O(n)）、
   排除用数组暂存（O(n) 空间）。
2. **排除错误路径**：
   - 逐个结点 `malloc` 建新链表 → 空间 O(n)，不符。
   - 递归 → 空间 O(n)（递归栈），不符。
   - 只把数据域倒序交换 → 需要知道长度并逐个定位，时间 O(n²)，虽能通过但低效。
3. **最终方法**：**头插法**。遍历原链表，把每个结点头插到新链表（复用头结点），
   遍历一遍即完成。时间 O(n)，空间 O(1)。

**解答过程**：

设指针 `p` 从首元结点开始，逐个摘下并头插。

```text
初始：  head → 1 → 2 → 3 → 4 → NULL
第 1 轮：把 1 摘下，头插 → head → 1 → NULL，p 移到 2
第 2 轮：把 2 摘下，头插 → head → 2 → 1 → NULL，p 移到 3
第 3 轮：把 3 摘下，头插 → head → 3 → 2 → 1 → NULL，p 移到 4
第 4 轮：把 4 摘下，头插 → head → 4 → 3 → 2 → 1 → NULL，p 变 NULL
结束。
```

**代码实现**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>
#include <stdlib.h>

typedef struct LNode { int data; struct LNode *next; } LNode, *LinkList;

/* 就地逆置：头插法，时间 O(n)，空间 O(1) */
void ReverseList(LinkList L) {
    if (L == NULL || L->next == NULL) return;   /* 边界：空表或只有一个结点 */
    LNode *p = L->next;          /* p 指向待处理的结点 */
    L->next = NULL;              /* 先把结果链表置空 */
    while (p != NULL) {
        LNode *q = p->next;      /* 关键：先保存 p 的后继，否则摘链后找不到 */
        p->next = L->next;       /* 头插第 1 步：p 接上结果链表 */
        L->next = p;             /* 头插第 2 步：头结点指向 p */
        p = q;                   /* 继续处理原链表的下一个 */
    }
}

/* 辅助：尾插建表 */
LinkList Build(int a[], int n) {
    LinkList L = (LinkList)malloc(sizeof(LNode));
    L->next = NULL;
    LNode *r = L;
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = a[i]; s->next = NULL;
        r->next = s; r = s;
    }
    return L;
}

void Print(LinkList L) {
    for (LNode *p = L->next; p; p = p->next) printf("%d ", p->data);
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    LinkList L = Build(a, 5);
    printf("逆置前："); Print(L);
    ReverseList(L);
    printf("逆置后："); Print(L);          /* 5 4 3 2 1 */
    return 0;
}
```

**复杂度**：时间 O(n)（每个结点处理一次），空间 O(1)（只用两个指针变量）。

> **【易错】** 本题最容易错的两处：
> 1. **忘记先用 `q` 保存 `p->next`** —— 一旦执行 `p->next = L->next`，
>    `p` 原来的后继就丢了，**链表后半段失联**，遍历提前结束。
>    **记忆：摘结点之前，先握住它的下一环。**
> 2. **漏掉空表或单结点链表的边界判断** —— 虽然循环本身能处理，
>    但显式判断能让逻辑更清晰，且避免某些实现下的空指针问题。

> **【重点】** 例题 1-2　顺序表删除区间元素（算法设计题）

**题干**：从顺序表中删除所有值在 `[s, t]` 区间内的元素（`s < t`）。
要求时间复杂度 O(n)，空间复杂度 O(1)。若 s 或 t 不合法或表为空，返回错误。

**题源**：408 常考题型
**涉及知识点**：1-3

**解题思路**：

1. **从题面信号切入**：「O(n) 时间 + O(1) 空间」→ 排除「每删一个就整体前移」（那是 O(n²)），
   也排除「用辅助数组暂存」（那是 O(n) 空间）。
2. **排除错误路径**：
   - 逐个删除：每次删除移动 O(n) 个元素，总代价 O(n²) → 超时。
   - 新建数组：空间 O(n) → 不符。
3. **最终方法**：**一遍扫描 + 覆盖写**。用一个写指针 `k` 记录「保留区」的末尾，
   读指针逐个扫描，保留的元素写到 `k` 位置。

**解答过程**：

```text
初始：  数据 3 5 7 2 9 1   s=2 t=5   k=0
读 3：  在区间内 → 丢弃
读 5：  在区间内 → 丢弃
读 7：  不在区间 → data[0]=7, k=1
读 2：  在区间内 → 丢弃
读 9：  不在区间 → data[1]=9, k=2
读 1：  在区间内 → 丢弃
结束：  length=2，数组前两位是 7 9
```

**代码实现**：

```c
// 编译：gcc -std=c11 -O2
#include <stdio.h>

#define MAXSIZE 100
typedef struct { int data[MAXSIZE]; int length; } SqList;

/* 删除 [s,t] 区间内的所有元素，要求 s < t */
int DeleteRange(SqList *L, int s, int t) {
    if (s >= t) return 0;                 /* 边界：区间不合法 */
    if (L->length == 0) return 0;         /* 边界：空表 */

    int k = 0;                            /* k 是写指针，指向下一个保留位置 */
    for (int i = 0; i < L->length; i++) { /* i 是读指针 */
        if (L->data[i] < s || L->data[i] > t) {
            L->data[k] = L->data[i];      /* 保留：写到 k 位置 */
            k++;
        }
        /* 在区间内的元素直接跳过，相当于被后面的元素覆盖 */
    }
    L->length = k;                        /* 更新表长 */
    return 1;
}

void Print(SqList *L) {
    for (int i = 0; i < L->length; i++) printf("%d ", L->data[i]);
    printf("\n");
}

int main(void) {
    SqList L = {{3, 5, 7, 2, 9, 1}, 6};
    printf("原表：      "); Print(&L);
    DeleteRange(&L, 2, 5);
    printf("删 [2,5] 后："); Print(&L);       /* 7 9 */
    return 0;
}
```

**复杂度**：时间 O(n)（一遍扫描），空间 O(1)（只用两个整型变量）。

> **【规律】** **「原地删除类」问题的通用模板**：
>
> ```text
> k = 0
> for i = 0 to n-1:
>     if 应保留(data[i]):
>         data[k] = data[i]; k++
> length = k
> ```
>
> 这个模板可解一类题：删除指定值、删除区间、删除重复（保留一个）、
> 按条件筛选。**核心思想是「用写指针覆盖读指针扫过的位置」，把删除变成覆盖。**

## 本章总结

### 核心内容（一页纸）

1. **线性表定义**：n 个同类型元素的**有限序列**。表头无前驱，表尾无后继，
   其余元素有且仅有一个前驱与后继。
2. **九种基本操作中带 `&` 的**：`InitList`、`ListInsert`、`ListDelete`、`DestroyList`
   —— 这些会改变表本身。
3. **顺序表地址公式**：`LOC(aᵢ) = LOC(a₁) + (i-1) × size`。
   **随机访问 O(1) 的全部秘密就在这个公式里。**
4. **顺序表插入**：**从后往前**移动；**删除**：**从前往后**移动。
   **平均移动**：插入 **n/2**，删除 **(n-1)/2**，均为 O(n)。
5. **顺序表插入的 `i` 上界是 `length+1`**（可在表尾后插入）；
   **删除的 `i` 上界是 `length`**（不能删不存在的元素）。
6. **头结点的四个作用**：统一空表与非空表、统一首元结点与其他位置的操作、
   便于表头操作、简化边界判断。**有头结点时空表表示为 `L->next == NULL`。**
7. **头插法与尾插法的顺序差异**：头插法结果**与输入顺序相反**，
   尾插法**一致**（需要额外尾指针）。
8. **链表插入的指针顺序**：**先接后，再接前**
   （先 `s->next = p->next`，再 `p->next = s`）。
9. **两个无前驱指针的技巧**：在 p 前插入 → 插到 p 后 + **交换数据**；
   删除 p 自身 → **搬后继的数据再删后继**（p 不能是尾结点）。
10. **「链表插入删除是 O(1)」必须附前提：已知前驱结点。**
    否则查找位置本身是 O(n)。
11. **顺序表 vs 链表**：顺序快在「**找**」（随机访问 O(1)，存储密度 1）；
    链表快在「**插**」（改指针 O(1)，但存储密度 < 1）。
12. **循环链表遍历的终止条件是「回到起点」**，不是 `NULL`（否则死循环）。
13. **静态链表的游标代替指针**：`p = p->next` 对应 `i = a[i].next`；
    但访问逻辑上第 i 个元素仍是 **O(n)**，不是 O(1)。
14. **两个算法模板（必须能默写）**：
    - **链表就地逆置**（头插法，O(n) 时间 / O(1) 空间）
    - **顺序表原地删除**（写指针 `k` 覆盖，O(n) 时间 / O(1) 空间）

## 自测答案

**自测题 1-1 答案**：

**快慢指针法**：设两个指针 `fast` 与 `slow`，初始都指向首元结点。

1. `fast` 先向前走 **k 步**。
2. 若 `fast` 在走 k 步的过程中变成 `NULL`，说明链表长度不足 k，返回失败。
3. 之后 `fast` 与 `slow` **同步前进**，直到 `fast` 变为 `NULL`。
4. 此时 `slow` 所指即**倒数第 k 个结点**。

**为什么成立**：`fast` 与 `slow` 之间的距离恒为 k。
当 `fast` 到达链表末尾（`NULL`）时，`slow` 距离末尾正好 k 个结点，
即位于倒数第 k 个位置。

```c
// 找倒数第 k 个结点，只遍历一次，空间 O(1)
LNode *FindKthFromEnd(LinkList L, int k) {
    if (k <= 0) return NULL;
    LNode *fast = L->next, *slow = L->next;

    for (int i = 0; i < k; i++) {          /* 第 1 步：fast 先走 k 步 */
        if (fast == NULL) return NULL;     /* 边界：链表不足 k 个结点 */
        fast = fast->next;
    }
    while (fast != NULL) {                 /* 第 3 步：同步前进 */
        fast = fast->next;
        slow = slow->next;
    }
    return slow;                           /* slow 即倒数第 k 个 */
}
```

**复杂度**：时间 O(n)（只遍历一次），空间 O(1)（只用两个指针）。

> **【规律】** 快慢指针还能解决：**找中间结点**（fast 走两步、slow 走一步）、
> **判断是否有环**（有环则两者必相遇）、**找环的入口**。
> 这三个是链表算法设计题的常见变体，解法骨架相同。

**自测题 1-2 答案**：

设表长为 n，共 **n+1** 个可插入位置（位置 1 到 n+1）。

在位置 i 插入时，需要把原来的第 i 到第 n 个元素（共 `n - i + 1` 个）依次后移一位。

**等概率假设**下，每个位置被选中的概率为 `1/(n+1)`。

```text
E(移动次数) = Σ(i=1 到 n+1) [ 1/(n+1) × (n - i + 1) ]

令 j = n - i + 1，当 i 从 1 到 n+1 时 j 从 n 到 0：

           = 1/(n+1) × Σ(j=0 到 n) j
           = 1/(n+1) × [n(n+1)/2]
           = n/2
```

**结论：平均移动 n/2 个元素。**

> **【易错】** 推导中最容易错的是**位置总数**：插入时是 **n+1** 个位置，
> 因此概率是 `1/(n+1)` 而不是 `1/n`。
> 删除时才是 n 个位置（不能删不存在的元素），概率 `1/n`，平均移动 `(n-1)/2`。
> **这两个「n+1 与 n」「n/2 与 (n-1)/2」的差异是本题的核心考点。**
