## 三、每章的统一结构

每章固定包含下列九节，顺序不变、不得删减：

```text
# 第 N 章 章节名
元信息块（优先级 / 前置 / 后续 / 考纲归属 / 掌握状态）
图例块（三通道配色说明）
## 前置知识点          本章开始前必须掌握的内容
## 知识点优先级与学习顺序  六列表格：序 / 知识点 / 优先级 / 前置依赖 / 预估投入
## 本章地图            白话说明本章解决什么问题、学习路径为何这样排
## 本章重点 / 难点 / 易错点
## 知识点讲解          ### N-1 知识点名　【优先级】
                       每个知识点：是什么 / 为什么（带量级依据） / 怎么用（步骤 + 代码）
                                   + 【易错】+【类比】+【记忆】+ 前置与延伸
## 典型例题            每章不少于 3 道：概念辨析 / 计算推导 / 算法设计
## 跨章串联
## 考频与分值
## 延伸知识点          超出 408 大纲，标注范围归属
## 本章总结
   核心内容（一页纸，可脱离正文独立复习）
   知识点串联图
   自测清单
   间隔重复表
   应落到实处的代码修改
## 自测答案 / 复习记录 / 待办与缺口
```

### 3.1 代码规范

- 考研侧代码统一使用 **C 语言**（遵循 408 以 C 描述算法的惯例），编译命令写 `gcc -std=c11 -O2`。
- 逐行或逐逻辑块注释，注释说明「做什么」与「为什么」。
- 这是与 `02_竞赛` 侧的**关键差异**：竞赛侧用 C++17。

### 3.2 优先级判定依据

| 优先级 | 判定依据 |
|--------|---------|
| `P0` | 408 大纲明确要求**且**历年高频必考；不会则直接失分 |
| `P1` | 大纲要求但频率中等；或作为 P0 的前置知识点 |
| `P2` | 大纲边缘、低频，或仅作背景知识 |

> **【重点】** 优先级的**实际**等级要叠加「被依赖次数」。
> 一个被三个 P0 知识点依赖的 P1，其在学习路径上的实际优先级高于标称等级。
