## 本章地图

线性结构里每个元素「前后各一个邻居」，但大量真实关系是分层的：文件系统、组织架构、淘汰赛对阵图——一个结点下面挂多个子结点，这就是**树**。二叉树是树的特化（每结点至多两个孩子，且分左右），它把「多叉」收进「左右两个孩子」的统一格式，于是**遍历、存储、性质推导全部变得可公式化**。

本章主干五段：先建立树的术语体系与性质；再把二叉树的核心性质（第 i 层最多 2^(i-1) 个、完全二叉树编号公式等）背熟推熟；然后攻克全章枢纽——**遍历**（递归三种 + 非递归栈实现 + 层序队列实现，以及由两种序列重构二叉树）；随后把树与森林「扭」成二叉树统一处理（孩子-兄弟表示法）；最后补上三个高应用度的专题：**哈夫曼树**（压缩编码）、**堆**（优先队列与堆排序）、**并查集**（等价类合并）。学完本章，第 5 章的图遍历不过是「带环的树遍历」。

## 本章重点

> **【重点】** **结点数定律**：结点数 = 总度数 + 1，即 n = 边数 + 1（除根外每个结点恰有一条入边）。这是所有「求叶子结点数」题的万能钥匙。

> **【重点】** **二叉树五性质**：①第 i 层至多 2^(i-1) 个结点；②深度 k 的二叉树至多 2^k − 1 个结点；③n0 = n2 + 1；④n 个结点的完全二叉树深度 ⌊log2 n⌋ + 1；⑤完全二叉树编号 i（从 1 起）：双亲 ⌊i/2⌋，左孩 2i，右孩 2i+1（存在性看是否 ≤ n）。

> **【重点】** **三种遍历的相对顺序**：前序（根左右）、中序（左根右）、后序（左右根）——**根的插位不同**，左右子树内部各自保持同构递归；层序自上而下自左而右。

> **【重点】** **哈夫曼树**：n 个带权叶子构造的 WPL（带权路径长度）最小的二叉树；每次取**权值最小的两棵**合并，重复至只剩一棵。哈夫曼编码是**前缀码**，任一字符编码都不是另一字符的前缀。

> **【重点】** **堆**：完全二叉树 + 父结点不小于（大顶）或不大于（小顶）孩子；数组存储下 i 的孩子为 2i、2i+1（下标从 1）；插入上溯、删除下溯，均 O(log n)。

---

## 本章难点

> **【难点】** **由中序 + 另一序列重构二叉树**：前序 / 后序定根，中序分左右——前序首（后序尾）是根，到中序里切出左右子树再递归。**前序 + 后序不能唯一重构**（两孩缺失时无法区分左右），选择题必考。

> **【难点】** **线索二叉树的指针判别**：lchild 指左孩还是前驱、rchild 指右孩还是后继，靠 tag 位区分；中序线索化后找后继分「有右孩走右子树最左」与「无右孩直接顺线索」两路。

> **【难点】** **哈夫曼树不是唯一，但 WPL 唯一**：权值相同的结点交换位置可得不同形态的哈夫曼树，最小 WPL 值相同；树高也不唯一。

---

## 本章易错点

> **【易错】** **头号易错：n0 = n2 + 1 用错推广**。公式只对**二叉树**成立（度数只有 0、1、2）；直接搬去算普通树必错。普通树用 n = 总度数 + 1 配合 n0、n1、n2…联立方程。

> **【易错】** **完全二叉树编号公式忘了乘除基准**：下标从 1 起才有「双亲 ⌊i/2⌋、孩子 2i 与 2i+1」；下标从 0 起则双亲 ⌊(i−1)/2⌋、孩子 2i+1 与 2i+2。两种口径的题都出过。

> **【易错】** **「前序 + 中序」与「后序 + 中序」能唯一重构，前序 + 后序不能**——记反是最常见的丢分点。

> **【易错】** **完全二叉树判定的「编号连续」而非「看起来满」**：判定方法是层序编号连续无空洞（最后一层结点必须全部靠左）；只看形状疏漏会判错。

> **【易错】** **哈夫曼树没有度为 1 的结点**（每次恰合并两棵），n 个叶子的哈夫曼树共 **2n − 1** 个结点；填空题高频。

> **【易错】** **堆是「半序」不是「全序」**：兄弟之间无大小约束；「堆中任一路径有序」是对的，「同层有序」是错的。

## 知识点讲解

### 4-1　树的定义、术语与性质　【P0】

**是什么**：树是 n ≥ 0 个结点的有限集合，n = 0 为空树；非空时恰有一个**根**，其余结点分成 m ≥ 0 个互不相交的子集，每个子集又是一棵树（递归定义）。术语：双亲 / 孩子 / 兄弟；度（结点孩子数，树的度 = 结点度的最大值）；叶子（度 0）；深度（层数）；有序树与无序树；森林（互不相交的树的集合）。

**为什么**：树是「分层关系」的通用模型；其递归定义直接决定了本章几乎所有算法的递归形态——「处理根 + 递归处理每棵子树」。

**怎么用（结点数定律）**：设各度数结点数为 n0, n1, n2, …（度 = 孩子数）。边数 = 总度数 = n − 1（除根外每结点一条入边），于是 **n = 总度数 + 1**，即 n0 + n1 + n2 = 0×n0 + 1×n1 + 2×n2 + 1。两条方程联立可解任意「求叶子数」题。

> **【规律】** 常用推论：度为 m 的树第 i 层至多 m^(i-1) 个结点；h 层 m 叉树至多 (m^h − 1)/(m − 1) 个结点（等比求和）。完全 m 叉树的推导同理。

**前置与延伸**：
- 前置：无
- 延伸：森林 = 多棵树的集合；树与森林的转换见 4-7

### 4-2　树的三种存储结构　【P1】

**是什么**：树（多叉）没有像二叉树那样统一的链式格式，常用三种存储：**双亲表示法**（数组存「数据 + 双亲下标」）、**孩子表示法**（每结点挂孩子单链表）、**孩子兄弟表示法**（每结点两个指针：第一个孩子、下一个兄弟）。

**为什么**：三种存储分别服务三类查询：双亲表示法**找双亲 O(1)** 但找孩子要扫全表；孩子表示法**找孩子快**找双亲慢；孩子兄弟表示法把任意树**统一成二叉链格式**——它正是树转二叉树（4-7）的存储基础。

**怎么用**：

```c
#include <stdio.h>

/* 双亲表示法 */
#define MAXTREE 100
typedef struct {
    char data;
    int parent;                  /* 双亲下标，根为 -1 */
} PTNode;
typedef struct {
    PTNode node[MAXTREE];
    int n;                       /* 结点数 */
} PTree;

/* 孩子兄弟表示法（二叉链表） */
typedef struct CSNode {
    char data;
    struct CSNode *firstchild;   /* 第一个孩子 */
    struct CSNode *nextsibling;  /* 下一个兄弟 */
} CSNode, *CSTree;
```

> **【规律】** 孩子兄弟表示法中「firstchild 走下去、nextsibling 横着走」——树被转成了二叉树：**左指针 = 第一个孩子，右指针 = 下一个兄弟**。这是 4-7 转换规则的存储层解释。

**前置与延伸**：
- 前置：知识点 4-1；单链表（第 1 章 1-4）
- 延伸：并查集（4-11）就是双亲表示法的应用升级版

### 4-3　二叉树：定义、满与完全、五条性质　【P0】

**是什么**：二叉树是每结点**至多两棵子树**（分左右，次序不可颠倒）的树。五种基本形态：空、仅根、仅左子树、仅右子树、左右俱全。**满二叉树**：每层都满（深度 k 有 2^k − 1 个结点）；**完全二叉树**：与等高满二叉树按层序编号**一一对应**（编号连续、最后一层靠左）。

**为什么**：完全二叉树的「编号连续」使它能**无缝映射到数组**（无空洞），这是堆能数组化的根基，也是性质④⑤成立的前提。

**怎么用（五条性质的用法）**：

| # | 性质 | 典型用法 |
|---|------|---------|
| ① | 第 i 层至多 2^(i-1) 个结点 | 求某层结点数上界 |
| ② | 深 k 至多 2^k − 1 个结点 | 反推最小深度 ⌈log2(n+1)⌉ |
| ③ | **n0 = n2 + 1** | 已知度数分布求叶子数 |
| ④ | n 个结点的完全二叉树深 ⌊log2 n⌋ + 1 | 求深度、求第几层 |
| ⑤ | 编号 i：双亲 ⌊i/2⌋，孩 2i、2i+1 | 数组实现堆、判结点存在 |

> **【注意】** n0 = n2 + 1 的推导（一分钟记住）：边数 = n − 1 = n1 + 2n2（度即出边）；又 n = n0 + n1 + n2；两式消去 n 得 n0 = n2 + 1。**推导比背结论可靠**，普通树、B 树的类似公式都按这个思路现场推。

> **【规律】** 判完全二叉树的万能法：给 n 个结点按层序编号 1 至 n，若最大编号 i 的双亲、左孩、右孩编号全部 ≤ n 或按 ⑤ 规则「应存在则存在」，即完全；编号出现空洞则不是。

**前置与延伸**：
- 前置：知识点 4-1
- 延伸：堆（4-10）、第 6 章的完全二叉树结构（B 树的反例）

### 4-4　二叉树的存储　【P0】

**是什么**：顺序存储：按**完全二叉树编号**存入数组，非完全树补「虚结点」占位，空间可能浪费（单斜树退化成 O(2^n)）；链式存储：二叉链表（lchild、data、rchild），可有双亲三叉链表。

**为什么**：完全 / 满二叉树用顺序存储**零空洞零浪费**且 O(1) 定位双亲孩子；一般二叉树用链式，空间与形态成正比。**选型原则按「是否接近完全」**。

**怎么用**：

```c
#include <stdio.h>
#include <stdlib.h>

typedef char ElemType;

/* 链式：二叉链表 */
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

/* 顺序存储的定位规则（下标从 1，容量需按深度 2^k 预留） */
/* 编号 i 的左孩 2i，右孩 2i+1，双亲 i/2 */
```

> **【注意】** 顺序存储 j 号与 i 号是否同双亲、是否祖先子孙，全部用编号运算判断（i ≤ j 且 j ∈ [2i, 2i+1]…逐层上推 j /= 2 看 i 是否出现）。选择题爱出「顺序存储中两编号结点的关系判断」。

**前置与延伸**：
- 前置：知识点 4-3 性质⑤
- 延伸：堆（4-10）是顺序存储的唯一高频应用

### 4-5　二叉树的遍历　【P0】（全章枢纽）

**是什么**：按某规则访问每个结点一次。深度方向三种递归序（根的插位不同）：**前序 DLR、中序 LDR、后序 LRD**；广度方向一种：**层序**。非递归遍历用栈把递归显式化。

**为什么**：遍历是树一切算法的骨架——计数、查找、插入、线索化全部长在遍历框架上；「递归三行」与「栈实现」的对应关系是理解递归的最好教材。

**怎么用**：

```c
#include <stdio.h>
#include <stdlib.h>
#define MAXN 100

typedef char ElemType;
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

/* 递归三式：只换一行输出位置 */
void PreOrder(BiTree T) {
    if (T == NULL) return;
    printf("%c ", T->data);          /* D */
    PreOrder(T->lchild);             /* L */
    PreOrder(T->rchild);             /* R */
}
void InOrder(BiTree T) {
    if (T == NULL) return;
    InOrder(T->lchild);
    printf("%c ", T->data);          /* 根插中间 */
    InOrder(T->rchild);
}
void PostOrder(BiTree T) {
    if (T == NULL) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    printf("%c ", T->data);          /* 根插最后 */
}

/* 中序非递归：一路向左入栈，弹栈访问，转入右子树 */
void InOrderIter(BiTree T) {
    BiTree stack[MAXN];
    int top = -1;
    BiTree p = T;
    while (p != NULL || top != -1) {
        if (p != NULL) {             /* 左链全部入栈 */
            stack[++top] = p;
            p = p->lchild;
        } else {                     /* 左走尽：弹栈访问，转右 */
            p = stack[top--];
            printf("%c ", p->data);
            p = p->rchild;
        }
    }
}

/* 层序遍历：队列 */
typedef struct {
    BiTree data[MAXN];
    int front, rear;
} Queue;

void LevelOrder(BiTree T) {
    Queue q = { {0}, 0, 0 };
    if (T == NULL) return;
    q.data[q.rear] = T;
    q.rear = (q.rear + 1) % MAXN;
    while (q.front != q.rear) {
        BiTree p = q.data[q.front];
        q.front = (q.front + 1) % MAXN;
        printf("%c ", p->data);
        if (p->lchild != NULL) {
            q.data[q.rear] = p->lchild;
            q.rear = (q.rear + 1) % MAXN;
        }
        if (p->rchild != NULL) {
            q.data[q.rear] = p->rchild;
            q.rear = (q.rear + 1) % MAXN;
        }
    }
}
```

> **【规律】** 三个万能结论：①**中序 + 层序**也能唯一重构（层序定根、中序分左右，逐层走）；②前序序列中，任何结点的后继必在其右子树或其祖先的右子树中；③n 个结点的二叉树其**空指针域共 n + 1 个**（2n 个指针 − (n − 1) 条边），这个 n + 1 就是线索化的空间来源（见 4-8）。

> **【类比】** 非递归遍历 = 把递归时系统栈里压的东西自己手动压：每个结点「路过时压栈（第一次见 = 前序位）、从左子树回来时访问（第二次见 = 中序位）、从右子树回来时访问（第三次见 = 后序位）」。

**前置与延伸**：
- 前置：知识点 4-4；栈（第 2 章 2-2）、队列（第 2 章 2-5）
- 延伸：第 5 章 DFS / BFS 就是图版的深 / 广度遍历；莫里斯遍历 O(1) 空间（超纲）

### 4-6　由遍历序列重构二叉树　【P0】

**是什么**：由**中序 + 前序**（或中序 + 后序，或中序 + 层序）唯一确定二叉树；**前序 + 后序不能**唯一确定。

**为什么**：重构是「遍历」的逆问题，也是历年真题固定考点的画图题形态；「能不能唯一」的辨析比画图本身更常考。

**怎么用（前序 + 中序，递归三步）**：

1. 前序**第一个**字符是根（用后序则是**最后一个**）。
2. 到中序中找到根，左边是左子树的中序，右边是右子树的中序；由长度回切前序得到左右子树的前序。
3. 对左右子树递归。

**示例**：前序 `ABDECF`，中序 `DBEACF`：根 A；中序中 A 左边 `DBE`（左子树，3 个）、右边 `CF`（右子树，2 个）；左子树前序 `BDE`（根 B，中序 `DBE` → 左 D 右 E）；右子树前序 `CF`（根 C，中序 `CF` → 右孩子 F）。

> **【规律】** 前序 + 后序为什么不行：只有一个孩子的结点无法判定该孩子是左还是右（前序「根A子」后序「子A」中，子在前在后都讲得通）。n 个结点两两不同的序列对共 (2n)! / [2^n × n!] 量级的歧义，结论只需记「不能唯一」。

**前置与延伸**：
- 前置：知识点 4-5（知道每种序列的生成规则）
- 延伸：表达式树的先序 / 后序 / 中序对应前 / 后 / 中缀式（第 2 章 2-8 的逆问题）

### 4-7　树、森林与二叉树的相互转换　【P0】【补充】

**是什么**：三套规则同一内核（孩子兄弟表示法）：
- **树 → 二叉树**：加线（兄弟相连）、抹线（只留第一个孩子的线）、旋转（左孩右兄弟）。
- **森林 → 二叉树**：各树先转二叉树，后一棵二叉树**作为前一棵根的右孩子**依次连接。
- **二叉树 → 森林**：根的右链拆开成若干棵，各按二叉树转树还原。

**为什么**：树与森林没有统一的链式格式，转成二叉树后**遍历、存储、算法全部复用**二叉树那一套。这也是孩子兄弟表示法存在的原因。

**怎么用（遍历对应关系，必背）**：

| 原结构 | 转换后的二叉树遍历 |
|--------|------------------|
| 树的先根遍历 | 对应二叉树的**前序** |
| 树的后根遍历 | 对应二叉树的**中序** |
| 森林的先序遍历 | 对应二叉树的**前序** |
| 森林的中序（后根）遍历 | 对应二叉树的**中序** |
| 层序 | **没有**对应关系（选择题陷阱） |

> **【规律】** 「树的后根 = 转换后二叉树的中序」是最高频考点：后根遍历最后访问根，中序最后访问的是「右链走完」的根——两者一致。检验方式：拿三结点小树 A(孩子 B、C) 转换后手推一遍。

**前置与延伸**：
- 前置：知识点 4-2（孩子兄弟表示法）、4-5（遍历）
- 延伸：B 树、B+ 树（第 6 章）把「多叉」重新请回来，因为磁盘按块读、多叉降树高

### 4-8　线索二叉树　【P1】

**是什么**：利用二叉链表中 n + 1 个空指针存「遍历前驱 / 后继」：lchild 无左孩时改存**前驱**，rchild 无右孩时改存**后继**；另设 ltag / rtag 标志（0 = 指向孩子，1 = 指向线索）。按中序规则线索化得**中序线索二叉树**，另有先序、后序版本。

**为什么**：一般二叉链表找前驱后继只能再遍历一次（O(n)）；线索化后 O(1) 顺线走，且遍历可**无栈无递归**进行。

**怎么用（中序线索树上找后继，两路）**：

1. 结点有右孩（rtag = 0）：后继 = **右子树中最左结点**（一路 lchild 走到底）。
2. 结点无右孩（rtag = 1）：后继 = rchild 线索直接给出。

```c
typedef struct ThreadNode {
    char data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;              /* 0 孩子，1 线索 */
} ThreadNode;
```

> **【易错】** 先序线索树**找不到某类结点的前驱**（如无双亲信息的结点），后序线索树**找不到右孩子的后继**——「哪种线索树找哪种前驱后继会失灵」是选择题固定考点：先序找前驱、后序找后继需要双亲信息。

**前置与延伸**：
- 前置：知识点 4-5（知道空指针共 n + 1 个）
- 延伸：线索化的工程对应是「链表 + 缓存的迭代器」

### 4-9　哈夫曼树与哈夫曼编码　【P0】

**是什么**：n 个带权叶子，WPL = Σ 权 × 路径长度。WPL 最小的二叉树叫哈夫曼树（最优二叉树）。哈夫曼编码：权大的字符路径短——左 0 右 1（约定可反），从根到叶的 0/1 串即编码，天然是**前缀码**。

**为什么**：变长编码按使用频率分配码长，总长最短；前缀属性保证译码无需分隔符（任何编码都不是别的前缀，逐位走树遇叶即译）。

**怎么用（构造算法）**：n 个权值全部建为单结点树入集合；每步取**最小、次小**两棵合并（新根权 = 和），放回集合；重复 n − 1 次。**没有度为 1 的结点，共 2n − 1 个结点**，用大小为 2n − 1 的数组存储。

**完整示例**：权 {2, 3, 4, 5}：
合并 2+3=5 → 集合 {4, 5, 5}；合并 4+5=9 → {5, 9}；合并 5+9=14。
WPL = 2×3 + 3×3 + 4×2 + 5×1 = 6+9+8+5 = **28**。
（若同层两棵子树交换，形态不同但 WPL 相同——WPL 唯一，树形不唯一。）

> **【规律】** 三个必背数字：n 个叶子的哈夫曼树结点总数 **2n − 1**、度 2 结点 **n − 1**、度为 1 结点 **0 个**。选择题直接考这三个数。

> **【注意】** 哈夫曼编码是「最优前缀码」，但**不是唯一**最优；且若题目权值出现 0 或要求定长比较，先看清问的是哈夫曼树还是一般最优树。

**前置与延伸**：
- 前置：知识点 4-3（二叉树形态）、贪心直觉（阶段 2 贪心）
- 延伸：第 7 章堆可实现合并过程（优先队列取两小）；竞赛侧文件压缩（zlib 前身思想）

### 4-10　堆与优先队列　【P0】

**是什么**：堆 = **完全二叉树** + **堆序性质**：大顶堆任一双亲 ≥ 孩子，小顶堆任一双亲 ≤ 孩子。用数组存储（编号规则即 4-3 性质⑤），下标 i 的双亲 ⌊i/2⌋、孩子 2i 与 2i+1。

**为什么**：完全二叉树保证数组无空洞（树高 O(log n)），堆序保证**根即最值**——插入、删最值、建堆全部 O(log n) 或 O(n)，这是优先队列的标准实现。

**怎么用（小顶堆核心操作）**：

```c
#include <stdio.h>

int heap[1001];                  /* 下标从 1 开始，heap[0] 不用 */
int size = 0;

void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }

/* 上溯：插入后修堆序 */
void siftUp(int i) {
    while (i > 1 && heap[i / 2] > heap[i]) {
        swap(&heap[i / 2], &heap[i]);
        i /= 2;
    }
}

/* 下溯：删除堆顶后修堆序 */
void siftDown(int i) {
    for (;;) {
        int smallest = i, l = 2 * i, r = 2 * i + 1;
        if (l <= size && heap[l] < heap[smallest]) smallest = l;
        if (r <= size && heap[r] < heap[smallest]) smallest = r;
        if (smallest == i) break;
        swap(&heap[i], &heap[smallest]);
        i = smallest;
    }
}

void push(int x) { heap[++size] = x; siftUp(size); }

int popTop(void) {
    int top = heap[1];
    heap[1] = heap[size--];      /* 尾元素补顶 */
    siftDown(1);
    return top;
}
```

> **【规律】** **自上而下建堆（逐个插入）是 O(n log n)**；**自下而上建堆（从最后一个双亲 size/2 起倒序 siftDown）是 O(n)**——后者就是第 7 章堆排序的建堆方式，选择题考过两种建法的复杂度辨析。堆中**任一根叶路径有序，兄弟之间无序**。

> **【类比】** 淘汰赛擂台：冠军（堆顶）是最大，但亚军不一定在决赛另一侧——兄弟无序的直观解释。

**前置与延伸**：
- 前置：知识点 4-3、4-4（完全二叉树编号规则）
- 延伸：第 7 章堆排序；竞赛侧 `priority_queue`（C 模块）与 Dijkstra 堆优化（阶段 5）

### 4-11　并查集　【P1】

**是什么**：并查集维护**不相交集合**：Find(x) 查元素所在集合（返回代表元），Union(a, b) 合并两集合。存储就是 4-2 的**双亲表示法**：fa[i] 存双亲下标，根的 fa 指自己；两元素同根即同集合。

**为什么**：等价类问题（连通性、朋友圈、Kr通路）只问「谁和谁一伙」，不需要完整树形；并查集用近 O(1) 均摊完成查与并，是 Kruskal 最小生成树（第 5 章）的直接前置。

**怎么用**：

```c
#include <stdio.h>

#define MAXN 1005
int fa[MAXN];

void makeSet(int n) {            /* 初始化：各自为根 */
    for (int i = 1; i <= n; i++) fa[i] = i;
}

int find(int x) {                /* 查找 + 路径压缩 */
    if (fa[x] == x) return x;
    return fa[x] = find(fa[x]);  /* 递归途中把沿途结点直挂根上 */
}

void unite(int a, int b) {       /* 合并：根相连 */
    int ra = find(a), rb = find(b);
    if (ra != rb) fa[ra] = rb;
}
```

> **【规律】** 两大优化：**路径压缩**（find 时把沿途结点直挂根）与**按秩 / 按大小合并**（矮树挂到高树下）。两者同用，单次操作均摊 **O(α(n))**（α 为反阿克曼函数，可视为不超过 4 的常数）。只做其一也能过 408 的题，竞赛侧两个都要。

> **【注意】** 408 口径下并查集属树的「等价类应用」，选择题考「路径压缩后树形变化」与「find 的均摊复杂度」，算法设计题考「用并查集判连通块个数」（数根的个数）。

**前置与延伸**：
- 前置：知识点 4-2（双亲表示法）
- 延伸：第 5 章 Kruskal；竞赛阶段 3（并查集 / 种类并查集）、阶段 5（Kruskal）

## 典型例题

### 例题 4-1　（性质计算题 · 选择题风格）
**题干**：某二叉树有 5 个度为 2 的结点、3 个度为 1 的结点，求叶子结点数与总结点数。

**解题思路**：直接套 n0 = n2 + 1 与 n = n0 + n1 + n2。

**解答过程**：n0 = n2 + 1 = 5 + 1 = **6**；n = 6 + 3 + 5 = **14**。
验算（结点数定律）：边数 = n − 1 = 13 = 1×3 + 2×5 = 13，成立。

**复杂度分析**：O(1)。

### 例题 4-2　（重构与遍历题 · 综合应用题风格）
**题干**：已知二叉树前序 `ABDHIECFJG`，中序 `HDIBEAFJCG`，重构该树并写出后序序列。

**解题思路**：递归三步（前序定根、中序分侧、按长度回切），先画出树再走一遍后序。

**解答过程**：
1. 前序首 A 是根；中序中 A 左侧 `HDIBE`（5 个）为左子树，右侧 `FJCG`（4 个）为右子树。
2. 左子树前序 `BDHIE`：根 B；中序 `HDIBE` 中 B 左 `HDI`、右 `E`。B 的左子树前序 `DHI`：根 D，中序 `HDI` → D 左 H、右 I。B 右孩子 E。
3. 右子树前序 `CFJG`：根 C；中序 `FJCG` 中 C 左 `FJG`、右空。C 左子树前序 `FJG`：根 F，中序 `FJG` → F 左空、右 `JG`；JG：前序 `JG` 根 J，中序 `JG` → J 左空、右 G。
4. 树形：A( B( D(H, I), E ), C( F(, J(, G)) ) )。
5. 后序：左右根 → **H I D E B J G F C A**。

**复杂度分析**：重构 O(n²)（每层线性查找根）；加哈希定位可 O(n)（超纲优化）。

### 例题 4-3　（哈夫曼构造题 · 综合应用题风格）
**题干**：权值 {5, 29, 7, 8, 14, 23, 3, 11} 构造哈夫曼树，求 WPL 与总结点数，并说明为什么哈夫曼编码能无歧义译码。

**解题思路**：每次取两小合并，逐步记录每次合并产生的新权值——**所有非叶权值之和恰等于 WPL**（每合并一次，新权值就是两个叶子的路径长度贡献之和的累加）。

**解答过程**：
排序 {3, 5, 7, 8, 11, 14, 23, 29}。
合并 3+5=8 → {7, 8, 8, 11, 14, 23, 29}
合并 7+8=15 → {8, 11, 14, 15, 23, 29}
合并 8+11=19 → {14, 15, 19, 23, 29}
合并 14+15=29 → {19, 23, 29, 29}
合并 19+23=42 → {29, 29, 42}
合并 29+29=58 → {42, 58}
合并 42+58=100（根）。
WPL = 各非叶权之和 = 8+15+19+29+42+58+100 = **271**。
总结点数 = 2n − 1 = **15**（8 个叶子 + 7 个度 2 结点，无度 1）。
译码无歧义的原因：编码按「从根到叶」生成，任一字符编码都不是另一字符编码的前缀（前缀码），译码时逐位走树、遇叶即输出并回根，不会停在歧义半路。

**复杂度分析**：朴素 O(n²)；用堆（4-10）可 O(n log n)。

### 例题 4-4　（堆操作题 · 选择题风格）
**题干**：将序列 {45, 78, 23, 56, 12, 99} 就地建大顶堆（自下而上），写出建堆后的数组。

**解题思路**：按性质⑤放入数组（下标 1 起：45,78,23,56,12,99），从最后一个双亲 ⌊6/2⌋ = 3 起倒序 siftDown（大顶版：与较大孩子比较，父小则换）。

**解答过程**：
初始数组 [_,45,78,23,56,12,99]。
i=3：23 的孩子 99（6 号，右孩）较大，23 < 99 交换 → [_,45,78,99,56,12,23]。
i=2：78 的孩子 56、12，较大 56 < 78，不动。
i=1：45 的孩子 78、99，较大 99 交换 → [_,99,78,45,56,12,23]；45 落到 3 号，其孩子 23，45 > 23 停。
建堆结果：**[99, 78, 45, 56, 12, 23]**（下标 1 至 6）。
验证堆序：99 ≥ 78、99 ≥ 45；78 ≥ 56、78 ≥ 12；45 ≥ 23。成立。

**复杂度分析**：自下而上建堆 O(n)（各结点下溯高度求和为线性）。

## 本章总结

### 核心内容（一页纸）

- **结点数定律 n = 总度数 + 1**，二叉树推论 **n0 = n2 + 1**（只对二叉树成立）。
- 二叉树五性质：层上界 2^(i-1)、深 k 上界 2^k − 1、n0 = n2 + 1、完全树深 ⌊log2 n⌋ + 1、编号 i 双亲 ⌊i/2⌋ 孩子 2i/2i+1（**下标从 1 起的口径**）。
- **满二叉树每层满；完全二叉树编号连续**（最后一层靠左），可无缝数组化。
- 遍历：前中后序只差**根的插位**；非递归 = 手动栈；层序 = 循环队列。
- **中序 + 前序 / 后序 / 层序可唯一重构；前序 + 后序不能**（单孩结点左右无法区分）。
- 树 → 二叉树：**左孩子右兄弟**；树先根 = 二叉树**前序**，树后根 = 二叉树**中序**；森林逐树右链相接；层序无对应关系。
- 线索二叉树：n + 1 个空指针存前驱后继 + tag 区分；**先序找前驱、后序找后继会失灵**（缺双亲）。
- **哈夫曼树**：每次取两小合并；n 个叶子共 **2n − 1** 结点、**无度 1 结点**；WPL 唯一、形态不唯一；编码是**前缀码**，逐位走树遇叶即译。
- **堆**：完全二叉树 + 父子序（兄弟无序）；自下而上建堆 **O(n)**、逐插建堆 O(n log n)；插入上溯、弹顶下溯 O(log n)。
- **并查集**：双亲数组 + 根代表集合；路径压缩 + 按秩合并均摊 **O(α(n))**；连通块个数 = 根的个数。

### 知识点串联图

```text
树与二叉树
├── 树（递归定义、度与深度、n = 总度数 + 1）
│   ├── 存储：双亲 / 孩子 / 孩子兄弟
│   └── 并查集（双亲表示法 + 路径压缩 + 按秩合并）
├── 二叉树（左右有序、至多两孩）
│   ├── 满与完全（编号连续 → 数组化）
│   ├── 五条性质（n0 = n2 + 1 等）
│   ├── 遍历：前 / 中 / 后（递归与非递归栈）+ 层序（队列）
│   ├── 重构：中序 + 前序 / 后序 / 层序唯一；前序 + 后序不唯一
│   ├── 转换：左孩子右兄弟；先根 = 前序，后根 = 中序
│   └── 线索二叉树（n + 1 空指针利用，tag 区分）
├── 哈夫曼树（取两小合并，2n − 1，WPL 最小，前缀码）
└── 堆（完全二叉树 + 堆序，O(n) 建堆，O(log n) 增删）
```
