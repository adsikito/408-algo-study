## 第十五章：排序

> 课件来源：`排序的基本概念.pdf`、`插入排序.pdf`、`交换排序.pdf`、`归并和计数排序.pdf`、`直接插入排序.c`、`shell排序.c`、`冒泡排序.c`、`快速排序.c`、`简单的选择排序.c`、`堆排序.c`、`归并排序.c`、`计数排序.c`
>
> 本章是考试的绝对核心：**每个排序都要会手算每一趟的结果、背下复杂度与稳定性**，复习时对照速查表逐格背熟。

## 🗺️ 本章地图

本章解决一个问题：**把无序序列变有序，而且要能算清每一趟的结果和代价**。学习顺序：先用三大概念（就地、稳定、内外部）建立全章的"评价语言"→ 再按三大族学算法：插入族（直接插入→希尔）、交换族（冒泡→快排）、选择族（简单选择→堆排序），每一族都是"朴素版的痛点推出改进版"→ 最后学跳出比较框架的计数/桶/基数。这个顺序本身就是因果链：每个新算法都为修前一个的短板而生，速查表里的每个复杂度都能顺着这条链推出来。

## 📌 本章重点（3-5个）

⭐ **三大基本概念**：就地排序（恒定额外空间）、内部/外部排序（能否一次载入内存）、稳定排序（相同关键字相对位置不变）
⭐ **插入排序族**：直接插入（有序表+无序表）、折半插入、2-路插入、希尔排序（缩小增量 d=n/2→1）
⭐ **交换排序族**：冒泡（swapped / LastSwappedIndex 两次优化）、快速排序（partition 划分 + 分治递归）
⭐ **选择排序族**：简单选择（每趟选最小）、堆排序（大顶堆 + 向下调整，建堆 O(n)）
⭐ **归并/计数/桶/基数**：归并"分+治"O(nlogn) 稳定；计数排序前缀和 + 从后向前遍历保稳定；基数逐位计数排序

## 🔥 本章难点（2-3个）

🔥 **快速排序的 partition 过程与退化分析**：pivot 放到正确位置、小的去左大的去右；有序数组 + 每次取末尾元素做 pivot → 递归树退化为高度 n 的单链，复杂度 O(n²)；最好 T(n)=2T(n/2)+n → O(nlogn)
🔥 **稳定性的根源分析**：冒泡稳定（相邻相等不交换）、快排不稳定（根源在基准的选取，把 >= 改成 > 无意义）、计数排序必须**从后向前**遍历才稳定
🔥 **堆排序的建堆与调整**：向下调整法从 a[n/2] 到 a[1] 原地建堆 O(n)；排序每趟 a[1] 与 a[k] 交换后对堆顶做一次向下调整

## ⚠️ 本章易错点（3-5个）

⚠️ **复杂度背反**：直接插入最好 O(n)（基本有序）最坏 O(n²)；希尔最好 O(n^1.3) 最坏 O(n²)；快排**最好/平均 O(nlogn)、最坏 O(n²)**——最坏是快排不是其他
⚠️ **稳定性记串**：稳定的只有——直接插入、冒泡、归并、计数（"插冒归计"）；希尔、快排、简单选择、堆排序都不稳定（选择排序因远距离交换破坏相对位置）
⚠️ **趟数与有序区算错**：n 个记录都是 n-1 趟；插入第 i 趟有序区 [1,i]、乱序区 [i+1,n]；冒泡第 i 趟乱序区 [1,n-i+1]，比较到 n-i 即停
⚠️ **快排取基准位置错**：课件 partition 用**末尾元素**做 pivot（最后交换 a[i+1] 与 a[high]）；代码模板用**首元素** a[l] 做基准挖坑填坑——两种写法边界不同不能混用
⚠️ **计数排序输出顺序**：稳定版必须**从后向前**遍历原数组放到 sum[a[i]] 位置再自减；从前往后输出则相同元素相对顺序颠倒，失去稳定性

## 📖 知识点讲解

### 1. 排序的三大基本概念

**是什么**：先用三个生活类比统一认识——排序算法像整理书架：**就地**是"只在书架上倒手，不借别的桌子"；**稳定**是"同名的书互不插队"；**内部/外部**是"书少一次全搬进屋里排，书多得分批从仓库搬"。严格定义：① **就地排序**：使用恒定的额外空间产生输出，仅通过修改线性表中元素的顺序来排序（插入排序、选择排序是就地；归并排序、计数排序的经典实现不是）。② **内部/外部排序**：所有待排序记录能一次载入内存处理叫内部排序；不能一次载入、需借助硬盘/CD 等辅存叫外部排序（记录数量非常大时用，**归并排序及其变体是典型的外部排序算法**）。③ **稳定排序**：关键字（排序时用来比大小的那个字段）相同的记录排序后相对位置不变——对可能存在重复键的**键值对**（如人名做键、详细信息做值）排序时稳定性至关重要。

**为什么**：考研三问就是"这算法就地吗、稳定吗、多少趟"，概念不清全盘皆输；稳定性决定了多关键字排序能否"先按次关键字排、再按主关键字稳定排"来省事。

**怎么用**——先用 3 个元素的迷你序列建立手感：对 (5,a) (3,b) (5,c) 按数值升序排，稳定的结果是 (3,b) (5,a) (5,c)——两个 5 谁先谁后没变；若排成 (3,b) (5,c) (5,a)，c 就插到了 a 前面，键值对场景（a、c 携带的信息不同）会拿到错乱数据。判断口诀：
```
就地 = 辅助空间 O(1)          （归并 O(n)、计数 O(k) 直接出局）
稳定 = 相等元素不"远距离换位"  （逐个对照速查表背）
```

> ⚠️ 注意事项："稳定"看的是**关键字相同时相对位置**，不是数值不重复；不稳定的算法无论怎么写比较符号（>= 改 >）都救不回来。

> 🎯 规律：拿到任何排序先问三件事——额外空间多大？相等元素会不会被远距离换位？数据能否一次进内存？

> 💡 一句话总结：就地看空间，稳定看相等，内外部看内存。

### 2. 直接插入排序（及折半插入、2-路插入）

**是什么**：直接插入就是整理手牌——每摸一张新牌，从右往左比，比它大的牌顺手右移一格，给它腾出空位插进去。严格说：把 n 个待排序元素看成**一个有序表 + 一个无序表**。开始有序表只含 1 个元素、无序表含 n-1 个；每趟从无序表取出第一个元素，在有序表中**顺序查找**插入位置并插入，重复 n-1 趟完成。

**为什么**：表中记录基本有序、或记录总量很少时，直接插入效率很高——这一性质正是希尔排序和 C++ STL（数据 ≤8 个时退用插入排序）改进的出发点。

**怎么用**——先用 5 元素小数组 {5,3,8,1,4} 全程手算（`|` 左边为有序表）：
```
初始   [5]         | 3 8 1 4
第1趟  摸 3：3<5，5 右移一格    → [3 5]      | 8 1 4   → 3 5 8 1 4
第2趟  摸 8：8>5，原地落位      → [3 5 8]    | 1 4     → 3 5 8 1 4
第3趟  摸 1：8、5、3 全部右移   → [1 3 5 8]  | 4       → 1 3 5 8 4
第4趟  摸 4：8、5 右移，4>3 停  → [1 3 4 5 8]          → 1 3 4 5 8
共 n-1=4 趟：第 3 趟移动最多、第 2 趟零移动——代价由"序列有多乱"决定。
```
课件原例 {3,1,7,5,2,4,9,6}（逐趟）：
```
初始: [3] 1 7 5 2 4 9 6      （3 直接入有序表）
插1 : [1 3] 7 5 2 4 9 6      （1<3 插左侧）
插7 : [1 3 7] 5 2 4 9 6      （3<7 插右侧）
插5 : [1 3 5 7] 2 4 9 6      （与 7、3 依次比较，落在 3 和 7 之间）
插2 : [1 2 3 5 7] 4 9 6      （与 7、5、3 依次比较后右移，落在 1 和 3 之间）
...共 n-1=7 趟
```
代码模板（改良写法：边找边移，哨兵 x 暂存待插元素）：
```c
for(int i=1;i<=n-1;i++){        // 枚举趟数，有序区[1,i] 乱序区[i+1,n]
    x=a[i+1];                   // 乱序区第一个数
    for(j=i;j>=1;j--)
        if(a[j]>x) a[j+1]=a[j]; // 大于x就后移
        else break;             // 找到第一个<=x的位置
    a[j+1]=x;
}
// 时间：最好O(n) 最坏O(n*n) 平均O(n*n)；就地；稳定
```
两个变体：**折半插入**——查找表本身有序时，用折半查找代替顺序查找定位；**2-路插入**——另设等大数组 d，首记录放 d[0]，比 d[0] 大插右侧、小插左侧（d 是**环状数组**），减少移动记录次数。

> ⚠️ 注意事项：比较条件是 `a[j]>x` 才移、`a[j]<=x` 即停（等号在 x 侧停下才能保证稳定性）；倒着遍历是"边找边移"的关键。

> 🎯 规律：第 i 趟只干一件事——把 a[i+1] 插进前面的有序区；比较与移动次数由已有的逆序对（前大后小的数对）决定，所以基本有序时接近 O(n)。

> 💡 一句话总结：有序表逐个插入，基本有序时最快。

| 对比 | 直接插入 | 折半插入 | 2-路插入 |
|------|---------|---------|---------|
| 定位方式 | 顺序查找 | 折半查找 | 与 d[0] 比较，环形数组 |
| 改进目标 | — | 减少比较次数 | 减少移动次数 |
| 稳定性 | 稳定 | 稳定 | 稳定 |
| 前提 | — | 表基本有序时收益大 | 需 O(n) 辅助数组（非就地） |

### 3. 希尔排序（缩小增量排序）

**是什么**：希尔是给直接插入"抄近道"——先让小元素按增量 d 跳着往前挪（坐电梯），免得它们在最后一趟里一步步爬楼梯。严格说：又称"缩小增量排序"，属于插入排序。思路：**先将整个记录表按增量 d 分割成若干子表，分别做直接插入排序；再缩小增量重复，最后对整表做一次直接插入排序**。子表内元素在原表中相隔固定常数 d（如第一次 d=5，第二次 d=3，最后 d=1）。

**为什么**：利用直接插入的两个高效场景——"基本有序"和"记录很少"。分组排让关键字较小的记录**跳跃式前移**（不是一步一步挪），最后一次整表插入时只需少量比较和移动。

**怎么用**——先用 {5,3,8,1,4} 走一遍（n=5，增量 d=n/2=2 → 1）：
```
d=2 分组（同组元素下标相隔 2）：
下标:  1   2   3   4   5
值 :   5   3   8   1   4
       └───┼───┘ 组1（下标 1,3,5）
           └─────── 组2（下标 2,4）

第1趟 d=2：组1 {5,8,4} 组内插入 → {4,5,8}；组2 {3,1} 组内插入 → {1,3}
          → 4 1 5 3 8（已经比初始有序得多）
第2趟 d=1：整表直接插入
          [4] 1 5 3 8 → 插1 → [1 4] → 插5 → [1 4 5]
          → 插3（5、4 右移）→ [1 3 4 5] → 插8 → [1 3 4 5 8]
```
课件原例 {49,38,65,97,76,13,27,49,55,4}：
```
第1趟 d=5: {49,13}{38,27}{65,49}{97,55}{76,4} 五组各自直接插入
           → 13 27 49 55 4 49 38 65 97 76（基本有序）
第2趟 d=3: 再分割、组内直接插入（进一步基本有序）
第3趟 d=1: 整表一次直接插入 → 有序
代码骨架：
for(int d=n/2; d>=1; d/=2)          // 枚举增量（也是组数）
    for(int i=1+d;i<=n;i++){        // 从每组第二个数开始
        x=a[i];                     // 本组有序区最后一个数是 a[i-d]
        for(j=i-d;j>=1;j-=d)
            if(a[j]>x) a[j+d]=a[j]; else break;
        a[j+d]=x;
    }
// 时间：最好O(n^1.3) 最坏O(n*n)；就地；不稳定
```

> ⚠️ 注意事项：组内元素下标是 i、i-d、i-2d……组内插入的步长是 d 不是 1；增量为 n/2、每次减半到 1 是课件取法；**不稳定**（相等元素被分到不同组，先后次序被打乱）。

> 🎯 规律：希尔 = 给直接插入加预处理——增量从大到小、逐趟减少逆序对，为最后一趟 d=1 铺路；组内步长是 d 不是 1。

> 💡 一句话总结：分组跳跃前移，最后一次整表插入。

### 4. 冒泡排序（含两次优化）

**是什么**：冒泡像石头沉水——每趟从头到尾两两比较、逆序就交换，一趟下来当前最大的元素一定"沉"到乱序区末尾。严格说：从前往后对乱序区**两两比较、逆序则交换**，每趟把当前最大元素"沉"到乱序区末尾，共 n-1 趟。第 i 趟乱序区为 [1, n-i+1]，只需比较到 n-i。

**为什么**：基本实现不论数组是否有序都要跑满两层 for。优化目标：**数组提前有序时提前结束**（一次优化）、**跳过已有序的后缀减少无意义比较**（二次优化）。

**怎么用**——先全程手算 {5,3,8,1,4}（从前往后两两比较，大数沉底）：
```
第1趟（j 比 1..4）：
  (5,3)换 → 3 5 8 1 4    (5,8)不换    (8,1)换 → 3 5 1 8 4    (8,4)换 → 3 5 1 4 8
  → 本趟结果 3 5 1 4 8（8 沉底，就位于第 5 格）
第2趟（只比前 4 个）：(3,5)不换 (5,1)换 (5,4)换 → 3 1 4 5 8（5 就位）
第3趟（只比前 3 个）：(3,1)换 (3,4)不换 → 1 3 4 5 8（4 就位）
第4趟（只比前 2 个）：(1,3)不换，整趟零交换 → flag=0，提前结束
```
课件原例 {1,4,2,5,4,8} 第一趟逐步：(1,4)不换 → (4,2)交换 → [1,2,4,5,4,8] → (4,5)不换 → (5,4)交换 → [1,2,4,4,5,8] → (5,8)不换；最大值 8 已在末尾，第二轮只泡前 5 个。第二次优化例子 {4,2,1,5,6,8}：第一趟最后一次交换发生在 1 和 4 之间（位置 LastSwappedIndex），**该位置之后的元素已有序**，第二趟 j 只从 0 比到 LastSwappedIndex 就结束。
```c
int flag=0;                          // 标记是否发生交换
for(int i=1;i<=n-1;i++){             // n-1趟，乱序区[1,n-i+1]
    flag=0;                          // 每趟开始前必须重置！
    for(int j=1;j<=n-i;j++)
        if(a[j]>a[j+1]){ flag=1; swap(a[j],a[j+1]); }
    if(flag==0) break;               // 一轮无交换→已有序，提前结束
}
// 时间：不优化最好=平均=最坏O(n^2)；优化后最好O(n)；空间O(1)；就地；稳定
```

> ⚠️ 注意事项：flag **每趟开始前都要初始化为 0**；冒泡稳定的本质原因是**比较和交换的是相邻元素，键值相同的关键字不交换位置**；第二轮即使数组已有序，算法本身并不知道，仍需第三阶段的比较来判断。

> 🎯 规律：第 i 趟必把乱序区最大值送到位置 n-i+1；"整趟无交换"是全局有序的充要信号。

> 💡 一句话总结：相邻比交换，无交换即有序。

| 对比 | 一次优化（swapped） | 二次优化（LastSwappedIndex） |
|------|--------------------|------------------------------|
| 做法 | 整趟无交换则 break | 记录本趟最后一次交换位置，下趟只比到此 |
| 针对问题 | 数组已有序仍跑满 | 数组后段已有序仍做无意义比较 |
| 效果 | 有序数组降到 O(n) | 减少比较次数，趟数相同 |

### 5. 快速排序

**是什么**：快排像军训整队——拉一人当标杆（pivot），一声令下"比我小的站左、比我大的站右"，标杆一次站进自己的最终位置，再对左右两队各自重复这套口令。严格说：分治算法。每趟选一个基准 **pivot**（可取首/尾/随机/中间元素），通过划分 **partition** 把 pivot 放到排序后的正确位置：比它小的都在左边、比它大的都在右边，划分操作时间 O(n)；再对左右两组递归，这就是"分"与"治"。

**为什么**：T(n)=T(k)+T(n-k+1)+n——每趟划分确定一个元素的最终位置并分成两组。最好情况每次选中中间元素：T(n)=2T(n/2)+n，由主定理得 O(nlogn)；最坏情况每次选中最大/最小元素（如对**有序数组**每次取末尾 pivot）：T(n)=T(n-1)+n，递归树退化成高度 n 的单链，O(n²)。平均按 n/10、9n/10 假设，依然是 O(nlogn)——**只要每次不选最大/最小，就是 O(nlogn) 量级**。

**怎么用**——先用 {5,3,8,1,4} 走第一趟（代码模板写法：首元素 5 做基准，挖坑填坑，□ 表示坑）：
```
初始  5 3 8 1 4   取走 a[1]=5 做基准，坑在位置1
① j 从右找 <5：a[5]=4 填坑1，坑移到 5 → 4 3 8 1 □   （i=2）
② i 从左找 >5：a[3]=8 填坑5，坑移到 3 → 4 3 □ 1 8   （j=4）
③ j 从右找 <5：a[4]=1 填坑3，坑移到 4 → 4 3 1 □ 8   （i=4）
④ i、j 相遇于坑 4 → 基准归位：a[4]=5
第1趟结果：4 3 1 | 5 | 8   （5 就位，左侧全 <5，右侧全 >5）
再递归 {4,3,1}（p=4 → 1 3 | 4）与 {8}（单个不用排）→ 最终 1 3 4 5 8
```
课件手算（尾元素做 pivot）：{1,8,3,9,4,5,4,7} 取 7 为 pivot，i=-1、j 从 0 扫到 pivot 前：j 指的元素 ≤7 就 i++ 并交换 a[i]、a[j]，>7 什么都不做；扫描完交换 a[i+1] 与 a[7]，7 归位 → {1,3,4,5,4} | 7 | {8,9}，再对两侧递归。

有序数组 + 每次取末尾 pivot 的退化递归树：
```
[1..n] → [1..n-1] → [1..n-2] → ... → [1]     每层只分出 1 个元素
高度 = n（而非 logn）→ O(n²)
```
```c
// 代码模板：首元素做基准，挖坑填坑
void QSort(int a[],int l,int r){
    if(l>=r) return;                 // 递归出口
    int i=l,j=r,p=a[l];              // 取区间第一个数做基准
    while(i<j){
        while(i<j&&a[j]>=p) j--;     // j 从后往前找小于p的数
        if(i<j) a[i++]=a[j];         // 补到前面的坑
        while(i<j&&a[i]<=p) i++;     // i 从前往后找大于p的数
        if(i<j) a[j--]=a[i];         // 补到后面的坑
    }
    a[i]=p;                          // 基准归位
    QSort(a,l,i-1);  QSort(a,i+1,r);
}
// 时间：最好平均O(nlogn) 最坏O(n*n)；不稳定；就地
// 空间：仅一个临时变量O(1)，另需递归栈 最好O(logn) 最坏O(n)
```

> ⚠️ 注意事项：快排**不稳定**——划分阶段的交换破坏元素相对位置，不稳定的根源在**基准的选取**（同一数字被选为 pivot 时，其他相同元素会被甩到它一侧或两侧）；把比较时 >= 改成 > 没有意义；要得到稳定快排需记录相同元素的相对位置，要额外空间。递归树高度即递归深度，直接决定栈空间。

> 🎯 规律：一趟划分只保证 pivot 一个元素绝对就位；基准选得好坏决定递归树是平衡（O(nlogn)）还是单链（O(n²)）。

> 💡 一句话总结：基准归位分两侧，有序数组退化慢。

| 对比 | 快速排序 | 归并排序 |
|------|---------|---------|
| 思想 | 分治：先划分后递归（治在先） | 分治：先递归后合并（治在后） |
| 时间 | 最好平均O(nlogn) **最坏O(n²)** | 恒为 O(nlogn) |
| 空间 | O(1)+递归栈 O(logn)~O(n) | 辅助数组 O(n) |
| 稳定性 | 不稳定 | 稳定 |
| 就地 | 是 | 否 |

### 6. 简单选择排序与堆排序

**是什么**：人肉排序的直觉就是选择法——扫一眼剩下的一堆、挑最小的放最前；堆排序改进的只是"扫一眼"这一步的速度：把数据组织成堆，最值永远站在堆顶。严格说：**简单选择排序**：第 i 趟在乱序区 [i,n] 中找最小值，与乱序区第一个位置 a[i] 交换，共 n-1 趟。**堆排序**：把顺序表当完全二叉树建**大顶堆**（父亲 ≥ 孩子的完全二叉树，a[1] 最大；结点 i 的孩子是 2i、2i+1），之后每趟把堆顶 a[1] 与乱序区末尾 a[k] 交换、k--、对堆顶做一次向下调整，执行 n-1 趟。

**为什么**：选择排序的比较次数与初始序列无关（恒为 n(n-1)/2 量级）；堆排序则把"每趟找最大"从 O(n) 降到 O(logn)，整体升到 O(nlogn)，还保持就地。

**怎么用**——先手算简单选择 {5,3,8,1,4}：
```
第1趟 [1,5] 找 min=1（位4），与 a[1]=5 交换 → 1 3 8 5 4
第2趟 [2,5] 找 min=3（位2），就是自己，无变化 → 1 3 8 5 4
第3趟 [3,5] 找 min=4（位5），与 a[3]=8 交换 → 1 3 4 5 8
第4趟 [4,5] 找 min=5（位4），就是自己，无变化 → 1 3 4 5 8
共 4 趟，每趟都完整扫一遍乱序区——比较次数与序列乱不乱无关。
```
再手算堆排序 {5,3,8,1,4}（向下调整 = 拿它和较大的孩子比，比孩子小就换下去，直到成为叶子或比两个孩子都大）：
```
建堆（n=5，从 a[n/2]=a[2] 倒着调到 a[1]）：
初始数组 5 3 8 1 4                树:
                                     5
                                   /   \
                                  3     8
                                 / \
                                1   4
DownAdjust(a[2])：孩子 a[4]=1、a[5]=4 中 4 大，3<4 交换 → 5 4 8 1 3
DownAdjust(a[1])：孩子 a[2]=4、a[3]=8 中 8 大，5<8 交换 → 8 4 5 1 3
得到大顶堆（数组与树两视角）：
数组: 8 4 5 1 3                树:      8
                                      /   \
                                     4     5
                                    / \
                                   1   3

排序（每趟：堆顶换到乱序区末尾 → 堆缩小一格 → 新堆顶向下调整）：
第1趟 8↔3 → 3 4 5 1 [8]   调整堆顶 → 5 4 3 1 [8]
第2趟 5↔1 → 1 4 3 [5 8]   调整     → 4 1 3 [5 8]
第3趟 4↔3 → 3 1 [4 5 8]   3>1 已满足，不调
第4趟 3↔1 → 1 [3 4 5 8]   完成
```
```c
// 简单选择：O(n^2) 不稳定 就地 空间O(1)
for(int i=1;i<=n-1;i++){
    minn=i;
    for(int j=i+1;j<=n;j++)          // 遍历乱序区找最小下标
        if(a[j]<a[minn]) minn=j;
    swap(a[i],a[minn]);              // 与乱序区第一个位置交换
}
// 堆排序：O(nlogn) 不稳定 就地
void DownAdjust(int a[],int i,int n){        // 向下调整
    int now=i,nex;
    while(2*now<=n){
        nex=2*now;                            // 先指左孩子
        if(2*now+1<=n&&a[2*now+1]>a[2*now]) nex=2*now+1; // 右孩子更大
        if(a[now]<a[nex]){ swap(a[now],a[nex]); now=nex; }
        else break;                           // 父亲大，满足大顶堆
    }
}
for(int i=n/2;i>=1;i--) DownAdjust(a,i,n);   // 原地建堆 O(n)
int k=n;
for(int i=1;i<=n-1;i++){                     // n-1趟 O(nlogn)
    swap(a[1],a[k]);  k--;                   // 最大值换到末尾，堆减一
    DownAdjust(a,1,k);                       // 新堆顶向下调整
}
```

> ⚠️ 注意事项：建堆从**最后一个非叶子结点 a[n/2] 倒着调整到 a[1]**，总时间 O(n)（不是 O(nlogn)）；向上调整边插入边建堆是 O(nlogn)；简单选择排序**不稳定**（远距离交换会跨越相等元素，如 {2,2,1}）。

> 🎯 规律：选择族每趟都锁定一个最值的最终位置；堆只是把"找最值"从 O(n) 扫描升级为 O(logn) 调整。

> 💡 一句话总结：每趟选最值，堆顶换到尾。

### 7. 归并排序

**是什么**：归并像合并两列已按身高排好的队伍——两边排头比一比，矮的出列站进新队，一边空了另一边整队跟上；唯一真正干活的动作就是这次"合并"。严格说：蕴含**分治**思想的排序。"分"：mid=(l+r)/2 把数组折半拆分，递归拆到 n 个长度为 1 的子数组；"治"：把两个有序子数组合并成一个有序数组。mergeSort 理解为"分+递"，merge 理解为"治+归"。

**为什么**：总时间 = 拆分时间（每次折半，O(1) 可忽略）+ 子数组排序时间 + 合并时间，共 O(logn) 层、每层合并 O(n)，恒为 O(nlogn)，**不受初始序列影响**；合并时值相同的两个关键字不存在交换的可能，所以稳定。

**怎么用**——先用 {5,3,8,1,4} 走全程：
```
拆：[5,3,8,1,4] → [5,3,8] | [1,4] → [5,3][8] | [1][4] → [5][3][8][1][4]
合并：[5]+[3]→[3,5]；[3,5]+[8]→[3,5,8]；[1]+[4]→[1,4]
最后 merge [3,5,8] 与 [1,4]：
   左半 [3,5,8]     右半 [1,4]        输出 t
         ↑i               ↑j
   3 vs 1 → 取 1 → t=[1]
   3 vs 4 → 取 3 → t=[1,3]
   5 vs 4 → 取 4 → t=[1,3,4]
   右半取空 → 左半依次抄入 → t=[1,3,4,5,8]
```
课件原例 {5,1,4,2,8,4}：拆成 {5,1,4}|{2,8,4} → {5,1}{4}|{2,8}{4} → {5}{1}{4}{2}{8}{4}，然后逐层合并：{1,5}{4} → {1,4,5}；{2,8}{4} → {2,4,8}；最后合并得 {1,2,4,4,5,8}（两个 4 相对位置未变）。
```c
void MergeSort(int a[],int l,int r){
    if(l>=r) return;
    int mid=(l+r)/2;
    MergeSort(a,l,mid);              // 前一半排有序
    MergeSort(a,mid+1,r);            // 后一半排有序
    int i=l,j=mid+1,k=0,t[105];
    while(i<=mid&&j<=r)              // 合并两个有序序列
        t[k++] = (a[i]<=a[j]) ? a[i++] : a[j++];   // <=保证稳定
    while(i<=mid)  t[k++]=a[i++];
    while(j<=r)    t[k++]=a[j++];
    for(i=0;i<k;i++) a[l+i]=t[i];    // 放回原数组
}
// 稳定；非就地；时间O(nlogn)；空间O(n)——空间换时间
```

> ⚠️ 注意事项：合并时取等号的一方必须选**前半段**（a[i]<=a[j] 取 a[i]），相等元素前段的先进 t，稳定性才保得住；辅助数组大小依次为 1,2,4,…,n/2 开两个，空间 O(n) 量级，因此归并不是原地排序。

> 🎯 规律：总代价 = 层数 O(logn) × 每层合并 O(n)，与初始序列无关；稳定性全押在"相等时先取左半"这一个等号上。

> 💡 一句话总结：折半拆分逐层合并，稳定但要 O(n) 空间。

### 8. 计数排序

**是什么**：计数排序不比大小，改"报名到格子"——值是几，就在几号格子划一笔；数完再算"不超过 i 的共有几个"，每个元素该站哪一格就一步到位。严格说：针对**特定整数范围**的非比较排序，类似哈希映射：用 count[] 统计每个不同元素出现的次数，再对映射后的数组排序输出（某些情况比快速排序还快）。

**为什么**：基于比较的排序下界是 O(nlogn)，计数排序绕开比较，直接用"值当下标"统计频率；统计出 count 后做**前缀和**（从第 1 项累加到第 i 项：count[i]=count[i]+count[i-1]），新 count[i] 就表示"≤i 的元素个数"即排序后位置信息。

**怎么用**——先用 {5,3,8,1,4} 走稳定版四步：
```
① 统计 count[1..8]：值 1,3,4,5,8 各出现 1 次
   count:  1 0 1 1 1 0 0 1
② 前缀和 sum[i] = ≤i 的元素个数
   sum:    1 1 2 3 4 4 4 5
③ 从后向前遍历原数组 {5,3,8,1,4}（k=sum[a[i]] 就是它的目标位）：
   4 → t[sum[4]=3]=4, sum[4] 减为 2
   1 → t[sum[1]=1]=1, sum[1] 减为 0
   8 → t[sum[8]=5]=8, sum[8] 减为 4
   3 → t[sum[3]=2]=3, sum[3] 减为 1
   5 → t[sum[5]=4]=5, sum[5] 减为 3
④ t = 1 3 4 5 8
```
课件原例稳定版四步（{1,4,1,2,5,2,4,1,8}）：
```
① 统计：count[值]++                     → 0 3 2 0 2 1 0 0 1
② 前缀和：count[i]+=count[i-1]          → 0 3 5 5 7 8 8 8 9（位置信息）
③ 从后向前遍历原数组：k=count[a[i]]; t[k]=a[i]; count[a[i]]--;
④ t[1..n] 即输出（例：最后一个8放t[9]；最后一个1放t[3]……）
```
```c
// 代码骨架：非就地，时间O(n+maxx)，稳定；缺点：浪费空间
for(i=1;i<=n;i++) cnt[a[i]]++;               // 计数
for(i=1;i<=maxx;i++) sum[i]=sum[i-1]+cnt[i]; // 前缀和
for(i=n;i>=1;i--){                           // 从后向前→稳定
    k=sum[a[i]];  t[k]=a[i];  sum[a[i]]--;
}
```

> ⚠️ 注意事项：**为什么从后向前**——sum 是"≤该值"的位置，相同元素中后出现的先被放到更靠后的空位，相对顺序保持不变（3 个 1 排序后仍是原顺序），这就是稳定性；有负数时开大小 max-min+1 的数组、把最小值映射到下标 0（count[arr[i]-min]++）。适用要点：数据范围 range 不明显大于 n 时高效；通常作**基数排序的子过程**；可用部分哈希 O(1) 统计频率；适用于整数（含负数），**不适用于小数**。

> 🎯 规律：count→前缀和把"值"翻译成"排名"；从后向前填位是稳定性的全部秘密——后出现的相同元素先占靠后的坑。

> 💡 一句话总结：值当数组下标，前缀和定位置。

### 9. 桶排序与基数排序

**是什么**：计数排序的痛点是值域一大就要开一整排格子——桶排序把"一格一值"放宽成"一段值一个桶"，基数排序则把大数拆成一位一位、每轮只用 0~9 十个格子。严格说：**桶排序**：把待排序列分配到若干个桶里（如按 n/10 整除定桶号），每个桶内再个别排序（可用其他排序算法或递归桶排），最后按桶顺序依次取出；**桶排序不是比较排序**，不受 O(nlogn) 下限影响，是**用空间换取时间**的排序。**基数排序**：从待排序数组的**最低有效位到最高有效位逐位**进行计数排序，使用计数排序作为子过程。

**为什么**：数据**均匀分布**时桶排接近线性；当数值范围在 1 到 n² 时计数排序退化到 O(n²)（range 太大"失灵"），基数排序仍能线性完成——它把"值域大"的问题拆成 d 轮"单数字排序"。

**怎么用**——先用 {5,3,8,1,4} 各走一小遍：
```
桶排序（桶界人为设定：值 ≤4 进 0 号桶、≥5 进 1 号桶）：
分桶 → 0号桶 [3,1,4]    1号桶 [5,8]
桶内各自插入排序 → [1,3,4]  [5,8]
按桶序依次取出 → 1 3 4 5 8
基数排序：5 个数全是一位数，d=1，按个位做一轮计数排序即得 1 3 4 5 8
（个位就是最高有效位——这正解释了复杂度里 d 的含义：由最大值的位数决定）
```
课件原例：
```
桶排 {8,5,22,15,28,9,45,42,39,19,27,47,12}：按 n/10 分桶
→ [8,5,9] [15,19,12] [22,28,27] [39] [45,42,47]
→ 桶内各自排序，按桶序输出
桶排时间 = 遍历O(n) + 桶内排序总和；n 个数 m 个桶均匀时每桶 n/m 个，
桶内快排总代价 m*(n/m)log(n/m) = n(log n - log m)；m=n 时每桶1个元素
不再需要桶内排序 → 退化为计数排序 O(n)。时间复杂度 O(n+m)。

基数排序 {170,45,75,90,802,24,2,66}：补足3位
第1轮按个位计数排序、第2轮按十位、第3轮按百位
→ [2,24,45,66,75,90,170,802]
时间 O(d(n+b))：d=最大值位数(802→d=3)，n=数组长度，b=基数(十进制b=10)
d=log_K(K 为计算机可表示最大整数) → O((n+b)·log_K)；b 取足够大(=n)时 → O(n)
```

> ⚠️ 注意事项：桶排有相当的限制——桶个数和大小是人为设置的，要求数据**分布偏均匀**、又要兼顾桶设计效率和空间；数据跨度过大时空间消耗大、m 比 n 大太多时时间性能也不好，开发中很少直接用。基数排序渐进复杂度中隐含更高的常量因子、并非完全线性，快排更能有效利用硬件缓存；基数排序同样需要额外空间。

> 🎯 规律：非比较三兄弟是同一思路的三档精度——一格一值（计数）、一段一桶（桶）、一位一排（基数），全用空间换时间。

> 💡 一句话总结：桶要均匀，基数逐位，空间换时间。

| 对比 | 计数排序 | 桶排序 | 基数排序 |
|------|---------|--------|---------|
| 核心做法 | 值做下标统计次数 | 分桶后桶内各自排序 | 逐位做计数排序 |
| 时间 | O(n+k)，k=max-min+1 | O(n+m)（均匀时近线性） | O(d(n+b)) |
| 局限 | k 过大失灵（1~n² 时 O(n²)） | 要求数据分布偏均匀 | 只适用整数（可拆位） |
| 关系 | 桶排 m=n 的特例；基数排序的子过程 | 鸟巢排序的归纳结果 | 以计数排序为子过程 |

### 🧩 本章归纳：一条主线串全章

一条主线：**朴素算法各有短板 → 每个改进版都在补短板 → 补不动了就跳出"比较"框架**。

| 朴素版 | 短板 | 改进版 | 补法 | 代价 |
|--------|------|--------|------|------|
| 直接插入 | 小元素一步步挪 | 希尔 | 先分组跳跃前移 | 失去稳定性 |
| 冒泡 | 相邻交换太慢 | 快排 | 基准划分大步就位 | 失去稳定性、最坏 O(n²) |
| 简单选择 | 每趟扫全表找最值 | 堆排序 | 堆顶即最值，调整 O(logn) | 失去稳定性 |
| 比较排序全体 | O(nlogn) 下界 | 计数/桶/基数 | 不比较：值定位 / 分桶 / 拆位 | 耗空间、受数据分布限制 |

跨知识点共性规律：
1. **"每趟谁就位"视角**：插入（a[i+1] 进有序区）、冒泡（最大沉底）、快排（pivot 归位）、选择/堆（最值到端点）——所有手算题都从"这一趟谁定了最终位置"入手，趟数与有序区边界也随之推出。
2. **稳定性看"换位距离"**：相邻移动（插入、冒泡）或受控合并（归并取左半、计数倒序填位）→ 稳定；远距离交换/跨组调动（希尔分组、快排划分、选择远换、堆顶换尾）→ 不稳定。这就是"插冒归计"口诀背后的成因。
3. **复杂度 = 层数 × 每层代价**：分治/堆每层总计 O(n)、只有 O(logn) 层 → O(nlogn)；一次只定位一个元素、每层扫到底 → O(n²)；不比较则绕开 O(nlogn) 下界，但受值域（计数）与分布（桶）限制。

### 组1：内部排序 vs 外部排序

| 对比维度 | 内部排序 | 外部排序 |
|----------|---------|---------|
| 各自定义 | 待排序记录可以**一次载入内存**处理 | 记录**不能一次载入内存**，需借助辅存 |
| 核心区别 | 处理过程全在内存 | 与硬盘、CD 等外部存储器关联 |
| 各自特点 | 关注比较与移动次数 | 关注内外存数据交换（I/O）次数 |
| 使用场景 | 数据量不大、内存装得下 | 待排序记录数量非常大 |
| 典型示例 | 插入、冒泡、快排等本章大部分 | 归并排序及其变体是典型外部排序算法 |
| 记忆口诀 | 装得下叫内部，装不下借外存 | |

### 组2：直接插入排序 vs 希尔排序

| 对比维度 | 直接插入排序 | 希尔排序 |
|----------|-------------|---------|
| 各自定义 | 有序表+无序表，逐个顺序查找插入 | 按增量 d 分组各自插入，d 缩小到 1 再整表插入 |
| 核心区别 | 元素一步一步前移 | 小记录**跳跃式前移** |
| 各自特点 | 基本有序/量少时效率高 | 最后一趟整表插入只需少量比较移动 |
| 使用场景 | 数据量小或基本有序（STL ≤8 个用插入） | 数据量较大且较无序 |
| 典型示例 | {3,1,7,5,2,4,9,6} 逐个插入 | {49,38,65,...} 增量 5→3→1 |
| 记忆口诀 | 插入一步一步走，希尔跳跃分组走 | |

### 组3：冒泡排序 vs 快速排序

| 对比维度 | 冒泡排序 | 快速排序 |
|----------|---------|---------|
| 各自定义 | 相邻两两比较交换，大数逐趟沉底 | 选基准 partition 归位，左右递归 |
| 核心区别 | 每趟只前进一格（相邻交换） | 每趟确定基准最终位置（大步划分） |
| 各自特点 | 优化后最好 O(n)；稳定；恒定 O(1) 空间 | 平均 O(nlogn)；最坏 O(n²)；递归栈 O(logn)~O(n) |
| 使用场景 | 小数据/教学；要求稳定时 | 通用大规模排序（平均最快之一） |
| 典型示例 | {1,4,2,5,4,8} 第一趟 8 沉底 | {1,8,3,9,4,5,4,7} 取 7 划分成两组 |
| 记忆口诀 | 冒泡相邻慢慢挪，快排选桩两边分 | |

### 组4：简单选择排序 vs 堆排序

| 对比维度 | 简单选择排序 | 堆排序 |
|----------|-------------|--------|
| 各自定义 | 每趟在乱序区找最小值，交换到乱序区第一个位置 | 建大顶堆，堆顶与乱序区末尾交换后向下调整 |
| 核心区别 | 顺序扫描找最值 O(n) | 堆顶即最值，调整 O(logn) |
| 各自特点 | 比较次数与初始序列无关，O(n²) | 建堆 O(n)，排序 O(nlogn)，O(1) 辅助空间 |
| 使用场景 | 小数据、交换代价小 | 大数据、要求就地且 O(nlogn) |
| 典型示例 | 第 i 趟 [i,n] 找 min 与 a[i] 交换 | a[1] 与 a[k] 交换，k--，DownAdjust(a,1,k) |
| 记忆口诀 | 选择扫一遍，堆排调到底 | |

### 组5：稳定排序 vs 不稳定排序（本章算法归属）

| 对比维度 | 稳定排序 | 不稳定排序 |
|----------|---------|-----------|
| 各自定义 | 相同关键字排序后**相对位置不变** | 相同关键字相对位置可能改变 |
| 本章归属 | 直接插入、冒泡、归并、计数 | 希尔、快速、简单选择、堆排序 |
| 核心区别 | 相等元素不发生跨越式换位 | 划分/分组/远距离交换打乱相等元素 |
| 使用场景 | 键值对按主键排（人名→详细信息） | 纯数值排序、无相等键场景 |
| 典型示例 | 冒泡相邻相等不交换；归并取等号选前段 | 快排选相同元素做基准即乱序 |
| 记忆口诀 | 插冒归计稳，希选快堆不稳 | |

### 组6：计数排序 vs 桶排序

| 对比维度 | 计数排序 | 桶排序 |
|----------|---------|--------|
| 各自定义 | count[] 按值统计出现次数后定位输出 | 数组分散到有限数量的桶，桶内再排序 |
| 核心区别 | 一个值一个"格子"（部分哈希） | 一个桶装一段值域的多个元素 |
| 各自特点 | O(n+k)，k=值域范围，空间与数据范围成正比 | 均匀分布时 Θ(n)；桶内还要排序 |
| 使用场景 | 整数、值域不明显大于 n | 数据分布均匀或跨度不太大 |
| 典型示例 | {1,4,1,2,5,2,4,1,8} 统计 9 格 | 按 n/10 分 5 个桶各自排序 |
| 记忆口诀 | 计数一格一值，桶装一段一桶 | |

### 核心代码模板（合并版）
```c
// 1) 直接插入：边找边移
for(i=1;i<=n-1;i++){ x=a[i+1];
  for(j=i;j>=1&&a[j]>x;j--) a[j+1]=a[j];
  a[j+1]=x; }

// 2) 希尔：增量减半，组内插入（步长 d）
for(d=n/2;d>=1;d/=2)
  for(i=1+d;i<=n;i++){ x=a[i];
    for(j=i-d;j>=1;j-=d) if(a[j]>x) a[j+d]=a[j]; else break;
    a[j+d]=x; }

// 3) 冒泡：flag 优化
for(i=1;i<=n-1;i++){ flag=0;
  for(j=1;j<=n-i;j++) if(a[j]>a[j+1]){flag=1;swap(a[j],a[j+1]);}
  if(!flag)break; }

// 4) 快排：首元素基准挖坑
void QSort(int a[],int l,int r){
  if(l>=r)return; int i=l,j=r,p=a[l];
  while(i<j){
    while(i<j&&a[j]>=p)j--; if(i<j)a[i++]=a[j];
    while(i<j&&a[i]<=p)i++; if(i<j)a[j--]=a[i]; }
  a[i]=p; QSort(a,l,i-1);QSort(a,i+1,r); }

// 5) 简单选择
for(i=1;i<=n-1;i++){ minn=i;
  for(j=i+1;j<=n;j++) if(a[j]<a[minn])minn=j;
  swap(a[i],a[minn]); }

// 6) 堆排序：DownAdjust 后建堆+排序
for(i=n/2;i>=1;i--) DownAdjust(a,i,n);   // 建堆 O(n)
for(k=n,i=1;i<=n-1;i++){ swap(a[1],a[k]);k--;DownAdjust(a,1,k); }
// DownAdjust：nex=2*now；右孩子存在且更大则 nex=2*now+1；
//             a[now]<a[nex] 则交换下沉，否则 break

// 7) 归并
void MergeSort(int a[],int l,int r){
  if(l>=r)return; int mid=(l+r)/2;
  MergeSort(a,l,mid);MergeSort(a,mid+1,r);
  i=l;j=mid+1;k=0;
  while(i<=mid&&j<=r) t[k++]=(a[i]<=a[j])?a[i++]:a[j++];  // <= 稳定
  while(i<=mid)t[k++]=a[i++];  while(j<=r)t[k++]=a[j++];
  for(i=0;i<k;i++) a[l+i]=t[i]; }

// 8) 计数排序（稳定版）
for(i=1;i<=n;i++)   cnt[a[i]]++;                 // ①计数
for(i=1;i<=maxx;i++)sum[i]=sum[i-1]+cnt[i];      // ②前缀和
for(i=n;i>=1;i--){ k=sum[a[i]]; t[k]=a[i]; sum[a[i]]--; } // ③从后向前
```

**第2题（★★ 希尔手算）**

**第3题（★★★ 快排 partition）**
对数组 {1, 8, 3, 9, 4, 5, 4, 7} 做快速排序，选末尾元素 7 为 pivot：
（1）仿照课件逐步列出 i、j 的变化及每一步交换后的数组状态（共九步），写出第一趟结束后的结果；

**第4题（★★★★ 综合分析）**
（1）冒泡排序加入 swapped 标志后最好情况时间复杂度降为 O(n)，而简单选择排序无论输入是否有序都是 O(n²)，请从"比较次数与交换次数是否受输入影响"的角度分别解释原因；
