### 设计算法题 1　链表原地逆置
**题干**：设计算法将带头结点的单链表**原地**逆置，空间 O(1)。
**思路**：头插法重插——摘下每个结点插到头结点之后；或三指针逐个翻转。
**代码**：
```c
#include <stdio.h>
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;

void reverseList(LNode *head) {
    LNode *p = head->next, *q;
    head->next = NULL;
    while (p != NULL) {
        q = p->next;             /* 先存后继 */
        p->next = head->next;    /* 头插 */
        head->next = p;
        p = q;
    }
}
```
**正确性**：每个结点恰处理一次，头插使顺序天然倒置。
**复杂度**：时间 O(n)，空间 O(1)。

### 设计算法题 2　删除链表中绝对值相等的重复结点（保留首个）
**题干**：结点值 |data| ≤ n，删除绝对值重复的结点只保留第一次出现，尽量高效。
**思路**：辅助标记数组 O(n) 空间换一次遍历；值域小是题面给的信号。
**代码**：
```c
void dedupAbs(LNode *head, int n) {
    char *seen = calloc(n + 1, 1);       /* 标记 |data| 是否出现 */
    LNode *pre = head, *p = head->next;
    while (p != NULL) {
        int v = p->data > 0 ? p->data : -p->data;
        if (seen[v]) {                   /* 重复：摘除 */
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            seen[v] = 1;
            pre = p;
            p = p->next;
        }
    }
    free(seen);
}
```
**正确性**：保留首现即「先标后删」；数组随值域 O(n)。
**复杂度**：时间 O(n)，空间 O(n)。

### 设计算法题 3　两个升序链表合并为降序链表（原地）
**题干**：两升序单链表合并成一个**降序**链表，用原结点，空间 O(1)。
**思路**：归并 + 头插：比较两表头取小者，头插进结果——归并保序、头插倒序，一次遍历两件事。
**代码**：
```c
LNode* mergeDesc(LNode *A, LNode *B) {   /* 均带头结点 */
    LNode *head = (LNode *)malloc(sizeof(LNode));
    head->next = NULL;
    LNode *p = A->next, *q = B->next;
    while (p != NULL && q != NULL) {
        LNode *t = (p->data <= q->data) ? p : q;
        if (p->data <= q->data) p = p->next; else q = q->next;
        t->next = head->next;            /* 头插成降序 */
        head->next = t;
    }
    while (p != NULL) { LNode *t = p; p = p->next; t->next = head->next; head->next = t; }
    while (q != NULL) { LNode *t = q; q = q->next; t->next = head->next; head->next = t; }
    return head;
}
```
**正确性**：两表各取最小 → 头插后最小在尾部，天然降序。
**复杂度**：时间 O(m + n)，空间 O(1)。

### 设计算法题 4　共享栈（两栈共用一个数组）
**题干**：设计两栈共用一数组的入栈出栈，栈满条件是什么？
**思路**：两栈相向生长（第 2 章 2-2），判满 top0 + 1 == top1。
**代码**：
```c
typedef struct {
    int data[100];
    int top0, top1;                      /* top0=-1 起，top1=100 起 */
} DStack;

void initD(DStack *s) { s->top0 = -1; s->top1 = 100; }

int push0(DStack *s, int x) {
    if (s->top0 + 1 == s->top1) return 0;    /* 满：两顶相遇 */
    s->data[++s->top0] = x;
    return 1;
}
int push1(DStack *s, int x) {
    if (s->top0 + 1 == s->top1) return 0;
    s->data[--s->top1] = x;
    return 1;
}
int pop0(DStack *s, int *x) {
    if (s->top0 == -1) return 0;
    *x = s->data[s->top0--];
    return 1;
}
```
**正确性**：判满即空间耗尽；各自判空互不干扰。
**复杂度**：全部 O(1)，空间 O(100)。

### 设计算法题 5　循环队列判满的 size 方案
**题干**：不用牺牲单元，设计循环队列并给出判满判空。
**思路**：增设 size 计数（第 2 章 2-5 三方案之二）。
**代码**：
```c
typedef struct {
    int data[100];
    int front, size;                     /* front 队头下标，size 计数 */
} CQueue;

void initQ(CQueue *q) { q->front = 0; q->size = 0; }

int enQ(CQueue *q, int x) {
    if (q->size == 100) return 0;        /* 满：size 达容量 */
    q->data[(q->front + q->size) % 100] = x;
    q->size++;
    return 1;
}
int deQ(CQueue *q, int *x) {
    if (q->size == 0) return 0;          /* 空 */
    *x = q->data[q->front];
    q->front = (q->front + 1) % 100;
    q->size--;
    return 1;
}
```
**正确性**：rear 由 front + size 推出，无二义。
**复杂度**：O(1)；100 格全可用。

### 设计算法题 6　判断二叉树是否为二叉搜索树
**题干**：判断给定二叉树是否 BST。
**思路**：BST 中序递增——中序遍历中维护「前驱值」，一旦不增即否；比「逐结点比孩子」正确（后者漏跨层反例）。
**代码**：
```c
int check(BiTree T, int *pre) {          /* pre 初值设为极小 */
    if (T == NULL) return 1;
    if (!check(T->lchild, pre)) return 0;
    if (T->data <= *pre) return 0;       /* 中序必须严格递增 */
    *pre = T->data;
    return check(T->rchild, pre);
}
/* 调用：int pre = -2147483648; check(root, &pre); */
```
**正确性**：中序严格递增 ⇔ BST（等价定义）。
**复杂度**：时间 O(n)，空间 O(h)（递归栈）。

### 设计算法题 7　非递归求二叉树高度
**题干**：用**层序遍历**求二叉树高度（禁递归）。
**思路**：队列逐层出，记录每层最后一个结点，换层时高度加一。
**代码**：
```c
int height(BiTree T) {
    if (T == NULL) return 0;
    BiTree queue[1000];
    int front = 0, rear = 0, h = 0;
    queue[rear++] = T;
    while (front < rear) {
        int last = rear;                 /* 本层右边界 */
        h++;
        while (front < last) {           /* 弹完本层 */
            BiTree p = queue[front++];
            if (p->lchild) queue[rear++] = p->lchild;
            if (p->rchild) queue[rear++] = p->rchild;
        }
    }
    return h;
}
```
**正确性**：每轮 while 恰好消费一层。
**复杂度**：时间 O(n)，空间 O(宽度 ≤ n)。

### 设计算法题 8　判断二叉树是否为完全二叉树
**题干**：判完全二叉树（层序编号连续无空洞）。
**思路**：层序入队（空孩子也入队）；遍历中遇空后**不得再遇非空**——否则有空洞。
**代码**：
```c
int isComplete(BiTree T) {
    if (T == NULL) return 1;
    BiTree queue[1000];
    int front = 0, rear = 0, metNull = 0;
    queue[rear++] = T;
    while (front < rear) {
        BiTree p = queue[front++];
        if (p == NULL) { metNull = 1; continue; }
        if (metNull) return 0;           /* 空后还有结点：有空洞 */
        queue[rear++] = p->lchild;       /* 空孩子也入队 */
        queue[rear++] = p->rchild;
    }
    return 1;
}
```
**正确性**：完全树层序中「空之后全空」。
**复杂度**：时间 O(n)，空间 O(n)。

### 设计算法题 9　邻接表上的出边删除与插入（图基本操作）
**题干**：在邻接表中实现「插入边 ⟨u,v,w⟩」「删除边 ⟨u,v⟩」，给出删除时的前驱维护。
**思路**：插入头插 O(1)；删除必须找**前驱结点**再摘链（单链表无法自删）。
**代码**：
```c
int insertArc(ALGraph *g, int u, int v, int w) {
    ArcNode *p = (ArcNode *)malloc(sizeof(ArcNode));
    if (!p) return 0;
    p->adjvex = v; p->w = w;
    p->next = g->first[u];
    g->first[u] = p;
    g->e++;
    return 1;
}

int deleteArc(ALGraph *g, int u, int v) {
    ArcNode *pre = NULL, *p = g->first[u];
    while (p != NULL && p->adjvex != v) {    /* 找边结点与前驱 */
        pre = p;
        p = p->next;
    }
    if (p == NULL) return 0;                 /* 边不存在 */
    if (pre == NULL) g->first[u] = p->next;  /* 删头 */
    else pre->next = p->next;                /* 删中间 */
    free(p);
    g->e--;
    return 1;
}
```
**正确性**：前驱判空区分删头 / 删中间（第 1 章 1-5 的边界）。
**复杂度**：插入 O(1)；删除 O(度(u))。

### 设计算法题 10　两个等长升序数组求合并后的中位数
**题干**：两个等长升序数组 A、B（长 n），求合并后中位数，要求 O(log n)。
**思路**：折半比较**各自中位数**：a = A[mid]、b = B[mid]；a == b 即中位数；a < b 则中位数在 A 的右半与 B 的左半（各舍弃等长的一半）；否则对称。每次范围减半。
**代码**：
```c
int midOfTwo(int A[], int B[], int n) {   /* 返回中位数（下取整口径） */
    int lo1 = 0, hi1 = n - 1, lo2 = 0, hi2 = n - 1;
    while (lo1 < hi1) {
        int m1 = (lo1 + hi1) / 2, m2 = (lo2 + hi2) / 2;
        if (A[m1] == B[m2]) return A[m1];
        if (A[m1] < B[m2]) {              /* 舍 A 左半 + B 右半 */
            lo1 = m1 + 1;
            hi2 = m2;                     /* 长度奇偶：B 保留 mid */
            if ((hi1 - lo1) > (hi2 - lo2)) hi1 = m1;  /* 对齐长度 */
        } else {
            hi1 = m1;
            lo2 = m2 + 1;
            if ((hi2 - lo2) > (hi1 - lo1)) hi2 = m2;
        }
    }
    return A[lo1] < B[lo2] ? A[lo1] : B[lo2];
}
```
**正确性**：两中位数比较可安全舍弃两外侧等长部分（中位数分界性质）。
**复杂度**：时间 O(log n)，空间 O(1)。（O(n) 双指针归并取第 n 位是次优对照组，可在答案中先给 O(n) 再优化。）

### 设计算法题 11　荷兰国旗问题（三分数组）
**题干**：数组元素仅含 0、1、2，就地排序，一遍扫描。
**思路**：三指针——low 指 0 区右界、high 指 2 区左界、cur 扫描；遇 0 换到 low 前（low++，cur++），遇 2 换到 high 后（high--，**cur 不动**——换来的可能是 0/1 需再判），遇 1 跳过。
**代码**：
```c
void flag(int a[], int n) {
    int low = 0, high = n - 1, cur = 0;
    while (cur <= high) {
        if (a[cur] == 0) {
            int t = a[cur]; a[cur] = a[low]; a[low] = t;
            low++; cur++;
        } else if (a[cur] == 2) {
            int t = a[cur]; a[cur] = a[high]; a[high] = t;
            high--;                       /* cur 不动：换来的值未判 */
        } else {
            cur++;
        }
    }
}
```
**正确性**：循环不变量——[0,low) 全 0、(high,n) 全 2、[low,cur) 全 1。
**复杂度**：时间 O(n) 一遍，空间 O(1)。（快排 partition 的双指针思想变体。）

## B-4　综合题（非代码）高频套路

| 题型 | 套路 |
|------|------|
| 折半判定树 | 定根（mid 向下取整）→ 递归分半 → 数层算 ASL（成功 / 失败分开） |
| AVL 逐个插入 | 每插回溯找最小不平衡子树 → 判 LL/LR/RR/RL → 旋转后中序不变自查 |
| B 树删插 | 插叶分裂上移 / 删叶借或并；失败结点恒同层自检 |
| Dijkstra | 逐轮画 dist 表：挑最小画圈 → 松弛一圈 → 该列锁定 |
| 关键路径 | ve 正推 max → vl 逆推 min → e、l → 关键活动 l−e=0 |
| 散列表 | 逐元素探测入表 → 成功 ASL（分母 n）→ 失败 ASL（分母 m，走到空位） |
| 外部排序 | 段数 → 趟数 ⌈log_k r⌉ → 虚段补齐 → 最佳归并树读写量 |
