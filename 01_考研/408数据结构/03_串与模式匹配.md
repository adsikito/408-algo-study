## 本章地图

字符串查找是「在一段文字里找另一个词」：主串里找模式串。最直接的办法是从主串每个位置出发依次比对（BF 暴力匹配），最坏要 O(n × m)；KMP 的改进只有一个——**匹配失败时不回退主串指针**，靠预先算好的 next 数组让模式串「自己往左滑到最合适的位置接着比」。

学习路径：先把「串」当成一种线性表认识（存储、长度、子串），再看 BF 怎么做、慢在哪（主串指针回退）；然后进入本章核心——**手工算 next 数组**（next[j] = 模式串前 j-1 个字符中最长相等前后缀的长度 + 1），再把手工算法翻译成递推代码；最后补上 nextval 优化【补充】与完整匹配过程的推演方法。**全章枢纽：最长相等前后缀这一句话。**

---

## 本章重点

> **【重点】** **串的定义**：零个或多个字符组成的有限序列；字符个数 n 为串长，n = 0 时为空串；由一个或多个**空格**组成的串是空格串（不是空串）。

> **【重点】** **next 数组公式**（模式串下标从 1 开始）：`next[1] = 0`，`next[2] = 1`，
> `next[j] =` 「模式串第 1 至 j-1 个字符构成的串中，**最长相等前后缀的长度 + 1**」。

> **【重点】** **BF 与 KMP 的本质区别**：BF 失配时主串指针 i 回退（i = i - j + 2），KMP 主串指针**永不回退**，只按 `j = next[j]` 调整模式串指针；KMP 最坏 O(n + m)，BF 最坏 O(n × m)。

> **【重点】** **nextval 的含义**【补充】：在 next 基础上再做一步「若滑过去的字符与本位字符相同，则这次滑动必然还是失配，直接沿 next 链再滑」的优化。

---

## 本章难点

> **【难点】** **最长相等前后缀的求法**：对模式串每个位置 j，只看**前 j-1 个字符**（不含第 j 个），在所有「真前缀 = 真后缀」的相等对里取最长的。易错点：把第 j 个字符也算进去、或把「相等前后缀可以重叠」理解错——**前后缀可以部分重叠，但不能是整串本身**。

> **【难点】** **两种下标口径的公式换算**：教材口径（下标从 1，next[1] = 0）与工程口径（下标从 0，next[0] = -1）差一个常数。408 用教材口径，但选择题给过工程口径的代码让你判断——**先认口径再套公式**。

---

## 本章易错点

> **【易错】** **空格串与空串混为一谈**：空串长度为 0；空格串由空格组成，长度等于空格个数，两个都不是「没有内容」的同一回事。

> **【易错】** **求 next[j] 时把第 j 个字符算进去**：next[j] 只依赖模式串的**前 j-1 个字符**，与第 j 个字符是什么无关。

> **【易错】** **KMP 中 j 与 next[j] 的方向搞反**：失配后 j 变小（模式串左滑），i 永远不变；写成 i 回退就是 BF。

> **【易错】** **next 数组值与「第几」的错位**：教材口径下 next[j] 的物理含义是「失配后 j 应改成的下标」，不是「相等前后缀长度」本身——两者恰好差 1，填空题最爱考这个错位。

## 知识点讲解

### 3-1　串的定义与存储结构　【P1】

**是什么**：串（字符串）是零个或多个字符组成的有限序列，记作 `S = 'a1a2…an'`。子串是串中任意连续字符组成的子序列；包含子串的串叫主串；字符在序列中的序号叫该字符的位置。

**为什么**：串是「内容受限的线性表」——元素只能是字符，因此线性表的操作大部分可用，但**按内容匹配**（找子串）成了它特有的核心操作。

**怎么用**：三种存储方案：

| 存储 | 做法 | 优缺点 |
|------|------|--------|
| 定长顺序存储 | 静态数组 + length 或 `\0` 结尾 | 简单快，但长度受预分配限制 |
| 堆分配存储 | `malloc` 动态数组 + length | 长度可扩，释放需手动 `free` |
| 块链存储 | 每结点存 1 至多个字符的链表 | 省空间，但随机访问差，**考试只要求辨析** |

> **【注意】** 判空：顺序存储看 `length == 0` 或首字符是否 `\0`；两种判法对应两种长度记录方案，选择题考过辨析。`\0` 方案下 `\0` 本身不计入长度。

**前置与延伸**：
- 前置：线性表顺序存储（第 1 章 1-2）
- 延伸：第 6 章 B 树关键词比较也用串比较；竞赛侧字符串哈希与 KMP 见阶段 6

### 3-2　暴力匹配 BF　【P0】

**是什么**：从主串第 1 个字符起，与模式串逐位比较；失配则主串起点右移一位、模式串从头再来，直到匹配成功或主串剩余长度不足。

**为什么**：它是理解 KMP 的对照组——BF 的问题不是「比得太多」，而是**每次失配都把已比较过的信息全部扔掉**，主串指针回退重来。

**怎么用**（教材口径：主串、模式串下标均从 1）：

```c
#include <stdio.h>

int BF(char S[], int n, char T[], int m) {
    int i = 1, j = 1;                /* i 主串指针，j 模式串指针 */
    while (i <= n && j <= m) {
        if (S[i] == T[j]) {          /* 相同：两指针一起右移 */
            i++;
            j++;
        } else {                     /* 失配：i 回退到本次起点下一位，j 归 1 */
            i = i - j + 2;
            j = 1;
        }
    }
    if (j > m)                       /* 模式串走完：匹配成功 */
        return i - m;                /* 返回起点下标（教材口径） */
    return 0;                        /* 失败 */
}
```

> **【规律】** BF 最坏情形：主串 `aaaa…ab`（n 个 a）找 `aaab`——每趟都比到模式串最后一位才失配，共 (n - m + 1) × m 次比较，即 **O(n × m)**。最好情形 O(n + m)。

**前置与延伸**：
- 前置：知识点 3-1
- 延伸：KMP（下一知识点）消除的就是这里的 i 回退

### 3-3　KMP 思想与 next 数组手工计算　【P0】

**是什么**：KMP 在失配时利用「模式串自己已经比较过的部分」：失败位置 j 之前的模式串前缀里，**已与主串对上的部分**存在相等的前后缀，把模式串滑到「前缀对齐已比过的后缀」处即可继续比较。每个位置滑多远，预先算好存进 next 数组。

**为什么**：主串指针不回退意味着主串每个字符至多参与「一次失配 + 一次成功」的比较，比较次数上界 O(n)，加上预计算 O(m)，总计 **O(n + m)**——把乘法降成加法。

**怎么用（手工计算四步）**：

1. 写 `next[1] = 0`，`next[2] = 1`（教材口径，直接背）。
2. 对 j = 3 起的每个位置：取模式串**前 j-1 个字符**。
3. 在其中找「最长相等真前后缀」：即最大的 k，使前 k 个字符 == 后 k 个字符（k < j - 1）。
4. `next[j] = k + 1`；找不到相等前后缀则 k = 0，`next[j] = 1`。

**完整示例**：模式串 `ababaa`（下标 1 至 6）：

| j | 前 j-1 个字符 | 最长相等前后缀 k | next[j] = k + 1 |
|---|--------------|-----------------|-----------------|
| 1 | — | 规定 | 0 |
| 2 | a | 规定 | 1 |
| 3 | ab | 0 | 1 |
| 4 | aba | a（长 1） | 2 |
| 5 | abab | ab（长 2） | 3 |
| 6 | ababa | aba（长 3） | 4 |

故 `next = [0, 1, 1, 2, 3, 4]`。注意 j = 6 时前 5 个字符 `ababa` 的相等前后缀是 `aba`（前 3 个 == 后 3 个，中间的 b 共用），**允许重叠**。

> **【记忆】** 「加一替长」：next[j] = 最长相等前后缀长度 + 1。首两位固定 0 和 1。

> **【注意】** 工程口径（下标从 0）的同一个模式串算出的数组是 `[−1, 0, 0, 1, 2, 3]`——每个值恰比教材口径小 1。考试认「next[1] = 0」即教材口径。

**前置与延伸**：
- 前置：知识点 3-2（知道失配发生在哪）
- 延伸：nextval（3-5）；AC 自动机（多模式串版 KMP，超出考纲）

### 3-4　next 数组的代码实现（递推法）　【P0】

**是什么**：不用每位置暴力重算，而是**递推**：已知 next[j]，利用 `T[j] == T[next[j]]` 与否 O(1) 推出 next[j+1]。

**为什么**：手工法是理解工具，代码必须用递推——每位置 O(1) 均摊，总 O(m)；暴力重算是 O(m²)，会拖垮整体复杂度。

**怎么用**：

```c
#include <stdio.h>

void getNext(char T[], int m, int next[]) {
    int i = 1, j = 0;                /* i 待求位置，j 已知的最长相等前后缀指针 */
    next[1] = 0;
    while (i < m) {
        if (j == 0 || T[i] == T[j]) {
            i++;                     /* 匹配：长度加一 */
            j++;
            next[i] = j;
        } else {
            j = next[j];             /* 失配：j 沿 next 链回缩 */
        }
    }
}

int KMP(char S[], int n, char T[], int m) {
    int next[100];
    int i = 1, j = 1;
    getNext(T, m, next);
    while (i <= n && j <= m) {
        if (j == 0 || S[i] == T[j]) {
            i++;
            j++;
        } else {
            j = next[j];             /* 主串 i 不动，模式串左滑 */
        }
    }
    if (j > m) return i - m;
    return 0;
}
```

> **【规律】** getNext 与 KMP 主体**结构完全相同**，都是「相同则双进，失配则 j = next[j]」——把模式串自己当主串与自己匹配，就是 next 的递推。记一份代码得两份。

> **【注意】** `j == 0` 的判断对应 next[1] = 0：j 为 0 时无相等前后缀可滑，i、j 同时右移重新开始。选择题问「KMP 中 j == 0 的含义」，答「模式串第一个字符就失配，从主串下一字符重新比」。

**前置与延伸**：
- 前置：知识点 3-3 的手工过程（先会笔算，再看递推如何复现它）
- 延伸：nextval（3-5）在此代码上加两个判断即可

### 3-5　nextval 优化【补充】　【P1】

**是什么**：next 数组的再优化：若按 next[j] 滑过去的模式串字符 `T[next[j]]` 与当前失配字符 `T[j]` **相同**，这次滑动必然再次失配，于是直接沿链再滑：`nextval[j] = nextval[next[j]]`；不同则 `nextval[j] = next[j]`。

**为什么**：失配说明主串字符不等于 T[j]；若 T[next[j]] == T[j]，滑过去拿同一个字符来比还是不等，白白多比一次。nextval 一次算到位，把这类「注定失败」的比较全部省掉。

**怎么用**：仍以 `ababaa` 为例（next = [0, 1, 1, 2, 3, 4]）：

| j | T[j] | T[next[j]] | 是否相同 | nextval[j] |
|---|------|-----------|---------|-----------|
| 1 | a | — | 规定 | 0 |
| 2 | b | T[1]=a | 否 | 1 |
| 3 | a | T[1]=a | **是** | nextval[1] = 0 |
| 4 | b | T[2]=b | **是** | nextval[2] = 1 |
| 5 | a | T[3]=a | **是** | nextval[3] = 0 |
| 6 | a | T[4]=b | 否 | 4 |

故 `nextval = [0, 1, 0, 1, 0, 4]`。

> **【规律】** nextval 必须**从小到大**逐位算：nextval[j] 可能引用 nextval[next[j]]，而 next[j] < j，所以顺序递推即可。选择题常考「给出 next 求 nextval」，先列表再逐位判定，不要心算跳步。

> **【类比】** next 是「滑到最长的靠谱位置」，nextval 是「滑过去也不行的话，直接滑到再下一站」——公交坐过站了就别在这一站下车等同一班车。

**前置与延伸**：
- 前置：知识点 3-3、3-4
- 延伸：KMP 的工程实现普遍内置 nextval 等价逻辑（失配即连环跳）

### 3-6　KMP 完整匹配过程与比较次数　【P0】

**是什么**：给定主串与模式串及 next 数组，**逐步写出匹配过程中 i、j 的变化**——这是 408 综合题的标准问法，也是判断「是否真懂 KMP」的试金石。

**怎么用（推演模板）**：

1. i、j 都从 1 开始；每步只做一件事：相等则 i、j 同时加一，失配则 j = next[j]。
2. j 变成 0 时，i、j 同时加一（模式串从头再来，主串前进）。
3. j 超过 m 即匹配成功，起点 = i − m。
4. 数比较次数：**每次「比较」计一次**，包括成功比与失败比；失配滑动本身不算比较。

**推演示例**：主串 `ababcabcabababaa`...（截取 `ababcabababa`，长 11，下标 1 至 11）中找 `ababa`（m = 5，next = [0, 1, 1, 2, 3]）：

| 步 | 动作 | i | j | 比较结果 |
|----|------|---|---|---------|
| 1 | 比 S[1]=a 与 T[1]=a | 2 | 2 | 成 |
| 2 | 比 S[2]=b 与 T[2]=b | 3 | 3 | 成 |
| 3 | 比 S[3]=a 与 T[3]=a | 4 | 4 | 成 |
| 4 | 比 S[4]=b 与 T[4]=b | 5 | 5 | 成 |
| 5 | 比 S[5]=c 与 T[5]=a | 5 | 3 | 败，j=next[5]=3 |
| 6 | 比 S[5]=c 与 T[3]=a | 5 | 1 | 败，j=next[3]=1 |
| 7 | 比 S[5]=c 与 T[1]=a | 6 | 0 | 败，j=0 → i、j 各加一 |
| 8 | 比 S[6]=a 与 T[1]=a | 7 | 2 | 成 |
| 9 | 比 S[7]=b 与 T[2]=b | 8 | 3 | 成 |
| 10 | 比 S[8]=a 与 T[3]=a | 9 | 4 | 成 |
| 11 | 比 S[9]=b 与 T[4]=b | 10 | 5 | 成 |
| 12 | 比 S[10]=a 与 T[5]=a | 11 | 6 | 成，j > m 匹配成功 |

起点 = i − m = 11 − 5 = 6，主串第 6 位起为 `ababa`。主串指针 i 全程只前进不回退。

> **【规律】** KMP 的比较次数上界：**主串每字符至多「一败一成」两次比较**，故匹配阶段 ≤ 2n；含预计算总计 ≤ 2n + 2m = O(n + m)。填空题常问这个上界推导。

**前置与延伸**：
- 前置：知识点 3-3（next 数组在手）
- 延伸：第 4 章的非递归遍历同样是「栈不回退、指针单向」的思想亲缘

### 例题 3-1　（手工计算题 · 选择题风格）
**题干**：模式串 `aabbab`（下标从 1），求其 next 数组与 nextval 数组。

**解题思路**：按 3-3 四步先求 next，再按 3-5 逐位判「滑过去的字符是否相同」求 nextval。

**解答过程**：
| j | T[j] | 前 j-1 字符及其最长相等前后缀 | next[j] | T[next[j]] | nextval[j] |
|---|------|------------------------------|---------|-----------|-----------|
| 1 | a | —（规定） | 0 | — | 0 |
| 2 | a | a → 规定 | 1 | a（同） | 0 |
| 3 | b | aa → a（长 1） | 2 | a（同） | 0 |
| 4 | b | aab → 无 | 1 | a（异） | 1 |
| 5 | a | aabb → 无 | 1 | a（同） | 0 |
| 6 | b | aabba → a（长 1） | 2 | a（异） | 2 |

`next = [0, 1, 2, 1, 1, 2]`；`nextval = [0, 0, 0, 1, 0, 2]`。

**复杂度分析**：手工 O(m²)（表格法）；代码递推 O(m)。

### 例题 3-2　（概念辨析题 · 选择题风格）
**题干**：下列关于 KMP 算法的说法，错误的是：
Ⅰ. 匹配失败时主串指针回退到上一起点
Ⅱ. next[j] 只与模式串有关，与主串无关
Ⅲ. KMP 最好与最坏时间复杂度均为 O(n + m)
Ⅳ. next 数组可用递推法在 O(m) 内求出

**解题思路**：逐条对照定义：Ⅰ 违背 KMP 核心性质；Ⅱ 是 next 的定义（只看模式串自身前后缀）；Ⅲ 最好情形 O(n + m)（一路成功），最坏也是 O(n + m)（每字符至多两比）；Ⅳ 是 3-4 的结论。

**解答过程**：错误的是 **Ⅰ**。KMP 失配时**只有模式串指针 j 沿 next 链左移**，主串指针 i 永不回退——这正是它相对 BF 的全部优势来源。

**复杂度分析**：概念题，O(1)。

### 例题 3-3　（匹配过程推演题 · 综合应用题风格）
**题干**：主串 S = `abcabcaaa`（下标 1 至 9），模式串 T = `abcaa`，写出 KMP 匹配全过程（含 i、j 变化与比较次数），并给出匹配起点。next（教材口径）= [0, 1, 1, 1, 2]。

**解题思路**：套 3-6 推演模板逐步走，每失配一次就在表里记一行；结束时用「起点 = i − m」收尾。

**解答过程**：
| 步 | 动作 | i | j | 结果 |
|----|------|---|---|------|
| 1 | S[1]=a 比 T[1]=a | 2 | 2 | 成 |
| 2 | S[2]=b 比 T[2]=b | 3 | 3 | 成 |
| 3 | S[3]=c 比 T[3]=c | 4 | 4 | 成 |
| 4 | S[4]=a 比 T[4]=a | 5 | 5 | 成 |
| 5 | S[5]=b 比 T[5]=a | 5 | 2 | 败，j=next[5]=2 |
| 6 | S[5]=b 比 T[2]=b | 6 | 3 | 成 |
| 7 | S[6]=c 比 T[3]=c | 7 | 4 | 成 |
| 8 | S[7]=a 比 T[4]=a | 8 | 5 | 成 |
| 9 | S[8]=a 比 T[5]=a | 9 | 6 | 成，j > m |

共比较 10 次（成功 9 + 失败 1... 实计：步 1 至 9 每步一次比较，另步 5 失败一次即 10 次），起点 = 9 − 5 = **4**，主串第 4 位起为 `abcaa`。主串指针从未回退。

**复杂度分析**：匹配阶段比较 10 次 ≤ 2n = 18；预计算 O(m)。总 O(n + m)。

## 本章总结

### 核心内容（一页纸）

- **串**是内容受限的线性表；**空格串不是空串**，长度等于空格个数。
- 存储：定长顺序 / 堆分配 / 块链；`length` 与 `\0` 两种长度方案判空方式不同。
- **BF 最坏 O(n × m)**：每次失配主串指针回退、已比信息全部作废。
- **KMP 主串指针永不回退**：失配时 `j = next[j]`；总复杂度 **O(n + m)**。
- **next[j] = 前 j-1 个字符的最长相等真前后缀长度 + 1**；教材口径 `next[1] = 0`、`next[2] = 1`；前后缀**允许重叠但不含整串**。
- **next 数组与主串无关**，只由模式串决定；递推代码与匹配代码同构（「相同双进，失配跳链」）。
- **nextval**：`T[next[j]] == T[j]` 时直接跳 `nextval[next[j]]`，把注定失败的比较省掉；**从小到大逐位算**。
- 工程口径（下标 0，next[0] = −1）与教材口径整体差 1，**读题先认口径**。

### 知识点串联图

```text
串与模式匹配
├── 串的定义与存储（定长 / 堆分配 / 块链）
├── BF 暴力匹配（i 回退，O(n×m)）
└── KMP（i 不回退，O(n+m)）
    ├── next 手工计算（最长相等前后缀 + 1）
    ├── next 递推代码（getNext 与 KMP 同构）
    ├── nextval 优化（同字符连环跳）
    └── 匹配过程推演（比较次数上界 2n）
```
