## A-1　数据类型与 sizeof　【速查】

| 类型 | 典型字节数 | 范围（约） | 竞赛 / 考研注意 |
|------|-----------|-----------|----------------|
| `char` | 1 | −128 至 127 | 字符本质是小整数 |
| `short` | 2 | ±3.3 万 | 少用 |
| `int` | 4 | ±2.1 × 10⁹ | 10⁹ 量级乘法必溢出 |
| `long` | 4 / 8 | 视平台 | Windows 与 Linux 不同 |
| `long long` | 8 | ±9.2 × 10¹⁸ | 求和 / 乘积默认选它 |
| `float` / `double` | 4 / 8 | 有效位 7 / 15 位 | 比较用误差不用 `==` |

- `sizeof` 是**编译期**运算符：`sizeof(int)`、`sizeof(a)`（数组总字节）、`strlen(s)`（运行期数到 `\0`，不含 `\0`）——**sizeof 与 strlen 的区别**是经典辨析。
- 结构体对齐：成员按自身对齐数摆放，结构体总大小是**最大对齐数的整数倍**——考过「sizeof(struct)」计算题。

## A-2　赋值的本质与类型转换　【速查】

- 赋值 = 把右值的二进制**截断 / 补位**到左值类型：`char c = 300;` → 300 = 256 + 44 → c = 44（截断取低 8 位）。
- 隐式转换方向：小类型 → 大类型安全；大 → 小**静默截断**。
- 有符号 / 无符号混合运算：有符号**先转无符号**——`-1 < 0u` 为**假**，经典陷阱。
- 整数除法向零取整：`-7 / 2 = -3`；取模符号随被除数：`-7 % 2 = -1`。

## A-3　struct / union / enum　【速查】

```c
struct Node {              /* 各成员独立存储，总大小 ≥ 成员和 */
    int key;
    struct Node *next;
};

union Value {              /* 成员共享同一段内存，大小 = 最大成员 */
    int i;
    float f;
};

enum Color { RED, GREEN, BLUE };   /* RED=0, GREEN=1, BLUE=2 */
```

- 本工程全部链 / 树结点都是 `struct` + 自引用指针；`typedef` 起别名后免写 `struct`。
- `union` 判「共享内存、同一时刻只有一个成员有效」；`enum` 判「整常量别名」。

## A-4　指针的本质　【速查】

- 指针 = 存**地址**的变量。`int *p = &a;`：p 的值是 a 的地址，`*p` 解引用取内容。
- `p++` 移动**一个元素宽度**（不是 1 字节）——与指针类型相关。
- 二级指针 `T **pp`：修改链表头 / 树根时传 `&head`，函数内 `*pp = ...` 直接改外部指针（本工程第 1、4 章代码的惯例）。
- 野指针：未初始化 / 已 free 后继续用；空指针解引用 → 段错误。判空是代码题的**必写行**。

## A-5　数组、字符串与二维数组　【速查】

- 数组名在表达式中退化为**首元素地址**（`sizeof` 与 `&数组名` 两处例外）。
- 字符串 = `char` 数组 + `\0` 结尾；`char s[] = "abc"` 长度 4（含 `\0`），`strlen` 为 3。
- 二维数组 `a[m][n]` 按行优先连续存储；作函数参数必须传列数：`f(int a[][n])`。
- 数组与指针辨析：`int *p[5]`（指针数组，5 个指针）vs `int (*p)[5]`（数组指针，指向含 5 个 int 的数组）。

## A-6　内存分段模型　【重中之重】

```text
高地址 ┌──────────┐
       │ 栈区      │ 局部变量、函数参数、返回地址；自动管理，约 1-8 MB
       ├──────────┤
       │ 堆区      │ malloc/free 手动管理，向高地址长
       ├──────────┤
       │ 全局/静态区│ 全局变量、static 变量（程序全程存活）
       ├──────────┤
       │ 常量区    │ 字符串字面量（不可写）
       ├──────────┤
低地址 │ 代码区    │ 机器指令（只读）
       └──────────┘
```

- **大数组开全局**：局部 `int a[10⁷]` = 40 MB 栈分配 → 爆栈；全局区无此限制。
- 栈区与「数据结构的栈」同名不同物（第 2 章 2-1 的辨析点）。

## A-7　堆内存管理 malloc / free　【速查】

```c
#include <stdlib.h>

BSTNode *p = (BSTNode *)malloc(sizeof(BSTNode));  /* 申请不初始化 */
BSTNode *q = (BSTNode *)calloc(1, sizeof(BSTNode)); /* 申请并清零 */
if (p == NULL) return 0;                          /* 必判空 */
free(p);                                          /* 用完必还 */
p = NULL;                                         /* 防野指针 */
```

- `malloc` 失败返回 `NULL`；代码题的判空行是评分点。
- `free` 后指针仍指向原地址（悬空），续用 = 未定义行为。
- 内存泄漏：只 malloc 不 free；重复 free：未置 NULL 的二次释放。

## A-8　函数、递归与多文件　【速查】

- 传参全部**值传递**：想改外部变量传**指针**（或 C++ 引用）；大结构体传指针省拷贝。
- 递归三要素：终止条件、递归式、参数向终止推进——第 2 章 2-8 的「显式栈消递归」是本节的逆操作。
- 多文件：`.h` 放声明、`.c` 放定义；编译四步 = 预处理 → 编译 → 汇编 → 链接（概念级）。
- `static`：修饰全局变量 / 函数 = 限本文件可见；修饰局部变量 = 生命周期延至程序结束。

## A-9　代码题书写规范（408 算法设计题）

1. **可编译**：头文件、类型定义完整；不给伪代码。
2. **注释关键行**：循环不变量、边界、防野指针的行。
3. **复杂度必写**：时间 + 空间，说明「为什么」一句话。
4. 变量命名见名知义：`p` 结点、`pre` 前驱、`len` 长度、`cnt` 计数。

## 速查卡（一页打印）

| 场景 | 正确写法 | 常见错误 |
|------|---------|---------|
| 结点申请 | `malloc(sizeof(Node))` + 判空 + 初始化 | 忘判空 / 忘初始化 next |
| 修改表头 | 传二级指针 `Node **head` | 传一级指针改了副本 |
| 大数组 | 全局区定义 | 函数内 10⁷ 局部数组爆栈 |
| 字符串长度 | `strlen(s)`（不含 `\0`） | 与 `sizeof` 混用 |
| 两数交换 | 三变量或指针传参 | 值传参交换无效 |
| 有无符号比较 | 同侧统一 | `-1 < 0u` 恒假 |
| free 之后 | `p = NULL` | 继续访问悬空指针 |
