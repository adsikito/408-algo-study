## 本章地图

前面的结构管「怎么存」，本章管「怎么找得快」。查找的快慢不取决于运气，而取决于**结构是否为「缩小范围」付费**：顺序查找一个不省，折半每次砍半，分块先砍块再砍块内；树形结构把「比较一次、排除一半」固化成指针跳跃（BST → AVL → 红黑 → B 树，一路解决「退化」与「磁盘」两个瓶颈）；散列表则干脆绕过比较，用函数直接算出位置——代价是处理碰撞。

学习路径：先定义 ASL（衡量一切的尺子）；然后线性世界的三招（顺序、折半、分块）与判定树手算；再进入树形世界四代同堂（BST → AVL → 红黑 → B/B+），每代解决上一代的一个痛点；最后是反其道而行的散列表。**全章枢纽：ASL 与「每代解决什么瓶颈」。**

## 本章重点

> **【重点】** **ASL（平均查找长度）**：ASL = Σ pᵢ × cᵢ（查找第 i 个元素的概率 × 所需比较次数）；等概率下逐个定义每个结构的 ASL 公式（见各节）。

> **【重点】** **折半查找**：仅适用于**有序顺序表**；判定树是 BST 且为**平衡二叉树形态**；n 个元素的判定树高度 ⌈log₂(n+1)⌉，查找成功 ASL ≈ log₂(n+1) − 1，失败 ASL ≈ log₂(n+1)。

> **【重点】** **AVL 四种失衡与旋转**：LL 右单旋、RR 左单旋、LR 先左后右双旋、RL 先右后左双旋；失衡结点 = 最小不平衡子树的根。

> **【重点】** **B 树五条定义**（m 阶）：根至少 2 棵子树 1 个关键字；非根非叶至少 ⌈m/2⌉ 棵子树；每结点至多 m 棵子树 m−1 个关键字；叶子（失败结点）同层；关键字数 k 则子树数 k+1。

> **【重点】** **散列表两大冲突处理**：链地址法（同义词挂链）与开放定址法（线性 / 平方 / 双散列探测）；**删除只能懒删（标记）**，不能物理删，否则探测链断。

## 本章难点

> **【难点】** **AVL 删除可能引发旋转连锁**（一路旋转到根），插入至多一次旋转（单旋或双旋）即恢复平衡——「插入一次 / 删除多次」是选择题固定考点。

> **【难点】** **B 树删除的五种情况**：终端结点直接删 → 不够 ⌈m/2⌉−1 个时「兄弟够则借、兄弟不够则并」→ 合并向上传播；非终端结点删关键字用**直接前驱（左子树最右）或后继替换**化归为终端删除。

> **【难点】** **开放定址法的 ASL 手算**：失败查找要**沿探测序列走到第一个空位**才算失败；散列函数值相同不等于比较序列相同（堆积现象使不同散列值的探测序列交叉）。

## 本章易错点

> **【易错】** **头号易错：折半查找的 mid 取整方向与判定树形态**。`(low + high) / 2` 向下取整时，判定树左子树结点数 ≥ 右子树；手画判定树必须与代码口径一致。口诀「mid 向下取整，左肥右瘦」。

> **【易错】** **AVL 失衡类型的判读方向写反**：LL 指插入点在**失衡结点左孩子的左子树**，用**右单旋**——「类型名是位置、旋转是动作」，二者别混。

> **【易错】** **B 树「失败结点（叶子）同层」忘判**：B 树所有失败结点在同一层，等价于「根到每个失败结点的路径等长」——插入分裂使树长高**只从根长**，删除合并使树变矮**只从根缩**。

> **【易错】** **线性探测的「堆积」**：非同义词争夺同一探测位使 ASL 恶化；「散列函数均匀则探测序列不交叉」是**错**的说法。

> **【易错】** **散列表删除**：链地址法可物理删；开放定址法必须**打删除标记**，物理删除会截断探测链导致后位元素查不到。

## 知识点讲解

### 6-1　查找基本概念与 ASL　【P0】

**是什么**：查找表（静态：只查；动态：可插删）。关键字；平均查找长度 ASL = Σ pᵢcᵢ，衡量一切查找结构优劣的统一标尺。

**为什么**：比较型查找的代价就是「比较次数」，ASL 把它平均化后，才能在「顺序、折半、树形、散列」之间做定量比较——本章每节都是一道 ASL 计算题。

**怎么用**：等概率 pᵢ = 1/n 时 ASL = (Σcᵢ)/n。三类 cᵢ 口径：顺序查找第 i 个比较 i 次（成功）；折半看判定树**层数**（根为 1 层）；散列看**探测序列长度**。

> **【规律】** 查找成功 / 失败的 ASL **必须分开算**：失败情形常要走到「空指针 / 探测到空位」，判定树上对应外部结点（失败结点）。综合题两张表分开画。

**前置与延伸**：
- 前置：无
- 延伸：所有后续小节的统一标尺

### 6-2　顺序、折半、分块查找　【P0】

**是什么**：顺序查找：逐个比（有序表可加哨兵提前终止失败：比较到大于关键字即可停）。折半查找：有序**顺序表**上每次与 mid 比较、范围砍半。分块查找：**块间有序、块内无序**，先在索引（各块最大值）中折半 / 顺序定块，再块内顺序。

**为什么**：折半把 O(n) 压到 O(log n)，但要求顺序存储 + 有序（插入删除慢）；分块折中——索引有序允许快定位，块内无序允许动态插入。

**怎么用（折半代码 + 判定树）**：

```c
#include <stdio.h>

/* 折半查找：返回下标（1 起），失败返回 0 */
int BSearch(int a[], int n, int key) {
    int low = 1, high = n;
    while (low <= high) {
        int mid = (low + high) / 2;      /* 向下取整：左肥右瘦 */
        if (a[mid] == key) return mid;
        else if (a[mid] > key) high = mid - 1;
        else low = mid + 1;
    }
    return 0;
}
```

**判定树构造（n = 11 示例）**：low = 1, high = 11 → mid = 6（根）；左半 [1,5] → mid = 3；右半 [7,11] → mid = 9；继续分：3 的孩子 1、5，9 的孩子 7、11；1 的右孩 2，5 的右孩 4，7 的右孩 8，11 的左孩 10。
成功 ASL = (1×1 + 2×2 + 3×4 + 4×4) / 11 = 33/11 = **3**。

> **【规律】** 判定树三个性质：①树形 = 平衡二叉树形态（左右子树结点数差 ≤ 1）；②树高 = ⌈log₂(n+1)⌉；③**失败结点 = n + 1 个空指针**，失败 ASL 看失败结点层数（n = 11 时失败 ASL = 15/12... 按各失败结点层数求和除以 n+1）。

> **【注意】** 分块 ASL（等概率、b 块每块 s 个、索引顺序查找）：ASL = (b+1)/2 + (s+1)/2；**索引也折半**时 ASL = ⌈log₂(b+1)⌉ + (s+1)/2。令 s = √n 时 ASL 最小约 √n + 1。

**前置与延伸**：
- 前置：知识点 6-1；有序性
- 延伸：第 7 章折半插入排序复用 mid 比较；阶段 1 二分是竞赛版（值域二分）

### 6-3　二叉搜索树 BST　【P0】

**是什么**：左子树所有结点 < 根 < 右子树所有结点（递归成立）；**中序遍历得递增序列**。查找、插入、删除平均 O(log n)，最坏 O(n)（单斜退化）。

**为什么**：把折半的「范围砍半」搬进链式结构——查找路径就是一次不回头的比较序列；中序有序性使它同时承担「动态集合 + 排序输出」。

**怎么用（删除三情况）**：
1. 删**叶子**：直接删。
2. 删**单孩结点**：孩子顶替其位。
3. 删**双孩结点**：用**中序前驱（左子树最右）或后继（右子树最左）**替换值，再删那个替换结点（化归为情况 1 或 2）。

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct BSTNode {
    int key;
    struct BSTNode *lchild, *rchild;
} BSTNode, *BSTree;

BSTNode* BSTSearch(BSTree T, int key) {
    while (T != NULL && T->key != key)
        T = (key < T->key) ? T->lchild : T->rchild;
    return T;
}

void BSTInsert(BSTree *T, int key) {      /* 插入必在叶位 */
    if (*T == NULL) {
        *T = (BSTNode *)malloc(sizeof(BSTNode));
        (*T)->key = key;
        (*T)->lchild = (*T)->rchild = NULL;
    } else if (key < (*T)->key) BSTInsert(&(*T)->lchild, key);
    else if (key > (*T)->key) BSTInsert(&(*T)->rchild, key);
    /* 相等：不插入（或按计数处理） */
}
```

> **【规律】** 三个必考：①查找路径 = 比较序列，**同一关键字的查找长度由其层数决定**，等概率下 ASL 就是「每结点层数和 / n」；②插入序列不同 → 树形不同，但**中序序列恒递增**；③含 n 个结点的 BST 形态数 = 卡特兰数（第 2 章 2-1 的老朋友）。

**前置与延伸**：
- 前置：第 4 章 4-5（遍历）、4-6（重构）
- 延伸：AVL（下一节）治它的退化病

### 6-4　平衡二叉树 AVL　【P0】

**是什么**：任意结点左右子树**高度差的绝对值 ≤ 1** 的 BST。结点带平衡因子 bf = 左高 − 右高 ∈ {−1, 0, 1}。插入 / 删除后旋转恢复，保证 ASL 稳定 O(log n)。

**为什么**：BST 顺序插入会退化成单斜树（ASL 变 O(n)）；AVL 用旋转把高度钉死在 O(log n)——「每代解决上一代一个痛点」的第一课。

**怎么用（四种失衡判读）**：

| 类型 | 插入位置（相对失衡结点 A） | 旋转动作 |
|------|--------------------------|---------|
| LL | A 左孩子的左子树 | **右单旋**（A 右下，B 上提） |
| RR | A 右孩子的右子树 | **左单旋** |
| LR | A 左孩子的右子树 | **先对 B 左旋、再对 A 右旋**（双旋） |
| RL | A 右孩子的左子树 | 先对 B 右旋、再对 A 左旋 |

```text
LL 右旋示意：            B                A
                      A   …    →      C     B
                    C                        …
```

**插入操作流程**：①按 BST 规则插入（叶位）；②从插入点**向根回溯**，更新平衡因子；③发现 |bf| = 2 的**最小不平衡子树**根 A；④判类型（看插入点在 A 的哪一侧孩子的哪一侧）；⑤旋转后子树高度**恢复到插入前**，向上无需再调（插入至多一旋）。

**删除流程**：①按 BST 删除；②从被删处回溯找失衡；③旋转后子树高度**可能变矮**，需继续向上检查（删除可连锁旋转至根）。

```c
/* 右旋（LL 型）：以 A 为轴 */
BSTNode* rotateRight(BSTNode *A) {
    BSTNode *B = A->lchild;
    A->lchild = B->rchild;               /* B 的右子树过继给 A */
    B->rchild = A;
    return B;                            /* B 成为子树新根 */
}
/* 左旋（RR 型）对称。LR/RL = 两次单旋组合。 */
```

> **【规律】** 手算题套路：给插入序列逐个插入 → 画出每次失衡与旋转后的形态；**旋转后中序序列不变**（BST 性质保持），这是检验旋转对错的最快手段。

> **【注意】** n 层 AVL 最少结点数递推：N(h) = N(h−1) + N(h−2) + 1（N(0)=0, N(1)=1, N(2)=2…）。「深度为 k 的 AVL 至少含多少结点」必背递推；反过来「n 个结点的 AVL 最大高度」就是解这个递推。

**前置与延伸**：
- 前置：知识点 6-3
- 延伸：红黑树（6-5）放宽平衡换更低维护成本

### 6-5　红黑树（概念与性质）　【P1】

**是什么**：每结点带红 / 黑色的 BST，满足五条性质：①结点红或黑；②根黑；③叶（NIL 空叶）黑；④**红结点的孩子必黑**（无红红）；⑤任一结点到其所有 NIL 叶的路径含**相同数目的黑结点**（黑路同，黑高 bh）。

**为什么**：AVL 维护「严格平衡」的旋转代价高；红黑树只保证**最长路径 ≤ 2 × 最短路径**（由黑高性质推出 h ≤ 2·log₂(n+1)），近似平衡但插入删除的旋转次数摊还 O(1)——工程容器（map / set）的标准实现。

**怎么用（辨析为主）**：
- 等价理解：红黑树 = 2-3-4 树（4 阶 B 树）的二叉化——红结点与其黑双亲合并成一个 3/4 结点。
- 高度上界：bh ≥ h/2 且 bh ≥ log₂(n+1)/2 → **h ≤ 2log₂(n+1)**。
- 插入：新结点**先染红**（不破坏黑路同），冲突（父红）才调整：叔叔红则**染色上推**，叔叔黑则**旋转 + 换色**（至多 2 次旋转 + O(log n) 次变色）。
- 删除：可能产生「双黑」，按兄弟与侄子颜色分四种情况，可能上推（与 B 树删除的借 / 合并同构——它们本来就是同一棵 2-3-4 树）。
- **AVL vs 红黑**：AVL 更严格平衡（查询略快）、红黑调整更省（增删多的动态场景更快）。

> **【规律】** 「黑路同」能推一切：任一路径黑结点数 ≥ bh；无红红 → 红黑相间至多使路径翻倍 → h ≤ 2bh。选择题给「某红黑树高度 h 的范围」即由此推。

**前置与延伸**：
- 前置：知识点 6-3、6-4（旋转复用 AVL 的左旋右旋）
- 延伸：竞赛 C++ 模块 C 的 `map` / `set` 底层即红黑树

### 6-6　B 树与 B+ 树　【P0】

**是什么**：m 阶 B 树：平衡的多路搜索树，所有失败结点（叶）同层。**B+ 树**：n 棵子树的结点含 n 个关键字；**关键字全部出现在叶层**且叶层按序链接成有序链表；非叶结点只作索引。

**为什么**：BST 系在**磁盘**上失效——树高 log₂n 意味着 n = 10⁸ 时 27 次磁盘 I/O。B 树把结点做大（一个结点 = 一页 = 一次 I/O），树高压到 3 至 5 层；B+ 树进一步让**非叶不存数据**（一页放更多索引），且叶链支持**范围查询**——数据库索引的标准答案。

**怎么用（B 树手算要点）**：

| 操作 | 规则 | 记忆 |
|------|------|------|
| 插入 | 总插在**终端结点**；超出 m−1 个关键字则**从中间 key 分裂**，中 key 上移父结点 | 「插叶、分裂上移」 |
| 删除（终端） | 直接删；低于 ⌈m/2⌉−1 则**向够的兄弟借**，兄弟不够则**与兄弟 + 父中 key 合并** | 「删叶、借或并」 |
| 删除（非终端） | 用直接前驱 / 后继替换后化归为终端删除 | 「先换到叶子再删」 |
| 树高变化 | 分裂向上传播 → 树从**根**长高；合并向上传播 → 树从**根**变矮 | 失败结点恒同层 |

**手算示例（3 阶 B 树，⌈3/2⌉ = 2 棵子树下限）**：依次插入 1 至 5。插入 3 后某结点含 {1,2,3} 超 2 个 → 中 key 2 上移分裂为 {1} 与 {3} 两结点、父 {2}。继续插入 4、5 → 右结点 {3,4,5} 超 → 4 上移，父变 {2,4}，树高三层。

> **【规律】** 高度分析：n 个关键字的 m 阶 B 树高度 h 满足 log_m(n+1) ≤ h ≤ log_⌈m/2⌉((n+1)/2) + 1——选择题给 n、m 求高度范围。**B+ 树 vs B 树三差异**：①B+ 非叶只索引、关键字全在叶；②B+ 叶层链表支持范围查；③B+ 查找稳定到叶层（B 树可能在中间命中）。n 个关键字的 B+ 树每个非叶结点至多 m 棵子树 m 个关键字（注意与 B 树的 m−1 差一）。

**前置与延伸**：
- 前置：知识点 6-3（搜索树思想）、第 4 章 4-3（多路即 m 叉）
- 延伸：数据库索引（MySQL InnoDB）、LSM 树（工程延伸）

### 6-7　散列表（哈希）　【P0】

**是什么**：用散列函数 H(key) 把关键字直接映射到存储地址，理想 O(1)；冲突（不同 key 同地址）不可避免（鸽巢原理），两大处理路线：**链地址法**与**开放定址法**（线性探测 d = 0,1,2…；平方探测 d = 0,1,−1,4,−4…；双散列）。装填因子 α = 表中元素数 / 表长，**ASL 与 α 直接挂钩而与表长无关**。

**为什么**：以空间换时间走到极致——不比较、直接算地址；冲突处理的品质决定实际性能，α 是唯一的旋钮。

**怎么用（手算模板）**：H(key) = key % p（p 取**不大于表长的最大素数**）。线性探测：冲突则 (H + 1) % m、(H + 2) % m…逐个试。成功 ASL：每个元素按**实际探测次数**求平均；失败 ASL：从每个可能散列地址出发，走到**第一个空位**的比较次数求平均（分母 m 或 p，按题目口径）。

**完整手算示例**：表长 11，H(k) = k % 11，依次插入 22, 41, 53, 46, 30, 13, 1, 67：
22→0；41→8；53→9；46→(46%11=2) 空，入 2；30→(8) 冲突→9 冲突→10 入；13→2 冲突→3 入；1→1 入；67→(1) 冲突→2 冲突→3 冲突→4 入。
成功比较次数：22:1, 41:1, 53:1, 46:1, 30:3, 13:2, 1:1, 67:4 → ASL成功 = 14/8 = **1.75**。
失败（分母 11）：各起点走到最近空位的步数按表算（空位在 5,6,7 及其他），逐地址数后求平均。

> **【规律】** 四个必考：①**删除必须懒删**（开放定址法）；②线性探测有**堆积（聚集）**，平方探测缓解但不能探测所有位置（表长为 4k+3 的素数时可以），双散列无堆积；③链地址法删可物理删、α 可 > 1；④成功 ASL 分母是**元素数**、失败 ASL 分母是**散列地址数**（常见口径），混用即错。

> **【类比】** 散列表 = 按拼音首字母分格的字典架：函数告诉你去哪格，同格太挤就往后挪（开放定址）或同格挂串（链地址）。

**前置与延伸**：
- 前置：知识点 6-1（ASL 口径）；素数（阶段 1 筛法，选 p）
- 延伸：竞赛侧 `unordered_map`（哈希版映射）、字符串哈希（阶段 6）

## 典型例题

### 例题 6-1　（判定树手算 · 选择题风格）
**题干**：对含 11 个元素的有序表折半查找，画出判定树，求成功与失败 ASL。

**解题思路**：按 mid 向下取整逐层定根（见 6-2 的构造过程），层数即比较次数。

**解答过程**：
判定树：根 6；第二层 3、9；第三层 1、5、7、11；第四层 2、4、8、10（依次挂 1、5、7、11 的单侧）。
成功：层数分布 1(1 个)、2(2 个)、3(4 个)、4(4 个) → ASL = (1+4+12+16)/11 = **33/11 = 3**。
失败：12 个失败结点 = 第三层结点（1、5、7、11）各缺的孩子（4 个，挂在第 4 层）+ 第四层结点（2、4、8、10）各缺的 2 个孩子（8 个，挂在第 5 层）→ ASL失败 = (4×4 + 8×5)/12 = 56/12 = **14/3 ≈ 4.67**。

**复杂度分析**：O(log n) 级；构造判定树 O(n)。

### 例题 6-2　（AVL 手算 · 综合题风格）
**题干**：空 AVL 依次插入 50, 30, 70, 20, 40, 35，画出每步失衡与旋转后的树，说明各属哪种类型。

**解题思路**：每插一个检查平衡，从插入点向上找最小不平衡子树，按类型表旋转。

**解答过程**：
1. 插 50、30、70：平衡（50 的两孩 30、70）。
2. 插 20：结点 30 的 bf = 1、结点 50 的 bf = 1（左高 2、右高 1），均未失衡。树 {50(30(20,),70)}。
3. 插 40：40 挂在 30 的右侧。50 的 bf = 2（左高 3、右高 1）→ 失衡。插入点 40 在 50 的**左孩子的右子树** → **LR 型**。先对 30 左旋（40 上提：30(20,) 挂到 40 左），再对 50 右旋：新根 40，左孩 30(20)，右孩 50(,70)。
4. 各 bf 归位，树高 3。类型：**LR 双旋一次完成**（插入至多一旋）。

**复杂度分析**：单次插入 O(log n)（含回溯）。

### 例题 6-3　（B 树手算 · 综合题风格）
**题干**：3 阶 B 树（空）依次插入 1, 2, 3, 4, 5, 6，画出每次分裂后的形态；再删除 1，说明处理路径。

**解题思路**：插入全在终端结点，超 ⌈3⌉−1 = 2 个关键字即取中上移分裂；删除终端结点后不足 ⌈3/2⌉−1 = 1 个关键字才需借 / 并。

**解答过程**：
插入 1、2：根 {1,2}（3 阶每结点至多 2 个关键字）。
插入 3：{1,2,3} 超 → 中 key 2 上移为新根，得根 {2}，孩子 {1}、{3}。
插入 4：进 {3} → {3,4}。插入 5：{3,4,5} 超 → 4 上移，根 {2,4}，孩子 {1}、{3}、{5}。
插入 6：进 {5} → {5,6}。终态：根 {2,4}，三终端结点 {1}、{3}、{5,6}。
删除 1：{1} 变空，低于下限 1 → 兄弟 {3} 也只有 1 个（不可借）→ 与兄弟及父中 key 2 **合并**：父 {2,4} 中拿 2 与 {1}{3} 并成 {1,2,3}，父剩 {4}，孩子 {1,2,3}、{5,6}。树仍两层，合法。

**复杂度分析**：B 树插入删除 O(log_m n) 次 I/O 级操作。

### 例题 6-4　（散列手算 · 综合题风格）
**题干**：表长 7，H(k) = k % 7，线性探测。依次插入 14, 36, 42, 38, 40。求成功 ASL；再在删除 36 后说明为什么必须懒删。

**解题思路**：逐元素算散列址与探测路径；删除题答「探测链截断」。

**解答过程**：
14→0；36→1；42→0 冲突→1 冲突→2；38→3；40→5（40%7=5，空）。
成功比较：14:1, 36:1, 42:3, 38:1, 40:1 → ASL = 7/5 = **1.4**。
删 36：若物理删除，地址 1 变空。之后查找 42：H = 0 占用 → 探测 1 是**空** → 判「不存在」——但 42 在地址 2，**查丢**。故必须留删除标记，探测链继续走通。

**复杂度分析**：插查均摊 O(1)（α 适中时）；最坏 O(n)（全堆积）。

## 本章总结

### 核心内容（一页纸）

- **ASL = Σpᵢcᵢ 是唯一标尺**；成功与失败**分开算**，失败看空位 / 外部结点。
- 顺序 O(n)；**折半 O(log n) 只配有序顺序表**，判定树是平衡形态、高 ⌈log₂(n+1)⌉，mid 向下取整「左肥右瘦」；**分块 = 索引定块 + 块内顺序**，s = √n 最优。
- **BST**：中序递增；删除双孩用前驱 / 后继替换；最坏退化 O(n)。
- **AVL**：bf ∈ {−1,0,1}；**LL 右旋、RR 左旋、LR/RL 双旋**；插入至多一旋、删除可连锁；最少结点 N(h) = N(h−1) + N(h−2) + 1。
- **红黑树**：左根右、不红红、黑路同；h ≤ 2log₂(n+1)；插入先染红、至多 2 旋；等价 2-3-4 树。
- **B 树**：m 阶五条定义；插叶分裂上移、删叶借或并；失败结点同层、树高只从根变；**B+ 树**关键字全在叶、叶链支持范围查、查找稳定到叶。
- **散列**：α 是唯一旋钮；链地址可物理删可 α>1；开放定址**懒删**、线性探测有堆积；成功 ASL 分母 = 元素数、失败 ASL 分母 = 地址数。
