## 第七章：二叉搜索树与平衡树

> 课件来源：`二叉搜索树和平衡树.pdf`、`二叉排序树代码\二叉排序树代码.c`、`平衡二叉树代码\平衡二叉树代码.c`
>
> 本章主线：BST 用"左小右大"约束换来查找加速 → 但有序输入会退化成链表 → AVL 用平衡因子 + 四种旋转把高度锁死在 O(logn)。

## 🗺️ 本章地图

本章回答一个问题：怎样让查找既快又稳。路线：先给二叉树加"左小右大"约束得到 BST（知识点1）→ 查找、插入、删除共享同一条从根向下的路径（2-4）→ 但有序输入会把 BST 拉成链表，于是再加"高度差 ≤1"约束得到 AVL（5）→ 约束被破坏就用四种旋转修复（6）→ 把"查失衡、转一转"嵌进插入与删除的回溯过程（7）。这个顺序是"先立规矩、再看规矩的代价、最后学执法手段"——每一步都是为了补上一步暴露的漏洞。

## 📌 本章重点（3-5个）

⭐ **BST 定义三约束**：左子树所有结点 < 根 < 右子树所有结点，左右子树又各是 BST；**中序遍历即升序序列**
⭐ **BST 查找与插入**：查找最坏时间 = 树的深度；插入的新节点总在**叶节点位置**，递归写法"子问题返回新节点，上一状态用左/右子树接收"
⭐ **BST 删除三种情况**：叶子直接删；度为 1 由孩子顶替；度为 2 用**中序前驱/后继替换**后再删（转化为删叶子）
⭐ **平衡因子 BF**：左子树高度 − 右子树高度，AVL 中任意结点 BF 只能取 0、1、−1
⭐ **四种失衡 LL/RR/LR/RL**：LL 右旋、RR 左旋、LR 先左旋左孩子再右旋、RL 先右旋右孩子再左旋

## 🔥 本章难点（2-3个）

🔥 **度为 2 结点的删除转化**：找中序前驱（左子树最右）/后继（右子树最左）复制值覆盖，问题转化为删除该前驱/后继（必为叶子或度 1），"假删除"思想
🔥 **左旋/右旋的指针操作**：三步换爹 + 两次更新高度，谁当新根、原根去哪边、中间子树归谁，画图才不出错
🔥 **AVL 删除后的旋转类型判断**：与插入不同，删除靠**比较孩子两侧子树的高度**（如 `Geth(right->r) >= Geth(right->l)` 则 RR）选旋转，且删除后要逐层回查平衡

## ⚠️ 本章易错点（3-5个）

⚠️ **中序序列方向记反**：BST 的中序遍历是**从小到大**的升序序列（验证一棵树是否为 BST 的钥匙），不是先序
⚠️ **左旋右旋方向搞混**：失衡是因为**右边高 → 左旋**；左边高 → 右旋，别记反
⚠️ **LR/RL 两步顺序写错**：先转孩子再转失衡结点——LR 先对**左孩子左旋**，再对失衡点右旋；RL 先对**右孩子右旋**，再对失衡点左旋
⚠️ **旋转/删除后忘记更新高度 h**：旋转涉及 x、y 两个结点，删除回溯中每个结点都要 `h = max(左,右)+1`
⚠️ **删根结点特判遗漏**：被删结点是根时，删除后 root 要变成其孩子（pre==NULL 时 root=ch）

## 📖 知识点讲解

### 1. 二叉搜索树的定义与性质

**是什么**：先一句话点破：BST 是把"二分查找"种进树里——每个结点都是一个分流闸口，比它小的一律往左、比它大的一律往右，每过一关就排除掉一整棵子树。严格定义：二叉搜索树（Binary Search Tree），也称为**二叉排序树、二叉查找树**。在二叉树基础上增加三条规则约束：①左子树不空，则左子树上**所有**结点的值均**小于**根结点的值；②右子树不空，则右子树上所有结点的值均**大于**根结点的值；③左、右子树又各自是二叉排序树。

**为什么**：这三条约束把"有序性"编码进了树的结构——任取一个结点，它的左子树整体比它小、右子树整体比它大，于是每一次比较都能安全地排除掉一整棵子树，查找如同走一条从根向下的路径。

**怎么用**（课件示例：序列 8 3 10 1 6 14 4 7 13 依次插入建树）：
```text
        8
      /   \
     3     10
    / \      \
   1   6      14
      / \    /
     4   7  13
```
对它做中序遍历：1 3 4 6 7 8 10 13 14——**从小到大排好序的序列**。

跟着算——把 5 3 8 1 4 依次插入空 BST，一步一步看它长出来：
第1步：插 5，树是空的 → 5 当根。
第2步：插 3，3 < 5 走左 → 左空位，挂上。
第3步：插 8，8 > 5 走右 → 右空位，挂上。
第4步：插 1，1 < 5 走左到 3，1 < 3 走左 → 3 的左孩子。
第5步：插 4，4 < 5 走左到 3，4 > 3 走右 → 3 的右孩子。
```text
      5
     / \
    3   8
   / \
  1   4
```
第6步：验证——中序遍历得 1 3 4 5 8，恰好从小到大 ✓。

> ⚠️ 注意事项："左子树上所有结点"是整体约束，不是只跟直接左孩子比；中序有序是判断/验证 BST 的标准手段。
> 🎯 规律：判断/验证 BST 只需一招——中序遍历看是否严格升序。
> 💡 一句话总结：左小右大，中序升序。

### 2. BST 的查找：递归与非递归

**是什么**：先一句话点破：BST 查找就是"问路"——每个结点只回答一句"小了往左、大了往右"，问一个走一步，绝不回头。具体规则：找 key 时，T 为空则查找失败返回 NULL；key==T->data 成功返回 T；key<T->data 递归查左子树；否则递归查右子树。查找逻辑可以写成**递归和非递归**两种思路。

**为什么**：二叉排序树的**中序遍历**就是一个从小到大排好序的序列，但查找时完全没有必要先中序遍历生成有序数组、再二分查找——直接根据树的约束操作即可。查找时间最坏情况就是**树的深度**。

**怎么用**：
```c
// 递归版（课件 SearchBST）
BiTree SearchBST(BiTree T, KeyType key) {
    if (!T || key == T->data)      // 空树(失败) 或 找到
        return T;
    else if (key < T->data)        // 递归遍历其左孩子
        return SearchBST(T->lchild, key);
    else                           // 递归遍历其右孩子
        return SearchBST(T->rchild, key);
}
// 非递归版（二叉排序树代码.c）
BSTNode* Find2(BSTree root, int x) {
    BSTNode* p = root;
    while (p != NULL && p->data != x)
        p = (x < p->data) ? p->l : p->r;
    return p;
}
```

跟着算——在知识点 1 建好的树 5(3(1,4), 8) 里查 4 和查 6：
查 4（成功）：第1步 4 < 5 → 左走到 3；第2步 4 > 3 → 右走到 4；第3步 命中。共比 3 次，恰好等于结点 4 的深度。
查 6（失败）：第1步 6 > 5 → 右走到 8；第2步 6 < 8 → 左，但 8 的左孩子为空 → 走到空指针，判定失败。
```text
查 6 的路径：5 →(6>5,右) 8 →(6<8,左) ∅    一条路走到底，绝不回头
```
两次查找也顺带演示了"比较次数 = 目标深度、最坏 = 树的深度"这句话。

| 对比 | BST 查找 | 先排序+二分查找 |
|------|---------|----------------|
| 前置工作 | 插入时天然维护有序性 | 需要先做一次排序 |
| 查找代价 | 最坏 = 树的深度 | O(logn)，但要连续内存数组 |
| 动态插入删除 | 直接沿路径挂/摘结点 | 数组插删要移动元素 |

> ⚠️ 注意事项：比较只决定方向，不回溯；一条路走到底，失败以走到空指针为标志。
> 🎯 规律：查找是单向路径——成功时比较次数 = 目标结点深度，失败以走到空为标志。
> 💡 一句话总结：一次比较排除一半，深度即代价。

### 3. BST 的插入与最值查找

**是什么**：先一句话点破：插入就是一次"不成功的查找"——按查找规则走到空指针，那个空位正是新结点的家，所以新结点永远落在叶子位置。插入的**新节点都是在叶节点位置**：先寻找插入位置，再建立父亲结点和新结点的左右关系，是一种递归思想——子问题就是返回新节点，上一个状态就是左子树还是右子树来接收。最值查找：比当前节点小的值一定放在左子树上，**一直往左找最左边的节点就是最小值**；反之**一直往右找最右边的节点就是最大值**。

**为什么**：插入路径与查找路径完全一致，走到空指针处就是新结点的家；正因为"左小右大"逐层成立，极值必然位于最左/最右的链端。

**怎么用**：
```c
// 递归插入：返回插入后的新树（子树根）
BSTree Insert1(BSTree root, int x) {
    if (root == NULL) {                 // 递归出口：空位即插入点
        return CreateNode(x);
    }
    if (x < root->data)
        root->l = Insert1(root->l, x);  // 左子树接收新结点
    else
        root->r = Insert1(root->r, x);
    return root;                        // 注意：返回新树
}
// 非递归插入：pre 记录父亲
BSTNode *p = root, *pre = NULL;
while (p != NULL) { pre = p; p = (x < p->data) ? p->l : p->r; }
BSTNode* s = CreateNode(x);
if (x < pre->data) pre->l = s; else pre->r = s;
// 最值
while (t->l != NULL) t = t->l;   // 最小：一路向左
while (t->r != NULL) t = t->r;   // 最大：一路向右
```

跟着算——在树 5(3(1,4), 8) 上再插一个 6，再找一趟最值：
插 6：第1步 6 > 5 → 右走到 8；第2步 6 < 8 → 左，左为空 → 6 落座为 8 的左孩子（叶子）。
找最值：第1步 最小值从根 5 一路向左：5→3→1，1 无左孩子 → 最小是 1。第2步 最大值从根 5 一路向右：5→8，8 无右孩子 → 最大是 8。

> ⚠️ 注意事项：课件代码相等值走右子树（`x<root->data` 走左，否则走右）；递归插入务必把返回值接到 root->l / root->r 上并 `return root`。
> 🎯 规律：插入 = 失败的查找 + 空位落子；极值 = 沿最左/最右链走到底。
> 💡 一句话总结：新结点必是叶子，极值在两端。

### 4. BST 的删除（三种情况）

**是什么**：先一句话点破：删除的麻烦在于"人走了不能让队形乱"——叶子随便拔，度 1 的孩子顶上来，度 2 的没法用一个结点补两个空位，就找个"替身"（中序前驱/后继）来换值，把难题降级成删叶子。删除节点共**三种可能性**：
1. **叶子结点**：移除后不影响其他结点的排列规则，**直接删除**
2. **度为 1 的结点**：去掉该节点后，剩余的子树仍满足 BST 要求——把唯一的孩子**接入其父节点**（原在父左边就接左边，在右边就接右边）即可
3. **度为 2 的结点**：设要删节点 A，它的中序序列里**前一个（前驱）或后一个（后继）节点**恰好满足"左边都比它小、右边都比它大"——用前驱/后继的**值覆盖** A，然后删除那个前驱/后继节点。前驱/后继必是叶子或度 1 结点，问题又回到前两种情况（课件：序列 1234567 中删 4，先"假删除"复制值，真删除的一定是叶子）

**为什么**：直接删除度为 2 的结点会留下两个孩子的"空缺"，无法用一个结点接上；而中序前驱是 A 左子树的最大值、后继是右子树的最小值，顶替 A 后左右两半的大小关系依然成立。

**怎么用**（递归删除，前驱/后继两种都给出）：
```c
// 用中序后继替换（右子树最左结点）
if (root->l != NULL && root->r != NULL) {
    BSTNode* t = root->r;
    while (t->l != NULL) t = t->l;      // 后继
    root->data = t->data;               // 值覆盖
    root->r = Delete2(root->r, t->data);// 转化为删后继
} else {                                // 叶子或度1：孩子顶替
    BSTNode* p = root;
    root = (root->l != NULL) ? root->l : root->r;
    free(p);
}
// 非递归删除中找中序前驱：t = p->l 一路向右，同时记下父亲 tf
```

跟着算——在树 5(3(1,4), 8(7,9)) 上删度 2 的结点 5（前驱替换法）：
```text
删前：                 删后（值覆盖 + 删叶）：
        5                      4
       / \                    / \
      3   8                  3   8
     / \ / \                /   / \
    1  4 7  9              1   7   9
```
第1步：找中序前驱——5 的左子树最靠右结点：从 3 向右走到 4，4 无右孩子 → 前驱是 4。
第2步：值覆盖——把根的值改成 4（结点结构没动，只换了值）。
第3步：转化——删除"原前驱结点 4"，它是叶子，直接删。
第4步：验证——中序 1 3 4 7 8 9 仍升序 ✓。若用后继替换：后继 = 右子树最靠左 = 7，覆盖后删叶子 7，中序同样得到 1 3 4 7 8 9。

| 被删结点 | 处理方式 | 后续动作 |
|---------|---------|---------|
| 叶子 | 直接删除 | 无 |
| 度为 1 | 唯一孩子接到父亲 | 判断接左还是接右 |
| 度为 2 | 前驱（或后继）值覆盖 | 转化为删除叶子/度1结点 |

> ⚠️ 注意事项：删根结点时 pre==NULL，root 要改指向孩子；找到的"替身"可能有右孩子（找前驱时），不能想当然认为一定是叶子。
> 🎯 规律：删度 2 结点 = 换值不换结点——借中序前驱/后继当替身，把删除降级成删叶子。
> 💡 一句话总结：删二度找替身，前驱后继皆可。

### 5. BST 的退化问题与 AVL 的定义

**是什么**：先一句话点破：BST 的速度全押在"树长得匀不匀"上；AVL（自平衡——增删时自动"转一转"保持矮胖的 BST）的使命就是用"高度差 ≤1"这条纪律按住树，不让它长成面条。**AVL 树是最早被发明的自平衡二叉查找树**，任一结点对应的两棵子树的高度差绝对值不超过 1，也称**高度平衡树**，以发明者 G.M. Adelson-Velsky 和 E.M. Landis 命名。**平衡因子（BF, Balance Factor）= 左子树与右子树的高度差**（BF>0 左边高、BF<0 右边高，"失衡"即某结点 |BF|>1）；平衡二叉树中不存在平衡因子绝对值大于 1 的节点，BF 只可取 **0、1、−1**，分别对应左右子树等高、左子树较高、右子树较高。

**为什么**：BST 的查找效率取决于**树的高度**，保持树的高度最小即可保证查找效率。但 BST 会退化成单链表：原序列有序时（如 A = {1,2,3,4,5,6}），构造出的 BST 是右斜树（单链表），搜索效率降为 **O(n)**。AVL 保证查找、插入和删除在平均和最坏情况下都是 **O(logn)**，代价是增删时可能需要一次或多次**树旋转**（在保持有序的前提下局部更换子树根）重新平衡。

**怎么用**（同一个序列的两种命运）：
```text
输入 {8,3,10,1,6,14,...} → BST 高度 ~4，查找约 O(logn)
输入 {1,2,3,4,5,6}       → BST 退化右斜链，查找 6 要比 6 次 O(n)
AVL：插入过程中一旦某结点 |BF|>1 立即旋转 → 高度恒 O(logn)
```

跟着算——看 1 2 3 4 怎么一步步把 BST 拉成链（顺便算 BF）：
第1步：插 1 → 根，BF = 0（左右皆空）。
第2步：插 2，2 > 1 → 右孩子；1 的 BF = 0 − 1 = −1，仍在 {−1, 0, 1} 内。
第3步：插 3，3 > 1 → 2 → 右孩子；此时 1 的 BF = 0 − 2 = −2，越界失衡——但普通 BST 不管它。
第4步：插 4，继续向右长。
```text
1
 \
  2
   \
    3          每层只有右孩子 = 退化成链表
     \
      4
```
照这个长法，n 个有序数查找要 n 次；而平衡树只需约 log2n 次（10 万个数约 17 次）——这就是 AVL 存在的理由。

| 对比 | BST | AVL 树 |
|------|-----|--------|
| 高度 | 最坏退化为 n（单链表） | 恒为 O(logn) |
| 约束 | 仅左小右大 | 再加 |BF| ≤ 1 |
| 查找效率 | 平均 O(logn)，最坏 O(n) | 平均、最坏均 O(logn) |
| 插入/删除代价 | 直接挂/摘 | 可能伴随一次或多次旋转 |
| 适用场景 | 输入随机、改动少 | 查找密集、要防退化 |

> ⚠️ 注意事项：BF 是"左减右"，正表示左边高；课件判断失衡用"高度差绝对值为 1"表述，代码里写成 `Geth(l)-Geth(r) > 1`（左失衡）与 `Geth(r)-Geth(l) > 1`（右失衡）。
> 🎯 规律：有序输入是 BST 的天敌——约束高度，就是约束最坏情况。
> 💡 一句话总结：斜了就转，高度锁 logn。

### 6. 四种失衡与旋转：LL / RR / LR / RL

**是什么**：先一句话点破：旋转就是"局部换班"——高那一侧的孩子升职当新根，原根降级当副手，中间子树跟着换个爹；大小次序分毫不动，所以 BST 性质毫发无损。四种失衡（失衡 = 某结点 |BF|>1）与对策：
- **左旋**：加入新节点后**右边的高度增加**导致失衡。x 的右孩子 y 上提为新根，x 变 y 的左孩子，y 原左子树 ly 给 x 当右子树
- **右旋**：对称操作。y 的左孩子 x 上提为新根，y 变 x 的右孩子，x 原右子树 rx 给 y 当左子树
- **LL**：失衡节点左边高，新插入节点在失衡节点**左孩子的左边** → 直接对失衡节点**右旋**
- **RR**：失衡节点右边高，新插入节点在失衡节点**右孩子的右边** → 直接对失衡节点**左旋**
- **LR**：失衡节点左边高，新插入节点在失衡节点**左孩子的右边** → 先对左孩子**左旋**（转成 LL），再对失衡节点**右旋**
- **RL**：失衡节点右边高，新插入节点在失衡节点**右孩子的左边** → 先对右孩子**右旋**（转成 RR），再对失衡节点**左旋**

**为什么**：旋转的本质是"换根保序"——把高度多出来的一侧子树提上去当新根，原根降级，中间子树换爹但整体仍满足 BST 大小关系，既恢复平衡又不动摇有序性。LR/RL 一次旋不平，必须先局部转成 LL/RR 再整体转。

**怎么用**（课件图示 + 代码实现）：
```text
左旋前：  x               左旋后：  y
         / \                      / \
        lx  y                    x   ry
           / \                  / \
          ly ry                lx  ly

右旋前：  y               右旋后：  x
         / \                      / \
        x   ry                   lx  y
       / \                          / \
      lx rx                        rx  ry
```
```c
// LL → 对 x 右旋（平衡二叉树代码.c）
AVLTree LLrotation(AVLTree x) {
    AVLNode* y = x->l;        // y 指向 x 的左孩子
    x->l = y->r;              // y 的右孩子变成 x 的左孩子
    y->r = x;                 // x 变成 y 的右孩子
    x->h = Maxx(Geth(x->l), Geth(x->r)) + 1;  // 高度可能变化，先更 x 后更 y
    y->h = Maxx(Geth(y->l), Geth(y->r)) + 1;
    return y;                 // y 是新根
}
// RR → 对 x 左旋（对称）；LR：x->l=RRrotation(x->l); return LLrotation(x);
// RL：x->r=LLrotation(x->r); return RRrotation(x);
```

跟着算——拿两棵三结点失衡树把 RR 和 LR 各走一遍：
RR 型（依次插 1、2、3）：
```text
失衡：  1 BF=−2       对 1 左旋：    2 BF=0
         \                          / \
          2 BF=−1                  1   3
           \
            3
```
第1步：判型——新结点 3 插在失衡结点 1 的右孩子 2 的右边 → RR。
第2步：左旋——2 升为新根，1 降为 2 的左孩子，2 原左子树（空）给 1 当右子树。
第3步：更新高度——先算降级者 1，再算升级者 2。
LR 型（依次插 3、1、2）：
```text
失衡：    3 BF=+2     先对左孩子 1 左旋：  3 BF=+2    再对 3 右旋：   2 BF=0
         /                               /                         /    \
        1 BF=−1                         2                         1     3
         \                             /
          2                           1
```
第1步：判型——2 插在失衡结点 3 的左孩子 1 的右边 → LR。
第2步：先对 1 左旋——折线 3-1-2 拉直成 3-2-1，变成 LL 的形状。
第3步：再对 3 右旋——2 升为新根，1、3 分别为左右孩子。
第4步：验证——两种旋转后中序都是 1 2 3，旋转从不破坏有序性。

| 类型 | 失衡侧 | 插入位置 | 旋转动作 |
|------|--------|---------|---------|
| LL | 左边高 | 左孩子的左边 | 对失衡点**右旋** ×1 |
| RR | 右边高 | 右孩子的右边 | 对失衡点**左旋** ×1 |
| LR | 左边高 | 左孩子的右边 | 左孩子**左旋** → 失衡点**右旋** |
| RL | 右边高 | 右孩子的左边 | 右孩子**右旋** → 失衡点**左旋** |

> ⚠️ 注意事项：旋转后 x、y 的高度都要重算，顺序先 x（降级者）后 y（升级者）；LR/RL 是两次旋转、别只转一次。
> 🎯 规律：旋转前后中序序列不变——"换根保序"；同侧一旋到位，拐弯先整孩子。
> 💡 一句话总结：单旋对角治，双旋先整孩子。

### 7. AVL 的插入与删除

**是什么**：先一句话点破：AVL 的插删 = BST 的插删 + 回溯查岗——插完沿着原路一层层退回去（回溯），每退一层量一次 BF，谁失衡谁转，转完还得继续往上查，因为一次旋转可能让爷爷辈失衡。具体思路：
- **插入**算法思路：①先找到要插入的节点位置，插入新节点（与 BST 相同）；②**更新平衡因子**，根据平衡因子小于 −1 和大于 1 的情况进行讨论——回溯途中某结点左高差超 1 就按 LL/LR 调整，右高差超 1 就按 RR/RL 调整
- **删除**算法思路：①依据 BST 的删除特点，仍按三种条件删除，**保证最后删除的都是叶子节点**；②节点删除后，**依次对结点进行平衡因子检查**，若发现某节点不平衡，按平衡调节节点进行调节

**为什么**：插入/删除只影响一条路径上的高度，所以只需在回溯路上逐结点检查失衡并旋转；删除可能"转完还不平"或上层连环失衡，所以删除时的旋转类型要**重新按孩子高度判断**，不能照搬插入时的判断。

**怎么用**（插入判型看插入值，删除判型看孩子高度，课件代码要点）：
```c
// 插入：a 进入左子树后检查 root
root->l = Insert(root->l, a);
if (Geth(root->l) - Geth(root->r) > 1) {   // 左边高出1以上：LL 或 LR
    if (a < root->l->data) root = LLrotation(root);   // a 在左孩子的左边
    else                   root = LRrotation(root);   // a 在左孩子的右边
}
root->h = Maxx(Geth(root->l), Geth(root->r)) + 1;     // 记得更新高度

// 删除：左子树删完结点后，右侧可能过高，判型看高度而非被删值
if (Geth(root->r) - Geth(root->l) > 1) {
    AVLNode* right = root->r;
    if (Geth(right->r) >= Geth(right->l)) root = RRrotation(root);  // RR
    else                                  root = RLrotation(root);  // RL
}
if (root != NULL)
    root->h = Maxx(Geth(root->l), Geth(root->r)) + 1;    // 删除后也要更新
```

跟着算——把 3 2 1 4 5 依次插入 AVL：
第1步：插 3 → 根；插 2 → 左孩子；插 1 → 3 的 BF = +2，LL 型 → 右旋，2 当新根：2(1, 3)。
第2步：插 4：4 > 2 走右到 3，4 > 3 → 3 的右孩子。树为 2(1, 3(-, 4))，各结点 BF 都在 {−1, 0, 1} 内，不转。
第3步：插 5：5 > 2 → 3 → 4，挂为 4 的右孩子；回溯时 3 的 BF = 0 − 2 = −2 → RR 型 → 对 3 左旋，4 上提。
第4步：结果 2(1, 4(3, 5))，BF 依次为 2:−1、其余 0，全树恢复平衡。
删除判型再走一小步——设删除后某结点 x 左子树为空、右子树两层满：
```text
    x BF=−2      第1步：发现失衡；此时没有"新插入值"可比。
     \           第2步：看 right = x->r：Geth(right->r)=1 ≥ Geth(right->l)=0 → RR 型。
      y          第3步：对 x 左旋；若 right 是"左重"（Geth(right->l) 更大）→ RL 型。
       \
        z
```
一句话对比：插入判型看"新值插在哪一侧"，删除判型看"孩子的哪一侧更重"。

> ⚠️ 注意事项：删除后 root 可能为 NULL（删的是叶子），更新高度前要判空；度为 2 的删除同样走"前驱替换"再递归删前驱，删完立即检查本结点平衡。
> 🎯 规律：插删只动一条路径，查岗也在回溯路径上做——判型口诀：插入看新值，删除比孩子高。
> 💡 一句话总结：插入回溯查，删除逐层平。

### 🧩 本章归纳：一条主线串全章

**一条主线**：BST 用"左小右大"把二分查找搬进树里，查找/插入/删除共享同一条从根向下的路径 → 效率取决于树高 → 有序输入把树拉成链表，最坏 O(n) → AVL 加"每结点 |BF|≤1"约束，把高度锁死在 O(logn) → 插入/删除必然可能打破约束 → 用四种旋转在回溯途中即时修复。

**回头看才看得见的联系**：
1. **平衡树 = BST 约束 + 平衡约束 + 修复动作**：所有自平衡结构（AVL、红黑树、B 树）都是"加约束、破则修"这一个模式的不同实现，区别只在约束的松紧和修复的代价。
2. **中序有序是全章的检验器**：BST 靠中序升序定义"序"；删除度 2 结点选前驱/后继，本质是取中序序列里的左右邻居；旋转后用中序验证有序性未破——一个中序遍历，处处当裁判。
3. **一次操作只动一条路径**：查找、插入、删除都沿单条路径进行，所以维护（更新高度、查失衡、旋转）也只需在回溯路径上逐结点做——这正是 O(logn) 得以成立的根源。

## 🔍 相似概念辨析

### 组1：BST vs AVL

| 对比维度 | BST（二叉搜索树） | AVL（平衡二叉树） |
|----------|------------------|-------------------|
| 各自定义 | 左子树<根<右子树、递归定义的二叉树 | 任一结点左右子树高度差绝对值 ≤1 的 BST |
| 核心区别 | 只保证"序"，不保证"平衡" | 在 BST 上增加平衡约束 |
| 各自特点 | 有序输入退化为单链表 O(n) | 增删可能触发旋转，高度恒 O(logn) |
| 使用场景 | 输入随机、实现简单 | 查找密集、需稳定最坏性能 |
| 典型示例 | {1,2,3,4,5,6} 建成右斜链 | 插入后 |BF|>1 立即旋转调整 |
| 记忆口诀 | BST 管序不管平，AVL 又序又平 |

### 组2：左旋 vs 右旋

| 对比维度 | 左旋 | 右旋 |
|----------|------|------|
| 各自定义 | 右孩子上提为新根、原根降为左孩子 | 左孩子上提为新根、原根降为右孩子 |
| 核心区别 | 治"右边过高" | 治"左边过高" |
| 各自特点 | `y=x->r; x->r=y->l; y->l=x` | `y=x->l; x->l=y->r; y->r=x` |
| 使用场景 | RR 失衡、RL 的第二步 | LL 失衡、LR 的第二步 |
| 典型示例 | `RRrotation(x)` 返回 y 新根 | `LLrotation(x)` 返回 y 新根 |
| 记忆口诀 | 右重左旋，左重右旋 |

### 组3：LL/RR（单旋） vs LR/RL（双旋）

| 对比维度 | LL / RR | LR / RL |
|----------|---------|---------|
| 各自定义 | 新结点插在失衡点左孩子的左边 / 右孩子的右边 | 新结点插在失衡点左孩子的右边 / 右孩子的左边 |
| 核心区别 | 与失衡方向同侧，一次旋转到位 | 与失衡方向反侧（拐了弯），需两次旋转 |
| 各自特点 | 直接对失衡点右旋 / 左旋 | 先把孩子旋成同侧（LL/RR），再旋失衡点 |
| 使用场景 | 直线型失衡 | 折线型失衡 |
| 典型示例 | `LLrotation(x)` | `LR: x->l=RRrotation(x->l); LLrotation(x)` |
| 记忆口诀 | 同侧一旋，拐弯两旋 |

### 组4：中序前驱替换 vs 中序后继替换

| 对比维度 | 中序前驱替换 | 中序后继替换 |
|----------|-------------|-------------|
| 各自定义 | 用中序序列中前一个结点的值覆盖待删结点 | 用中序序列中后一个结点的值覆盖待删结点 |
| 核心区别 | 前驱 = 左子树**最靠右**结点 | 后继 = 右子树**最靠左**结点 |
| 各自特点 | `t=p->l; while(t->r) t=t->r;` | `t=root->r; while(t->l) t=t->l;` |
| 使用场景 | 删除度为 2 结点时的两种等价选择 | 同左，任选其一保持 BST 性质 |
| 典型示例 | 中序 1234567 删 5 → 用 4 覆盖再删叶子 4 | 用 6 覆盖再删叶子 6 |
| 记忆口诀 | 前驱左最右，后继右最左 |

### 组5：BST 查找 vs 二分查找

| 对比维度 | BST 查找 | 二分查找（有序数组） |
|----------|---------|---------------------|
| 各自定义 | 沿树从根向下按左右指针走 | 在有序数组上按 mid 折半收缩区间 |
| 核心区别 | 比较后走指针，无需连续内存 | 比较后移动下标，依赖顺序存储 |
| 各自特点 | 插入删除只改指针 O(1) 挂接 | 插入删除要移动元素 |
| 使用场景 | 动态数据集、频繁增删 | 静态有序数据、只查不改 |
| 典型示例 | `SearchBST(T->lchild, key)` | 课件提到"不必先中序生成有序数组再二分" |
| 记忆口诀 | 树找利增删，二分利静态 |

## 📋 速查表

### 复杂度速查
```
BST 查找/插入/删除：平均 O(logn)，最坏 O(n)（有序输入退化单链表）
AVL 查找/插入/删除：平均与最坏均为 O(logn)
AVL 旋转：单旋 1 次，双旋 2 次；代价 O(1)
BST 中序遍历：得到升序序列 O(n)
```

### BST 三约束与三操作
```
约束：左子树所有值 < 根 < 右子树所有值；左右子树又各是 BST
查找：key < 根 → 左走；key > 根 → 右走；走到空 → 失败
插入：按查找路径走到空位，新结点必为叶子
删除：叶子直接删；度1孩子顶替；度2前驱/后继值覆盖后再删
最值：最小 = 一路向左；最大 = 一路向右
```

### BST 模板（二叉排序树代码.c）
```c
/* 查找-非递归 */  while (p && p->data != x) p = x < p->data ? p->l : p->r;
/* 插入-递归 */    root->l = Insert1(root->l, x);  ...  return root; // 返回新树
/* 插入-非递归 */  pre 记父亲，循环到空，x<pre->data ? pre->l=s : pre->r=s
/* 删除-递归 */    度2: t=root->r; while(t->l) t=t->l;   // 后继
                   root->data=t->data; root->r=Delete2(root->r, t->data);
                   度0/1: root = root->l ? root->l : root->r; free(p);
/* 删除-非递归 */  度2: t=p->l; while(t->r) t=t->r;      // 前驱，记父亲tf
                   p->data=t->data; p=t; pre=tf;         // 转化为删t
                   度0/1: ch=p唯一孩子; pre->l==p?pre->l=ch:pre->r=ch;
                   pre==NULL 时 root=ch; free(p);
```

### AVL 旋转模板（平衡二叉树代码.c）
```c
/* LL → 右旋 */   y=x->l; x->l=y->r; y->r=x;  更新x,h再更新y,h; return y;
/* RR → 左旋 */   y=x->r; x->r=y->l; y->l=x;  更新x,h再更新y,h; return y;
/* LR 双旋 */     x->l = RRrotation(x->l);  return LLrotation(x);
/* RL 双旋 */     x->r = LLrotation(x->r);  return RRrotation(x);
```

### LL/RR/LR/RL 对照
```
LL：左边高，插在左孩子的左边   → 失衡点右旋 1 次
RR：右边高，插在右孩子的右边   → 失衡点左旋 1 次
LR：左边高，插在左孩子的右边   → 左孩子左旋 → 失衡点右旋
RL：右边高，插在右孩子的左边   → 右孩子右旋 → 失衡点左旋
```

### AVL 插入/删除要点
```
插入：BST 插入 → 回溯更新 h → |BF|>1 时按"插入值位置"判型旋转
删除：BST 三种删除（保证最后删的是叶子）→ 逐层检查 BF
      删左子树后右高：Geth(r)-Geth(l)>1，right->r>=right->l 取 RR 否则 RL
      删右子树后左高：Geth(l)-Geth(r)>1，left->l>=left->r 取 LL 否则 LR
      更新高度前判 root != NULL
验证：中序遍历同时打印 Geth(l)-Geth(r)，BF 应全部落在 {-1,0,1}
```
