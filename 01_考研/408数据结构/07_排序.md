## 本章地图

前面六章把数据组织起来，本章解决「把无序变成有序」本身。内部排序八种算法其实只有三种思路：**插入**（把新元素塞进已有序的前缀）、**选择**（反复挑最值放到位）、**交换**（逆序对两两交换或大范围划分）；第四种**归并**则走「分而治之」；第五种**计数 / 基数**绕过比较、按位分桶。每个算法的差异浓缩进四个属性：时间、空间、**稳定性**、适用场景。章末【补充】把战场搬到磁盘——外部排序，核心从「比较次数」变成「I/O 次数」。

学习路径：逐个学八个算法（每个都能手走一趟）→ 背大对比表 → 外部排序两节。**全章枢纽：大对比表；外部排序枢纽：归并趟数与 I/O 优化。**

## 本章重点

> **【重点】** **稳定性**：相等元素排序后相对次序不变则稳定。稳定：直接插入、冒泡、归并、基数（「插冒归基」）；不稳定：希尔、快排、简单选择、堆排（「希快选堆」）。

> **【重点】** **快排的划分**：每趟确定**一个**元素的最终位置；**基本有序 / 已有序时最坏** O(n²)（划分极不平衡）；快排是平均性能 O(n log₂n) 中常数最小的。

> **【重点】** **堆排两阶段**：建堆 O(n)（自下而上）+ 反复「取顶换尾、下溯」O(n log n)；**大顶堆出升序**（顶是最大，换到尾部）。

> **【重点】** **归并排序**：任何情况都是 O(n log₂n)，空间 O(n)，稳定——**唯一同时满足「稳定 + O(n log n) + 不受初始序影响」的内部排序**。

> **【重点】** **外部排序的总时间 = 内排序时间 + 外存读写时间 + 内部归并时间**，其中**读写 I/O 占大头**；优化方向：增大归并路数（败者树）、减少初始归并段数（置换-选择）、按哈夫曼思想组织归并顺序（最佳归并树）。

---

## 本章难点

> **【难点】** **希尔排序的时间复杂度**：依赖增量序列，无公认精确值（约 O(n^1.3)）；选择题考「优于直接插入的实验事实」而非精确公式。最后一趟增量必须为 1。

> **【难点】** **快排空间 O(log₂n)**：是**递归栈**深度的期望值，不是辅助数组；最坏 O(n)（递归深度 = n）。「快排空间复杂度」是选择题陷阱。

> **【难点】** **外部排序趟数公式**：S = ⌈log_k(r)⌉（k 路归并、r 个初始归并段）；趟数每减 1，读写次数大幅下降——所有优化的靶心都是这个式子。

---

## 本章易错点

> **【易错】** **头号易错：稳定口诀背反**。「插冒归基稳定，希快选堆不稳」；判断题给「简单选择排序稳定」必错——它靠**远距离交换**破坏稳定性。

> **【易错】** **快排划分后元素位置问法**：每趟后「该枢轴元素已到位」，但**两侧内部仍未有序**；问「第 i 趟后有多少元素最终就位」要数已完成划分的枢轴数，不是 i 个两侧边界。

> **【易错】** **基数排序的空间与位数**：空间 O(r)（r 为基数，桶数）；总时间 O(d(n + r))——d 是**最大位数**，别把 r（基数 10）和 d（位数）混用。

> **【易错】** **大顶堆排升序、小顶堆排降序**：方向反直觉；口诀「大顶出大放尾 → 升序」。

> **【易错】** **外部排序的 k 路归并败者树高度**：⌈log₂k⌉ + 1 层（含冠军结点上方），每次调整比较 **log₂k 次**；与「比较树」的层数口径差异是填空题陷阱。

## 知识点讲解

### 7-1　排序基本概念　【P0】

**是什么**：排序 = 按关键字非递减（或非递增）重排；**稳定性**定义见重点；内部排序（内存）/ 外部排序（磁盘，记录多到内存装不下）。

**为什么**：稳定性不只是概念题——多关键字排序（先按次要关键字排、再按主要关键字**稳定**排）依赖它；基数排序整个算法就建立在稳定传递上。

**怎么用**：判断一个算法稳定性的**机制化方法**：找「不相邻元素的远距离交换 / 跨越式放置」——有则必不稳定（希尔步长交换、快排划分交换、简单选择的 min 交换、堆排的顶尾交换）；只在相邻 / 顺序位置移动则稳定。

> **【规律】** 排序算法的「比较次数」与「移动次数」分开计：直接插入比较 O(n²) 移动 O(n²)（但**基本有序时退化几乎为 0 移动**，这是它仍被用于小数据的原因）。

### 7-2　插入排序（直接、折半、希尔）　【P0】

**是什么**：直接插入：逐个把 a[i] 插入前面已有序段。折半插入：定位用折半（**移动次数不变**，比较次数降到 O(n log n)）。希尔：按增量 d 分组做直接插入，d 逐轮缩小到 1。

**为什么**：插入的思想最朴素（像理牌），且对**基本有序**数据近乎线性；希尔让远距离的乱序先大致归位，减少最后一轮的移动量。

**怎么用**：

```c
#include <stdio.h>

void insertSort(int a[], int n) {          /* 升序，a[0..n-1] */
    for (int i = 1; i < n; i++)
        if (a[i] < a[i - 1]) {
            int key = a[i], j = i - 1;
            while (j >= 0 && a[j] > key) { /* 边比边后移 */
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = key;
        }
}

void shellSort(int a[], int n) {
    for (int d = n / 2; d >= 1; d /= 2)    /* 增量序列：折半 */
        for (int i = d; i < n; i++) {      /* 各组交替插入 */
            int key = a[i], j = i - d;
            while (j >= 0 && a[j] > key) {
                a[j + d] = a[j];
                j -= d;
            }
            a[j + d] = key;
        }
}
```

**手算示范**（直接插入，序列 49, 38, 65, 97, 76, 13, 27）：
趟 1 后 38,49,65,97,76,13,27；趟 2 后不变（65 已位）；趟 3 后不变；趟 4 后 38,49,65,76,97,13,27；趟 5 后 13,38,49,65,76,97,27；趟 6 后 13,27,38,49,65,76,97。
希尔（d = 3）：(49,97,27)、(38,76)、(65,13) 三组各自插入后 → 27,38,13,49,76,65,97；再 d = 1 收尾。

> **【规律】** 折半插入的比较次数与初始序**无关**（恒 O(n log n)）、移动次数与直接插入相同——「折半只优化比较」这半句是判断题。

### 7-3　交换排序（冒泡、快排）　【P0】

**是什么**：冒泡：相邻逆序互换，每趟把当前最大「冒」到尾。快排：选枢轴做**划分**——比它小的去左、大的去右，枢轴落定最终位置；对两侧递归。

**为什么**：冒泡稳定但 O(n²)；快排平均 O(n log₂n) 且常数小，是通用内排的默认冠军——代价是不稳定、最坏 O(n²)、递归栈空间。

**怎么用**：

```c
#include <stdio.h>

void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;                    /* 优化一：提前终止 */
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = 1;
            }
        if (!swapped) break;                /* 一趟无交换 → 已有序 */
    }
}

void quickSort(int a[], int low, int high) {
    if (low >= high) return;
    int pivot = a[low], i = low, j = high;  /* 枢轴取首元素 */
    while (i < j) {
        while (i < j && a[j] >= pivot) j--; /* 从右找小 */
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++; /* 从左找大 */
        a[j] = a[i];
    }
    a[i] = pivot;                           /* 枢轴就位 */
    quickSort(a, low, i - 1);
    quickSort(a, i + 1, high);
}
```

**手算示范**（快排一趟，序列 49, 38, 65, 97, 76, 13, 27，枢轴 49）：
j 从右找小于 49 的 27 → a[0]=27；i 从左找大于 49 的 65 → a[5]=65；j 找 13 → a[5]=13；i j 相遇 → a[5]=49。
一趟结果 **27, 38, 13, 49, 76, 97, 65**——49 就位，左侧全小于它、右侧全大于它。

> **【规律】** 快排五考点：①每趟确定一个枢轴的最终位；②**初始有序 / 逆序时最坏 O(n²)**（划分一边倒），优化：三者取中 / 随机枢轴；③枢轴取首元素时，「从右先动」保证相遇位元素 ≤ 枢轴；④递归深度期望 O(log₂n) = 栈空间；⑤「快速排序在所有 O(n log n) 中平均最快」指常数小，非大 O 差异。

> **【注意】** 冒泡两优化（提前终止 + 每趟边界收缩）后，**最好情况（已有序）一次扫描 O(n)**——冒泡最好 O(n)、最坏 O(n²)；判断题常拿它与快排的最好最坏对照。

### 7-4　选择排序（简单选择、堆排）　【P0】

**是什么**：简单选择：每趟从未排序区挑最小，与未排序区**首位**交换。堆排：建大顶堆 → 顶（当前最大）与尾部交换 → 堆大小减一、下溯修堆 → 重复。

**为什么**：简单选择的**交换次数最少（至多 n − 1 次）**，适合「移动代价极大」的场景；堆排把「挑最值」升级为 O(log n)，整体 O(n log₂n) 且空间 O(1)。

**怎么用**：

```c
#include <stdio.h>

void selectSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int mn = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[mn]) mn = j;
        if (mn != i) {                       /* 交换次数至多 n-1 */
            int t = a[i]; a[i] = a[mn]; a[mn] = t;
        }
    }
}

void heapSort(int a[], int n) {              /* 大顶堆，a[0..n-1]，下标 0 起 */
    #define A(i) a[(i) - 1]                  /* 转 1 起编号便于套公式 */
    for (int i = n / 2; i >= 1; i--) {       /* 自下而上建堆 O(n) */
        for (int k = i; 2 * k <= n; ) {
            int big = 2 * k;
            if (big + 1 <= n && A(big + 1) > A(big)) big++;
            if (A(k) >= A(big)) break;
            int t = A(k); A(k) = A(big); A(big) = t;
            k = big;
        }
    }
    for (int m = n; m >= 2; m--) {           /* 反复取顶换尾 */
        int t = A(1); A(1) = A(m); A(m) = t;
        for (int k = 1; 2 * k <= m - 1; ) {
            int big = 2 * k;
            if (big + 1 <= m - 1 && A(big + 1) > A(big)) big++;
            if (A(k) >= A(big)) break;
            int t2 = A(k); A(k) = A(big); A(big) = t2;
            k = big;
        }
    }
}
```

> **【规律】** 堆排四考点：①建堆 O(n)、总 O(n log₂n)、空间 O(1)、**不稳定**；②大顶堆升序；③「前 k 大 / 前 k 小」用部分堆排 O(n log k)（选择题常以「取前 k 大元素用什么」出现，与快排变体对照）；④**插入 / 删除 O(log n)** 直接复用第 4 章 4-10。

### 7-5　归并排序　【P0】

**是什么**：两两归并有序段：1 长度两两并 → 2 → 4 … 直到全表（2 路归并）；递归式「分到单元素，并回来」。

**为什么**：比较型排序中**唯一稳定 + 恒 O(n log₂n)** 的选手；也是外部排序的全部基础（磁盘上没有随机访问，只能顺序归并）。

**怎么用**：

```c
#include <stdio.h>
#include <stdlib.h>

void merge(int a[], int lo, int mid, int hi, int *tmp) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi)              /* 稳定的关键：相等先取左 */
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi)  tmp[k++] = a[j++];
    for (i = lo; i <= hi; i++) a[i] = tmp[i];
}

void mergeSort(int a[], int lo, int hi, int *tmp) {
    if (lo >= hi) return;
    int mid = (lo + hi) / 2;
    mergeSort(a, lo, mid, tmp);
    mergeSort(a, mid + 1, hi, tmp);
    merge(a, lo, mid, hi, tmp);
}
```

> **【规律】** 归并趟数 = **⌈log₂n⌉**（2 路归并 n 个元素）；总比较次数最坏 O(n log₂n)；空间 O(n)（辅助数组）+ O(log₂n)（递归栈）。k 路归并趟数 ⌈log_k n⌉——这就是外部排序趟数公式的出处。

### 7-6　计数、桶与基数排序　【P1】

**是什么**：计数排序：值域 [0, r] 时统计每个值出现次数，直接按序输出（不比较）。桶排序：按值域分桶，桶内各自排序。**基数排序**：按位（个十百…）多趟「分配 + 收集」，每趟必须**稳定**（用队列桶）。

**为什么**：比较排序的下界是 Ω(n log₂n)（决策树论证），计数 / 基数**绕过比较**达成线性——代价是依赖关键字结构（可拆位、值域有限）。

**怎么用（基数排序流程）**：d 位关键字、基数 r：第 1 趟按个位分配进 r 个队列 → 依序收集；第 2 趟按十位……共 **d 趟**。时间 O(d(n + r))，空间 O(r)。

> **【规律】** 手算题给 3 位数序列走基数排序：只需画「每趟分配后各队列内容 → 收集后的序列」；**每趟收集后低位的相对次序保持不变**（稳定性），这是整个算法的正确性根基。

### 7-7　八种排序大对比表　【P0】

| 算法 | 复杂度（最好 / 平均 / 最坏） | 空间 | 稳定性 | 备注 |
|------|------------------------------|------|--------|------|
| 直接插入 | O(n) / O(n²) / O(n²) | O(1) | 稳 | 基本有序时近乎线性 |
| 折半插入 | 比较 O(n log n)，移动 O(n²) | O(1) | 稳 | 只省比较不省移动 |
| 希尔 | — / 约 O(n^1.3) / — | O(1) | **不稳** | 依赖增量序列 |
| 冒泡 | O(n) / O(n²) / O(n²) | O(1) | 稳 | 两优化后可提前停 |
| 快排 | O(n log n) / O(n log n) / **O(n²)（有序时）** | O(log n) 栈 | **不稳** | 平均常数最小 |
| 简单选择 | O(n²) / O(n²) / O(n²) | O(1) | **不稳** | 交换次数 ≤ n−1 |
| 堆排 | O(n log n) × 3 | O(1) | **不稳** | 建堆 O(n)；大顶升序 |
| 归并 | O(n log n) × 3 | O(n) | 稳 | 恒定 n log n |
| 基数 | O(d(n+r)) × 3 | O(r) | 稳 | 不比较；d 位 r 基 |

> **【记忆】** 「不稳定四兄弟：希快选堆」；「恒 n log n 三选一：堆排省空间、归并保稳定、快排最快」。

### 7-8　外部排序：多路归并与败者树【补充】　【P0】

**是什么**：记录量大到内存装不下时：①分批读入，逐批内排序生成**初始归并段**写回磁盘；②对 r 个有序段做 **k 路归并**直至一段。归并趟数 S = ⌈log_k r⌉。**败者树**：k 路归并时维护「k 个段前哨中谁最小」的完全二叉树，胜者树 / 败者树使每次选最小的比较次数从 k − 1 降到 **⌈log₂k⌉**。

**为什么**：磁盘 I/O（毫秒级）比内存比较（纳秒级）慢 10⁵ 倍以上，外部排序优化的唯一靶心是**减少读写次数 = 减少趟数**：增大 k（败者树让多路不慢）、减少 r（置换-选择让段更长）、让小段先并（最佳归并树）。

**怎么用**：
- 读写次数（块为单位）：每趟把全部记录读写各一次 → 总读写 = **2 × 记录块数 × (S + 1)**（初始生成段一次读写 + S 趟归并读写... 按口径：初始段生成读 1 写 1，每趟归并读 1 写 1，共 S + 1 次全量读写）。
- 败者树：k 个叶子为各段当前记录；内部结点记「败者（较大者）编号」，冠军一路浮到根；新记录入树后沿父链 **⌈log₂k⌉** 次比较完成调整。
- 并行缓冲：输入缓冲 k 个、输出缓冲 1 个（2k 个输入缓冲更佳，双缓冲流水），使 I/O 与计算重叠（概念级考查）。

> **【规律】** 「增大 k 的代价」：k 太大使缓冲区太多、内存不够；败者树保证内部归并时间不随 k 增长——**k 可以放心加大**，这是选择题标准答案。

### 7-9　外部排序：置换-选择与最佳归并树【补充】　【P0】

**是什么**：
- **置换-选择排序**：生成**平均长度 2 × 内存容量**的初始归并段（超过内存工作区大小），把 r 压到 ⌈n / (2w)⌉ 量级（w 为工作区记录数）；机制：输出后立即读入新记录，若 ≥ 刚输出的则留本段，否则存入「下一段暂存区」。
- **最佳归并树**：段长不一时，按**哈夫曼思想**组织 k 叉归并（短段先并），总 I/O 最小；段数不满足严格 k 叉树时补**虚段**（空段）：补虚段个数 u = (r − 1) mod (k − 1)（r 为段数、k 为路数），u ≠ 0 时补 k − 1 − u 个。

**为什么**：置换-选择从源头减段数；最佳归并树让「归并顺序」也最优——两者与败者树分别作用在「段数、归并顺序、单趟速度」三个互不重叠的杠杆上，三者合用才是完整的外排优化。

**怎么用（最佳归并树手算）**：段长 {9, 30, 12, 18, 3, 17, 2, 6, 24}，3 路归并：r = 9，u = (9−1) mod 2 = 0，无需虚段。反复取最小 3 段合并：3+2+6=11；9+11+12=32；17+18+24=59；30+32+59=121。总读写记录数 = **2 × (内结点权值和) = 2 × (11+32+59) = 204**……按标准口径：比较与读写量由树权决定，WPL 型计算——总 I/O 记录数 = 2 × Σ(非叶权值)。

> **【规律】** 三个公式一页背：趟数 S = ⌈log_k r⌉；虚段数 = 补 (k − 1) − (r − 1) mod (k − 1) 个（当余数非零）；置换-选择平均段长 = 2w。综合题「求最少读写次数」= 建最佳归并树 + 2 × 非叶权值和 × （读写以记录计）。

> **【类比】** k 路归并 = k 台点钞机同时出钞、每次取最少的一张（败者树记住谁快谁慢）；置换-选择 = 流水线不空转，能接的活接着干，接不上的推给下一班。

## 典型例题

### 例题 7-1　（过程手算 · 选择题风格）
**题干**：对序列 49, 38, 65, 97, 76, 13, 27 做一趟快排（枢轴取首元素），写出结果；再指出哪几趟之后「有多少元素已最终就位」。

**解题思路**：划分填坑法（7-3 代码），每步记录 i、j 移动。

**解答过程**：
枢轴 49：j 从右找 27 → a[0] = 27；i 从左找 65 → a[5] = 65；j 继续找 13 → a[5] = 13；i j 相遇于位 5 → a[5] = 49。
一趟结果：**27, 38, 13, 49, 76, 97, 65**。49 已最终就位；两侧内部无序，需继续递归。
（后续：左半 27,38,13 枢轴 27 就位 → 13,27,38；右半 76,97,65 枢轴 76 就位 → 65,76,97。三趟后全部就位。）

**复杂度分析**：一趟划分 O(m)（m 为该段长度）。

### 例题 7-2　（对比辨析 · 选择题风格）
**题干**：下列说法正确的有：Ⅰ. 归并排序在任何初始序列下都是 O(n log₂n)。Ⅱ. 快排在初始序列基本有序时最快。Ⅲ. 简单选择排序的交换次数至多 n − 1。Ⅳ. 堆排是稳定的。Ⅴ. 基数排序的比较次数与初始序列无关。

**解题思路**：逐条对照大对比表与机制：Ⅰ 对（归并恒定）；Ⅱ 反了（快排有序时**最坏**）；Ⅲ 对；Ⅳ 错（顶尾远距交换不稳）；Ⅴ 对（基数不比较，按位分配）。

**解答过程**：正确的是 **Ⅰ、Ⅲ、Ⅴ**。

**复杂度分析**：概念题 O(1)。

### 例题 7-3　（外部排序计算【补充】 · 综合题风格）
**题干**：某文件含 10000 条记录，内存一次可对 1000 条排序。①用普通内排生成初始段，求段数 r 与 4 路归并趟数；②改用置换-选择生成段（平均段长 2000），求 r 与 2 路归并趟数；③说明两种方案读写量差异的来源。

**解题思路**：套 r = ⌈n/w⌉ 与 S = ⌈log_k r⌉。

**解答过程**：
① r = ⌈10000/1000⌉ = 10 段；S = ⌈log₄10⌉ = 2 趟。
② 平均段长 2000 → r = ⌈10000/2000⌉ = 5 段；S = ⌈log₂5⌉ = 3 趟。若配 4 路：S = ⌈log₄5⌉ = 2 趟（与①同趟数但每趟处理的段更少更长）。
③ 读写量 ∝ 记录块数 × 趟数；置换-选择把 r 减半，使「增大归并路数」的选择空间变大（k 大时 log_k r 更小）——**来源是初始段更长，趟数更少**。

**复杂度分析**：O(1) 公式计算。

## 本章总结

### 核心内容（一页纸）

- **稳定性口诀：插冒归基稳，希快选堆不稳**；机制 = 有无远距交换。
- 直接插入基本有序近线性；**折半插入只省比较不省移动**；希尔无精确复杂度、末趟增量必为 1。
- 冒泡两优化后最好 O(n)；**快排有序时最坏 O(n²)**、空间是递归栈 O(log n)、每趟定一个枢轴。
- 简单选择交换次数 ≤ n − 1；**堆排建堆 O(n)**、大顶出升序、O(1) 空间但不稳。
- **归并恒 O(n log n) + 稳定 + O(n) 空间**，趟数 ⌈log₂n⌉；相等先取左才稳定。
- 基数 O(d(n+r))、按位分配收集、每趟必须稳定；比较排序下界 Ω(n log n)。
- **外部排序三杠杆**：败者树增大 k（单趟比较 log₂k）、置换-选择减 r（平均段长 2w）、最佳归并树排顺序（哈夫曼 + 虚段 (k−1) − (r−1) mod (k−1)）；趟数 S = ⌈log_k r⌉，读写量与趟数成正比。

### 知识点串联图

```text
排序
├── 概念（稳定性 / 内外排 / 比较下界 Ω(n log n)）
├── 插入系（直接 → 折半 → 希尔）
├── 交换系（冒泡两优化 → 快排划分递归）
├── 选择系（简单选择 → 堆排两阶段）
├── 归并系（2 路 / k 路，稳定恒 n log n）
├── 分布系（计数 / 桶 / 基数：绕过比较）
├── 大对比表（四属性 × 八算法）
└── 外部排序【补充】
    ├── 多路归并 + 败者树（增大 k）
    ├── 置换-选择（减少 r，段长 2w）
    └── 最佳归并树（哈夫曼 + 虚段）
```
