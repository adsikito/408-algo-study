## 第九章：堆

> 课件来源：`09_堆__二叉堆.pdf`（共8页，本章无配套代码）
>
> 本章把完全二叉树装进数组：堆是优先队列和堆排序的引擎，也是第十章图算法（迪杰斯特拉、普里姆）的预备知识。

## 🗺️ 本章地图

- **本章解决什么问题**："反复取当前最值"如果每轮都扫一遍数组要 O(n)，堆把它降到取最值 O(1)、维护 O(log n)。
- **学习顺序**：先看载体——完全二叉树与编号规律（节1）→ 堆序定义（节2）→ 装进数组的下标公式（节3）→ 五个操作归结为"上浮/下沉"两个动作（节4）→ 应用（节5）。
- **为什么是这个顺序**：编号规律是"住进数组"的根基，堆序定义决定每个操作往哪个方向调；不懂"怎么存"就看不懂"怎么调"。
- **各节关系一句话**：节1~3 打地基（形态→性质→存储），节4 是主体（一切操作 = 单路径上浮或下沉），节5 是出口。

## 📌 本章重点（3-5个）

⭐ **堆建立在完全二叉树上**：满二叉树必然是完全二叉树；按层编号得到的父子结论，是堆能用数组存储的依据
⭐ **两套下标公式**：数组版——父 (i-1)/2、左孩子 2i+1、右孩子 2i+2；编号版——父 ⌊i/2⌋、左 2i、右 2i+1
⭐ **大顶堆与小顶堆**：根与孩子的大小关系对**所有子树**都成立；小顶堆的根一定是全树最小值，大顶堆相反
⭐ **两个调整方向**：删除/新值变大 → 向下堆化（heapify）；插入/新值变小 → 向上回溯
⭐ **堆的应用**：堆排序、优先队列、图算法（迪杰斯特拉、普里姆）

## 🔥 本章难点（2-3个）

🔥 **removeMin 的堆化过程**：删堆顶 → 最后一个元素补位 → 从堆顶逐层与**较小孩子**比较交换，直到叶子
🔥 **delete 任意结点的组合技**：先用 updateKey(i, INT_MIN) 把目标结点抬到堆顶，再用 removeMin() 移除——向上、向下两个方向一次用全
🔥 **调整方向的判定**：新值比原值小 → 向上回溯；新值比原值大 → 向下堆化（课件 updateKey 默认 new_val < val）

## ⚠️ 本章易错点（3-5个）

⚠️ **判断孩子是否存在要和总结点数 n 比较**：2i > n 无左孩子、2i+1 > n 无右孩子（数组版即 2i+1 越过 n-1 下标）
⚠️ **堆化要和"较小的孩子"交换**：小顶堆是父、左、右三者取最小交换，不是固定和左孩子换
⚠️ **两套公式混用**：结点编号从 1 开始（父 ⌊i/2⌋）与数组下标从 0 开始（父 (i-1)/2）不能混着算
⚠️ **updateKey 默认新值更小**：若 new_val > val，就是对更新结点做向下堆化；两种都要处理就加 if...else
⚠️ **数据结构的"堆" ≠ 第二章内存的"堆区"**：前者是完全二叉树+堆序，后者是 malloc 的内存段，两码事

## 📖 知识点讲解

### 1. 预备知识：完全二叉树与编号结论

**是什么**：堆的全部魔法来自完全二叉树的一个巧合——按层编号后，父亲的编号恰好是孩子的一半左右，记住编号关系就再也不用记指针。严格定义：如果二叉树中除了叶子结点，每个结点的度都为 2，称为**满二叉树**；如果除去最后一层结点为满二叉树、且最后一层结点依次从左到右分布，称为**完全二叉树**。所以满二叉树必然是完全二叉树。对任意完全二叉树按层次从左到右标号后，结点 i 满足三个结论：

```
① i > 1 时，父结点 = ⌊i/2⌋（i = 1 是根，无父）   例：结点45标号4，其父15标号2
② 2*i > n（n为总结点数）→ i 无左孩子（叶子）；否则左孩子 = 2*i
③ 2*i+1 > n → i 无右孩子；否则右孩子 = 2*i+1
```

**为什么**：堆与完全二叉树息息相关。完全二叉树按层编号**连续、无空洞**，编号之间的数量关系（2 倍、2 倍+1、除 2）恰好就是父子位置关系，这是堆能省掉所有指针、直接住进数组的前提。

**怎么用**（跟着算：用树 {10,15,20,45,50} 把三条结论各验一遍）：
```text
        10              第1步 按层从左到右编号：10→1、15→2、20→3、45→4、50→5
      /    \            第2步 用①：结点 45 标号 4，父 = ⌊4/2⌋ = 2，即结点 15 ✓
    15      20          第3步 用②：结点 15 标号 2，左孩子 = 2×2 = 4，即结点 45 ✓
   /  \                 第4步 用③：结点 20 标号 3，左孩子编号 = 6 > n=5 → 无左孩子（叶子）
  45    50
```

> ⚠️ 注意事项：判断有无孩子是拿编号换算结果与**总结点数 n** 比较，不是凭感觉看图。

> 🎯 规律：父子互算只靠"×2、+1、÷2"三个算术动作；数组下标版只是把编号整体减 1，别无新意。

> 💡 一句话总结：满必完全，编号藏公式。

### 2. 堆与二叉堆的定义

**是什么**：堆是"只讲究父子大小关系"的完全二叉树——每个父亲都压孩子一头（大顶堆），或被孩子压一头（小顶堆）；兄弟之间谁大谁小，堆一概不管。堆（Heap）是**一类基于完全二叉树的特殊数据结构**，分两种类型：
1. **大顶堆（Max Heap）**：根结点的值必须**大于**其孩子结点的值，对二叉树中所有子树都满足此规律
2. **小顶堆（Min Heap）**：根结点的值必须**小于**其孩子结点的值，对所有子树都满足

**二叉堆**的两条属性：① 必定是一颗完全二叉树（此属性决定了它适合存在数组中）；② 要么是小顶堆、要么是大顶堆。

**为什么**：小顶堆以任意一个结点为根，其左右孩子都要大于等于该结点的值，所以**整棵树的根结点一定是树中值最小的结点**；大顶堆特性正好相反。这一性质是堆能 O(1) 拿最值、进而支撑优先队列的底气。

**怎么用**（跟着算：逐条边验证下面真的是小顶堆）：
```
   小顶堆                大顶堆
     10                   100
   /    \               /     \
  15     20            45      50
 / \   /  \           /  \    /  \
45 50 100  30        10   15 20   30
```
```text
第1步 看根：10 < 15、10 < 20 ✓
第2步 看左子树：以 15 为根，15 < 45、15 < 50 ✓
第3步 看右子树：以 20 为根，20 < 100、20 < 30 ✓ —— 每条"父→子"边都成立，才是小顶堆
第4步 反例感受：若把叶子 45 改成 12，则 15 > 12 这条边违反堆序，整棵树就不再是小顶堆
```

| 对比 | 大顶堆 | 小顶堆 |
|------|--------|--------|
| 根与孩子 | 根 > 孩子 | 根 < 孩子 |
| 全局最值 | 根 = 最大值 | 根 = 最小值 |
| 典型用途 | 反复取最大 | 反复取最小（优先队列） |

> ⚠️ 注意事项：堆只约束"父与孩子"这一条边，**兄弟之间、左右子树之间没有大小关系**。

> 🎯 规律：只约束"父→子"一条边，却对所有子树成立 ⇒ 全局最值必然被顶在根上；兄弟无序不影响这一点。

> 💡 一句话总结：小顶根最小，大顶根最大。

### 3. 二叉堆的存储结构（数组）

**是什么**：把完全二叉树按层"拍平"塞进数组——因为编号连续无空洞，父子关系不用指针，用下标公式一算就到。二叉堆必定是完全二叉树，**一般用数组表示**。根元素用 `arr[0]` 表示，第 i 个结点的存储位置满足：

| 数组表示 | 含义 |
|----------|------|
| `arr[(i-1)/2]` | 第 i 个结点的父结点 |
| `arr[2*i + 1]` | 第 i 个结点的左孩子结点 |
| `arr[2*i + 2]` | 第 i 个结点的右孩子结点 |

**为什么**：完全二叉树按层编号连续无空洞，编号关系本质与完全二叉树自身特性一一对应；用数组存储不需要任何指针，随机访问下标即可定位父子。

**怎么用**（数组+树两视角对照着看，跟着算三步）：
```
        10            下标:  0    1    2    3    4
      /    \               | 10 | 15 | 20 | 45 | 50 |
    15      20
   /  \             例：arr[1]=15 的父 = arr[0]=10，
  45    50              左孩子 = arr[3]=45，右孩子 = arr[4]=50
```
```text
第1步 按层写入数组：arr = {10, 15, 20, 45, 50}（下标 0~4）
第2步 求父：15 的下标 i=1，父 = arr[(1-1)/2] = arr[0] = 10 ✓
第3步 求孩子：15（i=1）左 = arr[2×1+1] = arr[3] = 45，右 = arr[2×1+2] = arr[4] = 50 ✓
第4步 判边界：20（i=2）左孩子下标 = 5 ≥ n=5 → 不存在，20 是叶子
```

> ⚠️ 注意事项：两套公式别混用——"结点编号 i"从 1 开始（父 ⌊i/2⌋、孩子 2i、2i+1）；"数组下标 i"从 0 开始（父 (i-1)/2、孩子 2i+1、2i+2）。

> 🎯 规律：编号版 ×2、⌊i/2⌋ 平移一位就是下标版 2i+1、(i−1)/2——同一棵树、两套记号，做题先问自己"这个 i 从几开始"。

> 💡 一句话总结：父子关系全靠下标公式。

### 4. 小顶二叉堆的常见操作

**是什么**：堆的增删改全是同一个剧本——谁破坏了堆序，就只沿一条路径把谁"送"回该在的位置：新值变小往上顶，新值变大往下沉。五个核心操作：`getMin()`（取根）、`removeMin()`（移除最小元素）、`updateKey()`（更新指定下标的值）、`insert()`（插入结点）、`delete()`（删除结点）。调整堆保持属性的过程称为**堆化（heapify，把被破坏的堆序沿一条路修回去）**。

**为什么**：插入、更新、删除都只会**局部破坏**堆序，只需沿一条路径（向上或向下）逐层修正即可恢复，不必整树重排——这正是堆高效的原因。

**怎么用**（以小顶堆为例，大顶堆自己都能写出来）：

- **获得根元素 getMin()**：按存储结构，根结点就是 `arr[0]`，返回即可。
- **移除最小元素 removeMin()**：删除堆顶后，把**最后一个元素**放到堆顶，再向下堆化。例（堆 {10,15,20,45,50}）：删除堆顶 10，最后元素 50 作新堆顶；
  - 第一步：50(i=0) 的左孩子 l=arr[1]=15、右孩子 r=arr[2]=20，三者取最小 15，交换 15 和 50，继续对 i=1 堆化；
  - 第二步：50(i=1) 左孩子 l=arr[3]=45、右孩子不存在，50>45 交换，继续对 i=3 堆化；
  - 第三步：50 已到叶子结点，堆化完成。
  ```text
  图示（数组 + 树两视角，before/after）：
    50 补位后（堆化前）           堆化完成后
          50                        15
        /    \                    /    \
      15      20                45      20
     /                              \
    45                               50（已出堆，逻辑长度 n=3）
  数组轨迹：{50,15,20,45} → {15,50,20,45} → {15,45,20,50}，最终逻辑堆 {15,45,20}
  ```
- **更新指定下标的值 updateKey()**：课件假设 `new_val < val`，操作与堆化**方向相反**——从被更新结点开始**向上回溯**，直到结点的值大于父结点的值停止。例：把下标 4 的 50 更新为 8：
  - 第一步：8(i=4) 与父 15(i=(4-1)/2=1) 比较，8<15 交换；
  - 第二步：8(i=1) 与父 10(i=0) 比较，8<10 交换；
  - 第三步：8(i=0) 已是根结点，更新结束。
  - （若 new_val > val，就是对更新结点向下堆化；两种都处理就加 if...else）
- **插入结点 insert()**：将新结点插入到**树的末尾**；如果新结点的值大于其父结点，插入直接完成；否则类似 updateKey 向上回溯修正堆。例：插入 30(i=5)，大于父结点 20，直接完成；再插入 9(i=6)：9<父20 交换 → 9<父10 交换 → 9 成为根结点，插入完成。
  ```text
  图示（插入 9，两次上浮的 before/after）：
    落到末尾 i=6                  上浮完成后
          10                        9
        /    \                    /    \
      15      20                15      10
     /  \    /  \              /  \    /  \
    45  50  30   9            45  50  30  20
  数组轨迹：{10,15,20,45,50,30,9} → {10,15,9,45,50,30,20} → {9,15,10,45,50,30,20}
  （先与父 20 换、再与父 10 换；结果与练习第3题的堆一致，可对照检验）
  ```
- **删除结点 delete()**：把要删除的结点用无穷小 `INT_MIN` 替换（调 `updateKey(i, INT_MIN)`），它会上浮到堆顶；再调 `removeMin()` 把堆顶的 INT_MIN 移除。例：删除 15(i=1)：先 update(1, INT_MIN)，再 removeMin()。思路相当于"先把它抬到顶，再按正规流程送走"——用两次标准操作拼出任意删除，不必另写一套逻辑。

| 对比 | 向下堆化（heapify） | 向上回溯（updateKey/insert） |
|------|--------------------|-----------------------------|
| 触发时机 | 删堆顶补位后、新值变大 | 插入末尾后、新值变小 |
| 比较对象 | 与（较小的）孩子比较交换 | 与父结点比较交换 |
| 终止条件 | 到叶子，或已满足堆序 | 到根，或不小于父结点 |

> ⚠️ 注意事项：向下堆化必须与**较小的孩子**交换（三者取最小）；向上回溯的前提是"新值更小"，两个方向不能搞反。

> 🎯 规律：谁破坏堆序就只修谁——新值变小向上、变大向下，永远只沿一条"根叶路径"走到底，绝不整树重排。

> 💡 一句话总结：删除向下堆化，插入向上回溯。

### 5. 堆的应用

**是什么**：堆本身不是终点——凡是"反复取当前最值"的场合，排序、任务调度、最短路，都是堆的主场。课件列出三大应用与两个变体：
1. **堆排序（Heap Sort）**
2. **优先队列（Priority Queue）**：使用二叉堆，可以实现一个高效的优先队列
3. **图算法（Graph Algorithms）**：优先队列广泛应用于像**迪杰斯特拉算法**和**普里姆算法**的图算法当中
4. 变体：基于二叉堆还有**二项式堆、斐波那契堆**等

**为什么**：堆 O(1) 取最值、O(log n) 插入删除，天生适合"反复取最值"的场景；而最短路、最小生成树算法恰好要反复取"当前权值最小的顶点/边"。

**怎么用**：

| 应用 | 用到的堆性质 |
|------|-------------|
| 堆排序 | 反复取走堆顶（最值） |
| 优先队列 | getMin/insert/removeMin 高效组合 |
| Dijkstra、Prim | 堆加速"取最小权值顶点" |

小场景走一遍：5 个任务优先级 3、1、2、1、5 依次 insert 进小顶堆，之后每次 removeMin 弹出的依次是 1、1、2、3、5——不用排序，天然按优先级出队。

> ⚠️ 注意事项：变体（二项式堆、斐波那契堆）有余力再学，主线是二叉堆。

> 🎯 规律：算法里见到"每轮都要找最小/最大"，就把 O(n) 的扫描换成堆——取 O(1)、维护 O(log n)。

> 💡 一句话总结：反复取最值，先想堆。

### 🧩 本章归纳：一条主线串全章

**一条主线**：要"反复取最值"（节5 的需求）→ 完全二叉树编号连续（节1）→ 于是能住进数组、父子靠公式算（节3）→ 堆序保证最值被顶在根上（节2）→ 增删改只会局部破坏堆序，用上浮/下沉沿一条路径修复（节4）→ 这套"取 O(1)、修 O(log n)"的组合拳撑起堆排序、优先队列和图算法（节5）。

**回头看才看得见的共性**：
1. **无空洞换公式**：堆能"裸奔"在数组里，全靠完全二叉树编号连续——存储结构决定允许的操作（哈夫曼的 w/fa/l/r 数组、并查集的 fa 数组是同一哲学）。
2. **局部修复，不推倒重来**：一次调整只走一条根叶路径，这与 AVL"只在失衡点旋转"异曲同工——维护型结构都信奉"坏了修局部"。
3. **故意放弃全序**：堆不管兄弟大小、不管左右子树内部，只守"父压子"一条规则，换来 O(1) 取最值——约束得少、维护就便宜，而需要的信息（最值）一点没少。

## 🔍 相似概念辨析

### 组1：大顶堆 vs 小顶堆

| 对比维度 | 大顶堆 | 小顶堆 |
|----------|--------|--------|
| 各自定义 | 根结点大于其孩子结点、所有子树均满足的堆 | 根结点小于其孩子结点、所有子树均满足的堆 |
| 核心区别 | 根 = 全树**最大**值 | 根 = 全树**最小**值 |
| 各自特点 | 兄弟、左右子树之间无大小约束 | 同左 |
| 使用场景 | 反复取最大（如升序堆排序） | 反复取最小（优先队列、Dijkstra/Prim） |
| 典型示例 | 100(45,50)(10,15,20,30) | 10(15,20)(45,50,100,30) |
| 记忆口诀 | 大顶根最大，小顶根最小 | |

### 组2：满二叉树 vs 完全二叉树

| 对比维度 | 满二叉树 | 完全二叉树 |
|----------|----------|-----------|
| 各自定义 | 除叶子结点外，每个结点的度都为 2 | 除去最后一层为满二叉树，最后一层结点依次从左到右分布 |
| 核心区别 | 每一层都塞满 | 最后一层可以缺，但必须**靠左** |
| 各自特点 | 满二叉树必然是完全二叉树 | 完全二叉树未必是满的 |
| 使用场景 | 理论推导 | 堆的形态、数组存储 |
| 典型示例 | 7 个结点三层全满 | 5 个结点：10,15,20,45,50（最后一层缺右） |
| 记忆口诀 | 满必完全，完全未必满 | |

### 组3：向下堆化 vs 向上回溯

| 对比维度 | 向下堆化（heapify） | 向上回溯 |
|----------|--------------------|----------|
| 各自定义 | 结点与孩子比较交换、逐层下沉的调整 | 结点与父结点比较交换、逐层上浮的调整 |
| 核心区别 | 方向往**叶子**走 | 方向往**根**走 |
| 各自特点 | 三者取最小交换，到叶子或已满足为止 | 小于父才交换，到根或不小于父为止 |
| 使用场景 | removeMin、新值变大 | insert、updateKey（new_val<val）、delete 第一步 |
| 典型示例 | 50 补位堆顶：50↔15 → 50↔45 → 叶子 | 50 改 8：8↔15 → 8↔10 → 根 |
| 记忆口诀 | 删走下坡，插走上坡 | |

### 组4：堆（数据结构） vs 堆区（内存）

| 对比维度 | 堆（Heap，数据结构） | 堆区（heap，内存分区） |
|----------|---------------------|------------------------|
| 各自定义 | 基于完全二叉树、满足堆序的特殊数据结构 | malloc 申请的无名连续内存段（第二章） |
| 核心区别 | **逻辑结构**概念 | **物理内存分区**概念 |
| 各自特点 | 父子有大小序，数组即可存储 | 向高地址生长，程序员手动 free |
| 使用场景 | 优先队列、堆排序、图算法 | 运行时动态分配节点 |
| 典型示例 | arr = {10,15,20,45,50} | `Node *p = malloc(sizeof(Node))` |
| 记忆口诀 | 结构堆有序，内存堆要还 | |

## 📋 速查表

### 下标公式（数组下标 i 从 0 开始，n 为元素个数）
```
父结点   arr[(i-1)/2]
左孩子   arr[2*i+1]     存在条件：2*i+1 < n
右孩子   arr[2*i+2]     存在条件：2*i+2 < n
```

### 完全二叉树编号结论（结点编号 i 从 1 开始）
```
i > 1：父结点 = ⌊i/2⌋；i = 1 是根结点
2*i   > n → i 无左孩子；否则左孩子编号 = 2*i
2*i+1 > n → i 无右孩子；否则右孩子编号 = 2*i+1
```

### 操作复杂度
| 操作 | 含义 | 复杂度 |
|------|------|--------|
| getMin | 取堆顶 | O(1) |
| removeMin | 删堆顶 + 向下堆化 | O(log n) |
| insert | 末尾插入 + 向上回溯 | O(log n) |
| updateKey | 更新值后单向上浮 | O(log n) |
| delete(i) | update(i,INT_MIN) + removeMin | O(log n) |

### 操作速记
```
getMin      → return arr[0]
removeMin   → arr[0] = 最后一个元素; n--; 向下堆化(0)
insert(x)   → arr[n++] = x; 向上回溯(n-1)
update(i,v) → v < arr[i]：arr[i]=v 后向上回溯；v > arr[i]：向下堆化
delete(i)   → updateKey(i, INT_MIN); removeMin()
```

### 代码模板（通用写法，本章无配套代码）
```c
/* 向下堆化：小顶堆，对下标 i 的子树 */
void siftDown(int arr[], int n, int i) {
    while (1) {
        int l = 2*i + 1, r = 2*i + 2, smallest = i;
        if (l < n && arr[l] < arr[smallest]) smallest = l;
        if (r < n && arr[r] < arr[smallest]) smallest = r;
        if (smallest == i) break;        /* 到叶子或已满足堆序 */
        /* swap(arr[i], arr[smallest]) */
        int t = arr[i]; arr[i] = arr[smallest]; arr[smallest] = t;
        i = smallest;                    /* 继续向下 */
    }
}
/* 向上回溯：新值变小后从 i 出发 */
void siftUp(int arr[], int i) {
    while (i > 0) {
        int p = (i - 1) / 2;
        if (arr[i] >= arr[p]) break;     /* 不小于父结点，停止 */
        int t = arr[i]; arr[i] = arr[p]; arr[p] = t;
        i = p;                           /* 继续向上 */
    }
}
```

### 应用一览
```
一、堆排序 Heap Sort
二、优先队列 Priority Queue      —— 二叉堆实现的高效优先队列
三、图算法 Graph Algorithms      —— Dijkstra（迪杰斯特拉）、Prim（普里姆）
变体：二项式堆、斐波那契堆（有余力再学）
```
