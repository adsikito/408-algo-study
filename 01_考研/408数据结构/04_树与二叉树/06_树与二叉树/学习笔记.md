## 第六章：树与二叉树

> 课件来源：`树、二叉树、线索二叉树.pdf`、`树、二叉树和森林的转换.pdf`、`树的存储方式代码\`、`二叉树的存储方式代码\`、`二叉树的遍历代码\`、`二叉树深度遍历代码-非递归\`、`二叉树的线索化代码\`
>
> 本章主线：树是"一对多"的递归结构 → 二叉树是"左右有序、最多两子"的特例 → 遍历是全章操作的核心 → 线索化把 n+1 个空指针变废为宝。

## 🗺️ 本章地图

本章解决一个问题：怎样把"一对多"的层级关系放进计算机并高效访问。路线是：先认识树与二叉树长什么样（1-3）→ 用五条性质把结点数量关系变成公式（4）→ 选好存储结构（5）→ 遍历把树压成线性序列，是一切操作的地基（6）→ 非递归遍历与重构是遍历的正反两面（7）→ 线索化把遍历结论提前存进空指针（8）→ 树/森林与二叉树互转，让普通树也搭上二叉树算法的快车（9）。先定义、再性质、后操作：不懂定义谈不上性质，不懂遍历就理解不了线索化与重构。

## 📌 本章重点（3-5个）

⭐ **树的递归定义**：n(n≥0) 个结点的有限集合，有且仅有一个根，其余分为 m 个互不相交的子树——"树中还有树"
⭐ **二叉树的性质**：第 i 层最多 2^(i-1) 个结点；深度 k 至多 2^k-1 个；**n0 = n2 + 1**；完全二叉树深度 ⌊log2N⌋+1；编号满足 [i/2, i, 2i, 2i+1]
⭐ **三种遍历（先序/中序/后序）**：递归三段式，区别只在"访问根"的位置；层次遍历用队列
⭐ **遍历序列重构二叉树**：先序/后序定根，中序分左右，必须要有中序才能唯一重构
⭐ **线索二叉树**：n 结点二叉链表有 n+1 个空指针，利用空指针存前驱后继，加 ltag/rtag 区分孩子与线索

## 🔥 本章难点（2-3个）

🔥 **非递归遍历（尤其后序）**：借助栈，先序/中序一个模板；后序必须引入 pre 记录"最后访问的结点"，判断右子树是否已访问过
🔥 **中序线索化与找前驱后继**：Visit 时同时处理"p 的前驱线索"和"pre 的后继线索"；有孩子的结点找前驱 = 左子树最靠右结点、找后继 = 右子树最靠左结点
🔥 **树/森林与二叉树的相互转换**：加线（兄弟连线）→ 去线（只留第一孩子）→ 旋转；本质就是"孩子兄弟表示法"的图形化

## ⚠️ 本章易错点（3-5个）

⚠️ **结点的度与树的度混淆**：结点的度 = 该结点的子树个数；树的度 = 所有结点度的**最大值**（示例树中 A 的度为 3，树的度也是 3）
⚠️ **满二叉树与完全二叉树搞反**：满二叉树是"全满"（2^k-1 个结点），完全二叉树是"按层序编号与满二叉树 1~n 一一对应"；满二叉树是特殊的完全二叉树
⚠️ **性质记错方向**：是 n0 = n2 **+ 1**（叶结点比度为 2 的结点多一个），由 n=n0+n1+n2 与 n=n1+2n2+1 联立推出，别记成减 1
⚠️ **深度公式忘记取整**：完全二叉树深度 = ⌊log2N⌋ + 1（或 ⌈log2(N+1)⌉，此处是向上取整）；两个公式一个向下取整、一个向上取整，不能混写
⚠️ **遍历顺序写反 / 线索标志位弄混**：中序是"左根右"不是"根左右"；线索链表中 flag==0 指孩子、==1 指线索，Find 时必须判断 flag 否则会顺着线索走进死循环

## 📖 知识点讲解

### 1. 树的定义与核心术语

**是什么**：先一句话点破：树就是"一拖多"的族谱——一个根带一群孩子，每个孩子又各带一摊，一层层展开，所以元素之间天然是"一对多"。严格定义：树（Tree）是 n(n≥0) 个结点的有限集合 T，满足两个条件：①有且仅有一个特定的称为**根（Root）**的结点；②其余结点可分为 m(m≥0) 个互不相交的有限集合 T1、T2、……、Tm，每个集合又是一棵树，称为根的**子树（Subtree）**。树的定义具有**递归性**——"树中还有树"（递归：结构或算法"自己套自己"，这个词贯穿全章）。集合中的元素关系呈现**一对多**的情况。

**为什么**：递归定义决定了树的所有算法（查找、遍历、插入）都可以用"处理根 + 递归处理每棵子树"的框架实现；理解术语是读懂一切树题目前提。

**怎么用**——核心术语背牢（课件示例树 A~M）：
| 术语 | 含义 | 示例树中的值 |
|------|------|-------------|
| 结点 | 树中每个数据元素 | A、B、C…… |
| 根结点 | 没有前驱的特殊结点 | A |
| 双亲/孩子/兄弟 | A 是 BCD 的双亲；BCD 是 A 的孩子；BCD 互为兄弟 | B、C、D 互为兄弟 |
| 叶子结点 | 没有任何子结点的结点 | K L F G M I J |
| 结点的度 | 该结点拥有的子树个数 | A 的度 3，B 的度 2，M 的度 0 |
| 树的度 | 各结点度的最大值 | 3 |
| 深度/高度 | 根为第一层，逐层往下数 | 4 |
| 祖先/子孙 | A 是 F 的祖先（沿路径向上） | F 是 K 的叔叔结点 |

跟着算——用课件示例树把术语走一遍：
```text
A
├─ B：孩子 E、F（E 的孩子 K、L）
├─ C：孩子 G
└─ D：孩子 H、I、J（H 的孩子 M）
```
第1步：找根——没有双亲的结点只有 A，它就是根。
第2步：数叶子——K、L、F、G、M、I、J 都没有孩子，共 7 个叶子。
第3步：算树的度——A 的度为 3、D 的度为 3，其余都更小，取最大值得树的度 = 3。
第4步：体会递归性——把 B 连同 E、F、K、L 单独拎出来，仍是一棵以 B 为根的完整的树，这就是"树中还有树"。

> ⚠️ 注意事项：n=0 为空树；树的度看"最大"不看"根"；层数从 1 数起不是从 0。
> 🎯 规律：一切术语都从"父子关系"这一种连接推出来——找叶子看"有无孩子"、算度数"孩子个数"、找祖先沿父链上爬。
> 💡 一句话总结：树中还有树，一对多结构。

### 2. 树的三种存储结构

**是什么**：先一句话点破：三种存储的差别就一句话——每个结点"记的是谁"。双亲表示法人人记"我爸是谁"，孩子表示法人人记"我孩子都有谁"，孩子兄弟表示法人人只记两件事"我第一个孩子是谁、我右边兄弟是谁"。具体定义：
- **双亲表示法**：顺序表（数组）存储，每个元素 = 数据 + 双亲下标（双亲就是父结点）；根结点双亲域置 **-1**
- **孩子表示法**："顺序表 + 链表"组合（链表：用指针把结点串成串）：数组依次存各结点，每个结点挂一条孩子链表（把它的所有孩子串起来），存孩子 在数组中的下标；叶子结点链表为空
- **孩子兄弟表示法**：整棵树用二叉链表存储，结点三部分：**孩子指针域 | 数据域 | 兄弟指针域**（firstchild 找第一个孩子，nextsibling 找右边相邻兄弟）

**为什么**：三种结构各有侧重——双亲表示法找父结点 O(1) 但找孩子要遍历全表；孩子表示法恰好相反，找孩子快、找父慢；孩子兄弟表示法把普通树转成了二叉链表，能用二叉树的一整套算法处理普通树。两者还可以合二为一（数组元素带双亲下标 + 孩子链表头）。

**怎么用**（孩子兄弟表示法插入，代码核心）：
```c
typedef struct Node {
    int data;
    struct Node* ch;   // 保存长子（第一个孩子）的地址
    struct Node* bro;  // 保存右边相邻亲兄弟的地址
} Node;
// 插入 x（父亲fx）：fx 无长子则 s 做长子；否则沿 bro 走到最右兄弟挂尾部
if (f->ch == NULL) f->ch = s;
else {
    Node* p = f->ch;
    while (p->bro != NULL) p = p->bro;
    p->bro = s;
}
```

跟着算——用小树 A(B(E,F), C) 把三种存储各摆一遍：
```text
树：A 的孩子是 B、C；B 的孩子是 E、F

双亲表示法（记父）：           孩子表示法（记子）：
下标  0   1   2   3   4        下标 data  孩子链表
data A   B   C   E   F         0    A    →1 →2 ∧
父   -1   0   0   1   1        1    B    →3 →4 ∧
                               2    C    ∧
                               3    E    ∧
                               4    F    ∧

孩子兄弟表示法（记第一孩子 + 右兄弟）：
A: ch=B, bro=NULL
B: ch=E, bro=C            ← C 是 B 的右兄弟，也记在 B 身上
E: ch=NULL, bro=F
F: ch=NULL, bro=NULL
C: ch=NULL, bro=NULL
```
第1步：双亲表示法找 E 的双亲——读 parent[3] = 1，一步定位 B，O(1)。
第2步：双亲表示法找 B 的孩子——只能从头扫全表，看谁的 parent == 1，扫出 E、F，慢。
第3步：孩子表示法找 A 的孩子——沿 A 的链表直接读出下标 1、2（即 B、C），快。
第4步：孩子兄弟法找 B 的所有孩子——先 ch 找长子 E，再沿 bro 走到 F，F->bro 为空即停。

| 对比 | 双亲表示法 | 孩子表示法 |
|------|-----------|-----------|
| 结构 | 数组：data + parent下标 | 数组 + 孩子链表 |
| 找双亲 | O(1) 直接读 parent | 慢，要遍历所有链表 |
| 找孩子 | 慢，遍历整个表 | 快，沿孩子链表走 |
| 根的表示 | parent = -1 | 链表为空 |

> ⚠️ 注意事项：孩子兄弟表示法中，找结点 x 的所有孩子 = 先 `p = Find(x)->ch` 找长子，再沿 `p = p->bro` 一路向右。
> 🎯 规律：找谁快不快，看结构里"记没记谁"——记了父则查父 O(1)，记了子则查子快。
> 💡 一句话总结：双亲查父易，孩子查子快。

### 3. 二叉树的定义、五种形态与满/完全二叉树

**是什么**：先一句话点破：二叉树是"每个结点最多两个孩子、且左右是身份不能互换"的树——哪怕只有一个孩子，也必须交代清它是左孩子还是右孩子。严格定义：二叉树是每个结点**最多有两棵子树**的树结构，不允许存在度大于 2 的结点，且左右子树**有序**（不能交换）。五种最基本形态：①空二叉树；②仅有根结点；③根只有左子树；④根只有右子树（只有左子树或只有右子树的又叫**斜树**）；⑤左右子树俱全。

- **满二叉树**：所有分支结点都存在左子树和右子树，且所有叶结点都在同一层；即深度为 k 且有 **2^k − 1** 个结点（k≥1）
- **完全二叉树**：深度为 k、有 n 个结点，各结点能与深度为 k 的满二叉树层序编号 1~n **一一对应**

**为什么**：完全二叉树的"编号对应"性质让它可以无缝映射进数组（顺序存储、堆的基础），是考察频率最高的模型。

**怎么用**——完全二叉树特点：
- 所有叶结点只出现在第 k 层或第 k−1 层
- 若某结点右子树的最大层次为 i，则其左子树的最大层次为 i 或 i+1

跟着算——两棵 6 结点的树判一判（第1步编号、第2步对号）：
```text
候选1：                候选2：
      1                     1
    /   \                 /   \
   2     3               2     3
  / \   /               / \     \
 4   5 6               4   5     7
```
第1步：给候选1 按层序（从上到下、从左到右）编号 1~6，与满二叉树前 6 个编号一一对应，不缺不跳 → 是完全二叉树。
第2步：给候选2 编号：第 3 层最左的位置空着、右边却站着结点——相当于 6 号位缺、7 号位有，"跳号"了 → 不是完全二叉树。

| 对比 | 满二叉树 | 完全二叉树 |
|------|---------|-----------|
| 结点数 | 恰好 2^k − 1（全满） | 任意 n，编号对齐满二叉树 |
| 叶子位置 | 全部在最底层 | 在第 k 或 k−1 层 |
| 关系 | 特殊的完全二叉树 | 更一般，"缺右下角" |

> ⚠️ 注意事项：二叉树 ≠ 度为 2 的树——二叉树可以为空、左右子树有序；而度为 2 的树必须有结点且无左右之分。
> 🎯 规律：判完全二叉树只查一件事——层序编号连续不跳号，缺也只能缺编号末尾（右下角）。
> 💡 一句话总结：最多两子，左右有序。

### 4. 二叉树的五条性质（必背）

**是什么**：先一句话点破：这五条性质全是从"满二叉树每层翻倍"里数出来的账，考场最常用的是性质 3——不用一层层数就能算出叶子有多少。逐条列出：
1. **性质1**：第 i 层最多 **2^(i−1)** 个结点（i≥1）
2. **性质2**：深度为 k 的二叉树至多 **2^k − 1** 个结点
3. **性质3**：叶结点数比度为 2 的结点数**多一个**：**n0 = n2 + 1**
4. **性质4**：N 个结点的完全二叉树深度为 **⌊log2N⌋ + 1**（向下取整）
5. **性质5**：n 个结点的完全二叉树按层序编号（从上到下、从左到右依次编号），对任意结点 i 满足 **[i/2, i, 2i, 2i+1]** 规则：双亲 ⌊i/2⌋，左孩子 2i，右孩子 2i+1

**为什么**：性质 3 推导（课件原版）——
a. 总结点数为各类结点之和：n = n0 + n1 + n2
b. 总结点数为所有子结点数加一：n = n1 + 2·n2 + 1
两式相减得 **n0 = n2 + 1**。
性质 4 推导——树高 h 有 2^(h−1) ≤ n < 2^h，取对数得 h−1 ≤ log2n < h，故 h = ⌊log2n⌋ + 1（等价写法 ⌈log2(n+1)⌉，验证 n=5：⌊log2 5⌋+1=3，⌈log2 6⌉=3 ✓）。

**怎么用**：
```text
已知 n0 = 5，求 n2？        → n2 = n0 - 1 = 4
n 个结点完全二叉树的高度？   → ⌊log2N⌋ + 1
第 6 层最多几个结点？        → 2^(6-1) = 32
深度为 4 的二叉树最多结点？  → 2^4 - 1 = 15
```

跟着算——拿一棵 5 结点的完全二叉树把五条性质全部验证一遍：
```text
      1            结点标号 = 它的层序编号
     / \
    2   3          叶子：3、4、5 → n0 = 3
   / \             度1：无       → n1 = 0
  4   5            度2：1、2     → n2 = 2
```
第1步（性质1）：第 1 层 1 个 = 2^0；第 2 层 2 个 = 2^1；第 3 层实际 2 个 ≤ 上限 2^2 = 4 ✓。
第2步（性质2）：深度 3 的上限是 2^3 − 1 = 7，实际 5 ≤ 7 ✓。
第3步（性质3）：n0 = 3，n2 = 2，3 = 2 + 1，n0 = n2 + 1 成立（此时 n1 = 0，正好印证性质 3 与 n1 无关）。
第4步（性质4）：⌊log2 5⌋ + 1 = 2 + 1 = 3，与实际深度一致 ✓。
第5步（性质5）：结点 2 的双亲 ⌊2/2⌋ = 1 ✓；结点 2 的孩子是 2×2 = 4 和 2×2+1 = 5 ✓。

> ⚠️ 注意事项：性质 1、2 是"最多"，实际可以更少；性质 3 与 n1 无关，n1 是 0 还是 1 都不影响结论。
> 🎯 规律：数结点先想"每层翻倍"，求叶子直接代 n0 = n2 + 1，别一层层数。
> 💡 一句话总结：叶结点比度2结点多一个。

### 5. 二叉树的存储：顺序存储与链式存储

**是什么**：先一句话点破：顺序存储像"按编号分宿舍"——完全二叉树人人有编号，直接住进数组的对应格子，靠编号公式串门；链式存储像"各自租房靠指针联系"，一家一个地址。具体定义：
- **顺序存储**：按完全二叉树编号存入数组（根存 data[1]），依靠性质 5 的下标规则找双亲和孩子；普通二叉树要"补成完全二叉树"再存，空结点占位
- **链式存储**：每个结点定义**一个数据域 + 两个指针域**（l、r），可再加 fa 指向双亲

**为什么**：顺序存储对完全二叉树零浪费、随机访问快；但对普通二叉树要补虚结点，最坏（单支斜树）深度 k 只存 k 个有效结点却要占 2^k−1 的空间——**浪费空间**。链式存储按需 malloc，大小恰好 n 个结点，是通用选择。

**怎么用**：
```c
// 顺序存储：根存 data[1]
data[fxi * 2]     = x;  // flag==0，x 是 fx 的左孩子
data[fxi * 2 + 1] = x;  // flag==1，x 是 fx 的右孩子
// i 的双亲 data[i/2]（i/2==0 说明 i 是根）；孩子 data[2i]、data[2i+1]

// 链式存储
typedef struct Node {
    char data;
    struct Node* l;   // 指向左孩子
    struct Node* r;   // 指向右孩子
    struct Node* fa;  // 可选：指向双亲
} BTNode, *BTree;
```

跟着算——把上面那棵 5 结点完全二叉树存进数组（结点 A~E 对应编号 1~5）：
```text
下标:  1  2  3  4  5
data:  A  B  C  D  E
```
第1步：根 A 存 data[1]。
第2步：B 是 A 的左孩子 → 2×1 = 2 号位；C 是 A 的右孩子 → 2×1+1 = 3 号位。
第3步：D、E 是 B 的孩子 → 2×2 = 4、2×2+1 = 5 号位。
第4步：反查也成立——E 在 5 号位，双亲是 ⌊5/2⌋ = 2 号位即 B。
普通二叉树就没这么幸运了（斜树浪费演示）：
```text
A 存 1 号位           数组（深度 3 需 2^3−1 = 7 格）:
 \                    [A][ ][B][ ][ ][ ][C]
  B 存 3 号位             ↑ 中间全是虚结点占位：
   \                      3 个结点吃掉 7 格
    C 存 7 号位
```

> ⚠️ 注意事项：数组要先初始化（如全填空格）避免补位虚结点干扰；下标从 1 开始起算，从 0 开始则 2i/2i+1 规则失效。
> 🎯 规律：顺序存储的全部本领来自"2i 与 2i+1"编号公式——树越"完全"越划算，越斜越亏。
> 💡 一句话总结：顺序靠下标公式，链式靠指针。

### 6. 二叉树的遍历：层次遍历与三种深度遍历

**是什么**：先一句话点破：遍历就是把一棵树"压扁"成一条线性序列的方案——根排在最前、中间还是最后，就是先序、中序、后序的全部区别。遍历 = 沿某条搜索路径周游二叉树，对每个结点访问**一次且仅访问一次**。线性结构只有一条搜索路径无需讨论；二叉树是非线性结构，两条路线：
- **按层次（广度遍历）**：引入队列（先进先出：先来的先走，像排队）——根结点入队 → 取出队头访问，将其所有孩子入队 → 重复直到队列为空
- **按深度**：一条道走到黑，再返回走另一条道。按"访问根"的位置分三种：
  - **先序遍历**：根 → 左子树 → 右子树
  - **中序遍历**：左子树 → 根 → 右子树
  - **后序遍历**：左子树 → 右子树 → 根

**为什么**：递归遍历成立的依据是树的递归定义——递归就是函数直接或间接调用自身，**所有被调用的函数都将创建一个副本，各为调用者服务**；递归函数需两要素：**边界条件**（递归出口，防死循环）+ **递归条件**（递归体，大问题拆小问题）。

**怎么用**（课件示例树，记法 A(B(-,C(D,-)), E(-,F(G(H,K),-)))，`-` 表示空孩子）：
```text
        A
      /   \
     B     E
      \     \
       C     F
      /     / \
     D     G   -
          / \
         H   K

先序：A B C D E F G H K    （根在最前）
中序：B D C A E H G K F    （根在中间）
后序：D C B H K G F E A    （根在最后）
```
```c
// 三种遍历只差"访问根"的位置（二叉树的遍历代码.c）
void PreOrderBT(BTree root) {
    if (root == NULL) return;      // 边界条件：递归出口
    printf("%c ", root->data);     // 1.访问根结点
    PreOrderBT(root->l);           // 2.先序遍历左子树
    PreOrderBT(root->r);           // 3.先序遍历右子树
}
// 层次遍历：队列，出队访问、左右孩子入队
void LevelOrderBT(BTree root) {
    enqueue(root->data);
    while (队不空) {
        x = dequeue();  printf("%c ", x);
        if (p->l) enqueue(p->l->data);
        if (p->r) enqueue(p->r->data);
    }
}
```

跟着算——用一棵 5 结点小树手算四种遍历（先盯中序，其余同理）：
```text
      A
     / \
    B   C
   / \
  D   E
```
中序（左根右）：
第1步：规则是"先掏空左边再轮到根"。从 A 一路钻左：A → B → D，D 没有左孩子 → 访问 D。
第2步：退回 B → 访问 B；再访问 B 的右子树 E。
第3步：B 这棵左子树掏空了，轮到根 A → 访问 A。
第4步：最后访问 A 的右子树 C。→ 序列 **D B E A C**
先序（根左右）：一进门先访问 A，再递归左子树（B、D、E），最后递归右子树（C）→ **A B D E C**
后序（左右根）：左子树掏完（D、E、B），右子树掏完（C），全场最后才轮到根 A → **D E B C A**
层次遍历（队列）：
第1步：A 入队；出队访问 A，孩子 B、C 入队（队列：B C）。
第2步：B 出队访问，孩子 D、E 入队（队列：C D E）。
第3步：C、D、E 依次出队访问，队空结束 → **A B C D E**

| 遍历 | 口诀 | 根的位置 | 首个访问结点 |
|------|------|---------|-------------|
| 先序 | 根左右 | 最前 | 根 |
| 中序 | 左根右 | 中间 | 最左下结点 |
| 后序 | 左右根 | 最后 | 最左叶子 |

> ⚠️ 注意事项：先中后序的差别只是 printf 那一行的位置；递归出口是 `root == NULL`，漏写就死循环。
> 🎯 规律：三种深度序里"左永远先于右"，差别只是根在第几棒出场；层次序则严格按层推进。
> 💡 一句话总结：根的位置定先中后。

### 7. 非递归遍历与遍历序列重构二叉树

**是什么**：先一句话点破：递归遍历是系统帮你记回头路，非递归就是自己拿栈（后进先出的暂存结构，像叠盘子，最后放的最先取）记；而重构是遍历的逆操作——把序列当"指纹"，把树重新拼回去。递归遍历依赖系统栈，可手动用栈改写为非递归：
- **先序/中序非递归**（同一模板）：p 非空 → （先序先 Visit）p 入栈、p = p->l 一路向左；p 为空 → 出栈栈顶 f，（中序此时 Visit f）p = f->r 转右子树
- **后序非递归**：多一个 **pre 指针记录最后访问的结点**。p 为空时先 Get 栈顶 f（不出栈）：若 f 有右子树且 `pre != f->r`，则转入右子树；否则出栈访问 f 并 `pre = f`
- **重构二叉树**：先序（或后序）**定根**，中序**分左右子树**，递归切分即可还原唯一的树

**为什么**：先/中序模板中"入栈"就是记住"回头路"；后序必须保证右子树访问完才能弹根，仅凭栈顶无法区分"右子树没访问过"还是"刚访问完"，所以用 pre 标记。

**怎么用**（非递归后序核心 + 重构例题）：
```c
// 后序非递归（二叉树遍历-非递归.c）
f = Get(top);                    // 看栈顶但不出栈
if (f->r != NULL && pre != f->r)
    p = f->r;                    // 右子树存在且未访问 → 先访问右子树
else {
    f = Pop(top);  Visit(f);     // 右子树为空或已访问 → 访问栈顶
    pre = f;                     // pre 记录最后访问的结点
}
```
课件例题：
1. 前序 abdgcef + 中序 dgbaechf → 后序 **gdbehfca**
2. 中序 BDCEAFHG + 后序 DECBHGFA → 画出二叉树：A 为根，B 在左、F 在右；C 是 B 的右孩子，D、E 是 C 的左右孩子；G 是 F 的右孩子，H 是 G 的左孩子

跟着算——把课件例 1 拆成四步（先序 abdgcef + 中序 dgbaechf）：
第1步：先序第一个字母 a 定根；到中序里把序列切成 左"dgb"｜根a｜右"echf"。
第2步：处理左半：先序"bdg"的首字母 b 是根；中序"dgb"切成 左"dg"｜b｜右空。"dg"里先序首字母 d 是根、中序 g 排在 d 后面 → g 是 d 的右孩子。
第3步：处理右半：先序"cef"的首字母 c 是根；中序"echf"切成 左"e"｜c｜右"hf"；"hf"里 h 是根、f 排在 h 后面 → f 是 h 的右孩子。
第4步：拼后序 = 左子树后序(g d b) + 右子树后序(e f h c) + 根 a = **gdbehfca** ✓
```text
重构出的树：
        a
      /   \
     b     c
    /     / \
   d     e   h
    \         \
     g         f
```

> ⚠️ 注意事项：重构必须要有**中序**序列——只有先序+后序无法区分左右子树（如 "AB" 与 "BA" 两种都成立）；课件例 2 说明：中序+后序同样可以唯一重构。
> 🎯 规律：重构 = 先序（或后序）定根、中序切左右，再对每一半重复同样动作。
> 💡 一句话总结：先序后序定根，中序分左右。

### 8. 线索二叉树

**是什么**：先一句话点破：二叉链表近半指针域是空的（n+1 个），线索化就是让这些空指针"再就业"——直接指向遍历中的上一位和下一位，相当于给树装上双向链表式的跳转链接。n 个结点的二叉链表共有 2n 个指针域，有效分支只有 n−1 条，故有 **2n − (n−1) = n+1 个空指针域**。线索化 = 利用空指针存前驱后继（前驱/后继：某种遍历序列里排在它前一个/后一个的结点）：
- 左子树为空 → 左孩子指针指向**前驱**
- 右子树为空 → 右孩子指针指向**后继**
- 指向前驱后继的指针称为**线索**；按某种次序遍历并添加线索的过程叫**线索化**
- 为区分指针指孩子还是线索，加标志位：**ltag 为 0 指左孩子、为 1 指前驱；rtag 为 0 指右孩子、为 1 指后继**，结点结构 `[lTag | left | data | right | rTag]`

**为什么**：中序遍历结果为 DBEAC 的树中，A 的前驱是 E、后继是 C——这种关系本是遍历完成后才知道的；建树时就记录下来，以后找前驱后继**无需再从根开始遍历**。线索化之后既不用系统栈也不用辅助队列，可"像遍历数组一样遍历"；数据量越大，性能提升越明显。

**怎么用**（中序线索化，代码核心）：遍历时设 **pre 时刻指向当前访问结点的前一个结点**，Visit(p) 同时干两件事：
```c
void Visit(BTNode* p) {
    if (p->l == NULL) {        // p 没左孩子 → 加前驱线索
        p->l = pre;  p->lflag = 1;
    }
    if (pre != NULL && pre->r == NULL) {  // pre 没右孩子 → 给 pre 加后继线索
        pre->r = p;  pre->rflag = 1;
    }
    pre = p;
}
// 找 p 的中序前驱：lflag==1 直接取 p->l；
// 否则 p 有左孩子 → 前驱 = 左子树中最靠右的结点
BTNode* q = p->l;
while (q->r != NULL && q->rflag == 0) q = q->r;
// 找后继对称：rflag==1 直接取 p->r；否则 = 右子树中最靠左的结点
```

跟着算——把 5 结点小树中序线索化（中序序列 D B E A C）：
```text
      A
     / \
    B   C
   / \
  D   E
```
第1步：访问 D：D 无左孩子 → 左指针挂前驱线索（此前还没访问过结点，暂为空）；pre 为空，不用给谁补后继。pre = D。
第2步：访问 B：B 有左孩子，不加线索；但 pre=D 没有右孩子 → D 的右指针改指后继 B，D.rtag = 1。pre = B。
第3步：访问 E：E 无左孩子 → 左指针指前驱 B，E.ltag = 1；pre=B 有右孩子，不动。pre = E。
第4步：访问 A：A 有左孩子不动；pre=E 没有右孩子 → E 的右指针改指后继 A，E.rtag = 1。pre = A。
第5步：访问 C：C 无左孩子 → 左指针指前驱 A，C.ltag = 1。遍历结束，C 是最后一个结点，无后继，右指针保持空。
核对：5 个结点共 10 个指针域，有效分支 4 条 → 6 个空指针里 4 个被改成线索（D.r→B、E.l→B、E.r→A、C.l→A），D 的左、C 的右仍为空。

> ⚠️ 注意事项：flag==0 是孩子、==1 是线索；Find 递归时必须判 `lflag/rflag == 0` 才能顺着孩子走，否则会沿线索走进环。线索化后的"最后一个结点"的 r 线索通常为空（无后继）。
> 🎯 规律：线索化就是把遍历"顺路"做完——Visit 当前结点时，顺手把空指针接上前驱后继。
> 💡 一句话总结：空指针存线索，前后继直达。

### 9. 树、森林与二叉树的相互转换

**是什么**：先一句话点破：转换不是新发明，它就是孩子兄弟表示法的画图版——每个结点只认"第一个孩子"和"右边的兄弟"，认亲规则一改，普通树自然长成二叉树的模样。树 → 二叉树三步：
1. **加线**：在所有兄弟结点之间加一条连线
2. **去线**：每个结点只保留与第一孩子的连线，删除与其他孩子的连线
3. **层次调整**：以根结点为轴心，整棵树顺时针旋转一定角度，使层次分明

（森林 → 二叉树三步）：①把每棵树都转换为二叉树；②第一棵不动，从第二棵起，依次把后一棵二叉树的根作为前一棵二叉树**根的右孩子**连线；③层次调整。

（二叉树 → 树/森林，逆过程）：①若结点 x 是双亲 y 的左孩子，则把 x 的右孩子、右孩子的右孩子……都与 y 连线；②去掉所有双亲到右孩子的连线；③调整位置。

**为什么**：转换的本质就是**孩子兄弟表示法**的图形化——"第一孩子"转成左孩子、"右兄弟"转成右孩子（左孩子右兄弟）。判断转换结果：**看二叉树的根结点有没有右孩子——有右孩子就是森林，没有就是一棵树**。

**怎么用**（记忆图形流程）：
```text
普通树A(B,E,F / C,G / D,H,I,J):
  兄弟连线 B-C-D、E-F、H-I-J
  去线只留 A-B、B-E、C-G、D-H
  旋转 → A 的左孩子 B，B 的右孩子 C，C 的右孩子 D…
```

跟着算——把三步画出来（before / after）：
```text
转换前（普通树）：            转换后（二叉树，左=第一孩子，右=右兄弟）：
        A                             A
      / | \                          /
     B  C  D                        B
    / \  |  /|\                    /   \
   E  F  G H I J                  E     C
                                   \   / \
                                    F G   D
                                         /
                                        H
                                         \
                                          I
                                           \
                                            J
```
对照检查：A 只认第一孩子 B → B 是 A 的左孩子；B 的右兄弟 C → C 变成 B 的右孩子；E 是 B 的第一孩子 → 左孩子，F 是 E 的右兄弟 → E 的右孩子；C 的孩子 G → 左孩子，C 的右兄弟 D → 右孩子；D 的孩子 H → 左孩子，I、J 是 H 的右兄弟 → 串成右链。与"左孩子右兄弟"逐条吻合。

> ⚠️ 注意事项：转换是**一一对应、可逆**的；兄弟链转过去的"右孩子"方向是水平的，旋转后才分层。
> 🎯 规律：所有转换都在做同一件事——把"兄弟关系"折叠成"右孩子链"，第一孩子走左边。
> 💡 一句话总结：左孩子右兄弟，转换可逆。

### 🧩 本章归纳：一条主线串全章

**一条主线**：树"一对多"没法直接线性存取 → 二叉树用"左右有序、最多两子"把结构规范化 → 五条性质把结点数量关系变成公式 → 存储结构（顺序靠编号公式、链式靠指针）决定能做什么操作 → 遍历把树压成线性序列，是一切操作的地基 → 重构是遍历的逆过程 → 线索化把遍历的结论（前驱后继）提前存进空指针 → 转换让普通树、森林也能套用二叉树这一整套算法。

**回头看才看得见的联系**：
1. **"空指针/空位"是全章暗线**：顺序存储斜树要补虚结点、二叉链表有 n+1 个空指针、线索化正是把这 n+1 个空指针变废为宝——结构留白越多，恰恰越有挖掘潜力。
2. **递归定义决定递归算法**：树的定义是递归的，所以遍历、重构、找前驱后继全都是"处理根 + 对子树做同样的事"；非递归版本只是把系统栈换成手动栈，思想一点没变。
3. **"根"是全章的钥匙**：先/中/后序差别只在根的出场时机；重构靠"先序/后序定根、中序分左右"；判断转换结果是树还是森林看根有无右孩子——抓住根，每道题都有了下手处。

## 🔍 相似概念辨析

### 组1：普通树 vs 二叉树

| 对比维度 | 普通树 | 二叉树 |
|----------|--------|--------|
| 各自定义 | n≥0 个结点的有限集合，有唯一根，其余为 m 个互不相交的子树 | 每个结点最多有两棵子树的树结构 |
| 核心区别 | 结点度数不限 | **度最多为 2**，不允许度>2 |
| 各自特点 | 子树无左右次序 | 左右子树**有序**，可含空树 |
| 使用场景 | 层级关系建模（文件系统、组织架构） | 搜索、表达式、堆等算法载体 |
| 典型示例 | A 有 B、C、D 三个孩子 | 每个结点只有 l、r 两个指针 |
| 记忆口诀 | 树多子无序，二叉左右分 |

### 组2：满二叉树 vs 完全二叉树

| 对比维度 | 满二叉树 | 完全二叉树 |
|----------|---------|-----------|
| 各自定义 | 所有分支结点都有左右子树、叶结点全在同层 | 各结点与深度为 k 的满二叉树层序编号 1~n 一一对应 |
| 核心区别 | 结点数恰好 2^k−1（全满） | 允许"缺右下角"若干结点 |
| 各自特点 | 深度 k 必有 2^k−1 个结点 | 叶子只出现在第 k 或 k−1 层 |
| 使用场景 | 理论上限计算 | 顺序存储、堆的实现载体 |
| 典型示例 | 编号 1~15 的四层树 | 编号 1~12 连续对应的树 |
| 记忆口诀 | 满树全满，完全对号入座 |

### 组3：双亲表示法 vs 孩子表示法

| 对比维度 | 双亲表示法 | 孩子表示法 |
|----------|-----------|-----------|
| 各自定义 | 数组存结点，每元素附双亲下标 | 顺序表 + 每结点挂孩子链表 |
| 核心区别 | 记"父在哪" | 记"子在哪" |
| 各自特点 | 找双亲 O(1)，找孩子要遍历全表 | 找孩子快，找双亲要遍历 |
| 使用场景 | 频繁找父结点（并查集思想） | 频繁找孩子（图的邻接表类似） |
| 典型示例 | 根结点 parent 域置 -1 | 叶子结点链表为空 |
| 记忆口诀 | 双亲记父，孩子记子，可合二为一 |

### 组4：顺序存储 vs 链式存储（二叉树）

| 对比维度 | 顺序存储 | 链式存储 |
|----------|---------|---------|
| 各自定义 | 按完全二叉树编号存数组 | 结点 = 数据域 + 左右指针域 |
| 核心区别 | 靠下标公式定位（[i/2, i, 2i, 2i+1]） | 靠指针链接定位 |
| 各自特点 | 完全二叉树零浪费、随机访问快 | 普通二叉树按需分配、无虚结点 |
| 使用场景 | 完全二叉树、堆 | 一般二叉树（斜树也不怕） |
| 典型示例 | 普通树补虚结点存数组 → 浪费空间 | n 结点恰好 n 个 BTNode |
| 记忆口诀 | 顺序怕斜树，链式怕随机 |

### 组5：广度遍历 vs 深度遍历

| 对比维度 | 广度遍历（层次遍历） | 深度遍历（先/中/后序） |
|----------|--------------------|----------------------|
| 各自定义 | 逐层从上到下、从左到右访问 | 一条道走到黑再回头的访问 |
| 核心区别 | 借助**队列**（先进先出） | 借助**栈**或递归（后进先出） |
| 各自特点 | 按层次、父子关系推进 | 先中后三种，根位置不同 |
| 使用场景 | 求树的层次/最短层距、按层打印 | 求表达式值、克隆树、序列化 |
| 典型示例 | 根入队→出队访问→孩子入队 | `根-左-右` 递归三段式 |
| 记忆口诀 | 广度用队，深度用栈 |

### 组6：孩子指针 vs 线索

| 对比维度 | 孩子指针 | 线索 |
|----------|---------|------|
| 各自定义 | 指向实际左右孩子的指针 | 空指针改指前驱/后继的指针 |
| 核心区别 | 树形结构关系 | 遍历序列的线性关系 |
| 各自特点 | ltag/rtag == 0 时有效 | ltag/rtag == 1 时有效 |
| 使用场景 | 构树、插入删除 | 快速找前驱后继、免栈遍历 |
| 典型示例 | `p->l` 指左孩子 | 左空时 `p->l = pre, lflag = 1` |
| 记忆口诀 | 0 孩子 1 线索，先看标志再走路 |

## 📋 速查表

### 性质公式速查
```
第 i 层最多结点：    2^(i-1)          (i≥1)
深度 k 最多结点：    2^k - 1
满二叉树结点数：     2^k - 1（k为深度）
n0 = n2 + 1         （叶结点 = 度2结点 + 1）
完全二叉树深度：     ⌊log2N⌋ + 1
编号规则（完全二叉树，根存1号）：
  双亲 ⌊i/2⌋   左孩子 2i   右孩子 2i+1
空指针域个数：       2n - (n-1) = n + 1
```

### 三种存储结构模板

/* 双亲表示法 */  struct Node { char data; int fa; } t[maxx];  // 根 fa=-1

### 遍历模板
```c
/* 递归三段式（只差 Visit 位置） */
void XOrder(BTree root) {
    if (root == NULL) return;      // 边界条件
    // 先序：Visit(root);
    XOrder(root->l);
    // 中序：Visit(root);
    XOrder(root->r);
    // 后序：Visit(root);
}

/* 非递归先序/中序模板 */
while (p != NULL || 栈非空) {
    if (p != NULL) {
        // 先序放 Visit(p) 在这里
        Push(p);  p = p->l;
    } else {
        f = Pop(top);
        // 中序放 Visit(f) 在这里
        p = f->r;
    }
}

/* 非递归后序：多一个 pre 记录最后访问的结点 */
f = Get(top);                       // 看栈顶不出栈
if (f->r != NULL && pre != f->r) p = f->r;
else { f = Pop(top); Visit(f); pre = f; }

/* 层次遍历：队列 */
根入队 → while(队非空){ 出队访问; 左右孩子入队 }
```

### 中序线索化模板
```c
void Visit(BTNode* p) {
    if (p->l == NULL) { p->l = pre; p->lflag = 1; }        // 前驱线索
    if (pre != NULL && pre->r == NULL) { pre->r = p; pre->rflag = 1; }  // 后继线索
    pre = p;
}
/* 找前驱：lflag==1 → p->l；否则左子树最靠右结点
   找后继：rflag==1 → p->r；否则右子树最靠左结点 */
```

### 树/森林转换口诀
```
树 → 二叉树：加线（连兄弟）→ 去线（留第一孩子）→ 顺时针旋转
森林 → 二叉树：各自转换 → 后一棵根接到前一棵根的右孩子 → 旋转
二叉树 → 树/森林：左孩子的右链全部连回双亲 → 去掉双亲到右孩子的线 → 调整
判断树还是森林：看根结点有无右孩子（有→森林，无→树）
```
