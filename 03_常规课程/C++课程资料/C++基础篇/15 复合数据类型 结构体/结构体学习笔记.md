## 1. 模块一 · 基础篇（PDF 第 4–12 页）

### 1.1 结构体概述（P4–P5｜了解）

**一句话（教材级）：** 结构体（struct）是由**相同或不同类型**的数据构成的数据集合；它可以被声明为**变量、指针或数组**，集合中的每个元素称为**成员（member）**，成员一般用名字访问。

为什么要学它？——回答课件 P4 的提问：想同时保存一个学生的学号、姓名、年龄、各科成绩，用普通变量要写 4 个散装变量，数组又只能存**同一种类型**（比如只能存成绩数组，姓名没法塞进去）。需要一个「把这些打包成一个整体」的类型，这就是结构体存在的唯一理由。

> 🗣️ **人话总结（≤20字）：** 多个不同类型的变量，打包成一个新类型。

---

### 1.2 结构体的定义和初始化（P6–P8｜重点）⭐⭐⭐

#### ① 是什么

用 `struct` 关键字**创造一个新的数据类型**（注意：定义的是类型，不是变量！），类型里规定了这个包里有哪几个格子。

#### ② 为什么

数组里的元素必须同类型；而学生这个实体天然就是「字符串姓名 ＋ 整数年龄 ＋ 小数成绩」的混合物。只有自定义类型能表达这种混合。

#### ③ 怎么用 —— 定义语法（P6）

```cpp
struct student {      // struct 关键字 + 你起的新类型名
    string name;      // 成员1：每个成员后面必须有分号！
    int    age;       // 成员2
    double score;     // 成员3
};                    // ← 大括号后面还有一个分号！两个分号都不能少，否则编译报错
```

**怎么造变量？教材给出 3 种方式（P7）：**

| 方式 | 写法 | 适用场合 |
|---|---|---|
| 1️⃣ 先定义类型，再定义变量 | `student s1, s2, s3;` | ⭐最常用，推荐 |
| 2️⃣ 定义类型的同时定义变量 | `struct student { ... } s1, s2, s3;` | 只打算在这个文件用的临时类型 |
| 3️⃣ 省略类型名的匿名定义 | `struct { ... } s1, s2;` | 只要这几个变量、以后不再需要这种类型 |

> 对应 `代码/classcode.cpp:16` 的 `};// s1, s2, s3;` ——老师用的正是**方式2**，只是先用方式1的思路讲课，把尾随变量注释掉了。方式3 在枚举里还会再见（P35）。

#### ③ 怎么用 —— 初始化方式（P8）

**两种给成员填值的办法：**

```cpp
// 办法一：逐个赋值（点运算符，下一节细讲）
struct student s1;
s1.name  = "张三";     // 逐个填格子
s1.age   = 20;
s1.score = 99.5;

// 办法二：大括号整体初始化——按成员声明的顺序依次填入
student s3 = { "王五", 19, 90 };   // "王五"→name，19→age，90→score
```

**▶ 实测输出**（复刻 `classcode.cpp:41-49` 全段放开后的效果）：

```
张三        // cout << s1.name ：逐个赋值的成果
王五        // cout << s3.name ：大括号一次性初始化的成果
赵四        // cout << s2.name ：s2 从没碰过，用的是成员默认值(见1.4)
```

#### ④ 坑在哪

1. **两个分号**：最后一个成员后面的 `;` 和右大括号后的 `;` 缺任何一个都编译不过。新手最容易忘的是**大括号后的那个**。
2. ❗（本机踩坑实录）你的教材结构体用了**成员默认值**（见 1.4），在这样的源文件里：
   - 用 `g++ -std=c++11` 编译 `student s3 = { "王五",19,90 };` 会报错：
     `error: could not convert '{...}' from '<brace-enclosed initializer list>' to 'student'`
   - 原因：C++11 标准规定**带默认成员初始值的结构体不算聚合类**，不能用大括号整体初始化；**C++14 起才恢复允许**。换成 `-std=c++14`（Visual Studio 2019 之后默认就是这么编的）立即通过。
   - 所以：同一个知识点， Compiler 差异决定生死——记住这个报错长什么样，将来遇到就知道调标准。
3. 中英文标点：课件上的 `{“张三”，20，99.5}` 用了**全角引号逗号**，那是印刷体的引号，抄到代码里必须改成半角 `"张三", 20, 99.5`，否则满屏报错。PPT 正文的中文标点是渲染问题，**真正执行时永远是英文半角符号**。

> 🗣️ **人话总结：** 先造类型再造变量；两个分号，顺序填值。

### 1.3 结构体成员访问（P9｜重点）⭐⭐

#### ① 是什么

读/写某个具体格子的动作叫成员访问，语法：

```
结构体变量名 . 成员名
```

`.` 是**点运算符**，它的优先级很高，排在几乎所有运算符前面（这正是后面 `(*p)` 要加括号的根源）。

#### ② 为什么

结构体是一个「整体」，但我们日常要精确到某一项操作——查年龄只该动 age，其他成员不能被误伤。

#### ③ 怎么用（教材 P9 完整案例）

```cpp
#include <iostream>
using namespace std;
struct student {
    string name;
    int    age;
    double score;
};
int main() {
    student s1 = { "张三", 20, 99.5 };   // 大括号按顺序初始化
    cout << s1.name  << endl;            // 点运算符读出第1格
    cout << s1.age   << endl;            // 第2格
    cout << s1.score << endl;            // 第3格
    return 0;
}
```

**▶ 实测输出：**

```
张三
20
99.5
```

`classcode.cpp:43-49` 展示的是同一件事的另半边——先把 s1 挨个赋值，再用 `.` 输出（结果见上一节的「张三 王五 赵四」）。一读一写，配合记忆。

#### ④ 坑在哪

- 成员名写错不会给你「智能修正」，直接找不到标识符。
- `.` 左侧必须是**结构体变量本身**；如果手里是指针，就必须用 `->`（§2.1）——「有星箭头，无星点」。

> 🗣️ **人话总结：** 变量点什么，一格一格精准读写。

### 1.4 结构体默认值（P10）

#### ① 是什么

C++11 起，允许**在定义结构体时顺手给成员一份出厂设置**（术语叫默认成员初始化器）。之后每次创建变量，除非显式覆盖，否则自动带上这套默认值。

#### ② 为什么

没有默认值时，新变量内部的值是**垃圾值**（上一趟程序留在内存里的残渣）——用户忘了填就传出鬼数据。有了默认值，「忘记初始化」这类 bug 直接绝迹。注意 `classcode.cpp:6-9`：老师的 struct 就是三种写法混着用：

#### ③ 怎么用（三种等价写法对比）

```cpp
struct student {
    string name{ "赵四" };   // 写法①：花括号统一初始化(C++11推荐)
    int    age{ 20 };        // 写法①，int 也适用
    double score = 100;      // 写法②：老式等号，习惯C语言的人常见
    // string name = "C++";  // 写法②对string一样成立(PPT原文式样)
};
```

| 写法 | 示例 | 评语 |
|---|---|---|
| 花括号 `{ 值 }` | `int age{ 20 };` | 类内/数组通吃，防窄化转换，推荐 |
| 等号 `= 值` | `double score = 100;` | 传统写法，类的默认成员初始化器里完全合法 |

> 教材 P10 的原始三句其实是 `{ "C++" }`、`= "C++"` 两种家族的变体；核心记忆：**在成员声明后直接跟 `{"值"}` 或 `="值"` 都行**。

**▶ 实测输出**（`classcode.cpp:53-54` 放开后：新建 s1 直接调成员函数打印）：

```
赵四  20  100      // 一个成员都没赋值，凭默认值就出了完整的出厂状态
```

#### ④ 坑在哪

❗默认值会让结构体失去「C++11 聚合类」资格 → `{...}` 整体初始化报 `could not convert`（详见 1.2 的坑3，本机亲证）。团队项目里要么全体升级编译标准，要么默认值和整体初始化二选一。

> 🗣️ **人话总结：** 出厂自带数值，忘记初始化也不慌。

### 1.5 结构体中定义函数（P11–P12）

#### ① 是什么

结构体里不仅能放数据，还能**放函数**。放在里面的函数称为**成员函数**，它能直接读写本结构体的成员变量，不需要任何传参。（往这个方向走到极致，配上私有成员，就是下一阶段的**面向对象/类**——这节课先尝一口味道。）

#### ② 为什么

打印学生信息这种事，「信息」和「打印它」本来就是一体两面的能力。函数住进结构体后，任何 student 自己就会自我介绍：`s1.printInfo()`，数据和动作零距离。

#### ③ 怎么用（教材 P12 原型 + classcode.cpp:11-14 实战版）

```cpp
struct student {
    string name{ "赵四" };
    int    age{ 20 };
    double score = 100;

    void printInfo() {                       // 成员函数：不需要参数
        cout << name << "  " << age << "  " << score << endl;
        // 直接用成员名，相当于自动带了一个看不见的 s1. 前缀
    }
};
// 用法：
// student s1;
// s1.printInfo();     // 像调成员一样调用函数
```

**▶ 实测输出：**

```
赵四  20  100      // 注意 name/age/score 之间恰好是两个空格，全是函数里写的"  "
```

顺手说清所有权：`classcode.cpp` 的 `printStudent2`（§3.2）也是这样借道成员函数打印的。

#### ④ 坑在哪

- 成员函数里写的 `name` 永远指**当前那个对象自己的** name——谁调用 `printInfo()` 就打谁的信息；搞不清这一点，输出串号时排查不到病根。
- 本阶段函数体内不要试图给成员重新起相同的形参名遮蔽混淆（例如 `void setAge(int age){ age = age; }` 是错的，自赋值一场空）——正确姿势留到类那一章讲 `this`。

> 🗣️ **人话总结：** 数据和打印函数打包入住，一行调用。

## 2. 模块二 · 进阶篇（PDF 第 13–19 页）

### 2.1 结构体指针（P13–P16｜重点）⭐⭐⭐

#### ① 是什么

存放**结构体地址**的指针，就叫结构体指针。语法：

```cpp
struct 结构体名 *指针名;      // 教材写法，如 struct student *ps1;
student *ps1;                // C++里 struct 前缀可省，等价
```

#### ② 为什么

上节课你已掌握「`int* p = &a; *p = 10`」；指针换指向 int 还是换成 student，**逻辑一模一样**。需要它的三大理由：函数间传递大结构体只搬一个地址（8 字节）而不用整箱拷贝；被调函数能改主调方的原数据；将来链表、树等动态数据结构全靠它串起来。

#### ③ 怎么用 —— 访问成员的两种方式（P14 / P15）

| 方式 | 语法 | 记忆点 |
|---|---|---|
| **方式一：箭头 `->`** ⭐推荐 | `pName->field` | 「有星用箭头」，最简洁 |
| 方式二：解引用 + 点 | `(*pName).field` | **括号必须加**！ |

为什么方式二要加括号？——因为 `.` 的优先级比 `*` 高：不写括号的 `*p1.age` 会被理解成 `*(p1.age)`（先到 p1 里找 age 这个成员再解引用），而 p1 是指针、根本没有 age 成员 → 直接编译错误。加括号强行「先解引用成变量、再点成员」。

#### ③ 怎么用 —— 教材 P16 案例

```cpp
student s1;
student* ps1 = &s1;          // ps1 存的是 s1 的门牌号
ps1->name = "诸葛亮";         // 方式一：箭头写入
(*ps1).age = 20;             // 方式二：括号+点写入（与上一行效果完全相同）
cout << ps1->name   << endl; // 读也两样都行
cout << (*ps1).age << endl;
```

**▶ 实测输出：**

```
诸葛亮
20
```

再看 `classcode.cpp:58-65`（放开后实测）——默认值「赵四」打底，通过指针只改了 age：

```
赵四        // cout << ps1->name     ：名字没动，还是默认值
29          // cout << ps1->age      ：-> 改动的正是 s1 本尊，不是副本
100         // cout << (*ps1).score  ：方式二读出的默认分
```

一次实验同时验证了三件事：两种语法等价、默认值生效、**透过指针写的就是原变量本人**。

#### ④ 坑在哪

❗**野指针先绑后用**：刚定义的 `student* p;` 里是随机垃圾地址。没执行 `p = &某个真实变量;` 之前就 `p->age = 5;`，等于往陌生人家里搬家具——程序大概率崩溃或写出神秘 bug。（classcode 正确示范了 `ps1 = &s1;` 这一步。）
其他小坑：`.` 与 `->` 不通用（变量点、指针箭）；打印指针本身输出的是地址而非内容。

> 🗣️ **人话总结：** 指针存地址，箭头访问最省心。

### 2.2 结构体数组（P17–P19｜重点）⭐⭐⭐

#### ① 是什么

元素是**同一个类型的结构体**的数组。

```cpp
struct 结构体名 数组名[长度];      // 如 student arrstu[3];
```

#### ② 为什么

管理一个学生用 1.3 节的知识就够了；管理全班 50 个呢？总不能手写 50 个变量名。数组把「同一模板造出来的很多个实体」排成一列，配合 for 循环批量处理。

#### ③ 怎么用 —— 用法一：先声明，循环录入（教材 P18）

```cpp
student arrstu[3];                       // 3个student元素连排在内存里
for (int i = 0; i < 3; i++) {            // 第i个学生 = arrstu[i]，仍是普通变量 → 用 .
    cin >> arrstu[i].name >> arrstu[i].age >> arrstu[i].score;
}
for (int i = 0; i < 3; i++) {
    cout << arrstu[i].name << " " << arrstu[i].age << " " << arrstu[i].score << endl;
}
```

※运行时逐项键入（例如 `张三 20 88 ↵ 李四 21 92 ↵ …`），打印则回显你输入的三行。注意语法组合拳：`arrstu[i]` 是单个结构体变量 → 后面接 **`.`**；写成 `arrstu.name` 就错了——数组的第几号还不定，谈何姓名。

#### ③ 怎么用 —— 用法二：声明时直接初始化（教材 P19）

```cpp
student arrstu[3] = {              // 外层大括号=整个数组
    {"name1", 20, 90},             // 内层大括号=第0个学生的三个成员
    {"name2", 21, 92},             // 顺序必须与成员声明顺序一致
    {"name3", 22, 99},
};
for (int i = 0; i < 3; i++)
    cout << arrstu[i].name << " " << arrstu[i].age << " " << arrstu[i].score << endl;
```

**▶ 实测输出**（教材本例）：

```
name1 20 90
name2 21 92
name3 22 99
```

换成 classcode.cpp:91 的数据 `{李四…王五…张三…}` 时（见 §3.3），同样套路。

#### ④ 坑在哪

- 下标从 **0** 开始：长度 3 的合法下标只有 0、1、2，写 `arrstu[3]` 越界踩别的内存。
- 初始化的内层大括号**可以省**（编译器按顺序吞参数）但不建议省——省了排错时根本看不出哪组数字对应谁。
- ❗给函数传数组时「数组大小」会丢失（§3.3 坑2），这是本章第二大高频失分点。

> 🗣️ **人话总结：** 同款学生排队站好，下标点名。

## 3. 模块三 · 函数篇：结构体做函数参数（PDF 第 20–23 页｜重点）⭐⭐⭐⭐

本章核心问题只有一个：**把结构体递交给函数工作时，对方拿到的是原件还是复印件？**

### 3.1 值传递（P20–P21）

#### ① 是什么

形参写作 `void func(student s)`，调用时**把实参占的全部内存按字节拷贝一份**给形参（教材原话：「全部顺序传递给形参，形参必须是同类型的结构体变量」）。

#### ② 为什么(及代价)

拷贝保证了安全隔离——函数怎么折腾都不伤原图。但代价是开销随体积线性放大：我们的小 student 才 48 字节无所谓，等结构体大到几百上千字节（想想 §6.2 一个 teacher 就是 232 字节），每次调用都是一次「整箱搬家」。

#### ③ 怎么用（教材 P21 完整案例）

```cpp
struct student { string name{"C++"}; int age{20}; double score{99.5}; };

void printStudent(student s) {          // 形参 s 是实参的完整复印件
    cout << s.name << "\n" << s.age << "\n" << s.score << endl;
}

int main() {
    student s1 = { "王五", 21, 99 };
    printStudent(s1);                   // 整个 s1 复印进 s
    return 0;
}
```

**▶ 实测输出：**

```
王五
21
99
```

**复印件铁证**（复刻 classcode.cpp 增补对照实验，实测）：

```cpp
void addAge_copy(student s) { s.age += 1; }   // 只改自己那份
// main: student sk;  addAge_copy(sk);  cout << sk.age;
```

```
20        // 默认年龄仍是 20 —— 函数里的自增发生在复印件身上，原件纹丝不动
```

#### ④ 坑在哪
- 函数内做的修改**不会**反映到外面——想要「真改」，请走指针传递。
- 误以为形参 struct 便宜就到处用大结构体值传 → 性能陷阱。

> 🗣️ **人话总结：** 拷贝一份上班，原件毫发无损。

### 3.2 指针传递（P22）

#### ① 是什么

形参收的是地址：`void func(student* s)`。函数内部通过 `s->成员` 触达原件。

#### ② 为什么

一举两得：只搬 8 字节地址（快）；且顺着地址摸到的就是**本体**，能读也能改。

#### ③ 怎么用（教材 P22 案例，附勘误）

```cpp
void printStudentPtr(student *s) {     // 收地址
    cout << s->name  << endl           // 箭头逐格访问原件
         << s->age   << endl
         << s->score << endl;
}
// 调用时记得取址：
printStudentPtr(&s1);                    // & 不能忘！否则类型对不上
```

⚠️ **课件笔误提醒（P22）**：幻灯片定义的函数叫 `printStudent`，下面示例却调用 `printStudent2(&s1);`——名称前后不一致，照抄必然编译报错「未声明的标识符」。`classcode.cpp:22-24` 才是对的：定义 `printStudent2(student* ps)`，调用处也统一叫 printStudent2（且提供两种等价实参写法，实测均通过）：

```cpp
// void printStudent2(student* ps) { ps->printInfo(); }        ← 定义(classcode.cpp:22)
// student s1 = { "王五",21,88 }; student* ps2 = &s1;           ← 准备(classcode.cpp:84-85)
// printStudent2(ps2);   // 传现成的指针变量                     (classcode.cpp:86)
// printStudent2(&s1);   // 或现场取址，两条路完全等价            (classcode.cpp:87)
```

**▶ 实测输出（两次调用各打一行，用的是成员函数格式）：**

```
王五  21  88
王五  21  88
```

顺带巩固 §1.5：这里打印靠的就是 s1 自带的 `printInfo()` 成员函数，箭头之后照样能调。

#### ④ 坑在哪
- 忘写 `&` 把整个结构体塞过去 → 类型不匹配报错。
- ❗在函数内又对 `s` 取新地址覆写、却指望影响原变量（改的是地址本身）——指向不变才有改变原始一说。
- 空指针/野指针防御意识同 §2.1。

> 🗣️ **人话总结：** 递一张门牌，直通原件。

### 3.3 数组传递（P23）

#### ① 是什么

`void func(student arr[], int len)` —— 名义上传「数组」，实际 C++ 会把数组名自动退化为**首元素地址**，所以**本质还是指针传递**。

#### ② 为什么

循环处理一群学生是常态场景；传地址同样零拷贝、高效，并且让函数内的增删改直接作用于主调方的那片数组。

#### ③ 怎么用（教材 P23 + classcode.cpp:26-30 双版本对照）

```cpp
void printStudent3(student s[], int len) {   // len 是救命稻草，见坑2
    for (int i = 0; i < len; i++)
        s[i].printInfo();                    // s[i]是变量→点访问；也可借成员函数打印
}
int main() {
    student arrs[3] = { {"李四",20,100},{"王五",21,99},{"张三",22,91} };
    printStudent3(arrs, 3);                  // 数组名即首地址，直接裸传
    return 0;
}
```

**▶ 实测输出（实测）：**

```
李四  20  100
王五  21  99
张三  22  91
```

注意教师版更优雅：函数内循环直接调用每个元素的 `printInfo()` 成员函数，一行搞定排版（其输出与手写三字段一致，间隔两个空格）。这两条路径印证了「成员函数随对象随身携带」。

#### ④ 坑在哪
- ❗坑1（教材强调过半句的地方展开讲）：**函数内 `sizeof(arr)` 得到的不是数组字节数**，而是指针大小 8。所以长度必须作为独立参数 len 手工传入——这也是 hw_code.cpp:47 在 main 里用 `sizeof(tarray)/sizeof(tarray[0])` 先算好长度再传的原因（§6.2 细讲）。
- 坑2：既然是传址，函数对 `s[i]` 的任何修改都会永久生效——有时是功能（排序），有时是事故（无意识覆盖原始成绩）。

> 🗣️ **人话总结：** 数组传地址，长度自己捎话。

### 3.4 三种传参终极大对比（背这张表）

| 维度 | 值传递 | 指针传递 | 数组传递 |
|---|---|---|---|
| 函数头 | `void f(student s)` | `void f(student* s)` | `void f(student s[], int len)` |
| 实际传过去的是 | 全部成员的一份拷贝 | 首地址 | 首地址（数组名退化） |
| 内存开销 | 随体积增大（48B~巨大） | 固定 8 字节 | 固定 8 字节 |
| 能否改到原数据 | ❌ 不能 | ✅ 能 | ✅ 能 |
| 成员访问写法 | `s.name` 点 | `s->name` 箭头 | `s[i].name` 点 |
| 有无意外副作用风险 | 无（最安全） | 可能误改原件 | 可能误改原件 |
| 典型场景 | 只读展示小结构体 | 需改单个对象/求效率 | 批量处理N个对象 |
| `sizeof` 陷阱 | 无 | 无（就是指针） | ❌ 得到8而不是数组长度，须传len |

> 🗣️ **一句话记忆（≤20字）：** 小就值传图安全，大就用址改得动。

## 4. 模块四 · 其他复合类型（PDF 第 24–47 页）

### 4.1 共用体 / 联合体 union（P24–P29｜熟悉）

#### ① 是什么

若干成员**共用同一块内存**的特殊数据集合（也叫联合体）。语法长得和 struct 几乎一样，只是关键字换成 `union`：

```cpp
union person {
    int    age;
    double weight;
};
```

#### ② 为什么

有些场景里多个字段**天然不会同时存在**——比如某属性要么记年龄、要么记体重，二选一。既然不同时用，就没必要各占一块内存：让它们轮流占用同一块，最省地方。教材 P28 点名的两个铁律都由这条「复用」思想派生：
- 共用体占的内存 = **最长成员**占用的内存；
- **同一时刻只能保存一个成员**的值，新赋值会把旧值覆盖掉（内存覆盖技术）。

#### ③ 怎么用与内存真相（教材 P27 案例 + classcode.cpp:97-101 实测）

成员访问同样用点运算符 `p1.age`。把 classcode 的实验段放开运行：

```cpp
person p1;          // 尺寸按最大成员 double 算 = 8字节
p1.age = 20;        // 在共享内存里写入 int 20
cout << p1.age << endl;      // 正常读回
p1.weight = 50.5;   // ← 教材注释语重心长：这里一写，age 就被覆盖了！
cout << p1.age << endl;
cout << p1.weight << endl;
```

**▶ 实测输出：**

```
20           // 只写过 age=20 时读它，天经地义
0            // 写完 weight=50.5 再读 age —— 居然是 0！
50.5         // 最后写入的 weight 完好无损
```

为什么 age 是 0 而不是别的数？50.5 的二进制排进 8 字节后，低位 4 个字节恰好全是 0；而小端机器上 int age 读的正是这低 4 字节 → 0。（数值本身是巧合，但「旧值被踩烂」这个结论永远成立。）这正是教材说「共用体的成员不可以全部一起使用，只能单独使用其中某一个」的血泪注脚。

#### sizeof 一锤定音（P29 + classcode.cpp:104-111 实测）

```cpp
// student s1; person p1;
int lens = sizeof(s1);   // 结构体
int lenp = sizeof(p1);   // 共用体
cout << lens << " " << lenp << endl;
```

**▶ 实测输出（x64）：**

```
48 8      // student=48字节 vs person=8字节，差了整整6倍！
```

48 怎么来的？`string(32) + int(4) + 补空隙(4) + double(8)`——印证教材那句「结构体 ≥ 各成员之和，成员间可能存在缝隙」（这里的缝隙就是 4 字节对齐填充）。共用体则只取最大成员 double 的 8 字节。

#### 结构体 vs 共用体 对比总表

| 维度 | 结构体 struct | 共用体 union |
|---|---|---|
| 内存布局 | 各成员**各自占一块**，可能夹对齐缝隙 | 所有成员**叠在同一块**上 |
| 大小 | ≥ 成员大小之和（含缝隙），本例48B | ＝ 最长成员大小，本例8B |
| 改一个成员的影响 | 其他成员安然无恙 | 其余成员的值被覆盖/解读错乱 |
| 同一时刻可保存 | 所有成员同时有效 | 只能一个值 |
| 成员访问符号 | `.` / `->` 一样 | `.` / `->` 一样 |
| 典型用途 | 打包描述一个实体 | 省内存/硬件寄存器/多形态解读 |

#### ④ 坑在哪
- ❗给 A 成员赋过值又去读 B，不报错也不警告，拿到的是垃圾（还因字节巧合看起来"像那么回事"，最难排查）。
- classcode 里我们用的是 `double weight`，教材 P27 用的是 `float weight`——不影响结论（double 才 8 字节，union 大小都是 8）。

> 🗣️ **人话总结：** 一屋多人轮住，一次只能一位。

### 4.2 枚举类型 enum（P30–P39｜熟悉）

#### ① 是什么

用户自定义的**若干枚举常量的集合**。每个枚举常量本质上是一个有名字的整数，变量只能取表内列出的那几个名字。

```cpp
enum 类型名 { 枚举常量1, 枚举常量2, ... };
```

#### ② 为什么

函数参数收 `int status`，调用方随手传个 99 编译器不管你；换成 `enum Color c`，只能填 `Red/Green/Blue` 这几个**见名知意的合法名单**——把取值范围锁死在语义层面，靠编译器替你查错。这就是「限定取值集合」的价值。

#### ③ 怎么用

**第一步 定义类型并弄清默认值规则（P31–P32）**

```cpp
enum color { RED, BLUE, WHITE, BLACK };      // 默认按顺序 0,1,2,3
enum week  { Sun, Mon, Tue, Wed, Thu, Fri, Sat };  // Sun=0 ... Sat=6
```

- 未指定时从 **0 开始依次加1**；
- 可以给任意位置指定整数值，指定之后的仍「依次加1」，且**允许重复**（P32 官方例子）：

```cpp
enum fruit { apple, orange, banana=1, peach, grape };
// apple=0, orange=1, banana=1(重复也合法!), peach=2, grape=3

enum week { Sun=7, Mon=1, Tue, Wed, Thu, Fri, Sat };
// Sun=7, Mon=1, 之后 Tue..Sat 依次为 2,3,4,5,6
```

⚠️ 枚举常量**必须是标识符**，不能写字面量（P33 反例）：

```cpp
enum letter {'a','b','c'};          // ✅错误：字符常量
enum year   {2022,2023,2024};       // ✅错误：整数常量
enum letter {a,b,c};                // ✔️正确写法
enum year   {y2022,y2023,y2024};    // ✔️给数字套个名字
```

**第二步 定义变量（P34–P35）** —— 与结构体的三种方式同款思路：

```cpp
enum week {Sun,...,Sat};
week w1, w2;                          // 先定义类型再定义变量
enum {Sun,...,Sat} w1, w2;            // 匿名类型+变量一步到位(类型名可省)
```

**第三步 按「四允许三禁止」守则操作（P36–P39）**

| 守则 | 示例 | 后果 |
|---|---|---|
| ✅ 允许：赋表中列出的名字 | `w1 = Sun;` | 合法 |
| ✅ 允许：参与关系运算(比较本质比整数值) | `if (w1 < w2)` | 合法 |
| ✅ 允许：直接输出（打出它的整数值）/转成 int 参与+法 | `cout<<w1;` `int num=w1+w2;` | 输出整数 |
| ❌ 禁止：整型常量直接赋给枚举变量 | `w2 = 0;` | 编译报错 |
| ❌ 禁止：cin 直接输入 | `cin >> w2;` | 编译报错 |
| ❌ 禁止：不同枚举类型之间互相赋值 | `c1 = m1;`(color↔匿名型) | 编译报错 |
| 💡 惯例：输入输出都用 switch 翻译成字符串（P39/案例②） | 见 §5.2 | — |

**▶ 实测输出**（完整复刻 `classcode.cpp:114-135`，其中 `enum week{Sun=100,Mon,Tue=1,Wed,...}`）：

```
100     // cout << w1 (w1=Sun)：指定的起点值
2       // cout << w2 (w2=Wed)：Tue=1起依次加1 → Wed=2
102     // cout << w1 + w2 ：枚举拿出整数值运算
        // ⚠️ if (w1<w2) 即 100<2 为假 → 本行无任何输出，别以为漏跑了
```

被注释的三行毒药若放开分别在编译期死亡：`w2 = 0;`（❌整型赋枚举）、`cin >> w2;`（❌枚举不可输入）、`c1 = m1;`（❌跨枚举赋值；同型的 `m1 = m2;` 则没问题）。还有一句隐藏彩蛋：`int num = w1 + w2;` 能过——**枚举可以流向 int，int 不能流向枚举**，单向阀记忆法。

#### ④ 坑在哪
- 输出的是整数值不是名字（想打"星期日"？switch 或映射表伺候，案例②）。
- 用 `week w = 100;` 不行，必须 `w = Sun;`；（旧式 C 强转 `(week)100` 虽能用但在 beginners 阶段别碰，容易越界非法值）。
- 判断相等/比较时想的是「Mon 在 Tue 前」实际比较的是 1 < 2 的整数逻辑——理解了这个，第38页输出顺序就不再神秘。

> 🗣️ **人话总结：** 给一组整数起名字，取值只许点名。

### 4.3 用 typedef 定义类型（P40–P47｜熟悉）

#### ① 是什么

`typedef` 给**已存在的类型起别名**。语法骨架永远是：

```cpp
typedef  原类型   新别名;
```

别名一经诞生，**用原类型的地方全部可以换成别名**，二者完全同义。

#### ② 为什么

两大动机：①复杂类型写一遍太长（想想 `unsigned long long` / 函数指针），起短名省力可读；②兼容与迁移——底层把 `Myint` 从 int 换成 long long 时，业务代码一行不改。

#### ③ 怎么用 —— 五大用法全景表（对照 classcode.cpp 五段实测代码）

| # | 目标类型 | 写法 | 实测片段(from classcode.cpp:141-176) | ▶实测输出 |
|---|---|---|---|---|
| 1 | 基本数据类型 | `typedef int Myint;` | `myint num; num=100; cout<<num<<endl; int num2=200; cout<<num2;` | `100` 换行 `200`（末句无 endl） |
| 2 | 结构体 | `typedef struct Person P;` | `typedef student stu; stu s1; s1.name="typedef";` | `typedef` |
| 3 | 数组⭐特殊 | `typedef int C[10];` | `typedef int arr[10]; arr a; a[0]=100;` | `100` |
| 4 | 枚举类型 | `typedef week w;` | （先 `enum week{...}` 再 typedef）`w w1; w1=Sun;` | `100` |
| 5 | 指针⭐需警惕 | `typedef char* String;` | `typedef const char* str; str s="abcd";` | `abcd` |

用法 3（数组）的位置反直觉——**别名被挤在元素类型和元素个数之间**：`typedef int Arr[10]; Arr a;` 相当于 `int a[10];`。记不住时倒着想：「Arr a ⇒ a 是 int[10]」。
用法 4 的注意点已在 classcode 亲证：那个代码块里**重新定义了一遍 enum week**，所以它与其他枚举演示段不能同时放开（同名冲突），这是注释的另一重原因。

**⑤ 之深坑：const 遇上指针别名（P46 原文强调）**

```cpp
typedef char* String;
const String s1;      // 你以为＝指向常量的指针(const char*)？
                      // 实际＝char* const s1 —— 指针本身是常量！
String s2;            
s2 = s1;              // s1 不能改指向；但这行合法(s2可变)
```

原理：别名替换发生在类型整体层面，「const + 别名」修饰的是**整个别名所指的那个变量身份**。逐字面把它拆成 `const char*` 必定理解翻车。两句话背下来：**「typedef 出来的别名是铁板一块，const 加在前面动不了内部的星号结构」**。

#### ④ 坑在哪
- 数组别名的方括号位置；
- 别名重定义冲突（同一 main 里两份 enum week 不能并存——classcode 分段隔离的原因）；
- const + 指针别名的语义（上面专讲）。

> 🗣️ **人话总结：** 类型太长不好念，typedef 取个小名。

## 5. 课堂案例双打（PDF 第 48–51 页）

### 5.1 案例一：找总分最高的学生（P48–P49）⭐必考题型

#### 题目（P48 原文）

> 利用结构体，输入 n（2<n<100）个学生的姓名、年龄和三科（语文、数学、英语）成绩，找出总成绩最高的学生，输出该学生的信息。

#### 解题思路四步走

1. **建模**：一个学生 = name + age + chinese + math + english + **total**。total 虽然可由三科算出，但把它放进结构体当成员存起来，比较时直接读字段，逻辑清爽（教材设计意图）。
2. **装容器**：n 个学生 → `student s[100]`（按题目上限开够，再由 n 控制实际使用量）。
3. **边读边算**：循环读入每个学生的 5 项原始数据，当场把 total 补齐——数据入仓时就加工完毕，之后只需专心找最大。
4. **打擂台**：设擂主变量 `maxv=0`、冠军变量 `s2`；遍历数组，谁的 total 更大谁上台顶替擂主与冠军。一遍扫完，答案自然在手。

#### 教材代码逐段拆解（P49）

```cpp
#include <iostream>
using namespace std;
struct student {
    string name;
    int    age;
    double chinese, math, english, total;   // 三科+总分一起打包
} s[100];                                    // 顺手定义全局数组(方式②变体)
int main() {
    int n; double maxv = 0; student s2;     // 擂台三件套：门槛0/最优值/冠军本体
    cin >> n;
    for (int i = 0; i < n; i++) {           // 第一遍：录入+算总分
        cin >> s[i].name >> s[i].age >> s[i].chinese >> s[i].math >> s[i].english;
        s[i].total = s[i].chinese + s[i].math + s[i].english;
    }
    for (int i = 0; i < n; i++) {           // 第二遍：打擂台
        if (s[i].total > maxv) {
            maxv = s[i].total;
            s2 = s[i];                      // ⭐整结构体赋值！连姓名带年龄一并复制
        }
    }
    cout << s2.name << " " << s2.age << " " << s2.chinese << " "
         << s2.math << "  " << s2.english << " " << s2.total << endl;
    return 0;
}
```

三个精彩瞬间值得划线：
- `s2 = s[i]` —— **结构体整体赋值合法**，一次复制全部六个成员（string 也深拷贝干净），这是结构体的隐藏福利；
- 全局数组开在 struct 定义尾部 `} s[100];`，即 §1.2 方式二在实战中的样子；
- 教材输出格式里空格个数并不统一（有的单格有的两格），照抄时注意对齐自己想要的样式。

※推演运行示范（输入→输出对照）：

```
输入：
3
张三 18 90 85 88
李四 19 75 92 70
王五 18 95 98 93
输出：
王五 18 95 98  93 286
```

#### ④ 挑刺时间（教练视角优化项）
1. `maxv = 0` 有暗雷：若允许全零/负分则初值失真。更稳写法是初始化为第 0 个学生的总分，或 `maxv = -1e9`。
2. 两遍循环可并成一遍：录入循环内直接打擂，O(n) 变半 O(n/1)。教材分两遍纯粹为了思路清晰。
3. 记下标 `int best=i;` 比拷贝整个 s2 更轻量——不过那会失去演示「结构体整体赋值」的机会，教学取舍。

> 🗣️ **人话总结：** 先记账再打擂，冠军整箱搬走。

### 5.2 案例二：枚举输出星期（P50–P51）

#### 题目（P50 原文）

> 输入数字 0–6，0 表示星期日，通过 switch 和 enum 实现，输出对应的汉字表述。
> 输入用例：`0`　→　输出用例：`星期日`

#### 思路分析

1. 输入本质是整数（且前面刚背过 ❗枚举不能直接 `cin`），所以拿 `int n` 接收；
2. 定义 `enum week { Sun, Mon, Tue, Wed, Thu, Fri, Sat };` —— 枚举常量的默认序号恰好就是 0~6，与输入数字一一对应（这就是本题选枚举的点睛之笔）；
3. `switch (n)` 的每个 `case Sun:` 等标签看似「单词」，实为常量整数 0~6，完全合法；
4. 每个 case 输出对应汉字后**必须 break**，防止落穿到下一个分支。

#### 教材解法（P51 完整照录）

```cpp
enum week { Sun, Mon, Tue, Wed, Thu, Fri, Sat }; // 序号恰好=输入的0~6
int n; cin >> n;
switch (n)
{
case Sun: cout << "星期日" << endl; break;   // Sun 本质就是 0
case Mon: cout << "星期一" << endl; break;
case Tue: cout << "星期二" << endl; break;
case Wed: cout << "星期三" << endl; break;
case Thu: cout << "星期四" << endl; break;
case Fri: cout << "星期五" << endl; break;
case Sat: cout << "星期六" << endl; break;
}
```

运行验证：

```
输入：0   → 输出：星期日
输入：6   → 输出：星期六
输入：9   → 无任何输出(case全不命中且无default)
```

#### 常见错误预警
- 忘 break → 输入 0 会连环打出全部七行；
- 不建 default 分支 → 非法输入静默无反应，加一句 `default: cout << "输入错误";` 更稳；
- 这题如果硬要 `cin >> w;`(week 型) 直接编译失败——正向复习了「禁止」清单的用途。

> 🗣️ **人话总结：** 数字进门查户口，枚举名字对座位。

### 6.2 hw_code.cpp 逐行精讲——老师带学生（即 PDF P53 的作业题）

> 结构体嵌套 + 随机数赋分 + 数组传参三合一的收官之作。以下按行号精讲，最后附真实运行样例。

#### 第一幕：两个结构体的嵌套设计（L1–L14）

```cpp
#include <iostream>
#include <ctime>                     // L2: rand/srand/time 都靠它
using namespace std;
struct student                       // L4-9: 先造小件——学生模板
{
    string s_name;                   //   姓名前的 s_ 是"student成员"命名习惯
    int age;                         //   ⚠️留意：本程序从没给 age 赋值！
    int score;
};
struct teacher                       // L10-14: 再造大件——老师模板
{
    string t_name;                   //   老师，t_前缀同理
    struct student sarray[5];        // ⭐核心：老师的身上背着5个学生！(结构体嵌套数组)
};
```

为什么 student 必须写在 teacher **前面**？编译器读到 teacher 内部要用 `struct student` 时必须已经认识它——自上而下的依赖顺序，这是嵌套的铁律。
内存视角小账本：`sizeof(student)=40`（string32+int+int），`sizeof(teacher)=32+40×5=232` 字节。三个老师连排就是约 696 字节的大家族（x64 g++/MSVC 实测口径）。

#### 第二幕：赋值函数 allocatespace（L15–31）

```cpp
void allocatespace(struct teacher tarray[], int len) // L15: 数组传参→退化为指针(§3.3)
{
    string nameseed = "ABCDE";                        // L17: 名字生成器的原料库
    for (int i = 0; i < len; i++)                     // L18: 外层=第i位老师
    {
        tarray[i].t_name = "teacher_";                // L20: 先铺固定前缀
        tarray[i].t_name += nameseed[i];              // L21: 追加A/B/C → teacher_A..C
        for (int j = 0; j < 5; j++)                   // L22: 内层=该老师第j个学生
        {
            tarray[i].sarray[j].s_name = "student_";  // L24: 三层点阵 drilling!
            tarray[i].sarray[j].s_name += nameseed[j];// L25: student_A..E (每位老师学生同名)
            int random = rand() % 61 + 40;            // L26: 精妙区间见下框
            tarray[i].sarray[j].score = random;       // L27: 成绩入库
        }
    }
}
```

**L26 的随机分公式拆解（考试级考点）：**

```
rand() % 61      → 余数只可能是 0,1,2,...,60 (共61种)
      + 40       → 平移区间得 40,41,...,100   ✔闭区间[40,100]
```
口诀化记忆：想拿 [a,b] 区间的随机整数，公式是 `rand() % (b-a+1) + a`。这里 b-a+1=100-40+1=61。别顺手写成 %60（会漏掉100分）！
⚠️ 同行埋雷：**age 全程无人赋值**，每位学生的年龄都是垃圾值——好在打印函数没碰它。若作业要求输出年龄，这就是你的第一个修复任务（可加一句 `sarray[j].age = 18 + rand()%4;` 之类）。

#### 第三幕：打印函数 printinfo（L32–43）

```cpp

```
`wcout/中文`在控制台能正常出（实测通过），`\t` 让每个学生行首有个 tab，视觉上立刻表现出「归属关系」——排版也是信息。

#### 第四幕：主函数装配线（L44–51）

| # | 易错点 | 错误示范 | 正确姿势 | 本笔记出处 |
|---|---|---|---|---|
| 1 | 结构体定义两个分号 | `struct S{ int a; int b }` ←大括号后漏分号 | `struct S{ int a; int b; };` | §1.2坑1 |

## 10. 核心语法速查表（考前 30 秒过一遍）

| 想做什么 | 一行语法 | 迷你示例 |
|---|---|---|
| 定义类型 | `struct 名{ type 成员; ... };` | `struct student{ string name; int age; double score; };` |
| 三种建变量 | 类型后置/同步定义/匿名 | `student s1;` · `struct T{...}s1,s2;` · `struct{...}x;` |
| 整体初始化 | `名 v = {值1, 值2, ...};` | `student s={"张三",20,99.5};` |
| 读改成员 | `v.member` | `s.score = 98; cout<<s.name;` |
| 出厂默认值 | 成员声明后 `{}` 或 `=` | `string name{"赵四"}; double score=100;` |
| 内置成员函数 | struct 里直接写 void f(){...} | `void printInfo(){ cout<<name...; }` 调 `s.printInfo();` |
| 定义指针 | `类型* p = &变量;` | `student* p=&s;` |
| 指针取成员 | `p->member` 或 `(*p).member` | `p->age=29; cout<<(*p).score;` |
| 定义数组 | `类型 数组名[N];` | `student arr[3];` |
| 数组初始化 | `{ {...},{...},... }` | `arr[3]={{"李四",20,100},{"王五",21,99},{"张三",22,91}};` |
| 数组元素访问 | `数组[i].member` | `cout<<arr[0].name;` |
| 值传递函数 | `void f(名 v){...}` | `f(s1);` 改不动原件 |
| 指针传递函数 | `void f(名* p){...}` | `f(&s1);` 能改原件,内部 `p->` |
| 数组传递函数 | `void f(名 a[],int len){...}` | `f(arrs,3);` 内部 `a[i].` |
| 定义共用体 | `union U{int a;double b;};` | `U x; x.a=20;(再赋b则a报废)` |
| 定义枚举 | `enum E{A,B,C};` 可指定值 | `enum week{Sun=7,Mon=1,...};` |
| 用枚举 | 只赋表中名；输出的是整数 | `week w=Wed; cout<<w; //2` |
| 别名化类型 | `typedef 原型 新名;` | `typedef int Arr[10]; Arr a;` |
