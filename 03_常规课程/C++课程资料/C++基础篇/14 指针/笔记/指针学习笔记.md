## 模块一 基础篇（PDF 第 4–10 页）

### 1.1 指针概述【了解】（第 4 页）

【了解】级，三句话搞定：

- 内存就像一栋大楼，每个字节都有编号，这个编号就叫**内存地址**。地址的编号，就是指针。
- 光有名字找不到人，还得靠门牌号——程序要定位某块内存里的数据，靠的也是它的地址。没有指针，程序就只能喊名字，无法表达"位置"这个概念。
- **指针变量**：专门用来保存"别的变量的地址"的变量。

**🗣 人话总结**：地址即编号，指针存门牌。

### 1.2 指针的定义与初始化【熟悉】（第 5–8 页）

**❶ 是什么**

指针是保存内存地址的变量。定义语法：

```cpp
type *varName;      // 例如 int *p;
```

**❷ 为什么**

很多机制都要"隔着一层"操作数据：函数间共享并修改变量、遍历连续内存、动态分配……这些都要求先拿到目标"地址"这把钥匙。没有指针，就只有复印件思维，动不了原件。

**❸ 怎么用**

两个核心符号：

| 符号 | 名字 | 作用 | 类比 |
|---|---|---|---|
| `&变量` | 取地址符 | 获取变量的内存地址 | 问人家门牌号 |
| `*指针` | 解引用符 | 取出指针所指位置的值 | 按门牌号进门拿东西 |

结合教材第 8 页案例：

```cpp
int num = 100;
int *p = &num;                  // 定义同时初始化：p 记住 num 的地址
cout << "p = " << p << endl;    // 输出形如 00AFFB78（地址，十六进制）
cout << "*p = " << *p << endl;  // 解引用，顺着地址拿到 100
```

> 输出示例：
> ```text
> p = 00AFFB78     （每次运行会变，因为是系统分配的真实地址）
> *p = 100
> ```

code.cpp 中 `func2(&num)`、`change(&num1,&num2)` 等调用都是这一语法的延续——先把地址取出来交出去。

**④ 注意事项**

1. 指针只能装**地址**，不能直接装数值：`int* p = 100;` ✗（把 100 当门牌号，进门必翻车）。
2. `*` 号一词两义：**定义时**是"声明这是指针"，**使用时**是"解引用取值"。`int *p;` 和 `*p = 5;` 里两颗星含义完全不同。
3. 先初始化再使用：没指向正经人家的"野指针"解引用会出大事（详见 6.1）。

**🗣 人话总结**：星号定意声明，用意取值。

### 1.3 指针运算 ++ / --【熟悉】（第 9–10 页）

**❶ 是什么**

指针保存的地址本质是个整数 → 可以加减。指针 ± 1 叫做**移动一个元素**，移动步长 = 指向类型的大小，不是一律加 1 字节。

**❷ 为什么**

内存里经常一排排躺着同类型数据（数组）。有了"步长固定"的移动能力，指针才能像尺子一样一格一格滑过去遍历——这是下一节数组篇的地基。

**❸ 怎么用**

教材第 10 页示例：

```cpp
int num = 100;
int* p = &num;
cout << p << endl;   // 输出如 00AFFB78
p++;                 // 指针向后移动一格：跨过一个 int = 4 字节
cout << p << endl;   // 输出如 00AFFB7C（恰好大了 4）
p--;                 // 移回来恢复原地址
```

> 输出示例：`00AFFB78`、`00AFFB7C`——差值正好 4（int 的字节数）。

换类型验证步长规律：`char*` 一次移 1 字节，`double*` 一次移 8 字节。**步长由指向的类型决定**。

**④ 注意事项**

- 对**单个普通变量**的指针做 ++/-- 毫无意义：num 只有一格，移过去就是别人的地盘（非法内存）。移动是为数组和连续内存准备的。
- 区分两种写法：`p + 1` 只是临时算出下一个位置，p 本身没动；`p++` 才真正改变了 p。

**🗣 人话总结**：加减即移动，步长看类型。

## 模块二 数组篇【重点】（第 11–14 页）

### 2.1 数组名可以看成指针（第 11–12 页）

**❶ 是什么**

数组名的值就是**首元素（索引 0）的地址**：`arr ⇔ &arr[0]`。由此得到下标访问的本质等式：

```text
arr[i]  ⇔  *(arr + i)
```

**❷ 为什么**

数组在内存中连续排列成同规格的格子，只要记住起点地址＋利用步长移动，就能定位任何元素。下标语法只是给 `*(arr+i)` 穿的糖衣——编译器底层就是这么翻译的。

**❸ 怎么用**

教材代码与 code.cpp 第 63–73 行被注释段的合并演示：

```cpp
int arr[5] = { 1,2,3,4,5 };
cout << arr     << endl;   // 首元素地址，如 00AFFA8C
cout << &arr[0] << endl;   // 同上 → 与上一行完全相等
cout << &arr[1] << endl;   // 如 00AFFA90（前者 +4 字节）
cout << arr + 1 << endl;   // 与上一行相等：+1 个元素 = +4 字节
cout << arr[2] << " " << *(arr + 2) << endl;  // 3 3 —— 完全等价
```

> 输出示例（绝对地址每次运行会变，相对关系恒定）：
> ```text
> 00AFFA8C
> 00AFFA8C
> 00AFFA90
> 00AFFA90
> 3 3
> ```

但是！数组名和真指针有一个**决定性差别**：

```cpp
int arr[5] = { 1,2,3,4,5 };
int* p = arr;

// arr++;        // ✗ 编译报错！数组名是常量，不允许修改
p++;              // ✓ 指针是变量，随便移动
```

code.cpp 第 60 行注释里那句 `*(arr++)` 正是这个反例，旁边还留着当年的批注："错误 arr常量，不能更改"。

**④ 注意事项**

1. 一句话记住本质：**数组名 = 不能动的首地址（常量），指针 = 可以到处跑的变量**。
2. 经典考坑：`sizeof(arr)` 得到**整个数组**的字节数（此处 20），而 `sizeof(p)` 只有 4 或 8 字节（指针自身大小）——数组名并不真的等于指针变量。

**🗣 人话总结**：数组名常量坐镇，指针活人挪窝。

### 2.2 用指针遍历数组（第 13–14 页）

**❶ 是什么**

把数组名交给一个真正的指针：`int* p = arr;`，之后既能"原地偏移"也能"推着走"来访问每个元素。

**❷ 为什么**

这是读懂一切 C/C++ 风格数据遍历的通用钥匙，也是后面函数传数组、字符串处理的基础功。

**❸ 怎么用**

两种遍历姿势（对应 code.cpp 第 77–83 行与教材第 13–14 页）：

| 姿势 | 写法 | 特点 |
|---|---|---|
| 偏移法 | `*(p + i)` | p 原地不动，靠 i 算偏移；循环结束 p 还在开头 |
| 推进法 | `*p++` | 每读一个元素，p 就自动前进一步；读完停在末尾之外 |

```cpp
int arr[5] = { 1,2,3,4,5 };
int* p = arr;

for (int i = 0; i < 5; i++)
    cout << *(p + i) << " ";   // 输出 1 2 3 4 5，全程 p 未动
cout << endl;

for (int i = 0; i < 5; i++)
    cout << *p++ << " ";       // 输出 1 2 3 4 5，结束后 p 已越过末尾
```

> 两行都输出 `1 2 3 4 5`。注意 `*p++` 因优先级相当于 `*(p++)`：先取当前格子的值，再把 p 后移一位——"读一格、走一格"的组合拳。

**④ 注意事项**

- 推进法跑完后 **p 已经越界停在末尾之后**，想再遍历一遍必须重新 `p = arr;` 归位，否则读到的是越界垃圾值。
- 别把 `*p++` 读成"乘以 p++"；它是先解引用后自增的两步动作。

**🗣 人话总结**：偏移原地稳，推进须归位。

## 模块三 进阶篇（第 15–17 页）

### 3.1 二级指针【熟悉】（第 15–16 页）

**❶ 是什么**

一级指针存普通变量的地址；**二级指针存一级指针变量的地址**：

```cpp
int **ppn = &pnum;   // 语法：两颗星对应两层间接
```

**❷ 为什么**

一级指针自己也是变量、也要占格子、也有地址。当需要**改变指针本身的指向**（而非它指的数据）时，就必须抓住指针的地址。典型应用：函数内改主调方的指针、二维数组操作、链表头插。

**❸ 怎么用**

快递柜比喻：包裹＝数据（num）；写着柜门号的纸条＝一级指针（pnum）；楼栋索引牌上记着"那张纸条贴在哪一格"＝二级指针（ppn）。

解引用套娃链：`**ppn ⇔ *pnum ⇔ num`（想见真身必须解两次）。逐层内存图在第三部分"补·3.2"有 Step-by-Step 版，这里先看代码骨架（呼应 code.cpp 第 86–96 行）：

```cpp
int num = 100;
int*  p1 = &num;    // 一级：存 num 的地址
int** p2 = &p1;     // 二级：存 p1 的地址（注意是两颗星）

cout << num  << endl;   // 100
cout << *p1  << endl;   // 100：解一次引用
cout << **p2 << endl;   // 100：解两次才见到真身
```

> 三行全部输出 `100`——三个名字通向同一份数据。

code.cpp 里还有一段四轮改值实验（L98–111 逐步改 num / \*p1 / \*\*p2），每轮打印三视图验证结果始终同步，完整解读见"补·3.2 Step 4"。

**④ 注意事项**

- 星号数量 = 层级数量：写 `int* p2 = &p1;` 类型对不上，直接编译失败；少打一颗星是最常见手误。
- 取地址套娃有限制：`&(&num)` 这类写法不合法，二级指针存的必须是某个具体指针变量的地址。

**🗣 人话总结**：二级指针，专收指针地址。

### 3.2 多级指针（第 17 页）

一句话带过【了解】：指针级数理论上无限制，如 `int *****pa6 = &pa5;`，每加一颗星多一层间接；但实战几乎不会超过二级——星星越多，可读性坍塌越快，同事的眼泪越多。

**🗣 人话总结**：星星能更多，头脑限两级。

## 模块四 函数篇【重点】（第 18–26 页）

### 4.1 指针作为函数参数（第 18–22 页）

**❶ 是什么**

形参类型写成指针 `void f(int* p)`，调用时实参传地址 `f(&num);`——函数收到的是门牌号而不是复印本。

**❷ 为什么**

C++ 默认**值传递**：进函数的是复印件，函数里怎么涂改，原件都安然无恙。想让函数**真正修改外部的变量**，就得给它地址让它上门去改（或者用引用）。这正是 swap 类需求的理论前提。

**❸ 怎么用**

code.cpp 开头的三胞胎函数就是一组精心设计的对照实验（值传递/指针/引用三方对垒）：

```cpp
void func1(int  v1) { v1++; }     // 值传递：改的是复印件
void func2(int* v1) { (*v1)++; }  // 指针传递：顺地址上门改真身
void func3(int& v1) { v1++; }     // 引用传递：别名直改

// 在 main 中分别调用观察：
func1(num);   cout << num;   // 100　纹丝不动
func2(&num);  cout << num;   // 101　真变了！（实参必须写 &num）
func3(num);   cout << num;   // 102　引用同样有效
```

> 分组运行依次观察到 100 → 101 → 102。code.cpp 第 118–120 行被整段注释的正是 func1 组——它当年最先出场演示"值传递无效"。

**关键细节**：func2 里为什么写 `(*v1)++` 而不是 `*v1++`？后者因优先级等于"解引用当前地址＋把指针后移"，改不了值只会挪窝；加括号强制**先取内容再自增**——一处括号，天壤之别。

压轴登场经典 swap（教材 21–22 页题目，code.cpp 的 change 函数即答案）：

```cpp
void change(int* p1, int* p2) {
    int temp = *p1;   // 暂存 p1 所指的数
    *p1 = *p2;        // 把 p2 所指的数搬进 p1 的家
    *p2 = temp;       // 再把暂存值放回 p2 的家
}

int a = 100, b = 200;
change(&a, &b);
cout << a << " " << b;   // 输出 200 100 —— 真交换成功！
```

> 输出 `200 100`。若传值版 swap 则输出原序 100 200——空欢喜一场。

三种传递方式总结表：

| 方式 | 形参写法 | 调用写法 | 能否修改外部变量 |
|---|---|---|---|
| 值传递 | `int v1` | `f(num)` | ✗ 改不动 |
| 指针传递 | `int* v1` | `f(&num)` | ✓ 改得动 |
| 引用传递 | `int& v1` | `f(num)` | ✓ 改得动 |

**④ 注意事项**

- 调用时**实参必须传地址**：`func2(num)` 编译不过（int 无法隐转 int*）；
- 函数体内一律写作 `*p` 来读写外部变量，那里不需要再加 &。

**🗣 人话总结**：递上门牌号，才能改动真身。

### 4.2 指针作为函数返回值（第 23–26 页）

**❶ 是什么**

返回类型写成指针：`type* funcName() { return 地址; }`，交付的不是数值而是"位置"。

**❷ 为什么**

返回地址可以交付一大片结果（数组、结构体）或某对象的位置。但铁律随之而来：**地址指的东西必须活得比函数更久**——这就逼出了一条最容易踩的禁忌。

**❸ 怎么用**

正反教材 test1 / test2（code.cpp 第 24–33 行函数定义，第 137–143 行调用）：

```cpp
int* test1(int* p) {
    return p;          // ✓ 回传"别人给我的地址"，num 还活着
}
int* test2() {
    int v1 = 1;        // 局部变量：函数一结束立刻销毁
    cout << &v1 << endl;
    return &v1;        // ✗ 返回已拆房子的门牌号
}

// main 中调用对比：
int num = 100;
int* p1 = test1(&num);
cout << &num << endl;  // 00AFFB78
cout << p1 << endl;    // 00AFFB78 —— 两行一模一样 ✓ 安全

int* p2 = test2();     // 编译器警告：returning address of local variable
cout << p2 << endl;    // ⚠ 地址虽打印出来，指向的内容不可预测
```

> - test1 组输出两个相同的地址——安全。
> - test2 组：test2 内部打印一次 &v1，main 里又拿到同一个地址；但此刻那个栈格子早已随函数结束回收，里面的内容是残留垃圾或随时被覆盖——教科书称之为**悬垂指针**（dangling pointer）。它就像给了你一张已经拆迁房屋的门牌号：号码是真的，房子没了。

**④ 注意事项**

- **禁止返回局部变量的地址**。安全出路只有三条：static 变量、全局变量、new 出来的堆内存（外加像 test1 那样回传调用方给的地址）。
- 有些编译器只给警告不拦截错误——这是 C++ 给你的信任，别辜负它。

**🗣 人话总结**：局部变量已销毁，其址作废勿返。

## 模块五 字符串篇【重点】（第 27–29 页）

### 5.1 用指针定义字符串（第 27–28 页）

**❶ 是什么**

两种写法都能握住 `"hello"`，但性质截然不同：

```cpp
char str[] = "hello";        // 字符数组：把字符串常量的副本拷进自己的栈空间
const char* pc = "hello";    // 字符指针：仅记录常量区那份 hello 的首地址
```

**❷ 为什么**

两者的差异决定"这串字还能不能改"。数组版本是你自购的可写字画（内容归你），指针版本指着图书馆的原版藏书（公有财产，禁涂改）。

**❸ 怎么用**

结合 code.cpp 第 148–153 行：

```cpp
const char* pc1 = "abc";
cout << pc1  << endl;    // 输出 abc ——注意：打的是整串，不是地址！
cout << *pc1 << endl;    // 输出 a ——解引用只拿第一个字符
```

> 输出：
> ```text
> abc
> a
> ```

双形态对比表：

| 维度 | `char str[] = "hello"` | `const char* p = "hello"` |
|---|---|---|
| 内容能否修改 | ✓ 可以 `str[0]='H'` | ✗ 不行，常量区禁改 |
| 能否整体换内容 | ✗ 数组名是常量 | ✓ 可 `p = "world"` 改指向 |
| 数据存放位置 | 栈上的可写副本 | 只读常量存储区 |
| `sizeof` 结果 | 整个数组大小（6，含'\0'） | 指针自身 4 或 8 字节 |
| 使用建议 | 内容需要改时用 | 只读展示、传参用 |

**④ 注意事项**

1. **cout 特殊优待 char\***：其他类型的指针 cout 打印地址，唯独 char\* 被翻译成"打到 '\0' 为止的字符串"。想看地址得 `(void*)p` 强转——高频易错点。
2. 指向字符串常量时**务必加 const**：加了 const，误改会被编译器当场抓获；不加，埋下的非法访问雷只在深夜调试时炸。

**🗣 人话总结**：数组副本可改，指向常量莫动。

### 5.2 指针与字符数组（第 29 页）

**❶ 是什么**

让指针逐个字符扫过整个字符串，这是 C 风格字符串处理的基本功。

**❷ 为什么**

strlen、strcpy 等标准库函数内部全是这套逐字节扫描逻辑；练熟它等于提前看懂了半个 C 标准库的实现。

**❸ 怎么用**

对应 code.cpp 第 156–166 行，双姿势复刻教材第 29 页：

```cpp
char str[] = "hello world";
int len = strlen(str);

for (int i = 0; i < len; i++)
    cout << *(str + i);       // 姿势一：偏移法，str 不动
                              // （但绝不能 *(str++) ！str 是数组名常量）
char* pc = str;               // 借真指针上场
for (int i = 0; i < len; i++)
    cout << *pc++;            // 姿势二：推进法，边读边走
```

> 两种姿势都连续输出 `hello world`（11 个字符挤在一行）。循环边界 len 由 strlen 给出且不含结尾 '\0'，所以字母打完恰好收工，不多打一个空字节。

**④ 注意事项**

- 字符串自带隐藏结尾标志 `'\0'`：strlen("hello world")=11，但数组实际占了 12 字节——长度计算的高频踩坑点。
- 与 5.1 不同，此处 str 是货真价实的数组（可改内容），但它仍然不可 ++（数组名的宿命，见 2.1）。

**🗣 人话总结**：偏移推进皆可，勿越 '\0' 之界。

## 模块六 专项篇（第 30–41 页）

### 6.1 NULL 空指针与 nullptr（第 30–32 页）

**❶ 是什么**

**空指针**：明确宣布"不指向任何数据"的指针，值为 NULL（课件给出其真身 `#define NULL ((void *)0)`），C++11 起推荐 nullptr。

**❷ 为什么**

怕的不是空，是**野指针**——刚定义完天上乱指、或用完忘了收心的指针，里面存着不知谁的旧门牌。解引用野指针轻则数据错乱重则当场崩溃，而且 bug 出现位置飘忽不定极难排查。防御两条铁律：**定义时就置空，用完随手再置空**。

**❸ 怎么用**

对应 code.cpp 第 169–170 行：

```cpp
int* p1;                 // 野指针候选户：尚未指向任何人
int* p2 = NULL;          // 传统写法：先挂空挡
int* p3 = nullptr;       // C++11 推荐：语义最纯正

if (p3 != nullptr)       // 用之前先问一句
    cout << *p3;
else
    cout << "空指针，禁止解引用";   // 实际会输出这句
```

> 输出 `空指针，禁止解引用`。

为什么有了 NULL 还要 nullptr？NULL 本质是整数 0，函数重载匹配时可能被认成 int 版本产生二义性；nullptr 天生只为指针而生，类型安全。结论：**旧代码认识 NULL，新代码一律 nullptr**。

**④ 注意事项**

- 空指针解引用同样非法——"无家可归"和"家已塌方"一样危险，判空是唯一保险丝。

**🗣 人话总结**：不用就置空，用前先判空。

### 6.2 void 万能指针【熟悉】（第 33–35 页）

**❶ 是什么**

`void*`：可以接收**任何类型地址**的指针，江湖人称万能指针。

**❷ 为什么**

通用工具不该限定数据类型：复制内存的 memcpy、申请内存的 malloc 参数都是 void*——只要"来者是客"，管你什么类型统统接下。

**❸ 怎么用**

代价：动手（解引用）前必须先验明正身——强制转换回真实类型。对应 code.cpp 第 173–177 行：

```cpp
int num = 100;
void* p = &num;          // 万能接洽：任意地址吃得下
cout << p << endl;       // 打印地址本身没问题
// cout << *p;           // ✗ 编译报错！void* 不知道该读几个字节
cout << *(int*)p;        // ✓ 先强转回 int*，再解引用
```

> 输出一行地址＋一行 `100`。

**④ 注意事项**

- 强转前**必须确定原始类型**：明明装着 int 却转成 double 去解，会把比特胡乱解读成天文数字——强转只是糊弄了编译器，骗不了内存真相。
- 标准 C++ 禁止对 void\* 做加减移动：步长未知，无从走起。

**🗣 人话总结**：来者不拒全能收，动手先验明正身。

### 6.3 三种 const 修饰【重点】（第 38–41 页）

**❶ 是什么**

const 与指针的三种相遇：锁指向（方向不许换）、锁值（内容不许改）、双保险（全锁）。

**❷ 为什么**

权限管理防患未然：有的场合只许更新数据不许挪动位置（配置内容可变、监控方位固定）；有的反过来（扫描器不断前移、路过数据只读）。三把不同的锁精确圈权。

**❸ 怎么用**

总览对照表（code.cpp 第 181–193 行逐条验证；**被注释掉的那行正是各自实验中的非法行**）：

| 写法 | 名称 | 改指向 `p=&x` | 改值 `*p=n` | 口诀记忆 |
|---|---|---|---|---|
| `int* const p = &num;` | 指针常量 | ✗ | ✓ | 指向焊死，值可动 |
| `const int* p = &num;`（即 `int const* p`） | 常量指针 | ✓ | ✗ | 值冻结，可挪窝 |
| `const int* const p = &num;` | 双 const 锁 | ✗ | ✗ | 全部锁死 |

核心验证码：

```cpp
int num1 = 100, num2 = 200;

int* const p1 = &num1;     // 指针常量：方向焊死
// p1 = &num2;             // ✗ 编译错
*p1 = 300;                 // ✓ 改值自由

int const* p2 = &num1;     // 常量指针：数值冻结
p2 = &num2;                // ✓ 挪窝自由
// *p2 = 400;              // ✗ 编译错

const int* const p3 = &num1;   // 双锁：全禁
// p3 = &num2;             // ✗ 编译错
// *p3 = 500;              // ✗ 编译错
```

> 记忆口诀（课本原味）：**const 在 \* 左边修饰的是指向的值，在 \* 右边修饰的是指针本身**。另招：从右往左读声明，谁的近卫谁是 lock 对象。

**④ 注意事项**

- 课件金句延展：**引用的本质 ≈ `int* const`（指针常量）**——一经绑定不许改道，但通过它可以改值。这句话直接铺垫了下节的引用对比。
- 判断时盯住 const 与 \* 的相对位置即可，别让变量名插在中间乱了阵脚。

**🗣 人话总结**：星左锁值，星右锁向。

### 6.4 指针与引用的区别【重点】（第 36–37、41 页 ＋ hw.txt）

**❶ 是什么**

指针＝记录地址的**独立实体**；引用＝变量的第二个名字（**别名**），依附原变量而存在。

**❷ 为什么**

课件第 45 页布置的正是一道面试真题："引用与指针的相同点和不同点？"而 hw.txt 就是官方参考答案——这道题几乎是 C++ 面试固定节目，必须背得滚瓜烂熟。

**❸ 全面对照表**（整理自 hw.txt 原文＋课件 36–37 页深化）

| 维度 | 指针 | 引用 |
|---|---|---|
| **相同点** | 都是地址的概念：指针指向一块内存，内容是所指内存的地址；引用则是某块内存的别名 | （同左） |
| 本质 | 独立实体，自己也要占内存 | 仅别名（课件说法：本质 ≈ int* const 指针常量） |
| 初始化 | 可以不初始化 | **必须**初始化，且只此一次、"从一而终" |
| 改指向 | ✓ 可"见异思迁" | ✗ 终生绑死一人 |
| 能否为空 | ✓ 可以（NULL/nullptr） | ✗ 永远有所指 |
| sizeof 结果 | 指针自身大小（4/8 字节） | 所指变量本身的大小 |
| 自增 ++ 含义 | 地址向前移动一格 | 原变量的值 +1 |
| 多级能力 | 可 N 级套娃（二级三级…） | 只有一级，不存在"引用的引用" |
| 类型安全性 | 弱（地址随意强转） | 强（多了类型约束检查） |

hw.txt 一句话浓缩版（背诵利器）：

```text
相同点：都是地址的概念。
不同点：指针实体引用别名；引用从一而终指针见异思迁；引用非空指针可空；
        sizeof 有别；自增含义不同；引用只有一级且有类型检查。
```

**④ 注意事项／选型建议**

- 表达"可能暂时没有目标"→ 指针；保证"必有且终生唯一"→ 引用。
- 工程惯例：默认优先引用（代码干净直呼其名），确需"可空、可重定向、算术移动"时才亮指针。

**🗣 人话总结**：别名终身忠诚，指针自由可空。

### 6.5 课堂练习 checkMax（第 42–43 页）

**题目**：编写 `checkMax` 函数找出两数中的较大者——**三个参数全是指针**。

**解题思路（三步拆解）**：

1. **认角色**：p1、p2 是两路**进口**（各携带一个待比较的数）；pMax 是**出口**（负责把比较结果送回调用方）。"两进一出，全凭指针搭桥。"
2. **进口怎么读**：进来的是地址，`*p1`、`*p2` 解引用即是数值本体。
3. **出口怎么写**：往 `*pMax` 里赋值，就直接落进了调用方 v3 家里——这就是 4.1"传地址改真身"的标准应用。

**标准解法**（code.cpp 底部 L196–198 正是官方答案，也是全文件当前唯一激活运行的代码）：

```cpp
void checkMax(int* p1, int* p2, int* pMax) {
    if (*p1 > *p2)
        *pMax = *p1;      // 大者通过"出口指针"写回调用方
    else
        *pMax = *p2;
}

int v1 = 900, v2 = 200, v3;
checkMax(&v1, &v2, &v3);
cout << v3 << endl;        // 输出 900
```

> 当前直接编译 code.cpp 会输出 `900`。

**为什么用三指针而不直接 return？** 课堂意图是把"指针出口"思想钉进肌肉记忆：return 只能带回一个值，而指针参数天然支持多个出口、还能复用调用方的既有变量——这是 return 做不到的。

## 3.2 二级指针内存图 Step by Step

场景重建（地址为便于书写设的简化假地址）。

**Step 0｜开场：`int num = 100;`**

```text
┌───────────────────────────┐
│ 房间 A　地址 0x1000         │
│ 户主：num                  │
│ 存放：100                  │
└───────────────────────────┘
```

**Step 1｜一级介入：`int* p1 = &num;`**

```text
┌───────────────────────────┐         ┌──────────────────┐
│ 房间 B　地址 0x2000         │ ───────▶│ 0x1000: 100      │
│ 户主：p1                   │  指向    │ num 的家          │
│ 抽屉里：一张纸条「0x1000」   │         └──────────────────┘
└───────────────────────────┘
```

p1 的值 = 0x1000。想取到 100？去 B 房抽屉读纸条，照纸条找 A 房——这一趟就是 `*p1`。

**Step 2｜二级介入：`int** p2 = &p1;`**

```text
┌───────────────────────────┐         ┌───────────────────────────┐         ┌──────────────────┐
│ 房间 C　地址 0x3000         │ ───────▶│ 房间 B　地址 0x2000         │ ───────▶│ 0x1000: 100      │
│ 户主：p2                   │  指向    │ 户主：p1                   │  指向    │ num 的家          │
│ 抽屉里：纸条「0x2000」       │         │ 抽屉里：纸条「0x1000」       │         └──────────────────┘
└───────────────────────────┘         └───────────────────────────┘
```

三层递进完成：C 存 B 的地址，B 存 A 的地址，A 才住着 100。

**Step 3｜六种读法的寻宝路线**

| 表达式 | 寻宝路线 | 得到的结果 |
|---|---|---|
| `num` | 直达 A 房 | 100 |
| `p1` | 读 B 房抽屉的纸条 | 0x1000（仍是地址！） |
| `*p1` | 照纸条进 A 房 | 100 |
| `p2` | 读 C 房抽屉的纸条 | 0x2000 |
| `*p2` | 进 B 房（拿到 p1 的值） | 0x1000 |
| `**p2` | 进 B 房拿到纸条后再进 A 房 | 100 ★ 解两次才见真容 |

**Step 4｜四轮改值实验（对应 code.cpp L86–111，验证"多路同源"）**

```text
初始局面：num=100
  三视图打印：num=100 / *p1=100 / **p2=100          ……三角同步

第 1 轮：改源头      num  = 111
  三视图：111 / 111 / 111                            ……源头一动，下游齐晃

第 2 轮：走一级通道  *p1 = 1212
  三视图：1212 / 1212 / 1212                         ……顺一根藤摸到底

第 3 轮：走二级通道  **p2 = 333
  三视图：333 / 333 / 333                            ……多拐一层弯，殊途同归
```

**最终结论一图流**：num、p1、p2 三个变量其实是通往同一份"100"的三条线索——无论从哪条线写入，另外两条线读回来的永远一致。所谓多级指针，只是给同一扇门多配了几道寻路的钥匙。

# 第五部分 总结

## 5.1 全章知识体系树状图

```text
指针（内存地址的编号 ＆ 保存地址的变量）
├── 1. 基础
│    ├── 定义 type *p ──────── * 双面性：定义=声明 / 使用=解引用
│    ├── 取地址 &num ───────── int *p = &num;
│    └── 运算 p++/-- ───────── 步长=sizeof(类型)，为遍历而生
├── 2. 数组【重点】
│    ├── arr ≡ &arr[0] ─────── 首地址，但 arr 是常量（arr++ ✗）
│    ├── arr[i] ≡ *(arr+i) ─── 下标只是糖衣
│    └── 遍历两式 ──────────── *(p+i) 原地稳 / *p++ 推进快（用完记得归位）
├── 3. 多级指针
│    ├── 二级 int **p2=&p1 ─── 存指针的地址，**ppn 才见真身
│    └── N 级理论无限 ──────── 实战 ≤2 级
├── 4. 函数【重点】
│    ├── 参数传址 f(&num) ──── 改得动真身（值传 ✗ / 指针 ✓ / 引用 ✓）
│    ├── swap/change 范式 ──── temp 中转三步换
│    └── 返回 type* ────────── ⛔ 禁返局部变量地址（悬垂指针）
├── 5. 字符串【重点】
│    ├── 双形态 ────────────── char s[]=".." 可改副本 / const char* p=".." 常量禁改
│    ├── cout<<char* ───────── 打整串不打地址（特例！看地址需强转）
│    └── 逐字扫描 ──────────── *(s+i) / *p++ ；心里默念 '\0'
└── 6. 专项
     ├── NULL → nullptr ────── 不用即置空、用前必判空，根治野指针
     ├── void* 万能指针 ─────── 任意地址都收，强转后才能用
     ├── 三种 const【重点】 ─── 星左锁值 / 星右锁向 / 双锁全禁
     └── 指针 vs 引用【重点】 ── 九维对照（实体↔别名、可空↔非空…）
课堂落地：checkMax 三指针接线（两进一出）
```

## 5.2 核心语法速查表

| 场景 | 语法 | 最小示例（含结果） |
|---|---|---|
| 定义＋初始化 | `type *p = &var;` | `int *p = &num;` |
| 解引用读/写 | `*p` | `*p = 5;` → num 变 5 |
| 指针移动 | `p++`（步长=类型大小） | `int*` 后移 → 地址 +4 |
| 指向数组 | `int* p = arr;` | `*(p+i)` ↔ `arr[i]` |
| 推进遍历 | `*p++` | `while(...) cout << *p++;` |
| 作函数参数 | `void f(int* p)` ＋ `f(&x);` | change(&a,&b) 真交换 |
| 作返回值 | `int* f()` | 只许回 static/全局/new/入参地址 |
| 字符串指针 | `const char* s = "..";` | `cout<<s;` 整串 / `*s` 首字符 |
| 空指针 | `int* p = nullptr;` ＋ `if(p)` | 用前置空，杜绝野指针 |
| 万能指针 | `void* p = &x;` | `*(int*)p` 强转后再用 |
| 指针常量 | `int* const p = &n;` | 定向 ✗ 改值 ✓ |
| 常量指针 | `const int* p = &n;` | 定向 ✓ 改值 ✗ |
| 双 const | `const int* const p = &n;` | 双 ✗ |
| 二级指针 | `int** pp = &p;` | `**pp` 即原值 |

## 5.3 易错点速查卡

| # | 大坑现场 | 正确姿势 |
|---|---|---|
| 1 | `int* p;` 未初始化就 `*p` | 定义即 `= nullptr`，用前判空 |
| 2 | `int* p = 100;` 把数值当地址 | 只能装地址：`= &num;` |
| 3 | 值传参幻想改外部（func1 版惨案） | 传地址 `f(&v)` 或用引用 |
| 4 | `*v1++` 以为是"值加一" | 括号先行：`(*v1)++` |
| 5 | `arr++` 给数组名搬家 | arr 是常量；借 `int* p=arr` 再走 |
| 6 | `*p++` 走完还想继续扫 | 先复位 `p = arr;` |
| 7 | 返回局部变量的地址 | static／全局／new／入参地址 |
| 8 | `cout << charPtr` 期待看到地址 | 强转 `(void*)p` 再打 |
| 9 | 直接改写字符串常量 `p[0]='H'` | 要改就用 char[] 副本；常量加 const |
| 10 | 万能指针乱转类型后解引用 | 动手前确认原始类型再强转 |
| 11 | 两种 const 张冠李戴 | 星左锁值，星右锁向 |
| 12 | 空指针也敢解引用 | `if (p != nullptr)` 保险门 |
| 13 | strlen 与数组长度混为一谈 | strlen 不含 '\0'；数组占 len+1 |
| 14 | 二级指针少打一颗星 | 层级=星号数：存谁地址多一颗星 |

## 5.4 三条随身速记口诀

1. **指针存地址，星号取内容。**
2. **改真身传地址，局部地址莫返回。**
3. **星左锁值星右锁向，不用就空用前判空。**
