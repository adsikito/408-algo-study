## 一、模块一：模板概述 → 函数模板 → 原理（P4-P10）

### 1. 模板概述（P4）【了解】

**是什么**：C++ 的代码重用机制——功能相同、仅数据类型不同的类或函数，写一份"模板"即可。
**为什么**：避免为 int/double/string 每种类型重复写同一份代码；STL 各种组件都基于模板。
**怎么用**：不需要立即用，它是后面所有模板知识的入口。比喻：模具本身不是产品，但能浇铸出各种材料的产品。
**注意事项**：模板是"编译期"机制，不是运行时机制。

### 2. 函数模板（P5-9）【重点】

**① 是什么**：生成通用函数的模具，参数/返回类型可以是任意类型。
**② 为什么**：函数重载需要每个类型写一份（P8 Swap 案例），代码复用率低、可维护性低。
**③ 怎么用**（两种语法完全等价，P5/P6 格式 + P9 Swap 案例）：

```cpp
template<typename T>        // 或 template<class T>
void Swap(T& x, T& y) {     // 引用传参才能改实参
    T tmp = x;              // 临时变量类型也用 T
    x = y; y = tmp;
}
// 调用：Swap(a, b); 编译器自动推演 T
```

配套代码 change（mycode.cpp）与教材 P13 案例一致；教材 P13 输出：`200 100`、`23.12 1.112`。
⚠️ mycode.cpp test02 有个笔误：`cout << "v1 = " << v2 << "  v2=" << v2` 第一个打印写成了 v2，实际输出是 `v1 = 200 v2=200` → 交换后 `v1 = 100 v2=100`，容易误以为没交换成功；double 部分（v3/v4）打印正确：`1.1/2.2 → 2.2/1.1`。

**④ 注意事项**：class/typename 完全等价；T 必须支持函数体内用到的运算；T& 要求实参是左值（变量）。

**人话总结**：一份代码，编译器按类型生成各版本。

**对比：函数模板 vs 函数重载**

| 维度 | 函数重载 | 函数模板 |
| --- | --- | --- |
| 代码量 | 每种类型一份 | 只写一份 |
| 新增类型 | 必须新增重载 | 自动适配 |
| 可维护性 | 改逻辑要改多处 | 只改一处 |
| 适用 | 各类型逻辑不同 | 逻辑相同仅类型不同 |

**对比：class vs typename**

| 维度 | class | typename |
| --- | --- | --- |
| 模板参数位置 | template<class T> | template<typename T> |
| 等价性 | 完全等价 | 完全等价 |
| 推荐度 | 旧代码常见 | 现代 C++ 推荐，语义清晰 |

### 3. 函数模板的原理（P10）【熟悉】

模板本身**不是函数**，是编译器生成具体函数的模具。编译阶段编译器按实参类型推演 T，为每种类型生成一份专门代码（int 版、double 版……），彼此地址不同。本质：把程序员重复做的事交给编译器。

**人话总结**：模板不是函数，是编译器抄代码的模子。

## 二、模块二：实例化 → 类模板 → 类模板实例化（P11-P18）

### 4. 函数模板的实例化（P11-13）【重点】

**① 是什么**：用具体类型使用模板称为实例化，分隐式（编译器推演）和显式（自己指定）。
**② 为什么**：模板只是蓝图；实参类型不一致时推演会失败，需要显式指定或多模板参数。
**③ 怎么用**：

```cpp
template<class T> T add(T& v1, T& v2) { return v1 + v2; }
int n3 = add(n1, n2);        // 隐式实例化，T=int → 300
double d3 = add(d1, d2);     // 隐式实例化，T=double → 3.57
// double d4 = add(n1, d2);  // ❌ T 无法同时是 int 和 double（不做隐式转换）
int n4 = add<int>(n1, n2);   // 显式实例化
```

**P12 解法——多模板参数**：

```cpp
template<class T, class H>
T add(T& v1, H& v2) { return v1 + v2; }   // T 跟第一个实参，H 跟第二个
```

**配套代码 test01 输出**（mycode.cpp）：`300` → `3.577` → `102`。
第三条：两参数模板下 `add(n1,d2)` 合法，但返回类型是 T=int，102.343 截断为 102——**返回类型跟随第一个模板参数**。
**④ 注意事项**：编译器一般不做隐式类型转换；混型相加用多模板参数；注意截断；T& 形参不能传字面量。

**人话总结**：隐式靠推演，显式加尖括号，混类型多给参数。

### 5. 类模板（P14-16）【重点】

**① 是什么**：让类拥有基于通用类型的成员。
**② 为什么**：功能相同仅成员类型不同的类（int/double/string 数组类）不必各写一份。
**③ 怎么用**：

```cpp
template<class T1, class T2, ..., class Tn>
class 类模板名 { /* 类内成员声明 */ };

template <class T>
class Pair {
    T values[2];                  // 成员类型待定
public:
    Pair(T first, T second) {
        values[0] = first; values[1] = second;
    }
};
```

配套代码 test03 输出：`1  2`、`1.111  2.342`（Pair<int> 与 Pair<double> 是两个不同的类）。
**④ 注意事项**：成员函数类外定义必须加模板参数列表；类模板声明和定义通常放同一头文件；类模板名不是类型。

**人话总结**：类的蓝图，类名本身不是类型。

### 6. 类模板实例化（P17-18）【重点】

**① 是什么**：类名后跟 `<具体类型>` 得到真实类，再定义对象。
**② 为什么**：不实例化无法创建对象；每个 `<T>` 都是独立的新类。
**③ 怎么用**（P18 Test 案例：类内声明、类外定义）：

```cpp
template<class T>
class Test {
public:
    Test() {}
    void setData(const T& x);      // 类内只声明
    void showDate();
private:
    T num;
};
template<class T>                  // 类外定义必须加模板参数列表
void Test<T>::setData(const T& x) { num = x; }
template<class T>
void Test<T>::showDate() { cout << num << endl; }

int main() {
    Test<int> t1;                  // 实例化 int 版本
    t1.setData(100);
    t1.showDate();                 // 输出 100
}
```

配套代码 mycode.cpp：42-50 行类内定义版（当前启用）；52-60 行被注释的类外定义版（语法示范，两者等价）。
**④ 注意事项**：`Test` 只是模板名，`Test<int>` 才是类型；类外定义漏 template 前缀必报错；成员函数被调用时才实例化。

**人话总结**：加 `<类型>` 才落地，一个 T 一个类。

## 三、模块三：模板别名（P19-20）【重点】

**① 是什么**：给复杂类型名起短名字。typedef（旧）与 C++11 using（新）。
**② 为什么**：`Test<int>` 写多了又长又容易忘；typedef 只能"定死"具体类型，using 可以给整个模板家族起别名。
**③ 怎么用**：

```cpp
// 方式一：typedef（P19）—— 只能给具体化后的类型起别名
typedef Test<int> t;
t t1;                            // 等价于 Test<int> t1; 输出 100

// 方式二：C++11 using 模板别名（P20）—— 保留模板性
template <class T>
using t = Test<T>;
t<int> t1;                       // 还能写 t<double>、t<string>…
```

配套代码 test04（mycode.cpp 63-72 行）：`template<class T> using t = Test<T>;` + `t<int> t1;` → 输出 `999`。被注释的 `//typedef Test<int> t;` 就是老写法遗迹。
**④ 注意事项**：typedef 只能具体化后使用；using 模板别名可继续传类型参数。

**人话总结**：typedef 定死，using 留活口。

**对比：typedef vs using（模板别名）**

| 维度 | typedef | using（C++11） |
| --- | --- | --- |
| 语法 | typedef Test<int> t; | template<class T> using t = Test<T>; |
| 能否当模板别名 | 不能（t 已定死为 Test<int>） | 能（t<int>/t<double> 均可） |
| 可读性 | 类型在前名字在后，长名难读 | 名字在前，直观 |

## 四、模块四：课堂练习与作业（P21-P24）

### 练习 1：求数组最大、最小、平均值（P21-22）

**思路**：T 表示元素类型 → num[0] 初始化 max/min → 遍历比较 + 累加 → total/double(size) 求均值 → size==0 单独处理。

```cpp
template<typename T>
void MathHelper(T num[], int size) {
    T max = num[0], min = num[0], total = 0;
    for (int i = 0; i < size; i++) {
        if (num[i] > max) max = num[i];
        if (num[i] < min) min = num[i];
        total += num[i];
    }
    cout << "Max : " << max << "\nMin : " << min << endl;
    if (size == 0) cout << "Mean : " << 0 << endl;
    else cout << "Mean : " << total / double(size) << endl;
}
```

教材测试输出：int 数组（总和 74）→ Max:22 Min:1 Mean:7.4；double 数组（总和 58.7）→ Max:10.5 Min:1.5 Mean:5.87。
配套 mathHelper（mycode.cpp 4-27 行）+ test05 输出：`Max = 9 / min = 1 / 均值:3.8`；`Max = 5.5 / min = 1.1 / 均值:3.24`。
**注意**：T 须支持 >、<、+；size==0 时 num[0] 越界（判断应提前）；int 累加可能溢出；显式实例化 mathHelper<int>(...) 更清晰。

### 练习 2：input 类模板（P24 作业 + hw_code.cpp）

**题目**：类模板 input，构造时提示输入并校验范围，不合法重新提示。形式：`input ob("prompt message", min, max)`。
**配套代码逐行**：

```cpp
#include<iostream>
using namespace std;
template <class T>
class input{
    T min_value,max_value;              // 私有范围成员
public:
    input(T min_value,T max_value){     // 构造：形参和成员同名
        this->max_value=max_value;      // this-> 区分成员与形参
        this->min_value=min_value;
    }
    void output(T a){                   // 校验
        if(min_value<=a&&a<=max_value){ cout<<a<<endl; }   // 合法输出
        else{ cout<<"数据不在合法范围内，请重新输入。"; }    // 不合法提示
    }
};
int main(){
    int x,y,z;  cin>>x>>y>>z;      // 1 9 3
    input<int> in1(x,y);  in1.output(z);   // → 3
    char a,b,c;  cin>>a>>b>>c;     // a z f
    input<char> in2(a,b);  in2.output(c);  // → f（ASCII：97≤102≤122）
return 0;}
```

**与教材要求的差异**：教材要"构造函数提示输入+循环重输"，配套代码是简化版（只校验一次、只提示不循环）；想达标可在 output 里加 while 循环。char 比较按 ASCII 码。

### 三大易错点

1. **class vs typename**：完全等价，可互换；typename 语义更清晰。
2. **类外定义漏 template 前缀**：`void Test<T>::setData(...)` 缺 `template<class T>` → 编译错误。正确：`template<class T> void Test<T>::setData(...)`。
3. **声明定义分离 .h/.cpp**：main 里实例化时看不到定义 → 链接错误 LNK2019。正确：模板声明和定义都放头文件。

### 函数模板 vs 类模板

| 维度 | 函数模板 | 类模板 |
| --- | --- | --- |
| 定义 | template<class T> 返回类型 函数名(参数) | template<class T> class 类名 {...} |
| 实例化 | 调用时自动推演/显式<> | 必须显式 <类型> |
| 成员函数 | 模板即函数 | 类外定义加 template 前缀 |
| 组织 | 模板定义放头文件 | 声明定义必须同头文件 |
| 场景 | 通用算法 | 通用数据结构 |

## 九、随身速记口诀

1. 模板是模具不是代码，编译器照着实例化出各类型的真函数、真类。
2. 函数模板靠推演，类模板必须加尖括号；类外定义三件套：template 前缀 + Test<T>:: 作用域 + 全放头文件。
3. typedef 定死、using 留活口；类型对不上就多给一个模板参数。

## 十、下节课预告

STL（标准模板库）—— 模板技术的集大成应用。
