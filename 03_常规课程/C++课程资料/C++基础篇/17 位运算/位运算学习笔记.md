## 模块一（基础篇）

### 1. 位运算概述【了解】（P4-5）

**一句话**：位运算就是直接对整数在内存中的二进制位进行的运算。

- 计算机的世界就是二进制世界，所有数据都以 0、1 两种状态存储在设备中。
- 位运算直接操作底层二进制位，**效率高、代码简洁**，与指针并列 C/C++ 两大特色。
- 算术运算（+、-、*、/）也可以看成"符号位共同参与"的位运算，但位运算比它们更贴近硬件。

**六个位运算符总览（P5）**：

| 运算符 | 含义 | 举例 |
|---|---|---|
| & | 按位与 | a & b |
| \| | 按位或 | a \| b |
| ^ | 按位异或 | a ^ b |
| ~ | 按位取反 | ~a |
| << | 左移 | a << 1 |
| >> | 右移 | b >> 2 |

**人话总结**：位运算 = 直接拨动二进制开关。

### 2. 按位取反 ~【重点】（P6-8）

**① 是什么**：对一个数的**每一个二进制位**取反：1 变 0，0 变 1（单目运算符）。

**② 为什么**：需要"整体翻转"或"构造掩码"时，~ 是最快的工具。最典型的用途：让某个数的最低位变成 0（a & ~1），而不用关心这个数是几个字节。

**③ 怎么用**：

运算规则表：

| ~ | 结果 |
|---|---|
| ~0 | 1 |
| ~1 | 0 |

教材示例（P7）：

```
 a  = 01111010
~a  = 10000101
```

逐位对照：每一位都反过来。验证：0x7A = 122，~122 按补码 = -123，而 10000101 作为补码恰好是 -123，一致。

配套代码：code.cpp 中没有 ~ 的示例，这里补一段代码片段（嵌入到完整的 main + iostream 中可直接运行）：

```cpp
int a = 0x7A;              // 01111010 = 122
cout << (~a) << endl;      // 输出 -123（每一位取反）
int x = 7;                 // 00000111
cout << (x & ~1) << endl;  // 输出 6：最低位被清零
```

**④ 注意事项**：
- ~ 的优先级比算术运算符、关系运算符、逻辑运算符**都高**（P8），所以 `a & ~1` 不用给 ~1 加括号，先算 ~ 再算 &。
- ~1 的值不是"1 变 0 那么简单"，在 32 位 int 里 ~1 = 11111111 11111111 11111111 11111110（即 -2），最低位为 0、其余全为 1，所以它和任何数相与，只削掉最低位（P8 的用途原理）。

**人话总结**：~ 就是全体位大翻转。

## 模块二（逻辑篇）

### 3. 按位与 &【重点】（P9-11）

**① 是什么**：两个数按二进制位对齐，**两位同时为 1，结果才是 1**，否则为 0。

**② 为什么**：它是"筛选器"——想留下哪些位，就用 1 去遮；想清掉哪些位，就用 0 去遮。清零、取位、判奇偶全靠它。

**③ 怎么用**：

运算规则表：

| & | 0 | 1 |
|---|---|---|
| **0** | 0 | 0 |
| **1** | 0 | 1 |

教材示例（P10）：

```
a  = 01111010
b  = 10011000
&  = 00011000   ← 只有两位同时是1的地方留下1
```

验证：0x7A & 0x98 = 0x18 = 24，正确。

**三大用途（P11）**：

| 用途 | 做法 | 示例 |
|---|---|---|
| 1. 清零 | 与一个各位全 0 的数相与 | x & 0 = 0 |
| 2. 取指定位 | 与"目标位为1、其余为0"的掩码相与 | X=10101110 取低4位：X & 00001111 = 00001110 |
| 3. 判断奇偶 | 看最低位：0 偶 1 奇 | if ((a & 1) == 0) 等价于 a % 2 == 0 |

配套代码：code.cpp 第①段（被注释的奇偶判断）：

```cpp
int num = 130;
if ((num & 1)) {
    cout << "奇数" << endl;
} else {
    cout << "偶数" << endl;
}
```

**输出结果：偶数**。推导：130 = 10000010，最低位是 0，所以 num & 1 = 0，条件为假走 else。放开注释后运行即得此结果。注意源文件里中文是 GBK 乱码显示，语义就是"奇数/偶数"两支。

与 %2 的效率对比：% 需要除法运算，& 1 只需一次按位与，更贴近硬件、更快（现代编译器会把 %2 优化成 &1，但位运算写法是底层原理的直接体现）。

**④ 注意事项**：
- **& 和 && 完全不同**：& 是按位与（逐位运算），&& 是逻辑与（整体真假判断），别混用。
- **优先级大坑**：& 的优先级**低于** ==！`if (num & 1 == 0)` 实际是 `num & (1 == 0)` = `num & 0` = 恒 0，永远判"偶数"。必须写 `(num & 1) == 0`。code.cpp 里写的是 `if ((num & 1))`，把整体括起来，正确。

**人话总结**：& 是遮罩，同 1 才透光。

### 4. 按位或 |【重点】（P12-14）

**① 是什么**：两个数按位对齐，**两位同时为 0，结果才是 0**，否则为 1。

**② 为什么**：它是"开关打开器"——想把某些位强制变成 1（打开开关），用 | 最直接。

**③ 怎么用**：

运算规则表：

| \| | 0 | 1 |
|---|---|---|
| **0** | 0 | 1 |
| **1** | 1 | 1 |

教材示例（P13）：

```
a  = 01111010
b  = 10011000
|  = 11111010   ← 只要有一个1就为1
```

验证：0x7A | 0x98 = 0xFA = 250，正确。

**主要用途（P14）：把某些位设置为 1**。
比如将 X=10101110 的低 4 位全部置 1：找 Y=00001111（低 4 位为 1 其余为 0），X | Y = 10101111。

配套代码：code.cpp 中没有 | 的独立示例，补一段：

```cpp
int x = 0xAE;              // 10101110
cout << (x | 0x0F) << endl;// 10101111 = 175：低4位被置1
int flags = 0;             // 00000000
flags = flags | 0b0100;    // 把第2位"打开"→ 00000100
```

**④ 注意事项**：
- **| 和 || 不同**：| 是按位或，|| 是逻辑或。
- 置 1 用 |、清 0 用 &（配合 ~），两者配合才能自由操纵任意位。

**人话总结**：| 是开闸，有 1 就放行。

### 5. 按位异或 ^【重点】（P15-17）

**① 是什么**：两个数按位对齐，**相同为 0，不同为 1**（"不同"才叫"异"或）。

**② 为什么**：它是"翻转器 + 无痕交换器"——对 1 异或的位被翻转，对 0 异或的位原样保留；还自带 a^a=0、a^0=a 两条黄金性质，能不借助临时变量交换两个数。

**③ 怎么用**：

运算规则表：

| ^ | 0 | 1 |
|---|---|---|
| **0** | 0 | 1 |
| **1** | 1 | 0 |

教材示例（P16）：

```
a  = 01111010
b  = 10011000
^  = 11100010   ← 不同的位是1，相同的位是0
```

验证：0x7A ^ 0x98 = 0xE2 = 226，正确。

**三大用途（P17）**：

| 用途 | 做法 | 示例 |
|---|---|---|
| 1. 翻转指定位 | 目标位与 1 异或 | X=10101110 低4位翻转：X ^ 00001111 = 10100001 |
| 2. 与 0 异或值不变 | a ^ 0 = a | 10101110 ^ 00000000 = 10101110 |
| 3. 交换两个数 | 三行异或，不用临时变量 | a^=b; b^=a; a^=b; |

配套代码：code.cpp 第④段（当前唯一未注释、正在生效的代码）：

```cpp
int num1 = 100, num2 = 200;
cout << "num1 = " << num1 << "  num2 = " << num2 << endl;
num1 ^= num2;
num2 ^= num1;
num1 ^= num2;
cout << "num1 = " << num1 << "  num2 = " << num2 << endl;
```

**输出结果**：

```
num1 = 100  num2 = 200
num1 = 200  num2 = 100
```

逐行推导（用到交换律、结合律、a^a=0、a^0=a）：

| 步骤 | 运算 | 结果 | 推导 |
|---|---|---|---|
| 初始 | num1=100, num2=200 | - | 100=01100100，200=11001000 |
| 第1行 | num1 ^= num2 | num1 = 100^200 = **172** | num1 变成"混合值" |
| 第2行 | num2 ^= num1 | num2 = 200 ^ 172 = **100** | 200 ^ (100^200) = (200^200)^100 = 0^100 = 100 |
| 第3行 | num1 ^= num2 | num1 = 172 ^ 100 = **200** | (100^200)^100 = (100^100)^200 = 0^200 = 200 |

**④ 注意事项**：
- 异或满足**交换律和结合律**（这是三行交换能成立的数学基础）。
- 异或交换**只能用于整数**，不能用于浮点数。
- **同址清零陷阱**：如果两个变量指向同一块内存（如 swap(x, x) 或通过指针/引用传入同一变量），第一步 num1^=num1 后整块内存变 0，数据丢失。

**人话总结**：^ 不同为 1，还能空手换值。

**⑤ 异或的实战应用场景（拓展）**

异或凭借 `a^a=0` 和 `a^0=a` 两条黄金性质，在算法题和工程里非常常见，教材没讲但非常值得知道：

| 场景 | 思路 | 示例 |
|------|------|------|
| 1. 简单加密 | 文本逐字节与密钥异或 | `cipher = plain ^ key`；解密 `plain = cipher ^ key`（同 key 异或两次恢复原值） |
| 2. 找出现一次的数 | 一堆成对数字中有一个落单，把全部异或起来 | `[1,2,3,2,1]` → 全部异或 = `3`（成对的都被消掉） |
| 3. 不借临时变量交换两数 | 三行 `a^=b; b^=a; a^=b;` | 教材练习 1 已讲 |
| 4. 翻转指定位 | 与 1<<k 异或 | `a ^ (1<<3)` 翻转第 3 位 |
| 5. 判断两数是否相等 | `a ^ b == 0` | 比 `a == b` 在某些硬件上更快 |

**经典代码示例**（找落单的数，LeetCode 136 简化版）：

```cpp
int arr[] = {1, 2, 3, 2, 1, 4, 4};
int single = 0;
for (int x : arr) single ^= x;  // 成对消掉，留下的就是答案
cout << single;  // 输出 3
```

**人话总结**：异或三件套 = 加密、找单数、不用 temp 交换。

### 6. &、|、^ 三兄弟对比（P9-17 小结）

| 运算符 | 规则 | 记忆口诀 | 典型用途 |
|---|---|---|---|
| & 按位与 | 同 1 才 1 | 全一才一 | 清零、取指定位、判奇偶 |
| \| 按位或 | 同 0 才 0 | 有 1 则 1 | 把某些位置 1 |
| ^ 按位异或 | 相同 0 不同 1 | 不同为一 | 翻转指定位、交换两数、与 0 异或保值 |

三者对照同一个例子：

```
a  = 01111010
b  = 10011000
a&b= 00011000    ← 只保留公共的1
a|b= 11111010    ← 合并所有的1
a^b= 11100010    ← 剔除相同的位
```

## 模块三（移位篇）

### 7. 左移 <<【重点】（P18-19）

**① 是什么**：各二进制位全部左移 n 位，**左边丢弃、右边补 0**。

**② 为什么**：二进制下左移一位就是乘 2，这是乘法里最快的实现；构造掩码（1 << k）也全靠它。

**③ 怎么用**：

教材示例（P18）：设 a=10101110，a<<2 → 左移 2 位、右补 0 → 10111000（左边 10 被丢弃）。

教材示例（P19）：

```
00001011 << 1 = 00010110   即 11 << 1 = 22
00001011 << 2 = 00101100   即 11 << 2 = 44
```

数学意义：m << n 等价于 m × 2ⁿ。

配套代码：code.cpp 第②段（被注释的左移）：

```cpp
int num = 11;
cout << (num << 2) << endl;   // 输出 44
```

**输出结果：44**。推导：11 = 00001011，左移 2 位右补 0 → 00101100 = 44 = 11 × 4。注意 cout 后面是 `(num << 2)`，**括号强烈建议加**：`<<` 在 C++ 里既是位移运算符又是流插入运算符，写 `cout << num << 2` 编译器会按流插入链式解析（输出 num 的值再输出 2），结果与"先算位移再输出"完全不同。加括号既明确语义（先算 `num << 2` 得到 44，再插入到 cout），又消除阅读歧义。虽然严格说语法上不强制报错（位移优先级高于流插入），但**不写括号会让代码意图不清，是坏习惯**。

**④ 注意事项**：
- 左移时**被丢弃的高位若包含 1，结果溢出**，不再等于乘 2ⁿ（P18 原话：若舍弃的高位不包含 1，才每左移一位相当于乘 2）。
- 左移负数或移位位数 ≥ 类型位数是未定义/受限制行为，新手只对非负数用即可。

**人话总结**：左移 n 位 = 乘 2 的 n 次方。

### 8. 右移 >>【重点】（P20-21）

**① 是什么**：各二进制位全部右移 n 位，**右边丢弃**；左边补什么看符号：**正数左补 0，负数左补 1**（符号位扩展）。

**② 为什么**：右移是左移的逆操作，除以 2ⁿ 的最快实现；取某个二进制位的经典套路 (num >> i) & 1 也靠它。

**③ 怎么用**：

教材示例（P21）：

```
00001011 >> 1 = 00000101   即 11 >> 1 = 5
```

数学意义：右移 n 位相当于除以 2ⁿ 的**整除**（小数部分直接丢弃）。11 >> 1 = 11/2 = 5.5 → 取 5。

配套代码：code.cpp 第③段（被注释的右移）：

```cpp
int num = -11;
cout << (num >> 1) << endl;   // 输出 -6
```

**输出结果：-6**（在 MSVC/GCC/Clang 下均是）。推导（8 位示意，32 位同理）：

```
-11 的原码 = 10001011
   反码    = 11110100（符号位不变，其余取反）
   补码    = 11110101（反码+1，计算机里存的是这个）
右移1位，负数左补1：11111010
还原：这是负数的补码 → 减1得11111001 → 取反得00000110 = 6 → 加负号 = -6
```

**为什么不是 -5？** C++ 的 `/` 是向零取整（-11/2 = -5），而右移是向负无穷取整（floor，-11/2 → -6）。右移对负数比整除"多丢 1"，两者不可混用。

**④ 注意事项**：
- 右移不担心溢出，但**是整除**，小数部分直接丢弃（P21 原话）。
- P21 注：此为**带符号右移**，高位空位补符号位，正补 0、负补 1。C++20 之前这属于实现定义行为，主流编译器都补符号位；C++20 起标准明确规定为算术右移。
- 想让负数也按"无符号"逻辑右移，需转成 unsigned 再移。

**人话总结**：右移 n 位 = 除以 2ⁿ 取整，负数补 1。

### 9. 位运算赋值运算符【熟悉】（P22）

**① 是什么**：位运算与赋值结合的复合运算符，共 5 个。

**② 为什么**：写法更短，和 +=、-= 一个道理。

**③ 怎么用**：

| 复合运算符 | 含义 | 举例 | 等同于 |
|---|---|---|---|
| &= | 位与赋值 | a &= b | a = a & b |
| \|= | 位或赋值 | a \|= b | a = a \| b |
| ^= | 位异或赋值 | a ^= b | a = a ^ b |
| <<= | 左移赋值 | a <<= b | a = a << b |
| >>= | 右移赋值 | a >>= b | a = a >> b |

配套代码：code.cpp 第④段里的 `num1 ^= num2;` 就是**位异或赋值**，等同于 `num1 = num1 ^ num2;`。

**④ 注意事项**：复合运算符左边必须是可修改的变量；a <<= b 里 b 为负或超位宽是未定义行为。

**人话总结**：位运算赋值 = 算完塞回原变量。

## 模块四（实战篇）

### 10. 课堂练习1：异或交换两个数（P23-24）

**题目（P23 原文）**：输入两个整数 num1 和 num2，利用位运算交换它们的值。

**思路分析**：利用异或三条性质——交换律 (a^b = b^a)、结合律、a^a=0、a^0=a。目标是让一方先"记住"两数的混合信息，再分两次还原出对方。

**参考代码（P24 原文）**：

```cpp
int num1, num2;
cin >> num1 >> num2;
num1 ^= num2;      // num1 变成 num1^num2
num2 ^= num1;      // num2 = num2^(num1^num2) = num1（原值）
num1 ^= num2;      // num1 = (num1^num2)^num1 = num2（原值）
cout << num1 << endl;
cout << num2 << endl;
```

**逐步推导**（以 100、200 为例）：

1. `num1 ^= num2` → num1 = 100^200 = 172（混合值）
2. `num2 ^= num1` → num2 = 200^172 = 200^(100^200) = (200^200)^100 = 0^100 = **100**（原 num1）
3. `num1 ^= num2` → num1 = 172^100 = (100^200)^100 = (100^100)^200 = 0^200 = **200**（原 num2）

以 code.cpp 实际运行（100、200）验证：输出 num1 = 200  num2 = 100，交换成功。

**注意事项**：
- 只适用于整数；浮点数没有按位异或语义。
- 两个变量不能是**同一块内存**（同一个变量自我"交换"会直接清零：x^x=0）。
- 实际工程更推荐 `swap(num1, num2)`，异或交换的价值在于理解异或性质。

### 11. 课堂练习2（作业）：输出一个整数的二进制形式（P26）

**题目（P26 原文）**：利用位运算输出一个整数的二进制形式。输入 612，输出 `0000001001100100`。

**思路分析**：
- 612 = 512+64+32+4 = 2⁹+2⁶+2⁵+2²，其二进制为 1001100100（10 位），按 16 位补齐前导 0 → 0000001001100100。
- 核心套路：**从高位到低位，逐位取出**。第 i 位的值 = (num >> i) & 1——先把第 i 位挪到最低位，再用 & 1 截取。
- i 从"总位数-1"遍历到 0，即可从最高位打印到最低位。

**解法代码**（按教材输出格式，16 位）：

```cpp
int num;
cin >> num;
for (int i = 15; i >= 0; i--) {        // 从最高位(15)到最低位(0)
    cout << ((num >> i) & 1);          // 取出第i位并输出
}
cout << endl;
```

运行验证：输入 612 → 输出 `0000001001100100`，与作业要求一致。

**扩展版**（输出完整的 32 位，负数也正确）：

```cpp
int num;
cin >> num;
for (int i = 31; i >= 0; i--) {
    cout << ((num >> i) & 1);
    if (i % 4 == 0 && i) cout << ' ';  // 每4位加空格便于阅读
}
cout << endl;
```

输入 612 输出：`0000 0000 0000 0000 0000 0010 0110 0100`。负数如 -11 也能正确输出其补码形式（因为右移补符号位，(num>>i)&1 取出的就是补码位）。

**人话总结**：右移到位，与 1 截取。

## 第三阶段·补：易错点速查卡

### 五种位运算核心特性总表

| 运算符 | 运算规则 | 典型用途 | 数学意义 | 易错点 |
|---|---|---|---|---|
| & 按位与 | 同 1 才 1 | 清零、取指定位、判奇偶 (x&1) | 无直接对应 | 优先级低于 ==，必须写 (x&1)==0；与 && 混淆 |
| \| 按位或 | 同 0 才 0 | 把某些位置 1 | 无直接对应 | 与 \|\| 混淆 |
| ^ 按位异或 | 同 0 异 1 | 翻转指定位、交换两数、a^0=a | 无直接对应 | 同址交换会清零；只限整数 |
| << 左移 | 左丢右补 0 | 快速乘 2ⁿ、构造掩码 1<<k | m<<n = m×2ⁿ | 丢弃的高位含 1 时溢出；cout 里要加括号 |
| >> 右移 | 右丢，正补 0 负补 1 | 快速除 2ⁿ、逐位取值 (x>>i)&1 | m>>n = m÷2ⁿ 整除 | 负数是 floor 整除（-11>>1=-6，不是-5）；与 / 的向零取整不同 |

### 最容易出错的 4 个点（第三阶段重点）

1. **优先级问题**：~ 的优先级高于算术、关系、逻辑运算符（P8），所以 a & ~1 里 ~1 先算；但 &、^、| 的优先级**低于** ==，`num & 1 == 0` 是大坑，等价于 `num & (1==0)` = 0，必须写 `(num & 1) == 0`。位移符 << >> 在 cout 里与流插入 << 同名，表达式必须加括号：`cout << (num << 2)`。
2. **右移的符号位**：正数左补 0、负数左补 1（符号位扩展）。主流编译器均如此，C++20 起标准明确；负数右移是向负无穷取整，-11 >> 1 = -6 而非 -5。
3. **异或交换的陷阱**：交换两数的三行异或，前提是 num1、num2 是**不同的内存**；通过指针/引用交换同一变量时第一步就 x^x=0，数据清零。
4. **`int` 与 `unsigned` 混用的右移差异** ⚠️：有符号数 `int` 右移补符号位，无符号数 `unsigned` 永远补 0。这一区别在处理"位掩码"、"哈希"、"网络字节序"等场景非常关键——如果想拿到"逻辑右移"（高位补 0）的稳定行为，应该先转成 `unsigned` 再移。示例：

```cpp
int      a = -1;       // 11111111 11111111 11111111 11111111
unsigned b = (unsigned)a;
cout << (a >> 4);      // 输出 -1（算术右移，全补 1）
cout << (b >> 4);      // 输出 268435455 = 0x0FFFFFFF（逻辑右移，补 0）
```

## 第四阶段·测：随堂测验（答案留空，先自己写）

**第 1 题（★ 位运算基础：写出表达式的值）**

设 `int a = 12, b = 10;`（提示：12=1100，10=1010），写出下列各式的十进制结果：

1. a & b = ______
2. a | b = ______
3. a ^ b = ______
4. ~5 = ______
5. 7 << 2 = ______
6. -8 >> 1 = ______

> 💡 **解题思路提示**
> - 1-3 题：把 a、b 写成 4 位二进制（1100、1010），逐位按"同 1 才 1 / 有 1 就 1 / 不同为 1"算出结果，再转十进制。
> - 第 4 题（~5）：5 = 0000 0101，~ 后变 1111 1010，按补码解读 = -6（口诀：~x = -(x+1)）。
> - 第 5 题（7 << 2）：7 × 2² = 28。
> - 第 6 题（-8 >> 1）：算术右移补符号位，-8/2 向负无穷取整 = -4。

---

**第 2 题（★★ 位运算应用：判奇偶与取位）**

1. 不用 %，用一条位运算表达式判断 int x 的奇偶（结果为 1 表示奇数，0 表示偶数）：表达式 = ______
2. 取出 int x 的第 3 位（从第 0 位数起）的值：表达式 = ______
3. 把 int x 的最低位强制清零，其余位不变：表达式 = ______

> 💡 **解题思路提示**
> - 第 1 小题：取最低位 → `x & 1`（奇数结果为 1，偶数结果为 0）。
> - 第 2 小题：第 i 位用 `(x >> i) & 1`，i=3 即 `(x >> 3) & 1`。
> - 第 3 小题：清零 = 与 0；最低位要变 0、其他位不变 → 掩码是 `...11111110` → `~1`。答案：`x & ~1`。

---

**第 3 题（★★★ 综合：移位与逻辑混合）**

设 `unsigned char x = 0xD3;`（二进制 11010011）：

1. 将 x 的低 4 位清零、高 4 位保留：表达式 = ______（写出结果二进制）
2. 将 x 的最高位（第 7 位）翻转、其余位不变：表达式 = ______（写出结果二进制）
3. `(x >> 4) & 0x0F` 的作用是什么？对 x=0xD3 结果是多少？______

> 💡 **解题思路提示**
> - 第 1 小题：低 4 位清零 = 掩码高 4 位 1、低 4 位 0，即 `0xF0`（11110000）。答案：`x & 0xF0` = 11010000。
> - 第 2 小题：翻转第 7 位 → 与 1<<7 异或。答案：`x ^ 0x80`（10000000）= 01010011。
> - 第 3 小题：右移 4 位留下高 4 位，与 0x0F 截取后正好是高 4 位原本的值；作用是"**取高 4 位**"（高 4 位移到低 4 位位置）。x=0xD3 时结果 = 0x0D = 13。

**第 4 题（★★★★ 编程题）**

编写完整程序：输入一个整数（可能为负数），输出它的 32 位二进制补码形式，每 8 位用空格分隔。
示例：输入 612，输出 `00000000 00000000 00000010 01100100`；输入 -1，输出 `11111111 11111111 11111111 11111111`。
要求：只用位运算取位（禁止 bitset），并说明为什么负数也能输出正确结果。

> 💡 **解题思路提示**
> - 循环结构：`for (int i = 31; i >= 0; i--)`，i 从 31 递减到 0。
> - 取第 i 位：`(num >> i) & 1`。
> - 加空格：每 8 位用一次空格 → `if (i % 8 == 0 && i != 0) cout << ' ';` 或 `if (i == 23 || i == 15 || i == 7) cout << ' ';`。
> - 负数也能正确：负数在内存中存的就是补码形式（最高位全 1），`>> i` 算术右移补符号位，`& 1` 取出每一位就是补码位 → 输出结果恰好等于"补码的二进制表示"。
> - 进阶思考：如果改用 `unsigned int` 存，会发生什么？提示：右移从"补符号位"变成"补 0"，高位会全变 0 而不是 1，结果会丢符号信息。
