# 模块一：流与文件基础概念（P1-P12）

## 知识点1：数据流的概念（P4）【了解】

**①是什么**：数据流（data stream）是一组**有序、有起点和终点**的字节序列，包括输入流和输出流。C++ 通过"流（stream）"机制提供灵活且面向对象的 I/O 方法。按操作对象分为三类：文件流、字符串流、控制台流。

**生活化比喻**：流像自来水管——数据是水，从水源（文件/键盘/字符串）流向水池（程序），或者反向流出；你只管拧阀门（运算符），不用关心水在管子里怎么走。

**②为什么**：把各种 I/O 设备（屏幕、键盘、文件、字符串）统一抽象成"流"，同一套 `<<` `>>` 接口操作所有设备，代码风格一致。

**三类流一览**（课件 P5、P6、P10）：

| 流类别 | 头文件 | 相关类 | 用途 |
|--------|--------|--------|------|
| 控制台流 | `<iostream>` | istream/ostream/iostream | cin/cout 屏幕键盘 |
| 文件流 | `<fstream>` | ifstream/ofstream/fstream | 磁盘文件读写 |
| 字符串流 | `<sstream>`/`<strstream>` | istringstream/ostringstream（C++风格）；istrstream/ostrstream/strstream（C风格） | 内存字符串当流处理 |

> 人话总结：流是统一的水管接口，万物皆可流。

## 知识点2：文件处理简介（P11-P12）【了解】

**①是什么**：C++ 的文件处理也看作对象，使用文件流类（头文件 `<fstream>`）。文件分文本文件和二进制文件，**主要区别是存储形式**。三个核心类：

| 类 | 能力 | 来源 |
|----|------|------|
| ofstream | 写操作（输出） | 由 ostream 引申 |
| ifstream | 读操作（输入） | 由 istream 引申 |
| fstream | 同时读写 | 由 iostream 引申 |

**文件处理基本流程（三步）**（课件 P12 原文）：

```
打开文件 → 处理文件 → 关闭文件
```

**②为什么**：文件是外部设备资源，必须先建立关联（打开）、用完归还（关闭），否则数据可能丢失（缓冲区未刷回）或资源泄漏。

> 人话总结：开文件、用文件、关文件，三步走完。

# 模块二：文本文件读写实战（P13-P32）

## 知识点3：文件的输入与输出（P13-P18）【重点】

**①是什么**：读写前必须先打开文件。`open()` 是 fstream/ifstream/ofstream 的成员函数：

```
void open(const char *filename, ios::openmode mode);
```

第一参数是文件名和位置，第二参数是打开模式。

**②打开模式标志**（课件 P8-P9 mode 属性）：

| 标志 | 含义 |
|------|------|
| `ios::in` | 读（打开文件用于读取） |
| `ios::out` | 写（打开文件用于写入，**默认清空文件**） |
| `ios::app` | 追加（所有写入都在文件末尾） |
| `ios::trunc` | 截断（文件存在则清空） |
| `ios::binary` | 二进制模式 |
| `ios::ate` | 打开后定位到文件末尾 |

**模式组合**：用 `|` 连接（课件原文："或"或"+"把属性连接起来）。课件例子：

```cpp
ofstream outf;
outf.open("file.txt", ios::out | ios::trunc);  // 写入并截断（防已存在）
fstream file;
file.open("file.txt", ios::out | ios::in);     // 读写
```

**三类流的默认打开模式对比表**（课件 P16）：

| 流类 | 默认模式 | 说明 |
|------|----------|------|
| ofstream | `ios::out` | 只写，会清空 |
| ifstream | `ios::in` | 只读 |
| fstream | `ios::in \| ios::out` | 读写，不清空（无 out 单独截断语义时） |

**③写入与读取**（课件 P17）：
- **写入**：流插入运算符 `<<`，和输出到屏幕一样，只是对象换成 ofstream/fstream（不是 cout）；
- **读取**：流提取运算符 `>>`，和从键盘输入一样，只是对象换成 ifstream/fstream（不是 cin）。

**④关闭文件**（课件 P18）：程序终止时会自动关闭刷新所有流，但**应养成好习惯，终止前手动关闭所有文件**：

```
void close();
```

**④注意事项**：

```cpp
// 错误示范：打开后不检查是否成功
ifstream in;
in.open("不存在的文件.txt");
string s;
in >> s;            // 文件没打开，读取行为无意义
// 正确：
if (!in.is_open()) { cout << "打开失败" << endl; return 0; }
```

> 人话总结：open 定模式，<< 写 >> 读，用完 close。

## 知识点4：文件写入案例（P19-P21）【熟悉】

**文件写入五步法**（课件 P21 总结）：
1. 包含头文件 `<fstream>`
2. 创建流对象
3. 打开文件
4. 写入内容
5. 关闭文件

**覆盖写入（默认）**（课件 P19）——每次运行覆盖原内容：

```cpp
#include <iostream>
#include <fstream>          // 1.头文件
using namespace std;
int main() {
    ofstream outf;          // 2.创建流对象
    outf.open("file.txt");  // 3.打开（默认 ios::out，覆盖）
    outf << "     山村咏怀" << endl;          // 4.写入
    outf << "       邵雍" << endl;
    outf << "一去二三里，烟村四五家。" << endl;
    outf << "亭台六七座，八九十枝花。" << endl;
    outf.close();           // 5.关闭
    return 0;
}
```

**追加写入**（课件 P20）——`ios::app`，每次运行不覆盖：

```cpp
ofstream outf;
outf.open("file.txt", ios::app);   // 追加模式
outf << "     山村咏怀" << endl;   // 内容接在文件末尾
// ... 其余写入相同
outf.close();
```

**配套代码 test01() 走读**：

## 知识点5：文件读取案例（P22-P25）【熟悉】

**`>>` 的局限**（课件 P22 设问"能读取全部内容吗？"）：`>>` 以空格为分隔符，遇到空格就停——读不到含空格的全部内容。课件原文：可调用 get 函数来读取内容。

**四种读取方式对比表**（课件 P23-P24 + 配套代码 test04-test07）：

| # | 方式 | 代码 | 特点 |
|---|------|------|------|
| ① | char + get() 逐字符 | `while ((c = ifs.get()) != EOF)` | 效率低，不建议 |
| ② | char[] + `>>` 按词 | `while (ifs >> buf)` | 遇空格断开 |
| ③ | char[] + getline() 按行 | `while (ifs.getline(buf, sizeof(buf)))` | 按行读，需定长缓冲 |
| ④ | string + getline() 按行 | `while (getline(ifs, buf))` | **推荐**：自动变长 |

**逐字符读取**（课件 P23）：

```cpp
#include <iostream>
#include <fstream>
using namespace std;
int main() {
    char a;
    ifstream infile;
    infile.open("file.txt");       // 建立文件与流的关联
    while (!infile.eof()) {        // 未到文件尾
        infile.get(a);             // 逐字符取出
        cout << a;
    }
    infile.close();                // 断开关联
    return 0;
}
```

**四种方式完整版**（课件 P24）：

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;
int main() {
    ifstream ifs;
    ifs.open("file.txt", ios::in);
    if (!ifs.is_open()) {               // 打开失败检查
        cout << "文件打开失败！" << endl;
        return 0;
    }
    // 第一种：效率低，不建议
    // char c; while ((c = ifs.get()) != EOF) cout << c;
    // 第二种：按词（空格断开）
    // char buf[1024] = {0}; while (ifs >> buf) cout << buf << endl;
    // 第三种：按行（定长缓冲）
    // char buf[1024] = {0}; while (ifs.getline(buf, sizeof(buf))) cout << buf << endl;
    // 第四种：推荐——string 按行
    string buf;
    while (getline(ifs, buf))           // getline 需 <string>
        cout << buf << endl;
    ifs.close();
    return 0;
}
```

**文件读取五步法**（课件 P25）：1.包含头文件 → 2.创建对象 → 3.打开文件 → 4.读取内容 → 5.关闭文件。

**配套代码 test02()~test07() 走读**：

| 函数 | 演示内容 | 关键行解释 |
|------|----------|-----------|
| test02 | `infile >> cf`（string） | 只读第一个词（遇空格停）——演示 `>>` 的局限 |
| test03 | `char cf` + get() + `!eof()` 循环 | 逐字符输出全文；注释掉的 `char cf[1024]` 是备选的缓冲写法 |
| test04 | `char c; while ((c = infile.get()) != EOF)` | 方式①，注释标注"效率较低，不建议使用" |
| test05 | `string str; while (getline(infile, str))` | 方式④推荐写法 |
| test06 | `char buf[1024]; while (infile >> buf)` | 方式②按词读取 |
| test07 | `char buf[1024]; while (infile.getline(buf, sizeof(buf)))` | 方式③按行读取 |

每个函数都含 `is_open()` 检查：`if (!infile.is_open()) { cout << "文件打开失败" << endl; return; }`——课件强调的正确姿势。

**文件状态检查五函数**（专项补充）：

| 函数 | 含义 | 使用时机 |
|------|------|----------|
| `is_open()` | 文件是否打开成功 | **打开后立即检查** |
| `good()` | 流状态正常 | 综合判断 |
| `fail()` | 上次操作失败（格式错误等） | 读取失败分支 |
| `eof()` | 到达文件尾 | 循环终止条件 |
| `bad()` | 严重错误（流损坏） | 异常处理 |

```cpp
// 错误示范：打开失败未检查，后续直接用 → 数据错误甚至崩溃
// 正确：先 is_open()，读后判 eof()/fail()
```

> 人话总结：读取四招，getline+string 最好；打开先查 is_open。

# 模块三：二进制文件与综合操作（P26-P40）

## 知识点6：二进制文件读写（P26-P29）【重点】

**①是什么**：
- **写**：流对象调用成员函数 `write()`——`ostream& write(const char* buffer, int len);`（buffer 指向内存数据，len 是字节数）；
- **读**：成员函数 `read()`——`istream& read(char* buffer, int len);`

**文本文件 vs 二进制文件对比表**：

| 对比项 | 文本文件 | 二进制文件 |
|--------|----------|-----------|
| 打开方式 | 无 `ios::binary` | 加 `ios::binary` |
| 读写函数 | `<<` / `>>` / getline | `write()` / `read()` |
| 存储形式 | 可读字符（ASCII） | 原始字节（内存镜像） |
| 可读性 | 记事本可直接看 | 打开是乱码 |
| 适用场景 | 配置文件、日志、作文 | 对象快照、图片、大数据量 |

**最小示例（文本）**：

```cpp
ofstream out("a.txt");            // 文本
out << 12345;                     // 存成 5 个字符 '1','2','3','4','5'
```

**最小示例（二进制）**：

```cpp
ofstream out("a.bin", ios::binary);
int x = 12345;
out.write((char*)&x, sizeof(x));  // 存成 4 个原始字节
```

**③怎么用**（课件写案例，P27）：

```cpp
#include <iostream>
#include <fstream>
using namespace std;
class Student {
public:
    Student() {}
    Student(string name, int age) : name(name), age(age) {}
protected:
    string name;
    int age;
};
int main() {
    ofstream bof;
    Student s1("张三", 100);
    bof.open("student.txt", ios::out | ios::binary);   // 二进制写模式
    bof.write((const char*)&s1, sizeof(Student));      // 整个对象内存镜像写入
    bof.close();
    return 0;
}
```

**读案例**（课件 P29）：

```cpp
ifstream bif;
bif.open("student.txt", ios::in | ios::binary);
if (!bif.is_open()) {
    cout << "文件打开失败" << endl;
    return 0;
}
Student s2;
bif.read((char*)&s2, sizeof(Student));   // 整块读回对象
cout << s2.name << "   " << s2.age << endl;
bif.close();
```

**④注意事项——二进制读写含 string 成员的对象是陷阱**（见陷阱专题3）：

```
对象内存：  [string 对象（内含指向堆的指针）][int age]
write 写出：把"指针的值"写进文件，而不是指针指向的字符串内容！
换台机器/换个进程读回：指针地址失效 → 崩溃或乱码
```

> 人话总结：二进制读写是整块内存搬家，含指针成员要小心。

## 知识点7：fstream文件操作（P30-P37）【重点】

**①是什么**：`ifstream` 支持 `>>`，`ofstream` 支持 `<<`，**`fstream` 同时支持 `>>` 和 `<<`**——一个对象既读又写。

**②怎么用**：

**两种打开方式**（课件 P31）：

```cpp
fstream file(filename, ios::in | ios::out);   // 构造函数传文件名直接打开
// 或
fstream file;
file.open(filename, ios::in | ios::out);      // open() 打开
```

**模式语义要点**（课件 P33）：
- 模式和属性可单独使用，也可混合（用 `|` 连接）；
- **`ios::out` 默认会清空**——`ios::out|ios::trunc` 和单独 `ios::out` 打开时都会清空文件；
- 不想清空就用 `ios::out|ios::app`，数据以追加方式写入。

**读写操作全家桶**（课件 P34）：`<<`、`>>`、`read()`、`write()`、`put()`、`get()`、`getline()`。规律：

| 文件类型 | 读写方式 | 常用函数 |
|----------|----------|----------|
| 文本文件 | 逐行读写 | `<<` 写、`getline()` 读 |
| 二进制文件 | 整块读写 | `write()`/`put()` 写、`read()`/`get()` 读 |

**案例**（课件 P37，先写后读同一文件）：

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;
int main() {
    string str;
    fstream iofile;                                        // 2.创建对象
    iofile.open("file.txt", ios::out | ios::in | ios::trunc); // 3.打开（清空）
    iofile << "这里是写入内容测试" << endl;                  // 4.写入
    iofile << "this is test" << endl;
    iofile.close();                                        // 5.关闭（写后必须关）
    cout << "写入完毕" << endl;
    iofile.open("file.txt", ios::out | ios::in);           // 重新打开读
    while (getline(iofile, str))                           // 循环读取
        cout << str << endl;
    iofile.close();
    cout << "读取完毕" << endl;
    // 输出：写入完毕 / 这里是写入内容测试 / this is test / 读取完毕
    return 0;
}
```

**配套代码 test10() 走读**：

```cpp
fstream iof;
iof.open("file.txt", ios::out | ios::in | ios::trunc);  // 读写+截断
iof << "测试fstream" << endl;                            // 写入两行
iof << "123123123" << endl;
cout << "写入完毕" << endl;
iof.close();                // 先关闭：不关的话缓冲区未刷回，马上读会缺数据
iof.open("file.txt", ios::in);   // 再以读模式打开

cout << "读取完毕" << endl;
iof.close();
```

**RAII 与手动 close 对比**（专项补充）：

```cpp
// 手动 close：
ofstream out("a.txt");
out << "data";
out.close();          // 必须记得调用；若中途抛异常，这行不执行 → 数据丢失

// RAII：利用流对象析构自动关闭
{
    ofstream out("a.txt");
    out << "data";
}                     // 离开作用域自动析构 → 自动 close，异常安全
```

> 人话总结：fstream 读写一体，写完关闭再读，作用域结束自动关。

## 知识点8：文件定位和大小（P38-P40）【重点】

**①是什么**：C++ 文件定位分读位置和写位置：
- `seekg()`：设置**读**位置（get）
- `seekp()`：设置**写**位置（put）

```
istream& seekg(streamoff offset, seek_dir origin);
ofstream& seekp(streamoff offset, seek_dir origin);
```

offset 是偏移量，origin 是基准：

| 基准 | 含义 |
|------|------|
| `ios::beg` | 文件开头 |
| `ios::cur` | 当前位置 |
| `ios::end` | 文件结尾 |

**③怎么用**（课件示例）：

```cpp
inFile.seekg(2, ios::beg);   // 读指针从开头后移 2 字节
outFile.seekp(2, ios::cur);  // 写指针从当前位置后移 2 字节
```

**求文件大小**（`seekg` + `tellg` 组合，课件 P38-P40）：

```cpp
inFile.seekg(0, ios::end);          // 读指针移到末尾
streampos ipos = inFile.tellg();    // 当前位置 = 文件字节大小
```

**案例代码**（课件 P40）：

```cpp
#include <iostream>
#include <fstream>
using namespace std;
int main() {
    long start, end;
    ifstream ifile;
    ifile.open("test.txt", ios::in | ios::binary);
    start = ifile.tellg();          // 当前位置（刚打开为 0）
    ifile.seekg(0, ios::end);       // 跳到末尾
    end = ifile.tellg();            // 末尾位置
    ifile.close();
    cout << (end - start) << " bytes.\n";   // 文件字节大小
    return 0;
}
```

# 第三阶段：补

## 难点重讲一：打开模式组合的语义（放慢节奏）

```
只读：           ios::in                      （ifstream 默认）
只写（清空）：    ios::out                     （ofstream 默认，文件存在则清空！）
只写（追加）：    ios::out | ios::app          （内容加在末尾）
读写（保留内容）：ios::in | ios::out           （fstream 常用）
读写（清空）：    ios::in | ios::out | ios::trunc
二进制读写：      以上任何组合 | ios::binary
```

**为什么 `ios::out` 会清空？** 因为"写"的默认语义是"重新写一份"。想保留旧内容：要么追加（app），要么读写模式（`in|out` 不带 trunc）。

## 难点重讲二：二进制读写含 string 成员的对象（放慢节奏）

1. `Student` 含 `string name`——string 对象内部是"指针 + 长度"，真正的字符在**堆**上；
2. `write((char*)&s1, sizeof(Student))` 拷贝的是对象内存镜像——包括那个**指针的值**（地址），不是字符串内容；
3. 文件里存的地址只在当前进程有意义。读回后指针指向的地址可能无效 → 打印崩溃或乱码；
4. **正确做法**：含指针/动态内存成员的类，序列化要自定义——先写长度再写内容（或直接用文本格式、或用 JSON 等序列化库）：

```cpp
// 安全的自定义写出思路（伪代码）：
// out.write(name.size()); out.write(name.c_str(), name.size()); out.write(&age, sizeof(age));
// 读回时按相同顺序恢复
```

课件案例能"跑通"是因为同一程序内写后立即读、且 string 内部状态恰好一致——这是演示简化，工程上不可依赖。

## 常见陷阱专题（3 个最易错点）

### 陷阱1：ios::out 默认截断文件内容

- **错误写法**：以为 `open("log.txt", ios::out)` 会保留旧日志
- **后果**：每次打开文件被清空，历史数据丢失
- **正确写法**：追加用 `ios::out | ios::app`
- **如何记住**：out 是"重写"，app 才是"续写"

### 陷阱2：>> 运算符读取文本文件遇到空格就停止

- **错误写法**：用 `infile >> str` 读整行/整文件
- **后果**：只拿到第一个单词，内容丢失
- **正确写法**：按行用 `getline(infile, str)`，逐字符用 `get()`
- **如何记住**：尖括号吃词不吃句，整行交给 getline

### 陷阱3：二进制读写含 string 成员的对象

- **错误写法**：`write((char*)&对象, sizeof(对象))` 而对象含 string/指针成员
- **后果**：存下的是无效地址，读回崩溃或乱码（跨程序/跨机器必现）
- **正确写法**：自定义序列化（先长度后内容），或改用文本格式
- **如何记住**：整块搬家只适合"纯数据"，带指针的要拆包

|----------|----------|----------|------|

## 新手最常问的5个问题

**Q1：写文件后为什么要 close？**
写操作先进缓冲区，close 时才保证刷回磁盘；不关闭而程序异常退出，数据可能丢失。RAII 写法（让流对象离开作用域自动析构）可以免掉手动 close。

**Q2：文本文件和二进制文件怎么选？**
给人看的（配置、日志、文本）用文本；给程序整块存取的（对象快照、媒体数据）用二进制。文本可读可手改，二进制紧凑高效但不可读。

**Q3：fstream 和 ofstream/ifstream 怎么选？**
只写用 ofstream、只读用 ifstream、同一文件又读又写用 fstream。专一的类语义更清晰。

**Q4：eof() 为什么不适合做唯一的循环条件？**
eof 在"读完最后一个字符之后"才置位，容易多处理一次。更稳的写法是把读取操作本身作为条件：`while (getline(f, s))`、`while (f >> x)`。

**Q5：如何获取文件大小？**
`seekg(0, ios::end)` 跳到末尾再 `tellg()` 取位置，即为字节数；或先 `tellg` 起始位置再相减（更严谨）。
